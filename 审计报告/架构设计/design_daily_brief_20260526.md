# 每日重点股票操作简报 — 架构设计

> **设计人**：情墨 | **日期**：2026-05-26 | **版本**：v1.0  
> **pipeline_stage**: complete | **L级**：L1（策略/报告产出）

---

## 1. 需求摘要

在周度深度分析基础上，新增日度操作简报。定位为"每日路况"——基于周度战略，每日更新信号变化+风控检查+明日情景应对。输出PDF，每只股票独立文件。

---

## 2. 架构总览

```
Cron (Mon-Fri 15:30 CST, durable)
  ↓
腰子激活 → 日度简报流程（轻量版全团咨询）
  ↓
AI生成MD报告（4段式，≤200行）
  ↓
MD→HTML→PDF（Edge headless，复用现有CSS引擎）
  ↓
重点股票/股票报告/{名称}({代码})/重点关注股票日报_YYYYMMDD.pdf
```

## 4. 日度简报内容结构（4段式）

```
一、今日盘面速读（≤5行）
  大盘涨跌+量能 / 板块强弱 / 个股今日表现 / 北向当日流向

二、信号变化追踪（表格）
  技术四维(ADX/RSI/BB/OBV) 今日值→方向箭头 vs 昨日
  资金面 今日主力净流向 + 连续方向天数
  量价关系 今日形态
  关键价位距离 当前价距S1/S2/S3/R1/R2/R3的%

三、风控红线检查（表格）
  止损触发？S1/S2/S3是否被收盘价跌破
  不做清单触发？追涨/亏损加仓/RSI>80 等7项
  趋势健康度速查 日级敏感4项 红/黄/绿

四、明日情景应对表（三列表格）
  基于今日收盘价，更新四情景（高开/平开/低开/破位→判断→动作）
  
⚠️ 背离提示（条件输出）
  日度信号与周度趋势不一致时标注
  引用周度报告：[深度分析报告_YYYYMMDD]
```

## 5. 与周度深度分析的分工

| 内容 | 周度深度分析 | 日度操作简报 |
|:-----|:----------:|:----------:|
| 六维完整评分 | ✅ | 引用周度 |
| 三周期预判 | ✅ | 引用周度 |
| 基本面/估值/竞争格局 | ✅ | 不出现 |
| 技术信号追踪 | 快照 | **日度变化Δ** |
| 资金面追踪 | 周度趋势 | **日度流向** |
| 关键价位距离 | 计算 | **每日更新** |
| 止损触发检查 | 设定 | **每日检查** |
| 明日情景应对 | 框架 | **每日更新** |
| 不做清单检查 | 核查 | **每日核查** |

---

## 6. PDF生成方案

```
MD报告（AI产出）
  → HTML包装（基础CSS，A4纵向，字体Microsoft YaHei）
  → Edge headless --print-to-pdf
  → PDF输出
```

CSS样式继承报告样式基线v1.2品牌色（`#1a1a2e`/`#16213e`），但简化——日度简报不使用card-grid/score-card等复杂组件，仅需标题/表格/段落/警示框。
