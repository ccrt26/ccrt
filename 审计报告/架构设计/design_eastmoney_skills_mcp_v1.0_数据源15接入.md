## 三、接口契约

### 3.1 Skills API规格

```
端点:   POST https://mkapi2.dfcfs.com/finskillshub/api/claw/query
认证:   Header: apikey: <MX_APIKEY>
格式:   Content-Type: application/json
Body:   {"toolQuery": "<自然语言查询>"}
返回:   JSON (dataTableDTOList[]标准化数据 + rawTable原始数据)
限流:   50次/天/技能（免费版）
超时:   10秒
```

### 3.2 MCP Server配置契约

文件: `.claude/mcp_servers/eastmoney_skills.json`
```json
{
  "mcpServers": {
    "eastmoney_skills": {
      "type": "http",
      "url": "https://mkapi2.dfcfs.com/finskillshub/api/claw/query",
      "headers": {
        "apikey": "${MX_APIKEY}",
        "Content-Type": "application/json"
      },
      "method": "POST",
      "bodyTemplate": {"toolQuery": "{{query}}"},
      "timeout": 10000
    }
  }
}
```

API Key通过环境变量 `MX_APIKEY` 注入，不从配置文件读取。

### 3.3 数据源降级路径更新

```
研报:      东方财富[11] → Skills[15]财经资讯穿透 → 缓存[C]     ✅ 消灭独有源
宏观:      baostock[14] → Skills[15]宏观数据洞察 → 缓存[C]     ✅ 消灭独有源
资金流:    东方财富[9] → 同花顺[THS] → Skills[15] → 缓存[C]   ✅ 增强备源
行情:      腾讯[1] → 新浪[2] → 必盈[13] → Skills[15] → 缓存[C] ✅ 新增第四备源
财务:      东方财富[3] → 同花顺[THS] → 必盈[13] → Skills[15] → 缓存[C]
K线:       新浪[2] → 腾讯[B] → 必盈[13] → baostock[14] → 缓存[C]  (Skills不覆盖K线)
```

## 四、技术决策与权衡

### 4.1 选择MCP直连而非Python桥接（Phase 1）

| 选项 | 优点 | 缺点 | 选择 |
|:-----|:-----|:-----|:---:|
| MCP直连 | 零桥接，Claude Code原生调用；即时可用 | 仅Claude Code可用；PowerShell管线需另行适配 | ✅ Phase 1 |
| Python桥接 | PowerShell管线可直接调用；可批量缓存 | 多一层桥接维护成本；MCP优势浪费 | Phase 2可选 |
| 双路径 | 覆盖面最广 | 维护两份调用逻辑 | 长期方案 |

**决策**: Phase 1走MCP直连——Skills的最大价值在于"Claude Code分析链路中直接调取数据"，这是我们的主场景。Phase 2若需要PowerShell管线也能调用，再追加薄桥接（~50行Python）。

### 4.2 Skills作为备源而非主源

| 选项 | 风险 | 选择 |
|:-----|:-----|:---:|
| Skills做主源 | 50次/天限制太紧；免费政策可能变更；API可能不稳定 | ❌ |
| Skills做备源 | 仅在主源失败时调用，低频使用，限流安全 | ✅ |
| Skills仅做验证源 | 价值利用不充分 | ❌ |

**决策**: Skills统一作为备源（第三/第四优先级），不替代任何现有主源。仅在主源+现有备源均失败时调用Skills。这样50次/天的额度对于备源场景绰绰有余。

### 4.3 不为此接入创建独立的Python fetcher（Phase 1）

理由：
- Skills的toolQuery是自然语言接口，不需要结构化参数封装
- Claude Code通过MCP直接调用比PowerShell桥接更自然
- 创建独立fetcher会增加维护负担但不会增加调用场景
- Phase 2若需要管线集成，再创建薄桥接（~50行）

## 五、缓存策略

| 数据类 | 缓存TTL | 理由 |
|:------|:------:|:-----|
| 行情类（PE/PB/价格） | 1h | 盘中可变化，但备源场景低频 |
| 财务类（ROE/毛利率等） | 168h(7d) | 季频数据，变化慢 |
| 宏观数据 | 168h(7d) | 月频/季频公布 |
| 研报评级 | 24h | 日频更新 |
| 资金流向 | 6h | 盘中实时但作为备源低频调用 |
| 选股筛选结果 | 24h | 每日变化 |

缓存文件存放: `代码文件/数据/cache/skills_{category}_{date}.json`

| 安全 | API Key通过环境变量注入，不入库 |

## 七、风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|:-----|:---:|:---:|:-----|
| 50次/天额度耗尽 | 低 | 备源不可用，回退到缓存[C] | 计数器+80%告警；备源场景低频 |
| API Key泄露 | 低 | 被盗用 | 环境变量注入，不入配置文件；定期轮换 |
| 免费政策终止 | 中 | 需付费或弃用 | Skills非主源，停止后仅损失备源增强，不影响核心链路 |
| API格式变更 | 中 | MCP调用失败 | 返回结构标准化解析层；失败自动降级到缓存 |
