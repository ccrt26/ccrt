## 1. 需求摘要

东睦股份外部批评暴露四个方法论短板：
- **P0**：资金面评分只看"量"不看"结构"（主力方向vs散户方向），缺少突破性质分类（基本面驱动vs纯资金驱动）

- **P2**：事件驱动因子体系空缺（并购/订单/政策/产品周期无系统追踪）

本次优化不改评分引擎代码，仅升级知识库方法论+报告生成规范。

## 3. 模块设计

### 3.1 P0a — 资金面结构维度 [L1]

| 属性 | 值 |
|:-----|:---|
| 目标文件 | `.claude/agents/腰子-知识库/08-资金面分析.md` |
| 新增章节 | §四 资金结构维度评分 |
| 数据源 | [9]东方财富个股资金流向（已有管线） |

**新增方法论**：

```
资金结构 = 主力方向 + 散户方向 + 结构健康度

主力方向判定（连续3-5日）：
  连续净流入 → 主力进场（+2分）
  净流入>净流出交替 → 中性（+0）
  连续净流出 → 主力出货（-2分，升级至流金审查）

散户方向判定（反向指标）：
  散户连续出货+主力连续进场 → 筹码集中，健康（+1分）
  散户连续进货+主力连续出货 → 筹码分散，危险（-2分）

结构健康度 = f(主力方向, 散户方向, 成交量趋势)
  健康：主力进+散户出+量放大 → 教科书式上涨中筹码集中
  警惕：主力出+散户进+量放大 → 主力出货散户接盘
  中性：主力散户同向 → 无结构信号
```

**与现有评分整合**：资金面评分(0-10) = 量维×(0-7) + 结构维×(0-3)。量维沿用现有成交量判断，结构维新增。

### 3.2 P0b — 突破性质分类节点 [L1]

| 属性 | 值 |
|:-----|:---|
| 目标文件 | `.claude/agents/腰子-知识库/09-突破性质分类.md`（新建） |
| 触发时机 | 任何放量突破关键位时，在仓位建议前执行 |

**决策树**：

```
放量突破发生
  ↓
检查1: 基本面因子正向？（ROE>10% + 毛利率趋势↑ + 扣非真实）
  ├─ 否 → 检查2: 资金因子正向？（连续3日主力净流入）
  │        ├─ 否 → 纯动量突破 → 仅持有/减仓，不建议加仓
  │        └─ 是 → 资金驱动突破 → 轻仓试探(≤8%)，紧止损
  └─ 是 → 检查2: 资金因子正向？
           ├─ 否 → 基本面突破(无资金确认) → 持有，等资金确认后加仓
           └─ 是 → 质量+动量共振突破 → 可加仓(≤16%)，正常止损
```

**硬约束**：
- 纯动量突破（基本面负+资金负）：⛔禁止开新仓，现有持仓设5%紧止损
- 质量+动量共振：优先加仓信号
- RSI>80时，无论哪种分类，均不加仓（技术面否决）

### 3.5 P2 — 事件驱动因子体系 [L1]

| 属性 | 值 |
|:-----|:---|
| 目标文件 | `.claude/agents/青山-知识库/09-事件驱动因子体系.md`（新建） |
| 更新文件 | `.claude/agents/青山-知识库/01-因子体系总览.md`（追加第8族） |

**8大因子族扩展**：在现有7族（价值/动量/质量/成长/波动率/规模/情绪资金）基础上增加第8族——**事件驱动(Event)**。

事件驱动因子族包含：
- 并购事件因子：M&A公告→股价反应→整合效果
- 订单事件因子：大额合同→营收预期修正
- 政策事件因子：产业政策→行业beta偏移
- 产品周期因子：新品发布→市场份额变化

**定性评分规则**：事件因子不纳入量化模型（小样本+异质性），作为情景调整项。每事件评分(-2,+2)，叠加后调整综合评分的定性判断。+2=强利好且高确定性，-2=强利空且高确定性。
