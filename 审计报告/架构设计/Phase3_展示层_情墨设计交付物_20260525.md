## 1. 设计范围

三个交付物：
1. **持仓仪表盘HTML** (`模拟交易/展示/持仓仪表盘.html`) — L0 展示层
2. **risk_override 字段** (架构文档 §3.2) — L1 接口契约
3. **统一归因入口** (仪表盘内嵌) — L0 展示层

## 2. 设计确认

### 2.1 持仓仪表盘
- 技术方案：静态HTML + 嵌入式数据（JS常量），与现有报告体系一致
- 品牌色 #1a1a2e/#16213e，涨红(#e74c3c)/跌绿(#27ae60)
- 数据来源：positions.json + perf_summary.json + transactions.csv
- 模块：摘要卡片(5) + 基准对比(4) + 持仓明细表 + 决策来源归因 + 风险快照(4)
- 待执行指令横幅（腰子指令提示）

### 2.2 risk_override 字段
- 位置：指令JSON §3.2 每个decision对象
- 字段：risk_override (boolean) + risk_override_reason (string)
- 使用规则：流金明确警告+腰子仍交易→必须标记true
- 后评估联动：所有risk_override=true交易单独统计
- 连续3次亏损→L3升级

### 2.3 统一归因入口
- 位置：仪表盘"决策来源对比"section
- 按source字段（manual/auto）分组统计
- 包含：交易总数/买入/卖出/已完成交易 + 明细表
