# 设计文档：模拟交易引擎 safety_net 模式

> **pipeline_stage**: complete | **日期**: 2026-05-29 | **设计师**: 情墨
> **变更等级**: L1（工具/调度层，不改评分/交易/风控逻辑）

---

## 一、背景

当前引擎的 strict 模式有一个致命缺陷：如果腰子没有产出当日交易指令，引擎完全不动——包括不检查止损。这意味着止损形同虚设。

24 小时开机后，引擎将由 cron 每日自动触发。需要一个"即使没人看，纪律也要守"的模式。

## 二、设计方案

### 2.1 引擎模式三层化

```
有当日指令(.json存在+pending状态) → strict:  指令全覆盖(买入+卖出)
无当日指令                       → safety_net: 只执行出场检查(P1-P5)，不开新仓
(未来)                           → auto:     完全自动(暂不启用)
```

### 2.3 模式行为矩阵

| 行为 | strict | safety_net |
|:-----|:-----:|:-----:|
| 执行腰子 SELL/BUY 指令 | ✅ | N/A(无指令) |
| P1 止损检查 | ✅ | ✅ |
| P2 趋势恶化检查 | ✅ | ✅ |
| P3 预判转空检查 | ✅ | ✅ |
| P4 全部止盈(R3) | ✅ | ✅ |
| P5 止盈减仓(R2) | ✅ | ✅ |
| 自动开仓(评分排序) | ❌ | ❌ |
| 腰子 HOLD 保护 | ✅ | N/A |
