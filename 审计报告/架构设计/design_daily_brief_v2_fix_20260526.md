## 1. 问题诊断

审查全部7份v2日报，确认4个根因：

| # | 缺陷 | 根因 | 文件:行号 |
|:--|:-----|:-----|:---|
| 1 | 顶部"参考报告"行冗余，底部引用链接文字=文件名 | 模板写死了重复引用，且链接text使用原始文件名 | gen_daily_brief.py:244, 403 |
| 2 | 开盘/最高/最低用price×1.01/0.99估算 | 引擎不提供日内OHLC，脚本用估算值填充，违反"不推测"铁律 | gen_daily_brief.py:195, 234, 275 |

## 2. 修复方案

### 2.1 删除顶部冗余引用（问题1）

**改前** (line 244)：
```
> **参考报告**：[{name}({code})分析报告__{date_str}.pdf](...)
```
**改后**：删除该行。只保留底部"参考引擎报告"一处引用，链接文字改为简短形式：
```
> 参考引擎报告：[{name}({code})分析报告__{date_str}.pdf]
```
（纯文本引用，不带markdown链接，PDF文件名本身即可定位）

### 2.2 个股行情表使用真实数据（问题2）

**改前** (line 275)：`| {price:.2f} | {high_est} | {low_est} | **{price:.2f}** | — | — | — |`

**改后**：移除伪数据列，只展示确定数据：
```
| **{price:.2f}** | +{change_pct:.2f}% | {vol_rel} |
```
表格重构为：收盘价/涨跌幅/量价关系，三项均来自引擎实际数据。
- 涨跌幅从引擎Signals中获取（如有），否则标注"数据缺失"
- 删除lines 195, 234-235的high_est/low_est伪数据计算

### 2.3 `—` 替换为语义化标注（问题3）

| 位置 | 改前 | 改后 |
|:-----|:-----|:-----|
| 技术四维-波动方向列 | `—` | 删除"方向"列（布林带只有位置，无方向概念） |
| 技术四维-量能方向列 | `{"↑" if "同步" in str(obv) else "→"}` | 保持原逻辑，增加"↓"分支(背离时) |
| 资金面-趋势列 | `—` | `"单日"` (单日无趋势，标注为单日数据) |
| 关键价位-当前价行 | `—` / `—` | `"当前价"` / `"—"` （当前价行不适用距/解读概念，用"—"合理）|
| 方向列(ADX/RSI) | 已正确使用↑↓→ | 不改动 |

### 2.4 修复条件空行（问题4）

**改前** (line 329)：
```python
{"- 如果已持仓..." if chase_triggered else ""}
```
**改后**：不单独一行输出，将已持仓建议并入前一个条件块的else分支。
