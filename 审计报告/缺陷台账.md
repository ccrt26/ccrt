## 字段说明

| 字段 | 说明 |
|:-----|:-----|
| ID | 唯一编号，格式 `BUG-YYYYMMDD-序号` |
| 日期 | 发现日期 |
| 文件:行号 | 缺陷所在文件及行号 |
| 等级 | B0(阻断)/B1(严重)/B2(一般)/B3(轻微) |
| 描述 | 缺陷表现 + 预期行为 |
| 影响范围 | 影响的模块/功能/数据链路 |
| 状态 | 待修复/修复中/已修复/已验证/关闭 |
| 修复人 | 负责修复的角色 |
| 修复日期 | 修复完成日期 |
| 复查结果 | Proof 复查结论（通过/不通过） |
| 备注 | 根因分析 / 关联规则条款 |
