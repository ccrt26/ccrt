## 1. 迁移概要

### 1.1 背景

原山猫知识体系分散在以下位置：
- `.claude/agents/宏观巡检-山猫.md` — 角色定义与能力矩阵（179行）
- `.claude/agents/山猫-知识库/` — 9个独立知识文件（合计约12.6万字）
- `统一解读/角色解释包/山猫_宏观解释包.md` — 统一解读输出模板

本次迁移将上述分散知识统一归集到 `knowledge/roles/shanmao/`，形成结构化、模块化的知识体系。

### 1.2 迁移目标

1. 消除知识碎片化——一个入口、一套体系
2. 去冗余、重结构化——单文件≤500行，模块分工清晰
3. 建立注册表——每项知识可追溯版本、有效期、升级条件
4. 建立后评估机制——误判记录、反例管理、更新审批链路

### 1.3 迁移范围

| 范围 | 包含 |
|:-----|:-----|
| 角色定义 | 身份定位、能力矩阵、硬边界、团队分工、沟通风格 |
| 知识模块 | 货币政策/财政产业/宏观数据/A股政策/市场情绪/全球联动/极端事件/信息源/政策日历 |
| 统一解读 | 宏观解释包输出模板、必填字段 |
| 后评估 | 误判记录、反例管理、知识进化规则、更新流程 |

## 3. 关键变更说明

### 3.1 内容层面的变更

| 维度 | 旧体系 | 新体系 |
|:-----|:-------|:-------|
| 角色边界 | 分散在多个文档中 | 统一在01_角色职责与边界.md |
| 判断框架 | 7个独立文件，内容冗余（如流动性在01和06中重复） | 按功能域合并去重，控制在500行内 |
| 信息源 | 独立文件08 | 合并入03_输入证据与可信度规则.md |
| 解读模板 | 在统一解读包中 | 合并入05_输出模板与表达约束.md |
| 后评估 | 无正式机制 | 新增04_后评估与知识进化.md |
| 知识注册 | 无 | 新增registry.json（22条注册条目） |
| C10 (宏观区分度) | 旧角色定义中未包含 | 新增在01_角色职责与边界.md |

### 3.2 框架层面的变更

1. **阈值集中管理**：原分散在7个文件中的阈值，全部集中在 `02_核心判断框架.md` 中，便于统一维护和更新
2. **统一输出模板**：日报深度分析/每日简报/极端事件/腰子咨询 统一到 `05_输出模板与表达约束.md`
3. **知识进化链路**：新增完整的误判→反例→阈值调整→审计的闭环

### 3.3 删除/未保留的内容

- 旧知识库中"知识库导航"互链（如"返回知识库索引"）——新体系使用registry.json替代
- 旧文件中重复的DR007/Shibor/两融等阈值的多文档重复表述
- 旧角色定义中的"十、附录"部分（已在v2.3中移除）
- 原始知识库中部分过于细化的操作说明（如具体代码实现）
