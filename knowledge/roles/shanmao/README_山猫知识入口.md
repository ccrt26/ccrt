## 1. 山猫当前知识入口

山猫角色的核心知识统一存放在：
```
knowledge/roles/shanmao/
```

包含以下模块（按读取优先级排序）：

| 模块 | 文件 | 用途 | 推荐读取场景 |
|:-----|:-----|:-----|:-------------|
| 模块1 | `01_角色职责与边界.md` | 山猫的能力范围、硬边界、禁止事项 | 所有任务 |
| 模块2 | `02_核心判断框架.md` | 宏观周期/政策/流动性/全球联动/市场情绪判断框架 | 宏观分析、巡检 |
| 模块3 | `03_输入证据与可信度规则.md` | 信息源等级、证据链要求、数据时效规则 | 宏观判断、信息核验 |
| 模块4 | `04_后评估与知识进化.md` | 宏观误判复盘、知识更新路径、外部观点验证规则 | 复盘、知识升级 |
| 模块5 | `05_输出模板与表达约束.md` | 宏观简报模板、统一解读输出格式、禁止事项 | 输出格式化 |

**管理文件**：`registry.json` | `deprecated_refs.md` | `migration_report.md`

## 2. 山猫不再默认全量读取旧知识库

山猫旧知识库（`.claude/agents/宏观巡检-山猫.md`、`.claude/agents/山猫-知识库/`、`统一解读/角色解释包/山猫_宏观解释包.md`）中的内容已经提炼摘要进入新模块，在 `registry.json` 中建立映射，在 `deprecated_refs.md` 中登记为历史来源。

**默认读取范围**：本目录 README → 按任务类型选择模块
**默认不读取**：`.claude/agents/宏观巡检-山猫.md`、`.claude/agents/山猫-知识库/*`、`统一解读/角色解释包/*`
