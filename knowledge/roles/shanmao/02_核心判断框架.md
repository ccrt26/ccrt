## 1. 货币政策与流动性判断框架

### 1.1 央行工具箱速查

| 工具 | 频率 | 信号含义 |
|:-----|:-----|:---------|
| MLF利率 | 每月15日 | LPR定价锚；降=宽松，超额续作=量松价稳 |
| LPR 1Y/5Y | 每月20日 | 1Y降利好制造/中小；5Y降利好地产/银行/家电 |
| RRR降准 | 不定期 | 全面25bp常规，50bp=超预期，+降息=双降强宽松 |
| 逆回购 | 每工作日 | 连续净投放>5天=呵护；跨月/春节加大投放为季节性 |
| PSL | 每月初 | 财政+货币协同，利好基建/地产链 |
| 结构性工具 | 不定期 | 碳减排→新能源；科创再贷款→科技成长 |

### 1.2 DR007流动性判断矩阵

| DR007区间 | 持续时间 | 股市信号 |
|:----------|:--------|:---------|
| <1.30%（低于逆回购+20bp） | >3日 | 极度宽松，利好成长/科技/券商 |
| 1.30-1.70%（贴近逆回购） | 正常 | 中性，结构行情 |
| 1.70-1.90%（略偏紧） | >3日 | 边际收敛，注意小票流动性 |
| 1.90-2.20%（明显紧张） | >2日 | 全面承压，防御仓位 |
| >2.20%（极度紧张） | 任意 | 系统性风险，现金为王 |

### 1.3 M1-M2剪刀差

| 状态 | 含义 |
|:-----|:-----|
| M1>M2（正剪刀差扩大） | 存款活期化，牛市信号 |
| M1≈M2（接近0） | 震荡市，结构性行情 |
| M1<M2（负剪刀差扩大） | 存款定期化，熊市/防御信号 |

### 1.4 流动性四象限

```
宽货币（央行放水）
  II 宽货币紧信用  |  I 宽货币宽信用
  (政策底已现)    |  (全面利好，成长+周期)
紧信用——————+—————宽信用
  III 紧货币紧信用 |  IV 紧货币宽信用
  (现金为王防御)  |  (价值风格占优)
紧货币（央行收水）
```

### 1.5 社融总量三步法
1. 当月新增 vs 预期（超预期>10%=利好顺周期）
2. 存量同比 vs 名义GDP（超GDP+2%警惕泡沫，低于-1%信用收缩）
3. 连续3月趋势（连续上升=扩张利好，下降=收缩不利）

**票据冲量>15%** → 实体融资需求弱；**企业中长贷>15%** → 企业信心强

## 2. 财政与产业政策判断框架

### 2.1 年度关键会议

| 会议 | 时间 | 核心内容 |
|:-----|:-----|:---------|
| 两会 | 3月初 | 政府工作报告：GDP/赤字率/专项债/CPI目标/军费 |
| 政治局（经济） | 4/7/12月 | 每季度经济定调，措辞变化有政策含义 |
| 中央经济工作会议 | 12月中旬 | 来年政策总基调，首要任务+新提法+排序变化 |
| 国常会 | 每周三 | 具体政策措施转化 |

### 2.2 政策力度分级

| 级别 | 发布机构 | 影响时长 | 示例 |
|:----:|:---------|:--------:|:-----|
| S级 | 中共中央/国务院 | 3-10年 | 双碳/AI+/金融强国 |
| A级 | 发改委/工信部等部委 | 1-3年 | 行动计划/管理办法 |
| B级 | 省/市级政府 | 6月-2年 | 地方补贴方案 |
| C级 | 监管机构窗口指导 | 1-6月 | IPO节奏指导 |

### 2.3 7步政策影响评估
1. 发布机构级别判定（S/A/B/C）
2. 政策类型：增量/存量/信号
3. 直接受益/受损板块（申万一级）
4. 产业链传导链
5. 影响规模估算
6. 落地时间轴：立即/6月/1年以上
7. 市场预期对比：已Price in/超预期/低于预期

**评分**：12-15分=重大，8-11分=重要，5-7分=常规

### 2.4 产业政策五阶段

```
萌芽期 → 扶持期 → 规范期 → 成熟期 → 收缩期
主题投资  成长投资  选龙头   价值分红  回避
```

## 3. 宏观数据解读框架

### 3.1 核心指标速查

| 指标 | 发布时间 | 健康区间 | 预警 |
|:-----|:---------|:---------|:-----|
| 官方PMI | 月末9:30 | >50 | <49连续2月 |
| 财新PMI | 月初9:45 | >50 | <50+官方背离 |
| CPI | 9-15日 | 1-3% | >3%警惕通胀，<0%通缩 |
| PPI | 9-15日 | 0-5% | <0%=工业通缩 |
| 社融 | 10-15日 | 超预期>10% | 低于预期>10% |
| 社零 | 15日左右 | >8%强劲 | <3%疲弱 |
| 工业增加值 | 15日左右 | >6%偏强 | <3%偏弱 |
| 固投 | 15日左右 | 看三支柱组合 | 全面弱组合 |
| 失业率 | 15日左右 | <5.5% | >5.5%=宽松硬依据 |

### 3.2 经济四象限（增长 x 通胀）

```
高通胀(CPI>2.5%)
  过热(宽松退场)  | 滞胀(最差组合)
低增长——————+———————高增长
  衰退(政策宽松)  | 复苏(最好组合)
低通胀(CPI<1.5%)
```

### 3.3 高频跟踪12项

30城商品房成交面积/百城土地溢价率/螺纹钢表观消费和库存/水泥价格/高炉开工率/发电量/汽车销量/地铁客流/CCFI/BDI/六大发电集团耗煤量

**季节-环比-同比三看原则**：先看季节因素，再看环比动能，最后同比去季节趋势。

### 3.4 多维交叉验证原则

至少3个指标同向才判断趋势变化：
- 经济向上确认：PMI>50连续3月+社零>6%+工业增加值>5.5%+固投>4.5% → 至少3个
- 经济向下确认：PMI<49连续2月+社零<2%+工业增加值<3%+PPI连续为负 → 至少3个

## 4. A股政策维度判断框架

### 4.1 IPO节奏温度计

| 节奏 | 含义 |
|:-----|:-----|
| 加速期（每周5-8家） | 监管认为市场强 |
| 正常期（每周3-5家） | 不松不紧 |
| 减速期（每周1-2家） | 政策底信号 |
| 暂停期（0家） | 极端救市，重大政策底 |

### 4.2 监管周期判断

- **收紧期信号**：多家公司收监管函/立案调查增多/IPO现场检查比例提高/"零容忍"措辞频繁 → 基本面策略占优
- **宽松期信号**：并购重组加速/再融资放宽/科创板改革加速 → 主题投资活跃

### 4.3 解禁压力四维评分

1. 解禁数量占比（<1%=1分 ... >10%=5分）
2. 股东类型（控股1分 ... 定增机构4分）
3. 成本vs股价（远低于成本1分 ... 高于>50%为4分）
4. 解禁量/日均成交量（<1=1分 ... >20=5分）

**综合分** = 维度1×0.35 + 维度2×0.25 + 维度3×0.25 + 维度4×0.15
>3.5分需重点预警，2.5-3.5分需关注

### 4.4 *ST退市风险预警

- 每周：扫描股价<2元的非ST公司（1.5元=红色警报）
- 每周：扫描市值<5亿元的公司
- 每月：净利润为负+营收<1.5亿（接近红线）
- 每季：净资产为负+审计非标意见

## 5. 市场情绪五阶段定位

### 5.1 成交额阈值（2025年数据）

| 区间 | 状态 | 仓位建议 |
|:-----|:-----|:--------:|
| <6000亿 | 冰点 | 现金为王 |
| 6000-8000亿 | 低迷 | 低仓位 |
| 8000-1.2万亿 | 正常活跃 | 正常仓位 |
| 1.2-1.5万亿 | 乐观升温 | 适当积极 |
| 连续>1.5万亿 | 过热警惕 | 边打边撤 |

### 5.2 五阶段特征速查

| 阶段 | 成交额 | 涨停 | 涨跌比 | 北向 | 恐惧贪婪 |
|:-----|:------|:----|:------|:----|:--------|
| 极端悲观 | <6000亿 | <30家 | <0.3 | 持续流出→转入 | <25 |
| 情绪修复 | 6000-9000亿↑ | 40-80↑ | 1:1-2:1 | 转向流入 | 25-45↑ |
| 乐观升温 | 1.0-1.5万亿 | 90-200 | 2:1-4:1 | 持续流入 | 55-75 |
| 极端狂热 | 连续>1.5万亿 | >200家 | >80%涨 | 过热 | >85 |
| 情绪回落 | 从高点回落>30% | 骤降 | 炸板率>40% | 转为流出 | 快速回落 |

### 5.3 顶部/底部确认原则

- **顶部确认**：至少2-3组信号（缩量连降+炸板飙升+北向流出+涨跌比恶化）
- **底部确认**：至少2-3组信号（地量后放量+北向回流+涨停放大+恐惧贪婪<20回升）

## 7. 极端事件模式匹配框架

### 7.1 四大危机类型

| 类型 | 特征 | 恢复模式 | 持续 |
|:-----|:-----|:--------|:----:|
| 流动性危机 | 杠杆踩踏 | 流动性注入后V型 | 1-3月 |
| 外部冲击 | 国际事件传导 | 冲击源消退 | 1-7月 |
| 政策突变 | 监管一刀切 | 行业不可逆/市场可复 | 3-12月 |
| 结构性问题 | 产品/制度缺陷 | 干预+出清 | 1-2月 |

### 7.2 危机模式匹配清单

1. 成交量极端放大(>2万亿)或萎缩(<5000亿)？
2. 明确政策触发因素？可逆or不可逆？
3. 跌停>500家？
4. 北向大幅流出？
5. 结构性产品/杠杆集中暴露？

### 7.3 政策底→市场底时间差

- 流动性危机：政策底≈市场底
- 外部/结构性问题：政策底后1-3个月探底期，期间可能10-18%二次探底
- 历史案例间隔：0天（2020疫情）至77天（2018贸易战）

### 7.4 极高置信度危机预警组合

≥3项同时触发→80%概率3个月内显著下跌：
- 两融月降>10%
- 北向周流出>100亿
- 成交量<5000亿连续3日
- 跌停/涨停比<0.5连续2日
- 信用利差>2.5%
