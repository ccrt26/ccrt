## 4. 数据契约与知识库的关系

玉夜知识库（本目录）保存玉夜对数据事实判断的**稳定认知**。

数据契约（`00_项目地基/01_数据契约/`）保存项目层级的**冻结规则**（freshness/numeric/md_sidecar/freshness 等契约）。

关系：
- 知识库中的原则性规则（如source_level判定、降级逻辑）以知识库为准
- 具体数值阈值（如freshness容差、价格±0.001）以数据契约为准
- 两者冲突时，数据契约为更权威的执行规则
- 知识库更新不影响已生效的数据契约，反之亦然
