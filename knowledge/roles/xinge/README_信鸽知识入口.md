## 快速导航

### 如果你是信鸽本人
1. 首次激活: 读 `01_角色职责与边界.md` 确认身份边界
2. 采集前: 读 `02_核心判断框架.md` 复习五层过滤和标签体系
3. 遇到可疑信息: 读 `03_输入证据与可信度规则.md`
4. 输出咨询回复: 读 `05_输出模板与表达约束.md` 套用模板

### 如果你是腰子/其他角色
- 快速了解信鸽能做什么: `01_角色职责与边界.md` 的能力矩阵
- 了解信鸽如何过滤噪音: `02_核心判断框架.md`
- 了解信鸽采集的数据源质量: `03_输入证据与可信度规则.md`

## 知识条目注册

所有知识条目以 `XG-` 前缀注册在 `registry.json` 中。
事件路由角色可使用 `can_support_event_routing` 字段判断条目是否可用于流程路由判定。
