## 三、五层过滤漏斗

### 漏斗总览

```
原始消息 → L1黑名单 → L2五问法 → L3去重 → L4标签+上限 → 入库
```

每层丢弃的原因不同，**必须分开统计**并在采集日志中记录。

### L1 — 黑名单关键词+域名

命中以下关键词或域名来源 → 直接丢弃（不可恢复）

**黑名单关键词**:
```
行情点评 | 原因何在 | 技术分析 | MACD | 金叉 | 死叉
压力位 | 支撑位 | 明日展望 | 涨停预测 | 机构推荐
盘后总结 | 龙虎榜解读 | 资金流向解读 | 涨停板复盘
短线机会 | 牛股推荐 | 暴涨 | 暴跌 | 翻倍 | 腰斩
散户 | 股吧 | 吧友 | 大神 | 老师
```

**黑名单域名**:
```
guba.eastmoney.com | xueqiu.com | weibo.com
tieba.baidu.com | douyin.com | kuaishou.com
```

**维护原则**: 新增关键词前检查是否可能误杀正式公告（如"回购"不能加，因为回购公告是有效信号）。新增域名前确认是否还有新冒出的噪音平台。

### L2 — 腰子五问法（Q1-Q5）

标题必须命中至少1个Q → 否则丢弃（不可恢复）

| 问号 | 领域 | 当前regex | 覆盖信号 |
|:----:|:-----|:----------|:---------|
| Q1 | 财务 | `净利润\|营收\|EPS\|ROE\|毛利\|订单金额\|减值\|分红\|派现\|扣非\|利润分配\|业绩\|盈利` | 财报、预告、分红 |
| Q2 | 所有权 | `增持\|减持\|回购\|质押\|解禁\|收购\|股权\|控制权\|定增\|重组\|购买资产\|发行股份\|合并\|要约\|转让` | 增减持、回购、并购、定增 |
| Q3 | 监管 | `问询\|立案\|处罚\|警示\|ST\|退市\|注册批复\|核准\|通过\|暂停上市` | 监管处罚、ST风险、注册批复 |
| Q4 | 产能 | `投产\|量产\|定点\|获批\|新产品\|新线\|产能\|中标\|合同\|供货` | 新产品、量产、订单 |
| Q5 | 竞争 | `破产\|退出\|禁令\|制裁\|反倾销\|补贴\|关税\|准入\|政策\|法规` | 行业政策、竞争格局 |

**已知盲区**（待Phase 2扩展）:
- Q1: "回购注销"中的注销、"送转"、"配股"
- Q4: "客户验证"、"送样"、"通过认证"
- Q5: "双反"、"实体清单"

### L3 — 增量性检查（去重）

**算法**: Jaccard相似度 = 共同词数 / 总词数

- 与近3日已入库事件逐条对比
- 相似度 > `dedup_similarity_threshold` (0.70) → 丢弃
- 对比前先分词：去标点、按空格分割、过滤长度<2的词、去重

**特殊规则**:
- 首次覆盖研报（标题含"首次覆盖|首覆|首次|新覆盖"）→ 即使无评级调整也保留
- 普通研报无评级调整+无盈利预测修正 → 丢弃
- 相同公告的不同媒体转发 → 应被去重（title相似度通常>80%）
- 同一事件的不同进展公告 → 不应去重（如"筹划收购"vs"完成收购"）

### L4 — 标签分类 + 上限控制

**标签**: 见本节"事件分类体系"。

**上限规则**:
- 每只股票每天最多5条入库（`max_events_per_stock`）
- 按 impact_score 降序排列，取前N条
- **P0事件不受上限限制**，强制入库

### 过滤统计解读

每条采集日志的格式:
```
[filter] 600114 : L1 2→2 | L2 2→1 | L3 1→1 | L4 1→1
```

常见场景诊断:
| 场景 | L1 | L2 | L3 | L4 | 诊断 |
|:-----|:--:|:--:|:--:|:--:|:-----|
| 理想 | 1→1 | 1→1 | 1→1 | 1→1 | 单条有效信号 |
| L2拦截多 | 5→5 | 5→2 | 2→2 | 2→2 | 例行公告多，正常 |
| L3拦截多 | 2→2 | 2→2 | 2→0 | — | 同事件重复报道，正常 |
| L1拦截 | 3→1 | — | — | — | 噪音源污染，检查黑名单是否过宽 |
| L2全拦截 | 3→3 | 3→0 | — | — | Q1-Q5可能缺关键词，检查被滤标题 |

## 四、事件重要性评分

### impact_score 公式

```
impact_score = category_weight × probability × freshness
capped at 10.0
```

| 因子 | 取值 | 来源 |
|:-----|:-----|:-----|
| category_weight | 5-10 | 六类标签权重（见"事件分类体系"） |
| probability | 1.0 / 0.7 / 0.5 | 确定性判断（见下方） |
| freshness | 1.0 / 0.8 / 0.5 / 0.3 | 时效性权重（见下方） |

**示例**: 并购重组公告，确定性1.0，当天发布 → 9 × 1.0 × 1.0 = 9.0

### direction — 方向判断

| 方向 | 值 | 触发关键词 |
|:-----|:--:|:-----------|
| 利好 | +1 | 增持\|回购\|预增\|增长\|超预期\|获批\|中标\|突破\|利好\|注册批复\|通过\|核准\|上调\|实施 |
| 中性 | 0 | 默认值 |
| 利空 | -1 | 减持\|预亏\|预减\|下降\|不及预期\|立案\|处罚\|问询\|警示\|退市\|ST\|\*ST\|调查\|失败\|亏损\|暴跌 |

### probability — 确定性

| 确定性 | 值 | 触发关键词 |
|:-------|:--:|:-----------|
| 已确认 | 1.0 | 默认值 |
| 预计 | 0.7 | 预告\|预计\|预测 |
| 传闻/计划 | 0.5 | 传闻\|消息\|据悉\|或\|或将\|可能\|拟\|计划\|筹划 |

### freshness — 时效性

| 天数 | 权重 |
|:----:|:---:|
| 今天 | 1.0 |
| 昨天 | 0.8 |
| 3天内 | 0.5 |
| 7天内 | 0.3 |

### P0判定标准

P0事件不受单股5条上限限制，强制入库，双线上报。

| P0关键词 |
|:---------|
| 立案调查 |
| ST风险 |
| *ST |
| 退市风险 |
| 全部质押 |
| 重组失败 |
| 破产 |

```
信鸽标记P0 → 同时推送腰子+阿黑
  → 腰子1h内确认升级/降级
  → 超时 → 阿黑直接升级用户
```

## 七、模式识别（Phase 2目标，Phase 1人工识别）

### 模式A — 同股多信号

**触发条件**: 同一股票当日入库 >= 2 条事件

| 子类型 | 条件 | 含义 | 信鸽动作 |
|:-------|:-----|:------|:---------|
| A1 同向强化 | 全部同方向 | 信号确认，可升级权重 | 标记pattern: "A1" |
| A2 混合信号 | 方向不一致 | 需要人工判断 | 标记conflict |
| A3 事件链 | 同类别、不同进展 | 事件在演进 | 标记related_events |

### 模式B — 同板块跨股票共振

**触发条件**: 同一板块 >= 2 只股票同日有同类别事件

| 子类型 | 条件 | 含义 |
|:-------|:-----|:------|
| B1 政策共振 | 多只股票命中"行业政策" | 行业级政策出台 |
| B2 业绩共振 | 多只股票同日发业绩预告 | 行业景气拐点 |
| B3 减持共振 | 同板块多只股票同日减持 | 板块情绪恶化 |

**板块配对**: AI/算力(中科曙光+长电科技), 新能源/制造(拓普集团+上海电气)

### 模式C — 时间聚类

**触发条件**: 单只股票7天内 >= 3 条同类别事件

| 子类型 | 条件 | 含义 |
|:-------|:-----|:------|
| C1 密集期 | 同类别事件在短时间内集中出现 | 催化剂密集爆发期 |
| C2 真空期 | 7天+无任何事件 | 可能错过公告或数据源异常 |

### 信号升级矩阵

| 模式 | 原影响分 | 升级后 | 升级方式 |
|:-----|:--------:|:------:|:---------|
| A1 同向强化×2 | 6.0+6.0 | P1 | 合并为复合信号，最高分×1.5 |
| A2 混合信号 | 6.0 + (-6.0) | 0 | 不确定性增加，标记conflict |
| B1 政策共振 | 5.0×2 | P1 | 行业级别信号，推山猫 |
| C1 密集期 | 各分数 | P1 | 按周聚合报告 |
