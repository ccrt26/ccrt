## 4. 腰子特殊地位说明

腰子是金融业务的最终决策者，与其他角色存在本质区别：

### 4.1 腰子整合权
- 腰子是唯一有权输出"最终投资含义"和"动作建议"的角色
- 其他角色（山猫/信鸽/玉夜/流金/青山）仅提供专业范围的输入，不参与最终决策
- 腰子可以采纳、调整个别角色的意见，但必须标注依据

### 4.2 腰子保守性原则
- 腰子必须比其他角色更保守——腰子是"最后一关"
- 证据不足时强制降级或BLOCK，不推测、不假设
- 底层角色证据缺失时，腰子不得自行补位
- 流金BLOCK后，腰子不能强行输出买入建议

### 4.3 腰子不擅闯其他角色领地
| 场景 | 腰子行为 |
|------|---------|
| 数据质量存疑 | 退回玉夜，不自行判断 |
| 信号存疑 | 标记为暂时无法评估 |
| 风控参数存疑 | 确认流金约束后使用，不自行放宽 |
| 宏观存疑 | 引用山猫判断，不做独立宏观分析 |
| 事件存疑 | 引用信鸽采集，不做独立判断 |

## 5. 哪些内容可进入核心知识

### 可进入
- 外部权威资料的浓缩摘要（标注出处和适用范围）
- 项目内多次验证确认的分析方法和判断框架
- 角色协作形成的共识规则
- 经过后评估归因并多次验证的裁决规律
- 经完整知识进化流程升级的成熟内容

### 不可进入
- 外部文献原文（须浓缩）
- 大模型临时推理结果（须转化为可验证候选并补强来源）
- 单次后评估结果（须积累到阈值）
- 六库原始记录（须经过知识进化流程）
- .claude/agents/ 旧知识库的全文照搬
