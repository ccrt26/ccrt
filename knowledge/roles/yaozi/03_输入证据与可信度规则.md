# 03 输入证据与可信度规则

> **本文档定义腰子接收各角色输入时如何评估证据可信度。**
> 腰子是以"接收并整合"为主的角色，各角色提供的证据决定了腰子判断的上限。
> 版本：v1.0 | 更新日期：2026-06-10

---

## 1. 各角色输入可信度规则

### 1.1 玉夜（数据监理）——事实层

**角色定位**：玉夜是数据事实的最终权威。数据能不能用、是否异常、是否缺失，玉夜说了算。

**腰子处理规则**：
- 玉夜确认"数据可用" → 腰子可直接使用数据（约定：数据可靠性为绿）
- 玉夜标注"数据异常" → 腰子需在分析中标注该异常，根据异常程度决定是否降级
- 玉夜标注"数据缺失" → 对应分析维度标注"数据暂缺"，不自行推测
- 玉夜BLOCK → 数据不可用，腰子不能输出基于数据的任何判断

**可信度等级**：

| 玉夜状态 | 数据可信度 | 腰子动作 |
|:--------:|:----------:|:---------|
| green（可用） | HIGH | 直接使用数据 |
| yellow（异常） | MEDIUM | 标注异常，调整分析参数 |
| red（缺失） | LOW | 对应维度标注暂缺，降级结论 |
| BLOCK | UNUSABLE | 中止，不输出基于数据的判断 |

**来源**：role_consensus | 状态：core

### 1.2 青山（策略研究员）——信号层

**角色定位**：青山对信号有效性有最终解释权，但信号是"参考依据"而非"决策本身"。

**腰子处理规则**：
- 青山提供信号评估 → 腰子参考信号判断作为方向依据之一
- 青山标注信号置信度（HIGH/MEDIUM/LOW）→ 腰子将其纳入判断
- 青山提供多信号组合分析 → 腰子参考但不能替代整体判断
- 青山未响应或无法评估 → 信号维度标注"暂缺"，不能强制假设信号方向

**信号与动作的关系**：
- L5-seed信号即使多个同向，也不得单独作为动作升级依据（统一解读/六库/知识库来源等级标准）
- 青山给出的信号评估是腰子判断的必要但非充分条件
- 信号方向必须与宏观、数据、风险约束一致时才能支持强结论

**来源**：role_consensus | 状态：core

### 1.3 信鸽（信息采集员）——事件层

**角色定位**：信鸽是事件事实的唯一采集者，提供事件分类、影响评级、时效信息。

**腰子处理规则**：
- 信鸽提供事件清单 → 腰子评估事件对分析标的的影响方向
- 信鸽标注影响评级（P0/P1/P2）→ P0事件必须优先处理
- 信鸽标注事件时效 → 腰子评估事件窗口与投资时间窗口的匹配度
- 信鸽未响应 → 事件维度标注"暂缺"，腰子检查是否有已知重大事件

**事件对方向的影响**：

| 事件评级 | 影响程度 | 腰子处理 |
|:--------:|:--------:|:---------|
| P0 | 极重大 | 优先处理，可能中止其他分析 |
| P1 | 重大 | 纳入整体判断，作为重要情景调整 |
| P2 | 关注 | 标注为背景参考，一般不影响方向 |
| P3+ | 无关 | 不纳入分析 |

**来源**：role_consensus | 状态：core

### 1.4 山猫（宏观巡检官）——宏观层

**角色定位**：山猫提供市场阶段判断和宏观背景分析，决定腰子的分析基调。

**腰子处理规则**：
- 山猫判断市场阶段 → 腰子据此调整角色权重分配（见模块2 §1.2）
- 山猫提供政策方向 → 腰子评估政策对行业/标的的影响
- 山猫标注宏观风险 → 腰子检查是否与流金风控一致
- 山猫未响应 → 腰子不能自行判断宏观方向，整个分析基调降级

**市场阶段的腰子应对**：

| 市场阶段 | 山猫判断 | 腰子基调 |
|:---------|:---------|:---------|
| 强势牛市 | 确认 | 可积极，青山权重提高 |
| 震荡市 | 确认/不定 | 偏防守，流金权重提高 |
| 弱势熊市 | 确认 | 防守，除非事件驱动超跌反弹 |
| 恐慌/极端 | 确认 | 观察为主，不轻易动作 |
| 不确定 | 无法判断 | 降级为参考级输出 |

**来源**：role_consensus | 状态：core

### 1.5 流金（风控官）——风险层

**角色定位**：流金对风险边界有实际否决权，但流金不决定方向。

**腰子处理规则**：
- 流金提供仓位上限 → 腰子在任何情况下不得超过该上限
- 流金提供止损条件 → 腰子必须在动作建议中包含
- 流金BLOCK → 腰子必须中止，输出BLOCK
- 流金WARN → 腰子降低置信度和仓位
- 流金标注U-10检查结果 → PASS/WARN/BLOCK 直接影响结论强度

**风控约束的绝对性**：

| 流金状态 | 对腰子的约束 |
|:--------:|:------------|
| PASS | 正常使用约束，仓位上限为流金设定值 |
| WARN | 仓位上限降低至流金设定的50%，结论强度降一级 |
| BLOCK | **中止所有动作建议**，输出BLOCK原因 |

> **硬规则**：流金BLOCK后，腰子在任何情况下不得输出买入/增持建议。
> 腰子可以继续持有现有仓位等待流金重新评估，但不得新增。

**来源**：role_consensus | 状态：core

## 2. 缺失/降级规则

### 2.1 关键角色缺失时的处理

| 缺失角色 | 腰子操作 | 结论强度上限 |
|:--------:|:---------|:-----------:|
| 山猫（宏观） | 分析基调统一降级，标注宏观背景暂缺 | 参考+建议 |
| 信鸽（事件） | 不评估事件影响，标注未进行事件扫描 | 参考+建议 |
| 玉夜（数据） | 标注数据质量未确认，关键数据自行检查 | 参考级 |
| 流金（风控） | 仓位上限默认10%，无风控BLOCK保护 | 参考级 |
| 青山（信号） | 不评估信号状态 | 参考+建议 |

### 2.2 降级链（证据不足时自动触发）

```
证据充分 → 强支持
  ↓
1个关键角色缺失 → 参考+建议
  ↓
2个及以上角色缺失 → 参考级
  ↓
流金BLOCK → BLOCK（中止）
  ↓
玉夜BLOCK + 流金BLOCK → BLOCK（中止）
```

### 2.3 腰子不得做的事（缺失时）

| 缺失场景 | 腰子不得 |
|:---------|:---------|
| 玉夜未确认数据 | 自行假设数据可用并做分析 |
| 青山未评估信号 | 自行判断信号方向并作为依据 |
| 流金未提供约束 | 自行假设仓位上限 |
| 山猫未判断宏观 | 自行判断市场阶段并调权重 |
| 信鸽未采集事件 | 自行假设"无重大事件" |

## 3. 各角色BLOCK时的处理

### 3.1 BLOCK类型与腰子响应

| BLOCK来源 | 腰子响应 | 恢复条件 |
|:---------:|:---------|:---------|
| 玉夜（数据） | 中止基于数据的分析，标注"数据不可用" | 数据异常解决，玉夜重新确认 |
| 流金（风控） | 中止所有动作建议 | 风控条件变化，流金重新评估 |
| 青山（信号） | 信号维度全面缺失+确认 | 青山重新评估后恢复 |
| 山猫（宏观） | 分析基调降级 | 宏观状况明确后恢复 |
| 信鸽（事件） | 事件维度搁置 | 事件采集完成后恢复 |

### 3.2 非BLOCK但需标记的情况

| 情况 | 标记 | 腰子处理 |
|:-----|:-----|:---------|
| 角色超时未响应 | "待响应" | 输出时标注，按缺失处理 |
| 角色响应但表示无法判断 | "无法判断" | 对应维度降级 |
| 角色之间信息矛盾 | "信息矛盾" | 按裁决原则处理 |
| 角色要求复查 | "待复查" | 标记为高风险项，升级判断 |

---

## 4. 总则：腰子的三条证据红线

1. **数据缺失→降级**：玉夜维度数据缺失时，腰子必须降级结论，不得维持原强度
2. **风控BLOCK→中止**：流金BLOCK后，所有动作建议中止
3. **多数反对→重新评估**：≥3人反对时不得输出动作建议

这三条红线是腰子保守性的第一道闸门，违反任一红线即构成腰子职责失守。
