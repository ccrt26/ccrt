# 02 核心判断框架

> **本文档定义流金的风险识别框架，覆盖仓位风险、回撤风险、流动性风险、事件风险、组合暴露风险、过拟合检测和交易纪律审查。**
> 版本：v1.0 | 更新日期：2026-06-10

## 1. 仓位风险

### 1.1 HHI（Herfindahl-Hirschman指数）

```
HHI = Σ(w_i)^2

风险等级：
  <0.10  -> 分散良好
  0.10-0.15 -> 合理分散
  0.15-0.20 -> 中等集中
  0.20-0.30 -> 高风险集中
  0.30-0.40 -> 过度集中
  >0.40  -> 极端集中
```

### 1.2 行业集中度

```
行业HHI = Σ(行业权重_i)^2
行业分类：申万一级（31个行业）

单一行业权重 > 30% -> 预警
单一行业权重 > 40% -> 减仓
单一行业权重 > 50% -> 强制减仓
行业HHI > 0.20 -> 中度集中
行业HHI > 0.30 -> 极度集中

行业相关性加成：同行业HHI风险x1.5，同产业链x1.2
```

### 1.3 个股集中度硬规则

| 规则 | 阈值 | 性质 |
|:-----|:----:|:-----|
| 单股上限 | 总资产30% | 硬上限，不可突破 |
| 最大持仓数量（>20%） | 3只 | 硬上限 |
| 前2大持仓合计 | 总资产50% | 软上限，超出需书面说明 |
| 前3大持仓合计 | 总资产65% | 软上限，超出需减仓 |
| 单日单股加仓上限 | 总资产10% | 硬上限 |
| 新建仓单股初始上限 | 总资产15% | 硬上限 |

### 1.4 风险预算分配

| 规则 | 阈值 |
|:-----|:-----|
| 单只股票最大风险贡献 | RC_i/σ_p <= 30% |
| 单一行业最大风险贡献 | RC_sector/σ_p <= 40% |
| 总仓位VaR(95%)不低于 | -5%（日） |
| 总仓位CVaR(99%)不低于 | -10%（日） |
| 数据不足时退回 | 等权重 1/N |

**动态调整**：
- 组合GARCH波动率上升50% -> 仓位按倒数缩至50%
- 连续3日亏损 -> 总仓位降至当前50%
- 某股连续2日跌停 -> 该股风险预算归零
- 行业集中度红色预警 -> 该行业所有仓位风险预算降至50%

## 2. 回撤风险

### 2.1 四级预警体系

| 等级 | 回撤 | 颜色 | 行动 |
|:----:|:----:|:----:|:-----|
| L1 | <5% | 正常 | 无需干预 |
| L2 | 5-8% | 黄色预警 | 审查近期交易，仓位上限75% |
| L3 | 8-12% | 橙色预警 | 仓位上限50%，暂停开新仓 |
| L4 | 12-15% | 红色预警 | 仓位上限25%，强制止损浮亏>3%持仓 |
| 熔断 | >15% | 黑色 | 全部平仓，至少1周禁止交易 |

### 2.2 仓位上限映射

| 等级 | 总仓位 | 单股上限 | 开新仓 | 止损收紧 |
|:----:|:------:|:--------:|:-----:|:--------:|
| 正常 | 100% | 30% | 允许 | -8% |
| 黄色 | 75% | 20% | 谨慎 | -7% |
| 橙色 | 50% | 15% | 禁止 | -6% |
| 红色 | 25% | 10% | 禁止 | -5% |
| 熔断 | 0% | 0% | 禁止 | 全部平仓 |

### 2.3 回撤恢复规则

```
恢复触发：回撤从最大点恢复50%以上
第1步：仓位恢复至50%
第2步：连续5日无新低 -> 恢复至75%
第3步：回撤恢复至预算25%以内 -> 恢复至100%

禁止行为：
- 回撤加深中加仓摊平
- 恢复初期即满仓
```

### 2.4 四种熔断机制

| 熔断类型 | 触发条件 | 暂停时长 |
|:---------|:---------|:--------:|
| 日内亏损 | 单日净值>=5% | 当日+次日 |
| 连续亏损 | 连续3个交易日净值下跌 | 2个交易日 |
| 连败 | 连续5笔交易亏损 | 5个交易日 |
| 周亏损 | 周净值>=8% | 至下周一 |

### 2.5 回撤恢复模式库（快速参考）

| 模式 | 特征 | 恢复时长 | 案例 |
|:-----|:-----|:--------:|:-----|
| V型 | 15-25%跌幅 | <3个月 | 2020疫情底 |
| U型 | 25-40%跌幅 | 6-18个月 | 2018贸易战底 |
| L型 | >50%跌幅 | >5年 | 2008金融危机 |
| 阶梯下跌 | 30-50%跌幅，多次探底 | 2-4年 | 2021-2024熊市 |

## 3. 流动性风险

### 3.1 Amihud ILLIQ

```
ILLIQ = |R_t| / Volume_t（日度）
月度ILLIQ = 1/T x Σ(|R_t| / Volume_t)

分级（单位：|%|/亿元）：
  <0.005  -> 大盘蓝筹（极好）
  0.005-0.02 -> 中盘股（良好）
  0.02-0.10 -> 中小盘（一般）
  0.10-0.50 -> 小盘微盘（较差）
  >0.50  -> 僵尸股（极差）
```

### 3.2 换手率监控

| 换手率（日） | 判定 |
|:-----------:|:-----|
| <0.1% | 极低流动性，100万需多日平仓 |
| 0.1-0.5% | 低流动性，大单明显冲击 |
| 0.5-2% | 正常 |
| 2-5% | 活跃 |
| 5-10% | 非常活跃（关注异常） |
| >10% | 异常（可能操纵） |

### 3.3 平仓冲击成本

```
冲击成本 ≈ 0.1% + 0.5% x sqrt(持仓金额/日均成交额)

关键阈值：
  持仓金额/日均成交额 > 20% -> 需分批进出
  持仓金额/日均成交额 > 50% -> 无法不影响价格平仓

日均成交额至少是持仓金额的10倍以上。
```

### 3.4 流动性危机应对优先级

```
1. 优先平流动性最好的（冲击最小）-> 回收现金
2. 再平流动性中等的 -> 控制损失
3. 最后处理流动性差的（急不来）
```

## 4. 事件风险

### 4.1 退市风险筛查清单

```
检查项：
  - 近两年扣非净利润是否为负？
    -> 是且营收低于板块门槛 -> 财务类退市高风险
  - 股价是否<2元？
    -> <1.5元逼近面值退市线
  - 市值是否接近退市线？
    -> 主板<10亿预警，<5亿退市
  - 大股东存在资金占用？
    -> "其他应收款"异常增长
  - 近三年有财务造假记录？
    -> 重大违法退市风险
  - 审计意见？
    -> 无法表示/否定意见 -> 第二年可能退市
```

### 4.2 质押爆仓筛查

```
大股东质押比例 > 80% -> 危险
股价距预警线 < 15% -> 逼近预警
已触及预警线 -> 需确认是否补仓
已触及平仓线 -> 随时可能爆仓
```

### 4.3 融资融券风险

```
两融余额/流通市值 > 10% -> 融资过浓预警
两融余额/流通市值 > 15% -> 高杠杆风险
全市场维持担保比例 < 200% -> 预警
全市场维持担保比例 < 150% -> 危险
```

### 4.4 限售股解禁冲击

```
解禁冲击 = 解禁数量 x 当前股价 / 日均成交额

<0.5x 日均成交额 -> 影响较小
0.5-2x -> 可能有5-10%下跌压力
2-5x -> 可能有10-20%下跌压力
>5x -> 15-30%下跌压力，流动性不足
```

### 4.5 涨跌停风控

```
跌幅>=9.4%（逼近跌停）-> 禁止开仓，持有仓位挂卖单
已跌停 -> 流动性枯竭，排队挂单
连续2日跌停 -> 危机模式，不做新交易
ST股票 -> 不允许开新仓，已持有3日内清仓
```

## 5. 组合暴露风险

### 5.1 相关性矩阵监控

| 平均相关性 | 风险等级 | 行动 |
|:---------:|:------:|:-----|
| <0.30 | 正常 | 分散化有效 |
| 0.30-0.50 | 黄色预警 | 检查变化原因 |
| 0.50-0.70 | 橙色预警 | 结构性原因->换掉最高相关的1-2只 |
| >=0.70 | 红色预警 | 同质化，强制减仓/换仓 |
| ρ_max > 0.85 | 高度同步 | 建议替换其中一只 |

### 5.2 危机相关性趋同

```
正常市场：不同行业间ρ≈0.2-0.4
危机市场（2015/2020验证）：ρ≈0.7-0.9
结论：危机时分散化效果大幅缩水
```

### 5.3 组合风险综合评分卡

| 维度 | 权重 | 评分方法 |
|:-----|:---:|:---------|
| 集中度 | 25% | HHI + 行业集中度 + 个股最大权重 |
| 相关性 | 20% | 平均ρ + ρ变化趋势 |
| 流动性 | 20% | Amihud ILLIQ + 平仓冲击 |
| 事件风险 | 15% | 解禁/停牌/退市风险叠加 |
| 杠杆风险 | 10% | 融资使用+维持担保比例 |
| 波动率 | 10% | GARCH vs 历史波动率 |

**综合风险分（1-5）**：
- 1.0-1.5 -> 低风险
- 1.5-2.5 -> 正常
- 2.5-3.5 -> 关注（黄色）
- 3.5-4.0 -> 减仓（橙色）
- 4.0-5.0 -> 紧急调整（红色）

## 7. 过拟合检测

### 7.1 五红旗检查

| 红旗 | 条件 |
|:----|:-----|
| 红旗1 | 参数数 > sqrt(有效观测数) |
| 红旗2 | IS vs OOS Sharpe 差距 > 30% |
| 红旗3 | 年化Sharpe > 3 |
| 红旗4 | 参数扰动±10% -> Sharpe变化 > 30% |
| 红旗5 | 缺少Walk-forward验证 |

**综合判定**：
- 0面红星：无过拟合
- 1面：需审查该红旗原因
- 2面：大概率过拟合，需修改后方可用
- 3面+：确定过拟合，不可用

### 7.2 PBO（Probability of Backtest Overfitting）

```
PBO < 0.10 -> 极低风险
0.10-0.30 -> 低风险
0.30-0.50 -> 中等风险，需审查
>= 0.50  -> 高风险，不可直接使用
```

### 7.3 DSR（Deflated Sharpe Ratio）

```
DSR > 0.95 -> 统计显著
0.80-0.95 -> 弱显著
< 0.80  -> 不显著
< 0.50  -> 几乎肯定过拟合
```

### 7.4 Walk-forward效率（WFE）

```
WFE = OOS_Sharpe / IS_Sharpe

WFE > 0.80 -> 稳定
0.60-0.80 -> 正常衰减
0.40-0.60 -> 较大衰减
< 0.40  -> 严重衰减，过拟合
```

### 7.5 因子拥挤度四维检测

| 维度 | 指标 | 拥挤阈值 |
|:-----|:-----|:---------|
| 估值拥挤 | PE/PB中位数 | >历史90分位 |
| 交易拥挤 | 日均换手率 | >历史80分位 |
| 波动拥挤 | 20日波动率 | >历史90分位 |
| 相关性拥挤 | 组内平均相关性 | >0.5 |

**综合判定**：
- 0维：正常
- 1维：轻微拥挤，仓位降至70%
- 2维：中度拥挤，仓位降至50%
- 3维：严重拥挤，仓位降至30%
- 4维：全面拥挤，暂停该因子全部仓位

### 7.6 最小回测长度

```
T_min >= N x TC x 2
N=参数组合数, TC=平均持仓天数

A股建议：
  短线：最少1年回测，建议2-3年
  中短线：最少1.5年，建议3-4年
  中线：最少2年，建议4-5年
  长线：最少3年，建议5-6年
```

## 8. 交易纪律审查

### 8.1 盘前10项检查（P1-P10）

| 编号 | 检查项 | 不通过时的动作 |
|:----:|:-------|:--------------|
| P1 | 3日内无持仓风险事件 | 提前制定方案 |
| P2 | 隔夜外盘方向参考 | 记录 |
| P3 | 今日重大数据/政策 | 谨慎 |
| P4 | VaR(95%)<5%, CVaR(99%)<10% | 减仓 |
| P5 | 仓位<=当日回撤等级上限 | 减仓 |
| P6 | 冷却期已结束 | 不开新仓 |
| P7 | 各持仓止损价已设定 | 补设 |
| P8 | 市场状态评估明确 | 不做方向不明交易 |
| P9 | 策略参数已按市场调整 | 调整 |
| P10 | 心理状态冷静 | 情绪不稳不交易 |

### 8.2 盘中监控8项（M1-M8）

| 编号 | 监控项 | 关键阈值 |
|:----:|:-------|:--------:|
| M1 | 日内净值-3% | 检查持仓 |
| M2 | 单股-5% | 考虑止损 |
| M3 | >=1只跌停 | 优先处理 |
| M4 | 逼近9.4% | 涨不买跌止损 |
| M5 | 成交>日均3倍 | 检查异常 |
| M6 | 最重行业跌>3% | 考虑系统性减仓 |
| M7 | 日内-4% | 距熔断仅1% |
| M8 | 手动干预冲动 | 等5分钟再决定 |

### 8.3 盘后审查12项（A1-A12）

| 编号 | 审查项 | 合规标准 |
|:----:|:-------|:--------:|
| A1 | 止盈止损执行 | 100%执行率 |
| A2 | 冷却期遵守 | 0次违规 |
| A3 | 仓位偏离度 | <5% |
| A4 | 盈亏比 | >1.0关注，<0.5严重 |
| A5 | 持仓集中度 | 阈值范围内 |
| A6 | 交易频率 | 无异常高频 |
| A7 | 手续费/总亏损 | <20% |
| A8 | 连败计数 | <3笔正常，>=5熔断 |
| A9 | 追涨杀跌检测 | 0次 |
| A10 | 情绪化交易 | 100%可解释 |
| A11 | 最大单笔亏损归因 | 有明确归因 |
| A12 | 数据源合规 | 100%合规 |

### 8.4 禁忌交易行为

| 行为 | 严重等级 |
|:-----|:--------:|
| 不设止损开仓 | 致命 |
| 止损触发不执行 | 致命 |
| 冷却期开新仓 | 严重 |
| 加仓摊平亏损 | 严重 |
| 连败后加仓位 | 严重 |
| 手动下调止损价 | 严重 |
| 集合竞价追涨停 | 较严重 |
| 跌停恐慌卖出 | 较严重 |

### 8.5 冷却期制度

| 类型 | 冷却时长 |
|:-----|:--------:|
| 正常止损 | 3个交易日 |
| 大幅止损(>8%) | 5个交易日（含大亏归因分析） |
| 连续2次止损 | 5个交易日 |
| 连续3次止损 | 10个交易日 |
| 止盈后 | 1个交易日 |
| 大止盈(>15%) | 3个交易日 |

### 8.6 连败三级响应

| 等级 | 条件 | 响应 |
|:----:|:-----|:-----|
| 一级 | 3笔连败 | 审查模式，不停止交易 |
| 二级 | 5笔连败 | 暂停5日，深度审查 |
| 三级 | 8笔连败 | 强制至少15日停工+策略重构 |
