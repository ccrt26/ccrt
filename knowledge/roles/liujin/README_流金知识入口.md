## 2. 流金不再默认全量读取旧知识库

### 2.1 旧文件去向

流金旧知识库（`.claude/agents/流金-知识库/`、`统一解读/角色解释包/流金_风控解释包.md`）中的内容已经：
- 提炼摘要进入新流金模块
- 在 `registry.json` 中建立映射关系
- 在 `deprecated_refs.md` 中登记为历史来源

### 2.2 默认读取范围

流金启动时默认读取：
1. `knowledge/roles/liujin/README_流金知识入口.md` — 确定入口
2. 按任务类型选择对应的模块（见下文任务类型选择指南）
3. `.claude/agents/风控官-流金.md` — 角色定义（仍保留为启动入口文件）

### 2.3 旧文件默认不读取

旧文件保留作为：
- 历史版本追溯
- 审计证据链
- 升级前的基线参考
- 非核心知识的候选来源

**流金不得默认全量读取以下文件：**
- `.claude/agents/流金-知识库/*`
- `统一解读/角色解释包/流金_风控解释包.md`
- `统一解读/六库/*`

## 4. 与六库的关系

| 组件 | 定位 | 流金在其中的角色 |
|:-----|:-----|:-----------------|
| 流金知识库（本目录） | 流金稳定认知 | 主责维护 |
| 反例库（六库） | 失败案例，防单次失败改核心规则 | 读（检查）+ 写（报告） |
| 参数库（六库） | 可调整阈值、窗口、权重 | 读（参考）+ 写（候选） |
| 来源等级库（六库） | 知识来源可靠性判定 | 读（检查）+ 写（评估） |
| 模板污染库（六库） | 检查过度表达、空话、强结论 | 旧影使用，流金不写 |

**冲突时优先级**：
1. 外部权威资料（已在知识库中标注的） > 六库经验记录
2. 项目已验证经验（知识库中标注 project_verified） > 六库单次记录
3. 六库多次一致记录 > 知识库中未及时更新的过时内容（应启动更新流程）
4. 冲突无法确定时 -> 流金提出评估 -> 腰子裁决 -> 旧影审计

## 5. 哪些内容可进入核心知识

### 可进入
- 外部权威资料的浓缩摘要（标注出处和适用范围）
- 项目内多次验证确认的风险阈值和规则
- 角色协作形成的共识规则
- 经过后评估归因并多次验证的风控规律
- 经完整知识进化流程升级的成熟内容

### 不可进入
- 外部文献原文（须浓缩）
- 大模型临时推理结果（须转化为可验证候选并补强来源）
- 单次后评估结果（须积累到阈值）
- L5-seed 以 core 状态入库
- 六库原始记录（须经过知识进化流程）
