## 1. 信号评估输出模板

青山被腰子咨询时，使用以下模板生成 `signal_assessment` 段。

### 1.1 必填字段

| 字段 | 要求 | 说明 |
|------|------|------|
| interpretation_id | 必填 | 统一解读协议要求的解释对象ID |
| role_interpretations | 必填 | 当前角色为本次分析的贡献 |
| knowledge_refs | 必填 | 本次分析引用的知识条目（knowledge_id） |
| eval_hooks | 必填 | 可验证、可后评估的具体条件 |
| rule_refs | 必填 | 引用的规则条目编号 |
| audit_u9 | 必填 | 知识来源可审计性检查 |
| audit_u10 | 必填 | 知识等级与动作支持一致性检查 |

### 1.2 信号评估段落

```
### 信号评估（青山）

**已触发信号**：
| 信号ID | 名称 | 触发条件 | 当前是否匹配 |
|--------|------|---------|-------------|
| SIG-00X | XXX | XX | 是/否/部分 |

**来源等级与样本信息**：
- 来源等级：L5-seed（信号胜率库种子估计）
- 样本数：N/A（尚未经过项目内实证）
- 项目内评估：待后续后评估积累

**适用环境**：
- 适用：XXX、XXX
- 不适用：XXX、XXX（缩量震荡、退市风险等）
- 当前环境匹配度：高/中/低

**反证**：
- 同向信号数：X
- 反向信号数：X
- 已知冲突场景：XXX
- 历史失效比例：参考外部种子数据

**组合效果**：
- 多个同向信号叠加效果（严格限定：L5-seed 即使多个同向，也不得支持动作升级）

**动作升级判断**：
- 是否可支持动作升级：❌ 否
- 原因：所有信号均为 L5-seed 级别，来源等级不足以支撑强动作

**失效条件**：
- 若 XXX（外部条件变化），本信号结论失效
- 若 XXX（基本面数据变化），本信号结论失效
```

## 2. 信号组合规则说明

### 2.1 当前规则（基于 L5-seed 信号）

由于当前所有信号均为 **L5-seed 级别**，以下规则仅作为输出格式参考，不代表动作支持依据：

```
多个L5-seed信号同向 → 可为腰子提供参考信息
多个L5-seed信号同向 → 不得支持动作升级
多个L5-seed信号同向 → 不得提升输出强度
```

### 2.2 升级后规则（仅适用于经过项目验证的信号）

以下规则仅在信号来源等级达到 L3 或以上，且 can_support_strong_action=true 时适用：

```
多个同向信号 → 可作为腰子判断的参考强度信息
非L5-seed且来源等级满足L1/L2/L3 → 可参考作为辅助依据
经过腰子特批并有项目验证记录 → 可支持动作升级
```

> **注意**：当前所有信号均为 L5-seed，以上升级后的规则尚未激活。

## 3. 输出强度分层

青山输出强度分为三个层次，来源等级决定可用层次：

| 输出层次 | 适用来源等级 | 输出特征 |
|---------|-------------|---------|
| 参考级 | L5 / L5-seed / L4 | "信号已触发，当前为参考信息"，不涉及动作支持 |
| 参考+建议级 | L3（外部权威） | "信号有效，当前环境匹配度为X，可作为辅助依据" |
| 强支持级 | L2 / L1 | "信号已验证有效，当前环境高度匹配，可支持操作" |

**当前可用的最高输出层次**：参考级（所有信号为 L5-seed）

## 4. 知识引用规范

青山输出中引用知识时，必须标注：

1. **知识条目**：引用 `registry.json` 中的 `knowledge_id`
2. **来源类型**：external_authority / project_verified / role_consensus / model_candidate
3. **来源等级**：L1 / L2 / L3 / L4 / L5 / L5-seed
4. **状态**：core / reference / candidate / deprecated

**格式示例**：
```
引用知识：[QS-FRAMEWORK-001] 因子评估IC/ICIR方法论
来源类型：external_authority | 来源等级：L3 | 状态：core
```
