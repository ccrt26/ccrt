# 候选层目录

## 用途

此目录存放通过验证后进入候选层的文献卡片副本或链接。

## 子目录

| 子目录 | 用途 |
|:-------|:-----|
| `parameters/` | 参数候选——验证表明文献中的参数有效 |
| `counterexamples/` | 反例候选——文献构成对既有知识的反例 |
| `core_knowledge/` | 核心知识候选——文献可升级为核心知识 |

## 规则

1. 进入候选层前必须完成项目验证（validated = true）
2. 进入候选层前必须经过腰子统一口径（finance_aligned = true）
3. 候选层内容不得进入 active_index.json
4. 候选层内容不得进入角色启动上下文
