# 角色主责路由规则 v1.0

> **本文档定义外部文献的主责角色（primary_role）路由规则。**
> 配套文档：[POLICY_外部文献入库流程_v1.0.md](POLICY_外部文献入库流程_v1.0.md) | [POLICY_文献状态机_v1.0.md](POLICY_文献状态机_v1.0.md)

---

## 一、路由总规则

阿黑在 G0 阶段根据文献 material_type 判断主责角色。
每篇文献有且仅有一个 primary_role。
`support_roles` 补充其他角色职责范围内的边界，但不要求所有角色默认阅读。

**玉夜不是所有文献默认必经角色。** 只有文献明确涉及数据、样本、统计口径、指标定义、回测结果、事实冲突时，才将玉夜加入 support_roles 或设为 primary_role。

## 三、支撑角色加入规则

当文献内容涉及其他角色职责范围时，可将其加入 `support_roles`。

| 角色 | 支撑场景 |
|:-----|:---------|
| 山猫 | 文献包含宏观背景、经济环境、政策影响维度 |
| 信鸽 | 文献需要事件时间线、公告解读、监管背景 |
| 青山 | 文献涉及策略实现、信号验证、技术方法 |
| 流金 | 文献包含风控维度、仓位建议、极端情境考虑 |
| 玉夜 | 文献涉及数据源、统计方法、指标定义、回测口径 |

> `support_roles` 的添加规则：**必需时才加，不默认加载。**
> 不要为了让"多个角色看同一篇文献"而随意扩充 support_roles。

## 四、跨领域文献处理

跨领域文献指同时涉及宏观、策略、风控等多个维度的文献。

处理规则：
1. **必须指定一个 primary_role**——按文献最核心的内容选择
2. 其他角色只补充自己职责范围内的边界
3. 综合金融口径由腰子统一
4. 不得要求所有角色默认阅读全文
5. 各角色只阅读与自身职责相关的部分

跨领域文献的常见 primary_role 选择指引：
- 宏观维度占主导 → 山猫
- 策略/方法维度占主导 → 青山
- 风控维度占主导 → 流金
- 以事件/公告为切入点展开多维度分析 → 信鸽
- 数据方法/统计口径为核心 → 玉夜

## 五、合法角色列表

程序 identity_role 检查支持以下角色：

```
山猫, 信鸽, 青山, 流金, 玉夜, 腰子, 阿黑, 旧影, 情墨, 新安, 红结, 红枫, 千光
```

`primary_role` 和 `support_roles` 中的每个角色必须属于此列表。
