# 外部文献入库流程 v1.0

> **本文档定义外部文献从登记到生效/归档的标准流程。**
> 所有外部文献必须按本文档流程处理，禁止跳过任一阶段门。
> 配套文档：[POLICY_文献状态机_v1.0.md](POLICY_文献状态机_v1.0.md) | [POLICY_角色主责路由_v1.0.md](POLICY_角色主责路由_v1.0.md)

---

## 一、核心原则

1. **外部文献不得直接进入角色核心知识库**——必须经过完整流程后才能成为生效知识。
2. **外部文献不得直接进入角色启动上下文**——角色启动上下文只读 `active_index.json`。
3. **文献卡片由金融团队产出**——程序、阿黑、AI 均不得代写文献卡片或总结文献。
4. **程序只做治理，不做金融判断**——程序不得阅读文献、不得解释金融含义、不得替角色判断。
5. **未验证、未确认、无适用边界的内容不得进入生效区。**

## 二、总体流程

```
外部文献进入
  │
  ▼
[1] 原文登记 (RAW_RECEIVED)
  │  只登记来源、日期、版本、链接/路径
  │
  ▼
[2] 阿黑路由 (ROUTED)
  │  判断 material_type → 指定 primary_role
  │
  ▼
[3] 主责角色产出文献卡片 (CARD_DRAFTED)
  │  填写核心结论、适用范围、适用条件、不适用条件
  │
  ▼
[4] 支撑角色补充边界（如需）
  │  其他角色只补充自身职责范围内的边界
  │
  ▼
[5] 腰子统一金融口径 (FINANCE_ALIGNED)
  │  finance_aligned = true
  │
  ▼
[6] 参考知识 (REFERENCE_ONLY)
  │  不可执行，不可进入核心知识库
  │
  ▼
[7] 项目验证 (VALIDATION_PENDING)
  │  生成验证记录，validated = true
  │
  ▼
[8] 候选层
  ├── 参数有效 → PARAM_CANDIDATE
  ├── 形成反例 → COUNTEREXAMPLE_CANDIDATE
  └── 可升级核心知识 → CORE_CANDIDATE
  │
  ▼
[9] 对应角色确认
  │  confirmed_roles 填入确认角色
  │
  ▼
[10] 程序检查 + 旧影复查
  │   python3 tools/knowledge_guard.py lint
  │   python3 tools/knowledge_guard.py transition CARD-XXX --to ACTIVE
  │
  ▼
[11] 腰子/用户放行
  │
  ▼
[12] 生效入库 或 归档淘汰
      ACTIVE / DEPRECATED
```

## 三、阶段门（Gate）

| 阶段门 | 名称 | 是否可跳过 | 负责人 |
|:-------|:-----|:----------|:-------|
| G0 | 需求识别与路由 | 不可跳过 | 阿黑 |
| G1 | 金融口径与角色职责确认 | 不可跳过 | 腰子全体 |
| G2 | 技术方案设计 | 不可跳过 | 情墨 |
| G3 | 实施 | 需授权 | 执行团队 |
| G4 | 执行者自检 | 不可跳过 | 实施者 |
| G5 | 独立复查 | 不可跳过 | 旧影 |
| G6 | 放行归档 | 不可跳过 | 腰子/用户 |

> ⚠️ G5 不得由 G3 同一实施者自签通过。
> ⚠️ G6 如无法取得真实腰子/用户放行，只能标记为"G6 待放行"，不得声称 PASS。

## 四、角色职责

### 阿黑
- 只负责 G0 路由、派单、状态汇总
- **不得写文献卡片**
- **不得解释金融内容**
- **不得代签任何角色结论**

### 主责角色（山猫/信鸽/青山/流金/玉夜之一）
- 阅读相应内容
- 产出文献卡片（核心结论、适用范围、适用条件、不适用条件）
- 填写 reading_scope

### 腰子
- 统一金融口径
- 决定文献是否可进入参考知识、候选层、生效区
- 最终金融口径不得由其他角色代签

### 旧影
- G5 独立复查
- 检查流程是否越级、证据链是否完整、角色确认是否真实、程序检查是否通过
- 不替金融团队解释文献

### 程序（knowledge_guard.py）
- 字段检查
- 状态机校验
- 索引生成
- 过期复审提醒
- 越级拦截
- **不得解释金融内容**
- **不得总结文献**
- **不得替角色判断**

## 五、阅读规则

| 文献篇幅 | 规则 |
|:---------|:-----|
| 短文献（可全文阅读） | 主责角色原则上读全文 |
| 长文献（>5000字或复杂） | 主责角色可按章节阅读，但必须填写 `reading_scope` |
| 跨领域文献 | 各角色只阅读与自身职责相关的部分；综合金融口径由腰子统一 |

## 六、禁止事项

1. ⛔ 外部原文直接进入角色启动上下文
2. ⛔ 外部文献直接成为核心规则
3. ⛔ 未验证内容进入候选层
4. ⛔ 未确认内容进入 ACTIVE
5. ⛔ 玉夜被默认设为所有文献必经角色
6. ⛔ 阿黑写文献卡片或代下金融判断
7. ⛔ 程序解释金融内容
8. ⛔ 程序自动总结文献
9. ⛔ 程序自动升级规则
10. ⛔ 旧影代替金融团队确认结论
11. ⛔ 腰子确认缺失时放行
12. ⛔ `active_index.json` 加载 raw/cards/candidates/deprecated 内容
