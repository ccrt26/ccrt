1.1 业务描述

拓普集团（601689.SH）是国内汽车零部件平台型龙头，上交所主板上市。主营业务涵盖NVH减震器、底盘轻量化、热管理系统、智能驾驶执行器（IBS/EPS）、空悬系统五大产品线，深度绑定特斯拉+比亚迪+吉利+蔚小理等头部新能源车企。
