一、公司概要

拓普集团（601689.SH）是国内汽车零部件平台型龙头，上交所主板上市。主营NVH减震器、底盘系统、热管理系统、空气悬架、线控制动(IBS)，深度绑定特斯拉、比亚迪、吉利、华为等头部新能源车企。
