一、公司概要

招商银行（600036.SH）是A股公认的最优零售银行，上交所主板上市。以零售业务（财富管理/信用卡/消费贷）见长，零售AUM在股份制银行中遥遥领先，不良贷款率和拨备覆盖率均为行业最优水平。

维度 内容
所属行业 银行 / 股份制银行（申万）
主营业务 零售银行+财富管理+批发银行
市场地位 股份制银行零售之王，高净值客户粘性极强
上市板块 上交所主板

核心投资逻辑

  1. 零售银行护城河 — 高净值客户粘性极强，零售存款成本远低于同行
  2. 财富管理转型 — 从"赚息差"到"赚手续费"，轻资产模式ROE更高
  3. 资产质量最优 — 不良率+拨备率双优，在经济下行期抗风险能力最强
  4. 估值历史低位 — PE ~6.0x，处于过去10年最低分位区间，深度价值
