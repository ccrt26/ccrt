  1. 锂电设备龙头（L1） — 宁德时代核心供应商，锂电全球产能扩张→设备订单确定性强
  2. 光伏+氢能设备平台化 — 从锂电设备向光伏(TOPCon/HJT)+氢能(电解槽)延伸→市场空间扩大
  3. 海外扩产机遇 — 欧洲/美国锂电本土化→中国设备出口，先导有海外客户基础
  4. 今日+3.98%领涨 — 10只重点股中涨幅最大，设备更新政策+高端装备板块走强
