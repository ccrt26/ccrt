一、公司概要

多瑞医药（301075.SZ）是小盘化学制药企业，深交所创业板上市。主营业务为化学药品制剂及原料药的研发、生产和销售。由于流通市值较小（估计<50亿），不在主流数据源的常规覆盖范围，部分技术面数据不可获取。

核心问题：公司近年陷入严重经营困境——营收萎缩、毛利率崩塌、持续亏损。这是一个"困境反转型"博彩，而非稳健投资标的。
