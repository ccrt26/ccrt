一、公司概要

上海电气（601727.SH）是中国最大的综合装备制造集团之一，上交所主板上市。业务覆盖能源装备（火电/核电/风电/光伏）、工业装备（电梯/电机/自控）、集成服务（工程总包/运维）。控股股东为上海市国资委，是典型的"大国重器"型国企。
