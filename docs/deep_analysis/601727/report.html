一、公司概要

1.1 业务描述

上海电气（601727.SH）是国内最大的综合能源装备制造集团之一，上交所主板上市，上海市国资委控股。主营火力/核能/风电发电设备、输配电设备、工业装备（电梯/电机/机床）、环保装备。是中国三大动力（上海电气/东方电气/哈尔滨电气）之首，核电主泵/汽轮机/发电机国内市占率>40%。市值约1200亿，员工超5万人。
