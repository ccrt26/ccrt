# 铁律量化项目协作宪法

1. **代码化闸门**：所有确定性检查由脚本完成，AI只处理需要判断的任务。
2. **上下文包裹**：角色间交接使用结构化包裹，禁止转发原始对话。
3. **签名即责任**：每个决策签名不可篡改，日志全记录。
4. **数据层零Token**：禁止AI直接读取大于500KB的数据文件，禁止用AI做简单API调用或计算。
5. **流程状态机驱动**：阿黑只能驱动流程，不能直接修改状态或签名。
6. **文件规模铁律**：新文件单文件≤500行，Agent定义文件≤250行/12KB，Command文件≤40行/2KB。
7. **最低Token原则**：角色切换通过command文件，禁止spawn Agent；输出压缩，关键结论≤200字。
8. **日志先行**：一切操作必须产生结构化日志后才可执行下一步。
