自动续跑]
    L5 -->|否| L6[6. 推进到下一阶段
pipeline_engine.ps1 -Advance]
    L5Y --> L1

    L6 --> L7[7. 循环回到步骤1]
    L7 --> L1

三、流程引擎状态机（pipeline_engine.ps1）

stateDiagram-v2
    [*] --> Idle: 无活跃流程

    Idle --> Stage1_情墨: -Start
    Stage1_情墨 --> Gate1: -Validate

    Gate1 --> Stage1_情墨: FAIL → -Retry
    Gate1 --> Stage2_审查: PASS → -Advance

    Stage2_审查 --> Stage3_红结: -Advance

    Stage3_红结 --> Gate2: -Validate
    Gate2 --> Stage3_红结: FAIL → -Retry
    Gate2 --> Stage4_验证: PASS → -Advance

    Stage4_验证 --> Gate3: -Validate
    Gate3 --> Stage4_验证: FAIL → -Retry
    Gate3 --> Stage5_部署: PASS → -Advance

    Stage5_部署 --> Stage6_后评估: -Advance
    Stage6_后评估 --> [*]: -Complete → 归档

    note right of Gate1: 闸门1 — 设计闸
    note right of Gate2: 闸门2 — 代码闸
    note right of Gate3: 闸门3 — 上线闸
