## 总体目标

把当前项目从”多套缓存/脚本/闸门各说各话”的数据状态，收敛为：

1. 地基契约承认 D04 数据中台。
2. 当日权威、历史权威、归档权威清晰。
3. 旧 numeric/freshness 闸门能识别新权威链路。
4. L3 归档与 L2 SQLite 有可验证的数据基础。
5. UnifiedDataSource 先 shadow/dual-write，再 guarded cutover。
6. 旧入口、重复缓存、Windows 遗留资产按证据清理。
