## 一、STEP0 要解决的问题

STEP0 只解决 D04 数据地基重设计开工前的 5 个冻结问题：

1. D04 是什么能力。
2. D04 能做什么、不能做什么。
3. L1/L2/L3 权威源如何划分。
4. registry / gate 后续如何落地。
5. STEP1 到 STEP4 分别允许改什么、禁止改什么。

STEP0 不解决：

1. 生产代码实现。
2. L2 SQLite 创建。
3. 历史数据迁移。
4. UnifiedDataSource 切换。
5. GitHub 上传。
6. 角色签字争议。
