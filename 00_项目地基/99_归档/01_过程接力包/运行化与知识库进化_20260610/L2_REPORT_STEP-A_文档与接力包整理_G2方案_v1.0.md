# STEP-A：文档与接力包整理 G2 方案

> 日期：2026-06-09
> 流程编号：F-MIGRATE + F-ARCH
> 阶段门：G0/G2
> 目标：把地基 1.0 过程文档从“散落证据链”收口为可导航索引和运行手册。

---

## 1. 阶段目标

只整理说明，不改程序，不迁移生产数据，不删除历史接力包。

本阶段完成后，后续会话应能通过少量入口文件知道：

1. 地基正式文件在哪里。
2. 五步优化和 WARN 收口证据在哪里。
3. L1/L2/L3 数据分层怎样运行、怎样回滚。
4. 哪些旧入口保留、废弃、隔离或待审。
5. 什么时候可以进入 L2 数据实装。

---

## 3. 禁止修改范围

| 禁止 | 说明 |
|:-----|:-----|
| 删除历史接力包 | 历史证据链必须保留 |
| 移动 `.md` 文件 | 需另开 F-MIGRATE 映射表和回滚方案 |
| 修改脚本 | 本阶段只做文档 |
| 修改 JSON 注册表 | 结构化权威资产不在本阶段范围 |
| 修改日报/深度分析入口 | 生产入口不在 STEP-A |

## 5. 执行顺序

1. 盘点 `五步优化接力包/` 的索引、总结、运行手册、回滚手册、WARN 记录。
2. 盘点 `00_总览/` 的 START/INDEX/STATE 与本阶段入口的关系。
3. 新增或更新运行化阶段索引。
4. 新增运行手册、回滚手册、数据分层手册的骨架。
5. 新增旧入口治理表和 WARN 收口记录。
6. 更新 `目录治理索引.md`，只增加链接，不改变原有结论。
7. 跑文档层验收命令。
