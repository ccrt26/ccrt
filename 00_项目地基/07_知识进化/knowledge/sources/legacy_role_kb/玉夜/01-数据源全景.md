## 一、数据源总览

铁律量化项目采用"1+2主备架构"，覆盖行情、K线、财务、板块、资金流向、北向资金、研报、融资融券八大类数据。每条数据必须按**主API → 备API[B] → 缓存[C]**的顺序获取。

### 1.1 数据源编号规范

| 编号 | 角色 | 含义 |
|:----:|:----:|:-----|
| [1] | 主源（行情） | 腾讯API — 实时行情/批量行情/分时 |
| [2] | 主源（K线）/ 备源（行情） | 新浪API — K线数据 / 行情备用 |
| [3] | 主源（财务） | 东方财富datacenter API — 季报财务数据 |
| [5] | 本地计算 | 技术指标（MA/RSI/MACD/布林带），非外部API |
| [7] | 主源（板块） | 东方财富push2 API — 行业板块排行 |
| [7b] | 主源（板块成分股） | 东方财富push2 API — 板块内成分股 |
| [8] | 主源（北向资金） | 东方财富datacenter-web API — 北向持股明细 |
| [9] | 主源（个股资金） | 东方财富push2 API — 个股资金流向 |
| [10] | 主源（行业资金） | 东方财富push2 API — 行业资金流向 |
| [11] | 主源（研报） | 东方财富reportapi — 分析师研报/评级 |
| [12] | 主源（融资融券） | 东方财富datacenter API — 融资融券明细 |
| [THS] | 备源（多类） | 同花顺THS via akshare — 财务/板块/资金流/研报/两融备源 |
| [13] | 备源（多类） | 必盈API biyingapi.com — 行情/K线/三大报表备源（免费版200次/天） |
| [14] | 主源（分红/宏观/预告）/ 备源（K线/财务） | baostock免费库 — 16个action；Phase 1-3独有源，Phase 4备源增强 |
| [15] | 备源增强（多类） | 东方财富Skills MCP — 官方MCP金融数据接口；行情/财务/资金流/宏观/研报备源；50次/天/技能 |
| [C] | 缓存兜底 | 本地JSON缓存 — 所有API的最后兜底层 |

### 1.2 数据源优先级配置（来自 stock_data_fetcher.psm1）

```
Quote      : 腾讯[1] → 新浪[B] → 必盈[13] → Skills[15] → 缓存[C]
KLine      : 新浪[2] → 腾讯[B] → 必盈[13] → baostock[14] → 缓存[C] (Skills不覆盖K线)
Financial  : 东方财富[3] → 同花顺[THS] → 必盈[13] → baostock[14] → Skills[15] → 缓存[C]
Sector     : 东方财富[7] → 同花顺[THS] → Skills[15] → 缓存[C]
FundFlow   : 东方财富[9] → 同花顺[THS] → Skills[15] → 缓存[C]
Northbound : 东方财富[8] → 缓存[C]（2024/08政策变更后个股日频不可得，仅季度快照~57天滞后）
Southbound : AKShare[THS-SB]主源(hist_em) → AKShare[THS-SB]备源(summary) → 缓存[C]（2026-05-27新增，日频补位北向失效）
Research   : 东方财富[11] → 同花顺[THS] → Skills[15] → 缓存[C]（Skills财经资讯穿透消灭独有源风险 ✅）
Margin     : 东方财富[12] → 同花顺[THS] → 缓存[C]（THS上交所/深交所官方数据备源）
Macro      : baostock[14] → Skills[15] → 缓存[C]（Skills宏观数据洞察消灭独有源风险 ✅）
```

## 二、各数据源详细规格

### 2.1 [1] 腾讯实时行情 — 主源（行情）

| 属性 | 值 |
|:-----|:---|
| 端点 | `http://qt.gtimg.cn/q=<market><code>` |
| 方法 | HTTP GET |
| 超时 | 5秒（单只）/ 10秒（批量） |
| 频率限制 | 间隔>=0.3秒；每10次额外sleep 2秒 |
| 批量支持 | 是，逗号分隔，单次最多约80只 |
| 市场前缀 | `sh` — 6开头（上海主板/科创板）；`sz` — 0/3开头（深圳主板/创业板） |

#### 返回字段映射

腾讯返回 `var hq_str_xxx="值1~值2~..."` 格式，以 `~` 分隔。关键字段索引：

| 索引 | 字段名 | 说明 | 类型 |
|:----:|:------|:-----|:----:|
| 1 | Name | 股票名称 | string |
| 2 | Code | 股票代码 | string |
| 3 | Price | 最新价 | double |
| 4 | PrevClose | 昨收价 | double |
| 5 | Open | 开盘价 | double |
| 6 | Volume | 成交量（手） | long |
| 30 | Time | 数据时间 | string |
| 31 | Change | 涨跌额 | double |
| 32 | ChangePct | 涨跌幅（%） | double |
| 33 | High | 最高价 | double |
| 34 | Low | 最低价 | double |
| 37 | Turnover | 成交额（万） | double |
| 38 | TurnoverRate | 换手率（%） | double |
| 39 | PE | 静态市盈率 | double |
| 43 | Amplitude | 振幅（%） | double |
| 44 | MktCap | 总市值 | double |

#### 已知问题

- PE为**静态PE**（基于上年年报），非PE(TTM)。根据红线规则，PE(TTM)必须手动计算，禁止直接用此字段做否决判断。
- 非交易日返回的数据可能为空或前一交易日数据
- 高频调用会触发腾讯反爬，返回空字符串或错误码

### 2.2 [2] 新浪K线 — 主源（K线）

| 属性 | 值 |
|:-----|:---|
| 端点 | `http://money.finance.sina.com.cn/quotes_service/api/json_v2.php/CN_MarketData.getKLineData` |
| 参数 | `symbol=<market><code>&scale=<scale>&ma=5&datalen=<count>` |
| 方法 | HTTP GET |
| 超时 | 8秒 |
| 需设置User-Agent | 是，需模拟浏览器 |

#### 参数说明

| 参数 | 值 | 说明 |
|:----|:---|:-----|
| scale | 240 | 日线 |
| scale | 60 | 60分钟线 |
| scale | 30 | 30分钟线 |
| scale | 15 | 15分钟线 |
| scale | 5 | 5分钟线 |
| datalen | 120（默认） | 返回K线条数 |
| ma | 5 | 附带5日均线 |

#### 返回字段（JSON数组）

```json
[{"day":"2026-05-23","open":"10.50","high":"10.80","low":"10.30","close":"10.60","volume":"500000"}]
```

| 字段 | 说明 | 类型 |
|:----|:-----|:----:|
| day | 日期 | string |
| open | 开盘价 | double |
| high | 最高价 | double |
| low | 最低价 | double |
| close | 收盘价 | double |
| volume | 成交量 | long |

#### 已知问题

- 新浪API稳定性不如腾讯，偶发超时
- 停牌期间K线无新数据（正常，需标记非错误）
- 部分次新股历史K线较短，datalen超出实际返回条数时不会报错

### 2.3 [2-备] 腾讯K线 — 备源（K线）

| 属性 | 值 |
|:-----|:---|
| 端点 | `http://web.ifzq.gtimg.cn/appstock/app/fqkline/get` |
| 参数 | `param=<market><code>,day,,,<count>,qfq` |
| 方法 | HTTP GET |
| 超时 | 8秒 |
| 复权方式 | qfq = 前复权 |

#### 返回结构（嵌套JSON）

```
data.{code}.qfqday → [["date","open","close","high","low","volume"], ...]
data.{code}.day     → [...]
```

优先取 `qfqday`（前复权），若无则取 `day`。字段顺序：`[0]=Date, [1]=Open, [2]=Close, [3]=High, [4]=Low, [5]=Volume`

### 2.4 [1-备] 新浪行情 — 备源（行情）

| 属性 | 值 |
|:-----|:---|
| 端点 | `http://hq.sinajs.cn/list=<market><code>` |
| 方法 | HTTP GET |
| 超时 | 5秒 |
| 需设置Referer | `http://finance.sina.com.cn` |

#### 返回字段

新浪返回 `var hq_str_xxx="字段1,字段2,..."` 格式，以逗号分隔。

| 索引 | 字段名 | 说明 |
|:----:|:------|:-----|
| 0 | Name | 股票名称 |
| 1 | Open | 开盘价 |
| 2 | PrevClose | 昨收价 |
| 3 | Price | 最新价 |
| 4 | High | 最高价 |
| 5 | Low | 最低价 |
| 8 | Volume | 成交量（手） |
| 9 | Turnover | 成交额（万） |
| 31 | Time | 数据时间 |

#### 重要限制

- **新浪行情不提供PE、换手率、市值、振幅**，这些字段在备源中为 null
- 涨跌幅和涨跌额需从Price和PrevClose手动计算
- 成交额字段含非数字字符，需正则清洗

### 2.13 [14] baostock — 新源（分红/宏观/预告/K线财务备源）

#### K线返回字段（比新浪[2]更丰富）

K线接口返回18个字段：date, code, open, high, low, close, preclose, volume, amount, adjustflag, turn(换手率), tradestatus, pctChg(涨跌幅), **peTTM**(滚动市盈率), **pbMRQ**(市净率), **psTTM**(滚动市销率), **pcfNcfTTM**(滚动市现率), isST

> **注意**：peTTM为baostock计算值，不可直接替代PE(TTM)自算公式。仅作参考校验用。

#### 调用方式

```

### 5.1 东方财富反爬特征

东方财富API存在以下反爬机制：
- 部分端点需要 `Referer` 头，且需指向东方财富自身域名
- 非标准UT参数（如 `ut=bd1d9ddb04089700cf9c27f6f7426281`）为固定值，变更可能导致拒绝服务
- 高频请求会触发空响应（不返回HTTP错误码，但data为空）
- 板块类API（push2端点）反爬最为敏感

## 七、特殊场景下的API行为

### 7.1 交易日-非交易时段

在交易日但非连续竞价时段（如11:30-13:00午休，或15:00后），API行为：
- 腾讯行情：返回 **当日最后一笔成交价**（15:00后即为收盘价），非实时价格
- 新浪K线：返回完整日线数据，当日K线以收盘价更新
- 资金流向类：收盘后方可获取完整日数据

### 7.2 节假日

- 所有行情API返回空或前一交易日数据
- 需与 `每日荐股/运营记录/holidays_2026.csv` 交叉验证
- 节假日返回空数据属于**正常行为**，不算异常

### 7.3 个股停牌

- 腾讯行情：返回停牌前最后一日数据，涨跌幅为0
- 新浪K线：无新K线数据（正常）
- 资金流向：停牌期间数据为空（正常）
- **注意**：停牌股不能用常规异常标准判断

### 7.4 新股/次新股

- 上市不足60天的股票，K线数据不足，技术指标计算结果不稳定
- 部分财务数据可能只有1-2个季度的披露
- PE百分位计算样本不足时会返回null

## 八、玉夜巡检时的数据源检查优先级

8. **同花顺THS桥接[THS]** — 检查备源可用性
9. **本地缓存[C]** — 检查各缓存文件的新鲜度
