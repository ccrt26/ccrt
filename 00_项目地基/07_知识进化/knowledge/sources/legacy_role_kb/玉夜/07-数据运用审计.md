# 07 — 数据运用审计

> **定位**：玉夜第七审计维度（利用率）。在数据质量六维度（完整性/准确性/时效性/一致性/唯一性/有效性）基础上，新增数据"用没用"的检查。
> **关联文件**：`重点股票/分析逻辑/数据运用优化方案_v1.0.md`（审计参照标准）
> **触发时机**：每次深度分析报告产出后 + 每周五晚巡检 + 每月末

---

## 一、审计维度定义

| 维度 | 核心问题 | 不可用阈值 | 警告阈值 | 巡检频率 |
|:----:|:--------|:--------:|:-------:|:------:|
| **利用率** | 拉取的数据被分析报告引用了吗？ | 单份报告引用<12/19类 | <15/19类 | 每次报告产出 |

与现有六维度不同：利用率审计的对象不是"数据本身质量"，而是"分析端对数据的使用质量"。数据100%准确但只用10%=浪费。

## 二、U-1~U-4 报告级检查（每次深度分析报告产出时）

### U-1 数据源种类统计

**方法**：统计报告中出现的所有数据源编号（[1][2][3][5][7][8][9][10][11][12][14][tushare]等），去重计数。

**PASS标准**：≥12/19类

**检查方式**：grep 报告中所有 `[数字]` 和 `[tushare]` 引用，去重计数。

### U-2 强制字段存在性

**方法**：检查以下强制字段是否出现在报告中。每个字段对应一个正则匹配模式：

| 强制字段 | 所在章节 | 正则匹配 |
|:--------|:------|:-----|
| 质押风险行 | §六 风控 | `质押.*(占其持股\|占总股本)` |
| 杜邦拆解行 | §三.3 盈利能力 | `净利率.*周转率.*杠杆` |
| 管线板块相位 | §二.2 行业定位 | `管线板块相位\|SectorPhaseMap` |
| 四档资金拆解表 | §六 风控 | `超大单.*大单.*中单.*小单\|超大单净额.*大单净额` |
| PE历史分位 | §五 估值 | `PE.*分位\|百分位\|历史分位` |
| 行业资金方向 | §二.2 行业定位 | `行业资金.*[\[（]10[\]）]` |

**PASS标准**：全部6项存在。缺少任一项→FAIL，标注缺失项。

### U-3 资金面四档结构

**方法**：检查§六（深度分析）或§2.2（日报）的资金面是否包含四档拆解，而非仅"主力净流入"一行。

**PASS标准**：包含超大单/大单两档及以上（中单/小单可选）。

### U-4 "数据不可获取"率

**方法**：统计报告中出现"数据不可获取""数据缺失""数据不可得"的次数，除以应出现的数据源字段总数。

**PASS标准**："不可获取"率 <20%。≥20%→WARN，≥50%→FAIL。

> **注意**：北向个股日频标注"不可获取"是预期的（政策限制），不计入FAIL分子。

## 五、A/B类问题判定与闭环

### A类：单份报告缺陷

**触发**：U-1~U-4任一项FAIL，且为首次/非连续发生。

**闭环路径**：
```
玉夜标注缺失项 → 直接通知腰子 → 腰子补全 → 玉夜重新检查该项 → PASS → 关闭
```

**时限**：
- 缺失≤2项：2小时内补全
- 缺失≥3项：当天内补全
- 超时未补 → 升级为B类，报阿黑

### B类：模板/流程缺陷

**触发**：连续2次同类型A类FAIL，或周报识别出模式问题。

**闭环路径**：
```
玉夜标注"B类-模式问题" → 上报阿黑 → 阿黑分派责任人（腰子+情墨）→ 责任人修复模板 → 通知旧影 → 旧影验证模板 → PASS → 关闭
```

**判定标准**：同一强制字段连续2次缺失 = B类。不同字段缺失 = 各自独立的A类。

## 六、阈值与升级规则

| 条件 | 判定 | 动作 |
|:-----|:---:|:-----|
| 单份U-1<12类 | A类FAIL | 打回腰子补全 |
| 单份U-2<6项 | A类FAIL | 打回腰子补全 |
| 单份U-4≥50% | A类FAIL | 检查数据管线是否异常 |
| 连续2次同项FAIL | B类 | 上报阿黑，模板修复 |
| 月度某数据类利用率<目标值 | WARN | 标注退化，下月追踪 |
| 月度加权平均<目标值 | FAIL | 上报阿黑，根因分析 |
| 连续2次同项B类 | 联合审查 | 腰子+情墨+责任人会诊 |
| 连续3次同项B类 | L3升级 | 请示用户 |
