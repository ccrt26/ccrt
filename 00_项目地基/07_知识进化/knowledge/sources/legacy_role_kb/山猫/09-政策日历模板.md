# 政策日历模板 — 山猫宏观巡检

> 版本 v1.0 | 生效日期 2026-05-24
> 用途：山猫在每个月初/季初填充当月关键政治经济事件，作为宏观简报的日历前瞻部分

---

## 一、年度固定事件

### 政治会议

| 事件 | 通常时间 | 关键看点 | 市场影响 |
|:-----|:--------|:--------|:--------|
| 中央经济工作会议 | 12月中旬 | 次年经济政策定调 | ⭐⭐⭐⭐⭐ |
| 两会(全国人大/政协) | 3月5-15日 | 年度GDP目标、财政赤字率、专项债额度 | ⭐⭐⭐⭐⭐ |
| 中央政治局会议(经济) | 4/7/10/12月 | 季度经济形势研判+政策微调 | ⭐⭐⭐⭐ |
| 国常会 | 每周三 | 具体政策部署、减税降费 | ⭐⭐⭐ |
| 中央金融工作会议 | 约5年一次(上次2023) | 金融监管方向 | ⭐⭐⭐⭐ |
| 三中全会 | 换届后第三年秋季 | 重大改革部署 | ⭐⭐⭐⭐ |

### 经济数据发布日历（月度模板）

```
【YYYY年MM月 重要数据发布日历】

第一周(1-7日):
├── PMI(制造业) — 上月最后一天
├── PMI(非制造业) — 当月第1天
├── 财新PMI — 当月第1-3天
└── 外汇储备 — 当月7日

第二周(8-14日):
├── CPI/PPI — 当月9-10日
├── 社融/M2/新增贷款 — 当月10-15日
└── 贸易数据 — 当月7-10日

第三周(15-21日):
├── 工业增加值/社零/固投 — 当月14-16日
├── GDP(季末月) — 当月15-18日
└── LPR报价 — 当月20日

第四周(22-月底):
├── 规模以上工业企业利润 — 当月27-28日
└── 央行季度货币政策报告(季末月)
```

## 三、季末特殊关注

| 季度 | 额外关注 |
|:----:|:--------|
| Q1(1-3月) | 两会政策窗口、年报披露季、春节效应 |
| Q2(4-6月) | 年报/一季报披露截止(4/30)、分红除权高峰、半年报预告(6月底) |
| Q3(7-9月) | 半年报披露(8/31截止)、政治局年中定调、三季报预告(9月底) |
| Q4(10-12月) | 三季报披露(10/31截止)、中央经济工作会议、基金年度排名、ST/*ST保壳 |

## 四、事件影响评估模板

每项事件输出时使用：

```
【事件名称】
时间：[精确到日]
性质：[例行/临时/紧急]
主要内容：[3-5条关键点]
政策力度：[强/中/弱]（对照历史阈值）
市场影响：
  - 短期(1-3日)：[预判+置信度]
  - 中期(1-4周)：[预判+置信度]
  - 板块影响：[受益/受损行业]
历史参照：[类似事件的历史市场反应]
```

## 五、维护规则

- 每年12月更新次年年度政治日历
- 每月初填充当月具体数据发布日期
- 临时事件（如突发政策、领导人讲话）随时增补
- 事件发生后72小时内补充实际影响回顾
