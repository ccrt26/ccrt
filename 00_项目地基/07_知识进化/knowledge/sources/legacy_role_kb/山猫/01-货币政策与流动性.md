## 一、央行货币政策工具箱

中国人民银行实施货币政策的主要工具分为价格型、数量型和结构型三大类。理解这些工具的触发条件、操作频率和信号含义，是判读货币政策方向的基础。

### 1.1 价格型工具

#### MLF（中期借贷便利，Medium-term Lending Facility）

```
期限：3个月/6个月/1年（主力为1年期）
操作频率：每月15日（遇节假日顺延）
操作方式：招标方式，利率由央行决定
2025年最新1年期MLF利率：2.00%（需定期确认）
```

**信号含义**：
- MLF利率是LPR定价的"锚"——LPR = MLF利率 + 银行加点
- MLF利率下调 → 降息信号 → LPR预计跟随下调 → 利好股市（降低企业融资成本）
- MLF利率不动但超额续作 → "量松价稳"，中性偏宽松
- MLF缩量续作 → 回收流动性，偏紧信号

**操作解读框架**（5步检查清单）：

| 步骤 | 检查项 | 判断标准 |
|:----:|:------|:---------|
| 1 | 利率是否调整 | 下调=宽松信号，上调=紧缩信号，不变=维持 |
| 2 | 续作规模 vs 到期规模 | 超额续作=净投放，等额=中性，缩量=净回笼 |
| 3 | 超额续作幅度 | >1000亿=明显宽松，<500亿=微调 |
| 4 | 连续趋势 | 连续3个月超额续作=宽松周期确认 |
| 5 | 与市场预期的偏差 | 超预期降息/超额续作 > 符合预期 > 不及预期 |

#### LPR（贷款市场报价利率，Loan Prime Rate）

```
报价频率：每月20日9:15（遇节假日顺延）
报价行：18家商业银行（含外资行）
两个品种：1年期LPR（短期贷款基准）、5年期以上LPR（房贷基准）
2025年最新1年期LPR：3.10%，5年期LPR：3.60%（需定期确认）
```

**LPR对A股的影响路径**：
- 1年期LPR下调 → 企业短期贷款/票据融资成本降 → 利好制造业、中小企 → 中证500/中证1000偏利好
- 5年期LPR下调 → 房贷利率降 → 利好房地产、银行（以量补价）、家电/建材
- LPR非对称下调（1年期降5年期不动） → 政策更关注企业端 → 对地产板块偏空
- LPR连续不动超过6个月 → 货币政策进入观察期 → 市场对"降息"预期降温

#### SLF（常备借贷便利，Standing Lending Facility）

```
别称："利率走廊上限"
期限：隔夜/7天/1个月
操作频率：按需申请（金融机构主动发起）
2025年最新隔夜SLF利率：2.55%（需定期确认）
```

**利率走廊机制**：

```
利率走廊上限 = SLF利率（央行借钱给银行的最高价）
利率走廊下限 = 超额存款准备金利率（银行把钱存央行的最低价）
利率走廊中枢 = 7天逆回购利率（央行的政策利率锚）
市场利率 DR007 应在走廊内波动
```

当DR007突破SLF利率时 → 银行间流动性极度紧张 → 央行通常立即干预。

### 1.2 数量型工具

#### 存款准备金率（RRR，Required Reserve Ratio）

```
操作频率：不定期（近年约2-4次/年，每次25bp或50bp）
传导机制：降准 → 银行可贷资金增加 → 信贷扩张 → M2增速上行
2024-2025年加权平均准备金率：约6.6%（需定期确认）
```

**降准对A股的五阶段传导**：
1. 降准消息公布（盘后/周末多见） → 次日开盘券商板块领涨（直接受益）
2. 银行间利率下行 → 债券收益率下行 → 股息率策略吸引力上升
3. 信贷投放加速 → 实体企业获得资金 → 盈利预期改善
4. 流动性外溢至股市 → 增量资金入场 → 成交额放大
5. 通胀预期抬头（如果连续大幅降准） → 警惕政策转向

**降准信号的分级判断**：

| 级别 | 特征 | 股市影响 |
|:----:|:-----|:---------|
| 定向降准 | 仅针对特定领域（小微/三农） | 结构利好，总体影响有限 |
| 全面降准25bp | 常规操作，市场通常已预期 | 温和利好（靴子落地） |
| 全面降准50bp | 超预期力度 | 重大利好，券商/银行/地产链强势 |
| 降准+降息同日 | "双降"，罕见的强宽松信号 | 极强的短期利好，但需警惕后续通胀 |

#### 逆回购（Reverse Repo）

```
期限：7天为主力品种，14天/28天为辅
操作频率：每个工作日（央行公开市场操作）
2025年最新7天逆回购利率：1.50%（需定期确认）
```

**每日逆回购数据解读**（盘前必读项）：
- 当日操作量 vs 当日到期量 → 净投放/净回笼
- 连续净投放天数 → 连续>5天=呵护流动性
- 跨月/跨季/春节前 → 通常加大投放（季节性，勿过度解读）

#### PSL（抵押补充贷款，Pledged Supplementary Lending）

```
主要投向：棚改（历史）、保障性住房、城中村改造、"平急两用"基础设施
信号含义：PSL投放=财政+货币协同发力，对基建/地产链有利
关注频率：每月月初央行公布上月PSL数据
```

### 1.3 结构型工具

| 工具 | 用途 | 信号含义 |
|:-----|:-----|:---------|
| 再贷款再贴现 | 支持小微/三农/科技/绿色 | 结构宽松，总量影响有限 |
| 碳减排支持工具 | 清洁能源/节能环保/碳减排 | 利好新能源产业链 |
| 科技创新再贷款 | 科技企业贷款支持 | 利好科技成长板块 |
| 设备更新再贷款 | 推动大规模设备更新 | 利好高端制造/工业母机 |

## 二、银行间流动性指标体系

### 2.1 核心利率指标

#### DR007（存款类机构7天质押式回购利率）

```
定义：存款类机构（银行）之间以利率债为质押的7天期回购加权平均利率
地位：央行认定的"市场基准利率"
正常区间：围绕7天逆回购利率（1.50%）上下波动，一般+/-30bp内
紧张信号：DR007持续高于1.90%（即偏离政策利率40bp以上）
宽松信号：DR007持续低于1.30%（即偏离政策利率20bp以上）
```

**DR007日内监控要点**：
- 早盘9:00-9:30：开盘利率，判断当日资金面松紧的第一信号
- 午盘：若午盘利率未回落，全天资金面偏紧概率大
- 尾盘14:30后：若尾盘飙升，机构紧急融资，可能是超预期紧张

**DR007周度/月度趋势判断矩阵**：

| DR007位置 | 持续时间 | 流动性判断 | 股市信号 |
|:----------|:--------|:----------|:---------|
| <1.30% (低于逆回购利率20bp+) | >3个交易日 | 极度宽松 | 利好成长/科技/券商 |
| 1.30%-1.70% (贴近逆回购利率) | 正常 | 合理充裕 | 中性，结构行情为主 |
| 1.70%-1.90% (略偏紧) | >3个交易日 | 边际收敛 | 注意小票流动性压力 |
| 1.90%-2.20% (明显紧张) | >2个交易日 | 紧张 | 全面承压，防御仓位 |
| >2.20% (极度紧张) | 任意 | 危机模式 | 系统性风险，现金为王 |

#### Shibor（上海银行间同业拆放利率）

```
关键期限：隔夜、1周、2周、1个月、3个月、6个月、9个月、1年
重点关注：Shibor隔夜（ON）、Shibor 1周（1W）、Shibor 3个月（3M）
Shibor vs DR007：Shibor包含信用风险溢价（因参与机构含非存款类），通常略高于DR007
```

#### 同业存单利率（NCD Rate）

```
关注品种：1年期AAA级同业存单利率
正常区间：低于1年期MLF利率（2.00%）约10-20bp
紧张信号：1年期NCD利率 > MLF利率 → 银行中长期负债压力大 → 不利于信贷扩张
趋势含义：NCD利率持续上行 → 银行"缺长钱" → 降准预期升温
```

### 2.2 流动性分层分析

A股不同市值板块对流动性的敏感度差异显著：

```
大盘蓝筹（沪深300）：对宏观流动性敏感度中等，受益于外资流入
中盘成长（中证500）：对流动性敏感度较高，DR007低位时表现更好
小盘微盘（中证1000/国证2000）：对流动性高度敏感，DR007上升时最先承压
```

**流动性分层预警规则**：
- DR007 < 1.50% 且持续 → 小盘成长优于大盘价值
- DR007 1.50-1.80% → 无明显分层，按基本面选股
- DR007 > 1.80% 且持续 → 大盘价值优于小盘成长
- DR007 > 2.00% → 小盘微盘承压，防御为主

## 三、社融数据解读

社融（社会融资规模）是一个流量概念，反映一定时期内实体经济从金融体系获得的资金总额。

### 3.1 数据发布与口径

```
发布时间：每月10-15日（央行官网）
数据形式：当月新增 + 存量同比增速
结构分项：人民币贷款、政府债券、企业债券、非标（信托+委托+未贴现承兑）、股票融资
```

### 3.2 社融总量解读框架

**总量判断三步法**：

```
步骤1：当月新增 vs 市场预期（Wind/彭博一致预期）
  - 超预期 >10% → 经济动能强于预期 → 利好顺周期
  - 符合预期 → 中性
  - 低于预期 >10% → 信用扩张不及预期 → 防御信号

步骤2：存量同比增速 vs 名义GDP增速
  - 社融增速 > 名义GDP增速+2% → 信用扩张偏快 → 警惕资产泡沫
  - 社融增速 ≈ 名义GDP增速 → 信用与经济增长匹配 → 健康状态
  - 社融增速 < 名义GDP增速-1% → 信用收缩 → 经济下行压力 → 不利股市

步骤3：连续3个月趋势
  - 连续上升 → 信用扩张周期 → 利好股市（估值扩张+盈利改善预期）
  - 连续下降 → 信用收缩周期 → 不利股市（估值收缩）
  - 震荡 → 结构性行情
```

### 3.3 社融结构解读框架

**分项健康度评估**（5分制）：

| 分项 | 健康信号 | 预警信号 | 理想占比 |
|:-----|:---------|:---------|:--------:|
| 人民币贷款（最重要） | 企业中长期贷款占比>40% | 票据冲量占比过高（>15%） | 55-65% |
| 政府债券 | 专项债发行前置（Q1-Q2占全年>60%） | 全年发行节奏严重后移 | 15-25% |
| 企业债券 | 产业债发行回暖 | 城投债比重过高 | 5-10% |
| 非标融资 | 信托贷款回暖（基建配套） | 非标大幅压降（监管收紧信号） | 0-5% |
| 股票融资 | IPO节奏稳定 | IPO突然暂停（救市信号/负面信号） | 1-3% |

**关键结构信号**：
- **票据冲量**：当银行的票据融资占新增贷款比重超过15% → 银行找不到好的实体贷款项目，只能用票据"凑数" → 实体融资需求弱 → 经济内生动能不足
- **企业中长贷高增**：企业中长期贷款增速>15% → 企业信心强、资本开支意愿强 → 利好制造业、设备制造
- **居民贷款萎缩**：居民中长期贷款（房贷为主）连续3个月负增长 → 房地产市场需求冰冻 → 利空地产链

### 3.4 M1-M2剪刀差

```
M0 = 流通中现金
M1 = M0 + 企业活期存款
M2 = M1 + 准货币（居民储蓄存款 + 企业定期存款 + 其他存款）

M1-M2剪刀差 = M1同比增速 - M2同比增速
```

**剪刀差的宏观含义**：

| 剪刀差状态 | 含义 | 股市含义 |
|:----------|:-----|:---------|
| M1 > M2（正剪刀差，扩大） | 存款活期化，企业投资意愿强，经济活跃 | 牛市信号——资金从定期转向活期，准备投资/消费 |
| M1 ≈ M2（剪刀差接近0） | 经济不温不火 | 震荡市，结构性行情 |
| M1 < M2（负剪刀差，扩大） | 存款定期化，企业居民投资意愿弱，经济低迷 | 熊市/防御信号——钱"躺"在定期里不动 |

**真实案例判断**：
- 2024年M1-M2负剪刀差曾达-8%以上（历史极端水平），反映了居民企业极度保守、资金沉淀在定期存款中，信用传导受阻
- 如果剪刀差从-8%收敛到-3% → 经济触底回暖信号 → 积极关注顺周期品种
- 如果剪刀差从+5%收窄到+1% → 经济动能减弱 → 适当降低风险暴露

### 3.5 信用脉冲

```
信用脉冲 = Δ(新增信贷) / GDP × 100%

简化计算：用"社融存量同比增速的变化"替代
```

**信用脉冲与股市的关系**：
- 信用脉冲由负转正 → 历史上A股出现阶段性反弹的概率较高（约70%+）
- 信用脉冲持续为正 > 6个月 → 有望出现趋势性行情
- 信用脉冲见顶回落 → 通常领先股市见顶约3-6个月（先行指标）
- 信用脉冲触底回升 → 通常领先股市见底约1-3个月

## 四、美联储政策传导

### 4.1 FOMC会议机制

```
FOMC（联邦公开市场委员会）：每年8次定期会议（约每6周一次），3/5/6/7/9/11/12月 + 1月
关注重点：利率决议 + 点阵图（3/6/9/12月会议）+ 经济预测摘要（SEP）+ Powell发布会
决议公布时间：北京时间周四凌晨2:00（夏令时）/ 3:00（冬令时）
```

**FOMC会议周的A股应对策略**：

| 阶段 | 时间窗口 | 操作建议 |
|:-----|:---------|:---------|
| 会前1周 | FOMC前5个交易日 | 降低仓位波动率，关注北向资金是否提前流出 |
| 决议当日 | 周三美盘=周四A股 | 上午多看少动，等北向资金方向明确再判断 |
| 会后1-3日 | FOMC后3个交易日 | 北向资金方向确认后跟随，警惕"利好出尽" |
| 会后1-2周 | 市场完全消化 | 回归基本面，关注中美利差变化 |

### 4.2 点阵图（Dot Plot）解读

```
发布时间：3/6/9/12月FOMC会议
内容：每位FOMC委员对未来利率的点估计
解读重点：中位数预测（Median dot）的变化方向
```

**点阵图变化对A股的影响**：
- 中位数显示"年内降息次数增多" vs 上次预期 → 美元↓美债收益率↓中美利差收窄 → 北向资金流入↑A股↑
- 中位数显示"年内降息次数减少" vs 上次预期 → 美元↑北向资金流出压力↑A股承压
- 点阵图离散度变大（委员分歧加大） → 不确定性上升 → 市场波动率上升

### 4.3 缩表（QT）与扩表（QE）

```
缩表（Quantitative Tightening）：美联储减少持有的国债/MBS，回收流动性
扩表（Quantitative Easing）：美联储购买国债/MBS，注入流动性

当前状态（2025年）：QT持续中但节奏已放缓（需定期确认）
关注指标：美联储资产负债表规模周度变化
```

**QT/QE对全球流动性的传导**：
- QT → 全球美元流动性收紧 → 新兴市场资金流出 → A股外资流出风险↑
- QT放缓/停止 → 流动性边际改善 → 新兴市场压力减轻
- QE（危机模式） → 全球流动性泛滥 → 新兴市场受益 → A股外资大幅流入

### 4.4 中美利差与汇率

```
中美利差 = 中国10年期国债收益率 - 美国10年期国债收益率
USDCNY（在岸人民币）/ USDCNH（离岸人民币）

传导链条：
中美利差收窄（中国利率降/美国利率升）
  → 人民币贬值压力↑
  → 北向资金流出（汇率贬值侵蚀外资收益）
  → A股承压（尤其外资重仓股：茅台/宁德/美的/恒瑞等）
```

**利差-汇率-资金流联动阈值**：

| 中美利差 | USDCNY | 北向资金 | A股影响 |
|:---------|:-------|:---------|:--------|
| >+100bp (中国利率高于美国) | <6.50 | 大幅流入 | 强势，外资重仓领涨 |
| 0~+100bp | 6.50-6.80 | 温和流入/平衡 | 中性 |
| -100bp~0 | 6.80-7.10 | 温和流出/平衡 | 防御板块相对抗跌 |
| -200bp~-100bp | 7.10-7.30 | 持续流出 | 全面承压，小盘更弱 |
| <-200bp | >7.30 | 大幅流出 | 系统性风险，现金为王 |

## 五、流动性四象限

这是判断宏观环境对A股影响的综合框架：

```
         宽货币（央行放水）
              |
    II 宽货币紧信用  |  I 宽货币宽信用
    (政策底已现，    |  (最佳配置窗口：
     等待信用扩张)   |   全面利好股市)
              |
   ——紧信用—————+——————宽信用——
              |
    III 紧货币紧信用 |  IV 紧货币宽信用
    (最差组合：     |  (企业盈利好但
     现金为王，      |   估值受压制，
     防御为主)      |   价值风格占优)
              |
         紧货币（央行收水）
```

**四象限的股市策略**：

| 象限 | 宏观特征 | 历史出现时期 | 股市风格偏好 | 仓位建议 |
|:----:|:---------|:-----------|:------------|:--------:|
| I 宽货币宽信用 | 央行放水+实体信贷扩张 | 2020Q2-Q3、2024Q4 | 成长+周期（全面牛） | 进攻（80%+） |
| II 宽货币紧信用 | 央行放水但实体不接 | 2023H2-2024H1 | 主题炒作（科技/题材） | 结构（50-70%） |
| III 紧货币紧信用 | 央行收水+实体冷 | 2018全年、2022Q1-Q2 | 高股息防御（红利） | 防御（30-50%） |
| IV 紧货币宽信用 | 实体强但央行收水 | 2017年、2021年 | 价值>成长（顺周期） | 中性（50-70%） |

**象限切换的先行指标**：
- 货币端：7天逆回购利率/DR007趋势 → 最早信号（领先1-2个月）
- 信用端：社融增速/M1-M2剪刀差 → 确认信号（同步或略滞后）
- 综合判断：当货币端先行转向+信用端滞后确认 = 象限切换窗口

**当前判断**（2025年5月）：
基于近期政策信号（需每次巡检时更新），当前可能处于 II→I 切换窗口或 I 象限确认期。判断核心是盯着社融增速是否持续回升和M1-M2剪刀差是否收敛。

## 六、每日流动性巡检清单

山猫每日盘前必须检查的5个流动性指标：

```
[ ] 1. DR007开盘利率（9:00公布） —— 判断当日资金面松紧
[ ] 2. 央行逆回购操作量 vs 到期量 —— 公开市场操作方向
[ ] 3. 昨日北向资金净流入/流出 —— 外资态度
[ ] 4. USDCNY中间价/离岸CNH —— 汇率压力
[ ] 5. 最近一次MLF/LPR变动及下次操作日 —— 政策利率预期
```

**快速判断口诀**：
- DR007低+逆回购净投放+北向流入+人民币稳 → 流动性环境友好，可积极
- DR007高+逆回购净回笼+北向流出+人民币贬 → 流动性收紧，防御为主
- 三正一负 → 审慎乐观，仓位不激进
- 三负一正 → 减低仓位，观望
