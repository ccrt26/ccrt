## 一、核心命题：任何因子都会衰减

### 1.1 这是一个确定性事件

因子衰减不是"可能发生"——它是"一定会发生"。就如同熵增定律，因子的超额收益（青山）会随着时间的推移被市场吸收、套利、稀释，最终回归到零甚至负值。

青山的角色不是阻止衰减，而是：
1. 尽早发现衰减的信号
2. 在衰减前最大化因子的贡献
3. 在衰减中最小化损失
4. 在衰减后及时替换

### 1.2 金融学根源

因子的超额收益来自"市场的定价错误"。当越来越多的投资者发现并利用同一个定价错误时，他们的交易行为本身会纠正这个错误——买入被低估的股票推高其价格、卖出被高估的股票压低其价格。这就是"套利消除定价错误"的机制。

**因子的超额收益 = 市场定价错误 × (1 - 已被套利的比例)**

当"已被套利的比例"接近100%时，因子失效。

## 二、衰减模式识别

### 2.1 四种衰减模式

```
模式A：线性衰减
  IC: 0.06 → 0.05 → 0.04 → 0.03 → 0.02 → 0.01 → 0
  特征：可预测、有时间窗口做应对
  常见：基本面因子（信息扩散缓慢均速）
  
模式B：指数衰减
  IC: 0.08 → 0.04 → 0.02 → 0.01 → 0.005 → ...
  特征：前期衰减快、后期趋近于零但"死而不僵"
  常见：套利者涌入后的量价因子

模式C：断崖式衰减
  IC: 0.06 → 0.06 → 0.06 → -0.03（崩！）
  特征：前期无征兆，突发失效
  常见：制度变革（如T+1→T+0）、政策冲击、踩踏式资金撤离

模式D：周期波动
  IC: 0.06 → 0.01 → 0.07 → -0.02 → 0.05 → ...
  特征：上下周期波动，均值在下降
  常见：市场风格依赖型因子（成长因子、小市值因子）
```

### 2.2 如何区分"周期波动"和"永久衰减"

这是青山面临的最困难判断——因子IC下降到0.02，是因为因子永久失效了，还是仅仅当前市场环境不适？

**四条诊断标准**：

| 诊断维度 | 周期波动 | 永久衰减 |
|:---------|:---------|:---------|
| 历史是否有过类似幅度的下降并恢复？ | 有 | 无 |
| 同类因子（如其他动量因子）是否也衰退？ | 否（孤立衰退） | 是（系统性衰退） |
| 因子拥挤度是否处于历史高位？ | 否 | 是 |
| 因子背后的经济学逻辑是否已改变？ | 否 | 是 |
| 制度建设是否导致因子套利机制变化？ | 否 | 是 |

**判断流程**：

```
因子IC连续下降（降幅>50%）
  │
  ├── Step 1: 检查同类因子
  │   ├── 同类因子也在衰退 → 系统性问题，可能是市场风格切换（周期）
  │   └── 仅此因子衰退 → 进入Step 2
  │
  ├── Step 2: 检查因子拥挤度
  │   ├── 拥挤度>80分位 → 拥挤导致的衰减（可能永久）
  │   └── 拥挤度正常 → 进入Step 3
  │
  ├── Step 3: 检查经济学逻辑
  │   ├── 逻辑仍然成立（如"便宜的股票长期回报更高"） → 可能是周期波动
  │   └── 逻辑已被破坏（如制度变更） → 永久衰减
  │
  └── 处理：
      ├── 周期波动 → 等待恢复（设置恢复观察期）
      ├── 可能的永久衰减 → 降权40%+，设置3个月观察期
      └── 确认永久衰减 → 退役
```

## 三、IC衰退预警阈值体系

### 3.1 三级预警系统

```
🔴 红色预警（立即行动）：
  ├── ICIR（近30日滚动）< 0.1，且连续3个月
  ├── IC均值（近30日）< 0，且连续2个月
  ├── 多空收益（Q5-Q1）连续20个交易日为负
  └── 单日IC跌破历史3倍标准差（异常事件）

🟡 黄色预警（密切观察）：
  ├── ICIR（近30日）< 0.2，且连续2个月
  ├── IC均值（近30日）< 历史均值的50%
  ├── 分组单调性连续10日不通过
  └── 因子自相关从>0.6降至<0.4

🟢 绿色（正常）：
  └── 以上均不触发
```

### 3.2 预警触发后的标准操作

```
红色预警触发：
  ├── 立即：因子权重降至原权重的20%（保留微量暴露以持续观察）
  ├── 24小时内：青山出具因子异常诊断报告
  ├── 3个交易日内：流金评估风险敞口
  └── 5个交易日内：提出修复方案或退役建议

黄色预警触发：
  ├── 因子权重降至原权重的60%
  ├── 每个交易日记录预警指标变化
  ├── 积累10个交易日后：青山出具评估报告
  └── 如果恶化至红色：执行红色流程
  
绿色状态下：
  └── 常规月度评估
```

### 3.3 IC衰退与换手率的联合预警

IC下降的同时如果换手率上升——这是最危险的信号组合：

```
IC↓ + 换手率↑ ＝ "因子信号在变弱，但交易在变多"
  → 可能原因：资金在加速涌入，踩踏风险上升
  → 处理：立即降权至20%，冻结任何基于该因子的新增仓位
```

## 四、交易拥挤度量

### 4.1 拥挤度的五个维度

| 度量 | 计算方法 | 预警阈值 | 数据需求 |
|:-----|:---------|:--------|:--------|
| 持仓集中度 | 因子Top 20%股票中，机构持仓占比均值 | > 历史85分位 | 需要机构持仓数据 |
| 估值扩张 | 因子Top 20%股票的加权PE中位数 | > 历史90分位 | 行情+财报 |
| 换手率异常 | 因子Top 20%股票的日均换手率 | > 历史85分位 | 行情数据 |
| 内部相关性 | 因子Top 20%股票间收益率的平均相关性 | > 0.6 | 行情数据 |
| 资金流向 | 因子Top 20%股票的资金净流入集中度 | 前3只占>40% | 资金流数据 |

### 4.2 本项目的拥挤度实现

项目当前的拥挤度预警（后评估v1.5 §四(二)）覆盖的是**个股层面**：

```
个股拥挤预警：
  条件1：换手率 > 该股票自身20日分位的80%值 AND 量比 > 1.5
  条件2：换手率 > 推荐池80分位值 AND 量比 > 推荐池80分位值
```

但缺少**因子层面**的拥挤度检测——即所有高分股票作为一个整体的拥挤信号。这是青山需要补充的维度。

### 4.3 因子拥挤的A股真实案例

**案例1：小市值因子（2015-2017）**

```
时间线：
  2015年：小市值因子超额显著（借壳预期+壳价值）
  2016年：资金涌入小市值策略，拥挤度迅速上升
  2017年：监管收紧借壳+IPO加速，壳价值崩塌
  结果：小市值因子超额从年化+15%急转至-10%
```

**案例2：北向资金因子（2018-2022）**

```
时间线：
  2018-2020：北向资金持续流入，跟随策略超额+8-10%/年
  2021年：跟随策略被广泛传播，拥挤度上升
  2022年：北向资金因子超额降至+1-2%/年（接近失效）
  原因：信息从"独家"变为"公开"，领先优势消失
```

## 五、策略容量估算（Capacity）

### 5.1 容量上限公式

```
单票容量上限 = min(
    日均成交额 × 持仓占比上限 / 目标换手率,
    流通市值 × 持股上限比例
)

策略总容量 = Σ(所有候选股票的单票容量) × 分散度折扣

其中：
  持仓占比上限：单只股票占该股日均成交额的比例上限
    机构通常取5-10%，散户策略可适当放宽
  目标换手率：策略的预期日换手率
  分散度折扣：因为无法所有候选股票同时达到容量上限
    通常取60-80%
```

### 5.2 A股不同市值的容量参数

| 市值区间 | 日均成交额(万元) | 单票容量(万元) | 容量级别 |
|:--------|:-------------:|:------------:|:-------:|
| > 1000亿 | 50,000-200,000 | 5,000-20,000 | 大容量 |
| 300-1000亿 | 15,000-50,000 | 1,500-5,000 | 中等 |
| 100-300亿 | 5,000-15,000 | 500-1,500 | 中小容量 |
| 50-100亿 | 2,000-5,000 | 200-500 | 小容量 |
| < 50亿 | < 2,000 | < 200 | 极低容量 |

### 5.3 本项目容量评估

本项目为虚拟/模拟交易，暂无实际资金容量约束。但如果将来对接实盘，需要考虑：

- 当前股票池约80-120只（板块动量筛选后），中位数市值在100-500亿区间
- 假设策略总资金500万：远低于任何一只股票的容量上限，无需担心
- 假设策略总资金5000万：需要在部分小盘股上做持仓限制
- 假设策略总资金5亿：需要重新评估整体策略容量

**青山的建议**：即使当前没有容量约束，也应该在策略评估中记录"理论容量上限"，为将来规模扩大做准备。

## 六、因子生命周期五阶段

### 6.1 五阶段模型

```
阶段1：发现期（Discovery）
  ├── 特征：研究者发现因子在经济和统计上有意义
  ├── IC表现：初始IC较高（可能存在数据挖掘偏差）
  ├── 资金规模：仅研究者自己或所在机构在使用
  └── 建议操作：积累样本外验证数据，不上实盘

阶段2：发表期（Publication）
  ├── 特征：因子通过学术论文或研报公开发表
  ├── IC表现：IC仍高，但开始被套利
  ├── 资金规模：学术圈和量化机构开始关注
  └── 建议操作：在他人涌入前尽快部署，设定退出时间表

阶段3：拥挤期（Crowding）
  ├── 特征：大量资金基于同一因子交易
  ├── IC表现：IC开始下降，波动增大
  ├── 关键信号：持仓集中度↑、估值扩张↑、内部相关性↑
  └── 建议操作：降权、加拥挤度监控、准备替代方案

阶段4：衰减期（Decay）
  ├── 特征：因子超额收益持续下降
  ├── IC表现：IC跌至原来的30-50%，ICIR恶化
  ├── 关键信号：多空收益大幅缩水、单调性消失
  └── 建议操作：大幅降权（至20%）、加速寻找替代

阶段5：失效期（Obsolescence）
  ├── 特征：因子完全失去预测力
  ├── IC表现：IC≈0或为负且不显著
  ├── 关键信号：IC在统计上不显著（|t|<1）
  └── 建议操作：退役、从评分引擎中移除、归档评估报告
```

### 6.2 A股因子的阶段时长参考

| 因子类型 | 发现→发表 | 发表→拥挤 | 拥挤→衰减 | 衰减→失效 | 总生命周期 |
|:---------|:--------:|:--------:|:--------:|:--------:|:--------:|
| 基本面价值因子 | 2-3年 | 3-5年 | 1-2年 | 1-2年 | 7-12年 |
| 量价动量/反转 | 0.5-1年 | 1-2年 | 0.5-1年 | 0.5-1年 | 2.5-5年 |
| 另类数据因子 | 1-2年(数据独占) | 0.5-1年(数据公开后) | 0.5-1年 | 0.5年 | 2.5-4.5年 |
| A股政策红利因子 | 0.5-1年 | 0.5-1年 | 0.5年 | — | 1.5-2.5年(政策终止即失效) |

## 七、策略退化的6个前兆信号

### 7.1 六信号体系

当以下信号中出现2个以上时，青山应触发策略退化诊断：

```
信号1：超额收益连续N月为负
  阈值：滚动60日超额收益 < 0，连续2个月
  检测方法：策略收益 - 沪深300收益（或等权全市场收益）

信号2：胜率持续下降
  阈值：日胜率（当日选股中有正收益的比例）从>55%降至<45%
  检测方法：逐日统计选股中涨幅>0的比例

信号3：最大回撤创新模式
  阈值：最近一次回撤 > 历史最大回撤的1.5倍
  或：回撤的"形状"从缓慢累积变为单日暴跌（拥挤踩踏特征）

信号4：因子间相关性异常升高
  阈值：原本相关性<0.3的因子，相关性升至>0.5
  含义：多样化假象——看似多因子其实同质化

信号5：持仓集中度不自然上升
  阈值：Top 5持仓占比从<30%升至>50%
  含义：模型过度自信于少数股票

信号6：与基准的相关性升至极高水平
  阈值：策略收益与沪深300的Beta从设计的0.8升至>1.2
  含义：策略失去了独立于市场的青山选择能力
```

### 7.2 退化诊断流程

```
触发退化诊断
  │
  ├── Q1: 是单一维度退化还是多维度同时退化？
  │   ├── 单一维度 → 该维度因子问题（可以针对性修复）
  │   └── 多维度同时 → 系统性问题（可能是市场环境根本变化）
  │
  ├── Q2: 同类因子或同类策略（如公开指数量化基金）是否也在衰退？
  │   ├── 同行业都在衰退 → 市场风格/宏观原因（非本项目特有问题）
  │   └── 仅本项目衰退 → 自身策略问题
  │
  ├── Q3: 因子IC是否下降的同时换手率上升？
  │   ├── 是 → 拥挤踩踏信号（紧急）
  │   └── 否 → 可能是正常的市场风格切换
  │
  ├── Q4: 否决规则是否在"过度否决"？
  │   ├── 否决率从设计的20-30%升至50%+ → 否决过度收紧
  │   ├── 否决率降至<5% → 否决可能过于宽松
  │   └── 否决率正常但策略仍退化 → 否决以外的问题
  │
  └── 诊断结论示例：
      "策略退化的主要原因：[X]，次要原因：[Y]
       建议：[具体行动]"
```

## 八、应对措施层级

### 8.1 四层应对体系

```
Layer 1: 降权（Mild）
  ├── 适用：ICIR从0.4降至0.25, 但IC仍为正
  ├── 操作：因子权重降至原来的60-80%
  └── 监控：接下来10个交易日IC是否稳定在降权后的水平

Layer 2: 暂停（Moderate）
  ├── 适用：ICIR < 0.15连续1月, 或IC < 0连续2周
  ├── 操作：因子权重降至原来的20%（保留微量观察）
  ├── 监控：每日IC, 设置"恢复条件"（如ICIR恢复至>0.25）
  └── 恢复：满足恢复条件+连续5个交易日确认

Layer 3: 替换（Severe）
  ├── 适用：因子已被判定为永久衰减或失效
  ├── 操作：退役旧因子, 上线候选因子（必须经过灰度测试）
  └── 灰度：新旧并行5个交易日，新胜率>=旧+5%→切换

Layer 4: 复合因子重构（Systemic）
  ├── 适用：多个因子同时退化（系统性问题）
  ├── 操作：重新设计因子组合逻辑（如从线性打分→非线性）
  ├── 或：引入新的因子族（如从纯量价因子扩展至基本面因子）
  └── 时间：至少20个交易日的设计与回测
```

### 8.2 降权幅度计算公式

```
新权重 = 原权重 × min(1, ICIR_current/ICIR_target)

其中 ICIR_target = 0.3（合格线）

例如：因子原权重=25%, ICIR从0.4降至0.2
  新权重 = 25% × (0.2/0.3) = 25% × 0.667 = 16.7%
```

但设置上下限：
- 新权重不低于原权重的20%（保留最低暴露以持续观察）
- 新权重不高于原权重的100%（不因一次ICIR提升就大幅升权）

## 九、策略版本管理与AB对照

### 9.1 版本管理原则

每个策略版本变更必须满足：

```
1. 变更前：有基准版本的完整评估数据（至少20个交易日）
2. 变更中：有灰度期（新旧并行，至少5个交易日）
3. 变更后：有变更后vs基准的对比数据
4. 任何时间：可以回溯任意历史版本的策略表现
```

### 9.2 AB对照设计

```
AB测试标准设计：

A组（旧版本/基准）：
  ├── 权重方案：[w1, w2, w3, ..., wn]_old
  ├── 阈值方案：[t1, t2, ..., tm]_old
  └── 交易规则：[r1, r2, ..., rk]_old

B组（新版本/实验）：
  ├── 权重方案：[w1, w2, w3, ..., wn]_new（与A的不同点）
  ├── 阈值方案：同A（控制变量）
  └── 交易规则：同A（控制变量）

比较指标（至少5个交易日）：
  ├── 日胜率：B胜率 vs A胜率（B >= A + 5%）
  ├── 平均收益：B选股平均收益 vs A选股平均收益
  ├── 最大回撤：B选股最大回撤 <= A选股最大回撤
  ├── 换手率：B换手率 <= A换手率 × 1.2（不显著增加交易成本）
  └── 信息比率：B的日收益/日收益标准差 >= A的同样指标
```

### 9.3 切换决策矩阵

| 条件 | 决策 |
|:-----|:-----|
| B在所有5项指标上 >= A | 立即切换 |
| B在4/5项上 >= A, 且未达标的差距<10% | 切换，但标记需观察的指标 |
| B在3/5项上 >= A | 延长灰度期至10个交易日 |
| B在<3项上 >= A | 不切换，分析原因，修改方案 |

### 9.4 回滚机制

如果切换后新版本表现显著不如灰度期表现：

```
回滚触发条件（满足任一）：
  ├── 切换后连续3个交易日，B胜率 < A同期胜率 - 5%
  ├── 切换后单日最大回撤 > A历史最大回撤 × 1.5
  └── 切换后连续5个交易日，B平均收益 < A同期平均收益

回滚操作：
  1. 立即恢复至A版本（上一个稳定版本）
  2. 青山 24小时内出具B版本失败分析报告
  3. B版本标记为"已否决"并归档
  4. 不影响其他因子的正常运作
```

## 十、自测题

**题1**：因子的IC从0.06降到0.03, 但同期市场环境发生了明显变化（从震荡市变为牛市）。这是永久衰减还是周期波动？

**答案**：更可能是周期波动。震荡市中因子的IC通常较高（市场分化提供选股空间），牛市中因子的选股超额会收窄（普涨环境下个股差异缩小）。关键验证：等待市场回到震荡状态后，因子的IC是否回到约0.06的水平。如果回到，确认为周期波动。如果不回到，可能是在牛市期间因子被套利者加速套利，变为了永久衰减。在等待验证期间，因子维持当前权重但不升权。

**题2**：为什么"IC下降+换手率上升"是最危险的信号组合？给出具体的实盘情景。

**答案**：这个组合意味着：虽然因子的预测力在下降（信号变弱），但市场上的资金仍在加速基于这个弱信号交易（换手在上升）。实盘情景：一个动量因子IC从0.06降至0.02，但由于此因子的策略最近被量化圈热议，新资金涌入→买入动量信号最高的股票→推高这些股票的价格→动量信号看起来"还在赚钱"→吸引更多资金→形成正反馈循环。但这个循环是不可持续的——因为因子本身已经没有真实预测力，价格推高是资金流入的人为结果。一旦资金流入停止或逆转，踩踏式下跌就会发生，而且跌幅远超因子历史任何回撤。处理：应立即降权至20%并冻结该因子相关的新增仓位，等待拥挤信号消退。

**题3**：项目当前只有约20个交易日的数据，如何判断因子是否在衰减？

**答案**：目前无法做出可靠的衰减判断——20个交易日的数据既不足以建立IC的统计基线，也无法区分周期波动和永久衰减。现阶段能做的是：（1）记录每个交易日的IC值，建立基线数据；（2）关注是否有极端异常（如单日IC从+0.1突降至-0.3）；（3）开始计算滚动ICIR（需要至少再积累10个交易日才能有30日滚动）；（4）在所有因子评估中明确标注"数据不足（N<60），结论具有高不确定性"。在数据积累到60个交易日前，避免做出"因子已失效"或"因子应该退役"的确定性判断——过早退役一个有效的因子和过晚退役一个失效的因子，两种错误的代价是不对称的（前者更糟，因为你永久丢失了一个可能有效的青山来源）。
