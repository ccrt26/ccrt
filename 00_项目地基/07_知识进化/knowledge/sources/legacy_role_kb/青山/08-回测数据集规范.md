## 三、样本量判断标准

| 判断 | 标准 | 适用场景 |
|:-----|:-----|:--------|
| ❌ 小样本(不下确定性结论) | <20个交易日 | 青山铁律#4 |
| ⚠ 初步结论(标注置信度) | 20-60个交易日 | 新因子观察期 |
| ✅ 中等样本(可出结论) | 60-250个交易日(约1年) | 因子评估 |
| ✅ 大样本(较高置信度) | 250-750个交易日(1-3年) | 策略定型 |
| ✅ 长期验证 | >750个交易日(>3年) | 策略稳定性的最可靠证据 |

## 四、回测窗口规范

### 因子评估回测窗口
```
最短窗口：3年(约750个交易日)
推荐窗口：5年(覆盖至少一个牛熊周期)
必需包含：至少1个上升期+1个下降期+1个震荡期
```

### 市场状态划分(用于分层回测)

| 状态 | 定义 | 代表性时段 |
|:-----|:-----|:---------|
| 牛市 | 指数>MA60且MA60斜率>0 | 2014.07-2015.06, 2019.01-2019.04, 2020.03-2021.02 |
| 熊市 | 指数<MA60且MA60斜率<0 | 2015.06-2016.01, 2018.01-2019.01, 2021.02-2024.02 |
| 震荡市 | 指数围绕MA60波动 | 2016.02-2017.12, 2019.05-2019.12 |

### Purge+Embargo(防数据泄露)
```
Purge区间：持有的N天后，剔除N天数据
Embargo区间：训练集和测试集之间至少间隔M天
M ≥ 持有周期 × 2
例如：持仓5天，则Embargo ≥ 10天
```

---

## 五、回测前检查清单

- [ ] 数据时段：覆盖至少3年，含至少1个牛市+1个熊市
- [ ] 样本量：≥250个交易日
- [ ] 停牌处理：停牌日不填充虚假数据
- [ ] 复权方式：使用前复权数据
- [ ] 幸存者偏差：包含了已退市/ST股票的历史数据
- [ ] 数据时点：财务数据使用实际可得时间(非报告期时间)
- [ ] Purge+Embargo：已设置合理间隔
- [ ] 多源验证：关键数据点交叉验证[1]+[2]

---

## 六、维护规则

- 新增数据问题时即时登记
- 每季度检查数据时段是否需要更新
- 市场状态划分每年重新审视(新增代表性时段)
- 青山做因子评估时，必须引用本规范说明回测窗口
