## 一、评估体系总览

### 1.1 六维度评估框架

青山的因子评估不是"看一个IC就算完"——一个因子能否上实盘，需要从六个维度交叉验证：

```
                    ┌─────────────────────────┐
                    │    因子评估 六维框架     │
                    └─────────────────────────┘
                                    │
        ┌───────┬───────┬───────┬───┴───┬───────┬───────┐
        │       │       │       │       │       │       │
    预测力   稳定性   区分度   持续性   可交易性   独立性
    (IC)    (ICIR)   (分层)  (自相关)  (换手率) (相关性)
```

| 维度 | 核心指标 | 阈值（合格线） | 本文件章节 |
|:-----|:---------|:------------:|:--------:|
| 预测力 | Rank IC均值 | >0.03 | 二 |
| 稳定性 | ICIR | >0.3 | 三 |
| 区分度 | 分组单调性 + 多空收益 | 单调性通过 + 多空>0 | 四 |
| 持续性 | 因子一阶自相关 | >0.6 | 六 |
| 可交易性 | 月换手率 | <50%（单边） | 七 |
| 独立性 | 与现有因子相关性 | <0.5 | 九 |

一个因子在这六个维度全部达标，才能建议上线。任一维度不达标，必须分析原因并提出针对性改进方案。

### 1.2 评估等级体系

```
S级（优秀）：6/6达标 + ICIR>0.5 + 分层单调性完美
A级（可上线）：6/6达标
B级（可观察）：5/6达标，未达标项有明确改进路径
C级（需改进）：4/6达标
D级（不可用）：<=3/6达标
```

## 二、Information Coefficient (IC)

### 2.1 定义与公式

```
IC_t = corr(FactorValue_t, ForwardReturn_t+1)

其中：
  FactorValue_t：在t日截面上所有股票的因子值
  ForwardReturn_t+1：这些股票在t+1日的收益率
  corr：相关系数函数
```

本质上，IC回答一个问题："今天的因子值能在多大程度上解释明天的收益？"

### 2.2 Pearson IC vs Rank IC

| 维度 | Pearson IC | Rank IC (Spearman) |
|:-----|:----------|:-------------------|
| 计算 | corr(因子值, 收益值) | corr(因子排名, 收益排名) |
| 对极端值的敏感性 | 高（一个极端值可大幅扭曲IC） | 低（只看排序，不论绝对大小） |
| 对分布假设 | 需要近似正态分布 | 无分布假设 |
| 统计检验力 | 较高（满足假设时） | 略低但更稳健 |
| 本项目推荐 | — | **使用Rank IC** |

### 2.3 Rank IC的计算步骤

```
Step 1: 获取T日所有N只股票的因子值 → [F_1, F_2, ..., F_N]
Step 2: 获取T+1日所有N只股票的收益率 → [R_1, R_2, ..., R_N]
Step 3: 对因子值做排名（最大=1，最小=N）
Step 4: 对收益率做排名（最大=1，最小=N）
Step 5: 计算两组排名的Spearman相关系数
  ρ = 1 - (6 × Σd_i²) / (N × (N² - 1))
  其中 d_i = rank(F_i) - rank(R_i)
```

### 2.4 IC的判定标准（A股适用）

| |IC| | 判定 | 操作建议 |
|:-------:|:-----|:---------|
| > 0.10 | 强预测力 | 可独立使用（且换手率可接受时） |
| 0.05 ~ 0.10 | 良好 | 适合多因子模型核心成分 |
| 0.03 ~ 0.05 | 有效 | 可加入多因子模型 |
| 0.01 ~ 0.03 | 弱但存在 | 仅作辅助，权重不超过10% |
| < 0.01 | 无预测力 | 不能用（或仅作负面剔除信号） |

**IC为负值的处理**：

```
IC = -0.05（显著为负）≠ 废物

负IC意味着：因子值越高 → 未来收益越低
这是一个"反向预测"因子，可以使用，但方向要反转。

处理方式：
  ├── 方案A：因子方向反转（将-"因子值"作为新因子）
  ├── 方案B：作为负面剔除信号（因子值最高的股票剔除不出手）
  └── 方案C：不直接使用，但在多因子模型中做负加权

项目的选择（针对Spearman=-0.436的整体评分）：
  ├── 基本面Spearman=-0.182 → 降权（20→15）
  └── 消息面Spearman=-0.124 → 降权（20→15）
```

### 2.5 IC衰减曲线

IC的另一个重要维度是其在时间上的衰减模式：

```
IC Decay Curve（IC衰减曲线）：

回看期:    1天    3天    5天    10天   20天
IC:      0.045  0.038  0.031  0.023  0.015

→ 该因子最适合1-5天的短期预测，10天后几乎无预测力
```

**衰减曲线的意义**：确定策略的"最佳调仓频率"——IC衰减到一半的时间点，就是策略应调仓的周期。

## 三、ICIR（信息系数信息比率）

### 3.1 定义与公式

```
ICIR = mean(IC序列) / std(IC序列)

其中：
  IC序列 = [IC_day1, IC_day2, IC_day3, ..., IC_dayN]
  通常使用滚动窗口（如近60个交易日）
```

ICIR衡量的是"预测力的稳定性"——因子是每天稳定地准一点点，还是今天准明天不准？

### 3.2 判定标准

| ICIR | 判定 | 说明 |
|:----:|:-----|:-----|
| > 0.5 | 优秀 | 预测力极其稳定，适合作为策略核心因子 |
| 0.3 ~ 0.5 | 良好 | 足够稳定，可以信赖 |
| 0.15 ~ 0.3 | 可接受 | 有一定稳定性，需辅以其他因子 |
| < 0.15 | 不足 | 预测力波动过大，单独使用风险高 |
| < 0 | 灾难 | IC方向时正时负，完全不可靠 |

### 3.3 IC、ICIR与样本量的关系

ICIR的统计显著性依赖于样本量（观测天数N）：

```
t_statistic = ICIR × √N

例如：ICIR=0.3, N=60 → t = 0.3 × √60 ≈ 2.32（显著，|t|>2）
      ICIR=0.3, N=20 → t = 0.3 × √20 ≈ 1.34（不显著）
```

**这意味着**：在项目运行的早期（<20个交易日），即使观察到的ICIR不错，也缺乏统计显著性。样本量不足时，不要过早下结论"因子有效"或"因子无效"。

### 3.4 ICIR滚动监控

```
ICIR应使用滚动窗口（至少30日，推荐60日）：

日期        IC(近5日均值)   ICIR(近30日滚动)   趋势
2026-03-15    0.052            0.37            ↑
2026-03-16    0.049            0.36            →
2026-03-17    0.038            0.32            ↓（关注）
2026-03-18    0.025            0.28            ↓（预警）
2026-03-19    0.018            0.24            ↓↓（需排查）
```

## 四、分层回测（Quantile Backtest）

### 4.1 方法概述

按因子值将股票池分成N组（通常5组=五分位，或10组=十分位），计算每组在下一期的平均收益。

```
五分位分组（T日截面）：

Q1（低因子组）：因子值最低的20%股票 → 平均收益 R_Q1
Q2           ：因子值次低的20%股票 → 平均收益 R_Q2
Q3           ：因子值中间的20%股票 → 平均收益 R_Q3
Q4           ：因子值次高的20%股票 → 平均收益 R_Q4
Q5（高因子组）：因子值最高的20%股票 → 平均收益 R_Q5

多空收益（Long-Short Spread）= R_Q5 - R_Q1（假设正向因子）
```

### 4.2 十分位 vs 五分位的选择

| 维度 | 五分位 | 十分位 |
|:-----|:------|:------|
| 每组样本量（全市场~5000只） | ~1000只 | ~500只 |
| 组间差异的统计显著性 | 较高 | 较低（样本量更小） |
| 对极端因子的敏感度 | 中等 | 高（能看见头部10%的极端表现） |
| 本项目推荐 | 日常评估 | 深度分析 |

**项目适用**：由于本项目的股票池通常为80-120只（板块动量筛选后），五分位每组仅约16-24只股票，样本量偏小。建议使用三分位（Q1低/Q2中/Q3高）作为日常评估，五分位仅在深度分析时使用。

### 4.3 单调性检验

**单调性条件**（针对正向因子，预期Q5收益>Q1收益）：

```
R_Q1 < R_Q2 < R_Q3 < R_Q4 < R_Q5  （严格单调）
```

或更宽松的：

```
(R_Q5 + R_Q4) > (R_Q2 + R_Q1)      （头部>底部）
```

**单调性不满足时怎么办**：

| 不单调的模式 | 可能的含义 | 处理方式 |
|:------------|:----------|:---------|
| Q1最低, Q5最高, 中间乱序 | 因子在中间区间无区分力 | 提高因子使用阈值（只用Q1/Q5信号） |
| Q1>Q5但中间单调 | 因子方向搞反了 | 反转因子符号后重新评估 |
| 所有组收益相近 | 因子完全无区分力 | 弃用 |
| Q5极高, Q1-Q4相近 | 因子只在顶部有效 | 用因子上分位做正向选股 |

### 4.4 多空收益的归因分析

多空收益（Q5-Q1）可以进一步分解：

```
多空收益 = 青山部分 + Beta部分 + 行业部分

青山部分：因子本身的选股能力（我们要的）
Beta部分  ：市场暴露差异（Q5和Q1对市场的Beta不同）
行业部分  ：行业分布差异（Q5和Q1的行业构成不同）
```

**建议回测时同时计算**：
1. 原始多空收益
2. Beta中性化后的多空收益（对冲市场暴露）
3. 行业中性化后的多空收益（对冲行业暴露）
4. 双中性化后的多空收益（纯青山）

## 五、t检验

### 5.1 单日IC的t检验

```
H0: IC均值 = 0（因子无预测力）
H1: IC均值 ≠ 0（因子有预测力）

t = mean(IC) / (std(IC) / √N)

其中 N = 观测天数

|t| > 2 → 在95%置信水平下拒绝H0，因子有显著预测力
|t| > 2.58 → 在99%置信水平下显著
```

### 5.2 多空收益的t检验

```
H0: 多空收益均值 = 0
H1: 多空收益均值 ≠ 0

t = mean(Q5收益 - Q1收益) / (std(Q5收益 - Q1收益) / √N)

|t| > 2 → 多空收益显著不为零
```

### 5.3 小样本下的注意事项

项目数据积累初期（<30个交易日），t检验的统计功效不足：
- 即使真正的IC=0.05、ICIR=0.3，在小样本中也可能"不显著"
- 这不等同于"因子无效"——只是"还没有足够数据证明它有效"
- 建议在小样本阶段：更关注IC均值和ICIR的方向，而非显著性

## 六、因子自相关（Factor Autocorrelation）

### 6.1 定义

```
因子自相关（一阶）= corr(FactorValue_t, FactorValue_t+1)

即在T日的因子值排名与T+1日的因子值排名之间的相关性。
```

### 6.2 判定标准

| 一阶自相关 | 判定 | 含义 |
|:--------:|:-----|:-----|
| > 0.8 | 非常稳定 | 因子信号变化慢，适合低频调仓 |
| 0.6 ~ 0.8 | 稳定 | 因子信号有一定持续性，正常水平 |
| 0.4 ~ 0.6 | 中等 | 因子信号有一定变化，需要关注 |
| 0.2 ~ 0.4 | 不稳定 | 因子信号变化快，调仓频率可能过高 |
| < 0.2 | 极不稳定 | 因子信号几乎每天随机变化——可能本身是噪声 |

**高自相关的优势**：
- 调仓频率低 → 交易成本低
- 因子信号的"有效期"长，实盘中信号漂移小

**高自相关的风险**：
- 可能是一个"状态变量"（如行业归属、市值大小）而非"预测变量"
- 与市场Beta高度相关的因子自相关通常较高（因为Beta本身自相关高）

### 6.3 因子自相关与IC衰减的关系

```
因子自相关高 + IC衰减慢 → "慢牛"型因子：稳定、持久、低频
  （典型：ROE、市值等基本面/结构性因子）

因子自相关低 + IC衰减快 → "脉冲"型因子：强但短、需要快速反应
  （典型：短期反转、换手率变化等量价因子）

因子自相关高 + IC衰减快 → 可疑——可能因子变化慢但预测窗口短
  → 建议检查：是否因子在预测Beta而非青山？
```

## 七、换手率评估

### 7.1 定义

**单边换手率**：

```
单边日换手率 = Q5组合中与上一日Q5组合不同的股票数 / Q5组合总股票数
```

如果是做多策略（只买不卖空）：

```
策略换手率 = max(调入比例, 调出比例)
```

**双边换手率**（学术常用）：

```
双边换手率 = (买入金额 + 卖出金额) / (2 × 组合总市值)
 ≈ 2 × 单边换手率
```

### 7.2 A股成本约束下的换手率上限

```
假设：
  单次交易成本（佣金+印花税+滑点）= 0.15%
  年化超额收益目标 = 10%
  交易成本容忍度 = 超额收益的30% = 3%

年化最大双边换手率 = 3% / 0.15% = 2000%
年化最大单边换手率 = 1000%
月化最大单边换手率 ≈ 83%
```

但实际操作中，超过50%的月换手就需要警惕——因为滑点在换手率高时会非线性增长（冲击成本随交易量上升）。

### 7.3 换手率判定标准

| 月单边换手率 | 判定 | 适用场景 |
|:----------:|:-----|:---------|
| < 20% | 低换手 | 基本面因子、适合大资金 |
| 20% ~ 50% | 中等 | 大多数因子的正常范围 |
| 50% ~ 80% | 高换手 | 需扣除成本后评估净收益 |
| > 80% | 极高 | 只有高频策略或极小资金可行 |

**A股反转策略换手率警告**：反转策略月均换手65-80%，年化成本拖累3-4%/年。如果策略预期的年化超额（扣除成本前）不到8%，反转策略的净收益可能为负。

## 八、行业中性后的纯青山评估

### 8.1 为什么需要中性化后评估

一个因子的多空收益可能来自两部分：

```
总多空收益 = 青山（因子本身的选股能力）
           + Beta（行业暴露偏差）
```

例子：某因子恰好做多新能源行业、做空传统能源行业。在新能源牛市中，这个因子看起来很有效——但这不是因子能力强，而是行业Beta在撑腰。

### 8.2 中性化后评估的步骤

```
Step 1: 对因子值做行业中性化（对行业哑变量回归，取残差）
Step 2: 用中性化后的因子值重新分组（Q1-Q5）
Step 3: 计算中性化后的分组收益和多空收益
Step 4: 对比原始 vs 中性化后的ICs和多空收益

如果中性化后IC显著下降：
  → 原始因子的预测力主要来自行业暴露，非真青山

如果中性化后IC基本不变或略有下降：
  → 因子有独立的个股选择能力

A股实证案例（残差动量）：
  原始价格动量ICIR = -0.244
  行业+市值中性化后 = -0.215（改善0.03）
  残差动量（剥离行业Beta）= +0.151（方向转正！）
```

### 8.3 市值中性化同理

如果因子选出的高分组市值显著小于低分组（在A股常见），那么多空收益中包含了小市值效应（Size Premium），需要剥离。

## 九、因子相关性矩阵与独立性评估

### 9.1 相关性矩阵

在加入一个新因子前，必须计算其与所有现有因子的相关性：

```
           ROE    PE反转  残差动量  换手率  资金流
ROE       1.00    0.12     -0.05     0.08    0.03
PE反转    0.12    1.00     -0.35     0.25    0.18
残差动量   -0.05  -0.35     1.00     0.15   -0.10
换手率     0.08    0.25     0.15     1.00    0.55
资金流     0.03    0.18    -0.10     0.55    1.00
```

**解读**：
- ROE与PE反转相关性仅0.12 → 各自有独立信息
- 换手率与资金流相关性0.55 → 存在一定重叠，需关注
- 如果两个因子相关性>0.7 → 基本是同质因子，取一个即可

### 9.2 增量信息检验

新因子是否有增量信息的黄金标准：

```
回归：Return_t+1 = α + β1×Factor_existing_t + β2×Factor_new_t + ε

如果β2显著不为零 → 新因子有增量信息
如果β2不显著 → 新因子没有超越现有因子的增量预测力
```

### 9.3 独立性判定

| 新因子与现有因子的最大相关性 | 判定 | 操作 |
|:--------------------------:|:-----|:-----|
| < 0.3 | 高度独立 | 放心加入 |
| 0.3 ~ 0.5 | 中度相关 | 加入但降权，或用正交化残差 |
| 0.5 ~ 0.7 | 高度相关 | 必须正交化或择一保留 |
| > 0.7 | 基本同质 | 保留ICIR更高的那个 |

## 十、Fama-MacBeth横截面回归

### 10.1 方法概述

FM回归是因子评估的"金标准方法"——比简单的IC计算更严谨，因为它同时控制了多个因子的影响。

**FM两步法**：

```
Step 1（时间序列回归——估计Beta）：
  对每只股票，用前36-60个月数据：
  R_it - R_ft = α_i + β_i × (R_mt - R_ft) + ε_it
  
  得到每只股票的Beta估计值 β_i

Step 2（横截面回归——检验因子溢价）：
  对每个月t：
  R_it = γ_0t + γ_1t × β_i + γ_2t × Size_i + γ_3t × B/P_i + ... + ε_i
  
  得到每个因子在该月的风险溢价 γ_kt
  
  最终因子溢价的显著性：
  t(γ_k) = mean(γ_k) / (std(γ_k) / √T)
```

### 10.2 FM回归在本项目中的简化应用

由于项目数据积累有限（<60个月），完整的FM回归暂时不可行。但简化的多因子IC评估可以部分实现：

```
简化方法：增量IC分析

Step 1: 计算单因子的Rank IC
Step 2: 用现有因子对收益做多元回归，取残差收益
Step 3: 计算新因子与残差收益的Rank IC（即增量IC）

如果增量IC仍然显著 > 0.02 → 新因子有增量信息
```

### 10.3 FM回归与简单IC的对比

| 维度 | 简单IC | FM回归 |
|:-----|:------|:------|
| 所需数据量 | >=20个交易日 | >=36个月 |
| 控制变量 | 无 | 可同时控制多个因子 |
| 因子间相关性干扰 | 存在 | 已控制 |
| 本项目当前可行性 | 可执行 | 数据不足，暂不可行 |

## 十二、自测题

**题1**：一个因子IC=0.08, ICIR=0.2, 月换手率=15%——这个因子能直接上线吗？

**答案**：值得上线但有顾虑。IC=0.08表示预测力良好，月换手率15%表示交易成本可控。但ICIR=0.2偏低——意味着IC波动较大（std(IC)≈0.08/0.2=0.40），某些交易日IC可能为强负值。建议：先加入多因子模型但给予中等权重（15-20%），用ICIR加权（而非等权），并在接下来的20个交易日中密切监控ICIR是否改善到>0.3。如果ICIR持续<0.2，应降权并排查是否在某些市场状态下IC反转。

**题2**：为什么分层回测的单调性比多空收益（Q5-Q1）更重要？

**答案**：多空收益只看两端——Q5和Q1的差异。如果Q2-Q4的收益是随机的，这意味着因子在"中等区间"完全没有区分力。在实盘中，你不会只买Q5和卖Q1——你会根据因子值在整个区间上分配仓位。如果Q2-Q4的收益信号是噪声，那么在这些仓位上的配置就是随机下注。单调性保证因子在所有区间上都有区分力，让仓位分配在任何因子水平上都有意义。项目的五档仓位映射（评分≥80→25%, ≥65→20%...）就是基于单调性假设——如果单调性不成立，这个仓位映射就需要重新设计。

**题3**：在项目当前数据不足的情况下，如何在"不等数据积累完"和"不过早下结论"之间平衡？

**答案**：三个阶段策略：（1）前20个交易日——只做定性观察，不做任何因子评估结论。观察方向性：因子是否大致如预期方向（如预期负相关的因子确实显示负IC）、有无明显异常。（2）20-60个交易日——开始计算IC均值和ICIR，但必须标注"统计显著性不足（N<60）"。可以开始做因子间的横向对比（哪个因子更强），但不做"是否显著"的二元判断。（3）60+个交易日——进入正常评估周期，使用本文件全部方法论。这是避免"小样本过度自信"的最基本纪律。
