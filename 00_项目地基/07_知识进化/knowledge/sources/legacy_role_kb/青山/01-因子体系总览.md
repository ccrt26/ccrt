## 一、什么是因子——策略研究员的视角

### 1.1 核心定义

因子（Factor）是可用于预测股票横截面收益差异的量化特征变量。从策略研究员的角度，一个合格的因子必须满足三个条件：

1. **可量化**：能够用确切的数值表达式计算，不存在主观判断空间
2. **可回测**：存在足够长的历史数据可用于验证其预测能力
3. **有经济学逻辑**：因子为什么能预测收益，必须有合理的金融学解释（不能是纯数据挖掘）

在铁律量化项目中，每一个评分维度本质上都是一个复合因子信号的容器。技术面的8个子项（S1-S8）各是一个独立因子，加权组合后形成技术面复合因子。

### 1.2 青山的角色定位

青山不负责因子的日常计算和报告生成（那是Claude和评分引擎的工作）。青山的职责是：

- **评估**：当前在用的因子是否还在有效运作？
- **探索**：有没有新的、更好的因子可以加入？
- **优化**：现有因子的权重、参数、组合方式能否改进？
- **预警**：哪个因子正在衰减，需要降权或替换？
- **设计**：新因子从理论到回测方案的完整设计

青山设计、Claude执行回测——这是铁律量化的核心分工。

### 2.2 各因子族详解

#### 2.2.1 价值因子（Value）

**金融学逻辑**：买入价格低于内在价值的股票，等待市场修正定价错误。这是最古老的因子族，Graham和Dodd在1934年就提出了这一框架。

**经典指标**：

| 指标 | 公式 | A股适用性 | 本项目使用 |
|:-----|:-----|:--------:|:--------:|
| E/P (盈利收益率) | TTM_EPS / 当前价 | 高 | V2否决阈值 |
| B/P (账面市值比) | 每股净资产 / 股价 | 中（银行/周期股适用） | 未使用 |
| S/P (营收市值比) | 每股营收 / 股价 | 中（轻资产公司适用） | 未使用 |
| 股息率 | 每股分红 / 股价 | 中（仅分红稳定的蓝筹） | 未使用 |
| FCFE/P | 每股自由现金流 / 股价 | 中（数据覆盖有限） | 未使用 |
| PE(TTM)历史分位 | 当前PE在历史5年中的分位数 | 高（相对估值的重要参考） | 未使用 |

**关键公式——PE(TTM)**：

```
PE(TTM) = 当前股价 / TTM_EPS

其中：
  TTM_EPS = 最新年报EPS - 去年同季EPS + 最新季报EPS
```

注意：严禁直接使用腾讯/新浪等数据源提供的静态PE做否决判断（红线§1.2）。静态PE使用的是去年年报数据，在财报真空期可能严重滞后。

**A股特殊说明**：A股银行股PB长期低于1（约0.5-0.8），不要用国际标准（PB<1=低估）直接套用——这是市场对银行资产质量的折价，不是错误定价。同理，A股科技股PE可以长期>50，仅用PE否决会错失高成长标的。

#### 2.2.2 动量因子（Momentum）

**金融学逻辑**：过去表现好的股票在未来一段时间内继续表现好（动量效应），或过去表现好的股票在未来反转（反转效应）。A股与美股在此存在根本性差异（详见02-A股因子实证特征.md）。

**经典指标**：

| 指标 | 回看期 | A股特征 | 本项目使用 |
|:-----|:------|:--------|:--------:|
| 短期价格反转 | 1M | 显著反转效应（IC为负） | 未显式使用 |
| 中期价格动量 | 3M-6M | 弱反转到中性 | 未显式使用 |
| 长期价格动量 | 12M | 股：弱动量 / 行业：正向动量 | 未显式使用 |
| 残差动量 | 12M(skip=1) | ICIR=+0.151，方向转正 | 未使用（重要候选！） |
| 均线多头排列 | 5/10/20/60日 | 技术面有效因子 | S1均线系统 |
| 成交量动量 | 5日/20日均量对比 | 放量配合价格方向有效 | S8趋势动量 |

**残差动量的重要性**（来自A股实证研究）：

```
原始价格动量（12月回看）：
  ICIR = -0.244（负向——A股整体呈反转）

行业+市值中性化后：
  ICIR = -0.215（改善0.03）

残差动量（剥离行业Beta后）：
  ICIR = +0.151（方向转正！）
```

这意味着：A股的个股动量被行业均值回归效应所掩盖。当剥离行业Beta后，个股层面的特质动量（残差动量）是真实存在且正向的。这是青山应重点关注的候选因子之一。

#### 2.2.3 质量因子（Quality）

**金融学逻辑**：盈利能力强的公司、财务健康的公司、经营稳健的公司长期回报更高。这是唯一在所有市场（A股、美股、欧股、日股）中都具有稳健正向预测力的因子族。

**经典指标**：

| 指标 | 公式 | A股适用性 | 本项目使用 |
|:-----|:-----|:--------:|:--------:|
| ROE(TTM) | TTM净利润 / 平均净资产 | 高 | F1盈利能力 |
| ROA | 净利润 / 总资产 | 高（银行/保险用ROA更合适） | 未使用 |
| ROIC | NOPAT / 投入资本 | 中（计算复杂但有增量） | 未使用 |
| 毛利率稳定性 | std(近8季度毛利率) / mean(近8季度毛利率) | 中 | 未显式使用 |
| 经营现金流/净利润 | CFO / NI | 高（A股盈余管理识别关键指标） | V6否决 |
| 资产负债率 | 总负债 / 总资产 | 高 | V4否决 |
| 应计质量 | |Δ(流动资产-现金)-Δ(流动负债-短债)-折旧| / 平均总资产 | 中（需财报数据积累） | 未使用 |

**A股特殊关注——经营现金流/净利润比**：A股存在较强的盈余管理动机（保壳、再融资、股权激励达标），净利润可以被操控但现金流很难被操控。该比率持续<0.5是强烈预警信号。

#### 2.2.4 成长因子（Growth）

**金融学逻辑**：高增长公司的未来盈利能力将远超当前水平，当前价格低估了其未来价值。

**经典指标**：

| 指标 | 回看期 | 本项目使用 |
|:-----|:------|:--------:|
| 营收增速YoY | 最近季度 vs 去年同季 | F3成长性 |
| 净利润增速YoY | 最近季度 vs 去年同季 | F3成长性 |
| 总资产增速 | 最近季度 vs 去年同季 | 未使用 |
| ROE变化 | 当前ROE - 一年前ROE | 未显式使用 |
| 研发费用增速 | YoY（适用于科技/医药） | 未使用 |

**A股特殊说明**：A股成长因子在2019-2021年（核心资产牛市）表现极强，2022年后大幅衰减。成长因子与市场风格高度相关，不能单独使用——必须结合当前市场风格（价值/成长）做动态加权。

#### 2.2.5 波动率因子（Low Volatility）

**金融学逻辑**：低波动率股票的长期风险调整后收益高于高波动率股票——这是"低波动率异象"（Low Volatility Anomaly），与传统CAPM预测相反。

**经典指标**：

| 指标 | 公式 | 本项目使用 |
|:-----|:-----|:--------:|
| 历史波动率 | std(近20日收益率) × √252 | 隐性使用（风控维度） |
| Beta | cov(个股收益, 市场收益) / var(市场收益) | 未显式使用 |
| 下行波动率 | std(min(收益率, 0)) × √252 | 未使用 |
| 最大回撤 | max(历史高点 - 当前价格) / 历史高点 | 风控否决 |
| ATR | 近14日TR的EMA | P1-P5止损计算 |

#### 2.2.6 规模因子（Size）

**金融学逻辑**：Fama-French三因子模型中，小市值公司长期回报高于大市值公司（SMB因子）。

**经典指标**：

| 指标 | 本项目使用 |
|:-----|:--------:|
| 流通市值 | 否决层（S5弹性否决50亿以下） |
| 总市值 | 未显式使用 |
| log(市值) | 学术常用（正态化处理） |

**A股小市值效应**：
- 小市值因子在剩余流动性充裕期（如2021-2023年）显著占优
- 但2024年起因子切换加快，小市值不再持续有效
- 监管环境（注册制推进、退市常态化）抑制壳价值，削弱小市值效应

#### 2.2.7 情绪/资金面因子（Sentiment & Flow）

**金融学逻辑**：投资者情绪和资金流动包含短期定价信息，可预测未来1-3日的股价方向。

**经典指标**：

| 指标 | 本项目使用 |
|:-----|:--------:|
| 换手率 | 拥挤度预警（后评估§四(二)） |
| 主力资金净流入方向 | 资金面20分 |
| 北向资金持仓变化 | 资金面评分（部分股票） |
| 融资余额变化 | 未使用 |
| 大宗交易折溢价 | 未使用 |
| Amihud非流动性 | 学术常用候选因子 |
| 量比 | 拥挤度预警（与换手率联合判断） |

#### 2.2.8 事件驱动因子（Event）— 2026-05-26新增

**金融学逻辑**：并购、订单、政策、产品周期等离散事件会引起基本面突变和预期修正，其alpha无法被月度/季度频率的传统因子捕捉。

**经典指标**：

| 指标 | 本项目使用 |
|:-----|:--------:|
| 并购事件 | 定性评分(-2,+2)，情景调整项 |
| 重大订单/合同 | 定性评分(-2,+2)，情景调整项 |
| 产业政策 | 定性评分(-2,+2)，情景调整项 |
| 产品周期/新品 | 定性评分(-2,+2)，情景调整项 |

**核心约束**：
- ⛔ 不纳入量化评分模型（小样本+强异质性→严重过拟合风险）
- ✅ 作为情景调整项，定性评分叠加在综合判断之上
- 数据源：[人工]，无API覆盖
- 详见：青山-知识库/09-事件驱动因子体系.md

## 三、多因子模型演进——学术脉络

### 3.1 Fama-French三因子模型（1993）

```
E(R_i) - R_f = β_market × (E(R_m) - R_f) + β_size × SMB + β_value × HML

其中：
  SMB (Small Minus Big) = 小市值组合收益 - 大市值组合收益
  HML (High Minus Low)   = 高B/P组合收益 - 低B/P组合收益
```

三因子解释了约90%的股票收益横截面差异（R²≈0.90），是量化选股的理论基石。

### 3.2 Carhart四因子模型（1997）

在三因子上加入动量因子（MOM）：

```
+ β_momentum × WML (Winners Minus Losers)
```

WML = 过去12个月赢家组合收益 - 过去12个月输家组合收益

### 3.3 Fama-French五因子模型（2015）

在三因子上加入盈利因子（RMW）和投资因子（CMA）：

```
+ β_profitability × RMW (Robust Minus Weak)
+ β_investment × CMA (Conservative Minus Aggressive)

RMW = 高营业利润率组合 - 低营业利润率组合
CMA = 低总资产增速组合 - 高总资产增速组合
```

五因子加入后，HML（价值因子）变得冗余——盈利和投资因子吸收了价值的解释力。但这是基于美股数据——A股的价值因子仍有独立的增量信息。

### 3.4 Hou-Xue-Zhang q-factor模型（2015）

从投资经济学出发，替代了Fama-French框架：

```
E(R) = f(投资因子, ROE因子, 规模因子)
```

核心思想：折现率不变时，高ROE对应高估值（高PB），高投资对应低估值（低PB）。

### 3.5 A股因子研究的特殊性

A股不适合直接套用美股因子模型，原因包括：

| 差异维度 | 美股 | A股 |
|:---------|:-----|:-----|
| 动量效应 | 正向（12M动量显著） | 短期反转、残差动量（见02文件） |
| 小市值效应 | 稳健但近期减弱 | 受政策周期影响巨大 |
| 价值因子 | B/P稳健 | PE比PB有效（银行股PB扭曲） |
| 投资者结构 | 机构主导 | 散户主导（约60%交易量） |
| 政策影响 | 相对独立 | 产业政策可颠覆行业因子表现 |
| 交易制度 | T+0/Bid-Ask | T+1/涨跌停/融券限制 |

## 四、因子构建方法论

### 4.1 数据预处理标准流程

任何原始数据在转换为因子值之前，必须经过以下预处理：

```
原始数据
  │
  ├── Step 1: 缺失值处理
  │    ├── 财务数据：前值填充（最近一期有效值）
  │    ├── 行情数据：<=5%缺失→中位数填充；>5%→排除该日
  │    └── 标记：填充后的因子在报告中标注"含估算值"
  │
  ├── Step 2: 缩尾处理（Winsorize）
  │    ├── 方法：1%和99%分位截尾
  │    ├── 作用：消除极端值对IC/回归的干扰
  │    └── 替代方案：MAD法（中位数±3×1.4826×MAD）
  │
  ├── Step 3: 标准化（Z-score）
  │    ├── 公式：z_i = (x_i - μ) / σ
  │    ├── μ和σ来自截面的mean和std（同一日所有股票）
  │    └── 结果：均值=0，标准差=1
  │
  └── Step 4: 中性化（可选，按需）
       ├── 行业中性化：因子值对行业哑变量回归，取残差
       ├── 市值中性化：因子值对log(市值)回归，取残差
       └── 联合中性化：因子值对行业哑变量+log(市值)回归，取残差
```

### 4.2 行业中性化详解

行业中性化是A股因子处理中最重要的转换之一。A股行业轮动剧烈，如果不对因子做行业中性化，你选出的"好股票"可能只是恰好处于轮动中的行业。

**方法**：

```
设 F_i 为股票i的原始因子值
设 D_i 为股票i的行业哑变量矩阵（行业j取1，否则0）

回归：F_i = α + Σ(β_j × D_ij) + ε_i

中性化后的因子值：F'_i = ε_i（即回归残差）
```

**什么时候必须做行业中性化**：
- 财务因子（PE、PB、ROE）：不同行业天然差异大，必须中性化
- 动量和反转因子：行业轮动的Beta效应会掩盖个股特质动量

**什么时候不应做行业中性化**：
- 如果策略本身就包含行业选择逻辑（如本项目板块动量筛选）
- 如果行业信号本身就是青山来源的一部分

**关键实证数据（来自A股残差动量研究）**：

```
原始价格动量（12M，skip=1）：ICIR = -0.244
行业中性化后：              ICIR = -0.215（改善0.03）
行业+市值中性化后：         ICIR = -0.215
残差动量（剥离行业Beta后）：  ICIR = +0.151（方向转正！）
```

25个基点的ICIR改善幅度看似不大，但从负转正（残差动量）的质变是关键发现。

### 4.3 市值中性化

```
设 F_i 为原始因子值
设 S_i = log(股票i的流通市值)

回归：F_i = α + β × S_i + ε_i

中性化后的因子值：F'_i = ε_i
```

**为什么用log(市值)**：市值的横截面分布严重右偏（少数超级大盘 + 大量中小盘），取对数后近似正态，回归更稳健。

### 4.4 因子正交化

当多个因子之间存在高度相关性时，需要正交化以避免多重共线性。

#### 方法一：回归法（顺序正交）

```
for j in 2..n:
    F_j_orth = residual of regressing F_j on F_1, F_2, ..., F_(j-1)
```

**缺点**：正交化结果依赖于因子的排列顺序——先处理哪个因子会影响所有后续因子的残差。

#### 方法二：对称正交（Schmidt正交化）

```
基于所有因子的协方差矩阵进行同时对称正交化
将协方差矩阵开平方根后逆变换
```

**优点**：不依赖因子排列顺序，所有因子被平等对待。
**缺点**：计算量较大（需要矩阵开平方根），且改变了每个因子与原始定义的对应关系。

#### 方法三：Gram-Schmidt正交化

```
u_1 = v_1
u_2 = v_2 - proj(v_2, u_1)
u_3 = v_3 - proj(v_3, u_1) - proj(v_3, u_2)
...
```

最经典的正交化方法，但同回归法一样依赖顺序。

#### A股因子正交化经验

根据华泰金工的研究，A股因子正交化确实能提升多因子组合的IR（提升幅度约10-15%），但代价是每个因子的独立经济学解释变模糊。项目的多因子评分模型目前未做正交化——各维度之间可能存在一定的共线性（如技术面和资金面可能同向），这是未来优化的空间。

## 六、因子库管理规范

### 6.1 命名规范

```
格式：[类别]_[指标]_[参数]_v[版本]

示例：
  qual_ROE_TTM_v1      质量·ROE_TTM·第1版
  momo_Rev_1M_v1       动量·1月反转·第1版
  momo_ResM_12M_s1_v1  动量·残差动量·12月回看skip1·第1版
  val_EP_TTM_v1        价值·盈利收益率·TTM版·第1版
  tech_MA_BullAlign_v1 技术·均线多头排列·第1版
```

### 6.2 版本控制规则

当因子发生以下变更时，必须升级版本号：

| 变更类型 | 版本升级 | 示例 |
|:---------|:--------|:-----|
| 调整参数（如回看期从1M改为3M） | v1→v2 | momo_Rev_1M_v1 → momo_Rev_3M_v2 |
| 调整构建方法（如缩尾从1%改为2%） | v1→v2 | 同上 |
| 调整数据源（如从源A改为源B） | v1→v2 | 同上 |
| 重大方法论变更（如从价格动量改为残差动量） | 新建因子 | 不升级原版本，新建独立因子 |
| 仅调整权重（因子本身不变） | 不升级因子版本 | 在评分引擎中记录权重变更 |

### 6.3 因子注册表格式

每个因子在进入评分引擎或用于回测前，必须在因子注册表中登记：

### 6.4 数据源1+2绑定原则

每个因子的每个数据字段必须遵循项目的1+2主备架构（红线§1.2）：

## 八、自测题

**题1**：A股为什么不能用美股的传统12月动量因子？

**答案**：A股在个股层面整体呈短期反转效应（非传统动量），12个月回看期原始价格动量ICIR=-0.244（显著负向）。而美股12月动量ICIR通常为正且显著。原因包括：A股散户占比高导致的过度反应和均值回归、T+1制度限制趋势跟踪策略效率、行业轮动速度远快于美股。但如果做行业中性化后的残差动量，A股也存在正向动量信号（ICIR=+0.151），只是被行业均值回归效应掩盖。

**题2**：什么时候应该做行业中性化，什么时候不应该？

**答案**：当因子在行业间存在天然水平差异时必须做（如PE——银行业天然低PE、科技业天然高PE，不中性化选出的全是银行股）。当策略本身就包含行业选择逻辑（如本项目板块动量），且行业层面的信息本身就是青山来源的一部分时，不应做行业中性化——否则会剔除行业选择带来的超额收益。折中方案是：因子层面做行业中性化以纯化信号，策略层面独立做行业配置决策，两者不互相干扰。

**题3**：一个因子IC=0.05、ICIR=0.3、月换手率=70%——这个因子能用吗？

**答案**：预测力（IC=0.05）和稳定性（ICIR=0.3）尚可，但月换手率70%是致命问题。A股单边交易成本约0.1-0.15%（佣金+印花税+滑点），70%月换手率意味着每月约70%的持仓被更换，双边换手140%，年化交易成本=140%×12×0.15%≈2.5%。如果策略年化超额收益本身只有5-8%，交易成本就吃掉了一半。结论：这个因子需要搭配低换手过滤条件（如只在信号强度超过1.5倍标准差时才交易），或作为复合因子的次要成分（权重<15%），不能独立使用。
