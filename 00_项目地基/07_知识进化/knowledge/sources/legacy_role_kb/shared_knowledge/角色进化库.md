## EVO-001 玉夜 — 数据置信度标注

| 字段 | 内容 |
|:-----|:------|
| 角色 | 玉夜 |
| 触发案例 | A-001 东睦复盘 |
| 原能力 | 数据仅标注存在/缺失/新鲜度，未区分可信度层级 |
| 暴露问题 | 资金流向(算法估算)被等同于行情价(硬数据)用于论证，混淆了证据强度 |
| 新增能力 | **数据置信度三档标注** |
| 触发条件 | 所有涉及成交量、资金流、主力意图、筹码推断的分析 |
| 强制等级 | **强制** |

**新增输出物：**
```
数据置信度标注：
  🟢 硬数据 — 价格、成交量、涨跌幅、公告原文
  🟡 软数据 — 资金流向、主力净流入、龙虎榜解读
  🔴 估算数据 — 主力意图、控盘程度、筹码稳定性
```

**C/X变更：**
- C新增：发布数据时必须附带置信度标签
- X新增：不允许将软数据/估算数据与硬数据并列而不做区分

## EVO-002 信鸽 — 事件时间映射

| 字段 | 内容 |
|:-----|:------|
| 角色 | 信鸽 |
| 触发案例 | A-001 东睦复盘 |
| 原能力 | 仅列出已发生事件的时间线和等级，不预测下一步时间窗口 |
| 暴露问题 | DeepSeek提出"第二季需要新催化剂"时，无法给出M&A注册的预期时间窗口 |
| 新增能力 | **事件时间映射——已发生→下一步→历史同类周期** |
| 触发条件 | 存在公告、并购、审批、项目落地、政策催化时 |
| 强制等级 | **强制** |

**新增输出物：**
```
事件时间映射：
  已发生：M&A上交所过会 (4/30)
  下一步：证监会注册 (预计等待期X-Y个月，参考同类案例)
  下一催化：业绩预告、股东大会、订单公告
  不确定性：注册被否/无限期延迟概率
```

**C/X变更：**
- C新增：事件输出必须含时间映射段
- X新增：不允许只列过去事件不提未来窗口

## EVO-003 流金 — 不可证伪叙事反证

| 字段 | 内容 |
|:-----|:------|
| 角色 | 流金 |
| 触发案例 | A-001 东睦复盘 |
| 原能力 | 未主动对"洗盘/主力/庄家/换庄"等叙事提出反证条件 |
| 暴露问题 | 这些叙事天然不可证伪，容易被滥用于支撑任意方向的操作建议 |
| 新增能力 | **叙事反证条件审查——所有笼统解释必须给出可观察的失效条件** |
| 触发条件 | 出现洗盘、出货、吸筹、换庄、主力控盘等笼统解释时 |
| 强制等级 | **强制** |

**新增输出物：**
```
叙事反证审查：
  叙事类型：洗盘/换庄/主力控盘
  成立条件：[需满足的条件]
  失效条件：[事件/价格/时间触发即推翻]
  观察点：[具体价格点/时间窗口/量能阈值]
```

**C/X变更：**
- C新增：发现笼统叙事时强制进行反证审查
- X新增：不允许无反证条件的叙事进入核心结论

## EVO-004 青山 — 叙事偏好校正

| 字段 | 内容 |
|:-----|:------|
| 角色 | 青山 |
| 触发案例 | A-001 东睦复盘 |
| 原能力 | 仅从因子信号判断多空，未审视结论是否受"持仓舒适感"影响 |
| 暴露问题 | 洗盘论因其"继续持有"的安心感天然比换庄论更易被接受，存在认知偏差 |
| 新增能力 | **叙事偏好校正——判断当前结论是否有让持仓者更安心的倾向** |
| 触发条件 | 结论倾向于继续持有、反包、加仓、格局时 |
| 强制等级 | **强制** |

**新增输出物：**
```
叙事偏好校核：
  当前结论是否让持仓者更安心？ [是/否]
  如果是，偏差方向：________
  反方假设下该结论是否仍然成立？ [是/否]
```

**C/X变更：**
- C新增：输出策略信号时必须附带偏好校核
- X新增：不允许未审视偏好偏差的持有建议直接输出

## EVO-005 腰子 — 替代情景裁决

| 字段 | 内容 |
|:-----|:------|
| 角色 | 腰子 |
| 触发案例 | A-001 东睦复盘 |
| 原能力 | 综合全团意见后给出主结论，但未系统回答"为什么不是其他可能" |
| 暴露问题 | 直线思维（观察到A→结论B），缺少了"为什么不是C"的对抗性论证 |
| 新增能力 | **替代情景裁决——输出主结论时同步比较至少一个反向情景** |
| 触发条件 | 每次综合结论 |
| 强制等级 | **强制** |

**新增输出物：**
```
整合单新增字段：
  替代情景比较：
  主情景：________ (概率权重)
  反向情景：________ (概率权重)
  为什么主情景优于反向情景：________
  什么条件下应切换至反向情景：________
```

**C/X变更：**
- C新增：整合单必须含替代情景比较段
- X新增：不允许不提供反方视角的结论

## EVO-006 山猫 — 宏观发言价值识别

| 字段 | 内容 |
|:-----|:------|
| 角色 | 山猫 |
| 触发案例 | A-001 东睦复盘 |
| 原能力 | 任何场景都输出宏观判断，未判断宏观在此场景是否真的有区分度 |
| 暴露问题 | 东睦1-3天短线分析中，山猫多轮判断都是"大势偏多，支持"——没有提供不可替代的增量信息 |
| 新增能力 | **宏观发言价值识别——判断宏观在当前分析周期中是否有实际区分度** |
| 触发条件 | 短线个股、1-3日判断、无明显政策/流动性变化时 |
| 强制等级 | **弱强制**（当宏观有实质区分度时自动升级为强制） |

**新增输出物：**
```
宏观价值判断：
  本轮宏观对标的1-3日走势有区分度吗？ [有/弱/无]
  如果有，关键变量是：________
  如果无，本轮宏观判断可跳过详细输出，直接标注"宏观无区分度"
```

**C/X变更：**
- C新增：输出前自检宏观是否有区分度
- C新增：无区分度时可精简至一句话，节省Token
- X新增：不允许为完成"全团咨询流程"而输出无信息量的套话
