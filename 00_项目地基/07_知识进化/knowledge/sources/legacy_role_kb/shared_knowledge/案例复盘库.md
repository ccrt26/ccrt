## A-001 东睦股份短线分析复盘

### 基础信息

| 字段 | 内容 |
|:-----|:------|
| 案例编号 | A-001 |
| 案例名称 | 东睦股份短线分析复盘：洗盘论与换庄论分歧下的反证机制升级 |
| 标的 | 东睦股份(600114) |
| 分析日期 | 2026-05-26 ~ 2026-06-02 |
| 复盘日期 | 2026-06-02 |
| 参与角色 | 山猫、信鸽、玉夜、流金、青山、腰子 |
| 外部观点来源 | DeepSeek(专家模式)、豆包(专家模式) |
| 入库等级 | A级 |

### 核心问题

面对涨停后开板、成交缩量、资金大幅分歧，应如何判断是**主力洗盘**、**游资换庄**，还是**趋势衰竭**。

### 原始判断

团队初判：涨停质量偏弱（内盘2倍外盘、封单由7.9万手缩至5.9万手），建议谨慎，不追涨，已有仓位可持有观察。

### 外部观点分歧

| 来源 | 核心论点 | 数据证据 | 前瞻含义 |
|:-----|:--------|:---------|:---------|
| **DeepSeek** | 换庄接力——老资金出逃→新资金进场→第二季启动 | 5/29放量大跌+今日涨停反包，认为新资金强力进驻 | 明天验证：高开高走则确认，低开闷杀则套利结束 |
| **豆包** | 强势洗盘→反包——主力并没有走，洗盘后继续拉升 | 6/1成交额9.7亿(近期最低)=洗盘完成标志，开板=二次洗盘 | 洗盘完成后空间打开，持有待涨 |

### 关键证据分歧

| 数据点 | 对洗盘论 | 对换庄论 |
|:-------|:---------|:---------|
| 5/29成交额15.6亿(放量跌) | 主力顺势深洗10%，以恐慌逼出浮筹 | 老游资真实获利出逃 |
| 6/1成交额9.7亿(近期最低) | **✅ 洗盘完成，没人卖了** | ❌ 无法解释：换庄日成交量为何最低 |
| 今日内盘/外盘=2:1 | 洗盘过深导致低位抄底盘解套卖出，仍合理 | ❌ 新资金强势接盘应外盘>内盘 |
| 今日封单缩水24%(7.9→5.9万手) | 二次洗盘，挤出不坚定者 | ❌ 新资金护盘不力 |
| 主力净流出5/29-6/1累计-3.55亿 | 主力减仓过半后操盘力度下降 | 老资金出清，新资金才入+1.11亿 |

### 最终综合判断

采用**修正版洗盘论**：洗盘框架正确（6/1缩量是硬性证据），但非教科书式"完美洗盘"——主力在第一波(5/21-5/25)建仓后已在高位减持部分仓位，所以洗盘深度较大(10%)，今日反包力度弱于第一波。主力仍在但控盘力下降。

### 做对了什么

- 开盘即识别涨停质量偏弱（内盘/外盘、封单趋势）
- 要求设置失效条件（36.62支撑、CSRC注册风险）
- 半仓操作建议降低了情绪风险

### 做错/不足

1. 事件缺少时间映射——未给出M&A注册的预期周期
2. 资金流数据未标注可信度——主力净流入是算法估算值
3. 替代情景反驳不足——未系统回答"为什么不是其他可能"
4. 团队共识过快形成——缺少系统性反方

### 触发进化

触发6条新规则：
- R01 数据置信度规则（玉夜）
- R02 事件时间映射规则（信鸽）
- R03 不可证伪叙事规则（流金）
- R04 替代情景规则（腰子）
- R05 叙事偏好校正规则（青山）
- R06 影子角色规则（全员）

### 最终教训

短线个股分析不能只给主观点。必须同时给出：**替代情景 + 反证条件 + 数据置信度 + 下一催化时间窗口**。核心能力从"观点判断"升级为"带反证、带置信度、带替代情景的统一解读"。
