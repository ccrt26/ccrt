## 一、什么是因子

### 1.1 核心定义

因子（Factor）是用来预测股票未来收益的量化指标。任何一个可以被数值化、并且与未来收益有统计关系的特征，都可以被称为因子。

在铁律量化项目中，因子不是抽象概念——每一只股票的每一个评分维度，本质上都是一个因子信号的载体。技术面的均线多头排列是因子，资金面的连续净流入是因子，基本面的ROE水平也是因子。

### 1.2 六大类因子

| 类别 | 核心指标 | 项目中的对应维度 |
|:-----|:---------|:---------------|
| 价值因子 | PE、PB、PS、股息率 | 基本面维度（PE否决、PE评分） |
| 动量因子 | 过去N日涨跌幅、均线排列 | 技术面维度（S1均线系统、S8趋势动量） |
| 质量因子 | ROE、毛利率、现金流/净利润 | 基本面维度（S4盈利能力） |
| 波动率因子 | ATR、Beta、波动率 | 风控维度（ATR止损计算） |
| 成长因子 | 营收增速、净利润增速 | 基本面维度（S3成长性） |
| 情绪因子 | 换手率、资金流、量比 | 资金面维度（主力净流入）+ 消息面维度 |

### 1.3 单因子 vs 多因子

- **单因子**回答一个问题："这个指标能不能预测未来收益？" 方法是通过IC计算判断因子值与未来收益的相关性。
- **多因子**回答另一个问题："多个因子组合在一起，怎么分配权重最优？" 方法是通过多因子回归或打分模型，如项目的六维加权评分体系。

项目的评分体系（基本面15分 + 技术面30分 + 资金面20分 + 消息面15分 + 板块趋势持续性5分 + 风控否决）本质上是一个**多因子打分模型**，每个维度内部又包含多个子因子（如技术面的S1-S8共8个子项）。

## 二、IC（信息系数 Information Coefficient）

### 2.1 定义与公式

IC衡量单因子对下一期收益的预测能力：

```
IC = corr(因子值_T日, 收益_T+1日)
```

即在T日计算每只股票的因子值，在T+1日观察每只股票的实际收益，计算这两组数据的相关系数。

### 2.2 两种计算方式

| 类型 | 公式 | 特点 |
|:-----|:-----|:-----|
| Pearson IC（正常IC） | pearsonr(因子值, 收益) | 受极端值影响大，对离群值敏感 |
| Rank IC（Spearman IC） | spearmanr(因子排名, 收益排名) | 只关心排序关系，不受极端值影响，更稳健 |

**项目中统一使用Rank IC（即Spearman相关系数）**，这是后评估v1.5做出的关键设计决策——后评估v1.5 §三(三)明确规定使用Spearman计算各维度评分与次日涨跌幅的相关系数。

### 2.3 IC的判定标准

| IC绝对值 | 判定 | 说明 |
|:-------:|:-----|:-----|
| > 0.10 | 很好 | 因子有强预测力，实盘可用 |
| > 0.05 | 不错 | 因子有中等预测力，可加入多因子模型 |
| > 0.03 | 有预测力 | 因子有弱预测力，可观察 |
| < 0.03 | 弱 | 单独使用意义不大，可能需与其他因子组合 |
| ≈ 0 | 无用 | 因子完全没有预测力，应弃用 |
| < 0（负值） | 反向预测 | **这也是有用的信号！** 反转因子可以反向使用 |

### 2.4 IC为负值的正确处理

IC为负值不意味着"这个因子废了"。它意味着因子值越高，未来收益越低——这是一个**可靠的反向信号**。

项目中的实际情况：
- v1.5后评估发现整体Spearman = -0.436，评分反向（高分股反而跌得多）
- 基本面维度Spearman = -0.182，基本面好的股票短线表现反而差
- 消息面维度Spearman = -0.124，单日涨跌幅噪声大

**这不是"找到了无用因子"，恰恰相反，这是"找到了一个稳定反向的因子"——同样有价值。** 正确的处理方式是把反向因子"翻转"使用，或者降低其权重（项目选择降低权重：基本面20→15，消息面20→15）。

## 三、Rank IC（排名IC = Spearman相关系数）

### 3.1 为什么Rank IC比Pearson IC更稳健

考虑以下场景：
- 股票A：因子值=100（极端值），收益=+2%
- 股票B：因子值=10，收益=+1%
- 其他98只股票：因子值在20-30之间

Pearson IC会被A的极端值严重扭曲，可能计算出虚高的相关性。而Rank IC只看排序——A排第1、B排第100——不会因为A的因子值特别大就给A更大的权重。

### 3.2 项目中的Spearman标准（后评估v1.5 §三(三)）

| Spearman ρ | 判定 | 操作 |
|:----------:|:-----|:-----|
| ρ > 0.3 | 有效预测 | 权重可上调 |
| 0.1 ≤ ρ ≤ 0.3 | 弱相关 | 维持当前权重 |
| ρ < 0.1 | 无预测力 | 重构评分逻辑 |
| ρ < 0（负相关） | 反向指标 | 立即暂停排查 |

**5日滚动窗口说明**（v1.5新增）：相关系数使用最近5个交易日为滚动窗口每日计算，而非使用全量历史数据的单一相关系数。滚动窗口能更快反映评分维度预测力的变化趋势——因为A股短线因子的衰减速度很快，全量历史数据会掩盖近期失效的信号。

### 3.3 Spearman相关系数的数学理解

Spearman ρ衡量的是**两个变量的排名是否同方向变化**，而非数值大小是否相关。公式上：

```
ρ = 1 - (6 × Σd_i²) / (n × (n² - 1))
```

其中d_i是第i个样本在两个变量上的排名之差，n是样本量。

- ρ = 1：完美正相关——因子排名最高的股票，收益排名也最高
- ρ = -1：完美负相关——因子排名最高的股票，收益排名最低
- ρ = 0：完全不相关——因子排名和收益排名没有任何关系

### 3.4 评分区分度（Spearman版）

后评估v1.5 §一(二)引入了评分区分度的相对排名法：

```
评分区分度（相对排名）= spearmanr（评分排序，涨跌幅排序）
目标 > 0.2
```

这与传统的分组法（高分组的平均收益减低分组的平均收益）不同。相对排名法的优势在于**天然去除了市场beta的影响**——如果大盘大涨，所有股票都涨，传统分组法可能显示"区分度好"（因为高分组涨了），但这实际上是beta而非alpha。Spearman只看排名关系，消除市场整体涨跌的干扰。

## 四、IR（信息比率 Information Ratio）

### 4.1 定义与公式

```
IR = mean(IC) / std(IC)
```

IR衡量的是**因子预测力的稳定性**。IC均值告诉你因子"平均好不好"，IC标准差告诉你因子"每次波动大不大"。

### 4.2 IR的判定标准

| IR | 判定 | 说明 |
|:--:|:-----|:-----|
| > 0.5 | 可实盘 | 因子预测力稳定，可以信赖 |
| 0.3 - 0.5 | 可观察 | 因子有潜力，需要更多数据验证 |
| < 0.2 | 不可靠 | 预测力波动太大，不能依赖 |

### 4.3 高IC低IR的危险场景

假设一个因子的IC统计：
- 第1天：IC = +0.30
- 第2天：IC = -0.25
- 第3天：IC = +0.28
- 第4天：IC = -0.22
- 第5天：IC = +0.29

IC均值 ≈ 0.08（看起来不错），但 std(IC) ≈ 0.27，IR = 0.08/0.27 ≈ 0.30。

这个因子"平均"预测力不错，但**方向时正时反、极不稳定**。你今天根据因子买入，明天因子可能就发出反向信号，导致反复止损。这就是为什么只看IC不看IR会掉坑里。

### 4.4 中IC高IR的优质场景

另一个因子：
- IC均值 = 0.04（不惊艳）
- IC标准差 = 0.05（非常稳定）
- IR = 0.04/0.05 = 0.8（非常优秀）

虽然每次预测力一般，但每次都很稳定地"对一点点"。这种因子在多因子组合中非常宝贵——它的贡献虽然小，但确定性强。

### 4.5 项目中的IR缺席与替代

项目目前没有直接计算IR（需要至少30个交易日的连续IC序列），但通过以下机制间接实现了IR的核心思想：

- **5日滚动Spearman**：每日计算最近5日的相关系数，监控预测力的稳定性——如果连续5日的Spearman波动很大（今天+0.3明天-0.1），说明该维度预测力不稳定，等价于低IR。
- **维度误判率监控**：连续3日>20%触发维度重构——本质上是在监控"预测力的波动"。
- **附录B缓冲区**：目标值→警告值→停用值的三级阈值——最小化了单日异常值干扰，和IR的"稳定性检查"逻辑一致。

## 五、分组收益（Quantile Returns）

### 5.1 方法

按因子值把股票等分成N组（常用5组，即五分位），计算每组下一期的平均收益：

- Q1：因子值最低的20%
- Q2：因子值次低的20%
- ...
- Q5：因子值最高的20%

### 5.2 核心检验指标

| 检验项 | 方法 | 理想结果 |
|:-------|:-----|:---------|
| 多空收益 | Q5收益 - Q1收益 | 绝对值越大越好 |
| 单调性 | Q1 < Q2 < Q3 < Q4 < Q5 | 严格递增（或严格递减） |
| 多空稳定性 | 逐日计算多空收益 | 正收益天数 > 负收益天数 |

### 5.3 单调性为什么重要

如果分组收益是：Q1=-1%, Q2=+3%, Q3=-2%, Q4=+1%, Q5=+0.5%——虽然Q5的平均收益高于Q1，但中间"上蹿下跳"，说明因子值中段没有区分能力。这种因子可能在极端值上有预测力，但在中段完全随机。

### 5.4 项目中的应用

项目的五档仓位映射（评分≥80→25%、≥65→20%、≥45→10%、≥30→5%、<30→0%）本质上就是分组收益思想的应用：假设评分越高的组，未来收益越好，所以仓位应该越高。

但这个假设在v1.5后评估中被**证伪**——Spearman=-0.436，评分更高的组收益反而更差。这说明当前的评分权重配置存在系统性问题，v2.4正在通过权重重构（技术面升、基本面降）来修复。

## 六、因子换手率

### 6.1 定义

```
换手率 = 本期Q5组合中与上期Q5组合不同的股票数量 / Q5组合总股票数
```

衡量的是"因子选出的好股票变化有多快"。换手率高意味着因子的信号变化频繁。

### 6.2 换手率对策略的影响

| 换手率 | 含义 | 策略影响 |
|:------:|:-----|:---------|
| < 20% | 低换手，信号稳定 | 交易成本低，容量大，适合大资金 |
| 20%-50% | 中等换手 | 正常水平 |
| > 50% | 高换手 | 交易成本高，不适合大资金；信号可能含噪声 |
| > 80% | 极高换手 | 几乎每天换一批股票，因子很可能不稳定 |

### 6.3 项目中的换手率

项目没有直接计算因子换手率，但**拥挤度预警**（后评估v1.5 §四(二)）间接使用了换手率的分位判断：换手率超过该股票自身20日分位的80%值，且量比>1.5，触发拥挤预警。这是在用换手率的异常变化来捕捉拥挤交易信号。

## 七、单因子检验完整流程（5步）

> 这是量化因子的"入门仪式"。任何新因子在接入评分系统前，必须走完这5步。

### Step 1：数据清洗

| 操作 | 方法 | 目的 |
|:-----|:-----|:-----|
| 去极值 | ±3σ截尾 或 MAD法（中位数±3×1.4826×MAD） | 消除极端值对统计的干扰 |
| 标准化 | Z-score: (x - mean) / std | 让不同量纲的因子可比 |
| 行业中性化 | 因子值对行业哑变量回归，取残差 | 消除行业属性干扰（不是选了好行业，是选了好股票） |

### Step 2：IC计算

逐日计算因子值与次日收益的Rank IC，统计IC均值、IC标准差、IC>0的天数占比、ICIR。

### Step 3：分组回测

按因子值分5组，每组等权持有，逐日计算每组收益。输出Q1-Q5的累计收益曲线图。

### Step 4：单调性检验

检查分组收益是否单调递增/递减。如果不单调，考虑因子是否需要非线性变换（如取对数、平方）。

### Step 5：换手率计算

计算每日Q5组合与上日Q5组合的重叠比例，评估交易成本和容量。

## 十、自测题

**题1**：Spearman相关系数为-0.436意味着什么？应该怎么处理？

**答案**：意味着评分排序与次日涨跌幅排序呈中等负相关——评分越高的股票，次日涨幅排名反而越低（跌得越多）。这说明评分体系存在系统性缺陷，不是某个维度的问题而是整体逻辑相反。处理方式：（1）立即排查各维度Spearman，定位主要负贡献维度（已做：基本面-0.182、消息面-0.124）；（2）降低负相关维度的权重（v2.4已执行：基本面20→15、消息面20→15）；（3）提升正相关维度的权重（技术面+0.199，25→30）；（4）不要简单地把整个评分系统翻转——这样做会引入新的未知风险。应通过灰度测试逐项验证。

**题2**：IC很高（0.1）但IR很低（0.1）的因子能用吗？为什么？

**答案**：不能直接使用。IC=0.1说明平均预测力不错，但IR=0.1=0.1/1.0意味着std(IC)≈1.0，即IC在-0.9到+1.1之间大幅波动。每次使用时你都在赌"这次IC是正还是负"，这等价于随机下注。它可能在某些特定市场环境下有效（比如只在牛市中IC为正），需要通过场景化回检（见文件12-路径优选与市场状态自适应.md）找到它有效的具体条件后，才能有条件地使用。

**题3**：分组收益单调性检验的目的是什么？

**答案**：验证因子值从低到高时，未来收益是否单调递增（或递减）。单调性检验的目的有三个：（1）确认因子在"所有区间"上都有区分度，而不仅是在极端值上有区分度；（2）找到因子的"有效区间"——如果只有Q1和Q5有区分度，中间Q2-Q4随机，那么在中等因子值区域应该降低该因子的权重；（3）检验因子是否需要非线性变换，不单调的因子取对数或平方后可能变得单调。在项目中的等价检验是"评分区分度"——≥70分组胜率 vs <70分组胜率，差值≥15%。
