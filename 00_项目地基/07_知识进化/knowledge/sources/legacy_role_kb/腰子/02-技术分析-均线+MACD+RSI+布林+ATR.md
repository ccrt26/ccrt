## 一、均线系统（MA -- Moving Average）

### 1.1 核心概念

均线是过去 N 个交易日收盘价的算术平均值，反映一段时间内的平均持仓成本。

```
MA(N) = (C1 + C2 + ... + CN) / N
```

### 1.2 常用周期含义

| 均线 | 周期 | 含义 | 用途 |
|:-----|:----|:-----|:-----|
| MA5 | 周线 | 一周平均成本，超短期趋势 | 短线入场/出场信号 |
| MA10 | 双周线 | 两周平均成本，短期趋势 | 短线趋势方向 |
| MA20 | 月线 | 一月平均成本，中期趋势 | **最核心的趋势判断线** |
| MA50 | 季线 | 一季度平均成本，中期趋势 | 中期持仓方向 |
| MA120 | 半年线 | 半年平均成本，长期趋势 | 牛熊分界线之一 |
| MA250 | 年线 | 一年平均成本，长期趋势 | 牛熊分界核心线 |

### 1.3 均线排列

**多头排列（看多）**：
```
MA5 > MA10 > MA20 > MA50
```
当短期均线在上、长期均线在下，呈向上发散状态时，说明近期买入者的成本高于早期买入者、且股价持续推高，买方力量强劲。这是最强的上升趋势信号。

**空头排列（看空）**：
```
MA5 < MA10 < MA20 < MA50
```
当短期均线在下、长期均线在上，呈向下发散状态时，说明市场在持续下跌，持有者不断被套。

**均线缠绕（震荡）**：
均线相互交错、方向不明。说明市场方向感缺失，多空力量均衡，通常出现于横盘整理阶段。

### 1.4 金叉与死叉

**金叉（Golden Cross，看多）**：短期均线自下而上穿越长期均线。
- 经典金叉：MA50 上穿 MA200/MA250（长期看多信号）
- 快速金叉：MA5 上穿 MA20（短期看多信号）

**死叉（Death Cross，看空）**：短期均线自上而下穿越长期均线。
- 经典死叉：MA50 下穿 MA200（长期看空信号）

**金叉/死叉的可靠性**：
- 周期越长（如周线金叉 vs 日线金叉），信号越可靠
- 成交量配合：金叉+放量 > 金叉+缩量
- 零轴位置：MACD 零轴上方金叉可靠度高于零轴下方金叉

### 1.5 均线斜率

**均线斜率比均线位置更重要**：
- MA20 向上倾斜且斜率增大 -> 趋势加速
- MA20 走平 -> 趋势可能转折
- MA20 向下倾斜 -> 趋势走弱

斜率计算（简化）：
```
MA20斜率 ≈ (今日MA20 - 5日前MA20) / 5日前MA20
```

### 1.6 均线收敛与发散

**均线收敛**：多条均线间距不断缩小（< 1%）。
- 含义：不同周期持仓成本接近，市场蓄势待发
- 操作：等待方向选择（向上突破追入/向下跌破回避）

**均线发散**：均线间距不断扩大。
- 向上发散：上升趋势加速，可加仓
- 向下发散：下降趋势加速，应回避

### 1.7 价格与均线的关系

- **价格站上 MA20**：趋势转好的重要信号（MA20 被称为"生命线"）
- **价格在 MA20 上方运行**：强势特征，MA20 为动态支撑
- **价格在 MA20 下方运行**：弱势特征，MA20 为动态阻力
- **回踩 MA20 不破**：趋势健康的确认信号，适合加仓

- **每日荐股v2.4 S1均线系统(6分)**：MA5>MA10>MA20 且价格站上MA20 得6分；均线收敛（间距<1%）得4分；死叉得1分

## 二、MACD（指数平滑异同移动平均线）

### 2.1 核心概念

MACD(12,26,9) 由三部分组成：

```
EMA12 = 12日指数移动平均（快线）
EMA26 = 26日指数移动平均（慢线）
DIF = EMA12 - EMA26（差离值，即快慢线差值）
DEA = DIF的9日EMA（信号线，对DIF平滑）
柱状线 = (DIF - DEA) * 2（MACD柱，反映DIF与DEA的差距）
```

EMA（指数移动平均）与 MA（简单移动平均）的区别：EMA 赋予近期价格更高权重，反应更灵敏。

### 2.2 核心信号

**金叉/死叉**（DIF与DEA的交叉）：
- 金叉：DIF 上穿 DEA -> 看多信号
- 死叉：DIF 下穿 DEA -> 看空信号

**零轴判断**：
- DIF/DEA 在零轴上方 -> 多头市场（EMA12 > EMA26，短期均价高于长期均价）
- DIF/DEA 在零轴下方 -> 空头市场
- DIF 上穿零轴 -> 趋势由空转多
- DIF 下穿零轴 -> 趋势由多转空

**柱状线变化**：
- 红柱变长（正值增大）-> 上涨动能增强
- 红柱变短（正值减小）-> 上涨动能减弱
- 绿柱变长（负值绝对值增大）-> 下跌动能增强
- 绿柱变短（负值绝对值减小）-> 下跌动能减弱

### 2.3 不同时间框架的可信度

| 周期 | 信号频率 | 可靠性 | 适用场景 |
|:-----|:-------:|:------:|:--------|
| 15分钟 | 极高 | 低（噪音多） | 日内交易 |
| 60分钟 | 高 | 中低 | 短线T+0 |
| **日线** | 中 | **中高** | **短线1-5日** |
| 周线 | 低 | 高 | 中期趋势判断 |
| 月线 | 极低 | 极高 | 长期战略方向 |

**原则**：周线 MACD 金叉 + 日线 MACD 金叉 = 多周期共振，信号可靠性大幅提升。

### 2.4 项目对接

- **每日荐股v2.4 S6 MACD(2分)**：金叉得2分；多头运行得1分；死叉得0分
- **重点股票v2.2 1.1.4技术指标组合确认规则**：
  - 做多信号：MACD零轴上方金叉/DIF向上
  - 做空信号：MACD零轴下方死叉/DIF向下
  - 背离信号：价格新高但MACD未新高 -> 顶背离（详见04-背离信号系统）
- **模拟交易v1.4 趋势健康度**：MACD状态是六项指标之一（DIF零轴上方+柱状体向上=健康；DIF走平=预警；DIF下穿零轴=危险）

## 三、RSI（相对强弱指标）

### 3.1 核心概念

RSI(14) 衡量近期价格变动的速度和幅度：

```
RS = 14日内上涨日平均涨幅 / 14日内下跌日平均跌幅（取绝对值）
RSI = 100 - 100 / (1 + RS)
```

RSI 取值范围 0-100，反映买方力量与卖方力量的相对强弱。

### 3.2 区域判断

| RSI范围 | 含义 | 操作建议 |
|:-------|:-----|:--------|
| > 80 | 极度超买 | 大概率回调，减仓 |
| 70-80 | 超买区 | 警惕回调，不宜追高 |
| **40-55** | **蓄势区（最佳买入区域）** | **RSI从40-55区间向上突破时买入** |
| 30-40 | 偏弱区 | 观望 |
| < 30 | 超卖区 | 关注反弹机会 |
| < 20 | 极度超卖 | 恐慌性抛售后可能反弹 |

### 3.3 突破形态下的RSI特例

在强势突破行情中，RSI>70 不能简单视为超买：
- 如果股价放量突破、均线多头排列、且RSI>70是突破过程中产生的 -> 2分（不扣分）
- 如果震荡行情中RSI>70 -> 0分（超买风险）

### 3.4 RSI背离（详见04-背离信号系统）

- **顶背离**：价格新高 + RSI未新高 -> 上升动能衰竭
- **底背离**：价格新低 + RSI未新低 -> 下跌动能衰竭

### 3.5 项目对接

- **每日荐股v2.4 S5 RSI位置(3分)**：RSI 40-55 得3分；突破形态RSI>70也得2分（不扣）；RSI>70得0分
- **重点股票v2.2 1.1.4指标组合**：RSI 50-70区间震荡向上=健康；70以上钝化=预警；跌破50=危险
- **重点股票v2.2 3.2.1趋势健康度评分**：60-79分时检查RSI是否>70超买区；40-59分时RSI<50为减仓信号
- **后评估v1.5 3.4误判子类型**：RSI钝化(RSI>60钝化后回落) 作为独立误判子类型统计

## 四、布林带（Bollinger Bands）

### 4.1 核心概念

布林带(20,2) 由三条线组成：

```
中轨 = MA20
上轨 = MA20 + 2 * 标准差(20日)
下轨 = MA20 - 2 * 标准差(20日)
```

标准差反映了近期波动率。2个标准差覆盖了正态分布下约95%的价格数据，因此价格突破上下轨是小概率事件。

### 4.2 带宽信号

**带宽 = (上轨 - 下轨) / 中轨**

- **带宽收窄（<5%）**：波动率极低，"暴风雨前的宁静"。通常3-5日内出现大行情（方向由MA20斜率决定）
- **带宽扩张**：波动率加大，趋势延续或加速。放量突破上轨+带宽扩张 = 强势突破信号
- **带宽适中**：正常波动，按趋势操作

### 4.3 价格与布林带的关系

| 位置 | 含义 | 操作 |
|:-----|:-----|:-----|
| 价格触及上轨 | 短期超买 | 强势股可沿上轨运行5-10日（逼空行情），震荡股触及上轨应减仓 |
| 价格触及下轨 | 短期超卖 | 需结合成交量判断是恐慌底还是下跌中继 |
| 价格在中轨上方 | 偏强 | MA20 为动态支撑 |
| 价格在中轨下方 | 偏弱 | MA20 为动态阻力 |
| 价格从下轨反弹到中轨 | 修复中 | 观察能否站上中轨 |

### 4.4 布林带宽收窄后放量突破上轨

这是经典的高质量买入信号：
1. 带宽持续收窄（波动率降低，市场在蓄力）
2. 某日放量（成交额 > 5日均量 * 1.5）突破上轨
3. 说明：经过充分蓄势后，买方力量集中爆发
4. 后续：大概率走出一波趋势行情（而非一日游）
5. 止损：设置在突破前的中轨或下轨

### 4.5 项目对接

- **重点股票v2.2 1.1.4背离信号**：价格触及上轨但RSI/MACD未确认 -> 假突破可能性大
- **后评估v1.5 3.5场景化回检**：路径分类中的逃顶路径使用布林触及上轨作为特征之一

## 五、ATR（平均真实波幅）

### 5.1 核心概念

ATR(14) 衡量价格波动幅度而非方向：

```
TR（真实波幅）= max(
    当日最高 - 当日最低,
    |当日最高 - 昨日收盘|,
    |当日最低 - 昨日收盘|
)

ATR = 前日ATR * 13/14 + 当日TR / 14（Wilder平滑法）
```

第一个ATR值用14日简单平均初始化。

### 5.2 ATR的三重含义

TR 取三项中的最大值，确保覆盖了跳空缺口的影响：
- 当日振幅（日内波动）
- 向上跳空（今日最高 - 昨日收盘）
- 向下跳空（昨日收盘 - 今日最低）

如果前一日涨停，次日跳空高开，普通振幅指标无法反映真实波动，但 ATR 可以。

### 5.3 ATR止损（项目的默认止损方法）

```
止损价 = 入场价 - 2 * ATR(14)
```

**为什么用 2*ATR 而不是固定百分比？**

| 方法 | 优点 | 缺点 |
|:-----|:-----|:-----|
| 固定百分比（如-5%） | 简单直观 | 高波动股经常误止损，低波动股止损太宽 |
| 2*ATR | 自适应波动率 | 极端行情下 ATR 可能膨胀到不合理的程度 |

**ATR止损的自适应逻辑**：
- 高波动股（如小盘题材股，ATR/价格>5%）：止损间距自动放宽，避免被正常波动震出
- 低波动股（如大盘蓝筹，ATR/价格<2%）：止损间距自动收窄，提高保护程度

### 5.4 项目中的 ATR 用法汇总

| 用法 | 来源 | 参数 |
|:-----|:-----|:-----|
| 动态止损 | 模拟交易v1.4 2.5节 | 入场景观止损默认用 KeyLevels.StopLoss（不直接用ATR，但后评估用2*ATR模拟） |

## 六、自测题（附答案）

**Q1: MACD 金叉在不同时间框架下（日线 vs 周线）可信度如何变化？**

A: 周线 MACD 金叉可靠性远高于日线。日线金叉一个月可能出现 2-3 次（含假金叉），而周线金叉一年可能只有 2-4 次，每次都具有较强的方向性指引。最佳策略是：周线 MACD 金叉确定中期方向，日线 MACD 金叉确定短期入场时机（多周期共振）。本项目重点股票v2.2 即采用日线+周线+月线三周期同步判断。

---

**Q2: RSI 在 40-55 和 >70 时发出的信号分别意味着什么？**

A:
- RSI 40-55（蓄势区）：买方力量在积蓄但尚未爆发，是最健康的买入区域。此时股价通常处于回调企稳或横盘整理阶段，一旦RSI从这个区间向上突破，意味着新的上涨动能开始释放。每日荐股v2.4 S5中RSI 40-55得3分（满分）。
- RSI > 70（超买区）：股价短期上涨过快，买家力量可能透支，存在回调风险。但需区分场景：如果是突破形态（放量突破+均线多头），RSI>70属于正常现象，不宜简单看空；如果是震荡行情，RSI>70提示减仓。

---

**Q3: ATR=2.5元、入场价50元，2*ATR止损价是多少？止损幅度百分比是多少？**

A:
```
止损价 = 50 - 2 * 2.5 = 45 元
止损幅度 = 2*2.5 / 50 = 5/50 = 10%
```
如果 ATR=5 元（高波动），则止损幅度达到 20%。后评估v1.5设定止损硬上限-8%，所以当 2*ATR 超过 8% 时会触发硬上限，实际止损价 = 50 * 0.92 = 46 元（而不是 40 元）。这个硬上限防止高波动股止损太宽失去保护意义。

---

**Q4: 布林带收窄后放量突破上轨，这说明什么？**

A: 这是一个高质量的技术信号，说明：
1. 带宽收窄 = 市场经过充分的横盘蓄势，波动率降到极低水平
2. 放量突破上轨 = 蓄势后买方力量集中爆发，选择向上突破
3. 放量确认了突破的有效性（缩量突破上轨可能是假突破）
4. 后续大概率走出一波趋势行情而非一日游
5. 操作：突破日或回踩上轨确认时可买入，止损设在突破前的中轨

在每日荐股v2.4 S3量价蓄势中，横盘后放量突破得满分5分。

---

**Q5: 五条均线（MA5/MA10/MA20/MA50/MA120）"多头排列"的具体形态是什么样的？**

A: 多头排列：MA5 > MA10 > MA20 > MA50 > MA120，且五条线全部向上发散。这表明：(1)短期买入者成本 > 中期 > 长期，大家都在赚钱；(2)趋势在不断向上推进；(3)每一轮回调都是均线支撑位。反之，空头排列则是 MA5 < MA10 < MA20 < MA50 < MA120 且全部向下，表明所有持仓者都在被套。
