## 一、因子衰减（青山 Decay）

### 1.1 定义

因子衰减是指一个曾经有效的量化因子，随着时间的推移其预测能力逐步下降直至完全失效的过程。

用一句话说：你发现的赚钱规律，别人也会发现——当足够多的人用同一条规律赚钱时，这条规律就不再能赚钱了。

### 1.2 衰减的三个原因

**原因一：套利者涌入（最核心原因）**

一个因子被公开后，资金会涌入——买入因子看好的股票，卖出因子看空的股票。这些交易行为本身就会推动股价，使因子的超额收益被"套利掉"。这是一个自毁机制：因子越有效，用的人越多，它就越快失效。

**原因二：市场结构变化**

因子有效时的市场环境（交易制度、投资者结构、监管政策、流动性环境）和现在的环境不同了。例如：2015年的杠杆牛市环境与2024年完全不同，当时有效的动量因子现在可能完全失效。

**原因三：数据挖掘偏差（假衰减）**

因子本身就是过拟合的产物——它在历史上从来就没有真正有效过，你看到的"有效"只是碰巧在回测数据上表现好。这不是"衰减"，是"本来就不存在"。区分真衰减和假衰减是量化研究的核心挑战。

### 1.3 衰减的信号

| 信号 | 具体表现 | 监测方法 |
|:-----|:---------|:---------|
| IC持续下降 | 近20日IC均值 < 近60日IC均值 × 0.5 | 滚动IC趋势图 |
| 分组收益单调性消失 | Q5-Q1的多空收益缩水到接近零或变负 | 分组累计收益曲线 |
| 多空收益缩水 | 多空收益从正变负，或从高变低 | 逐日多空收益序列 |
| 因子拥挤 | 最高分组的换手率、估值、波动率异常升高 | 拥挤度指标监控 |

### 1.4 衰减周期（A股经验）

| 因子类型 | 典型衰减周期 | 原因 |
|:---------|:-----------|:-----|
| 量价因子（动量、换手率、波动率） | 6个月-2年 | 容易被套利，竞争激烈 |
| 基本面因子（PE、PB、ROE） | 3-5年 | 基于公司真实盈利能力，衰减慢 |
| 另类因子（舆情、供应链、专利） | 不确定 | 数据获取门槛高，衰减速度取决于数据是否公开 |
| A股短线技术因子 | 1-6个月 | 短线交易者快速发现和套利 |

### 1.5 应对因子衰减的方法

1. **持续监控**：跟踪IC/IR的滚动趋势，而不是只看历史平均值。后评估v1.5的5日滚动Spearman就是为此设计的。
2. **因子轮动**：不押注单一因子。当某个因子IC下降时，降低权重、提升其他因子的权重。
3. **因子创新**：定期搜索新的候选因子。后评估v1.5 §七(四)的月度外部知识融合机制即服务于这一目的。
4. **路径优选**：不同因子的衰减速度在不同市场场景下不同——牛市里动量因子衰减慢，熊市里质量因子衰减慢。按市场状态动态切换因子权重可以延缓衰减（见文件12-路径优选与市场状态自适应.md）。

## 二、因子拥挤（Crowding）

### 2.1 定义

因子拥挤是指过多资金追逐同一因子的同一组股票，导致：
- 因子看好的股票被过度买入，价格远高于合理价值
- 一旦有任何风吹草动，拥挤的资金同时撤离，引发踩踏式下跌
- 因子的正常回撤被放大为踩踏——极端情况下单日跌幅远超历史任何回撤

### 2.2 拥挤的四个预警信号

| 信号 | 指标 | 阈值 |
|:-----|:-----|:-----|
| 换手率异常升高 | 因子最高分组的平均换手率 | 超过历史80分位 |
| 估值飙升 | 因子最高分组的PE/PB中位数 | 超过历史90分位 |
| 波动率异常 | 因子最高分组的日波动率 | 超过历史90分位 |
| 回撤异常 | 单日回撤幅度 | 超过历史最大回撤的1.5倍 |

### 2.3 项目中的拥挤度预警机制（后评估v1.5 §四(二)）

v1.5将拥挤度预警从固定阈值升级为动态分位阈值：

| 阈值类型 | 条件 |
|:---------|:-----|
| 动态分位阈值 | 换手率 > 该股票自身20日分位的80%值 **且** 量比 > 1.5 |
| 或 | 换手率 > 推荐池80分位值 **且** 量比 > 推荐池80分位值 |

触发拥挤预警的股票中，次日跌>2%的比例应 ≥ 60%（目标值）。

### 2.4 量比惩罚阈值（大盘自适应）

| 大盘状态 | 量比惩罚阈值 |
|:---------|:-----------:|
| 强势市场（全市场等权涨幅 > +2%） | > 15 |
| 正常市场（-2% ~ +2%） | > 12 |
| 弱势市场（< -2%） | > 8 |

注意弱势市场中量比阈值明显收紧——因为在下跌市场中，放量往往是出货信号，需要更早预警。

### 2.5 拥挤的外部研究支撑

后评估v1.5 §七(四)引用了衡泰xCN4（2026）的拥挤度因子研究：换手率分位+成交量分位联合判断对短线回调有显著预测力，加入多因子模型后IC提升约15%。这为项目的拥挤度预警提供了外部验证。

## 三、过拟合（Overfitting）

### 3.1 核心定义

过拟合是指模型在历史数据（训练集）上表现极好，但在未来数据（测试集/实盘）上表现差。在金融中的表现尤为危险：你找到了一个在历史上稳赚不赔的策略，欣喜若狂地投入实盘——然后开始持续亏损。

**在量化金融领域，过拟合是比"找不到因子"更大的陷阱。** 找不到因子，你不会亏钱。找到了假的因子，你会带着信心亏钱——而且是加倍亏。

### 3.2 过拟合的常见原因

**原因一：参数太多，样本太少**

经典的"自由度"问题。如果你有100个参数但只有50个观测值，你几乎一定能"拟合"出任何你想要的结果——但那只是巧合。量化金融中，常见的是用5年的日线数据（约1200个交易日）测试一个包含20个参数的策略——看似样本量大，但参数/样本比仍然危险。

**项目的参数情况**：评分体系包含6个维度、每个维度3-8个评分子项、多个否决阈值、豁免条件——参数总量约30-40个。日线数据累积约20个交易日（项目运行时间）。参数/样本比严重失衡。

**原因二：多次尝试不同参数（多重比较）**

你测试了100组不同的参数组合，选出了表现最好的一组。但"100组中最好的"与"真正有效的"完全是两码事——即使所有100组参数都是随机噪声，也会有一组"碰巧"在回测中最优。

这被称为"数据窥探偏差"（Data Snooping Bias）或"p-hacking"：你不停地试，直到找到"显著"的结果，但显著性是假的。

**原因三：生存者偏差**

只用了现在还活着的股票做回测。那些退市的、破产的、被收购的股票不在你的数据里。这意味着你的"历史表现"被系统性高估了——因为"失败者"已经被从历史数据中移除。

项目的股票池（6只重点股票 + 动态池约80-120只）目前不存在严重的生存者偏差（跟踪的是当前在市的股票），但未来扩展到更长时间的回测时需要注意这一点。

### 3.3 过拟合的红色警报信号

| 信号 | 说明 |
|:-----|:-----|
| 样本内夏普 > 3.0 | 几乎可以确定存在过拟合或未来函数 |
| 样本外/样本内表现比 < 0.5 | 样本外表现不到样本内的一半 |
| 参数敏感性极高 | 参数微调（如阈值从0.80改为0.81）导致结果完全不同 |
| 最优参数在所有参数的极端值上 | 最优结果出现在参数的边界上（如PE阈值=最大值300）——说明你不是在找最优，是在"拟合" |
| 去掉任何一个因子后结果暴跌 | 模型稳定性差，可能过度依赖某个特定因子 |
| 反向因子也"有效" | 如果用因子值的负数，回测结果也很好——说明纯属巧合 |

## 四、防范过拟合的方法

### 4.1 Walk-forward（前向验证）

这是时间序列数据防过拟合的**最重要方法**。

```
传统交叉验证（错误！）：
训练: [2020年, 2022年, 2021年]  ← 随机打乱，不保持时间顺序
测试: [2021年, 2019年, 2023年]

Walk-forward（正确）：
训练: [2020年1月-6月] → 测试: [2020年7月]
训练: [2020年1月-7月] → 测试: [2020年8月]
训练: [2020年1月-8月] → 测试: [2020年9月]
...
```

Walk-forward的核心原则：**只能用"预测日之前"的数据训练，用"预测日当天"的数据验证。** 绝对不能用未来数据来训练——这是时间序列预测的铁律。

### 4.2 样本外测试（Train/Validation/Test 分割）

时间序列的正确分割方式：

```
├── 训练集（70%）：最早的一段时间，用于拟合模型参数
├── 验证集（15%）：训练集之后的一段时间，用于选择超参数
└── 测试集（15%）：最近的一段时间，用于最终评估——只能用一次！
```

**关键原则**：测试集只能使用一次。如果测试完后发现结果不好，回去调参数再测试，那么测试集就变成了"第二个验证集"——失去了样本外验证的意义。

### 4.3 Purging + Embargo（清除 + 禁运）

这是Marcos Lopez de Prado在《Advances in Financial Machine Learning》中提出的方法：

- **Purging（清除）**：从训练集中删除与测试集有时间重叠的样本。例如，如果训练样本的标签（T+1收益）与测试样本的输入（T日因子值）有重叠，必须清除。
- **Embargo（禁运）**：在训练集和测试集之间留出一段"禁运期"，完全不用这段时间的数据。这防止了"测试集的信号通过标签泄露到训练集中"。

对于T+1日线策略，至少需要1日的禁运期。

### 4.4 参数数量控制

经验法则：
```
参数数量 < 样本量 / 10
```

对于一个运行了20个交易日的策略，最多只能有2个参数。项目当前约30-40个参数——这在统计上是极度危险的。

**但这不是说必须减少参数**——业务上确实需要这些参数。关键是**意识到风险**：
- 当前的参数值很大程度上是"拍脑袋"（或基于有限数据的经验判断），而非统计优化
- 需要积累更多数据（至少60个交易日）后才有可能进行参数优化
- 任何参数调整都必须通过Walk-forward验证

### 4.5 最简单的过拟合检验：反转因子方向

将因子的符号反转（取负号），用同样的方法回测。如果反向因子也表现良好，几乎100%是过拟合——因为一个真正有预测力的因子，反向应该是表现差，而不是表现好。

## 五、项目中的过拟合风险分析

### 5.1 当前风险等级：高

| 风险维度 | 现状 | 风险等级 |
|:---------|:-----|:-------:|
| 参数/样本比 | 约30-40个参数 vs 约20个交易日 | **极高** |
| 样本外观测 | 仅v1.5一次后评估（首次实战回检） | **不足** |
| 参数敏感性 | 权重调整（20→15）对结果影响显著 | **高** |
| Walk-forward验证 | 未执行 | **缺失** |
| 反转检验 | 未执行 | **缺失** |

### 5.2 v2.4权重调整是否有过拟合风险？

v2.4的权重调整（基本面20→15、技术面25→30、消息面20→15）依据的是v1.5后评估的Spearman相关系数计算。

**有过拟合风险，但风险可控。** 原因是：

1. **调整方向是合理的**：Spearman负相关的维度降低权重、正相关的升高权重——这在逻辑上自洽。
2. **但Spearman本身是用样本内数据算的**：v1.5的Spearman计算使用的是"v2.4调整前"的20个交易日数据。调整后的v2.4在这个数据上的表现只会更好——这是必然的，因为你是根据这个数据的结论去调的。
3. **真正的考验是调整后新数据的表现**：如果调整后Spearman改善，说明调整有效；如果调整后Spearman仍然为负，说明问题不在权重而在评分逻辑本身。

**结论**：此次权重调整需要在新数据上验证（至少再跑5-10个交易日），如果Spearman仍然为负，应立即触发维度重构而非继续微调参数。——反复微调参数本身就是过拟合的典型症状。

### 5.3 灰度测试——项目当前的防过拟合屏障

后评估v1.5 §五(四)的灰度测试规则是目前唯一在运行的防过拟合机制：

```
新旧规则并行5个交易日 → 新规则胜率 ≥ 旧规则+5% → 切换
```

灰度测试的优势在于：它在新数据上验证（而不是在调整参数时用的旧数据上验证），提供了一个真正的"迷你样本外测试"。

但灰度测试的局限也很明显：
- 5个交易日的数据量太少，统计上不够显著
- 如果市场在这5天里恰好处在某个特定状态（如强势上涨），测试结果可能不代表一般情况
- 灰度测试不能替代系统性的Walk-forward回测

### 5.4 自动化回测引擎——未来的防线

后评估v1.5 §五(五)设计了自动化回测引擎，核心流程：

```
加载历史数据（近30/60/90日） → 模拟新参数 → 新参数胜率 ≥ 旧参数+3% → 建议采纳
```

关键设计亮点：每次参数修改前都必须有对应的回测记录证明新参数更优。这比"我感觉这个参数应该好"强100倍。

但当前自动化回测引擎尚未实装（数据积累不足是主要原因——至少需要30个交易日的数据才能做有意义的回测）。

## 七、自测题

**题1**：为什么说"找到了反向因子"比"找不到因子"更可怕？

**答案**：这是两个不同层面的问题。"找不到因子"只是找不到能预测的指标，你不会基于它来做决策——结果是错过机会，但不亏钱。"找到了反向因子"的危险在于：你基于一个反向的因子做了正向的决策——因子告诉你"这只股票好"，实际上它应该告诉你"这只股票差"。你会带着信心持续做错误决策，不断加仓亏损。项目的Spearman=-0.436就是在警告：当前评分告诉你的方向，和实际方向是反的。这就是为什么发现负相关后要立即暂停排查（后评估v1.5 §三(三)：ρ<0→"立即暂停排查"）。

**题2**：Walk-forward验证和普通的交叉验证有什么本质区别？

**答案**：普通的K-fold交叉验证会随机打乱数据——时间顺序被破坏了。在金融预测中，这会让你用"未来的信息"去预测"过去"（信息泄露）。Walk-forward严格保持时间顺序：只使用预测日之前的数据训练，在预测日上验证。这模拟了真实交易中的信息约束——你在今天收盘时做决策，只能用今天之前的数据。如果你的模型能在严格的Walk-forward验证中表现好，它才可能在实盘中表现好。一句话：K-fold是"我知道明天会发生什么"的作弊模式，Walk-forward是"我什么都不知道"的真实模式。

**题3**：项目的权重调整（基本面20→15）有没有过拟合风险？如何验证？

**答案**：有过拟合风险。因为调整依据（Spearman=-0.182）是用样本内数据计算的——你根据数据A的结论去调整参数，数据A上当然会表现更好。这不一定说明参数真地变好了。验证方法：（1）观察调整后新5-10个交易日的基本面Spearman是否改善（最直接）；（2）Walk-forward回测：用调整前的数据评估、调整后的数据验证——如果调整后在真正的新数据上基本面Spearman从-0.182改善到正数，说明调整有效；（3）反转检验：如果把基本面权重从20→15改为20→25（反方向调整），是否也会在某些数据段上"表现更好"？如果是，说明权重变化本身不重要——任何调整都可能"碰巧"在某个数据段表现好，这是过拟合的证据。最严谨的验证是：在新数据上积累至少30个交易日后，重新计算各维度的Spearman。如果技术面仍然唯一正相关、基本面仍然负相关，说明问题不在权重而在评分逻辑本身——此时应触发维度重构而非继续微调参数。
