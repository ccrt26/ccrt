## 一、T+1交割制度

### 核心概念

A股实行**T+1**交割制度：当天买入的股票，最早**下一个交易日才能卖出**。这与美股/港股等T+0市场有本质区别。

### 实际影响

- 短线投资者无法在同一天内完成"买入-卖出"闭环
- 当日买入后发现行情逆转，无法立即止损
- 资金使用效率低于T+0市场
- 隔夜风险无法规避（买入后到次日开盘期间的利空消息无法通过卖出应对）

### 项目对接

- **模拟交易v1.4 开仓条件表**（白皮书 2.1节）：昨日开仓的股票当日才能卖出，新开仓的股票必须持仓到次日
- **模拟交易v1.4 出场检查**（白皮书 2.5节）：每次引擎运行时先检查已有持仓的出场条件，再检查开仓条件，顺序不可颠倒

## 二、交易时段与集合竞价

### 2.1 集合竞价（9:15 -- 9:25）

| 时段 | 可申报 | 可撤单 | 说明 |
|:-----|:------:|:-----:|:-----|
| 9:15 -- 9:20 | 是 | **是** | 虚假申报高发期，大单虚挂后撤单 |
| 9:20 -- 9:25 | 是 | **否** | 申报不可撤销，价格反映真实买卖意愿 |
| 9:25 | -- | -- | **产生开盘价**（最大成交量原则） |

**开盘价确定原则**：在满足成交量最大的价位上，高于该价位的买单全部成交、低于该价位的卖单全部成交。若多个价位满足则取中间价。

**深市尾盘集合竞价**：14:57 -- 15:00，成交量纳入集合竞价撮合（深市特有，沪市为连续竞价至15:00）。

### 2.2 连续竞价（9:30 -- 11:30, 13:00 -- 15:00）

正常交易时段，按价格优先、时间优先原则连续撮合。

### 项目对接

- **模拟交易v1.4 引擎运行时序**（白皮书 2.4.2节）：
  - T+1日 09:35 运行引擎（集合竞价结束5分钟后，确保开盘价已稳定）
  - 入场价格优先使用**开盘价**（腾讯API parts[5]）
  - 超过 09:45 未运行则当日跳过开新仓，仅执行止损检查（用最新价代替开盘价）

## 三、涨跌停制度

### 3.1 各板块涨跌幅限制

| 板块 | 涨跌幅限制 | 说明 |
|:-----|:--------:|:-----|
| 主板 | +/-10% | 上海/深圳主板普通股 |
| ST / *ST | +/-5% | 风险警示板（含主板和科创板ST） |
| 科创板 | +/-20% | 688开头 |
| 创业板 | +/-20% | 300开头（2020年8月改革后） |
| 北交所 | +/-30% | 8/4开头 |
| 新股上市前5日 | 不设限制 | 仅限注册制下新股 |

### 3.2 涨跌停价计算

```
涨停价 = 前收盘价 * (1 + 涨跌幅限制比例)
跌停价 = 前收盘价 * (1 - 涨跌幅限制比例)
```

结果**四舍五入至 0.01 元**（分）。计算时必须用前收盘价而非当日开盘价。

主板 10% 涨停计算示例：前收盘 10.05 元 -> 涨停价 = 10.05 * 1.10 = 11.055，四舍五入得 11.06 元。

### 3.3 为什么涨停阈值是 9.4% 而不是 10%？

原因有三：
1. **四舍五入误差**：有的股票实际涨停价经四舍五入后不到 10%（如前收盘 3.67 元 -> 涨停价 4.04 元，涨幅实际为 10.08%，但反向计算时 4.04/3.67-1=10.08%）
2. **盘中触及涨停后回落**：开盘价涨幅可能在 9.5%-9.9% 之间，但尚未封死涨停
3. **留出安全边际**：9.4% 作为阈值可以覆盖绝大多数涨停场景且不误触发

### 项目对接

- **模拟交易v1.4 6.1.1 涨停不开仓**（白皮书）：当日开盘涨跌幅 >= 9.4%，跳过该股开仓，日志记录"涨停，跳过"
- **模拟交易v1.4 6.1.2 跌停不卖出**（白皮书）：触发止损但涨跌幅 <= -9.4% 时，标记"未成交"，持续跟踪至恢复流动性
- **每日荐股v2.4 V0否决**（白皮书 第十五条）：ST/*ST股票名称含"ST"即触发绝对否决，不参与评分

## 四、交易费用精确计算

### 4.1 费率标准

| 费用类型 | 费率 | 收取方向 | 说明 |
|:--------|:----:|:-------:|:-----|
| 佣金 | 万分之2.5 | 买卖双向 | 按成交金额计算，最低5元/笔 |
| 印花税 | 千分之1 | **仅卖出** | 由国家税务局征收 |
| 过户费 | 万分之0.2 | 买卖双向 | 2022年4月起由0.025‰降至0.02‰ |

### 4.2 计算公式

**买入总成本**：
```
成交金额 = 成交价 * 买入股数
佣金 = max(成交金额 * 0.00025, 5元)
过户费 = 成交金额 * 0.00002
总成本 = 成交金额 + 佣金 + 过户费
```

**卖出净收入**：
```
成交金额 = 成交价 * 卖出股数
佣金 = max(成交金额 * 0.00025, 5元)
印花税 = 成交金额 * 0.001
过户费 = 成交金额 * 0.00002
净收入 = 成交金额 - 佣金 - 印花税 - 过户费
```

### 4.3 最低佣金规则（关键门槛）

佣金不足 5 元时按 5 元收取。因此存在一个**最低成本交易金额**：
```
盈亏平衡股数 ≈ 5 / (0.00025 * 股价)  的整数倍
```
当 `成交金额 * 0.00025 < 5` 时，佣金固定为 5 元。这意味着：

- 小额交易的实际费率远高于万2.5
- 成交金额 2 万元时佣金恰好为 5 元（盈亏平衡点）
- 低于 2 万元的交易佣金被"惩罚性"收取

### 4.4 费用对短线交易的侵蚀

假设每日买入卖出一次：
- 一年约 242 个交易日
- 单边费率（佣金+过户费）：约 0.027%
- 双边费率（买卖双向）：约 0.054%
- 加上卖出印花税 0.1%：单次完整交易成本约 **0.154%**
- 年化交易成本（如果每天换手）：约 **37%**

结论：高频换手在A股制度下极难盈利。

### 项目对接

- **模拟交易v1.4 2.6交易费用**（白皮书）：佣金万2.5 + 印花税千1（仅卖出）+ 最低佣金5元，引擎完整实现了费用计算
- **模拟交易v1.4 2.4入场滑点**（白皮书）：入场价 * (1 + 0.1%) 作为滑点
- **模拟交易v1.4 2.3 AvgCost含佣金**（白皮书 3.2.1节）：positions.json 中 AvgCost 字段为含佣金成本

## 五、除权除息

### 5.1 基本类型

| 类型 | 标记 | 含义 | 示例 |
|:-----|:----:|:-----|:-----|
| XR | Ex-Right | 除权（现金分红） | 每10股派3元 -> 除权后价格下降0.3元 |
| XD | Ex-Dividend | 除息（送转股） | 每10股送5股 -> 股数变为1.5倍，价格相应调整 |
| DR | 同时除权除息 | 既有现金分红又有送转股 |

### 5.2 除权参考价公式

**仅现金分红**：
```
除权参考价 = 前收盘价 - 每股分红金额
```

**仅送转股**：
```
除权参考价 = 前收盘价 / (1 + 送股比例)
```
例如 10 送 5：送股比例 = 0.5，除权参考价 = 前收盘价 / 1.5。

**同时现金+送股**：
```
除权参考价 = (前收盘价 - 每股分红) / (1 + 送股比例)
```

### 5.3 除权除息时间线

```
T日（股权登记日）：收盘时持有股票的股东享有分红权益
T+1日（除权除息日）：股价按除权参考价开盘，分红权益消失
通常1个月内：现金分红到账；送转股到账
```

**重要**：买入股票后T+1才能卖出，如果T日是股权登记日当天买入，T+1日卖出时可以参与分红（但股价已除权，等于左口袋进右口袋，且持有一天交20%红利税）。

### 5.4 Ratio调整因子

```
Ratio = 除权后开盘价 / 除权前收盘价
```

Ratio 反映了除权对股价的缩放比例。例如：
- 前收盘 100 元，每 10 股派 2 元 -> 除权参考价 98 元 -> Ratio = 0.98
- 前收盘 100 元，每 10 股送 5 股 -> 除权参考价 66.67 元 -> Ratio = 0.6667

**关键洞察**：用 Ratio 等比调整（乘法）而非简单减法调整关键价位，是因为送转股改变了股本数量，所有价格相关指标都应等比缩放。

### 项目对接

- **模拟交易v1.4 6.2除权除息处理**（白皮书）：使用 Ratio 因子等比调整 StopLoss/Support/Resistance
  - 公式：调整后 KeyLevel = KeyLevel * Ratio
  - 配置：ex_dividend_dates.json 记录各除权日的 Ratio 值
  - 触发：引擎每日运行时检查当日是否有除权除息
- **模拟交易v1.4 8.2已知限制**（白皮书）：除权除息依赖人工配置 ex_dividend_dates.json，漏配会导致止损价永久高于现价

## 八、自测题（附答案）

**Q1: 为什么项目的涨停阈值是 9.4% 而不是 10%？**

A: 三个原因：(1) 四舍五入导致的误差，某些股票涨停价经四舍五入后实际涨幅不到 10%；(2) 盘中可能触及涨停后回落，开盘价涨幅在 9.5%-9.9% 之间但未封板；(3) 9.4% 提供安全边际，避免边界值误判。在模拟交易v1.4中，此阈值用于两条规则：涨停不开仓（检测 >= 9.4%）和跌停不卖出（检测 <= -9.4%）。

---

**Q2: 买入 1000 股 * 50 元，计算含佣金的总成本（佣金万2.5，最低5元）。**

A:
```
成交金额 = 1000 * 50 = 50,000 元
佣金 = max(50000 * 0.00025, 5) = max(12.5, 5) = 12.5 元
过户费 = 50000 * 0.00002 = 1 元
总成本 = 50000 + 12.5 + 1 = 50,013.5 元
实际买入均价 = 50013.5 / 1000 = 50.0135 元
```
若股数为 100 股（5000 元成交额）：
```
佣金 = max(5000 * 0.00025, 5) = max(1.25, 5) = 5 元
实际佣金率 = 5/5000 = 0.1% = 千1，远高于名义万2.5
```

---

**Q3: 除权除息后止损价如何调整？为什么用 Ratio 而不是简单减法？**

A: 止损价调整 = StopLoss * Ratio，其中 Ratio = 除权后开盘价 / 除权前收盘价。使用乘法而非减法的原因：(1) 送转股改变了股本数量，所有价格指标应等比缩放而非等量偏移；(2) 如果按现金分红金额直接减去，送转股场景下公式不正确（前收盘 100 元，10送5，除权参考价 66.67 元，等价于价格打 6.67 折，止损应从 90 调整到 60，而不是 90-33.33=56.67）；(3) Ratio 方法统一处理现金分红和送转股两种情况。此逻辑详见模拟交易v1.4 第6.2节。

---

**Q4: 交易费用对短线策略的侵蚀有多大？**

A: 单次完整买卖成本约 0.154%（佣金万2.5双向+印花税千1卖出+过户费万0.2双向）。如果每天换手一次，全年 242 个交易日则年化成本约 37%。这意味着短线策略必须实现年化 37% 以上的超额收益才能覆盖交易成本。小资金（单笔成交额<2万元）因最低佣金 5 元规则的惩罚效应，实际成本更高。
