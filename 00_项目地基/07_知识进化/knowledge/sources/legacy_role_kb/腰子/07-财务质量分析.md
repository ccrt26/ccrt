## 一、三大报表核心指标

### 1.1 利润表：从营收到底层利润

利润表回答"公司赚了多少钱"，但不是看最后一行就够了。每一行都要看：

```
营业收入
  - 营业成本
  = 毛利润 → 毛利率 = 毛利润/营收 （越高越好，反映产品竞争力）
  - 销售费用
  - 管理费用
  - 研发费用
  = 营业利润 → 营业利润率 = 营业利润/营收 （越高越好，反映经营效率）
  + 营业外收入
  - 营业外支出
  = 利润总额
  - 所得税
  = 净利润 → 净利率 = 净利润/营收 （越高越好，反映最终盈利能力）
```

**三费占比：**

```
三费占比 = (销售费用 + 管理费用 + 研发费用) / 营业收入
```

三费占比越低越好，但需要结合行业特性：
- 消费品：销售费用占比可能很高（广告投放），15%-30%正常
- 科技：研发费用占比高，10%-25%正常
- 制造：管理费用为主，5%-10%正常

**警惕信号：** 三费占比持续上升而营收增速下降 → 公司花了更多钱却换不来增长，产品竞争力可能下降。

### 1.2 资产负债表：公司的"骨架"

```
资产 = 负债 + 所有者权益
```

**关键比率：**

#### 资产负债率
```
资产负债率 = 总负债 / 总资产
```

| 行业 | 合理区间 | 危险线 |
|:----|:-------|:-----|
| 银行 | 90%-93% | 正常（银行是高杠杆经营模式） |
| 地产 | 70%-85% | >90%（恒大模式） |
| 制造业 | 30%-50% | >70% |
| 消费 | 20%-40% | >50% |
| 科技 | 15%-35% | >50% |

**项目对接：** 每日荐股v2.4 V6绝对否决预留：资产负债率>70% → 否决（当前为预留状态）。

#### 流动比率
```
流动比率 = 流动资产 / 流动负债
```

| 流动比率 | 含义 |
|:------:|:-----|
| >2 | 短期偿债能力充足 |
| 1-2 | 正常区间 |
| <1 | 短期偿债风险——流动资产不足以覆盖一年内到期的负债 |
| <0.5 | 极度危险——公司可能在短期内面临流动性危机 |

#### 商誉/净资产

```
商誉占比 = 商誉 / 净资产
```

商誉是并购中"买贵了"的部分——支付对价超过标的公司净资产公允价值的部分。

| 商誉占比 | 含义 |
|:------:|:-----|
| <10% | 安全，并购规模合理 |
| 10%-30% | 关注区，需关注并购标的经营情况 |
| 30%-50% | 高风险区，一旦并购标的业绩不达标将计提巨额减值 |
| >50% | 商誉减值炸弹——暴雷只是时间问题 |

**典型案例：** 某公司商誉/净资产=80%，当年计提商誉减值50亿，净利润从盈利30亿变为亏损20亿。商誉减值一旦发生，是不可逆的（无法恢复）。

### 1.3 现金流量表：利润的"测谎仪"

现金流量表分为三类现金流：

| 类型 | 含义 | 健康的公司表现 |
|:----|:-----|:------------|
| **经营现金流** | 卖产品/服务收到的现金 - 付出去的现金 | 正数、且 > 净利润 |
| **投资现金流** | 买设备/建厂/并购的净支出 | 通常为负数（在扩张） |
| **筹资现金流** | 借钱/还钱/分红/增发的净额 | 波动，成熟期可能为负（分红+还债） |

**最核心指标：经营现金流/净利润**

```
经营现金流/净利润 > 1：利润有真金白银支撑，利润质量高
经营现金流/净利润 0.5-1：部分利润对应的是应收账款，质量一般
经营现金流/净利润 < 0.5：利润可能虚增，存在美化报表嫌疑
经营现金流/净利润 < 0：极其危险的信号——赚了纸上利润但现金在流失
```

**为什么经营现金流>净利润如此重要？**

净利润可以通过会计手段调节（改变折旧方式、调整收入确认时点、变更坏账计提比例）。但经营现金流是银行账户里真实的现金流入流出，造假难度远大于利润造假。

**自由现金流：**

```
自由现金流 = 经营现金流 - 资本开支
```

自由现金流是公司在维持现有经营规模后，能自由支配的现金。这是DCF估值的核心输入，也是判断公司分红能力的关键。

## 二、盈利质量检查清单

以下检查清单应该逐项核对。每有一项不满足，就削弱一分对利润质量的信心。

### 2.1 八项核心检查

| # | 检查项 | 标准 | 不满足的含义 |
|:--:|:------|:-----|:----------|
| 1 | **经营现金流净额 > 净利润** | >1.0 | 利润没有现金支撑，可能是纸面利润 |
| 2 | **应收账款增速 <= 营收增速** | 应收不跑赢营收 | 通过放宽信用政策（赊销）拉营收，应收账款膨胀=未来坏账 |
| 3 | **存货增速 <= 营收增速** | 存货不跑赢营收 | 产品卖不出去，积压在库房里。存货跌价风险增大 |
| 4 | **商誉/净资产 < 30%** | <30% | 并购买了太多溢价，减值炸弹可能随时引爆 |
| 5 | **扣非净利润 ≈ 归母净利润** | 偏差<10% | 公司利润靠非经常性损益（卖资产、政府补贴）撑场面，主营业务不赚钱 |
| 6 | **研发费用资本化比例正常** | 不异常高 | 把研发支出计入资产（而不是费用），可以美化当期利润。但这是合法的"调节" |
| 7 | **前五大客户集中度** | 单客户<50% | 过度依赖单一客户，一旦客户出问题（或大客户压价），利润崩盘 |
| 8 | **关联交易占比** | 不异常高 | 通过关联交易转移利润或虚增收入 |

### 2.2 每一项的深入解读

#### 检查2：应收账款增速 vs 营收增速

**典型案例：**
- 公司A：营收增长30%，应收账款增长15%，收入质量健康
- 公司B：营收增长30%，应收账款增长80%，收入质量存疑

公司B的情况意味着：为了维持30%的营收增长，不得不大幅放宽客户付款条件（多赊账）。这种增长不可持续，而且多出来的应收账款中必然有一部分会成为坏账。

#### 检查4：商誉/净资产

**商誉减值的触发条件：** 被收购的公司业绩不达预期 → 需要计算商誉的可回收金额 → 如果可回收<账面值 → 计提减值 → 当期利润直接扣减，不可转回。

**高危特征：** 对赌期（业绩承诺期）刚过 → 业绩瞬间"变脸" → 商誉减值暴雷。要特别关注并购 3 年后的公司（对赌期通常是3年）。

#### 检查5：扣非净利润 vs 归母净利润

**扣非净利润** = 归母净利润 - 非经常性损益（政府补贴、资产处置收益、投资收益等）

如果扣非净利润远低于归母净利润，说明利润来自"卖资产、拿补贴"这种一次性收益。这种利润不可持续。

## 三、ROE杜邦分解——盈利能力的三棱镜

### 3.1 基础公式

```
ROE = 净利润 / 净资产
```

ROE是衡量"股东每投入1元赚了多少钱"的核心指标。

| ROE | 评级 |
|:---:|:----:|
| >20% | 非常好 |
| 15%-20% | 优秀 |
| 10%-15% | 合格 |
| 5%-10% | 差 |
| <5% | 极差（不如存银行） |

### 3.2 杜邦分解

ROE看起来只是一个数字，但杜邦分析将其拆解为三个独立维度：

```
ROE = 净利率 × 资产周转率 × 权益乘数

即：
ROE = (净利润/营收) × (营收/总资产) × (总资产/净资产)
```

三个因子分别代表三种赚钱模式：

| 模式 | 核心因子 | 代表公司 | 特征 | 风险 |
|:----|:--------|:--------|:-----|:-----|
| **茅台模式** | 高净利率（>30%） | 贵州茅台、恒瑞医药 | 产品有定价权，盈利能力强 | 品牌受损或定价权丧失 |
| **沃尔玛模式** | 高资产周转率（>1.5x） | 美的集团、顺丰控股 | 薄利多销，运营效率高 | 规模瓶颈、竞争加剧 |
| **银行模式** | 高权益乘数（>10x） | 招商银行、工商银行 | 高杠杆撬动收益 | 风险最大——坏账、挤兑 |

### 3.3 杜邦分解的实战意义

**案例对比：**

| 公司 | ROE | 净利率 | 资产周转率 | 权益乘数 | 分析 |
|:----|:---:|:-----:|:--------:|:------:|:-----|
| 公司A | 25% | 3% | 2.5x | 3.3x | 低利润+高周转+中杠杆。薄利多销模式。 |
| 公司B | 25% | 50% | 0.4x | 1.25x | 高利润+低周转+低杠杆。高端品牌模式。 |
| 公司C | 25% | 8% | 0.6x | 5.2x | 中利润+低周转+高杠杆。危险的ROE——靠借钱撑起来。 |

三家公司ROE都是25%，但赚钱方式完全不同。公司A和B的ROE相对健康，公司C的ROE（高杠杆）在高利率环境下或在信贷紧缩时最为脆弱。

### 3.4 ROE趋势比绝对值更重要

"ROE=20%但每年下降2%" vs "ROE=12%但每年上升2%"——后者往往被低估，前者往往被高估。

ROE趋势反映了公司的竞争地位是改善还是恶化。一个改善中的ROE（即使绝对值不高）意味着公司正在变好，市场最终会给以更高的估值。

## 四、财务造假预警信号

财务造假在A股并不罕见。以下预警信号越多个同时出现，造假概率越高。

### 4.1 七大预警信号

| 信号 | 详细说明 | 严重程度 |
|:----|:--------|:------:|
| 经营现金流长期远低于净利润 | 连续3年以上的经营现金流/净利润<0.5，最可靠的造假信号 | **极高危** |
| 应收账款增速持续大幅高于营收增速 | 连续2年以上应收增速>营收增速20个百分点以上 | **高危** |
| 存货异常增长而营收不增长 | 存货涨、营收不涨=产品滞销但公司不承认，虚增存货价值 | **高危** |
| 频繁变更会计师事务所 | 审计机构发现了问题，公司换一家"好说话"的 | **中高危** |
| 大股东高比例质押+减持 | 大股东用股票抵押借钱+不断卖出=大股东自己都不看好 | **高危** |
| 商誉占比过高+业绩承诺期刚过 | 并购"买买买"后业绩变脸，商誉需要减值但公司拖着不减 | **高危** |
| 毛利率显著高于同行业且无合理解释 | 同样做火锅底料的，你比海底捞还赚钱？异常高毛利必有鬼 | **中高危** |

### 4.2 经典造假路径

A股典型的财务造假三步走：

```
第一步：虚增收入（通过关联交易、虚假客户）
第二步：虚增利润（收入上去了，利润自然"来"了）
第三步：虚增资产（利润不能只是数字，需要"配套"资产——存货、在建工程、商誉）

现金流量表是最难造假的一张表——因为需要真金白银的银行流水配合。
经营现金流/净利润的背离是发现造假的最可靠线索。
```

### 4.3 造假公司的共同特征

- 注册地偏远（监管力度弱）
- 审计师为小型事务所（审计质量低）
- 近年频繁并购
- 毛利率远高于同行业
- 大股东高比例质押

## 五、行业特化财务指标

同一套指标在不同行业中含义完全不同。

### 5.1 银行

| 指标 | 含义 | 健康标准 |
|:----|:-----|:-------|
| **拨备覆盖率** | 贷款损失准备金/不良贷款 | >150%（越高越安全） |
| **净息差** | 贷款收益 - 存款成本 | >2%（过低则盈利能力差） |
| **不良贷款率** | 不良贷款/总贷款 | <1.5%（过高则资产质量差） |
| **资本充足率** | 资本/风险加权资产 | >10.5%（监管红线） |

### 5.2 科技

| 指标 | 含义 | 健康标准 |
|:----|:-----|:-------|
| **研发投入占比** | 研发费用/营收 | >10%（投入太少则无竞争力） |
| **研发费用率变化** | 研发投入是持续加大还是缩减 | 稳定上升最好 |
| **专利数量与质量** | 发明专利 vs 实用新型 | 发明专利价值更高 |
| **人均创收** | 营收/员工数 | 越高越好，反映人效 |

### 5.3 消费

| 指标 | 含义 | 健康标准 |
|:----|:-----|:-------|
| **存货周转天数** | 存货平均放在库房多少天 | 越低越好（白酒除外，老酒有价值） |
| **应收账款周转天数** | 客户平均多久付款 | 越低越好 |
| **预收账款(合同负债)变化** | 客户提前付了多少钱 | 增长=产品紧俏，下降=需求变弱 |
| **销售费用率** | 销售费用/营收 | 品牌力越强，这个比率越低 |

### 5.4 制造

| 指标 | 含义 | 健康标准 |
|:----|:-----|:-------|
| **产能利用率** | 实际产量/设计产能 | >80%（低则固定资产闲置） |
| **固定资产周转率** | 营收/固定资产 | 越高越好，反映设备利用效率 |
| **资本开支/折旧** | 再投资 vs 维护 | >1=在扩张，<1=在收缩 |
| **毛利率** | 产品竞争力 | >20%合格，>30%优秀 |

## 六、常见误区

| 误区 | 正解 |
|:-----|:-----|
| "净利润增长快就是好公司" | 需要看利润质量。经营现金流跟不上净利润的增长，说明利润是纸面上的。 |
| "ROE高就是好" | ROE=25%如果来自高杠杆（权益乘数5x+），风险巨大。高ROE必须结合杜邦分解判断。 |
| "资产负债率高=危险" | 行业不同标准不同。银行90%正常，制造业70%危险。需要行业对比。 |
| "毛利率高=护城河深" | 毛利率高但费用率也高，最终净利率很低——这不是护城河，是行业特性。护城河体现在"高毛利率+低费用率"的组合。 |
| "流动比率<1一定危险" | 餐饮/超市等现金流好的行业，流动比率<1可能是正常的（每天收现金、快速周转）。关键是看"现金循环周期"。 |
| "看财报就能发现所有问题" | 财报只是历史记录。最大的风险（商业模式颠覆、技术替代、政策变化）在财报公布之前就已经发生了。 |

## 七、自测题

### 题目1：为什么经营现金流/净利润是最重要的财务质量指标？

**答案：**

这是财务分析中最"诚实"的一个指标，原因有三：

1. **利润可以"做"出来，现金流很难"做"出来。** 净利润可以通过收入确认时点的选择、折旧方式变更、资产减值计提的时机等多种方法调节。但银行账户里的真金白银不会骗人——要么有，要么没有。经营现金流需要银行的对账单配合，造假难度呈指数级上升。

2. **它回答了最根本的问题：公司赚的钱到底能不能拿到手？** 一家公司净利润10亿，但经营现金流只有1亿，意味着9亿的利润对应的是应收账款、存货增加或其他非现金项目。这些"利润"很可能永远无法变成现金。

3. **历史上绝大多数财务造假案件，在暴雷前都出现了经营现金流与净利润持续背离的特征。** 康得新、康美药业、獐子岛——无一例外，造假被发现前经营现金流/净利润都持续<0.3。

### 题目2：一家公司ROE=25%，但净利率只有3%，靠什么撑起ROE？这种ROE健康吗？

**答案：**

ROE=25%但净利率只有3% → 杜邦分解：

```
ROE = 3%净利率 × 资产周转率 × 权益乘数
25% = 3% × 资产周转率 × 权益乘数
资产周转率 × 权益乘数 = 8.33
```

这意味着这家公司靠两种可能的组合：

- **高周转+中杠杆**：资产周转率=2.5x、权益乘数=3.3x（如零售/批发企业）
- **中周转+高杠杆**：资产周转率=1.5x、权益乘数=5.6x（如金融企业/高负债企业）

**健康程度判断**取决于具体组合：

- 如果是高周转模式（如京东、美的、顺丰），ROE相对健康——靠运营效率赚钱，商业逻辑可持续。
- 如果是高杠杆模式，ROE很危险——靠借钱放大收益，一旦融资环境收紧或利率上升，ROE和偿债能力双双承压。

**项目启示**：看到高ROE不要兴奋，先用杜邦分解看清楚"ROE是怎么来的"。高杠杆撑起的高ROE是定时炸弹。

### 题目3：商誉/净资产=40%意味着什么？项目当前有没有用到这个指标？

**答案：**

商誉/净资产=40%意味着：这家公司通过并购扩张，累计支付的溢价已经达到净资产的40%。这个水平处于高风险区。

**这意味着：**

- 公司历史上进行了大量并购，且每次都支付了较高溢价
- 如果被收购公司的经营不如预期，需要计提商誉减值，减值金额=业绩不达预期的对应部分
- 假设净资产100亿、商誉40亿，如果收购标的集体暴雷，最悲观情况下40亿商誉全部减值 → 净资产从100亿变成60亿 → ROE翻倍恶化

**项目当前对这个指标的使用：**
- **每日荐股v2.4**：商誉占比未纳入评分体系——当前财务评分只使用PE估值。
- **重点股票v2.2**：未在9项财务健康指标中明确列出商誉占比，但在"资产负债率"和"财务健康评估"框架下隐含关注。
- **规则红线v1.6**：商誉相关数据来自东方财富财务[3]，但未设置独立的否决规则。

**建议**：商誉占比>30%是值得重点关注的风险信号，在重点股票深度分析中应当主动披露，即使不在每日荐股评分中直接扣分。
