## 一、主力资金分类

### 1.1 按单笔成交金额分类

A股市场中，东方财富将每笔成交按其金额大小分为四个层次：

| 分类 | 单笔成交金额 | 对应主体 | 典型特征 |
|:----|:-----------|:--------|:--------|
| **超大单** | >100万元 | 机构（公募、保险、社保、QFII） | 中长期配置，换手率低，买入后持有周期长 |
| **大单** | 20万~100万元 | 游资、大户 | 中短期操作，灵活进出，追热点能力强 |
| **中单** | 4万~20万元 | 中户 | 有一定资金体量的个人投资者 |
| **小单** | <4万元 | 散户 | 情绪化交易，追涨杀跌，反向指标 |

### 1.2 关键计算公式

```
主力净流入 = 超大单净买入额 + 大单净买入额

主力净占比 = 主力净流入 / 总成交额

（正数=主力在买入，负数=主力在卖出）
```

### 1.3 主力资金数据的本质

**关键认知：主力资金数据不是真实账户数据。**

主力资金数据来自交易所的逐笔成交统计——把每笔成交按金额大小分档，但无法知道这笔成交背后是哪个账户、什么身份。所以：
- "超大单净买入"不等于"公募基金在买入"——也可能是多个散户恰好同一时间买入同一只股票，合并显示为一笔大成交
- 主力资金是"推算"，不是"事实"——是统计推论，需要交叉验证
- 精度取决于数据源——Level-1行情和Level-2行情的分档精度差异很大

**项目对接：** 规则红线v1.6 数据源[9]（个股资金流向）和[10]（行业资金流向）均为东方财富垄断数据，无免费备API。

## 二、主力资金分析的四大陷阱

### 陷阱1："假流入"（尾盘拉升）

**现象：** 尾盘最后15分钟，股价突然拉升2%-3%，主力资金显示"大幅净流入"。

**真相：** 主力用少量资金在尾盘流动性最差的时候拉高收盘价（制造好看的日K线），第二天高位出货。

**识别方法：**
- 检查尾盘成交量：尾盘拉升但成交量萎缩（<日内均量的50%），大概率是假突破
- 看次日开盘：第二天直接低开，尾盘拉升的涨幅全部回吐，确认出货
- 连续关注资金流：如果第二天主力大幅流出，确认是"诱多"

### 陷阱2："假流出"（对倒）

**现象：** 某只股票成交量突然放大3-5倍，但股价变动不大，主力资金显示"大幅净流出"。

**真相：** 主力通过自买自卖（对倒）制造放量假象，吸引市场关注。所谓"净流出"是因为一部分成交被统计为大单卖出——但这些单子其实也是主力自己的。

**识别方法：**
- 看股价变化：对倒是左口袋转右口袋，不应该引起价格方向性变动。放量但不涨不跌是典型的对倒特征。
- 看连续多日：对倒一般持续1-3天，之后要么真拉（建仓完成）要么大跌（出货完成）。

### 陷阱3：单日数据噪音极大

单日的主力资金净流入/流出数据波动极大，参考价值很低。

**案例：**
- 周一：主力净流入5亿（板块大涨，散户跟风，显示主力买入）
- 周二：主力净流出3亿（正常回调，显示主力卖出）
- 周三：主力净流入8亿（又大涨）

单看其中任何一天，都不能得出"主力在买入还是卖出"的结论。只有**连续3-5日的趋势**才有参考价值。

### 陷阱4：散户接盘与主力出货同时发生

**现象：** 主力资金显示净流出，但股价在涨。

**真相：** 这是典型的"主力出货、散户接盘"模式。主力通过小单逐步卖出，同时大单偶尔买入维持价格。结果是：股价不跌（散户还在接）、主力资金显示净流出（真相暴露）。

**判断标准：**
- 主力净流出 + 小单净流入 = 散户在接盘
- 主力净流出 + 股价高位 = 高度警惕
- 连续3天以上主力净流出 + 股价横盘或微涨 = 主力出货中

## 三、北向资金（沪深股通）

### 3.1 基本概念

| 方向 | 含义 | 标的范围 |
|:----|:-----|:--------|
| **北向** | 香港 → 内地（外资通过沪/深股通买A股） | 沪股通（上证180/380成分股）+ 深股通（深成指/中小创新成分股） |
| **南向** | 内地 → 香港（内资通过港股通买港股） | 恒生综指成分股 |

铁律量化关注的是**北向资金**——外资买A股的动向。

### 3.2 北向资金的三大特征

**特征1：被称为"聪明钱"——但不是每次都对**

北向资金确实在历史上展现了较好的择时和选股能力。但：
- 外资也会犯错（如2021年高位重仓中概股）
- 外资受全球流动性影响大（美联储加息→外资撤出新兴市场→A股承压，与个股基本面无关）
- 外资进出有额度限制，并非完全自由

**特征2：有明显的板块偏好**

| 偏好 | 典型标的 |
|:----|:--------|
| 消费龙头 | 贵州茅台、五粮液、美的集团（长期重仓） |
| 金融 | 招商银行、中国平安 |
| 新能源 | 宁德时代、隆基绿能 |
| 科技 | 工业富联、中际旭创（近期增加） |

**特征3：回避特定类型**

| 回避类型 | 原因 |
|:--------|:-----|
| 小盘股 (<100亿市值) | 流动性太差，进出困难 |
| 题材股/亏损股 | 不符合价值投资逻辑 |
| 次新股 | 历史数据不足，风险不可控 |

### 3.3 关键数据

| 数据项 | 数值 |
|:------|:----|
| 沪股通每日额度 | 520亿人民币 |
| 深股通每日额度 | 520亿人民币 |
| 总额度 | 已取消（2020年5月起） |
| 外资持股预警线 | 占公司总股本24%（超过后交易所公布） |
| 外资持股上限 | 30%（达到后不能再买入，只能卖出） |

### 3.4 北向资金的实际参考价值

**有参考价值的信号：**
- 连续5日以上北向资金净流入某只个股（持续流入趋势确认）
- 北向持股比例持续上升（从2%→5%），说明外资在系统性增配
- 北向资金与股价背离：股价下跌但北向资金逆势加仓（外资看好）

**不具参考价值的：**
- 单日净流入/流出金额（噪音太大）
- 持股占总股本比例<1%的变动（太小，无意义）

**项目对接：** 规则红线v1.6 数据源[8]北向资金，数据来自东方财富 datacenter-web.eastmoney.com，为季度数据，缓存TTL 168h（7天）。北向资金为东财垄断数据，无免费备API。

## 四、融资融券

### 4.1 基本概念

| 概念 | 含义 | 市场意义 |
|:----|:-----|:--------|
| **融资余额** | 投资者借钱买入的总规模 | 多头情绪指标——融资余额高=很多人加杠杆看多 |
| **融券余额** | 投资者借股卖出的总规模 | 空头力量指标——融券余额高=有人看空做空 |
| **融资净买入** | 当日融资买入 - 融资偿还 | 正向=当日更多人加杠杆买入 |
| **融资融券余额比** | 融资余额/融券余额 | 越高=市场越偏多 |

### 4.2 融资余额变化的解读

| 融资余额变化 | 市场含义 | 操作含义 |
|:----------|:--------|:--------|
| 持续上升 + 股价涨 | 良性看多，增量资金在加杠杆 | 趋势健康，可持仓 |
| 持续上升 + 股价不涨 | 多头在不断加仓但价格上不去=卖方也很强 | 警惕——多空分歧加大 |
| 快速下降 + 股价跌 | 多头在去杠杆（被迫或主动卖出） | 下跌可能加速 |
| 快速下降 + 股价不跌 | 杠杆资金退出但股价有支撑=有别的资金在接 | 可能是筑底信号 |
| 融资余额创新高 | 市场情绪极度亢奋 | 警惕——高点往往在融资余额最高点附近 |

### 4.3 融资融券的风险

**融资的风险：**
- 融资买入放大了上涨时的收益，也放大了下跌时的损失
- 券商有权在股价跌到一定程度时强制平仓
- 强平潮会引发加速下跌——融资盘互相踩踏

**融券的风险（做空）：**
- 理论上亏损无上限（股价可以无限上涨）
- A股融券成本高、券源有限，融券做空的门槛远高于融资做多
- 融券余额在A股中的占比极低（通常<总市值的0.1%），空头力量的实际影响有限

### 4.4 项目中的使用

**项目对接：** 规则红线v1.6 数据源[12]融资融券，数据来自东方财富 datacenter.eastmoney.com，缓存TTL 24h。融资融券为东财垄断数据。重点股票v2.2 第1.3.3条将融资余额变化作为情绪面指标之一，判断标准为"融资余额大幅增加→多头情绪"。

## 五、成交量分析

### 5.1 五种量能状态

| 量能状态 | 成交额特征 | 含义 |
|:--------|:----------|:-----|
| **放量** | >20日均量的1.5倍 | 多空分歧加大，有增量资金或恐慌资金 |
| **缩量** | <20日均量的0.5倍 | 市场参与度低，缺乏方向性 |
| **地量** | 近30日最低 | 变盘信号——极度缩量后方向选择 |
| **天量** | 近30日/60日最高 | 情绪极端——可能见顶或见底 |
| **温和放量** | 1.0-1.5倍均量 | 健康的量能增加 |

### 5.2 量价组合分析

| 量价关系 | 含义 | 操作建议 |
|:--------|:-----|:--------|
| **价涨量增** | 需求旺盛，趋势健康，增量资金在买入 | 持仓或加仓 |
| **价涨量缩** | 上涨动力减弱，量价背离 | 警惕回调，考虑减仓 |
| **价跌量增** | 恐慌抛售或主力出货 | 区分是Selling Climax(抄底机会)还是Distribution(逃命信号) |
| **价跌量缩** | 下跌动能衰竭，无人接盘 | 大概率继续跌，但跌幅可能收窄 |
| **放量突破阻力位** | 突破有资金确认，突破成功概率高 | 跟进，止损设在突破位下方 |
| **缩量回踩支撑位** | 抛压衰竭，调整可能结束 | 最佳低吸时机 |
| **放量跌破支撑位** | 支撑失效，趋势转弱 | 止损离场 |

### 5.3 地量与天量的实战意义

**地量（近30日最低成交量）→ 变盘信号：**

当一只股票缩到极致（地量），意味着多空双方都不愿意交易——买方在等更低的价格，卖方在等反弹卖出。这种僵局不会持续很久，一旦被打破就会产生方向性运动。

- **地量+在上升趋势中**：调整的尾声，大概率向上变盘
- **地量+在下降趋势中**：反弹乏力，大概率继续向下
- **地量+横盘**：方向选择即将到来

**天量（远超近期均值的异常放量）→ 情绪极端信号：**

- **天量+股价大涨**：买盘极度亢奋，可能是高潮期的顶部信号
- **天量+股价大跌**：恐慌情绪释放，可能是见底信号（Selling Climax）
- **天量+股价不涨不跌**：主力在对倒/换手，需结合后续方向确认

### 5.4 换手率解读

| 换手率 | 含义 | 操作含义 |
|:-----:|:-----|:--------|
| <1% | 极度冷清，无人关注 | 不参与，流动性太差 |
| 1%-2% | 低活跃度 | 关注但不急于进场 |
| 2%-5% | 正常活跃 | 健康的交易区间 |
| 5%-10% | 高活跃度，多空分歧加大 | 警惕——可能接近顶部或底部 |
| 10%-20% | 极度活跃，筹码在快速换手 | 高潮信号——主力大概率在出货 |
| >20% | 异常换手，筹码一日换手1/5 | 极高风险——游资快进快出 |

**项目对接：** 每日荐股v2.4 第(二十三)条：换手率2%-5%活跃区间+4分；>8%过热-2分；<1%冷清-2分。换手率是资金面评分维度的核心因子之一。

## 六、龙虎榜与席位分析

### 6.1 上榜条件

龙虎榜是交易所每日公布的异动股票成交明细。一只股票要上龙虎榜，需要满足以下条件之一：

| 条件 | 阈值 |
|:----|:----|
| 日涨跌幅偏离值 | >7% |
| 日换手率 | >20% |
| 日振幅 | >15% |
| 连续3日涨跌幅偏离值累计 | >20% |
| 其他（无涨跌幅限制首日、ST异常波动等） | 交易所认定 |

### 6.2 龙虎榜披露内容

龙虎榜会披露：买入金额最大的前5个席位（买一至买五）和卖出金额最大的前5个席位（卖一至卖五）。

每个席位会显示：
- 席位名称（如"机构专用"、"华泰证券深圳益田路营业部"等）
- 买入金额 / 卖出金额

### 6.3 机构席位 vs 游资席位

| 维度 | 机构席位 | 游资席位 |
|:----|:--------|:--------|
| 席位名称 | "机构专用" | 具体券商营业部名称 |
| 操作风格 | 偏中长期，买入后持有数周至数月 | 快进快出，T+1到T+3为主 |
| 买入可靠性 | 较高——机构买入通常有基本面支撑 | 较低——游资可能第二天就卖出 |
| 跟踪价值 | 机构连续买入某只股票值得关注 | 游资的进出太快，散户跟风大概率接盘 |

### 6.4 龙虎榜的解读方法

| 信号 | 含义 |
|:----|:-----|
| 买一至买五合计 > 卖一至卖五合计 | 买方力量更强，偏多 |
| 多个机构席位同时买入 | 机构合力看多，可信度较高 |
| 知名游资席位大量买入 | 短线炒作信号，快进快出 |
| 买一方量远超买二（>2倍） | 单一主力在"独食"，后续走势取决于这一个席位 |
| 同一席位既大量买入又大量卖出 | 对倒→制造活跃假象 |

### 6.5 龙虎榜的局限性

- 只披露前5名，无法看到完整的资金进出
- 一个营业部席位背后可能有多个客户，无法精确判断
- 游资会更换席位、伪装手法
- 龙虎榜数据是T日（当日）的，当你看到时交易已经结束

**项目状态：** 龙虎榜数据未纳入铁律量化自动化分析体系（无稳定免费API，需人工录入交易所披露数据）。在重点股票深度分析中，龙虎榜作为人工分析的辅助参考。

## 四、资金结构维度评分（P0新增）

> 2026-05-26 新增 | 回应东睦股份外部批评——资金面评分需从"只看量"升级为"量+结构"

### 4.1 核心框架

```
资金面评分(0-10) = 量维(0-7) + 结构维(0-3)

量维：沿用 §五 成交量分析的5种量能状态+换手率
结构维：主力方向 + 散户方向 + 结构健康度
```

### 4.2 主力方向判定（连续3-5日趋势）

| 条件 | 判定 | 结构分 |
|:-----|:---:|:-----:|
| 连续3日主力净流入 + 5日累计净流入>0 | 主力进场 | +2 |
| 连续5日主力净流入 | 主力强进场 | +3 |
| 流入流出交替，5日累计≈0 | 中性 | +0 |
| 连续3日主力净流出 + 5日累计净流出>0 | 主力出货 | -2 |
| 连续5日主力净流出 | 主力强出货 | -3（升级至流金审查） |

**数据源**：[9]东方财富个股资金流向（超大单+大单=主力）

### 4.3 散户方向判定（反向指标）

| 条件 | 判定 | 调整 |
|:-----|:---:|:---:|
| 散户出货 + 主力进场 | 筹码集中，健康 | +1 |
| 散户进货 + 主力出货 | 筹码分散，危险 | -2 |
| 散户主力同向 | 无结构信号 | +0 |

**使用注意**：散户方向本质是反向指标——散户持续出货且主力持续进货，是教科书式的上涨中筹码集中。

### 4.4 结构健康度综合

| 结构组合 | 健康度 | 含义 |
|:--------|:----:|:-----|
| 主力进 + 散户出 + 量放大 | **健康** | 上涨中筹码向主力集中 |
| 主力出 + 散户进 + 量放大 | **警惕** | 主力出货散户接盘 |
| 主力出 + 散户出 + 量缩小 | 冷却 | 多空都不愿交易，等待方向 |
| 主力进 + 散户进 + 量放大 | 亢奋 | 一致性过高，接近短期顶部 |
| 主力出 + 散户进 + 量缩小 | 阴跌 | 主力悄悄撤退 |
| 主力进 + 散户出 + 量缩小 | 蓄力 | 主力在缩量中悄悄吸筹 |

### 4.5 假信号识别

- **单日数据**：单日主力净流入/流出噪音极大，不纳入结构评分
- **尾盘异动**：尾盘15分钟急拉+主力净流入=疑似"假流入"（次日验证）
- **对倒嫌疑**：放量3-5倍但股价不变+主力净流出=疑似对倒
- **数据源限制**：[9]为东方财富垄断数据，逐笔成交统计而非真实账户数据（详见§1.3）

## 七、常见误区

| 误区 | 正解 |
|:-----|:-----|
| "主力资金单日净流入=看多信号" | 单日数据噪音极大。尾盘拉升、"假流入"等手法会让单日数据失真。连续3-5日趋势才有参考价值。 |
| "北向资金被称为聪明钱，跟着买就行" | 北向资金也会犯错，且受全球流动性影响（外资撤出新兴市场与A股基本面无关）。北向偏好大市值、消费金融，不适合小盘股投资者。 |
| "融资余额上升=好事" | 融资是放大镜——上涨时放大收益，下跌时放大损失。融资余额快速上升意味着市场在加杠杆，一旦下跌会引发强平潮。 |
| "换手率越高越好" | 换手率>10%意味着筹码在飞速换手，通常不是"健康的活跃"而是"高潮出货"。 |
| "龙虎榜显示机构买入，跟着买稳了" | 龙虎榜是T日的交易记录，你T+1才能看到。且龙虎榜资金≠该机构全部资金——机构可能在龙虎榜买入2000万但通过其他席位卖出了5000万。 |
| "量价关系是确定性的" | 量价关系是概率性的。放量上涨"通常"健康，但也可能发生在主力出货、散户接盘的阶段。没有任何单一量价信号是100%可靠的。 |

## 八、自测题

### 题目1：主力资金单日净流入为什么不能直接当作看多信号？

**答案：**

四个原因：

1. **单日噪音极大。** 主力资金是逐笔成交统计的推算，不是真实账户数据。一笔100万的大单可能是机构买入，也可能是10个散户恰好同一秒买入合并显示。单日的数据波动无从辨别。

2. **"假流入"的存在。** 主力在尾盘最后15分钟用少量资金拉高股价，资金统计显示"主力净流入"，但真实目的恰恰相反——制造好看的收盘价，第二天高位出货。

3. **主力可以通过拆单规避统计。** 为了防止被监测，专业机构会把大单拆成中单（4-20万）来降低透明度。如果机构真的想悄悄买入，反而不会显示为"主力净流入"。

4. **需要区分"单日买入"和"趋势性建仓"。** 主力一天买入2000万可能是因为当日有利好消息或板块上涨被动跟买，这与其长期意图关系不大。只有连续3-5日的净流入才能反映建仓意图。

**正确用法：** 主力资金单日净流入是一个"需要进一步确认"的信号，不能单独作为决策依据。应当结合连续多日趋势、股价所处位置、板块整体资金流向来综合判断。

### 题目2：北向资金持续流入但股价不涨，可能是什么原因？

**答案：**

三种可能性，按概率从高到低：

1. **内资在卖出，抵消了外资的买入。** 这是最常见的情况。外资通过北向渠道持续买入（每天几千万到几亿），但内资（公募、游资、散户）在更大规模地卖出。净结果是股价不涨甚至微跌。查看融资余额变化可以验证——如果融资余额在下降，说明内资在去杠杆。

2. **北向资金在做"左侧布局"。** 外资判断公司被低估，不顾短期股价下跌继续买入。这在外资增配A股的早期阶段很常见——他们在系统性地增加对中国资产的配置，短期价格并不影响其战略决策。

3. **外资内部的"假北向"。** 部分内地资金绕道香港通过沪深股通买回A股（利用香港更低的融资成本或其他套利动机），这部分"北向"实际上是内资，其投资逻辑与真正的外资不同，对股价推升作用有限。

**项目启示：** 北向资金持续流入但股价不涨=有价值信号但需要交叉验证。需要结合板块轮动位置、技术面形态、内资动向综合判断。

### 题目3：融资余额快速上升是好事还是坏事？

**答案：**

这取决于股价所处的位置和市场环境：

**在上升趋势初期 + 融资余额温和上升 → 好事。**
- 合理的加杠杆行为，反映增量资金持续看好，趋势健康。

**在股价已大幅上涨后 + 融资余额快速上升 → 危险信号。**
- 后知后觉的人在追高加杠杆，这些人往往是最后的接盘侠。
- 一旦股价回调5%-10%，大量融资盘会触发券商强平，引发踩踏式下跌。
- 历史规律：A股的阶段性高点往往与融资余额高点高度重合。

**融资余额快速上升 + 股价横盘或微跌 → 极度危险。**
- 多头在不断加仓但价格上不去，说明卖方力量非常强。
- 一旦卖方加大力度或买方力竭，下跌会很剧烈（因为杠杆放大了损失）。

**核心判断逻辑：** 融资余额本身没有好坏之分，它只是一个放大器。在上涨趋势中放大收益，在下跌趋势中放大损失。判断融资是好是坏，取决于你对趋势方向的判断是否正确。
