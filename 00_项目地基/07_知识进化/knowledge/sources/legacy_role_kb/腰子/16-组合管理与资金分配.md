# 16 — 组合管理与资金分配

> 腰子知识库第16号 | 2026-05-23
> 定位：腰子作为金融业务负责人，从"会选股"到"会配组合"的能力跃迁

---

## 一、为什么需要组合管理

单票分析告诉你"这只票好不好"，组合管理告诉你"这几只票放在一起行不行"。

三只评分80+的股票放在一起，不等于一个80分的组合。可能出现：
- 三只都是新能源 → 本质上只押了一个方向
- 两只高beta科技+一只券商 → 大盘跌3%组合跌8%
- 三只流动性都差 → 想跑的时候跑不掉

**组合管理的目标**：在给定的风险预算下，让多只持仓形成互补而非叠加。

## 二、相关性管理——避免虚假分散化

### 2.1 相关性矩阵

三只持仓之间的相关系数（基于近60日日收益）：

| 相关系数 | 含义 | 行动 |
|:--------:|:-----|:-----|
| > 0.7 | 高度正相关 | 视为同一风险敞口，只算半只 |
| 0.3-0.7 | 中度相关 | 可接受，但关注同跌风险 |
| < 0.3 | 低相关 | 真正的分散化 |
| < 0 | 负相关 | 天然对冲，但A股罕见 |

**项目实操**：每次开新仓前，检查与现有持仓的相关性。如果新票与任一持仓相关系数 > 0.7，腰子需判断是否实质上在加仓同一个方向。

### 2.2 行业集中度

HHI指数（赫芬达尔指数）衡量行业集中度：

```
HHI = Σ(每个行业的持仓占比²)
```

| HHI值 | 含义 | 行动 |
|:-----:|:-----|:-----|
| < 0.3 | 分散 | 正常 |
| 0.3-0.5 | 中等集中 | 关注 |
| > 0.5 | 高度集中 | 需要理由——这是主动押注还是疏忽？ |

**项目实操**：三只持仓最多覆盖三个不同的申万一级行业。如果两只同行业，腰子必须明确：这是有意为之（强烈看好该行业）还是疏忽。

### 2.3 风格因子重叠

两只不同行业的股票可能暴露于同一风格因子：

| 风格因子 | 典型同向暴露 | 看似不同实则相同 |
|:---------|:------------|:----------------|
| 市值 | 小盘成长+小盘价值 | 不同行业但都是小盘 |
| 动量 | 追高买入的任何票 | 不同行业但都在涨 |
| 波动率 | 高beta科技+高beta券商 | 不同行业但都高弹性 |
| 流动性 | 日均<5000万的任何票 | 不同行业但都难出货 |

**项目实操**：腰子在持仓审视时问自己："这三只票，有没有某个共同特征让我一损俱损？"

## 三、风险预算——亏多少是可以接受的

### 3.1 风险预算的定义

> 风险预算 = 你愿意为追求收益而承担的损失上限

不是"最大回撤不超过X%"这种事后指标，而是开仓前就分配好的**每笔交易的风险额度**。

### 3.2 三层风险预算体系

| 层级 | 定义 | 项目当前值 | 腰子的判断空间 |
|:----:|:-----|:---------|:------------|
| L1 单笔风险 | 单笔交易最大亏损占组合比例 | 2×ATR止损，硬上限-8% | 根据波动率环境微调ATR乘数(1.5-2.5) |
| L2 组合风险 | 同时持仓的最大回撤上限 | 无硬性规定（当前盲区） | **需要腰子设定** |
| L3 连败风险 | 连续亏损后的应对 | 5笔红旗/8笔重构 | 根据市场状态调整阈值 |

**L2是当前项目的盲区**。三只持仓各亏8%同时触发 = 组合亏24%（极端情况）。腰子需要主动管理组合层面的风险暴露。

### 3.3 波动率预算

根据当前市场波动率调整总仓位：

| VIX/波动率环境 | 建议总仓位 | 逻辑 |
|:-------------|:---------|:-----|
| 低波动（ATR percentile < 30） | 60-75% | 正常环境，可重仓 |
| 中波动（ATR percentile 30-70） | 40-60% | 项目默认区间 |
| 高波动（ATR percentile > 70） | 20-40% | 减少暴露，等风暴过去 |
| 极端波动（连续3日 > 2%振幅） | 0-20% | 现金为王 |

## 四、现金管理——空仓也是仓位

### 4.1 现金的五种角色

| 角色 | 占比 | 用途 |
|:-----|:----:|:-----|
| 机会储备 | 20-30% | 出现高分票时有钱可用 |
| 风险缓冲 | 10-20% | 持仓亏损时不用被迫割肉 |
| 心理安全垫 | 10% | 减轻焦虑，防止恐慌性操作 |
| 交易费用预留 | 2-5% | 佣金+印花税预留 |
| 已配置 | 剩余 | 持仓占用 |

**项目实操**：当前规则"仓位比例 = 占当前现金的%"，意味着现金是动态计算的。腰子需要额外判断：当前市场环境适合留多少现金。

### 4.2 市场状态 → 现金配置

| 市场状态 | 最低现金比例 | 逻辑 |
|:---------|:----------:|:-----|
| 强势牛市 | 20% | 少留现金，多配资产 |
| 正常/震荡 | 30% | 项目默认 |
| 弱势熊市 | 50%+ | 现金是最好仓位 |
| 恐慌暴跌 | 70%+ | 等情绪稳定再进场 |

## 五、再平衡——组合不是一劳永逸

### 5.1 触发再平衡的四个条件

1. **单一持仓盈利过大**：某只票浮盈超过入场价15%，占组合比例失衡 → 部分止盈，恢复均衡
2. **风格漂移**：原本分散的三只票因为市场变化变成了同一个风格（如都涨成了高动量） → 减仓同风格，找互补品种
3. **风险预算超支**：组合实际波动超过风险预算 → 降低总仓位
4. **时间触发**：持仓超过15天，重新审视每只票的持有逻辑

### 5.2 加仓vs分散

当出现新的高分票但已满仓（3只）时：

| 新票 vs 现有持仓 | 行动 |
|:----------------|:-----|
| 新票评分显著更高（>10分差距）且不同行业/风格 | 考虑替换最弱的持仓 |
| 新票和现有持仓同行业/同风格 | 不换——没有分散价值 |
| 新票评分相当但波动率更低 | 可以换——同等收益预期下降低风险 |
| 没有明确优势 | 不动——过度交易吃掉的摩擦成本不值得 |

## 六、组合健康度速查卡

腰子每次审视持仓时快速过一遍：

| 检查项 | 绿灯 | 黄灯 | 红灯 |
|:-------|:----:|:----:|:----:|
| 行业集中度(HHI) | < 0.3 | 0.3-0.5 | > 0.5 |
| 最大单股占比 | < 30% | 30-40% | > 40% |
| 现金比例 | 20-50% | 10-20% 或 50-70% | < 10% 或 > 70% |
| 持仓间最高相关性 | < 0.5 | 0.5-0.7 | > 0.7 |
| 组合ATR/入场价均值 | < 3% | 3-5% | > 5% |
| 连败笔数 | 0-2 | 3-4 | ≥ 5 |

**红灯项 ≥ 2 → 腰子必须审视是否调整组合。**
