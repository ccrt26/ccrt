## 二、板块生命周期理论

### 2.1 五个阶段全景

板块生命周期是理解板块轮动的基石。一个完整的板块周期通常经历以下五个阶段：

```
见底期 → 启动期(潜伏期) → 主升期 → 高潮期 → 退潮期(衰退期)
```

### 2.2 各阶段详述

#### 见底期

| 维度 | 特征 |
|:-----|:-----|
| 涨跌幅 | 长期下跌后企稳，底部横盘，波动收窄 |
| 换手率 | 极度萎缩（<1%），市场无人关注 |
| 资金流向 | 少量主力资金开始试探性买入（小单持续净流入） |
| 消息面 | 利空出尽，但无明显利好 |
| 技术特征 | 底部抬高，MACD底背离，成交量地量 |
| 持续时间 | 数周至数月不等 |

#### 启动期（潜伏期）-- 最佳入场时机

| 维度 | 特征 |
|:-----|:-----|
| 涨跌幅 | 成交量温和放大，突破底部区间，涨幅1%-5% |
| 换手率 | 1%-4%，相比见底期明显回升 |
| 资金流向 | 主力资金从试探转为温和净流入，连续小单吸纳 |
| 消息面 | 产业政策/行业景气信号开始出现 |
| 技术特征 | 放量突破下跌趋势线或横盘区，龙头股率先走强 |
| 持续时间 | 1-4周 |

**操作策略：** 埋伏（最佳入场时机）。此时板块尚未被市场广泛关注，上涨空间大、回调风险可控。

**项目对接：** 板块动量+10分（每日荐股v2.4 第(八)条），相位加分最高的一档。

#### 主升期

| 维度 | 特征 |
|:-----|:-----|
| 涨跌幅 | 沿5/10日均线持续上涨，多只个股共振 |
| 换手率 | 3%-6%，持续活跃，资金充分换手 |
| 资金流向 | 主力资金持续净流入，量价配合良好 |
| 消息面 | 政策落地、业绩兑现、行业景气度持续确认 |
| 技术特征 | 均线多头排列，板块指数沿趋势线上涨 |
| 持续时间 | 4-12周 |

**操作策略：** 持有+低吸（不加仓，在回调到均线支撑时低吸）。主升期的正常回调是加仓机会，但不宜在连续大涨后追高加仓。

**项目对接：** 板块动量+5分（每日荐股v2.4 第(八)条），主升调整判定。

#### 高潮期

| 维度 | 特征 |
|:-----|:-----|
| 涨跌幅 | 加速上涨，日内波动加大，出现长上影线 |
| 换手率 | >5%，甚至>10%，热度极高 |
| 资金流向 | 主力开始流出，散户大量接盘，呈现"主力流出、小单流入"反向特征 |
| 消息面 | 好消息频出，媒体铺天盖地报道 |
| 技术特征 | 放量滞涨、RSI>70超买、高位十字星增多 |
| 信号特征 | 非龙头股开始补涨（板块内扩散到底部垃圾股） |

**操作策略：** 减仓+回避。高潮期是最危险的入场时机——看似涨得最好，实则主力正在出货。

**项目对接：** 板块动量-5分（每日荐股v2.4 第(八)条），预警信号。

#### 退潮期（衰退期）

| 维度 | 特征 |
|:-----|:-----|
| 涨跌幅 | 持续下跌，跌破关键均线（MA20/MA50） |
| 换手率 | 先放量下跌（恐慌出货），后逐步萎缩（无人接盘） |
| 资金流向 | 主力大幅流出，无增量资金 |
| 消息面 | 利空开始出现，或此前利好被证伪 |
| 技术特征 | 均线空头排列，MACD零轴下方死叉 |

**操作策略：** 清仓+规避。衰退期的反弹是逃命机会，不是抄底机会。

**项目对接：** 板块动量-10分（每日荐股v2.4 第(八)条），扣分最严厉的一档。

## 三、板块四相位判定规则（项目使用）

### 3.1 核心公式

铁律量化v2.4定义了基于涨跌幅+换手率的四相位快速判定规则：

| 相位 | 判定条件 | 操作得分 | 含义 |
|:----:|:---------|:------:|:-----|
| **潜伏期 (accum)** | 涨跌幅 >= -1.5% 且换手率 <= 4%；或涨跌幅 >= -2% 且换手率 <= 2% | **+10** | 板块未启动，可以埋伏 |
| **主升调整 (rise)** | 换手率>3% 且涨幅>0%；或换手率>2% 且跌幅<-1% | **+5** | 板块活跃中，持有不加仓 |
| **高潮期 (peak)** | 换手率>5% 且涨幅>2% | **-5** | 板块过热，减仓回避 |
| **衰退期 (decline)** | 换手率>3% 且跌幅<-3% | **-10** | 板块退潮，规避 |

### 3.2 判定优先级

当板块数据同时满足多个相位条件时，按以下优先级判定：

```
衰退期(decline) > 高潮期(peak) > 主升调整(rise) > 潜伏期(accum)
```

即：先检查是否衰退期，再检查是否高潮期，以此类推。这是为了避免一个换手率高同时涨跌幅大的板块被错误判定为主升。

### 3.3 判定逻辑的实现要点

- 涨跌幅：板块指数当日涨跌幅（来自东方财富[7]）
- 换手率：板块整体换手率（来自东方财富[7]）
- 数据源：push2.eastmoney.com/api/qt/clist/get?fs=m:90+t:2
- 项目对接：每日荐股v2.4 第(八)条；重点股票v2.2 第1.4.1条

## 四、板块轮动规律

### 4.1 经济周期驱动轮动（美林时钟）

| 经济阶段 | 最优资产 | 优势板块 | 逻辑 |
|:---------|:--------|:--------|:-----|
| **复苏期** | 股票 > 债券 > 现金 > 商品 | 周期股（有色、化工、汽车） | 经济回暖，企业盈利改善 |
| **过热期** | 商品 > 股票 > 现金 > 债券 | 大宗商品、能源、原材料 | 通胀上升，商品价格走强 |
| **滞胀期** | 现金 > 商品 > 债券 > 股票 | 防御型（公用事业、必选消费） | 经济停滞+通胀，避险为主 |
| **衰退期** | 债券 > 现金 > 股票 > 商品 | 债券、高股息 | 降息预期，债券受益 |

### 4.2 A股特色轮动：五段循环

A股的板块轮动有明显的中国特色规律，通常遵循以下顺序：

```
金融（券商/银行）→ 周期（有色/化工/钢铁）→ 成长（科技/新能源）→ 消费（食品/医药）→ 防御（公用事业）
```

这个循环的逻辑是：
1. **金融先涨**：牛市初期，券商受益于交易量放大，银行受益于利率环境
2. **周期接力**：经济复苏预期升温，大宗商品和工业品涨价
3. **成长主升**：风险偏好提升，资金涌入高成长科技股
4. **消费补涨**：赚钱效应扩散到消费，消费股估值提升
5. **防御收尾**：行情尾声，资金撤向防御型板块，预示调整将至

### 4.3 政策驱动轮动

中国A股是"政策市"，产业政策是板块轮动的核心驱动力：

```
产业政策出台 → 相关板块受益预期形成 → 资金涌入 → 进入主升 → 政策落地/利好兑现 → 资金撤离
```

典型案例：2023年AI大模型政策 → 光模块（中际旭创）、算力（中科曙光）、AI应用（昆仑万维）轮番上涨。

### 4.4 资金驱动轮动："高切低"

当市场没有明确主线时，资金会在板块之间做"高切低"：

- **高切低** = 涨多了的板块资金撤出，涌入还没涨的板块
- **判断信号**：高位板块放量滞涨 + 低位板块突然放量启动
- **持续时间**：通常1-3周，偏短期

### 4.5 风格切换信号

| 切换类型 | 信号 | 含义 |
|:--------|:-----|:-----|
| 大小盘切换 | 沪深300 vs 中证1000 走势分化 | 大盘股走弱+小盘股走强=风险偏好上升 |
| 成长/价值切换 | 创业板 vs 上证50 走势分化 | 创业板强=成长风格，上证50强=价值风格 |
| 进攻/防御切换 | 科技+消费 vs 公用事业+银行 | 科技强=进攻，公用事业强=防御（避险） |

## 五、主线 vs 轮动 vs 脉冲的区分（v2.4核心创新）

### 5.1 三种板块类型的定义

| 类型 | 定义 | 操作价值 |
|:----|:-----|:--------|
| **强主线** | 20日涨幅>10% + 上涨天数>60% + 跑赢大盘>5% + 资金趋势持续 | 持有+回调加仓 |
| **短期脉冲** | 当日大涨但20日趋势不足 | 不能追，等待回调确认 |
| **冷门板块** | 当日弱 + 趋势弱 | 不参与，等信号 |

### 5.2 强主线判定标准（板块趋势持续性 >= 3分）

板块趋势持续性评分（5分制，每日荐股v2.4 第(二十七)条）：

| 子项 | 分值 | 判定条件 | 数据依赖 |
|:----|:---:|:---------|:---------|
| ①20日涨幅 | 1分 | 板块指数20日涨幅 > 10% | 板块指数20日K线 |
| ②上涨天数 | 1分 | 20日中上涨天数 > 12天（>60%） | 板块指数20日K线 |
| ③相对大盘超额 | 1分 | 板块20日涨幅跑赢沪深300 > 5% | 板块指数+大盘20日K线 |
| ④主力资金趋势 | 2分 | 20日净流入天数>12天+1分；最近5日持续净流入+1分 | 板块20日资金流 |

**判定：** 累计得分 >= 3分 → 判定为"强主线"。

### 5.3 板块动量双层判断矩阵

这是v2.4最核心的创新，解决了一个关键问题：同样的技术形态，在主线板块和冷门板块中，后续表现截然不同。

| 当日动量 | 长期趋势 | 判定 | PE否决(C1/C2) | 均线否决(C3/C5) |
|:---------|:---------|:-----|:----------:|:------------:|
| 强（主升/高潮） | 强（主线） | **主线加速** | 完全豁免 | 完全豁免 |
| 强（主升/高潮） | 弱（轮动） | **短期脉冲** | 豁免分降至70 | 豁免 |
| 弱（潜伏/中性） | 强（主线） | **主线回调** | 完全豁免 | 仅豁免C3 |
| 弱（潜伏/中性） | 弱（冷门） | **冷门** | 正常执行 | 正常执行 |

### 5.4 双层判断的核心逻辑

**为什么主线加速可以全面豁免？**

在主升趋势中，PE高位、均线回踩都是正常的。有色板块大涨时，15只涨>5%的股票全部因PE/均线被否决，这就是"误杀"。主线板块中，技术面的短期瑕疵不应成为否决理由。

**为什么短期脉冲只降豁免分而不完全豁免？**

短期脉冲没有持续的行业基本面支撑，可能是消息刺激一日游。降低豁免门槛（从85分降至70分）但保留否决能力，防止推荐没有基本面支撑的热门股。

**为什么主线回调只豁免C3？**

主线中的正常回调意味着趋势未变，均线短暂回踩（C3）可以豁免。但C5（MA10死叉MA20）是中线趋势转折的强烈信号，即使在主线中也需要更高分数证明个股质量。

## 六、A股板块轮动的独特性

### 6.1 题材炒作周期

A股特有的题材炒作周期比业绩驱动的周期短得多：

```
概念发酵（1-3天）→ 跟风（3-7天）→ 高潮（1-3天）→ 分化（3-5天）→ 退潮（1-2周）
```

识别题材炒作的关键信号：
- 龙头股连续涨停（散户无法买入）
- 跟风股放量但涨幅远小于龙头
- 消息面快速扩散（各大财经媒体密集报道）
- 换手率急剧放大（20%+）

### 6.2 三方博弈

A股板块轮动不只是基本面驱动，更是机构、游资、散户三方博弈：

| 参与者 | 资金规模 | 操作风格 | 偏好板块 |
|:------|:--------|:--------|:--------|
| 机构（公募/保险） | 大（亿级） | 中长期配置 | 消费、医药、新能源龙头 |
| 游资 | 中（千万-亿级） | 短期快进快出 | 题材、小盘、次新 |
| 散户 | 小（万-百万级） | 追涨杀跌、情绪化 | 热门股、题材股 |

### 6.3 北向资金偏好

北向资金（外资）有明显的板块偏好：

- **重点配置**：食品饮料（茅台、五粮液）、金融（招商银行、中国平安）、新能源（宁德时代）、家电（美的集团）
- **回避**：小盘股、题材股、亏损股、概念炒作
- **参考价值**：北向资金持续3-5日净流入某板块，往往是中线看好的信号

### 6.4 游资偏好

游资主导的板块轮动有鲜明的"短期爆发力"特征：

- **偏好标的**：流通市值<100亿、次新股、有题材催化
- **操作特征**：建仓快（1-2天）、拉升高举高打、出货也快
- **识别信号**：龙虎榜买一席位为知名游资、换手率骤增至15%+
- **风险提示**：游资退潮后股价往往快速回落，不适合中长线持有

## 七、常见误区

| 误区 | 正解 |
|:-----|:-----|
| "当天涨得好的板块就是好板块" | 当日大涨可能是高潮期（即将退潮）或短期脉冲（没有持续性）。需要结合20日趋势判断。 |
| "主线板块不会回调" | 主线板块的正常回调是健康的（清理浮筹），恰恰是加仓时机。 |
| "换手率越高越好" | 换手率>5%意味着多空分歧巨大。高潮期的高换手是主力出货信号，不是买入信号。 |
| "板块轮动可以精确预测" | 轮动规律是概率性的，不是确定性的。美林时钟在A股的适用性有限，政策变量经常打破节奏。 |
| "潜伏期的板块就一定会涨" | 潜伏期只表示"未启动"，不代表"即将启动"。有些板块会在见底期横盘数月甚至更久。 |

## 八、自测题

### 题目1：如何区分"主线板块的正常回调"和"板块退潮开始"？

**答案：**

三步验证法：

1. **看20日趋势持续性得分**：如果得分>=3分（强主线），回调大概率是正常的。如果得分<3分，警惕可能不是正常回调。
2. **看回调幅度和成交量**：正常回调缩量（<20日均量0.7倍）、跌幅温和（2%-5%）。退潮开始放量下跌（>20日均量1.5倍）、跌幅>3%。
3. **看龙头股表现**：正常回调中龙头股跌幅小于板块平均跌幅（龙头抗跌）。退潮开始龙头股率先下跌且跌幅大于板块平均。

### 题目2：为什么板块趋势持续性评分只有4个因子（20日涨幅/上涨天数/超额/资金趋势）？

**答案：**

这四个因子从不同维度交叉验证板块趋势的"质量"：

- **20日涨幅**：回答了"涨了多少"（幅度维度）
- **上涨天数占比**：回答了"涨得多稳"（持续性维度）——不是靠几天暴涨拉起来的，而是持续稳步上涨
- **相对大盘超额**：回答了"是真的强还是跟大盘涨"（独立性维度）——板块行情要有超额才有独立逻辑
- **主力资金趋势**：回答了"有没有钱在持续买"（资金面维度）——价格可以骗人，资金流向更难骗

四个因子同时满足>=3分，说明板块既涨了、又涨得稳、还独立于大盘、且有资金支撑。任何一个维度缺失都会降低可信度。

### 题目3：短期脉冲板块的否决豁免为什么是"降至70分"而不是完全豁免？

**答案：**

核心逻辑是"有条件的信任"：

- 短期脉冲说明当日资金在大力买入（第一层动量强），这种买入是有信息含量的，不应该完全无视，所以不能正常执行否决（那等于完全不信）。
- 但20日趋势不足（第二层趋势弱）说明没有持续的基本面/行业逻辑支撑，可能是消息刺激、游资突袭或情绪驱动。这种情况下，如果完全豁免否决，等于把短期脉冲当成主线来对待——这是危险的。
- "降至70分"的折中设计：70分要求个股有足够强的自身质量来弥补板块趋势的不足。即"板块给你的豁免减少了，你需要用更高的综合评分来证明自己"。
- 85分（正常豁免门槛）与70分的差距约为总分的一个标准差，既能保留板块信号的价值，又能过滤掉低质量的脉冲股。
