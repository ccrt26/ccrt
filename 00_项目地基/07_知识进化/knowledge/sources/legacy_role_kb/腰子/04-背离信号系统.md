## 一、背离的本质

### 1.1 什么是背离

**背离（Divergence）= 价格与技术指标方向不一致。**

- **顶背离**：价格创了新高，但技术指标没有创新高 -> 上升动能衰竭
- **底背离**：价格创了新低，但技术指标没有创新低 -> 下跌动能衰竭

### 1.2 背离的本质含义

背离反映的是价格与内在动力的脱节：

1. 价格是"果"，动力是"因"。价格创新高但动力跟不上 = 虚高（无根之木）
2. 背离不直接等于反转，而是**预警信号**：趋势内在的动力正在减弱
3. 背离的确认需要至少两个峰（顶背离）或两个谷（底背离）来对比

### 1.3 背离 vs 反转

| 概念 | 含义 | 时间关系 |
|:-----|:-----|:--------|
| 背离 | 趋势动能减弱，反转概率上升 | 反转可能发生在背离后1-20个交易日 |
| 反转 | 趋势方向实际改变 | 反转一定伴随背离，但背离不一定引发反转 |

**核心原则**：背离信号是"减速预警"而非"掉头信号"。看到背离后应该警惕、检查、准备，但不应急于反向操作。

## 二、RSI 背离

### 2.1 定义与识别

**RSI 顶背离**：
```
价格：高点 B > 高点 A（创新高）
RSI：高点 B' < 高点 A'（未创新高）
结论：上升动能衰竭，看空
```

**RSI 底背离**：
```
价格：低点 B < 低点 A（创新低）
RSI：低点 B' > 低点 A'（未创新低）
结论：下跌动能衰竭，看多
```

### 2.2 RSI 背离的特征

| 特征 | 说明 |
|:-----|:-----|
| **灵敏度** | RSI 背离是所有背离类型中最敏感、出现频率最高的 |
| **噪音** | 相应地，RSI 背离的假信号也最多（尤其在震荡市中） |
| **最佳使用场景** | 趋势末端的背离信号最可靠；趋势中段的背离经常被"钝化" |
| **确认要求** | RSI 最好配合 MACD 或量价背离才能提升可靠性 |

### 2.3 RSI 背离的可靠性排序

1. **周线 RSI 背离** > 日线 RSI 背离（周期越长越可靠）
2. **RSI + MACD 双背离** > 单独的 RSI 背离
3. **RSI 在极端区域（>70 或 <30）的背离** > RSI 在中间区域的背离
4. **清晰的双峰/双谷背离** > 模糊的多峰/多谷背离

## 三、MACD 背离

### 3.1 定义与识别

MACD 背离有三种形式，按可靠性从低到高排列：

**（一）柱状线背离（最常用）**：
```
价格：高点 B > 高点 A（创新高）
MACD柱：高点 B' < 高点 A'（柱高度降低）
结论：上涨动能减弱，看空
```

**（二）DIF 线背离（更可靠）**：
```
价格：高点 B > 高点 A（创新高）
DIF线：高点 B' < 高点 A'（DIF值降低）
结论：趋势本身在减速，比柱状线背离更可靠
```

**（三）DIF + 柱状线双背离（最可靠）**：
DIF 线和柱状线同时出现背离，信号强度最高。

### 3.2 MACD 背离 vs RSI 背离

| 维度 | RSI 背离 | MACD 背离 |
|:-----|:--------|:---------|
| 灵敏度（出现频率） | 高（常出现） | 低（较少出现） |
| 可靠性 | 中等 | **更高** |
| 假信号率 | 较高（需其他指标确认） | 较低 |
| 反转提前量 | 早（RSI先于MACD见顶/底） | 较晚 |
| 最佳用法 | 早期预警 | 确认信号 |

**实战策略**：RSI 背离做"预警"（开始关注），MACD 背离做"确认"（准备行动）。

### 3.3 MACD 零轴位置对背离的影响

- **零轴上方顶背离**：上涨趋势末端的背离，反转概率高
- **零轴下方顶背离**：反弹过程中的背离，可能只是反弹结束回到下跌
- **零轴下方底背离**：下跌趋势末端的背离，反转概率高
- **零轴上方底背离**：回调过程中的背离，大概率只是回调结束继续上涨

## 四、量价背离

### 4.1 定义

量价背离 = 价格变动与成交量变动方向不一致。

### 4.2 四种量价背离形态

| 形态 | 量价组合 | 含义 | 操作建议 |
|:-----|:--------|:-----|:--------|
| **价涨量缩** | 价格持续上涨 + 成交量持续萎缩 | 上涨动力不足，买方不愿意在高位追入 | 警惕回调，不宜追高 |
| **价跌量缩** | 价格持续下跌 + 成交量持续萎缩 | 抛压在减少，卖盘枯竭 | 关注企稳信号 |
| **突破量不足** | 突破关键阻力位 + 成交量低于5日均量 | 假突破概率大，买方参与不够 | 等待放量确认再入场 |
| **放量不涨** | 成交量放大 + 价格原地踏步或微涨 | 高位=主力出货；低位=多空博弈激烈 | 位置决定性质 |

### 4.3 放量暴跌的位置判断

放量暴跌的意义完全取决于位置：

| 位置 | 放量暴跌含义 | Wyckoff对应 |
|:-----|:-----------|:----------|
| **长期下跌后的低位** | Selling Climax（恐慌抛售），最后一跌 | SC -- 机会 |
| **上涨中段的回调** | 获利盘集中出逃，短期调整 | 正常回调 -- 等待企稳 |
| **大幅上涨后的高位** | 主力派发，趋势转折 | SOW -- 危险 |

### 4.4 量价背离与 Wyckoff 的衔接

Wyckoff 的"努力与结果定律"本质上就是量价背离的原理：
- 放量（大的努力）+ 价格变动小（小的结果）= 背离 = 反面有人在消化
- 缩量（小的努力）+ 价格变动大（大的结果）= 趋势真实 = 阻力小

详见 03-Wyckoff量价分析法 第六节。

## 五、多指标背离的叠加判断

### 5.1 背离叠加强度等级

| 级别 | 条件 | 信号强度 | 操作 |
|:----|:-----|:------:|:-----|
| **Level 3** | RSI背离 + MACD背离 + 量价背离 三者同时出现 | **极强** | 必须立即重视，准备反向操作 |
| **Level 2** | RSI背离 + MACD背离（无量价背离） | **强** | 高度警惕，检查其他指标 |
| **Level 1** | RSI背离 或 MACD背离 单一出现 | **中等** | 可参考但不宜单独决策 |
| **Level 0** | 仅技术指标区域超买/超卖（无背离） | **弱** | 仅为辅助参考 |

### 5.2 多周期背离叠加

| 组合 | 信号强度 | 含义 |
|:-----|:------:|:-----|
| 日线背离 + 周线背离同向 | **极强** | 中短期趋势都出现动能衰减，趋势转折概率极高 |
| 日线有背离 + 周线无背离 | 中等 | 可能仅为日线级别的短期调整 |
| 日线无背离 + 周线有背离 | 中强 | 长期趋势可能转折，但短期尚未体现 |

### 5.3 背离信号与趋势健康度的关系

背离信号不是孤立的，应放在更大的趋势框架中考量：

- **上升趋势中段出现顶背离**：可能只是技术性调整信号（RSI从70回到50再涨），而非趋势反转
- **上升趋势末端出现顶背离**：趋势反转的概率大幅提升（多个指标同时背离时尤其）
- **下降趋势中段出现底背离**：可能只是超跌反弹信号，反弹后继续下跌
- **下降趋势末端出现底背离**：结合放量企稳 + 底部抬高 = 反转概率高

## 六、背离的失效

### 6.1 背离失效的三种场景

**场景一：强势市场中的顶背离钝化**

在强牛市中（全市场等权涨幅 > 2%/日），顶背离可能反复失效：
- RSI 长期维持在 70-85 之间，每次小幅回调后继续创新高
- MACD 持续高位运行，背离信号被持续"修正"（继续上涨后指标也创新高）
- 操作教训：牛市中不要仅因为顶背离就做空，应结合均线和成交量判断

**场景二：弱势市场中的底背离反复**

在熊市中，底背离可能反复出现但每次反弹都是下跌中继：
- "背离之后再背离" -- 股价继续创新低，指标每次小反弹后又下去
- 操作教训：熊市中底背离是必要条件但非充分条件，需等待放量突破确认

**场景三：横盘震荡中的背离无效**

在区间震荡中，背离信号几乎无意义：
- 价格在区间上沿形成顶背离（正常，因为这是区间上沿）
- 价格在区间下沿形成底背离（正常，因为这是区间下沿）
- 操作教训：ADX<20 的震荡市中，背离信号不可信

### 6.2 如何避免被背离信号误导

1. **永远不单单凭背离操作**：背离必须有至少一个其他信号的确认（均线/成交量/趋势健康度）
2. **看趋势方向定背离意义**：上升趋势中的底背离比顶背离更可靠；下降趋势中的顶背离比底背离更可靠
3. **看背离的"级别"**：清晰的、跨度大的（两个峰/谷间隔 > 10个交易日）背离 > 模糊的、跨度小的背离
4. **结合 Wyckoff 位置判断**：吸筹区末端的顶背离可能是"震仓前的虚晃"，派发区末端的底背离可能是"诱多"

### 7.2 重点股票v2.2 背离处理规则详解（v2.2 3.2.1节）

这是项目中关于背离最核心的操作规则：

**规则一：趋势健康度评分 < 40 + 中/长期预判为看多时**

- 触发条件：短期技术面弱（趋势健康度低），但中长线基本面/板块逻辑看多
- 判定：短期技术指标与中长线出现背离
- 报告输出：必须展示"背离说明框"，明确标注"短线与中长线背离"提示
- 应对策略（差异化）：
  - 中长线持仓者：等待企稳信号（MACD金叉 + RSI回升至50以上）再考虑加仓，不建议盲目清仓
  - 短线交易者：严格执行止损纪律

**规则二：趋势健康度 < 60 + 中/长期预判同步看空时**

- 触发条件：多周期共振偏弱
- 报告输出："多周期共振偏弱"提示
- 应对：建议控制仓位，不宜加仓

**设计逻辑**：这两条规则解决了"技术面说卖但基本面说买"的矛盾——避免纯技术指标的短期噪音误导中长线决策，同时也不忽视技术面的风险提示。

### 7.3 每日荐股v2.4 S3 量价背离评分扣分规则

| 形态 | 得分 | 背离类型 |
|:-----|:---:|:--------|
| 横盘后放量突破 | 5 | 无背离（量价同步） |
| 洗盘后突破 | 4 | 可能含短期量价背离后修复 |
| 放量上涨 | 4 | 无背离 |
| 底部连阳 | 4 | 无背离 |
| 温和上涨 | 3 | 可能含价涨量缩预警 |
| 高位放量滞涨 | 1 | 严重量价背离（放量不涨） |
| 放量暴跌 | 0 | 可能是SC或SOW（位置决定） |

5分与1分的差值（4分）就是量价背离带来的评分损失，在100分制中占比4%，足以影响推荐排序。

## 八、自测题（附答案）

**Q1: 顶背离出现后，价格一定会跌吗？如果不是，什么情况下背离会失效？**

A: 不会。顶背离是"预警"而非"反转信号"。背离失效的三种典型场景：
1. **强势牛市中的钝化**：全市场持续上涨时，RSI长期>70、MACD高位运行，顶背离信号被不断上涨所"修正"（价格上涨后指标也被带起来创新高），背离消失。
2. **趋势中段的短暂背离**：上升趋势中RSI从70短暂回落到55再上涨到75（在此期间MACD走平），技术上形成背离但属于正常的趋势中调整，不应视为反转。
3. **横盘震荡中的假背离**：ADX<20时市场方向不明，价格在区间上沿自然出现顶背离（KDJ/RSI从高位回落），但这只是区间波动特征而非趋势反转信号。

结论：背离出现后应检查均线、成交量、Wyckoff位置来决定是否真的危险，而非机械地"看到背离就卖"。

---

**Q2: RSI背离、MACD背离、量价背离，三者的可靠性如何排序？**

A: 可靠性从高到低：

1. **量价背离**（最可靠）-- 成交量是真金白银的交易记录，不可能造假（A股虽然有对倒但能从总量上观察异常）。放量不涨意味着实实在在有人在卖出。可靠性最高。
2. **MACD DIF线背离** -- 比MACD柱状线背离更可靠，因为DIF反映的是趋势本身的速度（EMA12与EMA26的差），而非短期的柱状波动。
3. **MACD柱状线背离** -- 可靠性中等。柱状线受短期价格波动影响较大，有时只是技术性修正而非真正趋势变化。
4. **RSI背离**（最敏感但最不可靠）-- RSI出现背离的频率远高于MACD，但假信号也多。RSI背离更适合做"早期预警"而非"操作信号"。

实战中三者叠加使用效果最好：RSI背离做早期预警 -> MACD背离做确认 -> 量价背离做最后验证（三重确认=极高可靠性）。

**Q3: 项目的背离处理规则（重点股票v2.2 3.2.1节）里，短中长背离时应该怎么做？**

A: 项目中有两层背离处理规则：

**情况一：趋势健康度 < 40（短期技术面弱）+ 中长期预判看多**
- 这是"短线与中长线背离"场景
- 报告输出：背离说明框
- 操作分化：
  - 中长线持仓者：等待 MACD 金叉 + RSI 回升至 50 以上（企稳信号），再考虑加仓；不建议盲目清仓，因为中长线逻辑未变
  - 短线交易者：严格执行止损纪律，趋势健康度<40本身已触发"评估清仓"区间
- 核心逻辑：不让短期的技术噪音误导中长线持有者的战略判断

**情况二：趋势健康度 < 60 + 中长期预判同步看空**
- 这是"多周期共振偏弱"场景
- 报告输出："多周期共振偏弱"提示
- 操作：建议控制仓位，不宜加仓
- 核心逻辑：多周期同时偏弱时的风险远大于短中长背离时的风险（因为连中长期逻辑都不支持了）

**关键记忆点**：短空长多 -> 背离说明（不盲目清仓）；短空长空 -> 共振警告（果断减仓）。

**Q4: "背离之后再背离"怎么处理？**

A: 这是一个常见的实战难题。当第一次背离出现后价格没有反转而是继续沿原方向前进，形成了更大级别的第二次背离：

- **二次顶背离**：价格比第一次背离时更高，但指标比第一次背离时更低 -> 背离在加剧 -> 反转概率更高
- **二次底背离**：价格比第一次背离时更低，但指标比第一次背离时更高 -> 背离在加剧 -> 反转概率更高

处理原则：
1. 第一次背离 = 黄旗（警惕，准备）
2. 第二次背离 = 红旗（强烈警惕，检查所有指标）
3. 第二次背离 + 量价配合信号（放量突破/跌破关键位）= 行动信号
4. 不要"左侧猜底/猜顶"——等待趋势确认信号再入场，即使错过最初几个百分点的行情也好过被反复背离坑杀
