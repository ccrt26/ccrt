## 二、impact_score 公式

```
impact_score = category_weight × probability × freshness
capped at 10.0
```

| 因子 | 取值 | 来源 |
|:-----|:-----|:-----|
| category_weight | 5-10 | 六类标签权重（见上表） |
| probability | 1.0 / 0.7 / 0.5 | 确定性判断（见下） |
| freshness | 1.0 / 0.8 / 0.5 / 0.3 | 时效性权重（见下） |

**示例**：并购重组公告，确定性1.0，当天发布
→ 9 × 1.0 × 1.0 = 9.0

## 三、direction — 方向判断

| 方向 | 值 | 触发关键词 |
|:-----|:--:|:-----|
| 利好 | **+1** | 增持\|回购\|预增\|增长\|超预期\|获批\|中标\|突破\|利好\|注册批复\|通过\|核准\|上调\|实施 |

| 利空 | **-1** | 减持\|预亏\|预减\|下降\|不及预期\|立案\|处罚\|问询\|警示\|退市\|ST\|\*ST\|调查\|失败\|亏损\|暴跌 |

## 四、probability — 确定性

| 确定性 | 值 | 触发关键词 |
|:-----|:--:|:-----|
| 已确认 | **1.0** | 默认值 |
| 预计 | **0.7** | 预告\|预计\|预测 |
| 传闻/计划 | **0.5** | 传闻\|消息\|据悉\|或\|或将\|可能\|拟\|计划\|筹划 |

## 五、freshness — 时效性

基于发布日期距今天数：

| 天数 | 权重 |
|:----:|:---:|
| 今天 | 1.0 |
| 昨天 | 0.8 |
| 3天内 | 0.5 |
| 7天内 | 0.3 |

## 六、P0判定

P0事件不受单股5条上限限制，强制入库，双线上报。

| P0关键词 |
|:-----|
| 立案调查 |
| ST风险 |
| \*ST |
| 退市风险 |
| 全部质押 |
| 重组失败 |
| 破产 |

**P0上报协议**：
```
信鸽标记P0 → 同时推送腰子+阿黑
  → 腰子1h内确认升级/降级
  → 超时 → 阿黑直接升级用户
```
