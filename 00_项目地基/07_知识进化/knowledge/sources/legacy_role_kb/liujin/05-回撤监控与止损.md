# 05 — 回撤监控与止损

> **定位**：流金（风控官）本地知识库 —— 回撤预警体系、止损止盈纪律、冷却期机制
> **更新**：2026-05-23 | **关联文件**：03-持仓风险度量、06-交易纪律审查清单、腰子-知识库/11-仓位管理与止损策略

## 一、回撤分类体系

### 1.1 三种回撤

| 类型 | 定义 | 计算方法 | 用途 |
|:-----|:-----|:---------|:-----|
| 连续回撤 | 当前净值 vs 最近一个峰值净值的跌幅 | DD = (P_peak - P_now)/P_peak | 实时风控报警 |
| 最大回撤(MDD) | 历史上任意时刻至今经历过的最大回撤 | MDD = max(所有历史DD) | 策略整体风险评估 |
| 滚动回撤 | 固定窗口内的最大回撤 | DD_window = max(P_window_high - P_now)/P_window_high | 监控回撤趋势变化 |

### 1.2 回撤的数学关系

```
如果MDD=20%（从100跌到80）：
  需要的涨幅 = 80→100 = 25%
  这就是"回撤的复利破坏"：

回撤%  →  恢复所需的涨幅%
  5%   →   5.3%
 10%   →  11.1%
 15%   →  17.6%
 20%   →  25.0%
 25%   →  33.3%
 30%   →  42.9%
 40%   →  66.7%
 50%   →  100.0%
 70%   →  233.3%
 90%   →  900.0%

核心教训：回撤越大，恢复越难——不是线性关系，是指数级恶化。
所以核心任务不是"涨回来"，而是"别跌那么深"。
```

## 二、回撤四级预警体系

### 2.1 预警等级

| 等级 | 回撤幅度 | 颜色 | 含义 | 行动 |
|:---:|:------:|:---:|:-----|:-----|
| 一级 | -5%以内 | 🟢 正常 | 策略正常运行 | 无需干预 |
| 二级 | -5%至-8% | 🟡 黄色预警 | 关注期 | 审查近期交易，但不停策略 |
| 三级 | -8%至-12% | 🟠 橙色预警 | 警惕期 | 仓位降至50%，暂停开新仓 |
| 四级 | -12%至-15% | 🔴 红色预警 | 危机期 | 仓位降至25%，强制止损所有浮动亏损>3%的持仓 |
| 熔断 | >-15% | ⛔ 黑色 | 熔断 | 全部平仓，至少1周禁止交易 |

### 2.2 预警触发-解除规则

```
触发规则：
  - 日内触发即生效（不等收盘）
  - 收盘确认回撤等级后，次日按对应等级规则执行

解除规则：
  黄色→正常：回撤恢复到-3%以内且持续3个交易日
  橙色→黄色：回撤恢复到-8%以内且持续5个交易日
  红色→橙色：回撤恢复到-12%以内且持续5个交易日
  熔断→红色：冷却期结束后，回撤恢复至-15%以内

禁止行为：
  - 禁止在预警等级上升过程中"抄底加仓"
  - 禁止在预警解除条件未满足时提前恢复仓位
```

### 2.3 预警等级的仓位映射

| 预警等级 | 总仓位上限 | 单股上限 | 开新仓 | 止损收紧 |
|:------:|:--------:|:------:|:----:|:------:|
| 🟢 正常 | 100% | 30% | ✅ 允许 | 标准（-8%硬止损） |
| 🟡 黄色 | 75% | 20% | ✅ 允许（谨慎） | -7%硬止损 |
| 🟠 橙色 | 50% | 15% | ❌ 禁止新仓 | -6%硬止损 |
| 🔴 红色 | 25% | 10% | ❌ 禁止 | -5%硬止损 |
| ⛔ 黑色 | 0% | 0% | ❌ 禁止 | 全部平仓 |

## 三、熔断机制

### 3.1 四种熔断触发

| 熔断类型 | 触发条件 | 暂停时长 | 恢复条件 |
|:---------|:---------|:-------:|:---------|
| 日内亏损熔断 | 单日净值亏损≥5% | 当日剩余时间+次日 | 次日无新触发 |
| 连续亏损熔断 | 连续3个交易日净值均下跌 | 暂停2个交易日 | 2日后手动审查恢复 |
| 连败熔断 | 连续5笔交易亏损 | 暂停5个交易日 | 5日后检查策略参数 |
| 周亏损熔断 | 周净值亏损≥8% | 暂停至下周一 | 周末审查后恢复 |

### 3.2 熔断期间的规则

```
熔断期间：
  ✅ 允许：检查策略逻辑、审查交易记录、重新评估市场状态
  ✅ 允许：提前挂单平仓（减仓应急）
  ❌ 禁止：开任何新仓（任何理由都不行）
  ❌ 禁止：调整策略参数（要在冷静期结束后才能改）
  ❌ 禁止：认为"这次不一样"

熔断不是暂时的暂停，它是你的免疫系统在说：
  "发生了不该发生的事情，在搞清楚原因之前不要继续做。"
```

### 3.3 连续亏损熔断的级联效应

```
连续亏损次数 → 熔断响应：
  1-2次：正常——任何策略都有连续亏损
  3次：🟡 审查——连续3次亏损需要检查是否是策略本身出了问题
  4次：🟠 警惕——接近5次连败线
  5次：🔴 熔断——强制暂停，必须审查
  6次+：如果5次时没有熔断，那风控形同虚设
```

## 四、ATR止损

### 4.1 ATR（Average True Range）计算

```
True Range (TR) = max(
  High_t - Low_t,
  |High_t - Close_{t-1}|,
  |Low_t - Close_{t-1}|
)

ATR(14) = 14日TR的指数移动平均
  ATR_1 = TR_1（初始值）
  ATR_t = (ATR_{t-1} × 13 + TR_t) / 14
```

### 4.2 ATR止损倍数选择

| 倍数 | 止损宽度 | 被触发概率 | 适用场景 |
|:---:|:------:|:--------:|:---------|
| 1×ATR | 极窄 | 50-60% | 极短线（1-2天持仓） |
| 1.5×ATR | 窄 | 30-40% | 短线（3-5天） |
| 2×ATR | 标准 | 15-25% | 中短线（5-10天），**本项目标准** |
| 2.5×ATR | 宽 | 8-15% | 中线（10-20天） |
| 3×ATR | 很宽 | 3-8% | 长线（>20天） |

### 4.3 ATR止损 + 硬止损双层体系

```
层级1：ATR止损（技术止损）
  止损价 = 开仓价 - 2×ATR(14)
  逻辑：允许正常的市场波动，但不允许超出2倍正常波幅的异常波动
  
  例：开仓价10元，ATR(14)=0.3元
  止损价 = 10 - 2×0.3 = 9.4元（-6%）

层级2：硬止损（资金止损）
  止损价 = 开仓价 × (1 - 8%)
  逻辑：无论ATR是多少，单笔亏损不得超过8%
  
  例：开仓价10元
  硬止损价 = 10 × (1-8%) = 9.2元

两者取较小止损幅度 → 更紧的那个先触发
  ATR止损价9.4 > 硬止损价9.2 → 硬止损先触发 → 实际止损价9.2
  （在本例中，ATR止损更宽松，硬止损更紧→硬止损生效）

如果ATR(14)很大（波动剧烈的股票）：
  例：ATR(14)=0.6元，2×ATR=1.2元（-12%）
  ATR止损价10-1.2=8.8 < 硬止损9.2
  → ATR止损先触发 → 实际止损价8.8
  
但此时-12%已经超过了硬止损的-8%→
  实际上两者同时生效：硬止损在9.2触发（不要等到8.8）
```

### 4.4 动态ATR止损（随波动率调整）

```
在波动率上升时，ATR止损应该自动加宽，但硬止损不动：

调整后的ATR倍数 = 基准倍数 × (σ_current / σ_20day)

其中σ_current = GARCH预测的当前波动率

如果σ_current/σ_20day > 1.5：
  → 市场波动率异常升高，放宽ATR止损至2×1.5=3×ATR（但硬止损仍然8%不动）
  → 同时降低仓位至正常水平的50%（因为风险更高）

如果σ_current/σ_20day < 0.8：
  → 市场波动率处于低位，可收紧ATR止损至2×0.8=1.6×ATR
```

## 五、时间止损

### 5.1 定义与逻辑

时间止损不基于价格，而基于时间：**如果持仓N个交易日后仍无利润，则平仓。**

逻辑：资金有时间成本。持有一只"不涨也不跌"的股票，等于浪费了持有其他可能上涨的股票的机会。而且"横盘"往往是"下跌"的前奏——尤其在A股，"久盘必跌"是常见的经验规律。

### 5.2 时间止损参数

| 策略类型 | 时间止损（交易日） | 逻辑 |
|:---------|:---------------:|:-----|
| 短线动量 | 3天 | 动量策略需要快速的趋势确认 |
| 短线突破 | 2天 | 突破后若不立即拉升则突破为假 |
| 中短线选股 | 5天 | **本项目标准**：5天不涨即出 |
| 中线价值 | 10天 | 价值修复需要时间，但也不能无限等 |
| 长线持有 | 20天 | 不适合本项目，仅供对比 |

### 5.3 时间止损的变形：阶梯式时间止损

```
持仓第3天：如果浮亏>3% → 平仓
持仓第5天：如果浮亏>0% → 平仓（不赚就出）
持仓第8天：无论盈亏 → 平仓

逻辑：越久不涨，越可能有问题。时间越久，对"不涨"的容忍度越低。
```

## 六、移动止损（Trailing Stop）

### 6.1 固定百分比移动止损

```
规则：止损价 = 持仓期间最高价 × (1 - X%)

当股价创新高后，止损价自动跟随上移，但永远不下移。

示例（X=5%移动止损）：
  开仓价：10元，初始止损=10×(1-5%)=9.5元
  第3天：涨到11元（新高），止损=11×0.95=10.45元
  第6天：涨到12元（新高），止损=12×0.95=11.4元
  第8天：跌回11.5元，未触发止损（11.5>11.4），继续持有
  第10天：跌到11.3元，触发止损（11.3<11.4），平仓

  最终盈利：(11.4-10)/10=14%

移动止损的智慧：
  - 它不试图预测顶部
  - 它让利润自己跑，直到回调超过阈值
  - 但它可能在正常的回撤中被洗出去
  - X%太小→频繁被洗；X%太大→回吐过多利润
```

### 6.2 ATR移动止损

```
规则：止损价 = 持仓期间最高价 - N×ATR(14)

比固定百分比更智能——它考虑了股票自身的波动特征。

示例（N=2）：
  开仓价10元，ATR=0.3
  初始止损=10-2×0.3=9.4元
  
  涨到11元，ATR=0.35
  新止损=11-2×0.35=10.3元（已盈利锁定）

  涨到12元，ATR=0.4
  新止损=12-2×0.4=11.2元（盈利大幅锁定）
```

### 6.3 移动止损的参数选择

| ATR倍数N | 回撤容忍度 | 被洗概率 | 适用 |
|:------:|:--------:|:------:|:-----|
| 1.5 | 小 | 高（30-40%） | 快速止盈策略 |
| 2 | 中 | 中（15-25%） | 标准短线，**本项目推荐** |
| 2.5 | 较大 | 低（8-15%） | 中线趋势跟踪 |
| 3 | 大 | 很低（<8%） | 长线价值投资 |

## 七、冷却期制度

### 7.1 止损冷却期

```
正常止损后冷却期：3个交易日
  - 禁止开新仓
  - 允许持有现有仓位（如已被止损则现金等待）
  - 目的：防止"刚止损就报复性开新仓"

大幅止损（>8%）后冷却期：5个交易日
  - 禁止一切新交易
  - 必须完成"大亏归因分析"后才能恢复交易
  - 归因分析必须回答：
    1. 这笔亏损是策略框架内的正常亏损还是框架外的意外？
    2. 如果是意外，策略参数需要调整吗？
    3. 当前市场环境是否适合该策略？

连续2次止损后冷却期：5个交易日
  - 无论单笔亏损多少，连续止损说明策略在失效

连续3次止损后冷却期：10个交易日
  - 强制长期冷却，深度审查策略是否仍然有效
```

### 7.2 止盈冷却期

```
止盈后冷却期：1个交易日
  - 止盈后"自信心膨胀"是真实存在的心理偏差
  - 1天的冷却期让盈利的兴奋感消退，恢复正常判断

大止盈（>15%）后冷却期：3个交易日
  - 大盈利后容易"过度自信"+ "放松警惕"
  - 3天冷却期确保以平稳心态面对下一笔交易
```

### 7.3 冷却期状态机

```
状态：[正常交易] → [触发止损] → [冷却期中]
         ↑                          |
         └──── 冷却期结束 ──────────┘

冷却期间：
  ✅ 允许：分析市场、审查策略、做研究
  ✅ 允许：平掉现有亏损仓位
  ❌ 禁止：开新仓
  ❌ 禁止：修改策略参数（需冷却结束后冷静修改）
  ❌ 禁止：手动干预自动止损线（"我再看看"=放松纪律）
```

## 八、止盈分档制度

### 8.1 止盈分档

| 档位 | 盈利幅度 | 行动 | 逻辑 |
|:---:|:------:|:-----|:-----|
| R1 | +3% | 观察 | 微利，不值得操作 |
| R2 | +5% | 卖1/3，移动止损激活 | 锁定部分利润，剩余让利润奔跑 |
| R3 | +10% | 再卖1/3，收紧移动止损 | 大部分利润已锁定 |
| R4 | +15% | 卖剩余全部 | 超预期收益，全部兑现 |

### 8.2 R2/R3分步止盈的逻辑

```
问题：为什么不在+10%全部卖出？
回答：因为"让利润奔跑"的原则——+10%的股票可能继续涨到+20%。

问题：那为什么不在+20%再卖？
回答：因为贪婪。+10%之后回调到+5%的概率远大于涨到+20%的概率。

分步止盈是最优折中：
  +5%卖1/3：锁定最低保障利润
  +10%卖1/3：大部分利润落袋
  剩余1/3：用移动止损保护，让可能的超额利润继续增长
```

### 8.3 止盈与移动止损的配合

```
规则：一旦触发R2(+5%)，立即将剩余仓位的止损价移至成本价。
  → 剩余仓位无论如何都不会亏损（即"零风险仓位"）

规则：一旦触发R3(+10%)，移动止损收紧至N=1.5×ATR。
  → 放弃部分回调容忍度，确保已经赚到的不被大幅回吐

规则：R4(+15%)时，移动止损收紧至N=1×ATR。
  → 这时不允许再有任何大幅回调，稍有不对马上全平
```

## 九、连败三级响应机制

### 9.1 响应等级

| 等级 | 条件 | 响应 |
|:---:|:-----|:-----|
| 一级 | 连续3笔亏损 | 🟡 审查模式：审查最近所有交易，但不停止交易 |
| 二级 | 连续5笔亏损 | 🟠 暂停模式：暂停5个交易日，深度审查策略参数+市场环境 |
| 三级 | 连续8笔亏损 | 🔴 强制停工：暂停至少15个交易日，全面审查+策略重构 |

### 9.2 连败归因分析模板

```
连败归因分析（连续N笔亏损后）：

1. 每笔亏损的原因归类：
   □ 策略正常亏损（框架内的）
   □ 策略参数偏差（需要微调）
   □ 市场环境转变（策略失效）
   □ 执行错误（人为因素）
   □ 黑天鹅事件

2. 统计：
   正常亏损___笔（占___%）— 如果占多数，策略可能已经失效
   参数偏差___笔（占___%）— 需要调整参数
   环境转变___笔（占___%）— 当前市场不适合此策略
   执行错误___笔（占___%）— 纪律问题

3. 判断：
   □ 市场暂时不利→暂停等市场转好
   □ 策略参数需要调整→调整后小仓位测试
   □ 策略已过时→淘汰此策略
   □ 执行问题→加强纪律
```

### 9.3 连败后的恢复交易条件

```
恢复条件（所有条件都要满足）：
  1. 冷却期已满
  2. 完成归因分析并记录
  3. 如果是策略原因→已修改策略参数
  4. 如果是市场环境原因→市场环境已确认转变
  5. 恢复交易前48小时内未发生新的熔断事件
  6. 恢复后首次交易仓位不超过正常水平的25%
  7. 恢复后前3笔交易必须有更紧的止损（-5%硬止损）
```

## 十、止损纪律铁律

### 10.1 绝对遵守项

```
1. 止损价一旦设定，只能上移不能下移。
   →"我再给他一点空间" = 放松纪律 = 在慢性自杀

2. 止损触发后，必须执行平仓。
   →"马上就反弹了" = 最常见的亏损放大器

3. 止损后的冷却期不可跳过。
   →"刚刚止损了一个好机会来了" = 报复性交易 = 二次亏损

4. 连续止损2次后，必须暂停并审查，不能继续交易。
   →"下一笔一定赚回来" = 赌徒心理

5. 止损不得以任何理由临时取消或延迟。
   →"再看5分钟" = 纪律失效
```

### 10.2 止损失败案例分析

```
经典失败模式1："不设止损"
  心理："它肯定会涨回来的"
  结果：-5%→-10%→-15%→-25%→套牢→"长期投资"
  风控判定：⛔ 重大纪律违反

经典失败模式2："移动止损向下移"
  心理："把止损放宽一点，给它更多空间"
  结果：止损从-8%移到-10%→-12%→-15%→最终-25%割肉
  风控判定：⛔ 重大纪律违反（止损只上不下是铁律）

经典失败模式3："止损后马上开新仓"
  心理："把这个亏损赚回来"
  结果：第二笔亏损、第三笔亏损、连败
  风控判定：🔴 违反冷却期纪律

经典失败模式4："赚钱的卖太快，亏钱的死扛"
  心理："落袋为安"（对盈利）+"它肯定会反弹"（对亏损）
  结果：平均盈利2%，平均亏损12%，盈亏比0.17→必亏
  风控判定：🔴 止盈止损不对称（人类本性，需制度化克服）
```
