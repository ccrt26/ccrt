## 一、VaR（Value at Risk，在险价值）

### 1.1 定义

VaR回答一个问题：**在正常市场条件下，在给定置信水平下，未来N天内最大可能亏损多少？**

```
VaR(α, T) = inf{L : P(Loss > L) ≤ 1-α}

其中：
α = 置信水平（通常取95%或99%）
T = 持有期（通常取1天或10天）
L = 损失金额
```

**核心局限**：VaR不告诉你超出VaR阈值后的损失有多大。这是它的致命盲区。

### 1.2 三种计算方法对比

| 维度 | 方差-协方差法 | 历史模拟法 | 蒙特卡洛模拟 |
|:-----|:-----------|:---------|:----------|
| 核心思路 | 假设收益率服从正态分布，用μ和σ直接计算 | 用历史收益率序列直接取分位数 | 基于随机过程模拟大量路径取分位数 |
| 公式 | VaR = μ + σ × z_α | VaR = Percentile(returns, 1-α) | VaR = Percentile(simulated_paths, 1-α) |
| z_95% | -1.645 | — | — |
| z_99% | -2.326 | — | — |
| 优点 | 计算简单、可分解 | 不依赖分布假设、包含厚尾 | 最灵活、可处理复杂组合 |
| 缺点 | 忽略厚尾、低估极端风险 | 依赖历史数据长度、无法预测新情景 | 模型风险高、计算量大 |
| A股适用性 | 差——A股收益严重非正态 | 较好——直接用历史数据 | 中等——需校准波动率参数 |
| 项目推荐 | 快速估算用 | 常规风控用 | 重大决策深度分析用 |

### 1.3 方差-协方差法完整公式

```
单资产日VaR：
VaR_daily(95%) = μ_daily - 1.645 × σ_daily
VaR_daily(99%) = μ_daily - 2.326 × σ_daily

组合VaR（考虑相关性）：
VaR_portfolio = sqrt(w^T × Σ × w) × z_α

其中：
w = 权重向量
Σ = 协方差矩阵
w^T × Σ × w = σ_portfolio²（组合方差）

持有期缩放（假设独立同分布）：
VaR_T = VaR_daily × sqrt(T)
```

**A股日波动率参考值**（基于2020-2025年数据）：

| 板块 | 日均波动率σ_daily | 95%单日VaR | 99%单日VaR |
|:-----|:---------------:|:--------:|:--------:|
| 沪深300 | 1.2% | -1.97% | -2.79% |
| 中证500 | 1.5% | -2.47% | -3.49% |
| 中证1000 | 1.8% | -2.96% | -4.19% |
| 创业板指 | 2.3% | -3.78% | -5.35% |
| 科创50 | 2.5% | -4.11% | -5.82% |

### 1.4 VaR回测方法

```
Kupiec检验（比例检验）：
检验实际超出次数是否与VaR置信水平一致

LR_uc = -2 × ln[(1-α)^(T-x) × α^x / ((1-x/T)^(T-x) × (x/T)^x)]

x = 实际超出次数
T = 观测天数
α = 置信水平

拒绝域：LR_uc > 3.84（95%置信度下）
若拒绝 → VaR模型不准确
```

| 检验结果 | 含义 | 行动 |
|:---------|:-----|:-----|
| 超出次数≈预期 | VaR模型适当 | 继续使用 |
| 超出次数>预期 | VaR低估风险 | 收紧模型参数 |
| 超出次数<预期 | VaR过于保守 | 可适度放松，但需警惕模型误差 |

## 二、CVaR（Conditional VaR / Expected Shortfall）

### 2.1 定义

CVaR弥补了VaR的盲区——它告诉你在最坏的(1-α)%情况下，**平均**会亏多少。

```
CVaR_α = E[Loss | Loss > VaR_α]

即：损失超过VaR阈值时，损失的条件期望值
```

### 2.2 为什么巴塞尔协议III用CVaR替代VaR

| VaR的问题 | CVaR的改进 |
|:----------|:----------|
| 不区分"超出1块钱"和"超出100万" | 直接计算超出部分的平均值 |
| 不满足次可加性（组合VaR可能大于各VaR之和） | 满足次可加性，是"一致性风险度量" |
| 可能鼓励承担集中的极端风险 | 对极端风险分配更高的资本要求 |
| 正态分布假设下低估厚尾风险 | 天然包含尾部信息 |

### 2.3 计算方法

```
历史模拟法CVaR：
CVaR_α = avg{returns[i] | returns[i] ≤ VaR_α}

即：取历史收益率中低于VaR阈值的所有观测值的平均值
```

### 2.4 A股实战CVaR阈值参考

| 持仓类型 | VaR(95%) | CVaR(95%) | VaR(99%) | CVaR(99%) |
|:---------|:--------:|:---------:|:--------:|:---------:|
| 单只蓝筹（日） | -2.0% | -3.2% | -2.8% | -4.5% |
| 单只小盘（日） | -3.0% | -5.5% | -4.2% | -7.0% |
| 5只组合（日） | -1.2% | -2.0% | -1.7% | -2.8% |
| 10只组合（日） | -0.9% | -1.5% | -1.3% | -2.1% |

## 四、敏感性分析：Greeks在A股的应用

### 4.1 五大Greeks与A股映射

| Greek | 定义 | 公式 | A股应用场景 |
|:------|:-----|:-----|:----------|
| Delta | 价格对标的物价格的一阶导数 | Δ = ∂V/∂S | 相当于仓位本身：持有100股Delta=100 |
| Gamma | Delta对股价的二阶导数 | Γ = ∂²V/∂S² | A股T+1→Gamma风险无法当日对冲，隔夜Gamma风险更大 |
| 流金 | 价格对波动率的一阶导数 | ν = ∂V/∂σ | **这就是你名字的来源**：A股波动率变化剧烈，流金风险很高 |
| Theta | 价格对时间的一阶导数 | Θ = ∂V/∂t | A股：持股时间越长，时间磨损越大（不适合长期持仓的短线策略） |
| Rho | 价格对利率的一阶导数 | ρ = ∂V/∂r | A股：利率对银行/地产板块影响较大，对科技板块影响较小 |

### 4.2 A股特有的Greeks考量

```
非期权持仓的流金暴露估算：
流金_impact ≈ 持仓金额 × 持仓波动率敏感度 × Δσ

其中Δσ为波动率变化幅度。

例：持有100万创业板股票，创业板波动率从25%升至35%（Δσ=10%）：
流金_impact ≈ 100万 × 1.0 × 10% = 10万风险暴露
（简化算法：波动率上升10%意味着日波动区间扩大约0.63%×10=6.3%的额外风险区间）
```

### 4.3 A股各板块流金风险排序

| 板块 | 波动率敏感度 | 流金风险等级 | 说明 |
|:-----|:---------:|:---------:|:-----|
| 科创50 | 极高 | ⬛⬛⬛ | 日波动2.5%，波动率变化最剧烈 |
| 创业板 | 高 | ⬛⬛⬛ | 日波动2.3%，对政策和情绪高度敏感 |
| 中证1000 | 中高 | ⬛⬛ | 小盘股波动率变化频繁 |
| 中证500 | 中 | ⬛⬛ | 中等波动率敏感度 |
| 沪深300 | 中低 | ⬛ | 大盘蓝筹波动率相对稳定 |
| 上证50 | 低 | ◻ | 银行/保险等权重股波动率最低 |

## 五、相关性风险

### 5.1 三种相关性度量

| 度量 | 测量什么 | 公式 | 优点 | 缺点 |
|:-----|:---------|:-----|:-----|:-----|
| Pearson ρ | 线性相关 | ρ = Cov(X,Y)/(σx×σy) | 简单、广泛使用 | 只能测线性关系 |
| Spearman ρ_s | 单调相关（秩相关） | ρ_s = 1 - 6Σd²/(n(n²-1)) | 对异常值稳健 | 丢失部分信息 |
| Tail dependence | 尾部相关性 | λ_L = lim P(X<q|Y<q) | 直接测量危机时共跌 | 需要大量尾部样本 |

### 5.2 核心规律：危机时相关性趋同（Correlation Breakdown）

```
正常市场：
  - 沪深300 vs 中证500：ρ≈0.65
  - 银行 vs 科技：ρ≈0.30
  - A股 vs 美股：ρ≈0.20

危机市场（2008/2015/2020验证）：
  - 沪深300 vs 中证500：ρ≈0.85（↑0.20）
  - 银行 vs 科技：ρ≈0.70（↑0.40）
  - A股 vs 美股：ρ≈0.55（↑0.35）

结论：危机时分散化效果大幅缩水。
假设你持有5只"不相关"股票构建了"安全"组合——
在危机中它们会一起跌，不是因为你选股不好，而是因为相关性本身变了。
```

### 5.3 相关性风险的预警规则

| 条件 | 风险等级 | 行动 |
|:-----|:------:|:-----|
| 组合平均相关性ρ_avg < 0.3 | 正常 | 分散化有效 |
| 0.3 ≤ ρ_avg < 0.5 | 黄色预警 | 重新审视行业分散度 |
| 0.5 ≤ ρ_avg < 0.7 | 橙色预警 | 强制减仓至少1/3，增加跨板块分散 |
| ρ_avg ≥ 0.7 | 红色预警 | 组合接近同质化，分散化完全失效 |

### 5.4 相关性矩阵实战计算

```
对于N只持仓的组合：
  1. 计算每对持仓的日收益率Pearson相关系数（用最近60个交易日）
  2. 构建N×N相关性矩阵
  3. 计算平均相关性 = (Σ所有非对角线相关系数) / (N×(N-1))
  4. 检查：是否有任何一对相关性 > 0.80？（同质化警告）
  5. 检查：平均相关性在近20日是否有上升趋势？
```

## 六、波动率建模

### 6.1 EWMA模型（RiskMetrics标准，λ=0.94）

```
EWMA方差：
σ²_t = λ × σ²_{t-1} + (1-λ) × r²_{t-1}

其中：
λ = 0.94（RiskMetrics标准，日频数据）
r_{t-1} = t-1日的收益率

含义：今天的波动率 = 94%的昨天波动率 + 6%的昨天平方收益率
半衰期 ≈ ln(0.5)/ln(0.94) ≈ 11.2个交易日
```

### 6.2 GARCH(1,1)模型

```
GARCH(1,1)：
σ²_t = ω + α × ε²_{t-1} + β × σ²_{t-1}

其中：
ω = 长期平均方差 × (1-α-β)
α = 新信息权重（ARCH项，通常 0.05-0.15）
β = 旧信息权重（GARCH项，通常 0.80-0.90）
α+β = 持续性参数（越接近1，冲击持续越久）

A股典型参数（沪深300，日频）：
ω = 0.000002
α = 0.08
β = 0.90
α+β = 0.98 → 冲击半衰期 ≈ ln(0.5)/ln(0.98) ≈ 34个交易日
```

### 6.3 GARCH在A股风控中的应用

```
应用1：动态止损——在GARCH预测波动率升高时收紧止损幅
  止损幅度 = max(2×ATR(14), 2×σ_GARCH × sqrt(5))

应用2：仓位动态调整——波动率升高时降低仓位
  实际仓位 = 目标仓位 × (σ_target / σ_GARCH)

应用3：VaR动态调整——用GARCH替代常数波动率
  VaR_dynamic(95%) = μ - 1.645 × σ_GARCH
```

### 6.4 EWMA vs GARCH 选择指南

| 条件 | 推荐模型 | 原因 |
|:-----|:--------|:-----|
| 日频交易，数据量<100天 | EWMA (λ=0.94) | GARCH需要更多数据估计参数 |
| 周频/月频评估 | GARCH(1,1) | 长期波动率均值回归特征更明显 |
| 快速反应波动率变化 | EWMA (λ=0.90) | 降低λ可增加对近期信息的敏感度 |
| 要求稳定估计 | GARCH(1,1) | 参数稳定，预测更平滑 |

## 七、风险预算

### 7.1 三种风险分配方式

| 方法 | 逻辑 | 公式 | 适用场景 |
|:-----|:-----|:-----|:---------|
| 等权重 (1/N) | 每只股票分配相同资金 | w_i = 1/N | 无信息优势时最简单基准 |
| 等风险贡献 (ERC) | 每只股票贡献相同的组合风险 | RC_i = w_i × ∂σ_p/∂w_i = 1/N × σ_p | 追求风险分散化 |
| 最大分散度 (MDP) | 最大化分散化比率 | DR = w^Tσ / sqrt(w^TΣw) | 想尽可能分散但不等权 |

### 7.2 等风险贡献（ERC）计算步骤

```
步骤1：定义组合风险
σ_p = sqrt(w^T Σ w)

步骤2：计算每只资产的边际风险贡献
MRC_i = ∂σ_p/∂w_i = (Σw)_i / σ_p

步骤3：计算每只资产的风险贡献
RC_i = w_i × MRC_i = w_i × (Σw)_i / σ_p

步骤4：求解等风险贡献权重
目标：RC_i = σ_p/N , ∀i
约束：Σw_i = 1, w_i ≥ 0

这通常需要用数值优化（如SQP算法）求解。
```

### 7.3 风险预算在项目中的应用规则

| 规则编号 | 规则内容 | 阈值 |
|:-------:|:---------|:---:|
| RB-01 | 单只股票最大风险贡献不超过总组合风险的30% | RC_i/σ_p ≤ 30% |
| RB-02 | 单一行业最大风险贡献不超过总组合风险的40% | RC_sector/σ_p ≤ 40% |
| RB-03 | 总仓位VaR(95%)不超过总资金的-5%（日） | VaR(95%) ≥ -5% |
| RB-04 | 总仓位CVaR(99%)不超过总资金的-10%（日） | CVaR(99%) ≥ -10% |
| RB-05 | 若ERC无法计算（数据不足），退回等权重1/N | N/A |

### 7.4 风险预算动态调整

| 触发条件 | 调整动作 |
|:---------|:---------|
| 组合GARCH波动率上升50% | 总仓位按波动率倒数缩放至50% |
| 连续3日亏损 | 总仓位降至当前50% |
| 某只股票连续2日跌停 | 该股风险预算立即归零 |
| 行业集中度触发红色预警 | 该行业所有持仓风险预算降至50% |

## 八、快速参考卡

### 8.1 风险度量速查

```
场景：快速估算单日最坏亏损
  步骤1：确定持仓市值
  步骤2：确定板块（对应σ_daily）
  步骤3：VaR(95%) = 市值 × (μ - 1.645×σ)
  步骤4：VaR(99%) = 市值 × (μ - 2.326×σ)
  步骤5：CVaR(95%) ≈ VaR(95%) × 1.6（经验乘数）

场景：评估组合分散化程度
  步骤1：计算持仓间60日Pearson相关性矩阵
  步骤2：取非对角线元素平均值ρ_avg
  步骤3：对照§5.3的风险等级表

场景：波动率突变应对
  步骤1：计算σ_GARCH / σ_60day（当前/历史波动率比）
  步骤2：如果比值>1.5 → 波动率异常升高
  步骤3：仓位缩放系数 = min(1, 1.5 / 比值)
```
