## 一、Wyckoff 核心理论

### 1.1 核心思想

Richard Wyckoff（1873-1934）提出的量价分析方法，其核心信念是：

> **市场由"Composite Operator"（综合主力/聪明钱）驱动。通过分析价格和成交量的互动关系，可以识别主力当前处于吸筹、拉升、派发还是下跌阶段，从而跟随主力步伐操作。**

Wyckoff 不是预测市场，而是**识别市场当前阶段并顺势而为**。

### 1.2 四阶段循环

```
吸筹区(Accumulation) → 拉升区(Markup) → 派发区(Distribution) → 下跌区(Markdown)
      ↑                                                                   ↓
      └────────────────────────── 循环 ──────────────────────────────────┘
```

### 1.3 Wyckoff 三大定律

| 定律 | 内容 | 实战含义 |
|:-----|:-----|:--------|
| **供需定律** | 供>求价格下跌，求>供价格上涨 | 量价关系是供需的直观反映 |
| **因果定律** | 横盘蓄力的时间越长，后续趋势的幅度越大 | 吸筹/派发区越久，后续涨跌幅度越大 |
| **努力与结果定律** | 成交量(努力)与价格变动幅度(结果)应成比例 | 放量但价格不涨=努力无结果=危险信号 |

## 二、第一阶段：吸筹区（Accumulation）

主力在低位通过震荡建仓，持续时间通常为数周到数月。

### 2.1 吸筹区关键事件序列

```
PS → SC → AR → ST → (Spring) → SOS → LPS → 进入拉升区
```

### 2.2 各事件详解

| 事件 | 英文 | 量价特征 | 含义 |
|:-----|:-----|:--------|:-----|
| **PS** | Preliminary Support | 下跌后首次出现放量阳线，买方开始介入 | 初步支撑，下跌可能接近尾声 |
| **SC** | Selling Climax | 恐慌性放量暴跌，随后快速反弹（日内反转） | 最后一批恐慌盘出逃，"筹码交换"最激烈时刻 |
| **AR** | Automatic Rally | SC之后的自然反弹，量能一般 | 测试上方阻力，确认SC低点是有效支撑 |
| **ST** | Secondary Test | **缩量**回踩SC低点附近但不跌破 | 最关键的确诊信号——没有更多的卖盘了 |
| **Spring** | 震仓/弹簧 | 短暂跌破SC/ST低点后迅速拉回，常带长下影线 | 主力故意砸破支撑洗出最后的不坚定筹码 |
| **SOS** | Sign of Strength | **放量**突破吸筹区上方阻力（AR高点附近） | 强势信号，买方力量压倒卖方 |
| **LPS** | Last Point of Support | SOS突破后**缩量**回踩突破位不破 | 最佳买点！突破确认+回踩确认双验证 |

### 2.3 Spring（震仓）深度解析

Spring 是 A 股中最常见的洗盘手法：
1. 股价在吸筹区横盘数周，散户以为"跌不下去了"
2. 某日突然缩量急跌 3-5%，跌破横盘下沿
3. 恐慌盘抛出后，股价在当日或次日迅速拉回
4. 拉回后随即放量突破，进入拉升期

**Spring 的识别特征**：
- 下跌过程缩量（不是真抛售）
- 跌破支撑的时间很短（通常1-2日即拉回）
- 拉回时阳线实体较大
- 发生在横盘整理阶段，而非主跌浪

## 三、第二阶段：拉升区（Markup）

吸筹完成后，主力开始推高股价。这是最赚钱的阶段。

### 3.1 拉升区特征

- **回调缩量 + 反弹放量** = 趋势健康（最核心判断）
- SOS -> LPS -> SOS 交替出现 = 趋势延续
- 回调不破前低 = 上升趋势完整
- 均线多头排列且向上发散

### 3.2 拉升中的回调（LPS反复出现）

拉升区中每次缩量回调到均线支撑位企稳，都是一次 LPS 性质的加仓机会。每次放量突破前高，都是一次 SOS 性质的确认。

---

## 四、第三阶段：派发区（Distribution）

主力在高位出货，持续时间通常为数周到数月。

### 4.1 派发区关键事件序列

```
PSY → BC → AR → ST → (UT/UTAD) → SOW → LPSY → 进入下跌区
```

### 4.2 各事件详解

| 事件 | 英文 | 量价特征 | 含义 |
|:-----|:-----|:--------|:-----|
| **PSY** | Preliminary Supply | 上涨后首次出现放量阴线，卖方开始介入 | 初步供应，上涨可能接近尾声 |
| **BC** | Buying Climax | 放量拉升后冲高回落，日内出现长上影线 | 最后一批追涨资金进场，主力借机出货 |
| **AR** | Automatic Reaction | BC之后的自然回落 | 测试下方支撑 |
| **ST** | Secondary Test | **缩量**反弹测试BC高点但不破 | 买盘衰竭——没有那么多人愿意追高了 |
| **UT** | Upthrust | 短暂突破BC/ST高点后迅速回落 | 假突破，诱多陷阱 |
| **UTAD** | Upthrust After Distribution | 派发后期的高位假突破 | A股题材股最经典的见顶形态 |
| **SOW** | Sign of Weakness | **放量**跌破派发区下沿支撑 | 弱势信号，卖方力量压倒买方 |
| **LPSY** | Last Point of Supply | SOW跌破后**缩量**反弹至跌破位不破 | 最佳卖点/做空点！最后的逃命机会 |

### 4.3 UTAD -- A股最致命的陷阱

UTAD 在 A 股题材股中极为常见，流程如下：
1. 股价已从底部上涨 50%-200%（大幅盈利后）
2. 高位横盘整理（主力已在悄悄出货）
3. 某日突然放利好消息（可能是主力配合放出的消息）
4. 股价开盘冲高 3-5%，盘中创出新高
5. 但好景不长，当日冲高回落，收长上影线
6. 后续开始缩量阴跌，最终放量暴跌

**UTAD vs 真突破的区分**：
| 特征 | UTAD（假突破） | 真突破 |
|:-----|:------------|:------|
| 位置 | 大幅上涨后高位 | 低位或中位 |
| 突破时量能 | 放量但无法维持 | 持续放量 |
| 突破后走势 | 当日或次日回落 | 连续数日在突破位上方运行 |
| 消息面 | 伴随利好消息发布 | 不一定有特别消息 |

---

## 五、第四阶段：下跌区（Markdown）

派发完成后进入下跌趋势。

### 5.1 下跌区特征

- 反弹缩量 + 下跌放量 -> 趋势恶化
- SOW -> LPSY -> SOW 交替 -> 下跌延续
- 反弹不破前高 -> 下降趋势完整
- 均线空头排列且向下发散

## 六、量价配合规律（通用法则）

### 6.1 基本组合

| 量价形态 | 供需解读 | 信号 | 项目评分对应 |
|:---------|:--------|:----|:-----------|
| **价涨量增** | 需求 > 供给，增量资金持续入场 | 健康上涨，持仓或加仓 | S3 放量上涨+4分 |
| **价涨量缩** | 供给减少但需求也不足 | 上涨乏力，警惕回调 | 量价背离，扣分信号 |
| **价跌量缩** | 供给减少，抛压减轻 | 正常调整，不一定看空 | 需结合位置判断 |
| **价跌量增** | 抛压增大 | 恐慌抛售(SC)或主力出货(SOW) | 需位置判断 |
| **放量突破阻力** | 买方意愿强烈 | SOS，突破有效概率高 | S3 横盘后放量突破+5分 |
| **缩量回踩支撑** | 卖盘枯竭 | LPS，最佳买点 | S3 洗盘后突破+4分 |
| **放量不涨** | 高位卖盘在消化买盘 | 主力可能在出货 | S3 高位放量滞涨+1分 |
| **缩量下跌** | 主动性卖盘减少 | 下跌动能衰竭 | 可能接近底部 |

### 6.2 努力与结果定律的应用

这条定律是 Wyckoff 分析中最实用的工具：

- **放量 + 大阳线** = 努力有结果 -> 上涨真实，可信
- **放量 + 小阳线/十字星** = 努力无结果 -> 卖盘在消化买盘 -> **警惕**
- **放量 + 阴线** = 卖盘压倒买盘 -> 看空
- **缩量 + 大阳线** = 少量买盘即可推高 -> 抛压轻，看多
- **缩量 + 大阴线** = 少量卖盘即可砸低 -> 无承接，看空

## 七、A股实战中的 Wyckoff

### 7.1 A股的 Wyckoff 特征

1. **散户占比高导致形态更明显**：A股散户交易占比约60%（美股约10%），主力操盘的痕迹更重，Wyckoff 吸筹/派发形态更清晰
2. **震仓(Spring)极其常见**：缩量急跌 -> 快速拉回 -> 随即拉升，是A股主力最喜欢的手法
3. **UTAD 在题材股中是必修课**：高位利好消息放出 -> 冲高回落 -> 开始暴跌，大量散户在此被套
4. **政策催化打破 Wyckoff 节奏**：重大政策可以跳过吸筹直接进入拉升，或提前终止派发

### 7.2 日线级 Wyckoff vs 分时级 Wyckoff

- **日线**：判断大周期位置（吸筹/拉升/派发/下跌），用于战略方向
- **60分钟线**：识别短期的 SOS/LPS/UT，用于精确入场时机
- 日线 Wyckoff 阶段 + 60分钟 LPS = 最佳入场时机

**Step 1 -- 定位大趋势**：查看月线/周线的长期价格位置（底部/中位/高位）
**Step 2 -- 寻找关键量价事件**：最近30个交易日内是否有 SC/BC/Spring/SOS/UTAD 等事件？

**Step 4 -- 验证**：检查均线排列、MACD方向、成交量趋势是否与阶段判断一致

## 九、自测题（附答案）

**Q1: Wyckoff 的 SOS 和 LPS 有什么区别？在项目技术评分中分别对应哪些子项？**

A:
- **SOS（Sign of Strength）**：放量突破吸筹区上方阻力位，是买方力量的强势确认信号。发生在突破的关键时刻。
- **LPS（Last Point of Support）**：SOS突破后缩量回踩突破位不破，是确认支撑有效的信号。发生在突破后的回调中。
- 本质区别：SOS = 突破时刻（进攻），LPS = 回踩确认（防守）。
- 项目对应：SOS 对应每日荐股v2.4 S3中的"横盘后放量突破"（+5分）；LPS 对应"洗盘后突破"（+4分）。两者的分数差异反映了 SOS 是更明确的信号（+5 vs +4）。

---

**Q2: 震仓（Spring）和假突破（UTAD）如何区分？**

A:

| 维度 | Spring（震仓） | UTAD（假突破） |
|:-----|:------------|:------------|
| 大周期位置 | **低位**（长期下跌后横盘） | **高位**（大幅上涨后横盘） |
| 方向 | 先向下假跌破支撑 | 先向上假突破阻力 |
| 随后走势 | 迅速拉回支撑上方，随即拉升 | 迅速跌回阻力下方，随即暴跌 |
| 量能 | 跌破时缩量，拉回时放量 | 突破时放量但无法维持 |
| 角色 | 洗出浮筹，为拉升做准备 | 诱多出货，为下跌做准备 |
| 均线状态 | 均线从缠绕开始向上发散 | 均线从高处开始走平或死叉 |

关键判断：**位置决定性质**。低位 + 缩量急跌拉回 = Spring（机会）；高位 + 放量冲高回落 = UTAD（陷阱）。

**Q3: 6只重点股票当前分别处于 Wyckoff 哪个阶段？**

A: 这需要实际查看各股票的K线图和量价数据才能判断。但分析框架如下：

对每只股票执行以下判断流程：
1. 查看日线/周线价格处于近一年的什么位置（底部30% / 中部 / 顶部30%）
2. 寻找近30日内的量价特征事件（SC/BC/Spring/SOS/UTAD等）
3. 按事件序列归类：
   - 出现 SC -> AR -> ST -> Spring -> SOS -> LPS 序列 = **吸筹区后期/拉升区初期**
   - 均线多头排列 + 回调缩量反弹放量 + 没有明显的派发事件 = **拉升区**
   - 出现 BC -> AR -> ST -> UT -> SOW 序列 = **派发区**
   - 均线空头排列 + 反弹缩量下跌放量 = **下跌区**
4. 输出每个股票当前阶段并给出对应的操作策略

详见重点股票v2.2 第1.1.2节和附录B。

**Q4: "放量不涨"意味着什么？在不同位置的含义有何不同？**

A:
- **低位放量不涨**：买盘在进入但卖盘（套牢盘解套+主力吸筹打压）同时存在，属于吸筹过程中的正常博弈。后续如果突破放量区上沿，说明吸筹完成。
- **中位放量不涨**：可能是上升趋势中的换手（空中加油），也可能是趋势转弱的信号。需要看后续走势确认。
- **高位放量不涨**：最危险的信号。主力在利用追涨盘的买入来出货。如果连续3-5日放量但价格原地踏步，派发概率极高。对应每日荐股v2.4 S3高位放量滞涨仅得1分。

核心原则（Wyckoff 努力与结果定律）：成交量（努力）与价格变动（结果）应成比例。放量但不涨 = 大量努力没有得到应有的结果 = 反面有人在吸收这些努力（即有人在大量卖出）。
