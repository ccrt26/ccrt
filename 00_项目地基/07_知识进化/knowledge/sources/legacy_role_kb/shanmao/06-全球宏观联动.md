## 一、美元指数（DXY）与A股

### 1.1 负相关逻辑链

```
美元指数(DXY) ↑ → 新兴市场资金流出 → 北向资金流出 → A股承压
美元指数(DXY) ↓ → 新兴市场资金流入 → 北向资金流入 → A股受益

传导机制：
1. 资金流渠道：美元走强 → 全球资金流向美国（更高的无风险收益+汇率升值）
   → 新兴市场权益资产被减持 → A股资金面偏紧
2. 汇率渠道：美元走强 → 人民币贬值 → 以外币计价的A股资产"缩水"
   → 外资持A股的意愿下降
3. 基本面渠道：美元走强 → 大宗商品价格承压（以美元计价）
   → 资源国经济承压 → 全球经济增长预期下修
4. 企业层面：美元走强 → 有美元债务的企业偿债负担加重
   → 持有大量海外美元债的行业（航空/地产/能源）财务成本上升
```

### 1.2 DXY关键阈值与A股映射

| DXY区间 | 全球含义 | A股含义 | 北向资金预期 | 受益板块 | 受损板块 |
|:--------|:---------|:--------|:----------|:---------|:---------|
| <95 | 美元极度弱势 | 强力利好 | 大幅流入 | 有色/黄金/科技 | 外贸出口型 |
| 95-100 | 美元偏弱 | 温和利好 | 温和流入 | 消费/医疗 | 不明显 |
| 100-105 | 中性区间 | 中性 | 平衡 | — | — |
| 105-110 | 美元偏强 | 温和利空 | 温和流出 | 出口型制造(贬值受益) | 航空/地产(美元债) |
| >110 | 美元极度强势 | 显著利空 | 大幅流出 | 仅黄金/避险资产 | 全面承压 |

### 1.3 DXY趋势判断的实用规则

```
DXY的"连续趋势"比绝对值更重要：
  DXY连续5个交易日上涨 → 短期压制A股情绪
  DXY连续10个交易日上涨 → 北向资金大概率开始连续流出
  DXY单日大涨 > 1% → A股当日大概率低开

DXY与A股的"同步窗口"：
  DXY突破105整数关口 → 山猫应立即标注"美元走强预警"
  DXY突破110 → 系统性风险信号，建议降低A股仓位
  DXY跌破100 → 系统性利好，北向资金大概率加速流入

背离信号：
  DXY走强 + A股也走强 → A股内在动力极强（"该跌不跌"） → 牛市确认
  DXY走弱 + A股也走弱 → A股内在动力极弱（"该涨不涨"） → 熊市确认
```

## 二、美债收益率（10Y UST）与A股

### 2.1 传导机制 —— DCF估值的分母效应

```
美债10年期收益率是全球资产定价的"锚"（无风险利率rf）

DCF估值公式：
  股票内在价值 = Σ(FCF_t / (1 + r)^t)
  其中 r = 无风险利率 + 风险溢价

传导：
  UST 10Y ↑ → rf ↑ → r ↑ → 未来现金流的折现值 ↓ → 估值 ↓
                   （尤其对成长股：大部分价值在遥远的未来，折现效应更明显）

因此：
  UST 10Y ↑ → 成长股（高PE/远期现金流）估值受压最重 → 科技/创新药/AI
  UST 10Y ↓ → 成长股估值扩张 → 科技/创新药/AI受益最大
```

### 2.2 UST 10Y阈值与A股映射

```
UST 10Y区间（2025年背景）：
  < 3.5% → 全球利率环境边际宽松 → 成长股估值扩张 → 创业板/科创板受益
  3.5-4.0% → 中枢区间，A股按自身逻辑运行
  4.0-4.5% → 全球利率偏紧 → 成长股承压 → 风格转向价值/红利
  4.5-5.0% → 全球利率高压 → A股全面承压（高利率=流动性紧张）
  > 5.0% → 极端状态，"不要和美联储作对" → 现金为王，防御为主
```

### 2.3 UST 10Y变化的A股映射（delta维度）

```
UST 10Y单日变化 > +10bp → 成长股当日承压，创业板大概率跑输沪深300
UST 10Y单日变化 < -10bp → 成长股当日受益，创业板大概率跑赢
UST 10Y连续5日上升累计 > 20bp → 风格切换信号：关注从成长→价值的切换
UST 10Y连续10日下降累计 > 30bp → 成长反弹窗口

美债收益率曲线（10Y-2Y利差）：
  10Y-2Y > 0（正常，长期利率 > 短期）→ 经济正常
  10Y-2Y < 0（倒挂）→ 衰退预警信号（历史上领先衰退约12-18个月）
  10Y-2Y由负转正（结束倒挂）→ 衰退即将发生的最终确认信号

对于A股：
  收益率曲线倒挂 ≠ 立刻看空A股（有滞后性）
  倒挂结束时 → 应更加警惕（历史上衰退多在倒挂结束后开始）
```

### 2.4 TIPS收益率（实际利率）

```
TIPS（通胀保值债券）收益率 = 名义UST收益率 - 预期通胀率

TIPS收益率 > 1.5% → 实际利率偏高 → 黄金承压、成长股承压
TIPS收益率 < 0% → 实际利率为负 → 黄金受益、成长股受益
TIPS收益率上升 > 30bp/月 → 全球金融条件收紧 → A股偏空
```

## 三、大宗商品传导

### 3.1 原油（布伦特/WTI）

```
对A股的传导路径：

原油价格 ↑：
  正面影响：
    - 石化上游（中国石油/中国石化/中海油服）→ 直接受益
    - 新能源替代逻辑强化（光伏/风电/新能源车）→ 间接受益
    - 煤化工（油价高时煤化工经济性改善）→ 间接受益
  负面影响：
    - 航空/交通运输（燃油成本占运营成本20-40%）→ 利润压缩
    - 化工中下游（原料成本上升）→ 利润压缩
    - 物流/快递（运输成本上升）→ 利润压缩
    - 整体：油价 > 100美元 → 输入性通胀 → 央行收紧货币政策 → 利空全局

原油价格 ↓：
  正面：航空/交运/化工中下游/消费（居民加油成本降）→ 成本红利
  负面：石化上游/煤化工/新能源替代逻辑弱化 → 利润下滑

关键阈值：
  布伦特 $60-80 → 正常区间，对A股影响中性
  布伦特 $80-100 → 偏高水平，关注输入性通胀
  布伦特 > $100 → 高位，对全球经济是负向冲击
  布伦特 < $50 → 极度供给过剩，对产油国经济是严重打击
```

### 3.2 铜（"铜博士"）

```
铜价是全球经济的"博士"——铜价变动领先全球经济周期约3-6个月

铜价 ↑：
  含义：全球经济复苏预期增强 → 利好全球风险资产
  对A股行业：铜矿/冶炼企业直接受益，工业金属板块走强
  铜价与中证500相关性 > 与沪深300相关性（铜反映工业需求，偏中游）

铜价 ↓：
  含义：全球经济衰退风险上升 → 避险情绪升温
  领先A股下行约1-3个月（"铜博士"先行指标）

LME铜价阈值：
  > $10000/吨 → 全球经济强劲，利好周期股
  $8000-10000 → 经济正常
  $7000-8000 → 经济放缓信号
  < $7000 → 经济衰退风险上升 → A股系统性风险
```

### 3.3 黄金

```
黄金是纯粹的"避险晴雨表"

金价 ↑：
  含义：全球不确定性上升 / 美元走弱 / 实际利率下行 / 地缘风险上升
  对A股：整体偏负面（黄金涨=避险=风险偏好下降）
  板块：黄金股（山东黄金/中金黄金等）直接受益

金价与A股的关系：
  黄金涨 + A股跌 → 典型避险模式，持续期不定，关注触发事件的解决
  黄金涨 + A股也涨 → 流动性驱动（钱多了同时买黄金和股票）
  黄金跌 + A股涨 → 风险偏好提升（"Risk On"确认）
  黄金跌 + A股也跌 → 流动性枯竭（变现一切资产）→ 最危险模式

关键阈值：
  黄金 > $2500/盎司 → 全球避险情绪达到较高水平
  黄金创历史新高 → 山猫应询问"是什么在引发如此强烈的避险？"
```

## 四、地缘政治事件影响评估

### 4.1 对A股的传导路径

地缘政治事件对A股的影响，取决于事件的类型、规模、与中国的关系。

```
传导路径1：资金避险（最快，数小时内）
  地缘事件 → 全球资金流向避险资产（美债/黄金/美元）→ 新兴市场权益被减持 → A股承压

传导路径2：供应链冲击（数日至数周）
  地缘事件 → 关键原材料/能源供应中断 → 相关产业成本上升 → 企业利润下降

传导路径3：政策反应（数周至数月）
  地缘事件 → 各国出台反制/制裁/刺激政策 → 产业格局变化

传导路径4：长期格局变化（数月到数年）
  地缘事件 → 全球化模式变化 → 供应链重构 → 产业布局变化
```

### 4.2 影响评估矩阵

| 事件类型 | 对A股的直接影响 | 持续时间 | 恢复速度 | 避险应对 |
|:---------|:--------------|:--------:|:--------:|:---------|
| 台海紧张升级 | 重度冲击（全面） | 数日至数周 | 慢（持续性风险） | 大幅减仓 |
| 中美贸易/科技摩擦升级 | 重度-中度（定向行业） | 数周至数月 | 中 | 减受损行业，关注自主可控 |
| 中东冲突扩大化 | 中度（油价通道） | 数周 | 中（油价回落则恢复） | 增持石油/军工对冲 |
| 俄乌/欧洲地缘冲突 | 中度（大宗商品/外需） | 数月 | 慢 | 关注出口型企业风险 |
| 朝鲜半岛紧张 | 中度（短期恐慌） | 数日至1周 | 快（通常不持久） | 观望，不急于操作 |
| 南海争端 | 轻度（局部） | 数日 | 快 | 影响有限 |
| 全球性传染病/疫情 | 重度（需求冲击） | 数月 | 慢 | 防御性配置 |
| 重大自然灾害 | 轻度-中度（地区性） | 数日至数周 | 中-快（重建需求） | 关注保险/建材 |

### 4.3 事件评估四步法

山猫对任何地缘政治事件，按以下步骤评估：

```
步骤1 — 事件性质判定：军事冲突 / 经济制裁 / 外交争端 / 技术封锁 / 其他
步骤2 — 与中国关联度：直接涉及中国 / 间接影响中国 / 与中国关系不大
步骤3 — 影响路径识别：资金避险 / 供应链冲击 / 政策反应 / 格局变化
步骤4 — A股影响评估：
  - 影响范围：全面 vs 定向行业
  - 影响程度：重度/中度/轻度
  - 影响时长：数日/数周/数月
  - 建议：减仓/观望/对冲/不操作

事件发展过程中，每天跟踪：
  - 事件是否升级/降级
  - 市场是否定价充分（"Price in"）
  - 是否有新的影响路径出现
```

## 五、全球资金流向

### 5.1 EPFR（Emerging Portfolio Fund Research）数据

```
EPFR追踪全球基金的资金流向，是外资对新兴市场态度的核心指标

对A股的意义：
  EPFR新兴市场股票基金连续净流入 → 外资对中国的配置意愿上升 → A股利好
  EPFR中国专项基金净流入 → 最直接的信号

频率限制：
  EPFR数据为周度发布（每周五公布周三的数据），有3-4天延迟
  因此主要用来判断中期趋势，而非短期择时
```

### 5.2 全球资金"Risk On / Risk Off"框架

```
Risk On（风险偏好上升）：
  资金流向：权益 > 债券 > 现金
  区域流向：新兴市场 > 发达市场
  板块偏好：科技/周期 > 防御/红利
  信号：
    - EPFR新兴市场周度净流入
    - VIX下降 + 美股上涨
    - 美元指数走弱
    - 铜价上涨 + 金价稳定或下跌

Risk Off（风险偏好下降）：
  资金流向：现金 > 债券 > 权益
  区域流向：发达市场 > 新兴市场
  板块偏好：防御/红利 > 科技/周期
  信号：
    - EPFR新兴市场周度净流出
    - VIX飙升 + 美股下跌
    - 美元指数走强
    - 金价上涨 + 铜价下跌
```

### 5.3 新兴市场 vs 发达市场资金流向

```
新兴市场相对于发达市场的资金流入优势：
  - MSCI新兴市场指数 > MSCI发达市场指数（相对收益）→ 对A股有利
  - 此相对优势通常持续3-6个月，形成趋势后不容易突然逆转
  - 美元指数是此相对优势的最重要驱动因子
```

## 六、VIX / CBOE波动率

### 6.1 VIX指数解读

```
VIX（CBOE Volatility Index）= 标普500指数的隐含波动率，被称为"恐慌指数"

VIX区间含义：
  < 12 → 市场极度平静（可能过于自满，警惕黑天鹅）
  12-15 → 低波动，市场平静，风险偏好
  15-20 → 正常波动
  20-25 → 波动偏高，市场略显不安
  25-30 → 市场紧张，可能有事件冲击
  > 30 → 恐慌状态，大规模抛售
  > 40 → 极度恐慌，类似2008/2020危机级别
```

### 6.2 VIX对A股的影响

```
传导逻辑：
  VIX飙升 → 全球风险偏好骤降 → 外资从新兴市场撤退 → 北向资金流出 → A股承压

VIX变化率比绝对值更重要：
  VIX单日上涨 > 30% → 全球恐慌信号 → 次日A股大概率低开
  VIX单日上涨 > 50% → 极度恐慌 → A股次日低开幅度通常 > 2%
  VIX连续3日回落 → 恐慌消退 → 市场企稳信号

VIX与A股的"非对称性"：
  VIX ↑ 时A股跟跌的概率高（约70%）
  VIX ↓ 时A股不一定跟涨（约50%，因A股有独立的国内因素）
  即：A股对全球恐慌的敏感度 > 对全球平静的敏感度
```

### 6.3 VIX期限结构

```
VIX期货期限结构（VIX期货 vs VIX现货）：
  Contango（期货 > 现货，正常状态）→ 市场预期未来波动大于当前 → 不算恐慌
  Backwardation（期货 < 现货，倒挂状态）→ 当前恐慌程度超过未来预期 → 恐慌见顶信号 → 可能即将反转
```

## 七、亚洲市场联动

### 7.1 恒生指数（HSI）与A股

```
恒生指数 vs 上证综指的相关性：约0.7-0.8（高度相关）

差异分析：
  HSI > A股（恒指强于上证）→ 外资对中国的态度比内资更积极 → 关注北向资金是否流入
  HSI < A股（恒指弱于上证）→ 外资观望/撤退 → A股可能也难独善其身

AH溢价指数（追踪A股相对于H股的溢价水平）：
  AH溢价 > 140 → A股估值相对港股偏高 → 往H股方向回归的概率增大
  AH溢价 < 115 → A股估值相对港股偏合理/偏低
  通常范围：120-140之间
```

### 7.2 韩国KOSPI与日本日经

```
韩国KOSPI：
  - 半导体产业链（三星/SK海力士）占比极高
  - KOSPI走势领先半导体景气度的确认信号
  - KOSPI走强 → 半导体需求旺盛 → A股半导体板块跟涨
  - 与A股创业板指的相关性较高（两者均偏科技）

日本日经225：
  - 日元汇率是日经走势的重要驱动（日元贬值=日经涨）
  - 日经与A股的联动性中等（约0.3-0.5）
  - 日经走强 + A股走弱 → 日本承接了从中国流出的部分外资
  - 日经和A股同涨 → 亚洲资金全面流入
```

### 7.3 亚洲市场联动速查

| 信号 | A股含义 |
|:-----|:--------|
| 恒生+日经+KOSPI同涨 | 亚洲资金全面做多，A股大概率跟涨 |
| 恒生+日经+KOSPI同跌 | 亚洲资金全面撤退，A股防御为主 |
| 恒生涨+A股跌 | 外资看好但内资撤退，关注背离原因 |
| 恒生跌+A股涨 | 内资主导行情（国家队/游资），外资观望 |
| KOSPI领涨亚洲 | 半导体周期上行信号 |

## 八、美联储FOMC周期对A股的影响机制

### 8.1 FOMC周期的A股节奏

```
完整的FOMC周期的A股节奏：

FOMC前1-2周（预期博弈期）：
  - 市场开始消化可能的加息/降息预期
  - 北向资金可能出现观望或提前布局
  - A股波动率略有上升
  - 板块：金融/周期对利率预期最敏感

FOMC决议日（美东周三，北京时间周四凌晨）：
  - T+0当日（周四A股）：以消化信息为主，多看少动
  - 上午观察北向资金方向，下午确定跟随策略
  - 板块：决议超预期宽松 → 科技/成长涨；超预期紧缩 → 防御/红利涨

FOMC后1周（方向确认期）：
  - 北向资金方向确认（通常会后2-3天最关键）
  - A股跟随北向方向但幅度小于北向变化

FOMC后1个月（重新定价期）：
  - 市场完全消化利率决议
  - 回归基本面驱动
```

### 8.2 FOMC各类决议的市场影响

```
加息 vs 降息 vs 按兵不动：

加息（Fed Funds Rate ↑）：
  - 全球金融条件收紧 → 新兴市场资金流出 → A股偏空
  - 加息幅度超预期 → 冲击最大
  - 加息符合预期 → "靴子落地"，如果会前跌了足够多，会后可能反弹

降息（Fed Funds Rate ↓）：
  - 全球金融条件放松 → 新兴市场资金流入 → A股偏多
  - 降息但因"经济衰退"而降 → 信号复杂：降息好+衰退坏 → 看哪个逻辑占上风
  - 降息且暗示持续降息 → 连续利好 → A股持续受益

按兵不动 + 鸽派措辞（Dovish）：
  - 暗示下次降息 → 相当于降息预期 → A股偏多

按兵不动 + 鹰派措辞（Hawkish）：
  - 暗示可能还需加息 → A股偏空

按兵不动 + 中性措辞：
  - 无方向，A股按自身逻辑运行
```

### 8.3 FOMC决议对A股影响的衰减规则

```
FOMC影响随时间衰减：
  决议当日：影响权重约40%（情绪冲击最大）
  决议后1周：影响权重约30%（方向确认）
  决议后1个月：影响权重约20%（重新定价）
  决议后3个月：影响权重约10%（几乎消化完毕）

例外：如果FOMC开启了明确的加息/降息周期（而非一次性的调整），影响会持续整个周期。
```
