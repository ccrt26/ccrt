## 1. 定位与边界

### 1.1 参数库属于 L-K5

参数库是五层知识结构的第五层（L-K5），管理**可校准但不应写死在报告里的阈值、窗口、权重、证据有效期和字段可信等级**。

核心原则：

| 原则 | 说明 |
|:-----|:-----|
| 参数优先于逻辑重写 | 若问题是阈值过紧/过松，先修参数，不重写分析逻辑 |
| 参数变更必须走候选流程 | 不能直接改参数，需角色确认+腰子终审+旧影审计 |
| 只有 `applied` 参数可作为生效规则 | `proposed`/`role_review`/`approved`/`parked` 均为观察项 |
| C 层不得引用未 applied 参数 | 用户摘要只能引用已生效参数 |

### 1.2 参数库不做什么

| 禁止项 | 说明 |
|:-------|:-----|
| ⛔ 不直接改生产参数 | 参数值修改需走候选→角色确认→腰子终审→应用 |
| ⛔ 不直接改评分权重 | 权重变更需青山+腰子确认 |
| ⛔ 不直接改否决项 | 否决项变更需流金+腰子确认 |
| ⛔ 不把 proposed 参数当 applied 参数 | 只有 applied 才能作为生效规则 |

## 2. 参数类别

| 参数类别 | 示例 | 首要角色 | 联审角色 |
|:---------|:-----|:---------|:---------|
| 技术阈值 | 支撑位偏差、突破确认天数、量能倍数 | 青山 | 流金 / 腰子 |
| 证据窗口 | L2a 催化有效期、公告后观察期 | 信鸽 | 腰子 |
| 数据可信等级 | moneyflow、融资融券、主营构成、公告全文 | 玉夜 | 腰子 |
| 风控边界 | 否决项阈值、降级触发、恢复条件 | 流金 | 腰子 |
| 宏观覆写 | M 层触发阈值、行业暂停条件 | 山猫 | 青山 / 腰子 |
| 结论强度 | 强跟踪、等待、降级、移出所需证据 | 腰子 | 流金 / 青山 |

## 3. 参数最小字段

### 3.1 字段定义

| 字段 | 必填 | 说明 | 示例 |
|:-----|:----:|:-----|:-----|
| parameter_id | 是 | 参数全局唯一 ID | PAR-20260610-QINGSHAN-TECH-001 |
| parameter_name | 是 | 参数名称 | 技术修复确认窗口 |
| category | 是 | 参数类别 | 技术 / 证据 / 数据 / 风控 / 宏观 / 结论强度 |
| current_value | 是 | 当前值或当前口径 | 3 个交易日 |
| proposed_value | 是 | 建议值或建议口径 | 5 个交易日 |
| unit | 是 | 单位 | 交易日 / 百分比 / 倍数 |
| applicable_scope | 是 | 适用场景和标的范围 | 深度周报技术分析段；适用于 A 股 |
| source_ref | 是 | 来源后评估/报告/候选 | 东睦周报后评估 - 青山候选 |
| linked_candidate_id | 否 | 关联 KnowledgeUpdateCandidate | KUC-20260610-QINGSHAN-001 |
| owner_role | 是 | 首要确认角色 | 青山 |
| reviewer_roles | 否 | 联审角色 | ["流金", "腰子"] |
| evidence_refs | 是 | 证据引用，至少 1 条 | 后评估记录 / EvalHook 数据 |
| change_reason | 是 | 修改原因 | 3 日窗口震荡市误触发率 40%，延至 5 日后降至 15% |
| risk_if_applied | 是 | 采纳风险 | 窗口过长可能错过早期突破信号 |
| risk_if_ignored | 是 | 忽略风险 | 窗口过短导致频繁误触发，影响信号可信度 |
| status | 是 | 参数状态 | proposed / role_review / approved / applied / rejected / parked |
| version | 是 | 参数版本 | v1.0 |
| effective_from | 否 | 生效日期；未生效填 null | null（待应用） |
| reviewed_at | 否 | 最近复核日期 | 2026-06-10 |

### 3.2 status 状态机

```
                    ┌───────────┐
                    │ proposed  │  ← 后评估产生参数候选
                    └─────┬─────┘
                          │
              ┌───────────┼──────────┐
              │           │          │
     ┌────────▼────┐    ╔══╧══╗   ┌─┴─────────┐
     │ role_review │    ║ REJ ║   │  parked   │
     │ 角色评审中  │    ╚═════╝   │ 暂存待样本 │
     └────────┬────┘             └─────┬─────┘
              │                        │
     ┌────────┼─────────┐            │
     │        │         │            │
   ┌─▼──┐  ┌──▼───┐  ╔══╧══╗      │
   │APP │  │REJ   │  │park │      │
   └─┬──┘  └──────┘  └─────┘      │
     │                              │
   ┌─▼──────────┐                  │
   │  applied   │  ← 已生效       │
   │ 可引用为规则│                  │
   └─┬──────────┘                   │
     │                              │
   ┌─▼──┐                         │
   │clo │                         │
   └────┘                         │
                                   │
   ┌────────────────────────────────┘
   │ superseded → closed
```

| 状态 | 含义 | 是否可作为生效规则 |
|:-----|:-----|:------------------:|
| proposed | 新参数候选 | **否** |
| role_review | 角色评审中 | **否** |
| approved | 角色确认可更新 | **否** |
| applied | 已生效 | **是** |
| rejected | 已否决 | — |
| parked | 暂存待样本 | **否** |

## 4. 修参数还是修逻辑

| 情况 | 优先动作 | 说明 |
|:-----|:---------|:-----|
| 阈值偏差大但因果链成立 | **修参数** | 参数库更新窗口/阈值/倍数 |
| 样本不足导致信号不稳 | **降低置信度或增加样本门槛** | 不否定信号方向，收窄范围 |
| 证据等级被误判 | **修证据等级规则或字段可信等级** | 信鸽+玉夜确认 |
| 事件窗口过短/过长 | **修窗口参数** | 参数库证据窗口类别 |
| 规则方向反复错误 | **修分析逻辑** | 非参数问题，需重构逻辑 |
| 逻辑正确但市场风格变化 | **修 M 层/策略环境参数** | 不否定原逻辑，加环境条件 |
| 日报未执行周报指令 | **修场景适配器或执行流程** | 非参数问题 |
