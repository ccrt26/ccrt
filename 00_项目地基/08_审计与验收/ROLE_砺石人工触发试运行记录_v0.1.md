## G2 — 审查模板

每个样本固定输出以下 7 项方法校准：

| # | 审查维度 | 评判标准 |
|:--|:---------|:---------|
| 1 | 最大隐含假设 | 推断中最关键但未声明的假设 |
| 2 | 最强反证 | 最重要的反面证据 |
| 3 | 同源证据重复 | 同一数据支撑多个独立推论 |
| 4 | 因果混淆风险 | 相关性被误读为因果 |
| 5 | 结论强度是否过强 | 结论是否超出证据范围 |
| 6 | 建议 | PASS / WARN / BLOCK |
| 7 | 给腰子的校准参考 | 一句话可操作建议 |

### 评判规则

- **PASS**：未发现明显方法问题
- **WARN**：存在反证不足、结论偏强、同源证据等问题，但不阻断
- **BLOCK**：强动作结论缺关键证据，或推理链严重不成立

## G3 — 执行审查

### 样本一：科大讯飞(002230)日报_20260604

**样本路径：** `重点股票/股票报告/科大讯飞(002230)/科大讯飞(002230)日报_20260604.md`
**场景：** 日报
**检查对象：** 综合结论（回避）、资金面推理

#### 关键段摘要

> 明日主动作：回避。主力-64998万，回调6.7%。不带触发条件。
>
> **资金面**：超大单-47743万 + 大单-18133万 = 主力合计-64998万，中单+19334万逆势承接。
>
> **信号胜率**：主力净流入信号53%胜率；空头排列样本不足20，不触发。

#### 砺石方法校准

| 维度 | 评估 |
|:-----|:------|
| **1. 最大隐含假设** | "-64998万主力流出=必须回避"——直接假设主力大幅流出一定意味着短期继续下跌。但未区分：机构是否因板块配置调整而被动卖出（若为被动→可能一次性），还是对公司基本面的主动减仓（若为主动→持续卖出）。两种原因的恢复周期差异显著 |
| **2. 最强反证** | 中单+19334万逆势承接，小单+46541万也在买入——说明散户和中等资金在积极接盘。如果这是"主力洗盘"模式而非"主力持续出逃"，回避判断可能错过短期反弹。另：S1支撑 N/A（基线未提供），缺少关键价位参考线 |
| **3. 同源证据重复** | 有：价格"回调6.7%"和资金"主力-64998万"被分别用于支撑"回避"结论，但两者高度相关（主力流出是回调的原因之一），本质上不是两个独立证据 |
| **4. 因果混淆风险** | 有弱混淆：将超大单-47743万+大单-18133万简化为"主力合计-64998万→偏空"，未考虑超大单和大单的匹配度（两者同时巨额流出可能是单一机构的集中操作而非系统性减仓），也未与计算机板块的整体资金流做对照 |
| **5. 结论强度是否过强** | 是——"回避"是P0决策卡中最强否定性动作（比"观望"更强），且不带任何触发条件。-64998万绝对值大，但相对于科大讯飞千亿市值体量占比有限。确认是否为主动减仓前直接"回避"强度偏高 |
| **6. 建议** | **WARN** — 方向（不宜入场）合理，但"回避"对比"观望"的升级缺少资金面以外的独立判断依据 |
| **7. 给腰子的校准参考** | 建议增加"板块资金净流出对照表"以区分个股vs板块行为的归因，并在主力连续2日流出收窄至-1亿内可降级为"观望" |

### 样本二：盈峰环境(000967)日报_20260604

**样本路径：** `重点股票/股票报告/盈峰环境(000967)/盈峰环境(000967)日报_20260604.md`
**场景：** 日报
**检查对象：** 综合结论（观望）、趋势判断

#### 关键段摘要

> 明日主动作：观望。收11.06(-0.27%)，主力-1461万，上涨6.3%。仓位上限0%（禁止新开仓）。
>
> **资金面**：超大单+3113万 + 大单+4261万 = 主力合计-1461万（小单-6582万拖累），中单-791万。主力变动幅度不大。
>
> **相位**：环保板块→潜伏期。信号胜率：主力净流入53%；空头排列不足20；潜伏期相位不足20。

#### 砺石方法校准

| 维度 | 评估 |
|:-----|:------|
| **1. 最大隐含假设** | "潜伏期=限制仓位但不禁止操作"——假设潜伏期相位信号已积累足够样本支撑可靠判断。但报告自身注明潜伏期相位"不足20次→低样本不触发"，则该相位判断的可靠性较低，由此推导的"限制仓位上限但不构成操作禁止"的结论基础薄弱 |
| **2. 最强反证** | ① 资金面：超大单(+3113万)和大单(+4261万)同时为正，主力合计-1461万的主要拖累来自小单(-6582万)——说明机构资金其实在买入，散户在卖出，这通常被视为正面信号而非偏空信号；② 深度分析结论（强烈回避+3红旗+ROE 3.2%）与日报的"观望"之间有一个逻辑间隙未填充——深度分析给出的是"不入场"级别的判断，日报降级为"观望"缺少明确的升级/降级触发条件说明 |
| **3. 同源证据重复** | 无显著同源重复。量价、资金、信号三源基本独立 |
| **4. 因果混淆风险** | 有弱混淆："主力合计-1461万→净流出偏空"未分解主力组成——公司机构在买入(超大单+大单正)，只有散户小单卖出拖累。将总和归因为"偏空"忽略了机构买入的正面信号 |
| **5. 结论强度是否过强** | 否：观望判断温和合理。但仓位上限0%（禁止新开仓）与资金面（机构买入、主力-1461万幅度小）之间存在不一致——若深度分析的"强烈回避"是正确的，0%合规；但日报自身资金面未给出足够支撑0%的事实依据 |
| **6. 建议** | **WARN** — 日报与深度分析之间的逻辑链条存在间隙：深度分析"强烈回避"→日报"观望"的降级依据未记录 |
| **7. 给腰子的校准参考** | 建议在日报中注明「深度分析基线评级」与「日报当日动作」之间的关系——当深度分析为"强烈回避"时，日报"观望"需说明原因（如：断崖下跌后已缩量企稳、超卖反弹概率>70%等） |

### 样本三：盈峰环境(000967)深度分析报告_20260529

**样本路径：** `重点股票/深度分析/深度分析报告/盈峰环境(000967)/盈峰环境(000967)深度分析报告_20260529.md`
**场景：** 深度分析
**检查对象：** 核心投资逻辑、综合评分、操作建议

#### 关键段摘要

> **评级：** 强烈回避（3红旗🔴+ROE 3.2%+五日-17.6%断崖下跌）
>
> **一句话结论：** 不入场。五日-17.6%断崖+PE 59x+ROE 3.2%+3红旗。
>
> **核心投资逻辑：** ①新能源环卫装备放量(L1) ②环卫服务稳定现金流(L1) ③环卫市场化率提升 ④低估值防御属性
>
> **评分：** 基本面3.0/技术面2.0/资金面3.0/行业面5.5/估值3.0/风控2.0 → 加权 **2.8** → 强烈回避
>
> **综合建议：** 不入场。若已持有→反弹减仓(11.5-12减半，10元止损清仓)。

#### 砺石方法校准

| 维度 | 评估 |
|:-----|:------|
| **1. 最大隐含假设** | **"五日-17.6%断崖下跌为极端异常波动，原因尚未明确"**——这是全篇的核心假设。报告明确承认下跌原因不明（机构集中减持/合同丢失/大股东减持/业绩预警均有可能），但"强烈回避"建议正是建立在这个原因不明的断崖基础之上。如果断崖的原因是市场过度反应（如某机构强制平仓导致的技术性踩踏），则当前价位可能存在超跌机会——这与"强烈回避"的含意完全相反 |
| **2. 最强反证** | ① RSI 22极度超卖→技术反弹概率>70%——报告自身也承认这一点，但给出的建议是与"不参与"之间存在张力；② PS~2.6x vs 行业PS~1.5x，报告认为仍有43%下行空间，但新能源化可能提升PS中枢至2.5-3x→合理股价10-12元，当前10.69元已在区间内；③ 三个L1证据赛道全部不打折，但最终评分加权仅2.8——L1证据与评级的巨大落差说明评分框架本身可能存在向下偏误 |
| **3. 同源证据重复** | 有弱重复：ROE 3.2% 同时被用于支撑"强烈回避"（低盈利能力）和"PE 59x虚高"（估值偏高），但这两个推论共享同一个数据源，不能算独立验证 |
| **4. 因果混淆风险** | 有："五日-17.6%断崖"被整体归因为"基本面质量差+板块低增速"，但断崖的具体触发机制（如杠杆平仓、机构集体减持等）未被排除。如果断崖是技术性踩踏，基本面质量差是背景条件而非直接原因→因果关系不匹配 |
| **5. 结论强度是否过强** | 是——在"断崖原因尚未明确"的前提下给出"强烈回避"评级，隐藏着一个反向假设：断崖原因不明 = 按最坏情况假设。该逻辑在风险控制上合理，但在逻辑上属于"预设最坏结果来证实最坏假设"的循环论证。若改为"原因不明→无法评估→无法评级"才更接近逻辑自洽 |
| **6. 建议** | **WARN** — 分析质量高（D1-D5均有涉及），但核心假设(断崖原因不明→按最坏假设处理)的逻辑链存在循环论证。建议将断崖原因排查作为正式发报告的前置步骤 |
| **7. 给腰子的校准参考** | "断崖原因尚未明确"是该报告的最大不确定性来源。在正式裁决前，建议至少排除大股东减持/业绩预警两类已知可验证的原因，否则当前评级的置信度本质上等同于原因不明带来的不确定性等级 |
