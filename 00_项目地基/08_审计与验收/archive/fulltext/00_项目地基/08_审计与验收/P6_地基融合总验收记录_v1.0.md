### 5.2 核心原则

| 原则 | 说明 |
|:-----|:------|
| 正式权威的判定标准 | 以文件路径和内容为准，不以 git status 是否 tracked 为判断依据 |
| 未跟踪 ≠ 无效 | 文件路径存在于版本库工作区、内容完整、引用链正常，即视为有效归档 |
| G6 放行前置条件 | G6 放行前需要由人工或仓库负责人统一将新增文件纳入版本控制（`git add`） |
| G5 复查边界 | G5 复查以文件内容和链式完整性为判断对象。若出现范围外正式产物未解释，G5 可要求补说明 |
