## 2. 核心声明

1. **统一解读是原子能力 C-D07-0001，不是业务场景。** 四大业务场景可调用 C-D07-0001，但统一解读本身不是场景。
2. **重点股票分析-日报 ≠ 每日荐股。** 日报是重点池跟踪承接，每日荐股是独立推荐场景，不得混为一场景。
3. **CounterOpinion（反方挑战）** 是每个场景调用 D07 时的必需输入项，由反方角色提供。
4. **本试运行不形成投资建议。** 不写任何股票代码、价格、买卖建议、评分结论。

## 3. 四大业务场景最小链路

### 3.1 重点股票分析

| 字段 | 内容 |
|:-----|:------|
| **scenario_name** | 重点股票分析（含深度分析/日报/临时分析） |
| **input_objects** | [DataSnapshot（D03）, EvidencePackage（D05）, RuleRefs（R-FIN-0001 + R-ROL-0002）, RoleOpinions（山猫/信鸽/玉夜/流金/青山）, CounterOpinion, ScenarioContext] |
| **capabilities_called** | C-D01（数据采集）→ C-D03（数据治理）→ C-D05（证据抽取）→ C-D06（信号计算）→ C-D07（统一解读） |
| **rules_applied** | R-FIN-0001（金融铁律索引）、R-ROL-0002（反方角色规则） |
| **counter_opinion_required** | ✅ 必需。深度分析时必需；日报在结论/操作/风险变化时必需；临时分析涉交易判断时必需 |
| **output_object** | InterpretationObject → CanonicalReport（D10） |
| **pass_condition** | 全团咨询通过、D07 完成解读产出、CounterOpinion 已纳入考量 |
