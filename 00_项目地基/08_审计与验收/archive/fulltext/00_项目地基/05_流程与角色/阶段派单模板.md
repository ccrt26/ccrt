# 阶段派单模板

> 模板版本: 1.0 | 创建: 2026-06-02

---

## 可复制模板

```text
你现在执行：【阶段编号】：【阶段名称】

流程编号：【F-xxx】
启用阶段门：【G0/G1/G2/G3/G4/G5/G6】
跳过阶段门：【列出并说明原因】
唤醒角色：【角色列表】
执行模型：【DeepSeek/Codex/Claude/其他】

一、阶段目标
二、G1 业务/金融/角色口径（如适用）
三、G2 技术方案（如适用）
四、允许修改范围
五、禁止修改范围
六、必须完成任务
七、实现要求
八、验收命令
九、验收报告要求
十、最终回复格式
十一、禁止事项
```

---

## 使用说明

| 字段 | 填写规则 |
|:-----|:---------|
| **流程编号** | 从流程路由表选取对应编号 |
| **启用阶段门** | 列出本阶段实际使用的阶段门编号 |
| **跳过阶段门** | 列出跳过的阶段门并逐一说明原因 |
| **唤醒角色** | 从角色唤醒协议获取对应角色列表 |
| **执行模型** | 执行本次编码/文档工作的模型名称 |
| **G1 口径** | 如跳过 G1，需说明依据；如启用，需先由角色团队输出口径 |
| **G2 方案** | 如跳过 G2，需说明依据；如启用，需先输出技术方案设计 |
| **允许修改范围** | 本阶段允许新增/修改的文件路径模式 |
| **禁止修改范围** | 本阶段绝对不能碰的文件路径模式 |
| **验收命令** | 本阶段必须执行的全部验收命令 |

---

## 禁止事项

| 禁止 | 说明 |
|:-----|:------|
| ⛔ 执行模型只是执行器 | 不得自行承担角色职责 |
| ⛔ 金融口径未定不得进入技术实现 | G1 未输出前不得进入 G3 |
| ⛔ 项目角色负责口径和验收 | 执行模型不得自行通过验收 |
| ⛔ 不得进入下一阶段 | 本阶段未验收通过，不进入下阶段 |
| ⛔ 不得扩大范围 | 不得修改允许范围之外的文件 |
