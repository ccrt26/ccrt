# P3-CDE：四大业务场景闭环总包 v1.0

> **阶段：** P3-CDE 正式方案 | **归属：** 项目地基融合工程
> **本文件只固化场景调用矩阵、数据源最小登记范围、反方/规则治理准入。**
> **统一解读不是场景，是原子能力 C-D07-0001。**

---

## 1. 核心边界

| 边界 | 说明 |
|:-----|:------|
| 统一解读 | 不是场景，是**原子能力 C-D07-0001**。四大场景可调用 C-D07 |
| CounterOpinion | 是 D07 的输入对象之一 |
| 反方 | 只做反证挑战，不采集数据、不签金融结论、不替代腰子 |
| 日报 ≠ 荐股 | 日报是重点池跟踪承接，荐股是独立推荐场景，**不得混为一场景** |
| 本次范围 | 不写 source_registry、不写 rule_asset_registry、不拆规则、不新增能力 |
