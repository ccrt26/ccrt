# START_HERE：地基启动索引 v1.0

> **角色：** 任何角色启动时只允许先读本文件
> **性质：** 启动索引，不是权威母版
> **维护人：** 阿黑
> **集成提示：** json 是结构化权威资产，不按 md 规则删除。

---

## 1. 启动硬规则

| 规则 | 违反后果 |
|:-----|:---------|
| 任何角色启动时只允许先读 START_HERE | Token 消耗审计 FAIL |
| 不得启动时全量读取 `00_项目地基/` | 流程审计 BLOCK |
| 不得全量读取 `00_项目地基/00_总览/` | 流程审计 BLOCK |
| 不得把 `临时报告/` 作为启动必读 | 审计未通过 |
| 只能按任务路由读取最小必要文件集 | Token 门禁 FAIL |

---

## 2. 四层读取模型

```
L0 启动索引：START_HERE（本文件）
  → 角色身份声明
  → 任务类型→路由映射
  → 当前阶段指针
  ⚠️ 只允许读 L0

L1 任务索引：按任务类型读取最小必要文件
  → 见 §3 任务类型路由
  ⚠️ 只读当前任务对应的文件集

L2 权威母版：架构/规则变更时读取
  → 规则注册表 / 能力注册表 / INDEX 或 STATE
  ⚠️ 默认不读，仅架构变更或规则冲突时

L3 历史归档：点名才读
  → 仅通过 INDEX_审计验收归档索引_v1.0.md 追溯
  ⚠️ 禁止常规读取历史阶段文件
```
