## 1. 统一解读是 C-D07-0001 原子能力，不是业务场景

**核心定位：** 统一解读是 D07 原子能力，通过 InterpretationObject 集成全金融团意见 + 反方挑战。四大业务场景可调用 C-D07-0001，但统一解读本身不是场景。

| 字段 | 值 |
|:-----|:-----|
| 能力 ID | C-D07-0001 |
| 所属域 | D07 分析与情景 |
| owner | 腰子 |
| executor | 红结 |
| 调用方式 | AI 结构化流程 |
| rules_applied | R-FIN-0001, R-ROL-0002 |

**统一解读不做：** 不直接生成最终报告、不给交易指令、不采集数据、不绕过风控、不替代反方角色、不作为单个角色自由发挥。

## 2. 场景编排总则

| 约束 | 说明 |
|:-----|:------|
| 场景编排不是原子能力 | 场景只组合和调度已注册能力，不自建能力 |
| 不得直接读底层数据 | 数据必须由 D01-D03 能力域获取 |
| 只能调用已注册能力 | 未注册能力用 pending note 标注 |
| 必须产出标准产物对象 | 各场景产物见下方定义 |
| 审计要求 | 每次场景执行产出 AuditRecord 或 EvalHook |

## 3. 业务场景调用矩阵

本文件按“四大业务主场景”治理；深度分析、日报、临时分析是“重点股票分析”的子模式，不另列为独立主场景。统一解读是 D07 原子能力，不列为场景。

| 场景 | 必调能力 | D07 调用 | CounterOpinion |
|:-----|:---------|:---------|:---------------|
| **重点股票分析** | C-D01→C-D03→C-D05→C-D06→C-D07 | ✅ 必需 | ✅ 必需（深度分析必；日报条件；临时涉交易时必） |
| **每日荐股** | C-D01→C-D03→C-D05→C-D06→C-D07 | ✅ 推荐理由整合时 | ✅ 荐股/剔除/降级时必 |
| **保护机制** | C-D03→C-D05→C-D06→C-D07 | ✅ 风险解释时 | ⚠️ 涉降仓/止损时必 |
| **模拟交易** | C-D03→C-D05→C-D06→C-D07 | ✅ 复盘归因时 | ⚠️ 涉策略调整时必 |

> **⚠️ 重点股票分析-日报 ≠ 每日荐股。** 日报是重点池跟踪承接，每日荐股是独立推荐场景，不得混为一场景。

### 3.1 重点股票分析（深度分析/日报/临时分析）

| 属性 | 内容 |
|:-----|:------|
| 可调用能力 | D01-D12 全部 |
| 标准输入 | 股票池 + 日期范围 |
| 标准输出 | CanonicalReport + ReportSidecar + EvalHook |
| 产物对象 | DataSnapshot, InterpretationObject(含反方区块), EvidencePackage, ScenarioPackage, ActionPlan |
| runtime_applied | R-FIN-0001, R-ROL-0002 |
| 审计要求 | 全团咨询/发布闸门/红线检查 |

### 3.1.1 重点股票每日分析（日报）D07_v1.2 全量口径

| 项目 | 规则 |
|:-----|:------|
| 发布状态 | 已全量启用，不灰度，不保留新旧并行 |
| 默认框架 | D07_v1.2 |
| 必查项 | 多假设简版、反证、证据缺口、结论强度、U-9/U-10 |
| 长期机构资金 | 不每日强制，仅在财报季/已有记录/中期争议/周报证据链/用户要求时使用 |
| 问题处理 | 不回灰度，直接 F-FIX |
| 边界 | 日报不是每日荐股，不生成交易指令，不修改交易执行器 |
| canonical E3 关系 | 与 canonical E3 guarded-cutover 独立；canonical 是报告对象生产链路切换，不影响 D07_v1.2 日报分析口径全量启用 |

### 3.2 每日荐股

| 属性 | 内容 |
|:-----|:------|
| 可调用能力 | D01, D03, D05, D07, D08, D10 |
| 标准输出 | 候选清单 + 理由 + 风险提示 |
| runtime_applied | R-FIN-0001, R-ROL-0002 |

### 3.3 保护机制

| 属性 | 内容 |
|:-----|:------|
| 可调用能力 | D03, D08 |
| 标准输出 | ProtectionDecision + AuditRecord |
| runtime_applied | R-FIN-0001, R-ROL-0002 |

### 3.4 模拟交易

| 属性 | 内容 |
|:-----|:------|
| 可调用能力 | D07, D08, D11, D12 |
| 标准输出 | TradeDecision + EvalHook |
| runtime_applied | R-FIN-0001, R-ROL-0002 |

## 4. 规则资产治理

### 4.1 规则资产定位

| 规则 | 是 | 不是 |
|:-----|:---|:-----|
| 金融铁律 | 约束分析口径和公式 | ❌ 不是分析能力 |
| 红线 | 约束行为红线 | ❌ 不是审计产物 |
| 编码规范 | 约束代码风格 | ❌ 不是代码实现 |
| 角色边界 | 约束角色行为 | ❌ 不是角色本身 |
| 管理规范 | 约束流程和治理 | ❌ 不是执行载体 |
