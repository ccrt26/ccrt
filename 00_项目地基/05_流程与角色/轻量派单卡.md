# 轻量派单卡

> 版本: 1.0 | 创建: 2026-06-02 | 维护人: 阿黑

---

## 说明

**这个派单卡由阿黑生成，不由用户填写。**

收到用户需求后，阿黑自动识别路由信息并生成以下派单卡。派单卡是执行模型的输入，不是用户的填写义务。

---

---

## 填写指引

| 字段 | 来源 | 填写者 |
|:-----|:------|:-------|
| 用户原始需求 | 用户输入 | 阿黑直接引用 |
| 流程编号 | 自动路由判定表 | 阿黑自动匹配 |
| 启用阶段门 | 变更生命周期与阶段门 | 阿黑按流程编号判断 |
| 跳过阶段门及原因 | 变更生命周期与阶段门 | 阿黑按规则判断 |
| 唤醒角色 | 角色唤醒协议 | 阿黑按流程编号确定 |
| 允许/禁止修改范围 | 流程路由表 | 阿黑自动查询 |
| 必须验收命令 | 阶段执行标准 | 阿黑按文件类型判断 |
| 执行模型 | 当前执行者 | 阿黑自动填写 |
| 下一步 | 路由结果 | 阿黑自动判定 |
