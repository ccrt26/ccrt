# /红线检查 — 合规审查命令
> 闸门2关键组件，不通过→打回红结修复

## 执行
1. 运行 `powershell -File "代码文件/规则红线/check_redlines.ps1"`
2. 对照红线逐项审查：§1数据真实性 / §2资源节约 / §3 API缓存 / §4执行检查清单 / §5.4版本管理

## 报告格式
```
## ✅ 合规项
## ⚠️ 警告项 (标注§编号)
## ❌ 违规项 (标注§编号)
**总体判定：合规 / 基本合规（有建议）/ 不合规（需修正）**
```
