description: 对照规则红线逐项审查当前工作合规性

【红线检查 — 合规审查命令】

> 当用户输入 `/红线检查` 时执行。

## 管线位置

- **闸门2关键组件**：新安四层验证中的红线审查环节
- 不通过 → 打回红结修复 → 重新走闸门2

---

## 执行流程

1. **运行自动化检查**：`powershell -File "代码文件/规则红线/check_redlines.ps1"`
2. **对照红线逐项审查**（读取 `规则红线/分析的规则红线--Claude_v1.13.md`）：

### 检查维度

- **§1 数据真实性**：来源标记[编号] / PE(TTM)本地计算 / 双源交叉验证 / 无编造数据
- **§2 资源节约**：代码可完成的不交AI / 不全文阅读 / 不重复调用
- **§3 API缓存**：分层缓存 / 间隔>=0.3s / 降级路径可用
- **§4 执行检查清单**：来源→双源→PE→延迟→缓存→免责→否决→降级→时效→独有标注→禁输出→PE百分位
- **§5.4 版本管理**：独立文件存档 / 旧版保留 / CHANGELOG同步 / DOCX同步 / 版本号格式

## 输出原则

结论在前，关键结果≤200字。详细推导链放附录或文件中。

## 报告格式

```
## ✅ 合规项
## ⚠️ 警告项 (标注§编号)
## ❌ 违规项 (标注§编号)
**总体判定：合规 / 基本合规（有建议）/ 不合规（需修正）**
```
