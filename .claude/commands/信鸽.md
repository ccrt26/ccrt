# 信鸽 — 个股事件信息采集

> ⛔ 本command由定时调度（每日19:00）或开机自检或手动 `/信鸽` 执行。
> **权威设计**: `审计报告/架构设计/design_pigeon_info_collection_v1.0.md`
> **角色定义**: `.claude/agents/信息采集-信鸽.md`
> **配置文件**: `代码文件/信鸽信息采集/pigeon_config.json`
> **主控脚本**: `代码文件/信鸽信息采集/pigeon_collector.ps1`
> **输出目录**: `重点股票/消息面数据/`

---

## 执行前强制步骤

```
1. 读取 代码文件/信鸽信息采集/pigeon_config.json（目标股票、黑名单、Q1-Q5规则、权重）
2. 读取 重点股票/消息面数据/events_db.json（近3日已入库事件，用于去重）
3. 读取角色定义 .claude/agents/信息采集-信鸽.md §二（C/X边界自检）
4. 执行采集（Step 1-4 数据源 → 五层过滤 → 输出）
5. 采集后自检 §六（7条逐项确认）
```

## 执行铁律

1. ⛔ **只采权威源**：主源cninfo[16]→备源china-stock-mcp[17]→缓存[C]，禁止碰黑名单域名
2. ⛔ **五层过滤不可跳过**：L1黑名单→L2五问法→L3去重→L4标签+上限，必须全量执行
3. ⛔ **P0事件双线上报**：立案调查/ST风险/退市风险等 → 同时通知腰子+阿黑
4. ⛔ **不越界解读**：采集+标签+模式识别 ✓ | 深度金融解读 ✗（那是腰子/山猫的事）
5. 每个事件标注分类/方向/影响分/确定性/P0标记，不可缺字段
6. events_db.json追加时保留T+N回测预留字段（青山事后回填）
7. 所有数字标注数据源编号 [16][17][14][11][C]
8. 节假日自动跳过（读取 holidays_2026.csv）
9. API调用间隔 >= 1s（cninfo频率限制）

## 用法

```
/信鸽                    # 查看今日采集摘要
/信鸽 采集               # 立即执行全量采集（7只重点股票）
/信鸽 采集 600114        # 单只股票采集
/信鸽 原文 600114         # 下载并展示最近公告PDF原文
/信鸽 规则                # 查看/修改黑名单和Q1-Q5规则
/信鸽 状态                # 查看数据源健康状态
```

## 过滤统计解读

```
L1 (黑名单):   关键词/域名命中 → 直接丢弃
L2 (五问法):   未命中Q1-Q5任一 → 丢弃（不可量化）
L3 (去重):     与近3日入库事件相似度>70% → 丢弃
L4 (标签+上限): 超出5条/股 → 按impact_score排序截断（P0例外）
```
