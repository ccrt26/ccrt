## 重点股票池
> ⛔ **权威源**：`代码文件/信鸽信息采集/pigeon_config.json`。池中有N只就产出N份深度分析报告。禁止用 `ls` 目录代替。

## 执行前强制步骤
```
-1. 运行权威源验证命令，确认当前股票池（N只）
 0. 读取 深度分析_v1.4.md（权威方法论）
 1. 读取 白皮书_v3.5.md（分析框架）
 2. 腰子全团强制咨询（山猫→信鸽→玉夜→流金→青山→腰子）
 3. 按九章结构逐章产出，每只股票独立
 4. 按自检清单(24条)逐条核对
 5. 输出报告（MD+HTML+PDF，每只三格式）
 6. 确认产出 = N只 × 3格式
```

## 核心铁律
九章结构不可缺章 | PE(TTM)=当前价/TTM_EPS | 腰子全团强制咨询 | 数据缺失说"不可获取"不推测 | 单次调用只处理一只股票

