## 执行前强制步骤
```
-1. 运行权威源验证命令，确认当前股票池（N只）
 0. 读取 深度分析_v1.4.md（权威方法论）
 1. 读取 白皮书_v3.5.md（分析框架）
 1.5 ⛔ 读取 统一解读/统一解读协议_v1.0.md（解释对象规范）
 1.6 ⛔ 读取 `.claude/knowledge/流程规则库.md` R01-R06 + `.claude/knowledge/角色进化库.md` EVO-001~EVO-006；如遇相似情景，检索 `.claude/knowledge/案例复盘库.md`
 2. 腰子全团强制咨询（山猫→信鸽→玉夜→流金→青山→腰子）
 3. 按九章结构逐章产出，每只股票独立
 3.5 ⛔ 每章生成解释对象 → U-9/U-10闸门 → eval_hooks（写入report.json的 role_interpretations/yaozi_integration/audit_u9/audit_u10/eval_hooks）
 3.6 ⛔ 执行 A-001 进化闸门：数据置信度、事件时间映射、叙事反证、替代情景、偏好校正、影子角色触发判断
 4. 按自检清单(24条) + R01-R06逐条核对
 5. 输出报告（MD+HTML+PDF，每只三格式）
 6. 确认产出 = N只 × 3格式
```

## 核心铁律
九章结构不可缺章 | PE(TTM)=当前价/TTM_EPS | 腰子全团强制咨询 | 数据缺失说"不可获取"不推测 | 单次调用只处理一只股票 | R01-R06进化闸门必须留痕

## 执行后验证 + 门户同步

```
python3 代码文件/深度分析/parse_deep_analysis_report.py --validate <MD路径>
python 代码文件/信鸽信息采集/generate_portal.py
```
PASS→继续转HTML+PDF。FAIL→修复后重新验证。
