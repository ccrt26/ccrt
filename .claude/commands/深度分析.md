## 执行前强制步骤

```
0. 读取 重点股票/深度分析/深度分析逻辑/深度分析_v1.3.md（本文件的权威方法论）
1. 读取 重点股票/分析逻辑/重点股票跟踪分析逻辑白皮书_v3.5.md（分析框架）
2. 按方法论 §0.2 执行腰子全团强制咨询（山猫→信鸽→玉夜→流金→青山→腰子）
3. 按方法论报告结构（九章）逐章产出
4. 按方法论自检清单（21条）逐条核对
5. 输出报告
```

## 执行铁律

0. ⛔ **分析深度铁律**：只填表不分析 = 不合格。每章必须有表格+发现段落+判断结论。
1. ⛔ **腰子全团强制咨询**：山猫→玉夜→流金→青山，任一角色未发言不得输出最终结论
2. PE(TTM) = 当前价 / TTM_EPS，禁止直接用静态PE做否决
3. 数据缺失时说"数据不可获取"，绝不推测具体数字
4. 所有数字标注数据源编号（[2][3][7][8][9][10][11][12]→[5]），降级标注[C]或[人工]
5. API调用间隔 >= 0.3秒
6. 输出压缩：结论在前，禁止回显大段原始数据
7. ⛔ **九章结构不可缺章**：公司概要→宏观行业→财务深度→技术面深度→估值分析→风险评估→综合评分→操作策略→中长期展望
8. ⛔ **AI幻觉防范（v1.1）**：管线自动评分(data_scored.json)仅供参考，禁止直接引用。财务数据获取后先执行反常识检查（§0.4）。信号冲突>40分时先排除幻觉再裁决。
9. ⛔ **子赛道下钻（v1.1）**：§一.3三步下钻（申万一级→二级/三级→核心概念赛道），禁止笼统标注板块。
10. ⛔ **催化剂强制识别（v1.1）**：§一.4必须列出≥2条近期催化剂。
11. ⛔ **资金面3日趋势（v1.1）**：禁止只看单日资金。必须3日/5日连续趋势+主力/散户双向结构。
12. ⛔ **估值方法匹配（v1.1）**：先判定价值/成长/周期类型，再选估值方法。成长股禁用PE单一否决。
13. ⛔ **证据等级评定（v1.2）**：§零.5强制标注核心概念赛道的证据等级(L1-L4)，L3/L4必须声明"尚未有实质验证"。证据等级→行业面权重折扣。
14. ⛔ **竞争格局对比（v1.2）**：§一.5必须列出≥2家可比竞争对手，四维打分。禁止笼统说"龙头"而无竞对数据。
15. ⛔ **可比估值对标（v1.2）**：§五.1必须列出≥1家可比公司PS/PEG/PE区间，明确当前处于可比公司什么分位。
16. ⛔ **三档试仓框架（v1.3）**：§六.5仓位建议必须使用复合推导表（档位上限+评分上限+min逻辑）。禁止仅输出单一"建议仓位上限"。三档止损(§八.4)必须各自标注独立价位。
17. ⛔ **分段止盈（v1.3）**：§八.4a必须设定三段止盈目标，每段标注概率区间+证据要求。目标2概率<40%、目标3概率<10%。禁止笼统的单一目标价。
18. ⛔ **证据动态管理（v1.3）**：§零.7五步闭环必须执行。报告产出前检查证据等级是否有升级/降级信号（查询信鸽P0上报文件）。仓位上限/行业面权重必须与当前证据等级联动一致。
