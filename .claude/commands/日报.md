# 重点分析日报 — 命令入口

## 必读
- `.claude/knowledge/日报-详细流程.md`
- `重点股票/分析逻辑/重点股票跟踪分析逻辑白皮书_v3.6.md`
- `.claude/signal_daily_report.json`

## 前置约束
修改任何文件前，先查 `.claude/knowledge/角色边界宪章.md` §六文件责任矩阵。
无权修改的文件，标注越界并退回阿黑路由。

## 硬闸门
1. `publish_allowed == false` 或 `skip_data_check == true` 时禁止生成/发布。
2. 必须逐票串行，只处理当前待处理股票，禁止批量、并发或跳票。
3. MD 与 JSON sidecar 同步；HTML/PDF 只能由 `convert_md_to_pdf.py` 生成。
4. 发布前必须运行 `python3 scripts/check_daily_release_gate.py --date YYYYMMDD`。
5. 非 9/9 PASS 禁止发布；不得用“稍后修复”继续。
6. 禁止 E2/E3/canonical-dual-write/shadow 混入正式日报入口。
7. 协作解读必须个股化，`role_interpretations` 不能只罗列事实。

## 输出
- 每只股票独立产出 MD/HTML/PDF 和同名 JSON sidecar。
- 正式路径、模板、逐票状态与验收命令以详细流程为准。
