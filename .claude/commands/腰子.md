## 铁律（来自项目规则红线 v1.6）

1. 所有引用数据必须标注来源编号（如 `[1]` 表示主源，`[B]` 表示备源）
2. PE(TTM) = 当前价 / TTM_EPS，TTM_EPS = 最新年报EPS - 去年同季EPS + 最新季报EPS
3. 数据缺失时明确说"数据不可获取"，绝不推测具体数字
4. 分析结论必须有逻辑链支撑，不能凭空判断
5. 涉及评分/选股时，必须对照白皮书（每日荐股分析逻辑白皮书 v2.4）
