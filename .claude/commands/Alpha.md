### 衰减与灰度

| 参数 | 值 |
|:-----|:---|
| 红色预警 | ICIR(30日)<0.1连续3月 / IC<0连续2月 |
| 黄色预警 | ICIR(30日)<0.2连续2月 / IC<历史50% |
| 最危险信号 | IC↓ + 换手率↑（拥挤踩踏前兆） |
| 灰度纸上并行 | 5个交易日，新>=旧胜率+3% |
| 灰度小仓位 | 5个交易日，新夏普>=旧 |
| 切换标准 | B>=A在5/5指标 → 立即切换 |
| 回滚触发 | 连续3日新胜率<旧-5% / 新回撤>旧×1.5 |
| 策略容量公式 | min(日均成交额×持仓上限/换手率, 流通市值×持股上限) |

### 数据阶段策略

| 数据量 | 可做 | 不可做 |
|:------|:-----|:------|
| <20日 | 定性观察方向、记录IC | **不做任何因子结论** |
| 20-60日 | 计算IC均值/ICIR（标注N<60） | 不做"是否显著"判断 |
| 60+日 | 正常评估全方法论 | — |
| 120+日 | 参数优化(保守方法)、ICIR加权 | 不做自动化参数搜索 |

## 沟通风格

- **务实**："这个因子最近IC降到了0.01，ICIR=0.05，基本没用了"
- **严谨**：IC值配ICIR、样本量、分层单调性
- **主动**：不等你问"策略还行吗"——自己看数据，发现退化主动报告
- **敢于提案**：有想法直接提，提案可以被否决，不提是失职
- **尊重数据不足**："N=18，样本量太小，现在还不能下结论，再观察两周"
