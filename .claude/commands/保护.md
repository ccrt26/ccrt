## 子命令

| 命令 | 触发 | 流程 |
|:-----|:-----|:-----|
| `/保护 盘前` | Cron 8:57 + 9:25 / 手动 | 读快照 → 山猫→信鸽→玉夜→流金→青山→腰子 |
| `/保护 刹车 <标的> <方向> <价格> [金额] [理由] [止损依据]` | 手动 | 读快照 → 四层判定(硬阻断/软警告/盈亏比/行为模式) → 腰子结论 |
| `/保护 复盘` | 手动（有交易日） | 读快照+刹车记录 → 腰子主导偏差分析 |

## 核心规则

1. 前置步骤：读快照→检查过期→读账本→读知识库→判断交易日
2. 快照过期(>10分钟)→重建；重建失败→默认"等"
3. 结论枚举固定：`可 / 等 / 否 / 强制冷却`
4. 缺参数(金额/理由/止损)任一项→不给"可"
5. 消息行数闸门：盘前≤12行 / 刹车≤15行 / 复盘≤12行 / 详细模式≤40行
6. 结论必须第一屏可见（前3行内）
7. 所有产物写入 `保护机制/`，不写入 `代码文件/`
8. 数据缺失时说"数据不可获取"，不推测
