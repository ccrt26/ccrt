# 保护 — 交易者保护机制

> 独立系统。不引用代码文件/，不触发 pipeline_engine。

## 子命令

| 命令 | 触发 | 流程 |
|:-----|:-----|:-----|
| `/保护 盘前` | Cron 8:57 + 9:23 / 手动 | 山猫→信鸽→玉夜→流金→青山→腰子 |
| `/保护 刹车 <标的> <方向> <价格>` | 手动 | 信鸽→流金→青山→腰子（压缩） |
| `/保护 复盘` | 手动（有交易日） | 腰子主导偏差分析 |

## 前置步骤（所有子命令共享）

1. 读取 `保护机制/持仓账本.json`
2. 读取 `保护机制/知识库/行为模式.md`
3. 读取 `保护机制/知识库/个人风控参数.md`
4. 读取 `保护机制/知识库/陷阱日历.md`
5. 读取 `保护机制/知识库/持仓关键位.md`
6. 读取 `holidays_2026.csv`，判断当日是否交易日

## 一、盘前简报

### 触发
- Cron: 交易日 8:57（执行 8:50 阶段）
- Cron: 交易日 9:23（执行 9:23 阶段）
- 手动: `/保护 盘前`

### 前置过滤
- 节假日 → 输出"节假日跳过" → 结束
- 持仓为空 → 输出"无持仓数据，跳过盘前简报" → 结束

### 8:50 阶段流程

按序执行，每角色输出后接力：

**① 山猫** — 读取行情 API[1][2] 获取隔夜外盘数据，输出：
- 标普/A50/人民币汇率
- 情绪温度（冰/冷/温/热/沸），必须 ≥3 个指标支撑
- ≤50 字

**② 信鸽** — 读取 `events_db.json`，输出：
- 12h 内新增事件（无则写"无"）
- 今日关注（潜在催化剂，无则写"无"）
- ≤40 字

**③ 玉夜** — 检查行情 API 连通性，输出：
- 双源状态（正常/降级至缓存[C]）
- 重点股票财务数据时效
- ≤30 字

**④ 流金** — 读取持仓账本 + 行为模式 + 风控参数，输出：
- 持仓摘要（每只：成本、浮盈浮亏%）
- 止损线
- 仓位上限（已用%/剩余%）
- 今日禁止模式（基于行为模式库和风控参数）
- ≤60 字

**⑤ 青山** — 读取持仓账本 + 持仓关键位，输出：
- 每只持仓的信号方向 + 合理区间 + 当前价格位置
- 偏离预警（价格偏离区间 >10% 则标注）
- ≤50 字

**⑥ 腰子** — 综合以上五角色，输出：
- 今日一句话操作纪律
- ≤30 字

### 8:50 飞书消息格式

```
🔔 盘前简报 · M月D日 08:50

【腰子】<一句话纪律>

【山猫】
外盘数据
情绪：X  指标：A | B | C

【信鸽】
12h新事件：X
今日关注：X

【玉夜】
双源：X
财务时效：X

【流金】
持仓：A（成本X，浮亏/浮盈Y%）
止损：X
仓位上限：已用X%，剩余Y%

今日禁止：
  · X
  · X

【青山】
A：信号方向，区间 X — Y，当前偏Z
（其余持仓略）

——
⚠️ 以上分析不构成投资建议
```

### 9:23 阶段流程

**① 山猫** — 输出竞价数据，绑定重点股票池：
- 每只持仓的竞价方向和幅度
- ≤40 字

**② 腰子** — 判断是否修正 8:50 定调：
- 有/无修正，若有一句话说明
- ≤40 字

### 9:23 飞书消息格式

```
📊 竞价校准 · M月D日 09:23

<标的> 竞价 ±X%，其余持仓平

8:50 定调<有/无>修正。<说明>
```

## 二、盘中刹车

### 触发
`/保护 刹车 <标的代码> <买入/卖出> <价格>`

### 前置步骤
自动读取持仓账本 → 匹配标的 → 判断已持有/未持有 → 若持有计算浮盈浮亏

### 流程（压缩版，目标 ≤180 秒）

**① 信鸽** — 查 events_db，输出：
- 方向有无消息支撑
- 最近消息方向（利好/利空/中性/无）
- ≤30 字

**② 流金** — 计算盈亏比 + 持仓状态判断，输出：
- 入场价、止损位、目标位、盈亏比 → 合理/不合理
- 若已持有：当前浮亏/浮盈%，加仓=摊平警告
- ≤50 字

**③ 青山** — 对比持仓关键位，输出：
- 当前价在信号区间的偏低/中枢/偏高位置
- ≤30 字

**④ 腰子** — 综合判断：
- [可/等/否]，理由一句话
- ≤30 字

### 飞书消息格式

```
🛑 刹车 · <标的名称> · <方向> <价格>

【腰子】<可/等/否>。
<理由>

【信鸽】
消息支撑：X
最近消息方向：X

【流金】
入场 X，止损 X，目标 X
盈亏比 X : 1 — <合理/不合理>

⚠️ <持有状态警告，如适用>

【青山】
X 处于信号区间 X — X 的<偏低/中枢/偏高>位置
<信号判断>

——
⚠️ 以上分析不构成投资建议
```

## 三、盘后复盘

### 触发
`/保护 复盘`（有交易日时）

### 流程

1. 读取当日刹车记录 + 持仓账本（对比昨日），识别今日操作
2. 逐笔对比：每笔操作 vs 当日盘前简报纪律卡片
3. 产出偏差分析
4. 纪律评分（1-10）
5. 若发现新行为模式 → 追加到 `保护机制/知识库/行为模式.md`

### 飞书消息格式

```
📝 盘后复盘 · M月D日

【今日操作】
<方向> <标的> · <价格>

【偏差分析】
操作：<操作描述>
信号：<当日团队信号>
偏差：<偏差类型>
根因：<根因分析>

【纪律评分】X / 10

【明日改进】
<一句话>

——
⚠️ 以上分析不构成投资建议
```
