# 红结 自查清单 — 每次提交代码前逐项打勾

> 版本 v1.0 | 生效日期 2026-05-24
> 用途：红结 在 `git commit` 前必须逐项检查，全部通过方可提交。
> 关联：角色边界宪章 (红结: C/X边界) | 红线规则摘要 | 常见错误案例库

---

## 一、语法与运行

- [ ] **语法检查通过**：Python 文件须经 `python -m py_compile <file>` 零错误；PowerShell 脚本须经 `Get-Command -Syntax` 或逐文件加载无报错
- [ ] **import 完整**：所有依赖模块已安装或在项目中可用，无 `ModuleNotFoundError`
- [ ] **空输入/边界值处理**：所有函数对 `None`、空列表、零值、负数输入有防御，不抛未捕获异常

---

## 二、路径与跨平台

- [ ] **无盘符硬编码**：路径均使用 `os.path.join()` / `Join-Path` 构建，无 `C:\`、`D:\` 等硬编码
- [ ] **无 `\` 反斜杠硬写**：所有路径分隔符由 `os.path.sep` 或 `os.path.join()` 自动生成
- [ ] **项目根目录引用统一**：使用 `ROOT` 变量或相对路径推导，不假设用户安装位置

---

## 三、异常与日志

- [ ] **所有 API 调用在异常捕获内**：HTTP 请求、文件 IO、JSON 解析均包在 `try/except` 中
- [ ] **异常有降级路径**：每个 except 分支有明确的兜底策略（返回缓存/标记缺失/跳过），不静默吞异常
- [ ] **关键决策点有日志输出**：评分变动、否决触发、数据源切换、缓存命中/未命中均有 `print()` 或日志记录

---

## 四、文件规模与结构

- [ ] **单文件不超过 500 行**：超过则拆分为多模块或提取公共函数
- [ ] **单个函数不超过 80 行**：超过则拆分为子函数
- [ ] **无重复代码**：同类逻辑已提取为可复用函数，不出现 ≥3 处 copy-paste
- [ ] **import 在文件顶部**：无函数内 import 或延迟 import（除非处理循环依赖）

---

## 五、文档同步红线（红线 §5.4）

- [ ] **修改 .md 后同步生成 .docx**：执行 `python md_to_docx.py input.md output.docx` 或对应 `build_docx.ps1`
- [ ] **版本号一致性**：文件名版本号 = 文档内部声明版本号 = CHANGELOG 版本号 = 文档版本索引
- [ ] **CHANGELOG 只记已完成改动**：不写"计划做"/"将要"，"已修复"带文件路径+行号
- [ ] **提交前运行** `version_supervisor.ps1 -CrossCheck` 通过

---

## 六、数据源 1+2 架构

- [ ] **每个数据字段有主源+备源+缓存兜底**：无单一数据源依赖
- [ ] **数据源标号正确**：Price→[1], Volume→[2], EPS→[3], MA→[5], Sector→[7], Fund→[9], Northbound→[8], Consensus→[11], Margin→[12]
- [ ] **PE(TTM) 使用公式计算**：`当前价[1] / TTM_EPS[3]`，禁止直接用腾讯静态 PE 做否决
- [ ] **双源数据实际尝试了主+备两个 API**：行情/K线字段不跳过备源

---

## 七、编码规范

- [ ] **Python 编码声明**：文件头有 `# -*- coding: utf-8 -*-`
- [ ] **JSON 读写使用 `encoding="utf-8-sig"`**：兼容 BOM 标记
- [ ] **命名符合规范**：内部函数 `_` 前缀，常量全大写，变量 snake_case
- [ ] **无魔法数字**：阈值/权重/分数边界定义为模块级命名常量，函数体内不出现裸数字
- [ ] **禁止编造数据**：凡输出数字必可追溯到数据源；不可获取的字段不输出具体数值，标记为 None 或 "N/A"

---

## 八、角色边界自检（对照角色边界宪章）

- [ ] **红结 C-list 范围内**：编码实现/接口落地/脚本优化 —— 均在此列
- [ ] **未做架构决策**：模块拆分、接口契约、技术选型由 情墨 决定，红结 不自行修改
- [ ] **未做金融判断**：评分公式/否决阈值/因子权重由腰子确认，红结 不自行调整
- [ ] **发现问题已回给对应角色**：设计问题 → 情墨；数据异常 → 玉夜；逻辑存疑 → 腰子

---

## 九、常见错误专项排除（对照常见错误.md）

- [ ] **PE 计算**：确认使用的是 TTM PE 公式而非静态 PE（#数据 案例：2026-05-21 腾讯PE直接否决）
- [ ] **数据源标号**：确认所有字段在 FIELD_SOURCE_MAP 中注册（#数据）
- [ ] **缓存兜底**：API 不可达时不崩溃，有缓存降级路径（#系统）
- [ ] **权限/安全**：无硬编码密钥、Token、密码；敏感配置走环境变量（#红线）

---

## 十、红线规则快速对照

- [ ] **未删除任何 PDF 文件**（红线 §1.7）
- [ ] **报告有免责声明** + 降级路径 + 时效标注
- [ ] **独有数据标注"仅供参考"**
- [ ] **API 调用延迟 >= 0.3s**（避免触发频率限制）

---

## 检查流程

```
代码写完 → 对照本清单逐项打勾 → 全部通过 → git add + git commit
                                    ↓ 任一未通过
                                  修复后重新检查
```

违规记录：凡因跳过本清单导致的问题，录入 `常见错误.md` 并标注对应标签。
