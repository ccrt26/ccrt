# 日报 — 详细流程（从 .claude/commands/日报.md 拆分）

> 本文档为日报的完整操作手册。入口见 `.claude/commands/日报.md`。
> v7 冻结版本 (2026-06-04) — 后续流程变更必须先改本文档再执行。

## 逐票日报固化流程

### 数据链路时间线（交易日）
| 时间 | 任务 | 命令 |
|:----|:-----|:-----|
| 16:02 | Tushare 历史数据同步 | `tushare_history_sync.py --daily` |
| 16:05 | 日报数据就绪信号 | `daily_orchestrator.py --mode daily` |
| 16:10 | 日报解析 | `Invoke-DailyReportParser.py YYYYMMDD` |
| 16:12 | 下一只任务包准备（非生成） | `run_daily_report_one_by_one.py --prepare-next` |

### 逐票生成规程
1. 运行 `--prepare-next` 按 pigeon_config 顺序找下一只待处理股票
2. 脚本检查 `status/{date}_{code}.pass.json`：有 → 跳过；无 → 输出任务包
3. 从 `logs/daily_one_by_one_tasks/{date}_{code}.prompt.txt` 获取完整任务指令
4. DeepSeek/团队只写当前股票的 **MD + JSON**，禁止写 HTML/PDF
5. 禁止碰其他任何股票
6. 禁止碰 scripts/gate/crontab
7. 必须参考母版：`东睦股份(600114)日报_20260603.md/html`
8. 必须全团6角色解读：山猫_宏观 → 信鸽_事件 → 玉夜_数据 → 流金_风控 → 青山_信号 → 腰子_整合
9. 数据必须转成人话解释，禁止套用其他股票同一句话

### 逐票验收规程
1. 写完当前票 MD/JSON 后执行：
   ```
   python3 scripts/run_daily_report_one_by_one.py --date YYYYMMDD --render-only --only CODE --incremental-dedupe
   ```
2. 该命令：convert_md_to_pdf.py 渲染 HTML/PDF → check_single_stock（P0-H/P0-I/MD-SC）→ P0-I incremental-codes 去重检查
3. 全部通过 → 自动写入 `status/{date}_{code}.pass.json`
4. 任一失败 → 脚本 EXIT=2，停在当前票，不进入下一只
5. 修复只修当前票的 MD/JSON，重新执行 render-only
6. 禁止用 `--start-from` 跳过未通过股票
7. 通过后再 `--prepare-next` 自动推进

### 发布闸门
全部票通过 render-only + incremental-dedupe 后执行：
```
python3 scripts/check_daily_release_gate.py --date YYYYMMDD
```

闸门 9 项（P0-A 到 P0-I）：
- P0-A 基线权威性
- P0-B 数值源一致性
- P0-C 新鲜度退化
- P0-D MD/Sidecar一致性
- P0-E 日报样式锁定（convert_md_to_pdf 统一渲染）
- P0-F 协作解读完整性
- P0-G 日报内容完整度
- P0-H 渲染一致性
- P0-I 全团解读质量（含跨股票去重）

必须 **9/9 PASS** 才允许发布。禁止在非 9/9 时以任何理由发布。

### 地基隔离
- E2/E3/canonical-dual-write/shadow 禁止写入正式日报目录
- 地基任务只能通过独立命令运行，不能挂在日报生产入口上
- daily_orchestrator.py 入口已移除 --canonical-dual-write 参数

### 母版规则
- **内容母版**：`东睦股份(600114)日报_20260603.md`
- **样式母版**：`convert_md_to_pdf.py` 输出风格（body padding 15mm 18mm + 冻结 CSS）
- **模板优化必须先改母版+本文档，再生成新日报**
- HTML/PDF 只能通过 `convert_md_to_pdf.py` 生成
- 禁止手写 HTML / 自定义 CSS / 极简 CSS

### 禁止行为清单
1. 禁止批量生成全部股票（必须逐票串行）
2. 禁止并发生成多只股票
3. 禁止用 `--start-from` 跳过未通过股票
4. 禁止手写 HTML / 自定义 CSS / 极简 CSS
5. 禁止绕过 `convert_md_to_pdf.py`
6. 禁止 E2/E3/canonical-dual-write/shadow 混入日报入口
7. 禁止 --skip-data-check 生成生产日报
8. 禁止在非 9/9 时发布

## 执行铁律

0. ⛔ **日报是深度分析九章报告的日常精简衍生品**：财务数据/可比估值/证据等级复用深度分析结论，仅行情/资金/板块为每日增量更新
1. **不推翻周度判断**：日度信号与周度冲突→标注背离，不改中期判断
2. **只看变化**：不重复周度已有内容，聚焦"今天和昨天有什么不同"
3. **操作优先于分析**：终极产出是明日情景应对表+硬性纪律
4. 数据缺失时说"数据不可获取"，绝不推测
5. **⛔ 管线自动评分已作废**：基本面评分由深度分析独立判断，禁止使用管线20分制
6. **⛔ 方向标签强制对齐**：日报的"偏多/偏空/观望/不操作"标签必须与深度分析最终结论一致。深度分析说"Markdown不操作"→日报禁止写"偏多"。方向标签不一致=日报不合格，退回重做

## 文件输出（每只股票独立）

```
MD:   重点股票/股票报告/{名称}({代码})/{名称}({代码})日报_YYYYMMDD.md
HTML: 重点股票/股票报告/{名称}({代码})/{名称}({代码})日报_YYYYMMDD.html
PDF:  重点股票/股票报告/{名称}({代码})/{名称}({代码})日报_YYYYMMDD.pdf
```

> ⛔ 每个交易日必须产出N份×3格式（N=池子大小，以pigeon_config.json为准），覆盖全部重点股票池。
> ⛔ **三格式强制产出**：MD→HTML→PDF缺一不可。HTML供WEB上传，PDF供归档，MD供版本追踪。任一格式缺失=日报产出不完整，禁止结案。

### HTML+PDF生成步骤

1. 生成MD报告（按下方模板）
2. 将MD转为HTML（用下方冻结CSS包装）。⛔ 信号快照段外层必须保留 `<div class="machine-only">` 标签，保存为 `{名称}({代码})日报_YYYYMMDD.html`
3. Edge headless打印HTML为PDF：
   ```
   msedge --headless --disable-gpu --print-to-pdf="输出路径.pdf" "html文件路径"
   ```
4. ⛔ 验证：检查MD/HTML/PDF三个文件均存在且PDF > 100KB（非空文件）
