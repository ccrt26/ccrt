# 正式报告目录保护规则

> 版本 v1.0 | 生效日期 2026-06-01 | 维护人: 旧影
> 引用: CLAUDE.md §五工程规范、宪法 docs/constitution.md

## 一、正式报告目录

```
重点股票/深度分析/深度分析报告/
```

此目录下的所有文件（.md / .html / .pdf）属于正式报告，受本规则保护。

## 二、覆盖条件（6项全部满足才允许）

| 序号 | 条件 | 检查人 | 通过标准 |
|:----:|:-----|:------|:--------|
| 1 | 红结生成完成 | 红结 | formalize_keystock_deep_reports.py 执行完成，MD→HTML→Chrome PDF路线 |
| 2 | 情墨版式PASS | 情墨 | 表头可读、表格自动换行、重点内容加粗、分页正常、无乱码、无系统字段、与5月29日版式一致 |
| 3 | 腰子内容PASS | 腰子 | 结论清楚、参数解释成人话、风险优先展示、操作建议可执行、保留原报告完整分析 |
| 4 | 旧影release_gate PASS | 旧影 | release_gate.py 全部6闸门PASS |
| 5 | Web dry-run PASS | 千光/红枫 | docs/deep_analysis下10只股票HTML/PDF齐全 |
| 6 | 旧影签字允许覆盖 | 旧影 | 旧影在release_gate报告中签字 |

## 三、违规处理

### 未满足覆盖条件时
- 只能输出到 `临时报告/` 或 `临时PDF审阅版/`
- 不得进入 `重点股票/深度分析/深度分析报告/`
- pre-commit-check.py Check J 自动拦截直接写入操作

### 违规覆盖
- 发现后旧影标注 B1 缺陷
- 强制回退覆盖文件
- 记录违规到 audit_findings.jsonl

## 四、与 Git 自动化关系

- `重点股票/深度分析/深度分析报告/` **不是** AUTOCOMMIT 豁免路径
- 该目录下的文件提交需 pipeline token + release_gate PASS
- auto-sweep 不自动提交此目录文件（由 pipeline_auth.py PROTECTED_PATHS 保护）

## 五、例外

- 格式修正（错字/排版）且不影响结论 → 走 PATCH 流程，情墨+旧影双签即可
- 紧急修正 → 启动 EMERGENCY 流程，仍须满足覆盖条件 1-4（可跳过 5-6，事后补齐）
