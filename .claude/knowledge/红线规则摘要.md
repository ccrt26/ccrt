# 金融铁律摘要 — 全角色共享

> 完整版：`金融铁律/金融铁律_v1.17.md`
> 本文是高频使用规则的快速参考，所有角色优先查此处。

---

## 一、数据真实性（所有角色最高优先级）

1. **禁止编造**：任何数字必须来自真实API，禁止AI推断缺失财务指标
2. **不可获取=标注不可输出**：如筹码分布、社交情绪等
3. **PE(TTM) = 当前价[1] / TTM_EPS[3]**：禁止直接用腾讯静态PE做否决依据
4. **TTM_EPS = 最新年报EPS - 去年同季EPS + 最新季报EPS**

## 二、1+2主备架构

每个数据字段按：**主API → 备API([B]) → 缓存[C]** 三级获取。
双源数据（行情/K线）必须实际尝试主和备两个API。

## 四、API调用纪律

- 间隔 ≥ 0.3s
- 每10次休息2s
- 财务数据每7天拉取1次（防封IP）

## 五、文档与文件纪律

- ⛔ **禁止AI删除项目中任何PDF文件**
- CHANGELOG只记已完成改动，附带文件路径+行号
- 修改.md → 同步生成.docx
- 文件名版本号 = 文档内部声明 = CHANGELOG = 文档版本索引
- 提交前运行 `version_supervisor.ps1 -CrossCheck`

## 六、报告纪律

- 报告必须有免责声明
- 降级路径+时效标注
- 独有数据（无备源）标注"仅供参考"
- 样式基线已冻结，AI不可擅自修改品牌色/涨跌色/字体

## 七、角色通用红线

- 金融角色：不写代码，只出分析/诊断/方案
- 工程角色(除红结)：不写代码，只出设计/方案/审查
- 旧影：只审计不执行
- 所有角色：不编造、不越界、不删PDF
