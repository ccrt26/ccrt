# 错误案例库 — 全角色共享

> 用途：新任务发起前优先检查，避免重复犯错。
> 格式：日期 | 来源 | 错误描述 | 根因 | 修复 | 预防

---

## 入库标准

以下情况必须入库：
- 导致报告/决策错误的bug
- 风控驳回的决策（事后证明驳回正确）
- 数据源故障导致的错误结论
- 违反规则红线的操作
- 角色越界行为

## 分类体系

| 类别 | 标签 |
|:-----|:----:|
| 数据错误 | `#数据` |
| 计算逻辑错误 | `#逻辑` |
| 规则违反 | `#红线` |
| 角色越界 | `#越界` |
| 方法论缺陷 | `#方法论` |
| API/系统故障 | `#系统` |

## 检查规则

所有角色在以下节点**必须**先查错误案例库：
1. 发起新分析任务前
2. 修改评分/否决逻辑前
3. 新数据源接入前
4. 策略参数调整前

查询方式：搜索对应 `#标签`，检查是否有历史同类错误。
