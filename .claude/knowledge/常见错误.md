# 错误案例库 — 全角色共享

> 用途：新任务发起前优先检查，避免重复犯错。
> 格式：日期 | 来源 | 错误描述 | 根因 | 修复 | 预防

---

## 入库标准

以下情况必须入库：
- 导致报告/决策错误的bug
- 风控驳回的决策（事后证明驳回正确）
- 数据源故障导致的错误结论
- 违反金融铁律的操作
- 角色越界行为

## 分类体系

| 类别 | 标签 |
|:-----|:----:|
| 数据错误 | `#数据` |
| 计算逻辑错误 | `#逻辑` |
| 规则违反 | `#红线` |
| 角色越界 | `#越界` |
| 方法论缺陷 | `#方法论` |
| API/系统故障 | `#系统` |

## 案例库

> 以下为框架种子案例。每次发生新错误后追加至对应类别。

### #数据

```
2026-05-21 | 腾讯PE直接用于否决
根因：PE(TTM)未用公式自行计算，直接用接口返回静态PE
修复：强制使用 [1]/[3] 计算TTM PE
预防：PE否决前检查是否经TTM公式
```

### #逻辑

```
2026-05-24 | phase_mult 变量未初始化导致 compute_scores() 异常
根因：数据不足分支(最小K线<5时)未给 phase_mult 赋默认值
修复：在分支入口设置 phase_mult = 1.0
预防：所有分支路径的变量初始化检查 → audit_sections.ps1 Section C
```

```
2026-05-24 | 模块拆分后常量重复定义 (veto.py 与 __init__.py 范围重叠)
根因：拆分脚本未检测跨文件常量重复
修复：统一常量到 __init__.py，其他模块 import 引用
预防：拆分后运行重复定义检测
```

```
2026-05-24 | PSM1拆分边界+1偏移 — 每个子模块吞下相邻模块第一行
根因：Python 0-indexed 边界 vs 1-indexed 文件行号混淆
修复：全部8个子模块重新切割
预防：拆分脚本使用 Pythonic 边界 + 逐模块验证首尾行
```

所有角色在以下节点**必须**先查错误案例库：
1. 发起新分析任务前
2. 修改评分/否决逻辑前
3. 新数据源接入前
4. 策略参数调整前

查询方式：搜索对应 `#标签`，检查是否有历史同类错误。
