## 二、重设计目标

### 2.1 设计原则

1. **数据与代码分离**：脚本归代码文件/，数据归历史数据/
2. **按生命周期分层**：热数据(S级) → 温数据(B级) → 冷数据(A级) → 缓存(C级) → 可弃(D级)
3. **S级资产双副本**：交易流水+持仓+绩效→至少两份物理副本
4. **日期驱动命名**：所有文件以 YYYYMMDD 开头，天然幂等
5. **自动清理**：C/D级数据由脚本自动清理，不依赖人工

### 2.2 目标结构

## 三、数据生命周期管理

### 3.1 分层TTL与清理策略

| 层 | 目录 | TTL | 清理方式 | 触发时机 |
|:--:|:-----|:---|:--------|:--------|
| S | 00_核心交易/ | 永久 | 从不清理 | — |
| A | 01_交易快照/ | 365天 | 滚动删除 | 每次写入后检查 |
| A | 02_评估数据/ | 90天 | 滚动删除 | 每次写入后检查 |
| A | 03_分析报告/ | 365天 | 滚动删除 | 每次写入后检查 |
| A | 06_月度归档/ | 永久 | 从不清理 | — |
| B | 04_原始数据/ | 90天 | 滚动删除 | 每次写入后检查 |
| B | 05_参考数据/ | 90天 | 滚动删除 | 每次写入后检查 |
| C | cache/ | 按子目录TTL | 自动TTL清理 | 每日盘前 |
| D | — | 即时 | 脚本执行完即删 | 脚本finally块 |

### 3.2 滚动清理伪代码

```powershell
function Invoke-RollingCleanup {
    param($Dir, $RetentionDays, $Pattern = "*.json")
    
    $cutoff = (Get-Date).AddDays(-$RetentionDays)
    Get-ChildItem $Dir -Filter $Pattern | Where-Object {
        $_.LastWriteTime -lt $cutoff
    } | Remove-Item -Force
}
```

### 3.3 S级资产双副本机制

```
每次 sim_trading.ps1 运行后：
  ① 更新 00_核心交易/ 中的主副本
  ② 复制到 _backup/ 中的镜像副本
  ③ 校验两个副本的hash一致

如果主副本损坏/丢失：
  → 从 _backup/ 恢复
  → 记录恢复日志
  → 玉夜巡检告警
```

## 六、备份与恢复

### 6.1 S级资产备份策略

```powershell
function Backup-SLevelAssets {
    $sourceDir = "$rootDir/历史数据/00_核心交易"
    $backupDir = "$rootDir/历史数据/_backup"
    
    foreach ($file in @("transactions.csv", "positions.json", "perf_summary.json")) {
        $src = Join-Path $sourceDir $file
        $dst = Join-Path $backupDir $file
        
        if (Test-Path $src) {
            Copy-Item $src $dst -Force
            
            # 校验hash
            $srcHash = (Get-FileHash $src -Algorithm SHA256).Hash
            $dstHash = (Get-FileHash $dst -Algorithm SHA256).Hash
            
            if ($srcHash -ne $dstHash) {
                throw "S级资产备份校验失败: $file"
            }
        }
    }
}
```

### 6.2 恢复流程

```
检测到损坏/丢失 → 检查_backup/中最新的完整副本 → SHA256校验 → 恢复 → 记录日志
```

## 七、与现有系统的兼容

### 7.1 过渡期双写策略

迁移后首周，关键脚本同时写入新旧两个路径，确保无遗漏：

```
sim_trading.ps1 写入：
  新：历史数据/00_核心交易/positions.json
  旧：模拟交易/持仓记录/positions.json  （过渡期，1周后移除）
```

### 7.2 不破坏现有系统

- 每日荐股流程不改动（daily_workflow.ps1 仅追加路径引用）
- 重点股票分析不改动（run_keystock_analysis.ps1 仅追加路径引用）
- 模拟交易引擎不改核心逻辑（仅改输出路径）
