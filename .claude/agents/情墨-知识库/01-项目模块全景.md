## 一、项目文件清单总览

铁律量化项目采用 PowerShell + Python 混合架构，共包含 50+ 脚本文件，按功能划分为 7 大模块层。

### 1.1 数据层（Data Layer）

| 文件 | 类型 | 功能 | 关键依赖 |
|:-----|:----:|:-----|:---------|
| `代码文件/每日荐股/scripts/stock_data_fetcher.psm1` | PS模块 | 核心数据获取模块，封装腾讯API(行情)、新浪API(K线)、东方财富API(财务/板块/资金)的调用 | 无（底层模块） |
| `代码文件/每日荐股/scripts/stock_data_fetcher.ps1` | PS脚本 | 数据获取脚本入口 | stock_data_fetcher.psm1 |
| `代码文件/每日荐股/scripts/stock_data_fetcher_ths.py` | Python | 同花顺THS备源数据获取（通过akshare） | akshare库 |
| `代码文件/每日荐股/scripts/batch_data_collector.ps1` | PS脚本 | 批量数据采集调度 | stock_data_fetcher.psm1 |
| `代码文件/每日荐股/scripts/build_dynamic_pool.ps1` | PS脚本 | 动态股票池构建 | stock_data_fetcher.psm1 |
| `代码文件/每日荐股/scripts/is_market_open.ps1` | PS脚本 | A股交易日历判断 | 无 |

**数据源覆盖**：
- [1] 腾讯API — 实时行情/批量行情/分时
- [2] 新浪API — K线数据 / 行情备用
- [3] 东方财富datacenter API — 季报财务数据
- [7] 东方财富push2 API — 行业板块排行
- [8] 东方财富datacenter-web API — 北向持股明细
- [9] 东方财富push2 API — 个股资金流向
- [10] 东方财富push2 API — 行业资金流向
- [11] 东方财富reportapi — 分析师研报/评级

## 三、文件耦合度评估

### 3.1 耦合度分类标准

| 等级 | 标识 | 定义 | 改动一个文件时的影响范围 |
|:-----|:----:|:-----|:------------------------|
| 松散 | ◯ | 仅通过文件接口（JSON/CSV/文件系统）交互，无代码级引用 | 仅影响直接下游的读取方 |
| 中等 | ◉ | 存在模块间函数调用或脚本调用，但有明确的接口定义 | 影响上下游2-3个文件 |
| 紧密 | ● | 共享全局变量、硬编码依赖、无接口抽象 | 影响范围不可控，可能级联5+文件 |

## 四、改动风险等级

### 4.1 风险等级定义

| 等级 | 标识 | 含义 | 改动策略 |

## 五、模块边界定义

### 5.1 各层的职责边界

| 层 | 负责 | 不负责 |
|:---|:-----|:-------|
| 数据层 | 获取原始数据、填充缓存、1+2降级切换、数据格式标准化 | 数据含义解释、评分计算、报告生成 |
| 计算层 | 因子计算、多因子评分、回测模拟、绩效归因 | 数据获取、报告渲染、交易执行 |
| 展示层 | 报告模板渲染、HTML/DOCX生成、样式应用 | 数据采集、因子计算、合规检查 |
| 调度层 | 工作流编排、定时触发、任务依赖管理 | 具体业务逻辑、数据获取细节 |
| 监督层 | 版本一致性检查、红线合规验证、输出验证 | 业务逻辑修改、报告生成 |
| 服务层 | 外部API查询接口、数据服务化 | 内部数据采集、业务计算 |
| 工具层 | 格式转换、文件生成、通用工具函数 | 业务逻辑 |

### 5.2 跨边界调用规则

1. **数据→计算**：仅通过缓存文件（JSON/CSV），不允许直接调用API
2. **计算→展示**：仅通过标准化JSON输出，不允许展示层直接访问缓存
3. **调度→所有层**：通过命令行参数调用脚本，不允许直接修改脚本内部状态
4. **监督→所有层**：只读访问，不允许修改任何业务文件
5. **模拟交易→评分**：通过反馈分析文件传递优化建议，不直接修改评分引擎
