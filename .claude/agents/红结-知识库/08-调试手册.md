## 二、快速诊断流程图

```
发现问题
  ↓
① 确认现象
  ├── 脚本报错？ → 看脚本自身日志(临时报告/日志/)
  ├── 数据显示异常？ → 检查API连通性(玉夜巡检)
  ├── 评分结果异常？ → 检查输入数据→因子计算→评分逻辑
  └── 报告格式错误？ → 检查模板→数据填充→转换工具

② 定位层次
  ├── 第1层(基础设施)：配置/路径/权限 → 检查环境配置快照(红枫-知识库/05)
  ├── 第2层(数据采集)：API超时/数据缺失 → 检查API频率速查表(玉夜-知识库/07)
  ├── 第3层(数据加工)：TTM_EPS/MA等计算错误 → 检查公式参数
  ├── 第4层(因子计算)：因子打分异常 → 检查输入字段完整性
  ├── 第5层(评分引擎)：分数排序异常 → Golden Master比对
  ├── 第6层(风控/否决)：PE否决误判 → 检查PE(TTM)公式
  └── 第7层(报告输出)：输出格式/编码问题 → 检查模板和编码

③ 最小复现
  └── 隔离到最小可复现单元(单只股票+单日数据)

④ 修复验证
  └── 修复后重跑同一输入，对比输出
```

## 三、常见错误排查

### 3.1 数据相关问题

| 症状 | 可能原因 | 检查方法 | 修复 |
|:-----|:--------|:--------|:-----|
| 行情数据全空 | API不可达 | `curl`测试[1][2]API | 切换备源[B] |
| PE值异常大 | TTM_EPS计算错误 | 检查年报/季报数据+公式 | 检查EPS取值+除零保护 |
| 复权价格不连续 | 复权方式不一致 | 对比[1][2]同日期数据 | 统一使用前复权 |
| JSON解析失败 | 编码问题 | 检查文件是否为UTF-8 with BOM | `encoding='utf-8-sig'` |
| 北向数据为空 | 港股休市/非标的 | 检查日期+股票是否沪/深股通 | 标记N/A而非0 |

### 3.2 脚本相关问题

| 症状 | 可能原因 | 检查方法 | 修复 |
|:-----|:--------|:--------|:-----|
| `ModuleNotFoundError` | 依赖未安装 | `pip list` 确认 | `pip install <package>` |
| PowerShell拒绝执行 | ExecutionPolicy Restricted | `Get-ExecutionPolicy` | `powershell.exe -File script.ps1` 或改策略 |
| 路径找不到 | 硬编码盘符 | 搜索 `C:\` `D:\` | 改为相对路径/Join-Path |
| 内存不足 | 一次加载过多数据 | 检查加载量 | 分批处理+流式读取 |
| 脚本挂起无响应 | API无超时设置 | 检查TimeoutSec参数 | 设置合理超时(≤30s) |

### 3.3 编码相关问题

| 症状 | 可能原因 | 检查方法 | 修复 |
|:-----|:--------|:--------|:-----|
| 中文乱码(文件) | 写入编码错误 | 检查打开方式 | `encoding='utf-8'` |
| 中文乱码(控制台) | 控制台代码页 | `chcp` (应为65001) | `chcp 65001` |
| JSON含BOM导致解析失败 | 用utf-8-sig写入 | hex查看文件头 | 改用 `encoding='utf-8'` 写入 |

## 四、调试工具速查

### Python调试
```python
# 快速验证API响应
import requests
r = requests.get("https://qt.gtimg.cn/q=sh600000", timeout=10)
print(r.status_code, r.text[:200])

# 检查JSON合法性
import json
with open("data.json", "r", encoding="utf-8") as f:
    print(f.read()[:200])  # 先看原始内容
    f.seek(0)
    data = json.load(f)  # 再解析
```

### PowerShell调试
```powershell
# 快速验证API响应
$r = Invoke-RestMethod -Uri "https://qt.gtimg.cn/q=sh600000" -TimeoutSec 10
$r | Out-File -FilePath "debug_output.txt" -Encoding UTF8

# 检查文件编码
Get-Content -Path "data.json" -Encoding Byte -TotalCount 3  # 检查BOM: EF BB BF

# 逐行执行脚本(调试用)
Set-PSDebug -Trace 1
.\script.ps1
Set-PSDebug -Trace 0
```

### Git调试
```bash
# 查看某文件最近变更
git log --oneline -10 -- <file>

# 查看某次commit的具体改动
git show <commit-hash> --stat

# 搜索代码历史(某段代码何时引入)
git log -S "搜索的代码片段" --all
```

## 五、调试开关

在项目中使用统一的调试开关：

```python
# config.py 或脚本顶部
DEBUG = False  # 生产环境设为False
# DEBUG = True  # 调试时取消注释

def debug_log(msg):
    if DEBUG:
        print(f"[DEBUG] {msg}")
```

```powershell
# config.ps1 或脚本顶部
$DebugMode = $false
# $DebugMode = $true  # 调试时取消注释

function Write-DebugLog {
    param([string]$Message)
    if ($DebugMode) { Write-Output "[DEBUG] $Message" }
}
```
