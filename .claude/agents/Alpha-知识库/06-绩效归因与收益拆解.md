# 06 — 绩效归因与收益拆解

> **定位**：Alpha（策略研究员）本地知识库 —— 从"能不能赚钱"到"为什么赚钱/亏钱"的分析框架
> **更新**：2026-05-23 | **关联文件**：01-因子体系总览、04-因子衰减与策略退化、腰子-知识库/13-Brinson归因与Barra风险模型

## 一、核心命题：没有归因就没有进化

### 1.1 问题

模拟交易系统每天都在生产数据——交易流水、每日持仓快照、评估数据。策略迭代当前依赖手工分析，缺乏系统性的收益拆解框架。

一组典型的需要回答的问题：
- 6只股票里，哪只贡献了最多利润？是信号准还是运气好？
- 拓普集团赚了3%，是因为技术面选得好，还是正好赶上了板块轮动？
- 止损触发后，回头看止损价定得合理吗？
- 交易成本吃掉了我多少Alpha？

### 1.2 归因的三层结构

```
Level 1: 交易层面 — "这笔交易赚/亏了多少？"
    ↓
Level 2: 因子层面 — "哪些因子贡献了这笔收益？"
    ↓
Level 3: 决策层面 — "这个决策在当时的信息集下是否正确？"
```

## 三、Level 2 — 因子层面归因

### 3.1 因子收益拆解框架

每笔交易的收益可以分解为：

```
总收益 = 市场Beta收益 + 行业Beta收益 + 选股Alpha + 残差

其中：
  市场Beta收益 = 个股Beta × 同期指数涨跌幅
  行业Beta收益 = 行业Beta × 同期行业指数涨跌幅
  选股Alpha = 总收益 - 市场收益 - 行业收益
```

### 3.2 六维度归因

将选股Alpha进一步映射到白皮书的六维评分体系：

| 维度 | 权重 | 可归因的信号 | 代理变量 |
|:-----|:---:|:-----------|:--------|
| 技术面 | 20% | ADX趋势判断、RSI信号、布林突破、OBV背离 | 入场后5日技术指标方向准确率 |
| 基本面 | 20% | ROE/PE/PEG筛选 | 入场后财务数据vs预期的偏差 |
| 消息面 | 15% | 研报覆盖、催化剂事件 | 入场前后30日研报数量/评级变化 |
| 板块 | 18% | 板块相位、相对强度 | 同期申万行业指数涨跌幅 |
| 资金面 | 15% | 主力资金流向、融资余额 | 入场后5日资金净流入 |
| 宏观 | 12% | 宏观环境判断 | 同期沪深300涨跌幅 |

### 3.3 归因计算流程

```
对每笔已平仓交易：
  ① 计算总收益 R_total
  ② 计算市场收益 R_market = Beta_stock × R_CSI300
  ③ 计算行业收益 R_sector = Beta_sector × R_sector_index
  ④ Alpha = R_total - R_market - R_sector
  ⑤ 将Alpha分解到六个维度：
     技术面贡献 ≈ 入场时技术面分 × 技术面准确率
     基本面贡献 ≈ 入场时基本面分 × 基本面实现率
     ... (各维度类推)
  ⑥ 汇总所有交易 → 得出各维度的累计贡献
```

### 3.4 与IC分析的衔接

因子IC衡量的是横截面上因子的预测能力，归因衡量的是时间序列上因子的实际贡献。

| 指标 | IC分析 | 绩效归因 |
|:-----|:------|:--------|
| 视角 | 截面（cross-section） | 时序（time-series） |
| 问题 | 这个因子能区分好股票和坏股票吗？ | 这个因子在我们的交易中实际赚了钱吗？ |
| 输入 | 所有股票×因子值×下期收益 | 已执行交易×各维度得分×实际收益 |
| 输出 | IC/ICIR | 因子贡献度/贡献占比 |

**两者不一致时的判断**：
- IC高但归因贡献低 → 因子有效，但我们的交易执行没抓到 → 改进执行
- IC低但归因贡献高 → 可能是运气/过拟合 → 警惕衰退

## 四、Level 3 — 决策层面归因

### 4.1 决策质量评估框架

不只看结果，看决策过程：

| 决策类型 | 好结果 | 坏结果 |
|:--------|:------:|:-----:|
| **好决策** | ✅ 值得重复 | ⚠ 坏运气，不否定决策 |
| **坏决策** | ⚠ 好运气，不奖励决策 | ❌ 需要修正 |

**判断标准**：
- 好决策 = 在当时可用信息集下，符合白皮书规则的决策
- 坏决策 = 违反规则、忽略信号、情绪驱动的决策

## 五、交易成本归因

### 5.1 成本拆解

```
实际收益 = 理论收益 - 显性成本 - 隐性成本

显性成本：
  - 佣金：成交金额 × 0.025%（买卖双向）
  - 印花税：卖出金额 × 0.1%（仅卖出）
  - 最低佣金：5元/笔

隐性成本：
  - 滑点：预设入场价 vs 实际成交价的偏差（模拟假设0.1%）
  - 冲击成本：大单对市场价格的推动（小资金可忽略）
  - 机会成本：限价单未成交的踏空成本（模拟中不适用）
```

### 5.2 成本影响估算

| 场景 | 理论收益 | 佣金+印花税 | 滑点 | 实际收益 | 成本吃掉% |
|:-----|:------:|:---------:|:----:|:------:|:-------:|
| 短线(持仓3天,+2%) | 2.00% | 0.15% | 0.1% | 1.75% | 12.5% |
| 短线(持仓3天,-1%) | -1.00% | 0.15% | 0.1% | -1.25% | 25% |
| 中线(持仓20天,+8%) | 8.00% | 0.15% | 0.1% | 7.75% | 3.1% |
| 波段(持仓60天,+20%) | 20.00% | 0.15% | 0.1% | 19.75% | 1.25% |

**关键结论**：短线高频交易中，成本可能吃掉10-25%的理论收益。对模拟交易系统而言，短线信号需要更高的置信度阈值才能覆盖交易成本。

## 七、与现有数据的对接

### 7.1 数据源映射

| 归因需要的数据 | 现有数据源 | 位置 |
|:------------|:---------|:-----|
| 交易记录 | transactions.csv | 模拟交易/持仓记录/ |
| 每日净值 | snapshot_YYYYMMDD.json | 模拟交易/每日快照/ |
| 入场时评分 | 评估数据_YYYYMMDD.json | 重点股票/次日评估/ |
| 市场收益 | 沪深300日线 [1] | stock_data_fetcher |
| 行业收益 | 申万行业指数 | sector API (主) / THS (备) |
| 个股Beta | 需计算 | 个股日收益 vs 沪深300日收益(60日滚动) |

### 7.2 自动化归因脚本

归因计算脚本应与后评估同时触发（每日盘后），输入为最新的transactions.csv和评估数据，输出归因摘要追加到 `perf_summary.json` 的 `attribution` 字段中。
