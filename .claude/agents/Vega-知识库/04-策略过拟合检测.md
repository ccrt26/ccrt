> **定位**：Vega（风控官）本地知识库 —— 量化策略过拟合识别与审计

## 一、过拟合本质：你在拟合噪音而不是信号

### 1.1 一句话定义

过拟合 = 你的策略不是在捕捉市场规律，而是在记忆历史数据的随机噪音。它回测时看起来很厉害，实盘中一塌糊涂。

### 1.2 过拟合 vs 拟合良好的区别

| 维度 | 拟合良好 | 过拟合 |
|:-----|:--------|:-----|
| 回测表现 | 稳定、合理的收益 | 异常高收益、几乎没有回撤 |
| 参数敏感度 | 参数小变化→结果小变化 | 参数微调→结果巨变 |
| 样本外表现 | 与样本内接近（差距<20%） | 大幅低于样本内（差距>30%） |
| 不同时段 | 各时段表现一致 | 集中在某几个时段暴利 |
| 极端事件 | 有合理的回撤 | 完美避开了所有暴跌日 |
| 逻辑解释 | 有清晰的金融逻辑 | 逻辑牵强，或"数据证明有效"是唯一理由 |

### 1.3 A股过拟合高发区

```
A股特别容易过拟合的原因：
1. 历史短：A股有效的日线数据满打满算约15年（2010至今），约3700个交易日
2. 结构性变化多：2015股灾、2016熔断、2018贸易战、2020疫情、2024量化危机
   →历史数据中的"规律"可能是当时的制度/环境造成的，现在已不复存在
3. 散户比例高→噪音大→信噪比低→更容易拟合到噪音
4. 政策冲击频繁→策略在某个政策周期里表现好不代表什么
```

## 二、过拟合五红旗（Marcos Lopez de Prado方法论）

### 2.1 概述

五红旗来自Lopez de Prado的经典论文《The Deflated Sharpe Ratio》(2014)和著作《Advances in Financial Machine Learning》(2018)。当任意一面红旗升起，就需要警惕过拟合；两面红旗=大概率过拟合；三面红旗=几乎确定过拟合。

### 2.2 红旗1：参数过多

```
红旗1升起条件：参数数量 > sqrt(有效观测数)

有效观测数 = 样本长度 / 平均持仓时间

示例：
  回测3年（约750个交易日），平均持仓5天：
  有效观测数 = 750/5 = 150
  sqrt(150) ≈ 12.2
  
  如果策略参数>12个→红旗1升起

注意：参数包括——
  - 明显的：入场阈值、止损比例、仓位百分比
  - 暗含的：选股数量、池子范围、行业剔除规则
  - 都必须算进去！
```

### 2.3 红旗2：样本内(IS) vs 样本外(OOS)差距过大

```
红旗2升起条件：|Sharpe_IS - Sharpe_OOS| / max(Sharpe_IS, 0.1) > 0.30

即：样本外夏普比样本内下降超过30%

示例：
  样本内夏普=2.0，样本外夏普=1.2
  差距 = |2.0-1.2|/2.0 = 0.40 > 0.30 → 红旗2升起

更宽松的检查（也很有用）：
  OOS收益 < IS收益 × 0.5 → 高度可疑
  OOS最大回撤 > IS最大回撤 × 1.5 → 高度可疑
```

### 2.4 红旗3：夏普比率异常高

```
红旗3升起条件：年化夏普比率 > 3（单策略）

夏普比率基准参考：
  <0.5：低于市场平均水平
  0.5-1.0：正常水平
  1.0-1.5：良好
  1.5-2.0：优秀（顶级对冲基金水平）
  2.0-3.0：极其优秀（怀疑中）
  >3.0：红旗3升起（几乎可以确定有过拟合或幸存偏差）

A股特定参考：
  沪深300长期夏普≈0.3-0.5
  A股公募基金前10%的夏普≈1.0-1.5
  A股量化私募顶级策略夏普≈1.5-2.5

任何声称A股年化夏普>3的策略，默认假设是"有过拟合"，
直到你能用铁证排除。
```

### 2.5 红旗4：对微小参数变化极度敏感

```
红旗4升起条件：
  Sharpe(参数+1%) 与 Sharpe(参数) 的差异 > 30%

测试方法：
  对每个参数执行±5%、±10%、±20%的扰动
  记录夏普比率的变化

示例：
  参数A=20日（夏普=1.8）
  参数A=22日（+10%）→ 夏普=0.9
  变化=|1.8-0.9|/1.8=50% > 30% → 红旗4升起

这表示策略对这个参数高度敏感——
在实际交易中，参数的最佳值会随着市场环境漂移，
如果你的策略只在精确的某个参数值上有效，它实际是无法执行的。
```

### 2.6 红旗5：缺少Walk-forward验证

```
红旗5升起条件：回测未包含Walk-forward（推进式）验证

Walk-forward验证是唯一能模拟"如果当时真的按这个策略交易会怎样"的测试方式。
普通的"固定周期样本内→样本外"测试可以用一次，
但如果你真的在交易，你不可能"等三年回测完再决定参数"——

你必须每过一段时间就用最近的数据重新优化参数。

所以Walk-forward验证模拟的是：
  Period 1: 用[t-T, t]训练 → [t, t+W]验证
  Period 2: 用[t+W-T, t+W]训练 → [t+W, t+2W]验证
  ...以此类推

没有Walk-forward验证→你的策略在实际中可能根本无法更新参数
→红旗5升起。
```

### 2.7 五红旗综合判定

| 红旗数量 | 判定 | 行动 |
|:------:|:-----|:-----|
| 0面 | 无过拟合信号 | 正常监控即可 |
| 1面 | 有过拟合风险 | 审查该面红旗的具体原因 |
| 2面 | 大概率过拟合 | 策略需要修改后方可使用 |
| 3面 | 几乎可以确定过拟合 | 策略不可直接使用，必须重构 |
| 4-5面 | 确定过拟合 | 策略废弃，不能投入实盘 |

## 三、PBO（Probability of Backtest Overfitting）

### 3.1 定义

PBO是Lopez de Prado提出的一个更严谨的量度：它不只看"有没有过拟合"，而是直接回答——**在所有测试过的参数组合中，样本内最优的那一组，它在样本外的表现排第几？**

### 3.2 CSCV（Combinatorially Symmetric Cross-Validation）计算步骤

```
步骤1：将回测收益率序列按时间切成偶数块（如N=16块）

步骤2：生成所有可能的"一半做IS、一半做OOS"的组合：
  从N块中抽取N/2块做IS，剩余N/2块做OOS
  共有C(N, N/2)种组合

步骤3：对每种参数组合：
  - 在每个IS/OOS划分中，记录IS Sharpe Rank（IS中的排名）
  - 记录OOS Sharpe Rank（OOS中的排名）

步骤4：对每种IS/OOS划分：
  - 选出IS中Sharpe最高的参数组合（即"回测最优"）
  - 找到这个参数组合在OOS中的表现排名

步骤5：计算PBO：
  PBO = (最优IS参数的OOS排名低于中位数的划分数) / 总划分数的比例

通俗理解：PBO=60%意味着有60%的概率，你在回测中选出的"最佳参数"，
实际上在样本外的表现只是中下水平——这几乎完全是过拟合。
```

### 3.3 PBO判定标准

| PBO值 | 判定 | 可靠性 |
|:----:|:-----|:-----|
| PBO < 0.10 | 极低过拟合风险 | 高可靠性 |
| 0.10 ≤ PBO < 0.30 | 低过拟合风险 | 可通过 |
| 0.30 ≤ PBO < 0.50 | 中等过拟合风险 | 需进一步审查 |
| PBO ≥ 0.50 | 高过拟合风险 | 策略不可直接使用 |

## 四、紧缩阀（Deflated Sharpe Ratio / DSR）

### 4.1 定义

DSR回答的问题比夏普比率更精确：**在测试了大量参数组合之后，你观察到的夏普比率是否仍然"统计显著"？**

```
DSR = P[SR > E[max(SR_1, SR_2, ..., SR_N)]]

其中：
SR = 你的策略的夏普比率
N = 你测试过的参数组合总数
E[max(SR_1, ..., SR_N)] = 在所有N种参数组合中，仅凭随机概率（纯噪音）
                         你能期望看到的最高夏普比率

计算E[max SR]的近似公式：
E[max SR] ≈ σ_SR × [(1-γ)×Z^{-1}(1-1/N) + γ×Z^{-1}(1-1/(N×e))]

其中：
σ_SR = SR的标准误（≈sqrt((1+SR²/2)/T)）
γ ≈ 0.5772（Euler-Mascheroni常数）
Z^{-1} = 标准正态分布的逆CDF
```

### 4.2 DSR判定标准

| DSR | 判定 | 行动 |
|:--:|:-----|:-----|
| DSR > 0.95 | 统计显著，且考虑了多次测试 | 夏普比率可信 |
| 0.80 ≤ DSR < 0.95 | 弱显著 | 可以接受但需警惕 |
| DSR < 0.80 | 不显著（在N次测试后，这个夏普可能是碰巧的） | 策略不可信 |
| DSR < 0.50 | 极其不显著 | 策略几乎肯定是过拟合 |

### 4.3 DSR的直观理解

```
假设你测试了100种参数组合（N=100），每种都有对应的回测夏普比率。
纯噪音（完全无效的信号）下，100种组合中最佳的那个，
"期望最佳夏普"大约是0.8-1.2（取决于样本量T）。

如果你的最佳夏普是1.5，而E[max]是1.0：
DSR≈P[SR随机>1.5|N=100] ≈ 如果概率低→DSR高→SR可信

如果你的最佳夏普是1.2，而E[max]也是1.0：
DSR≈0.5→你的SR和"纯碰运气能达到的"差不多→不可信

DSR的核心洞察：测试的参数组合越多，需要的夏普阈值就越高。
测1000种组合→E[max SR]更高→你的策略要达到更高的SR才算"真正有效"。
```

## 五、最小回测长度

### 5.1 公式

```
T_min ≥ N × TC × 2

其中：
T_min = 最小回测时长（交易日数）
N = 参数组合数
TC = 平均持仓时间（交易日数）

含义：回测长度至少要能覆盖所有参数组合的两倍持仓周期。
否则：你只是在几个交易决策上做统计，结论完全不可靠。

示例：
  策略有20种参数组合，平均持仓5天
  T_min = 20 × 5 × 2 = 200个交易日 ≈ 10个月

  如果只回测了6个月（120个交易日）→ 不足以得出可信结论
```

### 5.2 A股最短回测周期建议

| 策略类型 | 典型持仓时间 | 最少回测长度 | 建议回测长度 |
|:---------|:---------|:---------|:---------|
| 短线（日内-3天） | 2天 | 1年 | 2-3年 |
| 中短线（3-10天） | 5天 | 1.5年 | 3-4年 |
| 中线（10-30天） | 15天 | 2年 | 4-5年 |
| 长线（1-6月） | 60天 | 3年 | 5-6年 |

**A股特殊性**：由于2015年后的市场结构和交易制度发生了多次根本性变化，
理想情况下回测应至少覆盖一个完整的牛熊周期（2018-至今，约6年）。
仅覆盖2020-2021牛市的回测往往严重高估策略表现。

## 六、Walk-forward（推进式）验证流程

### 6.1 完整流程

```
标准Walk-forward流程：

数据总长度 T（如2018.01-2025.12，约8年）

每步结构：
├── 训练窗口（In-sample）：过去M个月（如24个月）
├── 清洗期（Purging）：跳过P天（如5天）
├── 验证窗口（Out-of-sample）：未来W个月（如6个月）

滑动：
  Step 1: 训练=[2018.01-2019.12], 清洗(5天), 验证=[2020.01-2020.06]
  Step 2: 训练=[2018.07-2020.06], 清洗(5天), 验证=[2020.07-2020.12]
  Step 3: 训练=[2019.01-2020.12], 清洗(5天), 验证=[2021.01-2021.06]
  ...

每步执行：
  1. 在训练窗口中优化策略参数
  2. 用最优参数在验证窗口中交易（模拟实盘）
  3. 记录验证窗口的表现

最终评估：所有验证窗口的表现汇总
  → 这比单一的"样本内→样本外"测试可靠得多
```

### 6.2 Purging（清洗）和Embargo（禁运）

```
Purging（清洗期）：
  问题：训练数据的最后一笔交易可能和验证数据的第一笔交易重叠
  解决：在训练和验证窗口之间插入P天的不交易期
  规则：Purging ≥ 平均持仓时间

  例：平均持仓5天 → Purging=5天

Embargo（禁运期）：
  问题：如果验证窗口的持仓还没有完全平掉就进入下一次训练，
        训练数据就"污染"了验证数据（未来信息泄露）
  解决：每次验证窗口结束后，再等E天才开始下一次训练
  规则：Embargo ≥ 平均持仓时间 × 2

  例：平均持仓5天 → Embargo=10天

无Purging+Embargo的Walk-forward = 假Walk-forward，信息泄露严重。
```

### 6.3 Walk-forward效率（WFE）

```
WFE = OOS_Sharpe / IS_Sharpe

判定：
  WFE > 0.80：策略稳定，IS→OOS衰减很小
  0.60 ≤ WFE ≤ 0.80：正常衰减，可接受范围
  0.40 ≤ WFE < 0.60：衰减较大，需要警惕
  WFE < 0.40：严重衰减，几乎可以确定过拟合
```

## 七、因子拥挤度检测

### 7.1 何为因子拥挤

因子拥挤是指过多资金追逐同一个因子，导致：
- 因子看好的股票被过度买入，估值偏离合理水平
- 任何风吹草动，拥挤资金同时撤离 → 踩踏
- 因子的正常回撤被放大为极端回撤

### 7.2 拥挤度四维检测

| 维度 | 指标 | 计算方法 | 阈值 |
|:-----|:-----|:---------|:---:|
| 估值拥挤 | PE/PB中位数 | 因子最高组的PE/PB中位数 | >历史90分位 → 拥挤 |
| 交易拥挤 | 换手率 | 因子最高组的日均换手率 | >历史80分位 → 拥挤 |
| 波动拥挤 | 波动率 | 因子最高组的20日波动率 | >历史90分位 → 拥挤 |
| 相关性拥挤 | Pairwise Corr | 因子最高组内个股间平均相关性 | >0.5 → 同质化拥挤 |

### 7.3 拥挤度综合判定

| 预警维度数 | 拥挤等级 | 行动 |
|:--------:|:------:|:-----|
| 0 | 不拥挤 | 正常 |
| 1 | 🟡 轻微拥挤 | 关注，降低该因子仓位至70% |
| 2 | 🟠 中度拥挤 | 降低该因子仓位至50%，分散至其他因子 |
| 3 | 🔴 严重拥挤 | 降低该因子仓位至30%，设置止损 |
| 4 | ⛔ 全面拥挤 | 暂停该因子全部仓位 |

### 7.4 Pairwise Correlation拥挤检测

```
步骤1：取因子最高分组（如PE最低的20只股票）
步骤2：计算这20只股票两两之间的60日收益率相关性
步骤3：取所有pairwise相关系数的中位数
步骤4：对比该中位数与历史分布

如果当前中位数 > 历史80分位：
  → 该因子组内个股的同质化程度正在上升
  → 同质化 = 风险共振 = 一旦下跌就会一起跌
```

## 八、Vega策略过拟合审计清单

### 8.1 快速审计流程

```
□ 五红旗检查（§2）：
  红旗1：参数数 > sqrt(有效观测数)？
  红旗2：IS Sharpe vs OOS Sharpe 差距>30%？
  红旗3：Sharpe > 3？
  红旗4：参数扰动±10% → Sharpe变化>30%？
  红旗5：缺少Walk-forward验证？

□ PBO检查（如有条件计算）：
  PBO < 0.30？

□ DSR检查（如有条件计算）：
  DSR > 0.80？

□ 最小回测长度检查：
  回测天数 > 参数组合数 × 持仓天数 × 2？

□ Walk-forward质量：
  Walk-forward效率WFE > 0.60？

□ 因子拥挤度：
  是否有≥2个拥挤维度被触发？

□ 其他检查：
  - 不同时间段表现是否一致？
  - 最差的6个月表现如何？
  - 策略是否避免了未来函数？
  - 是否考虑了交易费用和滑点？
```
