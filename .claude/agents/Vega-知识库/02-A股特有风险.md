## 一、退市新规（2025年1月1日起全面实施）

### 1.1 四大退市通道概览

2024年4月，证监会发布《关于严格执行退市制度的意见》，退市新规于**2025年1月1日**全面实施。新规核心变化：收紧财务指标、新增市值退市、强化造假打击、规范类退市细化。

| 退市类型 | 核心逻辑 | 2025年影响 |
|:---------|:---------|:---------|
| 财务类 | 业绩不达标→*ST→退市 | 营收门槛翻倍，主板从1亿→3亿 |
| 交易类 | 股价/市值过低→直接退市 | 新增市值退市，主板<5亿退市 |
| 规范类 | 内控/信披违规→ST→退市 | 新增资金占用指标 |
| 重大违法类 | 财务造假/重大违法→直接退市 | 造假金额标准更严，单年≥2亿且占比≥30% |

### 1.2 财务类退市：四道红线

| 指标 | 主板 | 创业板/科创板 | 触发条件 |
|:-----|:---:|:----------:|:---------|
| 扣非净利润+营收 | 扣非净利润为负 **且** 营收<3亿 | 扣非净利润为负 **且** 营收<1亿 | 第一年→*ST；第二年→退市 |
| 净资产 | 净资产为负 | 同主板 | 第一年→*ST；第二年→退市 |
| 审计意见 | 无法表示意见/否定意见 | 同主板 | 第一年→*ST；第二年→退市 |
| 未披露年报 | 未在法定期限披露年报/中报 | 同主板 | 停牌2个月→*ST；再2个月→退市 |

**营收扣除项**（防止虚增保壳）：
- 与主营业务无关的收入
- 不具备商业实质的收入
- 贸易类/类金融业务收入
- 关联交易中显失公允的部分
- 审计认定的其他应扣除收入

### 1.3 交易类退市

| 指标 | 主板 | 创业板 | 科创板 | 北交所 |
|:-----|:---:|:----:|:----:|:----:|
| 面值退市 | 连续20日收盘价<1元 | 同主板 | 同主板 | 同主板 |
| 市值退市 | 连续20日市值<5亿 | <3亿 | <3亿 | <3亿 |
| 成交量退市 | 连续120日成交量<500万股 | <200万股 | <200万股 | <100万股 |
| 股东人数退市 | 连续20日股东<2000人 | 同主板 | 同主板 | 同主板 |

**关键特征**：交易类退市**不经过*ST阶段**，直接终止上市。无整改期，触发即退。

### 1.4 规范类退市（2025新增）

| 违规类型 | ST条件 | 退市条件 |
|:---------|:-------|:--------|
| 资金占用 | 大股东/关联方占用>1000万 **或** >净资产5% | 占用>2亿 **或** >净资产30%，6个月未整改→直接退市 |
| 违规担保 | 违规担保余额>1000万 **或** >净资产5% | 6个月未整改→退市 |
| 内控审计 | 内控被出具否定/无法表示意见 | 连续2年→退市 |
| 信披违规 | 被证监会立案调查 | 认定重大违法→直接退市 |
| 控制权争夺 | 控制权无序争夺→投资者无法获取有效信息 | 规定时间内未解决→退市 |

### 1.5 重大违法类退市

| 造假指标 | 标准 | 结果 |
|:---------|:-----|:-----|
| 财务造假金额 | 单年≥2亿 **且** ≥当年营收/利润/净资产的30% | 直接退市 |
| 连续造假 | 连续3年造假 | 直接退市 |
| 造假比例 | 造假金额≥当年净资产的50% **且** ≥5亿 | 直接退市 |
| 欺诈发行 | IPO/再融资过程中造假 | 不得上市，回购全部新股 |
| 重大违法 | 危害国家安全/公共安全/生态安全等 | 直接退市 |

### 1.6 2025年退市数据（实际统计）

| 退市类别 | 数量 | 占比 |
|:---------|:---:|:---:|
| 强制退市 | 25家 | 81% |
| 主动退市 | 6家 | 19% |
| **合计** | **31家** | 100% |

**2026年趋势判断**：市值退市正在取代面值退市成为主流退市通道。随着小盘股估值中枢下移，越来越多的股票面临市值退市风险。

### 1.7 Vega退市风险筛查清单

要评估一只股票是否有退市风险，逐项检查：

```
□ 近两年扣非净利润是否为负？
  → 是：营收是否低于板块门槛（主板3亿/科创板1亿）？
  → 是：🔴 财务类退市高风险

□ 股价是否 < 2元？
  → <1.5元：🟡 逼近面值退市线
  → <1元：🔴 面值退市计数中

□ 市值是否接近退市线？
  → 主板 < 10亿：🟡 预警
  → 主板 < 5亿：🔴 市值退市

□ 大股东是否存在资金占用？
  → 检查"其他应收款"异常增长
  → 检查关联交易披露

□ 近三年是否有财务造假记录？
  → 有行政处罚/立案调查：🔴 重大违法退市风险

□ 审计意见是什么？
  → 无法表示意见/否定意见：🔴 第二年可能退市
  → 保留意见：🟡 关注
```

## 二、ST规则体系

### 2.1 ST vs *ST 区别

| 类型 | 含义 | 触发条件举例 | 涨幅限制 | 跌幅限制 |
|:-----|:-----|:---------|:------:|:------:|
| ST | 其他风险警示 | 内控缺陷、资金占用、经营困难 | 5% | 5% |
| *ST | 退市风险警示 | 财务指标触及退市红线 | 5% | 5% |

### 2.2 2026年4月最新征求意见稿变化

证监会2026年4月发布征求意见稿，拟对ST/*ST交易制度做重大修改：

| 改革项 | 现行规则 | 拟改规则 | 影响分析 |
|:-------|:--------|:--------|:---------|
| ST/*ST涨跌幅 | 5% | **拟改为10%** | 扩大波动空间，增加ST投机博弈 |
| 创业板第四套标准 | 仅三套 | **新增第四套**：成长性+创新性 | 放宽创业板入口，但退市出口同步收紧 |
| 科创板ST制度 | 无正式ST | **将引入科创板ST** | 科创板不再是"免检区" |

### 2.3 ST触发清单

**财务类ST触发条件**：
- 最近一个会计年度净利润为负且营收低于板块门槛
- 最近一个会计年度净资产为负
- 被出具无法表示意见或否定意见的审计报告

**规范类ST触发条件**：
- 资金占用>1000万或>净资产5%
- 违规担保余额>1000万或>净资产5%
- 董事会/股东大会无法正常运作
- 内控被出具否定意见
- 生产经营受严重影响（停产3个月以上）
- 主要银行账户被冻结

### 2.4 ST交易规则对风控的影响

```
假设持有*ST股票，涨跌幅5%：
  - 连续跌停时每日可逃出的最大亏损=5%
  - 跌停封单可能连续多日打不开→T+1制度下无法当日止损
  - 从买入ST到确认退市，历史案例显示平均亏损50-80%

风控规则：
  - ST股票不允许开新仓（硬规则）
  - 已持有ST股票必须在首次ST公告后3个交易日内清仓
  - *ST股票持仓时间不超过1个交易日（即：买入次日必须卖）
```

## 三、融资融券风险

### 3.1 核心指标

| 指标 | 公式 | 监管要求 | 券商一般执行标准 |
|:-----|:-----|:--------|:-------------|
| 维持担保比例 | (现金+证券市值)/(融资额+融券市值) | ≥130% | ≥140%（多数券商更严） |
| 平仓线 | 维持担保比例<130% | T+1日补足 | T日即通知 |
| 即时平仓线 | 维持担保比例<110% | 立即平仓 | 立即平仓 |
| 提取线 | 维持担保比例>300% | 超出部分可提取 | 同监管标准 |

### 3.2 融资融券风险事件链

```
事件触发 → 股价下跌 → 维持担保比例下降 →
  130%平仓线 → 强制平仓 → 卖出砸盘 →
  进一步下跌 → 更多融资盘被平仓 → 踩踏下跌

A股典型案例：2015年股灾
  6月12日：两市融资余额2.27万亿（历史峰值）
  8月26日：两市融资余额降至1.11万亿
  跌幅：51%
  平仓连锁反应是股灾的核心放大器。

风控应用：
  1. 持有高融资余额股票时，一旦市场下跌需警惕连锁平仓风险
  2. 两融余额/流通市值 > 10% → 🟡 融资过浓预警
  3. 两融余额/流通市值 > 15% → 🔴 高杠杆风险
```

### 3.3 融资融券风险筛查

| 风险维度 | 指标 | 阈值 | 风险等级 |
|:---------|:-----|:---:|:------:|
| 融资集中度 | 个股融资余额/全市场融资余额 | >5% | 🟡 |
| 融资浓度 | 个股融资余额/流通市值 | >10% | 🟡 |
| 融资浓度 | 同上 | >15% | 🔴 |
| 融券集中度 | 个股融券余量/流通股本 | >5% | 🟡（做空压力） |
| 维持担保比 | 全市场平均维持担保比例 | <200% | 🟡 |
| 维持担保比 | 同上 | <150% | 🔴 |

## 四、股权质押风险

### 4.1 核心指标

| 指标 | 公式 | 预警线 | 平仓线 |
|:-----|:-----|:----:|:----:|
| 质押比例 | 质押股数/总股本 | >50%（大股东质押>80%个人持股） | — |
| 质押预警线 | 股价跌至质押时价格的X% | 160%（主板）| 140%（主板）|
| 质押平仓线 | 股价跌至质押时价格的X% | — | 130%（主板）|

### 4.2 质押风险判断标准

```
大股东质押比例：
  >50%：🟡 关注
  >70%：🟠 预警——大股东资金链紧张
  >80%：🔴 危险——大股东几乎全部质押，爆仓一触即发
  >90%：⛔ 极度危险——股东已无任何腾挪空间

全市场质押率：
  >40%：🟡
  >50%：🔴

个股质押风险事件链：
  股价下跌 → 触及预警线 → 股东补仓或追加质押 →
    若无法补仓 → 触及平仓线 → 券商强制平仓 →
      大量卖单 → 股价加速下跌 → 更多质押盘被平仓
```

### 4.3 质押爆仓风险筛查清单

```
□ 大股东质押比例是多少？（>70%即高危）
□ 当前股价距预警线还有多少空间？
  → <15%：🟡 逼近预警
  → 已触及预警线：🔴 需确认是否已补仓
  → 已触及平仓线：⛔ 随时可能爆仓
□ 是否有近期解押记录？（如果频繁解押再质押→典型的借新还旧，资金链极度紧张）
□ 质押股份是否已被司法冻结？（→近乎确定要爆仓）
□ 大股东是否有其他高质押股票？（交叉风险）
```

## 五、涨跌停限制与流动性风险

### 5.1 各板块涨跌幅限制

| 板块 | 代码特征 | 涨跌幅限制 | 注释 |
|:-----|:--------|:--------:|:-----|
| 上海主板 | 60xxxx | ±10% | — |
| 深圳主板 | 00xxxx / 001xxx | ±10% | — |
| 科创板 | 688xxx | ±20% | — |
| 创业板 | 300xxx / 301xxx | ±20% | 2020年8月改革后 |
| 北交所 | 8xxxxx / 4xxxxx | ±30% | — |
| ST / *ST | 含ST标识 | ±5% | 2026.4征求意见拟改为±10% |
| 上市首日 | — | 无限制（临时停牌机制） | 44%临停（主板）、无限制（科创/创业板） |

### 5.2 涨跌停对风控的核心影响

```
问题1：流动性消失
  跌停意味着"想卖卖不掉"——不是不想止损，是完全无法止损。
  
  T+1+T字跌停的最差情况：
  Day 1：买入（T+1不能卖）
  Day 2：跌停开盘，挂单卖不出去
  Day 3：继续跌停，还是卖不出去
  ...
  连续N天跌停后 → 实际亏损远超任何VaR计算

问题2：涨停的诱惑
  涨停开盘→封板→无法买进→追涨心理加剧
  这种"买不到的焦虑"常常导致次日涨停价追买→随后开板被套

问题3：涨跌停的不对称
  跌9.5%和跌10%在实际效果上区别不大——
  但跌停（10%）意味着流动性完全消失，这是质变。
  项目中的9.4%阈值建议就是为了在质变之前行动。
```

### 5.3 涨跌停风险等级

| 状态 | 风险等级 | 行动 |
|:-----|:------:|:-----|
| 涨幅≥9.4%（逼近涨停） | 🟢 不构成风险（但禁止追买） | 不开新仓 |
| 正常区间（-7%至+7%） | 🟢 正常 | 正常运行策略 |
| 跌幅7%-9.3% | 🟡 关注 | 观察是否扩大 |
| 跌幅≥9.4%（逼近跌停） | 🔴 禁止开仓 | 持有仓位的挂卖单 |
| 已跌停 | ⛔ 流动性枯竭 | 排队挂单，次日优先处理 |
| 连续2日跌停 | ⛔⛔ 危机模式 | 不做任何新交易，全力处理现有危机 |

## 六、限售股解禁风险

### 6.1 解禁类型与锁定期

| 解禁类型 | 锁定期 | 减持限制 |
|:---------|:-----|:---------|
| IPO首发原始股东 | 12个月（控股股东36个月） | 解禁后每3个月通过集中竞价减持≤1% |
| 定增股份 | 6个月（竞价）/ 18个月（定价） | 解禁后每3个月集中竞价减持≤1% |
| 股权激励 | 12个月起（分期解锁） | 每年解锁≤25% |
| 并购重组 | 12个月起（视交易方案而定） | 同IPO解禁 |
| 大股东自愿锁定 | 自定（≥6个月） | 到期即解禁 |

### 6.2 解禁冲击评估

```
解禁冲击 = 解禁数量 × 当前股价 / 日均成交额

冲击倍数分级：
  <0.5×日均成交额：影响较小
  0.5×-2×日均成交额：🟡 可能有5-10%的下跌压力
  2×-5×日均成交额：🟠 可能有10-20%的下跌压力
  >5×日均成交额：🔴 流动性不足以消化抛压，可能出现15-30%的下跌

减持意愿加权（经验判断）：
  ×0.1：大股东（控股股东通常不减持）
  ×0.3：机构投资者（解禁后有退出需求）
  ×0.5：PE/VC（有明确的退出压力）
  ×0.8：员工持股/股权激励（小股东集中抛售）
  ×1.0：持股比例<5%的自然人（几乎必然减持）
```

### 6.3 减持新规（2024年修订）

| 规则 | 内容 |
|:-----|:-----|
| 破发限制 | 股价低于IPO发行价→控股股东/实控人不得减持 |
| 破净限制 | 股价低于每股净资产→控股股东/实控人不得减持 |
| 分红限制 | 近三年累计分红<年均净利润30%→控股股东不得减持 |
| 大宗交易减持 | 受让方锁定6个月 |
| 协议转让减持 | 受让方锁定6个月 |
| 离婚减持 | 婚内过户→双方合并计算减持额度（堵漏洞） |

### 6.4 Vega限售股解禁风险筛查

```
未来30天内：
□ 是否有解禁事件？（查询解禁日历）
□ 解禁量/日均成交量 = ？分级评估
□ 谁在解禁？（大股东/VC/员工）— VC和员工的减持意愿最高
□ 当前股价 vs IPO/定增价：浮盈→减持动力强；浮亏→减持动力弱
□ 解禁前是否有异常量价行为？（可能有内幕抛售）
□ 是否满足减持新规的红线条件？（破发/破净/分红不达标→禁减）
```

## 七、停牌风险

### 7.1 停牌类型

| 类型 | 典型原因 | 最长停牌时间 | 影响 |
|:-----|:---------|:----------|:-----|
| 重大事项 | 并购重组、重大合同 | 原则上≤10日 | 资金锁死，无法止损 |
| 核查 | 股价异常波动核查 | 视核查进度 | 复牌后方向不确定 |
| 退市整理 | 退市决定后 | 15个交易日 | 彻底归零倒计时 |
| 被调查 | 证监会立案调查 | 期限不定 | 重大不确定性 |
| 技术停牌 | 系统故障、股东大会 | 半日到一日 | 影响较小 |

### 7.2 停牌风控规则

```
强制预防：
  - 单只股票占总资产>15%：必须关注停牌风险
  - 单只股票占总资产>25%：禁止（停牌即锁死1/4资金）
  
停牌期间：
  - 停牌超过5日的持仓：每日评估复牌后可能的方向和幅度
  - 停牌超过10日：每天计算穿透风险（复牌后如果连续跌停的最大亏损）
  - 并购重组停牌+公告失败：复牌大概率暴跌，准备好第一时间排队挂单
```
