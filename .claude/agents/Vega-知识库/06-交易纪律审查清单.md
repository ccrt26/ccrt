## 一、盘前检查清单（10项）

### 1.1 必须在开盘前完成

| 编号 | 检查项 | 通过标准 | 不通过时 |
|:---:|:-------|:---------|:--------|
| P1 | 今日是否有持仓面临解禁/除权除息/ST风险？ | 全部持仓未来3日内无风险事件 | 提前制定清仓/应对方案 |
| P2 | 隔夜外盘（美股/港股）涨跌情况 | — | 记录方向性参考，不做决策依据 |
| P3 | 今日是否有重大经济数据/政策发布？ | 已查阅财经日历 | 对重大事件日保持谨慎 |
| P4 | 当前持仓的总风险敞口（VaR+CVaR）是多少？ | VaR(95%)<总资金5%、CVaR(99%)<10% | 超限则减仓至安全线以内 |
| P5 | 当前回撤等级是什么？对应的仓位上限是多少？ | 仓位≤当日等级上限 | 超限则立即减仓 |
| P6 | 今日是否有冷却期限制？（止损/止盈冷却） | 冷却期已结束 | 冷却期内不开新仓 |
| P7 | 各持仓的止损价是否已经设定？ | 每只持仓都有明确止损价 | 补充止损价后再交易 |
| P8 | 当前市场状态评估（牛市/震荡/熊市） | 有明确判断+证据 | 不做无方向判断的状态下交易 |
| P9 | 今日策略参数是否需要按市场状态调整？ | 已按当前状态调整 | 避免在错误参数下交易 |
| P10 | 心理状态自评：是否冷静、客观？ | 无强烈情绪波动 | 情绪不稳时不交易 |

## 二、盘中监控清单（8项）

### 2.1 实时监控项

| 编号 | 监控项 | 检查频率 | 异常阈值 | 触发行动 |
|:---:|:-------|:------:|:--------|:---------|
| M1 | 单日净值变动 | 每30分钟 | -3% | 🟡 检查各持仓，确认非系统性风险 |
| M2 | 单日最大亏损持仓 | 每30分钟 | -5% | 🟠 该股检查：是否应该止损？ |
| M3 | 跌停持仓数量 | 实时 | ≥1只跌停 | 🔴 跌停股票挂单排队，优先处理 |
| M4 | 持仓涨跌停逼近度 | 实时 | 逼近9.4% | 🟡 涨→不开新；跌→准备止损 |
| M5 | 成交量异常 | 每小时 | 单只持仓成交>日均3倍 | 🟡 检查是否有异常事件 |
| M6 | 行业板块异动 | 每60分钟 | 持仓最重行业跌>3% | 🟠 行业系统性风险，考虑减仓 |
| M7 | 熔断线逼近度 | 实时 | 日内亏损达-4% | 🔴 距日内熔断(-5%)仅1%，高度警惕 |
| M8 | 是否有手动干预的冲动 | 每次产生冲动时 | "我想手动改止损/提前平仓/加仓" | 停下来，等5分钟，再决定 |

### 2.2 盘中熔断紧急处理

```
如果日内亏损达到-5%，触发日内熔断：

第1步（立即）：停止所有操作——不买不卖不改参数。
第2步（15分钟内）：确认熔断触发——核实净值计算无误。
第3步（30分钟内）：初步分析——什么导致了-5%？
  - 系统性风险？（大盘暴跌→宏观事件）
  - 个别持仓？（某只股跌停→个股风险）
  - 策略连续失败？（多只持仓同时亏损→策略失效）
第4步（当日收盘后）：完整复盘——填写"熔断事件报告"
第5步（次日）：按熔断规则执行——不开新仓，只可减仓
```

| A7 | 手续费占亏损比 | 手续费/总亏损（如果亏损） | <20%（手续费不是亏损主因） |

### 4.2 冷却期结束条件审查

```
所有条件必须满足才能结束冷却期：

□ 1. 冷却期自然时长已满
□ 2. 已完成归因分析并记录
□ 3. 如果是策略原因→策略参数已调整

□ 5. 心理状态自评为"冷静"

□ 7. 恢复后止损设置为正常水平的70%（更紧）

如果以上任一项不满足→延长冷却期1-2天
```

## 五、连败心理干预流程

### 5.1 连败的心理阶段（必知）

```
第1-2次连败：正常心态——"运气不好，下笔会赚"
  → 风险：开始轻微放松止损纪律（"这次差一点点，下次可能就对了"）

第3-4次连败：焦虑心态——"怎么会这样？"
  → 风险：试图"优化"策略→可能在情绪驱动下改参数→更糟
  → 干预：此时必须启动审查模式

第5-7次连败：愤怒/恐慌心态——"我要翻本！"
  → 风险：增加仓位、放宽止损、报复性交易
  → 干预：此时必须强制暂停

第8次+连败：绝望/放弃——"反正已经亏这么多了"
  → 风险：完全放弃纪律、all-in、破罐破摔
  → 干预：必须强制停工+外部干预
```

### 5.2 心理干预措施

| 连败数 | 心理干预 | 具体行动 |
|:-----:|:--------|:---------|
| 3笔 | 自我提醒 | "连续3笔亏损是正常现象，不代表策略失效。但我需要检查每笔亏损是否在策略框架内。" |
| 5笔 | 强制冷却 | "连续5笔亏损说明我需要暂停。不管是不是'运气问题'，继续交易会放大情绪影响。" |
| 8笔 | 外部求助 | "一个人扛不住了。找腰子或Claude讨论，获取外部视角。" |

### 5.3 禁止行为清单（连败时最易犯）

```
⛔ 加仓翻本："再加大仓位，一笔就赚回来"
⛔ 放宽止损："给多一点空间，别被正常波动震出去"
⛔ 改策略："这个参数不对，换一个试试"
⛔ 换股票："选股逻辑有问题，换一批票"
⛔ 忽视冷却期："冷却期是给新手设的，我知道自己在做什么"
⛔ 频繁查看账户："看看回本了没有"

这些都是你亏损后的情绪在说话——不是你的专业判断。
```

## 七、异常交易检测

### 7.1 频繁交易检测

```
频繁交易 = 交易频率显著高于策略正常水平

检测指标：
  日均交易笔数 > 正常水平的1.5倍 → 🟡
  日均交易笔数 > 正常水平的2倍 → 🟠
  日均交易笔数 > 正常水平的3倍 → 🔴 过度交易

A股短线策略的正常水平：
  中短线选股策略：日均0.5-1笔
  事件驱动策略：日均0.3-0.5笔
  高频/极短线：日均1-2笔

手续费侵蚀检测：
  日手续费/日盈亏 > 20% → 建议降低频率
  日手续费/日盈亏 > 50% → 交易频率过高，侵蚀大部分利润
```

### 7.2 追涨杀跌检测

```
追涨信号：
  - 买入价在全日涨幅>7%的区段 → 🟡
  - 买入价接近涨停价（>9%）→ 🔴 追涨停
  - 买入后15分钟内股价回落>2% → 🟠（典型的追高被套）

杀跌信号：
  - 卖出价在全日跌幅>7%的区段 → 🟡
  - 卖出价接近跌停价（<-9%）→ 🔴 恐慌杀跌
  - 卖出后15分钟内股价反弹>2% → 🟠（典型的杀跌后悔）

检测规则：
  如果1周内出现2次以上追涨信号 → 🟡 审查交易心理
  如果1周内出现2次以上杀跌信号 → 🟠 审查止损纪律（可能放松了）
  如果同一天出现追涨+杀跌 → 🔴 情绪化交易
```

### 7.3 情绪化交易检测

```
情绪化交易的信号：
1. 交易理由包含"我觉得"/"感觉"/"应该会"/"不会再跌了"
   → vs 正常理由："PE分位<20%、板块动量排名前3、技术面突破确认"

2. 同一只股票在3个交易日内"买→卖→买"（来回折腾）
   → 正常的: "买→持有→卖"，不会频繁在同一标的上反复

3. 亏损后的下一笔交易仓位突然增加50%以上
   → "翻本"心理

4. 盈利后的下一笔交易仓位突然增加50%以上
   → "过度自信"心理

5. 非交易时间（周末/深夜）频繁登录检查持仓
   → 焦虑信号——你对持仓的信心已经动摇

判定：
  1个信号：正常，注意即可
  2个信号：🟡 情绪开始影响交易
  3个信号：🟠 建议暂停交易1-2天
  4-5个信号：🔴 情绪化交易严重，强制暂停
```

## 十、禁忌交易行为速查

| 行为 | 严重等级 | 后果 | 预防措施 |
|:-----|:------:|:-----|:---------|
| 不设止损就开仓 | ⛔ 致命 | 单笔亏损无限 | 系统强制：无止损不开仓 |
| 止损触发不执行 | ⛔ 致命 | 小亏变深套 | 自动止损单不可撤回 |
| 冷却期开新仓 | 🔴 严重 | 报复性交易→扩大亏损 | 系统锁定：冷却期内禁止开仓 |
| 加仓摊平亏损 | 🔴 严重 | 亏损翻倍 | 项目铁律：亏损持仓不加仓 |
| 连败后加大仓位 | 🔴 严重 | 加速亏损 | 连败3笔→仓位自动降至50% |
| 手动下调止损价 | 🔴 严重 | 突破纪律底线 | 止损只能上移不能下移 |
| 集合竞价追涨停 | 🟠 较严重 | 当日无法止损 | 涨停≥9.4%不开新仓 |
| 跌停排队恐慌卖出 | 🟠 较严重 | 最低点出局 | 跌停不卖出，等反弹或次日 |
| 同一标的频繁进出 | 🟡 关注 | 手续费侵蚀 | 3日内同一标的最多1次开仓 |
| 没有任何理由就开仓 | 🟡 关注 | 纯赌博 | 必须填写开仓理由 |
