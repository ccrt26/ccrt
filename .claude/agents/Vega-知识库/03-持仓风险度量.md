## 一、集中度风险

### 1.1 Herfindahl-Hirschman指数（HHI）

HHI是测量集中度的标准工具。越集中→HHI越高→风险越大。

```
HHI = Σ(w_i)²

其中：
w_i = 第i只持仓占总资产的比例

取值范围：
  最小：1/N（完全等权重，N=持仓只数）
  最大：1.0（只有一只股票，100%集中）

示例：
  持有3只等仓位：HHI = (0.333)²×3 = 0.333
  持有3只等仓位+1只40%仓位：HHI = 0.4²+0.2²+0.2²+0.2² = 0.28
```

### 1.2 HHI风险评估

| HHI值 | 等效持仓数 | 风险等级 | 行动 |
|:-----:|:--------:|:------:|:-----|
| <0.10 | >10只等权 | 🟢 分散良好 | 正常运营 |
| 0.10-0.15 | 7-10只等权 | 🟢 合理分散 | 正常运营 |
| 0.15-0.20 | 5-7只等权 | 🟡 中等集中 | 审查集中来源，考虑增加分散度 |
| 0.20-0.30 | 3-5只等权 | 🟠 高风险集中 | 强制减仓最集中持仓，增加持仓数量 |
| 0.30-0.40 | 2-3只等权 | 🔴 过度集中 | 强制降仓至多只持仓 |
| >0.40 | <2.5只等权 | ⛔ 极端集中 | 立即减仓最大持仓 |

### 1.3 行业集中度

```
行业HHI = Σ(行业权重_i)²

行业分类标准：申万一级行业（31个行业）

预警阈值：
  单一行业权重 > 30%：🟡
  单一行业权重 > 40%：🟠
  单一行业权重 > 50%：🔴
  行业HHI > 0.20：🟠（相当于5个行业等权，但只有2-3个行业实际有仓位）
  行业HHI > 0.30：🔴（极度行业集中）

行业相关性加成：
  同行业：ρ≈0.6-0.8 → HHI风险直接×1.5倍
  同产业链上下游：ρ≈0.3-0.5 → HHI风险×1.2倍
  如：电子+半导体+消费电子=同一产业链，虽不同申万一级行业但相关度高
```

### 1.4 个股集中度硬规则（对于本项目组合）

| 规则 | 阈值 | 性质 |
|:-----|:---:|:-----|
| 单股上限 | 总资产30% | 硬上限，不可突破 |
| 最大持仓数量 | 3只（每只>20%） | 硬上限 |
| 前2大持仓合计 | 总资产50% | 软上限，超出需书面说明 |
| 前3大持仓合计 | 总资产65% | 软上限，超出需减仓 |
| 单日单股加仓上限 | 总资产10% | 防止集中建仓 |
| 新建仓单股初始上限 | 总资产15% | 新仓不宜过重 |

## 二、相关性矩阵与组合分散化

### 2.1 相关性矩阵构建标准

```
数据要求：
  - 日收益率序列
  - 最近60个交易日（约3个月）
  - 至少30个有效交易日（排除停牌日）
  - 使用对数收益率：r_t = ln(P_t/P_{t-1})

计算：
  Pearson ρ_ij = Cov(r_i, r_j) / (σ_i × σ_j)
  其中Cov = Σ[(r_i,t - μ_i)(r_j,t - μ_j)] / (T-1)

有效性检查：
  如果任意一对的ρ>0.90：可能数据问题或两者本质上是同一资产
  如果任意一对的ρ<-0.50：罕见，检查数据
```

### 2.2 分散化效果量化

```
组合方差分解：
σ²_p = Σ(w²_i × σ²_i) + ΣΣ(w_i × w_j × σ_i × σ_j × ρ_ij)

第一项：个股风险的加权和（可以通过增加持仓数来降低）
第二项：协方差交叉项（不能通过增加持仓数来降低——这就是系统性风险）

极限分解（N→∞时，等权重）：
σ²_p → 平均协方差 + (平均方差 - 平均协方差)/N

当N很大时，组合方差趋近于"平均协方差"——这就是市场系统性风险。
再增加持仓，也只能分散个股风险，无法分散系统性风险。

A股经验：
  N=5：可以分散约40%的个股风险
  N=10：可以分散约65%的个股风险
  N=15：可以分散约80%的个股风险
  N=20：边际分散效果极低（已达极限的90%+）
  N>20：纯属增加管理负担，风控效果几乎无增量
```

### 2.3 相关性监控规则

| 条件 | 判断 | 行动 |
|:-----|:-----|:-----|
| 组合平均ρ_avg < 0.30 | 分散化有效 | 正常 |
| 0.30 ≤ ρ_avg < 0.50 | 🟡 相关性上升 | 检查是否因市场同步涨跌导致（系统性原因）还是个股间共性增强（结构性原因） |
| 0.50 ≤ ρ_avg < 0.70 | 🟠 分散化减弱 | 结构性原因→换掉最高相关的1-2只 |
| ρ_avg ≥ 0.70 | 🔴 同质化 | 分散化失效，强制减仓或换仓 |
| ρ_max > 0.85（某对持仓相关性） | 🔴 一对持仓高度同步 | 建议替换其中一只 |
| ρ波动率上升（ρ的20日标准差） | 🟡 相关性不稳定 | 风控模型假设可能失效 |

### 2.4 相关性矩阵的局限（务必理解）

```
局限1：ρ只测线性关系。
  两只股票可能"风险因子相同"（如都依赖出口）但日收益相关度只有0.3。
  ρ不能代替你对基本面的理解。

局限2：60日窗口可能太短或太长。
  牛市60日和熊市60日，相关性矩阵可能完全不同。
  建议同时维护两个矩阵：60日（短）和250日（长），对比变化。

局限3：相关性本身就是波动的。
  你不能假设"这两只股票相关度0.3，所以它们永远相关度0.3"。
  在压力情境下，相关性会急剧升高（见01文件§5.2危机相关性趋同）。
```

## 三、流动性风险

### 3.1 Amihud非流动性指标

```
ILLIQ = |R_t| / Volume_t

其中：
R_t = 日收益率
Volume_t = 日成交额（亿元或百万元不等）

含义：每单位成交额能推动多大的价格变化。
ILLIQ越高→流动性越差→越小的成交额就能推动越大的价格变化→你越难在不影响价格的情况下平仓。

月度ILLIQ = 1/T × Σ(|R_t| / Volume_t)

其中T为该月的交易天数。
```

### 3.2 Amihud指标的A股分级

| ILLIQ级别 | 大致范围（单位：|%|/亿元） | 流动性描述 | 典型对应 |
|:--------:|:--------------------------:|:---------|:--------|
| 极好 | < 0.005 | 大盘蓝筹级别 | 贵州茅台、宁德时代、中国平安 |
| 良好 | 0.005 - 0.02 | 中盘股 | 沪深300中后段标的 |
| 一般 | 0.02 - 0.10 | 中小盘 | 中证500成分股 |
| 较差 | 0.10 - 0.50 | 小盘微盘 | 中证1000/中证2000 |
| 极差 | > 0.50 | 僵尸股/仙股 | 日成交不足500万 |

### 3.3 换手率监控

| 换手率（日） | 流动性描述 | 风控影响 |
|:----------:|:---------|:---------|
| < 0.1% | 极低流动性 | 🔴 100万资金可能就需要多日才能平仓 |
| 0.1% - 0.5% | 低流动性 | 🟠 大单会有明显冲击 |
| 0.5% - 2% | 正常 | 🟢 一般交易无冲击 |
| 2% - 5% | 活跃 | 🟢 进出无碍 |
| 5% - 10% | 非常活跃 | 🟡 关注：可能是异常换手（对倒、出货、游资击鼓传花） |
| > 10% | 异常 | 🔴 大概率有未公开信息或操纵 |

### 3.4 平仓冲击成本估算

```
冲击成本 ≈ 持仓金额 × spread_half × (1 + √(持仓金额/日均成交额))

其中：
spread_half = 半买卖价差（A股约0.05-0.15%，小盘股可达0.3-0.5%）

简化经验公式（A股适用）：
总冲击成本(%) ≈ 0.1% + 0.5%×√(持仓金额/日均成交额)

示例：
  持仓100万，日均成交5000万：冲击≈0.1%+0.5%×√0.02≈0.17%
  持仓100万，日均成交500万：冲击≈0.1%+0.5%×√0.2≈0.32%
  持仓100万，日均成交100万：冲击≈0.1%+0.5%×√1.0≈0.60%
  
结论：日均成交额应至少是持仓金额的10倍以上。
  → 持仓金额/日均成交额 > 20%：🟡 需要考虑分批进出
  → 持仓金额/日均成交额 > 50%：🔴 无法在不明显影响价格的情况下平仓
```

### 3.5 流动性压力测试

```
场景：市场急跌，需要3日内全部平仓
假设：
  - 所有股票的流动性同时恶化
  - 日均成交额降至正常水平的30%
  - 买卖价差扩大至正常水平的3倍

计算每只股票的平仓天数 = 持仓金额/(日均成交额×30%)

如果平仓天数 > 3：🟡 无法在目标时间内全部平仓
如果平仓天数 > 5：🔴 平仓过程本身会加剧亏损

极端案例：
  持有200万某小盘股，正常日均成交500万
  危机时日均成交降至150万
  平仓天数 = 200/150 = 1.33天 → 🟢 OK

  持有500万同一股票
  平仓天数 = 500/150 = 3.33天 → 🟡 勉强3天平仓
  但连续3天卖出500万，实际冲击可能远大于模型估算
```

## 四、情景压力测试

### 4.1 板块轮动冲击

```
情景：持仓集中的板块突然轮动转弱
假设：该板块下跌10%，其他板块不变

对组合的影响：
ΔV = Σ(w_i × β_i_sector × Δsector)

其中β_i_sector为股票i对该板块的敏感度（用60日收益回归估计）

如果ΔV < -5%：🟡 板块单一风险过高
如果ΔV < -10%：🔴 极度暴露于板块轮动风险
```

### 4.2 流动性枯竭情景

```
情景：市场成交额萎缩至正常水平的30%

检查项：
□ 哪些持仓的日均成交额×30% < 持仓金额？（→无法正常平仓）
□ 持仓组合的流动性储备：现金比例是否≥20%？
□ 最近一笔平仓需要多久？（按当前流动性估算）
□ 是否持有停牌股票？（停牌期间完全无法变现）

流动性不足时的优先级：
1. 先平流动性最好的（冲击小）→回收现金
2. 再平流动性中等的 →控制损失
3. 最后处理流动性差的 →因为反正急不来
```

### 4.3 黑天鹅事件情景

```
情景：当日沪深300跌-7%（熔断级别）

A股熔断机制（仅指数，非个股）：
  - 沪深300跌5%：暂停交易15分钟
  - 沪深300跌7%：全天暂停交易
  - 注意：2024年量化危机中并未触发熔断，因为微盘股暴跌+权重股未跌

对持仓的冲击推演：
Phase 1（冲击发生）：指数快速下跌，个股几乎无差别暴跌
Phase 2（恐慌扩散）：融资盘强平、止损盘涌出、流动性消失
Phase 3（缓解+分化）：优质股率先反弹，垃圾股继续下跌

需要在Phase 1就采取行动，否则到Phase 2已经出不去。
```

## 五、最大回撤（MDD）与相关比率

### 5.1 最大回撤计算

```
MDD = max((P_peak - P_t) / P_peak)

其中：
P_peak = 到t时刻为止的最高净值
P_t = t时刻的净值

全过程遍历：
对于每一个t：
  找到t之前所有净值中的最大值P_peak
  drawdown_t = (P_peak - P_t) / P_peak
MDD = max(所有drawdown_t)

注意：MDD是路径依赖的——它描述的是"曾经亏得最惨的时候有多惨"。
这与VaR不同：VaR是"一天最坏亏多少"，MDD是"一波最多亏多少"。
两者不可互相替代。
```

### 5.2 不同策略的MDD预期

| 策略类型 | 年化收益预期 | 预期MDD | Calmar比率 | 最大可接受MDD |
|:---------|:---------:|:------:|:--------:|:---------:|
| 保守型（高股息+蓝筹） | 8-12% | 8-12% | 0.8-1.5 | 15% |
| 稳健型（多因子选股） | 12-20% | 12-18% | 0.8-1.3 | 20% |
| 进取型（小盘成长+动量） | 18-30% | 18-30% | 0.7-1.2 | 30% |
| 激进型（短线+事件驱动） | 25-50% | 25-45% | 0.6-1.0 | 40% |
| 本项目（铁律量化） | 15-25% | 15-25% | 目标≥1.0 | 25% |

### 5.3 Calmar比率

```
Calmar Ratio = 年化收益率 / MDD

含义：每承担1%的最大回撤，你获得了多少年化收益。

判定标准：
  >2.0：优秀（回撤控制极好）
  1.0-2.0：良好（正常的风险回报比）
  0.5-1.0：一般（回撤偏大，需要优化）
  <0.5：差（承担了过多的回撤，收益不足以弥补）
  <0：亏损策略，无需进一步评估

本项目目标：Calmar > 1.0
```

### 5.4 滚动回撤监控

```
滚动20日回撤（最常用）：
DD_20d = (P_20d_high - P_current) / P_20d_high

滚动60日回撤：
DD_60d = (P_60d_high - P_current) / P_60d_high

两者的比值：
DD_20d / DD_60d
  < 0.5：短期回撤已经超过中期回撤的一半 → 🟡 回撤可能还在加深
  > 0.9：短期回撤已接近中期最大回撤 → 🔴 接近创出新低
```

## 六、回撤预算制度

### 6.1 回撤预算框架

```
总回撤预算 = 最大可接受回撤（如25%）

分解：
  策略回撤预算 = 60% × 总预算 = 15%（策略本身正常的波动）
  事件回撤预算 = 25% × 总预算 = 6.25%（用于黑天鹅冲击）
  预留缓冲 = 15% × 总预算 = 3.75%（不主动使用）

消耗规则：
  当累计回撤达到策略回撤预算的50%（7.5%）→ 🟡 预警
  当累计回撤达到策略回撤预算的75%（11.25%）→ 🟠 减仓至50%
  当累计回撤达到策略回撤预算的90%（13.5%）→ 🔴 暂停交易
  当累计回撤触及事件回撤预算（21.25%）→ ⛔ 强制清仓
```

### 6.2 回撤恢复规则

```
回撤后的仓位恢复：
条件：回撤从最大点恢复50%以上（即：如果MDD是20%，回撤恢复到10%以内）

恢复节奏：
  第1步：仓位恢复至正常水平的50%
  第2步：连续5个交易日无新低→仓位恢复至75%
  第3步：回撤恢复至预算的25%以内（6.25%）→仓位恢复至100%

禁止行为：
  禁止在回撤加深过程中加倍下注（"补仓拉低均价"）——这是散户行为的核心特征
  禁止在回撤恢复初期就满仓——此时的策略可能仍然不稳定
```

## 七、持仓风险综合评分卡

### 7.1 评分维度

| 维度 | 权重 | 评分方法 |
|:-----|:---:|:---------|
| 集中度 | 25% | HHI + 行业集中度 + 个股最大权重 |
| 相关性 | 20% | 组合平均ρ + ρ变化趋势 |
| 流动性 | 20% | Amihud ILLIQ + 平仓冲击估算 |
| 事件风险 | 15% | 解禁/停牌/退市风险叠加 |
| 杠杆风险 | 10% | 是否使用融资+维持担保比例 |
| 波动率 | 10% | GARCH预测波动率 vs 历史波动率 |

### 7.2 综合风险评分算法

```
每个维度得分为1-5（1=最安全，5=最危险）：

集中度得分：
  HHI<0.1 → 1
  0.1≤HHI<0.15 → 2
  0.15≤HHI<0.20 → 3
  0.20≤HHI<0.30 → 4
  HHI≥0.30 → 5

其他维度类似。

综合风险分 = Σ(维度得分 × 权重)

判定：
  1.0-1.5：🟢 低风险
  1.5-2.5：🟢 正常
  2.5-3.5：🟡 需要关注
  3.5-4.0：🟠 需要减仓或调整
  4.0-5.0：🔴 暂停新交易，紧急调整
```
