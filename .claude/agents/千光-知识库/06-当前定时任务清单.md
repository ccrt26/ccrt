## 五、任务依赖DAG

```
每日流程：
D01(选股池) → D02(行情) ──→ D04(评分) → D05(报告)
                  ↓
            D03(财务检查) ──↗

收盘后：
D06(备份) → D07(缓存预热)

每周流程：
W03(版本检查) → W02(周度审计)
W01(财务刷新) → W04(因子IC)

月度流程：
M01(深度审计) → M03(月报)
M02(因子评审)
```

## 六、节假日处理

```
交易日判断：中国A股交易日历
  - 周末(周六/周日)：跳过每日任务
  - 法定节假日：跳过每日任务
  - 调休工作日(周六/周日补班)：正常执行
  - 半天交易日(如除夕)：正常执行，提前至08:00

节假日日历来源：上交所/深交所官网交易日历
```

## 七、失败通知链

```
任务失败
  ↓
重试1次(间隔2分钟)
  ↓ 仍失败
降级执行(按失败处理列)
  ↓ 降级也失败
告警 → 玉夜巡检通道(标记P3)
  ↓
千光在下次对话中汇报+建议修复
```

## 八、维护规则

- 新增定时任务→千光登记于此+红结实现+红枫部署
- 任务下线→标记状态🔴+保留配置6个月
- 每次任务失败→记录失败日志+失败率>5%触发千光审查
- 每季度检查任务清单是否需要优化(合并/拆分/调整时间)
