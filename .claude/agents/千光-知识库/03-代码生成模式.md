> 关联文件：01-CI流水线设计、02-定时任务编排、04-构建脚本规范

## 一、模板化原则

### 1.1 触发条件

同一代码模式在项目中**出现3次及以上**时，应当考虑提取为模板。模板不是核心逻辑的替代品——模板只做骨架，具体逻辑由开发者在模板标注的插入点自行填充。

### 1.2 模板化的收益

- **一致性**：所有API调用有统一的错误处理和超时逻辑
- **可维护性**：修改重试策略时只需改模板，下游脚本自动继承
- **降低遗漏**：新人/Claude写脚本不会忘记 ErrorActionPreference、不会忘记编码声明
- **红线合规**：模板内嵌1+2数据源降级路径，防止遗漏

### 1.3 模板不做什么

- 不替代核心业务逻辑（评分公式、选股策略）
- 不自动生成完整脚本（只生成骨架）
- 不绕过人工审查（生成的代码仍需新安审查）

## 二、已识别的重复模式及模板

### 2.1 API调用封装模板

**出现位置**：`stock_data_fetcher.psm1`、`batch_data_collector.ps1`、玉夜巡检脚本、各类数据获取脚本

**重复模式**：
1. 构造URL
2. 设置超时和User-Agent
3. Invoke-WebRequest / Invoke-RestMethod
4. 检查HTTP状态码
5. 解析JSON
6. 错误时切换到备源
7. 记录耗时

**PS模板骨架**：

```powershell
<#
.SYNOPSIS
    {API_NAME} 数据获取 — {DATA_DESCRIPTION}
.DESCRIPTION
    主源 {PRIMARY_SOURCE} → 备源 {BACKUP_SOURCE} → 缓存[C]
    符合红线§1.1 数据源1+2架构
.NOTES
    模板版本: api-call-template v1.0
    生成时间: {GENERATION_DATE}
#>
function Get-{DATA_NAME} {
    param(
        [Parameter(Mandatory = $true)]
        [string]$Symbol,
        [int]$TimeoutSec = 15,
        [string]$CacheDir = "{CACHE_PATH}"
    )

    $ErrorActionPreference = "Stop"
    $startTime = Get-Date

    # === 主源 ===
    try {
        $url = "{PRIMARY_API_URL}"
        Write-Verbose "[{DATA_NAME}] 主源请求: $url"
        $response = Invoke-RestMethod -Uri $url -TimeoutSec $TimeoutSec `
            -Headers @{"User-Agent" = "TieLv/2.0"} `
            -ErrorAction Stop

        # TODO: {PRIMARY_PARSE_LOGIC} — 解析响应，提取需要的字段

        $elapsed = (Get-Date) - $startTime
        Write-Verbose "[{DATA_NAME}] 主源成功 (${elapsed}s)"
        return $result
    }
    catch {
        Write-Warning "[{DATA_NAME}] 主源失败: $_"
    }

    # === 备源 ===
    try {
        $url = "{BACKUP_API_URL}"
        Write-Verbose "[{DATA_NAME}] 备源请求: $url"
        $response = Invoke-RestMethod -Uri $url -TimeoutSec $TimeoutSec `
            -Headers @{"User-Agent" = "TieLv/2.0"} `
            -ErrorAction Stop

        # TODO: {BACKUP_PARSE_LOGIC} — 解析备源响应

        $elapsed = (Get-Date) - $startTime
        Write-Verbose "[{DATA_NAME}] 备源成功 (${elapsed}s)"
        return $result
    }
    catch {
        Write-Warning "[{DATA_NAME}] 备源失败: $_"
    }

    # === 缓存兜底 ===
    $cacheFile = Join-Path $CacheDir "{CACHE_KEY_PREFIX}_$Symbol.json"
    if (Test-Path $cacheFile) {
        $cacheAge = (Get-Date) - (Get-Item $cacheFile).LastWriteTime
        Write-Warning "[{DATA_NAME}] 使用缓存 (年龄: ${cacheAge})"
        return Get-Content $cacheFile -Raw | ConvertFrom-Json
    }

    Write-Error "[{DATA_NAME}] 所有数据源不可用"
    return $null
}
```

**Python模板骨架**：

```python
"""
{DATA_NAME} 数据获取 — {DATA_DESCRIPTION}
主源 {PRIMARY} → 备源 {BACKUP} → 缓存[C]
"""
import json
import time
import requests
from pathlib import Path

def get_{DATA_NAME}(symbol: str, timeout: int = 15, cache_dir: str = "{CACHE_PATH}"):
    """获取 {DATA_DESCRIPTION}，按1+2架构降级"""
    start = time.time()

    # === 主源 ===
    try:
        url = "{PRIMARY_API_URL}"
        resp = requests.get(url, timeout=timeout,
                          headers={"User-Agent": "TieLv/2.0"})
        resp.raise_for_status()
        data = resp.json()
        # TODO: {PRIMARY_PARSE_LOGIC}
        elapsed = time.time() - start
        print(f"[{DATA_NAME}] 主源成功 ({elapsed:.1f}s)")
        return result
    except Exception as e:
        print(f"[{DATA_NAME}] 主源失败: {e}")

    # === 备源 ===
    try:
        url = "{BACKUP_API_URL}"
        resp = requests.get(url, timeout=timeout,
                          headers={"User-Agent": "TieLv/2.0"})
        resp.raise_for_status()
        data = resp.json()
        # TODO: {BACKUP_PARSE_LOGIC}
        elapsed = time.time() - start
        print(f"[{DATA_NAME}] 备源成功 ({elapsed:.1f}s)")
        return result
    except Exception as e:
        print(f"[{DATA_NAME}] 备源失败: {e}")

    # === 缓存兜底 ===
    cache_file = Path(cache_dir) / f"{CACHE_KEY_PREFIX}_{symbol}.json"
    if cache_file.exists():
        age = time.time() - cache_file.stat().st_mtime
        print(f"[{DATA_NAME}] 使用缓存 (年龄: {age:.0f}s)")
        return json.loads(cache_file.read_text(encoding='utf-8'))

    raise RuntimeError(f"[{DATA_NAME}] 所有数据源不可用")
```

### 2.2 JSON/CSV读写模板

**出现位置**：评分引擎输出、数据缓存、workflow记录、评估数据、模拟交易数据

**PS模板**：

```powershell
# === JSON 安全读写（带编码和锁） ===
function Read-JsonSafe {
    param([string]$Path, [int]$RetryCount = 3)
    if (-not (Test-Path $Path)) { return $null }
    for ($i = 0; $i -lt $RetryCount; $i++) {
        try {
            return Get-Content $Path -Raw -Encoding UTF8 | ConvertFrom-Json
        } catch {
            if ($i -eq $RetryCount - 1) { throw }
            Start-Sleep -Milliseconds (100 * [Math]::Pow(2, $i))
        }
    }
}

function Write-JsonSafe {
    param([string]$Path, $Data, [int]$Depth = 10)
    $json = $Data | ConvertTo-Json -Depth $Depth -Compress
    $tmpPath = "$Path.tmp"
    $json | Set-Content $tmpPath -Encoding UTF8 -NoNewline
    Move-Item $tmpPath $Path -Force  # 原子写入
}

# === CSV 追加写入 ===
function Add-CsvRow {
    param([string]$Path, [hashtable]$Row, [string[]]$Columns)
    $exists = Test-Path $Path
    if (-not $exists) {
        ($Columns -join ',') | Set-Content $Path -Encoding UTF8
    }
    $values = $Columns | ForEach-Object { $Row[$_] -replace ',', ';' }
    ($values -join ',') | Add-Content $Path -Encoding UTF8
}
```

**Python模板**：

```python
import json
import csv
import os
from pathlib import Path

def read_json_safe(path: str, retry: int = 3):
    """安全读取JSON，支持重试"""
    if not os.path.exists(path):
        return None
    for i in range(retry):
        try:
            with open(path, 'r', encoding='utf-8') as f:
                return json.load(f)
        except (json.JSONDecodeError, IOError):
            if i == retry - 1:
                raise
            time.sleep(0.1 * (2 ** i))

def write_json_safe(path: str, data, indent: int = None):
    """原子写入JSON（先写临时文件再重命名）"""
    tmp_path = path + '.tmp'
    with open(tmp_path, 'w', encoding='utf-8') as f:
        json.dump(data, f, ensure_ascii=False, indent=indent)
    os.replace(tmp_path, path)  # 原子操作

def append_csv_row(path: str, row: dict, columns: list[str]):
    """追加CSV行，自动创建表头"""
    file_exists = os.path.exists(path)
    with open(path, 'a', newline='', encoding='utf-8') as f:
        writer = csv.DictWriter(f, fieldnames=columns)
        if not file_exists:
            writer.writeheader()
        writer.writerow(row)
```

**Python模板**：

```python
import logging
from datetime import datetime
from pathlib import Path

def setup_logger(name: str, log_dir: str = "{LOG_DIRECTORY}") -> logging.Logger:
    """初始化日志器 — 统一格式+文件+控制台"""
    logger = logging.getLogger(name)
    logger.setLevel(logging.DEBUG)

    # 文件handler（按月轮转）
    month_str = datetime.now().strftime('%Y%m')
    log_file = Path(log_dir) / f"{name}_{month_str}.log"
    fh = logging.FileHandler(log_file, encoding='utf-8')
    fh.setLevel(logging.DEBUG)

    # 控制台handler
    ch = logging.StreamHandler()
    ch.setLevel(logging.INFO)

    formatter = logging.Formatter(
        '[%(asctime)s][%(levelname)s] %(message)s',
        datefmt='%Y-%m-%d %H:%M:%S'
    )
    fh.setFormatter(formatter)
    ch.setFormatter(formatter)

    logger.addHandler(fh)
    logger.addHandler(ch)
    return logger
```

### 2.4 错误处理包装模板

**出现位置**：所有涉及API调用和文件操作的脚本

**PS模板**：

```powershell
# === 错误处理包装函数 ===
function Invoke-WithRetry {
    param(
        [scriptblock]$ScriptBlock,
        [int]$MaxRetries = 3,
        [int[]]$RetryDelays = @(1, 3, 9),
        [string]$TaskName = "Unknown",
        [scriptblock]$OnFailure = $null
    )
    $attempt = 0
    $errors = @()
    while ($attempt -le $MaxRetries) {
        try {
            if ($attempt -gt 0) {
                $delay = if ($attempt -le $RetryDelays.Count) { $RetryDelays[$attempt-1] } else { $RetryDelays[-1] }
                Write-Verbose "[$TaskName] 第${attempt}次重试，等待${delay}s..."
                Start-Sleep -Seconds $delay
            }
            $result = & $ScriptBlock
            if ($attempt -gt 0) {
                Write-Verbose "[$TaskName] 第${attempt}次重试成功"
            }
            return $result
        }
        catch {
            $attempt++
            $errors += $_
            Write-Verbose "[$TaskName] 第${attempt}次失败: $_"
            if ($attempt -gt $MaxRetries) {
                Write-Error "[$TaskName] 已达最大重试次数($MaxRetries)，最终失败"
                if ($OnFailure) { & $OnFailure }
                throw
            }
        }
    }
}
```

**Python模板**：

```python
import time
import functools
from typing import Callable, Any

def retry_on_failure(
    max_retries: int = 3,
    delays: list[float] = [1.0, 3.0, 9.0],
    task_name: str = "Unknown"
):
    """装饰器：指数退避重试"""
    def decorator(func: Callable) -> Callable:
        @functools.wraps(func)
        def wrapper(*args, **kwargs) -> Any:
            last_error = None
            for attempt in range(max_retries + 1):
                try:
                    if attempt > 0:
                        delay = delays[min(attempt - 1, len(delays) - 1)]
                        print(f"[{task_name}] 第{attempt}次重试，等待{delay}s...")
                        time.sleep(delay)
                    result = func(*args, **kwargs)
                    if attempt > 0:
                        print(f"[{task_name}] 第{attempt}次重试成功")
                    return result
                except Exception as e:
                    last_error = e
                    print(f"[{task_name}] 第{attempt + 1}次失败: {e}")
            raise RuntimeError(
                f"[{task_name}] 已达最大重试次数({max_retries})"
            ) from last_error
        return wrapper
    return decorator
```

## 三、代码生成触发条件

### 3.1 自动识别规则

| 模式特征 | 出现次数阈值 | 动作 |
|:--------|:----------:|:-----|
| 相同的参数块（param block）结构 | >=3个脚本 | 提取为模板，参数化差异部分 |
| 相同的try-catch/finally模式 | >=3处 | 提取为错误处理模板 |
| 相同的日志初始化代码 | >=3个脚本 | 提取为日志模板，作为模块导入 |
| 相同的JSON读写+临时文件重命名 | >=3处 | 提取为通用IO工具模块 |
| 相同的HTML结构块 | >=3处 | 提取为HTML模板函数 |
| 相同的API URL构造逻辑 | >=5处 | 提取为API配置模块 |

### 3.2 当前项目模板化优先级

基于实际代码审查，建议按以下优先级模板化：

| 优先级 | 模式 | 当前重复次数 | 预计减少代码行数 |
|:-----:|:-----|:---------:|:--------------:|
| P0 | 日志初始化 | 8+ | ~200行 |
| P0 | JSON安全读写 | 10+ | ~150行 |
| P1 | API调用+降级 | 6+ | ~300行 |
| P1 | 错误重试包装 | 5+ | ~100行 |
| P2 | HTML报告卡片 | 3+ | ~80行 |
| P2 | CSV追加写入 | 3+ | ~40行 |

## 四、生成代码的命名规范

### 4.1 文件命名

```
{模块前缀}_{功能描述}.{扩展名}
├── PowerShell: Get-{Noun}.ps1 / New-{Noun}.ps1 / Invoke-{Verb}.ps1
├── Python: {verb}_{noun}.py (snake_case)
└── 模板文件: tpl_{类型}_{描述}.ps1 / tpl_{类型}_{描述}.py

示例:
  Get-StockQuote.ps1           ← 获取股票行情
  fetch_quote.py               ← Python版行情获取
  tpl_api_call.ps1             ← API调用模板
  tpl_error_handler.ps1        ← 错误处理模板
```

### 4.2 函数命名

```
PowerShell: {Verb}-{Noun} (PascalCase, 标准Posh动词)
  Get- / Set- / New- / Invoke- / Write- / Read- / ConvertTo-

Python: {verb}_{noun} (snake_case)
  get_ / set_ / fetch_ / build_ / generate_ / convert_to_

模板参数: {UPPER_CASE_IN_BRACES}
  {API_NAME} / {DATA_DESCRIPTION} / {PRIMARY_API_URL}
```

### 4.3 模板参数化约定

| 占位符格式 | 用途 | 示例 |
|:----------|:-----|:-----|
| `{UPPER_SNAKE}` | 必须替换的变量 | `{API_URL}` → 实际URL |
| `{DESCRIPTION}` | 描述性文本 | `{DATA_DESCRIPTION}` → "股票实时行情" |
| `// TODO: {LOGIC}` | 需要人工实现的逻辑 | `// TODO: {评分计算逻辑}` |

## 五、模板维护和版本管理

### 5.1 模板存储

```
代码文件/templates/
├── ps/
│   ├── tpl_api_call.ps1          ← API调用封装
│   ├── tpl_json_io.ps1           ← JSON安全读写
│   ├── tpl_logger.ps1            ← 日志初始化
│   ├── tpl_error_handler.ps1     ← 错误处理
│   ├── tpl_html_card.ps1         ← HTML卡片
│   └── tpl_script_skeleton.ps1   ← 脚本骨架
├── py/
│   ├── tpl_api_call.py
│   ├── tpl_json_io.py
│   ├── tpl_logger.py
│   ├── tpl_error_handler.py
│   └── tpl_script_skeleton.py
└── README.md                     ← 模板使用说明
```

### 5.2 模板版本号

每个模板独立版本，格式：`v{MAJOR}.{MINOR}`

```
v1.0 — 初始创建
v1.1 — 增加参数/修复bug
v2.0 — 架构变更（不向后兼容）
```

### 5.3 使用模板生成代码的流程

```
1. 识别模式 → 确认对应模板存在
2. 复制模板 → 粘贴到目标脚本
3. 替换占位符 → {API_NAME}等替换为实际值
4. 填充逻辑 → TODO标记处插入业务代码
5. 移除模板注释 → 删除生成时间、模板版本等元信息
6. 运行 新安审查 → 确保生成代码质量
```

### 5.4 模板更新传播

当模板更新时：
```
模板 v1.0 → v1.1
    ↓
1. 记录CHANGELOG：tpl_api_call.ps1 v1.1 — 增加超时重试逻辑
2. 列出所有使用该模板的脚本
3. 评估是否需要手动更新已生成代码（仅重大变更时）
4. 新创建代码自动使用新模板
```

## 六、模板使用的反模式

| 反模式 | 问题 | 正确做法 |
|:-------|:-----|:--------|
| 复制模板但不替换占位符 | 生成的代码无法运行 | 每个占位符必须替换 |
| 模板中包含具体业务值 | 模板不再通用 | 具体值通过参数传入 |
| 模板过于复杂(>200行) | 模板变框架，学习成本高 | 模板控制在50-150行 |
| 每个微调都新建模板 | 模板爆炸 | 用参数覆盖差异，而非新建模板 |
| 模板覆盖核心逻辑 | 生成的代码都是骨架 | TODO标记保留给开发者填充 |
