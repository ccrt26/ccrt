# 测试数据工厂 — 新安质量工程师

> 版本 v1.0 | 生效日期 2026-05-24
> 用途：可复用的测试数据生成模式——模拟行情、模拟财务数据、边界用例数据

---

## 一、设计原则

1. **确定性**：同样种子生成同样数据，可复现
2. **隔离性**：测试数据不污染生产缓存
3. **覆盖性**：正常+边界+异常三类数据
4. **脱敏性**：使用虚构股票代码(600000~609999)，不与真实股票混淆

## 二、模拟行情数据

### 2.1 正常行情

```python
# test_data_factory.py — 生成模拟日线数据
import numpy as np
import pandas as pd

def generate_ohlcv(days=250, seed=42, start_price=10.0, volatility=0.02):
    """生成模拟OHLCV日线数据"""
    np.random.seed(seed)
    dates = pd.date_range(end=pd.Timestamp.now(), periods=days, freq='B')
    
    # 随机游走价格
    returns = np.random.normal(0.0005, volatility, days)
    close = start_price * np.exp(np.cumsum(returns))
    
    # 日间波动
    daily_range = close * volatility * np.random.uniform(0.5, 2.0, days)
    high = close + daily_range * np.random.uniform(0, 0.5, days)
    low = close - daily_range * np.random.uniform(0, 0.5, days)
    open_price = close - daily_range * np.random.uniform(-0.3, 0.3, days)
    
    # 成交量(对数正态)
    volume = np.random.lognormal(mean=15, sigma=0.8, size=days).astype(int)
    
    return pd.DataFrame({
        'date': dates,
        'open': np.round(open_price, 2),
        'high': np.round(high, 2),
        'low': np.round(low, 2),
        'close': np.round(close, 2),
        'volume': volume
    })
```

## 三、模拟财务数据

```python
def generate_financials(quarters=20, seed=42):
    """生成模拟财务季报数据"""
    np.random.seed(seed)
    
    base_eps = 0.5
    base_revenue = 1e9  # 10亿
    base_roe = 0.15
    
    data = []
    for q in range(quarters):
        eps = base_eps * (1 + np.random.uniform(-0.3, 0.3))
        revenue = base_revenue * (1 + np.random.uniform(-0.1, 0.2))
        roe = base_roe * (1 + np.random.uniform(-0.2, 0.2))
        data.append({
            'quarter': q,
            'eps': round(eps, 4),
            'revenue': round(revenue, 2),
            'roe': round(roe, 4),
            'assets_liability_ratio': round(np.random.uniform(0.3, 0.7), 4)
        })
    
    return pd.DataFrame(data)
```

### 边界财务数据

| 场景 | 参数设置 | 用途 |
|:-----|:--------|:-----|
| 亏损(EPS<0) | EPS=-0.5 | 测试PE负数处理 |
| 微利(EPS≈0) | EPS=0.001 | 测试PE极大值 |
| 净资产为负 | 资产负债率>100% | 测试PB负值 |
| 新上市(仅1季报) | quarters=1 | 测试数据不足 |
| 财务数据跳过 | quarters之间缺失 | 测试缺报处理 |

## 五、测试场景组合矩阵

| 测试场景 | 行情数据 | 财务数据 | 预期行为 |
|:--------|:--------|:--------|:--------|
| 正常评分 | 正常OHLCV | 正常财务 | 完整六维评分输出 |
| ST否决 | 正常OHLCV | 正常财务 + ST标记 | 触发ST否决 |
| PE否决 | 极高价格 | 极低EPS | 触发PE否决 |
| 换手否决 | 极高换手 | 正常财务 | 触发换手率否决 |
| 数据缺失 | 缺失K线 | 缺失财务 | 标记"数据不可获取" |
| 全0数据 | 全0 | 全0 | 不崩溃，标记异常 |
| 北向无数据 | 正常+无北向 | 正常 | 正常评分，资金因子标N/A |
