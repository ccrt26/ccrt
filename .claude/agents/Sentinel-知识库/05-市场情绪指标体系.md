## 一、两市成交额 —— 情绪的"心脏"

成交额是市场情绪最直接、最真实的温度计。它不能造假，反映了真金白银的参与程度。

### 1.1 成交额分档阈值（基于2025年A股数据）

```
情绪冰点（极度悲观/无人问津）：
  < 5000-6000亿（两市合计）
  特征：多数散户已离场或躺平，机构也无心交易
  历史出现时机：长假前后、市场连续大跌后、熊市末期
  → Sentinel建议：防御仓位，现金为王，等待放量反转信号

低迷区：
  6000亿 - 8000亿
  特征：交投清淡，仅少量活跃资金在炒作
  赚钱效应：几乎没有，存量博弈
  → Sentinel建议：低仓位，仅关注高确定性品种

正常活跃（基准健康区）：
  8000亿 - 1.2万亿
  特征：市场正常运行，有热点但不过热
  赚钱效应：结构性机会，非普涨
  → Sentinel建议：正常仓位，按策略执行

持续赚钱效应（乐观升温）：
  1.2万亿 - 1.5万亿
  特征：场外资金开始入场，热点扩散
  赚钱效应：明显的板块轮动，多个主线并进
  → Sentinel建议：适当积极，关注主线龙头

情绪过热（警惕区）：
  连续3日 > 1.5万亿
  特征：全民炒股氛围，新股民跑步入场
  历史规律：A股天量之后多出现阶段性顶部
  → Sentinel建议：边打边撤，逐步减仓高位品种
```

### 1.2 成交额趋势判断

**成交额变化率的信号**：

```
放量信号（与前5日均量对比）：
  放量 > 30% + 指数上涨 → 趋势确认，跟随做多
  放量 > 30% + 指数滞涨 → 多空分歧加大，警惕变盘
  放量 > 50% + 指数不涨 → "天量不涨，必有回调"

缩量信号（与前5日均量对比）：
  缩量 < -20% + 指数横盘 → 蓄势，等待选择方向
  缩量 < -30% + 指数下跌 → 下跌动能衰减，接近短期底部
  缩量 < -40% + 指数不跌 → "地量见地价"，反弹概率大
```

**周度成交额趋势判断**（比日度更可靠）：

```
连续2周成交额环比上升 → 增量资金入场确认 → 积极信号
连续2周成交额环比下降 → 资金离场确认 → 防御信号
单周异常放量（与4周均值比 > 50%）→ 情绪脉冲，需警惕后续回落
```

### 1.3 成交额的结构判断

```
成交额集中度：
  成交额前100只股票占总成交额比例 > 30% → 抱团行情，中小盘边缘化
  成交额前100只股票占总成交额比例 < 18% → 全面行情，小票活跃

板块成交额占比：
  某板块成交额占比突然超过正常值2倍以上 → 拥挤度过高，警惕退潮
  关注TMT板块（科技+传媒+通信）成交额占比（A股情绪放大器）：
    正常：15-25%
    过热：>30% → TMT拥挤度过高
```

## 二、涨跌家数比 —— 市场的"宽度"

涨跌家数反映市场行情的覆盖面——指数涨可能是少数权重股拉升（"赚指数不赚钱"），涨跌家数比才能看真实赚钱效应。

### 2.1 涨跌家数比阈值

```
极度乐观：
  上涨家数 > 4000家（两市5000+股票）→ 普涨行情，市场极度亢奋
  上涨家数占比 > 80% → 物极必反信号，次日分化概率大

正常偏多：
  上涨家数 2500-3500家 → 健康的多头行情
  涨跌比 1.5:1 至 3:1 → 赚钱效应明显

中性平衡：
  上涨家数 2000-3000家 → 结构性行情，精选个股

正常偏空：
  上涨家数 1000-2000家 → 防御行情，热点少

极度悲观：
  上涨家数 < 800家 → 普跌行情，恐慌蔓延
  上涨家数占比 < 15% → 物极必反信号，次日反弹概率大
```

### 2.2 AD Line（涨跌家数累计线）

```
AD Line = 累计(每日上涨家数 - 每日下跌家数)

AD Line 与指数的背离判断：
  指数创新高 + AD Line 未创新高 → 上涨动能减弱，背离看跌信号
  指数创新低 + AD Line 未创新低 → 下跌动能减弱，背离看涨信号
  AD Line 先于指数突破前高 → 市场宽度改善，上涨可期
```

### 2.3 指数与个股的背离

```
沪深300涨 + 中证1000跌 → "漂亮50"行情，仅权重股涨 → 赚钱效应差，多数人是亏的
沪深300跌 + 中证1000涨 → 权重压制、小票活跃 → 题材投机氛围重
此背离持续 > 3天 → 市场风格撕裂，警惕单方面修正
```

## 三、涨停/跌停分析 —— 情绪的"温度计"

### 3.1 涨停家数分档

基于2025年A股市场数据，涨停家数的阈值如下：

```
情绪极度低迷（冰点）：
  涨停家数 < 30家（剔除ST和新股）
  特征：市场几乎无人敢追涨停
  连板高度：1-2板
  → 市场处于恐慌/绝望阶段

情绪低迷：
  涨停家数 30-60家
  特征：游资保守，题材持续性极差
  连板高度：2-3板
  → 市场观望为主

正常活跃：
  涨停家数 60-90家
  特征：游资正常交易，有主线但不够强
  连板高度：通常5-7板
  → 市场正常，策略主导

情绪活跃（赚钱效应好）：
  涨停家数 90-150家
  特征：主线明确，多家连板，概念扩散
  连板高度：7-10板（出现妖股）
  → 积极交易窗口

情绪高潮（警惕）：
  涨停家数 > 150家
  特征：连板股票扎堆，各种概念乱炒
  连板高度：10板+
  → 越热越要警惕退潮

情绪过热（极度风险）：
  涨停家数 > 200家 + 连板高度15板+ 
  特征：百股涨停、全民打板
  → 历史经验：这是短期见顶的强烈信号
```

### 3.2 炸板率

```
炸板率 = 当日触及涨停但未能封死的股票数 / 当日触及涨停的股票总数 × 100%

炸板率阈值：
  < 20% → 封板意愿极强，市场情绪亢奋（情绪高潮特征，警惕过热）
  20-30% → 正常水平，多空博弈健康
  30-40% → 封板意愿偏弱，追涨风险上升
  > 40% → 情绪急剧转弱，高标股分歧严重（"炸板潮"）
  > 50% → 恐慌信号，几乎所有打板资金都在撤退
```

**关键预警信号**：
- 早盘涨停+午盘开板+收盘未回封（"天地板"） → 最恶性的情绪反转信号
- 高标股（连板高度最高那几只）突然炸板 → 龙头倒了，跟风股会更惨
- 炸板率突然从前一日的20%飙升到40%+ → 理性资金在"抢跑"，情绪急转直下

### 3.3 连板高度与梯队

```
连板高度 = 当前市场最高连续涨停板数（不含ST/新股）

梯队健康度判断：
  7板（总龙头）+ 5板（次高）+ 3板（中位）+ 2板（首板晋级）
  → 梯队完整，赚钱效应逐级传导 → 强势市场

  仅2-3板（无高位股）
  → 题材一日游，无持续性 → 弱势市场

  龙头7板但下面只有首板（梯队断层）
  → 独龙行情，后续空间有限 → 谨慎

  高标股突然跌停（"A杀"）
  → 情绪急转直下，最凶狠的退潮方式 → 立即减仓题材股
```

### 3.4 跌停家数 —— 恐慌的另一面

```
跌停 < 5家 → 市场正常，无恐慌
跌停 5-10家 → 局部风险释放，关注原因
跌停 10-30家 → 市场出现恐慌情绪，如果集中在某一板块=板块踩踏
跌停 30-50家 → 大面积恐慌，市场系统性风险上升
跌停 > 50家 → 极端恐慌，历史级别，通常伴随重大利空

跌停类型：
  "一字跌停" → 无法出逃，最危险 → 次日大概率继续跌停
  "放量跌停" → 有人接盘 → 恐慌释放中，关注次日是否企稳
  "尾盘跌停" → 理性资金的最后一击 → 次日低开概率大
```

## 四、北向资金（陆股通）

### 4.1 北向资金的核心观察维度

```
北向资金 = 通过沪港通/深港通买入A股的境外资金
价格：净买入金额（人民币计）

日频判断：
  单日净流入 > 50亿 → 外资积极看多 → 当日市场偏乐观
  单日净流出 > 50亿 → 外资避险/兑现 → 当日市场偏谨慎
  单日净流入/流出在 ±20亿以内 → 外资观望 → 无方向信号

连续趋势判断（比单日更重要）：
  连续3日净流入且单日 > 50亿 → 外资持续加仓信号 → 乐观
  连续5日以上净流入 → 外资中期看好A股 → 市场底部确认的概率高
  连续3日净流出 → 外资持续撤退 → 警惕

周频判断：
  单周净流入 > 300亿 → 外资大幅流入，情绪高潮
  单周净流入 100-300亿 → 外资积极流入 → 有利市场
  单周净流入 < 50亿或净流出 → 外资态度谨慎/负面

月频判断：
  月净流入 > 500亿 → 外资大举进入 → 对当月行情强劲支撑
  月净流出 > 300亿 → 外资系统性撤退 → 警惕中期调整
```

### 4.2 北向资金的结构分析

```
北向资金买什么：
  沪深300成分股（大盘蓝筹）＝ 北向资金传统偏好 → 茅台/宁德/美的/恒瑞等
  配置盘 vs 交易盘：
    配置盘（长期持有，高频反复进出频率低）→ 稳定信号
    交易盘（短线交易，快进快出）→ 噪音较多，不具长期指引
  如果北向大幅流入但仅流入少数股票 → 不是全面看好，仅是个股逻辑

北向资金卖什么：
  重仓股被持续减持 → 外资对该股票/行业估值不认可
  北向持续卖出 + 该板块下跌 → 外资助推板块下行压力
```

### 4.3 北向与南向资金的对跷跷板

```
北向（外资买A股）vs 南向（内地资金买港股）
  北向流入 + 南向流出 → 外资看好A股，内地资金从港股回流 → A股强于港股
  北向流出 + 南向流入 → 外资撤退，内地资金南下"抄底"港股 → A股弱于港股
  双流入 → 两个市场都有增量资金 → 整体乐观
  双流出 → 系统性资金流出中国权益市场 → 双向承压
```

## 五、两融余额

### 5.1 融资余额

```
融资余额 = 投资者通过融资融券借来的资金，用于买入股票的总金额
俗称"借钱炒股"的规模，是市场风险偏好的直接映射。

融资余额变化趋势：
  融资余额持续上升（周度）→ 散户/游资加杠杆 → 风险偏好提升
  融资余额持续下降 → 散户/游资去杠杆 → 风险偏好下降
  融资余额快速上升（单周 > 5%）→ 杠杆加速入场 → 警惕过热的回调风险
  融资余额快速下降（单周 < -5%）→ 杠杆恐慌出逃 → 短期有反弹需求

融资余额占流通市值比值：
  A股正常区间：2.0-2.5%（历史均值）
  > 2.5% → 杠杆水平偏高，警惕去杠杆风险
  < 1.8% → 杠杆水平偏低，市场处于低位
```

### 5.2 融券余额

```
融券余额 = 借股票卖出（做空）的规模
融券余额上升 → 做空力量增强 → 对标的构成压力
融券余额因制度变化而整体偏低（2024年融券新规限制后）

融券余额占两融比例：
  正常：<5%
  偏高空：>8%（历史上很少见）
```

### 5.3 融资买入额占比

```
融资买入额占两市成交额比例：
  < 7% → 杠杆资金参与度偏低，市场偏冷
  7-10% → 正常水平
  10-12% → 杠杆资金活跃，情绪升温
  > 12% → 杠杆资金过热，警惕回调
  > 15% → 极度亢奋，历史顶部区域常见
```

## 六、其他情绪指标

### 6.1 恐惧贪婪指数（0-100分位）

```
综合指标，融合波动率、动量、成交量、资金流等多维度

分位含义：
  0-25（极度恐惧）→ 市场过度悲观，往往是买入时机
  25-45（恐惧）→ 市场偏弱，观望为主
  45-55（中性）→ 市场不悲不喜，按策略执行
  55-75（贪婪）→ 市场乐观，趋势向好但需注意风险积累
  75-100（极度贪婪）→ 物极必反，历史顶部区域

使用要点：
  - 极度恐惧（<10）是买入信号，但抄底成功需要配合成交额放大确认反弹
  - 极度贪婪（>90）是卖出信号，但泡沫阶段可能持续1-2周甚至更长
  - 恐惧贪婪指数更适合用于判断"反转区域"而非精确的择时
```

### 6.2 新股破发率

```
新股上市首日破发（收盘价 < 发行价）的比例：
  破发率 < 10% → 打新情绪正常
  破发率 10-30% → 新股IPO定价偏高或市场情绪转弱
  破发率 > 30% → 市场情绪低迷，IPO实质性暂停的前兆
  破发率 > 50% → 极度低迷，历史上为市场底部区域特征

注意：注册制后新股破发成为常态，不能用零破发作为健康标准
    判断重点不是"有没有破发"而是"破发率是否突然大幅上升"
```

### 6.3 换手率

```
全市场日均换手率（流通市值加权）：
  < 2% → 市场冷清，筹码沉淀，交易不活跃
  2-5% → 正常区间，交易活跃但不狂热
  5-8% → 市场偏热，短线资金频繁进出，投机氛围重
  > 8% → 市场过热，筹码极度松动，警惕变盘

行业换手率对比：
  某行业换手率是该行业过去1年均值的2倍以上 → 该行业热度异常，关注持续性和退潮风险
```

### 6.4 新基金发行热度

```
权益类基金发行规模（月度）：
  单月 < 500亿 → 发行寒冬，市场底部区域特征 → 反向指标（低点加仓）
  单月 500-1500亿 → 正常
  单月 1500-3000亿 → 基金发行火爆，市场进入高潮期
  单月 > 3000亿 → 情绪过热，历史上多次对应市场顶部

爆款基金（首日售罄/配售）：
  明星基金经理的爆款基金出现 → 情绪高点信号
  连续多只爆款→"全民买基"氛围 → 中期顶部风险加大
```

### 6.5 散户情绪指标

```
百度指数（"炒股"/"开户"/"股票" 等关键词搜索量）：
  搜索量较正常水平暴增 > 2倍 → 散户大量关注 → 情绪过热信号
  搜索量低迷 → 散户不关注股市 → 底部信号

新增投资者开户数（中登公司，月度公布）：
  月开户 > 200万户 → 跑步入场 → 警惕过热
  月开户 < 80万户 → 市场冷清 → 底部特征

银证转账（证券交易结算资金银证转账）：
  连续2周净转入 → 散户资金入场 → 积极信号
  连续2周净转出 → 散户资金离场 → 防御信号
```

## 七、情绪五阶段定位方法

### 7.1 五阶段框架

A股市场情绪呈现周期性的五阶段波动。每个阶段有独特的指标组合特征。

```
极端悲观 → 情绪修复 → 乐观升温 → 极端狂热 → 情绪回落 → (回到极端悲观)
```

### 7.2 各阶段指标组合特征

#### 阶段一：极端悲观

| 指标 | 特征值 | 说明 |
|:-----|:------|:-----|
| 成交额 | < 6000亿 | 无人交易 |
| 涨停家数 | < 30家 | 无人敢追涨 |
| 涨跌比 | < 0.3 | 普跌 |
| 恐惧贪婪 | < 25 | 极度恐惧 |
| 新股破发率 | > 50% | 打新都亏钱 |
| 换手率 | < 2% | 筹码沉淀 |
| 两融余额 | 持续下降 | 杠杆不断出清 |
| 新基金发行 | 冰点 | 没人买基金 |
| 北向资金 | 持续流出/转为流入 | 外资在流出末端开始转向 |

**Sentinel判断**：满足上述6项以上 → 确认极端悲观区，需密切关注反转信号（放量+北向回流+涨停家数放大）。

#### 阶段二：情绪修复

| 指标 | 特征值 |
|:-----|:------|
| 成交额 | 6000-9000亿，逐步回升 |
| 涨停家数 | 40-80家，逐步增加 |
| 涨跌比 | 1:1 至 2:1 |
| 恐惧贪婪 | 25-45，逐步回升 |
| 北向资金 | 转向流入/波动变小 |
| 连板高度 | 3-5板，开始出现 |

**Sentinel判断**：成交额从冰点回升+涨停家数放大 → 情绪在修复。这个阶段是最好的买入窗口（"别人恐惧我贪婪"的理论执行时机）。

#### 阶段三：乐观升温

| 指标 | 特征值 |
|:-----|:------|
| 成交额 | 1.0-1.5万亿 |
| 涨停家数 | 90-200家 |
| 连板高度 | 7-12板，妖股横行 |
| 涨跌比 | 2:1 至 4:1 |
| 恐惧贪婪 | 55-75 |
| 两融余额 | 加速攀升 |

**Sentinel判断**：这是赚钱效应最好的阶段，多数策略都可以赚钱。但需要开始关注"从乐观到狂热"的转变信号。

#### 阶段四：极端狂热

| 指标 | 特征值 |
|:-----|:------|
| 成交额 | 连续 > 1.5万亿 |
| 涨停家数 | > 200家 |
| 炸板率 | < 15%（非健康的低） |
| 恐惧贪婪 | > 85（极度贪婪） |
| 新基金 | 爆款频出 |
| 散户 | 跑步入场 |
| 两融 | 突破历史高位 |

**Sentinel判断**：满足上述5项+ → 确认极端狂热区。警示"物极必反"，市场随时可能出现剧烈调整。这是减仓窗口。

#### 阶段五：情绪回落

| 指标 | 特征值 |
|:-----|:------|
| 成交额 | 从高点回落 > 30% |
| 炸板率 | > 40%（突然飙升） |
| 高标股 | A杀跌停 |
| 涨停家数 | 从200+骤降至<100 |
| 北向资金 | 转为流出 |
| 恐惧贪婪 | 快速回落 > 15个点 |

**Sentinel判断**：情绪回落的标志性事件——高标股炸板/天地板+成交量骤降。这是最快的杀跌阶段，应以保护本金为首要目标。持续1-3周。

### 7.3 五阶段定位快速检查表

```
当前是哪一阶段？逐一检查：

[ ] 成交额在哪个区间？（冰点/低/正常/活跃/过热）
[ ] 涨停家数 + 连板高度？（低/中/高/过热）
[ ] 炸板率趋势？（平稳/上升/飙升）
[ ] 北向连续方向？（流入/流出/无方向）
[ ] 恐惧贪婪指数分位？（恐惧/中性/贪婪）
[ ] 两融余额趋势？（升/降/平）
[ ] 新股破发率？（低/正常/高）
[ ] 换手率区间？（冷/正常/热）

匹配各阶段特征数最多的即为当前阶段。
```

## 八、多维交叉验证原则

单一情绪指标可能发出虚假信号，Sentinel必须至少3个指标同向才做判断。

### 8.1 情绪顶部确认的三信号组合

```
至少满足以下2-3组才算顶部确认：

[信号组1 — 量能] 成交额连续3日萎缩 > 20%（从高点回落）
[信号组2 — 涨停] 炸板率飙升 > 40% + 高标股炸板
[信号组3 — 外资] 北向资金连续3日净流出
[信号组4 — 宽度] 涨跌家数比持续恶化（上涨家数 < 40%）

如果4组信号同时出现 → 顶部确认的概率 > 80%，立即建议减仓
```

### 8.2 情绪底部确认的三信号组合

```
至少满足以下2-3组才算底部确认：

[信号组1 — 缩量] 成交量萎缩到"地量"（< 6000亿）+ 随后放量
[信号组2 — 外资] 北向资金连续3日净流入 + 单日 > 50亿
[信号组3 — 宽度] 涨停家数放大 + 炸板率 < 25%
[信号组4 — 情绪] 恐惧贪婪指数 < 20 + 随后回升

如果4组信号同时出现 → 底部确认的概率 > 70%，建议逐步加仓
```

### 8.3 情绪与大盘的交叉验证

```
情绪指标矛盾时（如成交额放大但涨跌比下降），以涨跌比为准（它反映真实赚钱效应）
情绪与指数背离时（如指数创新高但情绪指标未跟上），以情绪为准（先行信号）
情绪指标明显滞后时（如指数已跌了很多但恐惧贪婪还在>50），说明市场仍未恐慌 → 底部尚早
```
