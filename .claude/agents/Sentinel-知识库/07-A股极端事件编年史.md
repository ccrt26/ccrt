## 一、为什么需要极端事件知识

### 1.1 正常框架的边界

正常分析框架的前提：市场在均值附近波动，历史统计规律有效。但A股30年历史中，极端事件不是边缘情况——它们是塑造市场结构的核心事件。

当以下任意条件触发时，正常分析框架暂缓，启用极端事件模式（白皮书v3.0 §4.5）：
- 沪深300单日跌幅>5%
- 全市场跌停家数>500
- 北向资金单日净流出>100亿
- 重大政策突变（行业一刀切、监管风暴）
- 国际地缘政治黑天鹅

### 1.2 模式匹配的价值

新危机很少是全新的。更常见的是旧模式的变体。Sentinel的任务是：当市场异常时，从历史中找出最相似的危机模式，提供"这次像哪次"的判断。

## 二、七次关键危机

### 2.1 2015股灾（2015.06-08）

| 维度 | 内容 |
|:-----|:-----|
| **时间线** | 6/12 上证5178见顶 → 6/15-7/8 第一波下跌-32% → 7/9-7/23 国家队救市反弹+15% → 7/24-8/26 第二波下跌-28% |
| **触发因素** | 场外配资清理（HOMS系统切断）、杠杆踩踏 |
| **关键指标** | 两融余额从2.27万亿→1.43万亿(-37%)；日成交额从2.4万亿萎缩至0.8万亿 |
| **政策响应** | 降息降准(6/27)、证金公司入场(7/6)、限制减持(7/8)、公安部进驻查处恶意做空(7/9) |
| **恢复路径** | 2015.09-12 反弹+25%，但2016.01熔断打断恢复 |
| **先行指标** | 两融余额增速见顶于5月、创业板换手率连续>10% |
| **关键教训** | 杠杆驱动的牛市一旦去杠杆，流动性消失速度远超预期 |

### 2.2 2016熔断（2016.01）

| 维度 | 内容 |
|:-----|:-----|
| **时间线** | 1/4 熔断(跌5%触发15分钟暂停→恢复后跌7%全天休市) → 1/7 再次熔断 → 1/8 熔断机制暂停 |
| **触发因素** | 熔断机制本身的磁吸效应 + 减持解禁恐慌 + 人民币贬值 |
| **关键指标** | 4个交易日沪深300跌-25%；1/7全天交易仅15分钟 |
| **政策响应** | 1/7当晚宣布暂停熔断机制、1/8大股东减持新规 |
| **恢复路径** | 1月底见底，3个月回到熔断前水平 |
| **先行指标** | 熔断机制本身的"磁吸效应"——跌停→熔断预期→加速抛售 |
| **关键教训** | 制度设计缺陷 + 市场恐慌 = 极端速度的崩跌。流动性可以瞬间消失 |

### 2.3 2018贸易战（2018.03-10）

| 维度 | 内容 |
|:-----|:-----|
| **时间线** | 3/22 特朗普签署对华301调查 → 4/3 美公布500亿加税清单 → 6/15 美宣布对500亿加征25% → 7/6 第一轮加征生效 → 9/17 美宣布对2000亿加征10% → 10月市场见底 |
| **触发因素** | 中美贸易摩擦持续升级、汇率贬值、信用紧缩 |
| **关键指标** | 沪深300全年-25%；人民币从6.3→6.97(-10.6%)；民营企业信用利差飙升 |
| **政策响应** | 央行多次定向降准、10/19 刘鹤讲话稳市场、民企纾困政策 |
| **恢复路径** | 2019.01-04 反弹+36%（贸易谈判缓和 + 超跌反弹 + 政策宽松） |
| **先行指标** | 301调查启动(2017.08)、人民币贬值加速、北向资金持续流出 |
| **关键教训** | 贸易战对制造业+科技股打击最大。政策响应有滞后(6个月)，但最终效果显著 |

### 2.4 2020疫情（2020.01-03）

| 维度 | 内容 |
|:-----|:-----|
| **时间线** | 1/23 武汉封城 → 2/3 节后首日沪深300跌-7.9%(3100只跌停) → 2/4起持续反弹 → 3月全球疫情爆发二次探底 |
| **触发因素** | 新冠疫情突然爆发 + 春节长假期间恐慌积累 |
| **关键指标** | 2/3单日跌停3100只(占比80%)；北向资金单日净流出182亿 |
| **政策响应** | 央行1.2万亿逆回购、3000亿专项再贷款、减税降费 |
| **恢复路径** | 2/4起连涨14天→回到节前水平。3月受全球拖累二次探底 |
| **先行指标** | 疫情数据（新增确诊/疑似）、春运人员流动数据 |
| **关键教训** | 一次性冲击+政策强力响应=V型恢复。但全球传导可能导致二次探底 |

### 2.5 2021教育双减（2021.07）

| 维度 | 内容 |
|:-----|:-----|
| **时间线** | 7/23 中共中央办公厅发文 → 7/26 教育股暴跌(新东方-60%,好未来-70%) → 恐慌扩散至中概股+港股科技 |
| **触发因素** | 政策一刀切——学科类培训机构一律不得上市融资 |
| **关键指标** | 教育ETF单周-40%；中概互联ETF单周-20%；恒生科技指数7月-18% |
| **政策响应** | 政策本身即为冲击源。后续有安抚性信号(9月北交所设立) |
| **恢复路径** | 教育行业未恢复。科技股12个月后部分恢复 |
| **先行指标** | 2021.03 两会期间已有"规范校外培训"提案、2021.05 深改委会议 |
| **关键教训** | 政策风险是中国资产最大的非对称风险——上涨有限、下跌无限。跨行业恐慌传染力极强 |

### 2.6 2022上海封城（2022.03-04）

| 维度 | 内容 |
|:-----|:-----|
| **时间线** | 3/28 上海分批封控 → 4月全城静态管理 → 4/25 上证跌破3000 → 5月逐步解封 |
| **触发因素** | 奥密克戎疫情+严格清零政策+供应链中断恐慌 |
| **关键指标** | 上证从3500→2863(-18%)；北向资金3月净流出450亿 |
| **政策响应** | 4/29 政治局会议"全力稳增长"、5/25 全国稳住经济大盘会议 |
| **恢复路径** | 5-6月快速反弹至3400(+19%) |
| **先行指标** | 上海日新增确诊数据、地铁客流数据、港口吞吐量 |
| **关键教训** | 供应链中断恐慌具有放大效应。政策方向转变(清零→稳增长)是市场拐点 |

### 2.7 2024雪球敲入（2024.01-02）

| 维度 | 内容 |
|:-----|:-----|
| **时间线** | 1月中旬 中证500/1000快速下跌 → 雪球产品集中敲入 → 1/22 中证1000单日-5.8% → 2/5 上证2635见底 → 反弹开始 |
| **触发因素** | 中小盘快速下跌触发雪球产品集中敲入(估计2000-3000亿规模)→期货多头被迫平仓→现货跟跌 |
| **关键指标** | 中证1000从5800→4400(-24%)；两融余额快速下降；雪球密集敲入区(中证500:4800-5200,中证1000:5200-5600) |
| **政策响应** | 汇金增持ETF、限制DMA杠杆、限制融券卖出 |
| **恢复路径** | 2/5起中证1000反弹+30%至5800 |
| **先行指标** | 中证500/1000接近雪球密集区时成交量异常放大、IC/IM期货贴水急剧扩大 |
| **关键教训** | 结构化产品在极端行情下形成"负Gamma"——越跌越要卖。衍生品市场对现货的反馈循环可以制造快速崩跌 |

## 三、危机模式分类学

### 3.1 四大危机类型

| 类型 | 特征 | 历史案例 | 恢复模式 | 持续时间 |
|:-----|:-----|:--------|:--------|:-------:|
| **流动性危机** | 杠杆踩踏、买卖失衡 | 2015股灾、2016熔断 | 政策注入流动性后V型 | 1-3个月 |
| **外部冲击** | 国际事件传导 | 2018贸易战、2020疫情 | 冲击源消退后恢复 | 1-7个月 |
| **政策突变** | 监管政策一刀切 | 2021双减 | 行业不可逆，市场可恢复 | 行业永久/市场3-12月 |
| **结构性问题** | 产品/制度缺陷引爆 | 2024雪球敲入 | 政策干预+市场出清 | 1-2个月 |

### 3.2 危机模式匹配清单

当市场出现异常时，按此清单判断模式：

```
1. 是否伴随成交量极端放大(>2万亿)或萎缩(<5000亿)？
   → 如果是放大：更可能是流动性危机
   → 如果是萎缩：更可能是持续性熊市

2. 是否有明确的政策触发因素？
   → 有：判断政策是可逆(流动性/交易规则调整)还是不可逆(行业禁令)
   → 无：更可能是外部冲击或市场自发调整

3. 跌停家数是否>500？
   → 是：流动性危机级别，参考2015/2016模式
   → 否：结构性调整，参考2018模式

4. 北向资金行为？
   → 大幅流出：外部冲击模式，外资重仓股额外承压
   → 正常/流入：国内因素主导

5. 是否有结构性产品/杠杆的集中暴露？
   → 有：雪球/DMA/两融 → 可能触发负反馈循环
   → 无：标准调整
```

## 四、先行指标体系

### 4.1 跨危机共通的先行指标

| 指标 | 正常区间 | 预警阈值 | 领先时间 | 监测来源 |
|:-----|:--------|:--------|:-------:|:--------|
| 两融余额变化率 | -5%~+5%(月) | 月增>15%或月降>10% | 1-3个月 | 中证金融公司 |
| 北向资金累计流向 | ±50亿(周) | 连续2周净流出>100亿/周 | 1-4周 | 沪深股通 |
| 全市场成交量 | 8000-12000亿 | 连续3日<5000亿或>2万亿 | 即时 | 沪深交易所 |
| 涨停/跌停比 | 1.0-3.0 | <0.5(跌停数>涨停数2倍) | 即时 | 全市场统计 |
| 期现基差 | ±0.5% | 贴水>2%(恐慌信号) | 即时 | 股指期货 |
| 50ETF期权隐含波动率 | 15-25 | >35 | 即时 | 期权市场 |
| 信用利差(AA-AAA) | 0.5-1.5% | >2.5% | 1-3个月 | 中债 |
| 人民币汇率单周变动 | <1% | 单周贬值>2% | 1-2周 | 外汇交易中心 |

### 4.2 指标组合判断

单一指标误报率高，组合触发时可信度大幅提升：

```
★ 高置信度危机预警组合（≥3项同时触发）：
  □ 两融月降>10%
  □ 北向周流出>100亿
  □ 成交量<5000亿连续3日
  □ 跌停/涨停比<0.5连续2日
  □ 信用利差>2.5%
  
  → 触发后3个月内出现显著下跌的概率：>80%(基于2015-2024回顾)
```

## 五、政策干预节奏

### 5.1 干预升级阶梯

基于历史案例，政策干预通常按此节奏升级：

| 阶段 | 触发条件 | 典型政策 | 市场反应 | 历史案例 |
|:-----|:--------|:--------|:--------|:--------|
| 口头稳定 | 指数跌5-10% | 证监会/央行官员讲话 | 短暂止跌，通常无效 | 2018.06 易纲讲话 |
| 定向措施 | 指数跌10-15% | 降准、股东增持窗口指导 | 短期反弹3-5% | 2018.07 定向降准 |
| 强力干预 | 指数跌15-20% | 汇金增持、限制做空、国家队入场 | 中期底部概率50% | 2015.07 证金入场 |
| 最高层出手 | 指数跌20%+ | 国务院常务会议、政治局会议定调 | 政策底确认，高概率中期底部 | 2018.10 刘鹤讲话、2022.04 政治局会议 |

### 5.2 政策底→市场底的时间差

| 危机 | 政策底日期 | 市场底日期 | 间隔 | 政策底后继续跌多少 |
|:-----|:---------|:---------|:---:|:---------------:|
| 2015股灾 | 7/8(公安部+限制减持) | 8/26 | 49天 | -18% |
| 2018贸易战 | 10/19(刘鹤讲话) | 1/4(2019) | 77天 | -10% |
| 2020疫情 | 2/3(央行1.2万亿) | 2/3(同日见底) | 0天 | 0% |
| 2022封城 | 4/29(政治局) | 4/27(提前2天) | -2天 | 0% |
| 2024雪球 | 1/23(汇金增持) | 2/5 | 13天 | -3% |

**规律**：
- 流动性危机：政策底≈市场底（政策直接解决流动性问题）
- 外部/结构性问题：政策底后仍有1-3个月探底期（政策不能直接解决根本问题）
- 市场底常在政策底2周-2月后出现，期间可能有10-18%的二次探底
