## 一、证监会与交易所监管风向

### 1.1 监管风向的三大观测维度

**维度一：IPO节奏**

IPO节奏是最直接的政策温度计——监管对市场冷暖的判断直接体现在IPO放行速度上。

```
IPO节奏类型（按每周核准/注册数）：
  加速期：每周5-8家 → 监管认为市场强、可以多融资 → 利空短期流动性
  正常期：每周3-5家 → 正常节奏，不松不紧
  减速期：每周1-2家 → 监管呵护市场 → 政策底信号
  暂停期：0家 → 极端情况下的救市手段 → 重大政策底信号
```

**IPO节奏的历史政策含义**：
- 2015年股灾期间暂停IPO（2015年7-11月） → 最强救市组合拳之一
- 2023年8月后IPO实质性收紧 → 配合"活跃资本市场"的政策组合拳
- 2024年至今IPO节奏维持历史低位 → 监管呵护市场的姿态未变

**维度二：再融资审批**

| 状态 | 含义 | 利好/利空 |
|:-----|:-----|:---------|
| 再融资审批加速 | 支持企业融资发展 | 利好投行/券商，利空存量资金 |
| 再融资审批收紧 | 限制"圈钱"、保护存量投资者 | 利好存量市场 |
| 特定行业再融资受限 | 金融/地产等行业融资受限 → 供给侧收缩 | 利好该行业存量公司（竞争者无法融资扩产） |

**维度三：口头信号——证监会讲话措辞**

```
"保护中小投资者" → 常规表态
"加强市场监管" → 严查市场操纵、内幕交易
"活跃资本市场" → 最高层的KPI，会出利好组合拳
"维护资本市场平稳运行" → 稳定压倒一切，防止大涨大跌
"上市公司是市场的基石" → 监管焦点在上市公司质量
"投资端改革" → 引导长期资金入市（养老金/险资/银行理财）
"融资端收紧" → 控制IPO/再融资节奏
```

### 1.2 交易所层面监控

**异常交易监控**：
- 涨幅偏离值达±7%（主板）→ 进入监控视野
- 连续3个交易日涨幅偏离值累计达±20% → 异常波动，可能停牌核查
- 新股上市首日/前5日不设涨跌幅限制的品种 → 交易所重点监控

**重点监控股票的含义**：
- 一旦某股票被交易所列为"重点监控"，短线游资通常会撤离 → 上涨动力衰竭
- 监控期间若有连续涨停 → 可能触发更严的核查/停牌

### 1.3 监管周期判断

```
监管收紧期信号：
- 多家公司收到监管函/问询函
- 多家公司被立案调查
- IPO现场检查比例提高
- "零容忍"措辞频繁出现
→ 市场投机氛围被压制，短线交易难度加大，基本面策略相对占优

监管宽松期信号：
- 并购重组审批加速
- 再融资条件放宽
- 监管层表示"尊重市场"
- 科创板/创业板改革加速
→ 主题投资活跃，中小盘/成长股占优
```

## 二、减持规则体系

### 2.1 大股东减持限制（核心规则）

```
集中竞价减持限制：
  - 任意连续90个自然日内，减持股份总数 < 公司总股本的 1%
  - 减持前15个交易日必须预披露减持计划

大宗交易减持限制：
  - 任意连续90个自然日内，减持股份总数 < 公司总股本的 2%
  - 受让方6个月内不得转让

协议转让：
  - 单个受让方比例不低于5%
  - 受让方6个月内不得转让
```

### 2.2 2024年减持新规核心要点（"史上最严减持新规"）

```
破发：股价跌破IPO发行价 → 控股股东/实控人不得减持
破净：股价跌破每股净资产 → 控股股东/实控人不得减持
分红不达标：最近三年累计现金分红 < 年均净利润的30%，或累计分红金额 < 5000万元
  → 控股股东/实控人不得减持

离婚/解散/分立：绕道减持的路被堵死
司法强制执行/股票质押违约：参照集中竞价/大宗交易减持限制执行
```

**减持新规对A股的深层影响**：
- 满足减持条件的公司数量大幅减少 → 实际减持压力下降
- 倒逼分红 → 利好高股息策略
- 破发/破净公司股东无减持渠道 → 倒逼管理层做好市值管理

### 2.3 减持预警信号

Sentinel需要关注的减持预警：

```
一个月内大股东/董监高集中披露减持计划
  → 超过10家同行业公司 → 行业见顶信号？内部人对估值的不认可？

控股股东减持（vs 财务投资者减持）
  → 控股股东减持 = 比财务投资者减持信号更负面

减持数量占日成交量比例
  → 减持股数 > 近20日日均成交量的10% → 短期对股价有实质压制

大宗交易折价率
  → 折价 > 8% → 买方接盘意愿弱，股价压力信号
```

## 三、国家队动向

### 3.1 主要"国家队"力量

| 主体 | 性质 | 规模 | 风格 | 重点关注 |
|:-----|:-----|:-----|:-----|:---------|
| 中央汇金 | 国有独资公司 | 万亿级 | 长期持有，以银行/保险/金融为主 | 增持公告（直接托市信号） |
| 证金公司 | 证券公司融资平台 | 数千亿级 | 市场极端时期入市 | 持仓半年报/年报变化 |
| 社保基金 | 养老金投资 | 万亿级 | 长期价值投资 | 季报前十大重仓股变化 |
| 中国国新/中国诚通 | 国有资本运营公司 | 千亿级 | 战略持股+央企改革 | 增持国央企股票 |
| 养老金 | 基本养老保险基金 | 千亿级 | 极度保守，安全第一 | 入市比例提升 |
| 保险资金 | 商业保险公司 | 万亿级 | 长期投资+高分红标的 | 权益投资比例上限调整 |

### 3.2 国家队信号解读

**汇金增持的信号强度**：

```
汇金增持四大行 → 强烈托底信号（历史上多次精准抄底）
汇金增持ETF → 新版托市方式（2023Q4以来，直接买入沪深300/上证50/中证500ETF）
汇金公开声明"继续增持" → 政策底确认，持续性托底
汇金"正在买入" → 政策底+信心提振（比买入后公告更强）
```

**社保基金信号**：
- 社保基金权益投资比例提高 → 长期资金入场信号
- 社保基金持仓中某一行业占比提高 → 该行业获得"长期资金"认可

### 3.3 产业资本增减持信号

```
产业资本 = 上市公司大股东/管理层/产业集团（不包括金融机构和纯财务投资者）

产业资本净增持：
  - 连续2个月净增持 → 市场底部信号（内部人对估值认可）
  - 净增持金额 > 净减持金额 → 重要底部区域

产业资本净减持：
  - 持续净减持 → 正常状态（A股常年净减持），不一定看空
  - 减持金额突然大幅增加 → 可能的见顶信号

行业集中减持：
  - 同一行业多家公司集中减持 → 行业估值见顶信号（内部人认为"这个价够高了"）
```

## 四、大小非解禁日历

### 4.1 解禁类型与锁定期

| 解禁类型 | 锁定期 | 解禁规模特征 | 减持意愿 |
|:---------|:------|:-----------|:--------:|
| IPO首发原股东 | 上市后12-36个月（控股股东36个月） | 规模大，占总股本比例高 | 创始人/PE股东减持意愿差异大 |
| 定向增发（机构投资者） | 发行后6个月（竞价）/18个月（定价） | 规模较大 | 有获利后减持倾向较强 |
| 定向增发（大股东） | 发行后18个月 | 规模大 | 通常不减持（维护控制权） |
| 股权激励 | 授予后12-36个月分期解锁 | 规模较小（<3%） | 员工套现意愿随行就市 |
| 重组/借壳 | 协议约定，通常12-36个月 | 规模因交易而异 | 视重组标的质地而定 |

### 4.2 解禁压力评估矩阵

Sentinel评估一次解禁事件对股价的影响，从以下四个维度评分：

```
维度1：解禁数量占总股本比例
  <1% → 1分（几乎无影响）
  1-3% → 2分（轻微影响）
  3-5% → 3分（中等影响）
  5-10% → 4分（较大影响）
  >10% → 5分（重大影响）

维度2：解禁股东类型
  控股股东/实控人 → 1分（基本不减持）
  战略投资者 → 2分（可能长期持有）
  财务投资者（PE/VC） → 3分（有退出诉求）
  定增机构 → 4分（获利了结动力强）
  自然人/员工 → 3分（随行就市）

维度3：当前股价 vs 成本价
  股价远低于成本 → 1分（不忍减持）
  股价在成本附近 → 2分（可能观望）
  股价高于成本20-50% → 3分（有减持动力）
  股价高于成本>50% → 4分（强烈减持动力）

维度4：近期日均成交量
  解禁量/日均成交量 < 1 → 1分（一天就能消化）
  1-5 → 2分（几天消化）
  5-10 → 3分（需要一两周消化）
  10-20 → 4分（持续压力）
  >20 → 5分（重大冲击）

综合评分 = 维度1×0.35 + 维度2×0.25 + 维度3×0.25 + 维度4×0.15
  >3.5分 → 需重点预警
  2.5-3.5分 → 需关注
  <2.5分 → 常规注意
```

### 4.3 解禁预警清单管理

```
每周一检查本周和下周的解禁清单
筛选：综合评分 > 3.0 的品种 → 纳入当周预警
特别关注：解禁 + 前期涨幅过大 + 定增机构解禁组合
```

## 五、财报季时间轴与业绩预告

### 5.1 定期报告披露截止日

```
年报（年度报告）：4月30日
一季报：4月30日（与年报同期）
半年报（中期报告）：8月31日
三季报：10月31日

预告和正式报告的关系：
业绩预告（粗略，有强制/自愿之分） → 业绩快报（较详细，中小板/创业板要求） → 正式报告（完整审计/审阅）
```

### 5.2 财报季的四个时间窗口

Sentinel按以下四个窗口管理财报季：

| 窗口 | 时间 | 特征 | 策略含义 |
|:-----|:-----|:-----|:---------|
| 预跑窗 | 截止前4-6周 | 预告陆续发布，信息碎片化 | 提前识别业绩雷/业绩惊喜 |
| 密集窗 | 截止前2-4周 | 大批公司发布预告/快报 | 板块整体业绩趋势开始清晰 |
| 收官窗 | 截止前1-2周 | "丑媳"季——差公司拖到最后一刻 | 警惕踩雷集中爆发 |
| 消化窗 | 截止后2-4周 | 市场对财报信息的定价完成 | 超预期股分化（能否持续） |

### 5.3 业绩预告规则详解

**主板（沪市+深市主板）——强制预告条件**：

```
满足以下任一条件 → 必须发布业绩预告：

1. 净利润为负数（亏损）
2. 净利润实现扭亏为盈
3. 净利润同比变动 ±50% 以上
4. 期末净资产为负数（资产负债率>100%）
5. 年度营收 < 1000万元（触及退市风险警示标准）

年报预告截止日：1月31日
半年报预告截止日：7月15日
季报预告：主板无强制要求（一季报和三季报预告自愿为主）
```

**创业板——强制预告**：

```
创业板所有公司必须在1月31日前发布年度业绩预告
（比主板更严格，不论业绩如何都须预告）
```

**科创板——自愿为主**：

```
科创板原则上以自愿披露为主，不做强制要求
但若出现净利润为负/扭亏为盈/±50%变动 → 建议披露（非强制）
```

### 5.4 业绩变脸预警

```
业绩变脸定义：
  预告业绩 vs 正式报告差异 > 20%（向下修正）

Sentinel关注重点：
  - 已发布预告的公司，关注正式报告是否大幅下修
  - 连续2次业绩向下修正的公司 → 管理层可信度打折扣
  - 同行业多家公司向下修正 → 行业景气度下行
```

## 六、ST/*ST规则体系

### 6.1 风险警示类型

| 类型 | 全称 | 标识 | 主要触发条件 | 涨跌幅限制 |
|:-----|:-----|:----:|:-----------|:--------:|
| ST | 其他风险警示 | ST | 内控否/资金占用/违规担保等 | 5%（主板）/20%（科创板ST） |
| *ST | 退市风险警示 | *ST | 触及退市风险指标 | 5%（主板）/20%（科创板*ST） |

### 6.2 *ST的主要触发条件（退市风险警示）

```
财务类：
  - 年度净利润为负 + 营收 < 1亿元（主板）/ < 5000万元（科创板）
  - 期末净资产为负（资产负债率>100%）
  - 被出具无法表示意见/否定意见的审计报告

规范类：
  - 未按期披露年报/半年报且在停牌后2个月仍未披露
  - 半数以上董事无法保证年报真实性

交易类：
  - 连续20个交易日收盘价 < 1元（面值退市）
  - 连续20个交易日市值 < 3亿元（主板）/ < 5亿元（科创板）
  - 连续120个交易日累计成交量 < 500万股（主板）

重大违法类：
  - 重大信息披露违法
  - 欺诈发行
  - 重大财务造假
```

### 6.3 ST/*ST规则最新变化（2025-2026）

```
2024年4月退市新规：
  - 财务类退市："净利润为负+营收<1亿"（原为"净利润为负+营收<1亿"已执行）
  - 提高了财务造假退市标准：
    造假金额>2亿且占比>30% → 退市（原标准更宽松）
    连续2年造假>3亿且占比>20% → 退市
    连续3年以上造假 → 直接退市
  - 新增：大股东资金占用 > 2亿或占净资产30% → 退市风险警示
  - 新增：内部控制审计报告为否定意见 → ST

2025-2026年需持续关注的更新方向：
  - 科创板ST/*ST制度的进一步细化
  - 北交所退市制度的完善
  - 投资者索赔/集体诉讼制度的推进
```

### 6.4 退市风险预警清单管理规则

Sentinel的日常退市风险巡检：

```
[ ] 每周：扫描股价 < 2元的非ST公司（接近面值退市红线）
[ ] 每周：扫描市值 < 5亿元的公司（非ST类）
[ ] 每月：扫描上年度净利润为负+营收 < 1.5亿元的公司（接近*ST红线）
[ ] 每季：在季报披露后扫描净资产为负的公司
[ ] 每次季报后：检查审计意见类型（被出具非标意见的公司）

预警阈值设置：
  股价 1.5元 = 红色警报（距离1元退市仅剩30%空间）
  股价 2.0元 = 橙色警报（需密切关注）
  营收 1.0-1.5亿 + 净利润为负 = 黄色警报（接近*ST红线）
  市值 3-5亿 = 黄色警报
```

## 七、A股政策维度巡检清单

```
每周一：
  [ ] 本周解禁日程（重点：评分>3.0的品种）
  [ ] 上周IPO核准/注册家数及变化趋势
  [ ] 上周大股东减持公告情况

每月初：
  [ ] 上月再融资审核情况
  [ ] 上月国家队持仓变动（如有季报/年报）
  [ ] 上月退市风险公司名单更新

财报季（1月/4月/7月/8月/10月）：
  [ ] 预告截止日（1.31 / 7.15）
  [ ] 正式报告截止日（4.30 / 8.31 / 10.31）
  [ ] 业绩变脸预警（对比预告和正式报告）

不定期（事件触发）：
  [ ] 监管主要领导讲话
  [ ] 重大监管制度变化（减持新规/退市新规/IPO新规等）
  [ ] 汇金/国企公开声明增持
```
