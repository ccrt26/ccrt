## 一、PMI（采购经理指数）

PMI是经济运行的先行指标，通常领先GDP约1-3个月。国家统计局PMI与财新PMI并行发布，两者覆盖样本不同。

### 1.1 两种PMI对比

| 维度 | 官方PMI（统计局） | 财新PMI |
|:-----|:----------------|:-------|
| 发布机构 | 国家统计局 | 财新/Markit |
| 发布时间 | 每月最后一天9:30 | 每月第一个工作日9:45 |
| 样本规模 | 约3000+企业 | 约500+企业 |
| 企业规模 | 大企业为主 | 中小企业为主 |
| 偏向行业 | 重工业/国企 | 轻工业/民企/外贸 |
| 季节性调整 | 有（X12-ARIMA） | 有（Markit方法） |

**双PMI背离解读**：

```
官方PMI > 50 但 财新PMI < 50
  → 大企业好、中小企业差 → 权重股维稳但赚钱效应差 → 震荡市
  → 行业含义：上游/国企强，中下游/民营弱

官方PMI < 50 但 财新PMI > 50
  → 大企业承压但中小企业韧性 → 结构行情、创业板相对强势
  → 行业含义：出口导向+轻工业强于重工业

双PMI同时 > 50 → 全面复苏，牛市信号
双PMI同时 < 50 → 全面收缩，防御信号
```

### 1.2 PMI五大分项解读

PMI由五个扩散指数加权构成（权重为历史形成，统计局不公开精确数字，市场采用大致权重）：

```
PMI = 新订单 × 30% + 生产 × 25% + 从业人员 × 20% + 供应商配送时间 × 15% + 原材料库存 × 10%
（注：供应商配送时间为逆序指标——配送时间越长说明供应商越忙/需求旺，反而对PMI有正向贡献）
```

| 分项 | 健康阈值 | 预警阈值 | 先行含义 | 影响板块 |
|:-----|:--------:|:--------:|:---------|:---------|
| 新订单 | >51 | <49 | 需求端最核心指标，领先生产1-2月 | 全行业 |
| 生产 | >52 | <50 | 当前供给强度 | 制造业 |
| 从业人员 | >49 | <48 | 就业/人力成本压力 | 劳动密集型 |
| 配送时间 | 50附近 | >52(太慢)/<48(太快) | 太慢=需求旺(好)，太快=需求弱(坏) | — |
| 原材料库存 | 48-50 | <47(补库)/>52(积压) | 库存周期判断 | 上游资源品 |

### 1.3 PMI特殊分项信号

**价格相关分项**（领先PPI约1个月）：

```
主要原材料购进价格指数 > 60 → PPI上行预期 → 上游资源品利润改善
主要原材料购进价格指数 < 45 → PPI下行预期 → 上游承压，中下游或受益于成本下降
出厂价格指数 - 购进价格指数 > 0 → 企业利润空间扩大
出厂价格指数 - 购进价格指数 < -5 → 企业利润空间被压缩 → 警惕制造业利润下滑
```

**新出口订单**：

```
新出口订单 > 50 → 外需回暖 → 利好出口型制造业、港口/航运
新出口订单 < 48 持续3个月 → 外需疲弱 → 出口型行业承压
新出口订单与进口分项的差值 → 贸易顺差趋势的先行指标
```

**生产经营活动预期**：

```
> 58 → 企业家信心强 → 资本开支意愿强 → 利好设备制造
< 52 → 企业家信心弱 → 保守经营 → 利空制造业投资
```

### 1.4 PMI连续趋势判断

```
连续3个月在50以上且逐月上升 → 经济扩张加速 → 牛市信号增强
连续3个月在50以上但逐月下降 → 扩张速度放缓 → 涨幅趋缓/震荡
连续3个月在50以下但逐月上升 → 收缩放缓/接近见底 → 磨底阶段
连续3个月在50以下且逐月下降 → 经济加速收缩 → 系统性风险
```

## 二、CPI与PPI

### 2.1 CPI（消费者价格指数）

```
发布时间：每月9-15日（国家统计局）
核心指标：CPI同比、CPI环比、核心CPI（剔除食品和能源）
关键阈值：CPI > 3% 警惕通胀，CPI > 5% 严重通胀，CPI < 0% 通缩风险
```

**CPI对A股的影响机制**：

| CPI区间 | 经济含义 | 货币政策反应 | 股市含义 | 受益板块 |
|:--------|:---------|:----------|:---------|:---------|
| <0%（通缩） | 需求极度疲弱 | 必须宽松 | 先跌后涨（宽松预期） | 成长/券商 |
| 0-1% | 物价低迷，需求偏弱 | 有宽松空间 | 温和偏利好（政策空间大） | 成长/科技 |
| 1-3%（健康区） | 物价温和，经济健康 | 维持现状 | 最理想状态 | 消费/医药 |
| 3-5%（警戒区） | 通胀抬头 | 开始收紧 | 利空（政策收紧预期） | 上游资源/黄金 |
| >5%（危险区） | 严重通胀 | 强力紧缩 | 重大利空 | 黄金/现金 |

**核心CPI（剔除食品和能源）的重要性**：
- 核心CPI更反映趋势性通胀而非季节性波动
- 食品（尤其猪肉）波动大，剔除后更能判断真实通胀压力
- 核心CPI持续 < 1% = 有效需求不足，经济有通缩风险

**猪周期与CPI**：
- 猪肉价格在CPI中的权重约2-3%，但波动极大（可翻倍或腰斩）
- 猪价同比上涨50% → 直接拉动CPI约1-1.5个百分点
- 判断CPI时必须分辨是"猪周期引起的临时性上涨"还是"全面的物价上涨"

### 2.2 PPI（工业生产者出厂价格指数）

```
发布时间：每月9-15日（通常与CPI同日）
核心指标：PPI同比、PPI环比、生产资料PPI vs 生活资料PPI
关键阈值：PPI < 0% = 工业通缩
```

**PPI对板块利润的影响**：

| PPI状态 | 上游（采掘/原材料） | 中游（加工/制造） | 下游（消费品） |
|:--------|:------------------:|:----------------:|:------------:|
| PPI大幅上行（>5%） | 利润暴增 | 成本压力↑（看转嫁能力） | 利润受挤压 |
| PPI温和上行（0-5%） | 利润改善 | 量价齐升（最佳） | 成本可控 |
| PPI零附近（-1%~1%） | 利润微薄 | 竞争加剧 | 成本红利 |
| PPI负值（<-1%） | 利润压缩/亏损 | 受益于低成本（有条件） | 成本红利明显 |

**PPI-CPI剪刀差**：

```
PPI - CPI > 2% → 上游暴利、下游承压 → 利好采掘/有色/钢铁
PPI - CPI ≈ 0 → 利润分配均衡 → 中游制造业最受益
PPI - CPI < -2% → 下游成本红利、上游承压 → 利好消费/家电/食品
```

## 三、GDP增速

### 3.1 数据解读框架

```
发布时间：每季度下一个月的15日左右（Q1: 4月中旬, Q2: 7月中旬, Q3: 10月中旬, Q4: 次年1月中旬）
关键指标：GDP同比增速、GDP环比增速（季调后）
2024-2025年背景：中国经济增速在"5%左右"的目标区间运行
```

**GDP实际值与全年目标的关系**（以2025年5%目标为例）：

| Q1同比 | 含义 | Q2-Q4需要达到的增速 | 全年预期 |
|:------:|:-----|:------------------:|:--------:|
| >5.5% | 开局强劲 | 4.8%+ | 大概率完成或超额完成 |
| 5.0-5.5% | 开局良好 | 5.0%左右 | 有望完成 |
| 4.5-5.0% | 开局偏弱 | 5.2%+ | 需要政策加码 |
| <4.5% | 开局困难 | 5.5%+ | 强烈需要加码 |

### 3.2 三驾马车拆解

```
GDP = C（消费，约55%）+ I（投资，约40%）+ NX（净出口，约5%）
```

**消费部分**：最终消费支出对GDP的贡献率 > 60% = 消费驱动型，< 40% = 投资驱动型
**投资部分**：资本形成总额中，制造业投资（约30-35%）、基建投资（25-30%）、房地产投资（20-25%）
**净出口部分**：货物贸易顺差 - 服务贸易逆差，顺差扩大 = 对GDP正向拉动大

## 四、社零（社会消费品零售总额）

```
发布时间：每月15日左右
核心指标：社零同比、社零环比、限额以上 vs 限额以下、实物网上零售额
关键阈值：社零增速 > 8% = 消费强劲，< 3% = 消费疲弱
```

**社零结构性信号**：

| 分项 | 当前趋势观察 | 含义 |
|:-----|:-----------|:-----|
| 餐饮收入 vs 商品零售 | 餐饮增速 > 商品增速 = 体验消费强于实物消费 | 利好餐饮/旅游/酒店 |
| 限上 vs 限下 | 限额以上更好 = 消费升级/集中化 | 利好龙头企业 |
| 升级类消费品（化妆品/珠宝/体育娱乐） | 增速 > 总体社零 = 消费升级趋势 | 利好可选消费 |
| 汽车零售 | 汽车占社零约10%，是社零第一大品类 | 新能源车渗透率是关键变量 |
| 网上零售增速 | 线上渗透率见顶？仍在上升？ | 影响电商/线下零售估值 |

## 五、工业增加值

```
发布时间：每月15日左右（通常与社零同日）
核心指标：工业增加值同比、制造业增加值同比、高技术制造业增加值占比
关键阈值：>6% = 工业偏强，<3% = 工业偏弱
```

**工业增加值的行业维度分析**：

```
工业增加值同比的领先行业中：
- 高新技术制造业增速 > 传统制造业增速 → 产业升级在发生
- 装备制造业增速 > 工业总体 → 制造业投资景气
- 汽车制造业增速（新能源车产销量直接相关）
- 计算机/通信/电子设备增速（半导体/消费电子景气度）
```

## 六、固定资产投资

```
发布时间：每月15日左右（与社零、工业增加值同日）
三大支柱：制造业投资（约30-35%）、基建投资（25-30%）、房地产开发投资（20-25%）
```

**三支柱健康度矩阵**：

| 组合 | 制造业 | 基建 | 房地产 | 经济判断 | 利好板块 |
|:----:|:------:|:----:|:------:|:---------|:---------|
| 全面好 | >8% | >8% | 正增长 | 经济强劲 | 顺周期全面 |
| 制造强地产弱 | >8% | >5% | 负增长 | 新旧动能转换中 | 高端制造/科技 |
| 基建托底 | <5% | >10% | 负增长 | 政府兜底经济 | 工程机械/建材/建筑 |
| 全面弱 | <3% | <5% | <-10% | 经济下行严重 | 高股息/债券/防御 |
| 地产企稳 | — | — | 降幅收窄→正增长 | 最困难的时期过去 | 地产链反弹 |

**房地产投资的关键跟踪指标**：
- 30城商品房成交面积（高频，每周可得）
- 百城土地成交面积/溢价率
- 二手房挂牌量和价格
- 房企到位资金（国内贷款/自筹/定金及预收款/个人按揭）

## 七、进出口

```
发布时间：每月7日（海关总署）
核心指标：出口同比（美元计）、进口同比（美元计）、贸易差额
```

**出口对A股的意义**：
- 出口增速与中证500/中证1000相关性 > 沪深300（出口型企业中中小盘比例更高）
- 对美出口增速 = 中美关系+美国需求的温度计
- 对东盟/一带一路出口增速 = 中国出口结构转型的成效

**出口结构性分析**：

| 品类 | 持续强劲信号 | 持续走弱信号 |
|:-----|:------------|:------------|
| 机电产品（占总出口约60%） | 全球制造业周期上行 | 全球需求下滑 |
| 新能源（光伏/锂电池/新能源车"新三样"） | 能源转型持续 | 欧盟反补贴/美国关税 |
| 劳动密集型（纺织/家具/玩具） | 美国消费韧性 | 产业外迁至东南亚 |
| 钢材/化工 | 全球基建/工业需求 | 贸易摩擦/反倾销 |

## 八、就业

```
发布时间：每月15日左右（通常与社零同日）
核心指标：城镇调查失业率（警戒线=5.5%）、31个大城市调查失业率
青年失业率（16-24岁）：2023年6月后一度暂停发布，恢复后改用新口径（不含在校生）
```

**就业与政策的关系**：
- 失业率 > 5.5% → 政策宽松的"硬依据" → 大概率出台稳就业/稳经济措施
- 青年失业率持续高企 → 消费压力（年轻人是消费主力）
- 就业好 → 收入增长 → 消费 → 企业盈利 → 股市正循环

## 九、高频跟踪指标体系

月度宏观数据发布滞后，Sentinel需要建立高频数据跟踪体系，提前感知经济冷暖。

### 9.1 高频指标清单

| 高频指标 | 频率 | 跟踪什么 | 正常/健康区间 | 预警信号 |
|:---------|:----:|:---------|:------------|:---------|
| 30城商品房成交面积 | 周度 | 房地产需求 | 同比降幅<10% | 同比降幅>30%且持续 |
| 百城土地成交溢价率 | 周度 | 土地市场热度 | 5-15% | 持续<3%或>25% |
| 螺纹钢表观消费量 | 周度 | 基建+地产施工 | 季节性正常水平 | 同比下滑>15% |
| 螺纹钢社会库存 | 周度 | 钢材供需平衡 | 季节性去库 | 反常累库 |
| 水泥价格指数 | 周度 | 基建投资强度 | 季节性正常 | 跌至成本线附近 |
| 高炉开工率 | 周度 | 工业生产强度 | >75% (正常) | <65%持续 |
| 发电量/用电量 | 周度-月度 | 宏观经济冷暖 | 同比>3% | 同比<1% |
| 汽车销量（乘联会） | 周度 | 最大消费品类 | 同比>5% | 同比持续为负 |
| 地铁客流/拥堵指数 | 日度 | 城市经济活动 | 季节性正常 | 大幅偏离正常值 |
| 集装箱运价指数（CCFI/SCFI） | 周度 | 外需+出口 | 季节性正常 | 单周暴跌>10% |
| BDI（波罗的海干散货指数） | 日度 | 全球贸易热度 | >1500 | <800 |
| 六大发电集团耗煤量 | 日度 | 工业用电强度 | 季节性正常 | 同比大幅下降 |

### 9.2 高频数据的"季节-环比-同比"三看原则

```
1. 先看季节性：农历春节/国庆/暑期等因素导致的高频波动，避免"春节效应"误判
2. 再看环比：当前周与上周对比，判断短期动能变化
3. 最后同比：当前数据与去年同期对比，排除季节因素后的真实趋势
```

**季节性陷阱提醒**：
- 春节前1-2周：工地停工、工厂放假 → 螺纹钢/水泥需求骤降 → 这是正常的，不是经济恶化
- 每年11-12月：专项债资金集中使用 → 基建数据突然好转 → 可能是季节性而非趋势性
- 6月末/12月末：银行贷款冲量 → 票据利率异常波动 → 不代表真实融资需求

## 十、数据发布时间表

### 10.1 月度数据发布节奏

```
每月7日      海关总署发布上月进出口数据
每月9-15日   央行发布上月社融+信贷+M1/M2数据
每月9-15日   国家统计局发布上月CPI + PPI数据
每月15日左右  国家统计局发布上月社零+工业增加值+固定资产投资+就业
每月最后一天  国家统计局发布当月PMI（制造业+非制造业）
每月第一个工作日 财新发布上月财新PMI
```

### 10.2 季度数据

```
每季度次月15日左右：GDP增速（Q1: 4月中旬 / Q2: 7月中旬 / Q3: 10月中旬 / Q4: 次年1月中旬）
每季度次月：央行货币政策执行报告（5月/8月/11月/次年2月）
每季度末月：央行例会（3/6/9/12月）
```

### 10.3 年度关键数据日

```
1月中旬  ：上年度GDP初步核算数
1月底    ：地方两会陆续召开，各省GDP目标公布
3月初    ：全国两会，政府工作报告（全年GDP/赤字率/CPI目标）
7月中旬  ：上半年GDP初步核算数
12月中旬 ：中央经济工作会议（来年政策总基调）
```

### 10.4 Sentinel的"数据发布日历"管理规则

```
[ ] 提前1天：提醒次日有哪些数据发布 → 更新到每日简报中
[ ] 发布当天：记录实际数据，对比市场预期（Wind一致预期）和上月数据
[ ] 数据发布后1-2天：跟踪市场对数据的反应（板块走势、北向资金流向）
[ ] 数据发布后1周：判断数据对市场趋势的持续影响
```

## 十一、宏观数据综合判断矩阵

将多个宏观指标联合起来看，形成综合判断。避免单一指标误判。

### 11.1 经济四象限（增长 x 通胀）

```
          高通胀(CPI>2.5%)
              |
    过热      |    滞胀
  (宽松退场,   |  (最差的宏观组合:
   大宗商品牛)  |   现金+黄金+防御股)
              |
  ——低增长————+————高增长——
              |
    衰退      |    复苏
  (政策宽松,   |  (最好的宏观组合:
   债券牛,     |   股票全面牛)
   红利防御)   |
              |
          低通胀(CPI<1.5%)
```

### 11.2 宏观数据多维交叉验证原则

```
至少3个指标同向才判断趋势变化：

[经济向上确认] PMI>50连续3月 + 社零>6% + 工业增加值>5.5% + 固定资产投资>4.5%
       → 至少满足3个 → 经济扩张确认

[经济向下确认] PMI<49连续2月 + 社零<2% + 工业增加值<3% + PPI连续为负
       → 至少满足3个 → 经济收缩确认

[通胀抬头确认] CPI>2.5% + 核心CPI>1.5% + PMI购进价格>58
       → 至少满足2个 → 通胀压力确认

[通缩确认] CPI<0% + PPI<-2% + 核心CPI<0.5%
       → 至少满足2个 → 通缩压力确认
```
