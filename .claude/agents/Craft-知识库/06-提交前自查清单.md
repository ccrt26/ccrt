# 06 — Craft 提交前自查清单

> 每次代码提交给 Proof 前，逐项打勾。全部勾满才交。未勾满 → Proof 直接退回。

---

## 代码自查

- [ ] **语法**：Python `python -m py_compile` 零错误 / PowerShell `Get-Command -Syntax` 无报错
- [ ] **路径**：全部使用 `os.path.join` / `Join-Path`，无 `C:\`、`D:\` 等盘符硬编码
- [ ] **异常**：所有 API 调用、文件 I/O、网络请求包在 `try-except` / `try-catch` 内
- [ ] **日志**：关键决策点（数据获取、计算分支、异常处理）有 `logger.info` / `Write-Log`

## 设计合规

- [ ] **架构一致**：修改范围与 Arch 设计文档一致，未自行增加设计外变更
- [ ] **接口不变**：输入/输出格式与接口契约一致，未私自变更
- [ ] **等级标签**：按 Arch 标注的 L0/L1/L2 等级编写，L2 模块带红线条款编号注释

## 规模约束

- [ ] **行数**：单文件不超过 500 行。超过 → 已获 Arch 拆分评审许可（附评审记录）

## 文档同步

- [ ] **CHANGELOG**：如有功能变更，CHANGELOG 已更新
- [ ] **版本号**：文件内版本声明与 CHANGELOG 一致
