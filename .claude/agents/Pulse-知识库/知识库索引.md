## 一、索引使用说明

本索引是Pulse知识库的总目录。知识库共5个文件，覆盖数据监理所需的全部核心知识领域——从数据源全景、质量维度，到缓存审计、架构合规、异常告警。

**使用方式**：
1. **按任务类型检索**（第二章）：如果你在执行某个具体巡检任务，直接看对应的"先看"和"再深入"列
2. **按知识文件检索**（第三章）：如果你需要查看某个知识领域的完整内容，直接按编号跳转
3. **按异常等级检索**（第四章）：遇到特定等级的异常时，快速定位需要参考的决策规则

## 五、知识文件的依赖关系图

```
基础层（必须先掌握）：
  01-数据源全景 ──────────────────────────────────────────┐
  │  知道有哪些数据源、端点是什么、超时多少、字段映射如何      │
  └───────────────────────────────────────────────────────┤
                                                          │
质量判断层（基于基础层进行诊断）：                            │
  02-数据质量维度 ─── 依赖 01（需要知道字段范围才能定阈值）    │
  03-缓存策略与审计 ─ 依赖 01（需要知道TTL才能做审计）        │
  │                                                       │
  ├── 02告诉你"数据好不好"                                  │
  └── 03告诉你"缓存新不新"                                  │
                                                          │
架构合规层（基于前两层判断合规性）：                           │
  04-1+2架构合规检查 ─ 依赖 01(源配置) + 03(缓存路径)        │
  │  告诉你"数据获取路径是否符合红线要求"                      │
                                                          │
告警决策层（综合前四层的输出，决定行动）：                      │
  05-异常检测与告警 ─ 依赖 02(阈值) + 03(缓存状态) + 04(合规) │
  │  告诉你"这个异常该定什么级、要不要升级、要不要暂停操作"      │
```

### 5.1 推荐学习路线

**路线A — 快速上手（1天）**：01 → 05 → 04 → 02 → 03
（先知道有什么数据源，再掌握异常分类和告警机制，然后学合规和审计）

**路线B — 深度掌握（2-3天）**：按上述依赖图从基础层到告警决策层逐层学习
（适合需要独立完成全量巡检和复杂诊断的场景）

**路线C — 专题定向（按需查阅）**：直接从第二章的"按任务类型快速检索"中定位
（适合在执行特定巡检任务时的临时查阅）
