## 二、Windows Task Scheduler

| 任务名 | 触发器 | 状态 | 执行脚本 |
|:-----|:-----|:----:|:-----|
| TieLv-Pigeon | 每日19:00 | Ready | `pigeon_daily.bat` → `pigeon_collector.ps1` |
| TieLv-PigeonBoot | 用户登录时 | Ready | `pigeon_boot.bat` → `pigeon_boot_check.ps1` |

两个任务均已注册在当前用户下，无需管理员权限。
开机自检使用 `AtLogOn` 触发器（替代 `AtStartup`，效果相同：用户登录即触发）。

重新注册（如任务损坏）：
```powershell
& "代码文件/信鸽信息采集/register_pigeon_scheduler.ps1"
```

## 三、开机自检逻辑

```
系统启动 → Task Scheduler触发 pigeon_boot_check.ps1
  ↓
检查: 重点股票/消息面数据/{today}_events.json 是否存在?
  ↓
├→ 存在 → 今日已采集，跳过（exit 0）
└→ 不存在 → 继续检查
      ↓
      是否为节假日? → 是 → 跳过
      ↓
      否 → 运行 pigeon_collector.ps1 执行补采
      ↓
      记录 boot_check.log
```

## 四、节假日处理

- 节假日文件：`每日荐股/运营记录/holidays_2026.csv`
- 定时采集：节假日跳过（19:00触发时检测到节假日→exit 0）
- 开机自检：节假日跳过
- 手动采集：不检查节假日（用户主动触发不受限）
