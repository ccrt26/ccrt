# 审计报告标准模板 — 旧影审计官

> 版本 v1.0 | 生效日期 2026-05-24
> 用途：日检/周检/月检三套审计报告的标准化输出格式。旧影按此模板输出。

---

## 一、日检报告模板

触发：每日自动或 `/旧影` 召唤时

```markdown

| 编号 | 描述 | 发现日期 | 状态 | 备注 |
|:----|:-----|:--------|:----:|:-----|
| F-xxx | xxx | xxx | ✅已修复/🔴未修复 | xxx |

> 无上次遗留FAIL时标注"全部已修复"。

## 二、今日流水线健康

| 检查项 | 状态 | 详情 |
|:-------|:----:|:-----|
| 数据采集完成 | ✅/✗ | 成功_/总数_ |
| 评分引擎运行 | ✅/✗ | |
| 报告生成 | ✅/✗ | |
| 版本一致性 | ✅/✗ | version_supervisor |
| 文件>500行无审批 | ✅/✗ | _个超限文件 |
| Golden Master | ✅/✗ | |
| 缺陷台账闭环率 | _% | 目标≥80% |

## 三、新增问题
（无新增问题时标注"无"）
```

## 四、输出规则

- 日检报告输出至对话中(不存档文件，除非有FAIL)
- 周检报告输出至 `审计报告/audit_weekly_YYYY-MM-DD.md`
- 月检报告输出至 `审计报告/audit_monthly_YYYY-MM.md`
- 有FAIL的报告同时保存结构化数据至 `历史数据/审计历史/AUDIT-YYYY-MM-DD-TYPE.json`
- 所有报告末尾必须有闸门判定
