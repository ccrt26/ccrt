## 二、趋势查询

### 2.1 最近N次审计摘要

```python
import json, glob, os

def get_recent_audits(n=10):
    """获取最近N次审计摘要"""
    files = sorted(glob.glob("历史数据/审计历史/AUDIT-*.json"), reverse=True)[:n]
    audits = []
    for f in files:
        with open(f, 'r', encoding='utf-8') as fp:
            audits.append(json.load(fp))
    return audits
```

### 2.2 FAIL趋势

```python
def fail_trend(audits):
    """FAIL项趋势: 最近10次审计的FAIL计数"""
    return [(a['audit_id'], a['summary']['fail']) for a in audits]
```

### 2.3 持久性FAIL(连续≥3次)

```python
def persistent_fails(audits):
    """返回连续出现≥3次的FAIL项"""
    return [item for a in audits for item in a['fail_items'] 
            if item['consecutive_count'] >= 3]
```

## 三、持久性FAIL升级

| 连续次数 | 动作 |
|:--------|:-----|
| 1-2次 | 正常追踪，旧影在审计报告中标记 |
| 3次 | 升级为P0级审计事件，通知阿黑协调 |
| 4次 | 阿黑必须在1个交易日内给出处理方案 |
| 5次+ | 升级L3，请示用户 |

---

## 四、闭环率计算

```
闭环率 = 本期已修复FAIL数 / (本期已修复 + 期末仍OPEN的FAIL数)
目标: ≥80% (轻量化规范§9.2)
```

## 五、审计数据文件组织

```
历史数据/审计历史/
├── AUDIT-2026-05-24-DAILY.json    # 日检
├── AUDIT-2026-05-24-WEEKLY.json   # 周检
├── AUDIT-2026-06-01-MONTHLY.json  # 月检
├── index.json                      # 索引(所有审计记录的快速查询)
└── trend_report_2026-Q2.md         # 季度趋势报告
```

`index.json` 格式：
```json
{
  "last_updated": "YYYY-MM-DD",
  "total_audits": 0,
  "audits": [
    {"id": "AUDIT-2026-05-24-DAILY", "date": "2026-05-24", "type": "daily", "pass": 10, "warn": 2, "fail": 1}
  ]
}
```

## 六、维护规则

- 每次审计完成后即时保存JSON
- 同时更新index.json索引
- 每季度生成趋势报告
- 连续3次FAIL→自动触发升级
- 审计历史保留至少1年(滚动删除更早的记录)
