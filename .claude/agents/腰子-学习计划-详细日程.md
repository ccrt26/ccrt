## 如何使用本计划

### 每天的执行流程

```
1. 读取进度文件 → 确定当前 Day
2. 执行当日「学习任务」+「实战练习」
3. 填写「每日反馈表」
4. 更新进度文件 → Day+1
```

### 中断恢复机制

终端关闭后再次打开时，CLAUDE.md 自动检测进度文件中 `status: "in_progress"` 的任务。
检测到未完成的学习日 → 主动提醒用户 → 用户确认后从断点继续。

每个阶段完成后自动生成一份阶段总结报告，包含：
- 学习完成情况
