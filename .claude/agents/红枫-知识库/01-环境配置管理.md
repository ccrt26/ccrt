## 一、Python 环境

### 1.1 版本要求

| 属性 | 值 | 说明 |
|:-----|:---|:-----|
| 最低版本 | Python 3.9 | 低于此版本不支持部分库特性 |
| 推荐版本 | Python 3.10 / 3.11 | 当前生产验证版本 |
| 上限版本 | Python 3.12 | 3.13 尚未广泛验证，暂不推荐 |
| 架构 | x64（64位） | pandas/numpy 在 32 位下有内存限制 |

**版本检查命令**：
```powershell
python --version
```

### 1.2 pip 依赖清单（当前项目实际依赖）

| 包名 | 用途 | 类别 | 关键路径 | 备注 |
|:-----|:-----|:-----|:--------|:-----|
| numpy | 数值计算、评分矩阵运算 | 核心 | ✅ 是 | 评分引擎依赖 |
| pandas | 数据处理、DataFrame 操作 | 核心 | ✅ 是 | 全链路依赖 |
| python-docx | DOCX 报告生成 | 报告 | ✅ 是 | md_to_docx.py 依赖 |
| openpyxl | Excel 文件读写 | 工具链 | ⚠️ 否 | 部分数据输出用 |
| mcp | MCP Server 通信 | 外部查询 | ⚠️ 否 | 外部 API 查询 |
| requests | HTTP 请求 | 核心 | ✅ 是 | 所有 API 调用基础 |
| urllib3 | HTTP 连接池 | 核心（间接） | ✅ 是 | requests 底层依赖 |
| certifi | SSL 证书验证 | 核心（间接） | ✅ 是 | HTTPS 请求依赖 |
| charset-normalizer | 编码检测 | 工具链 | ⚠️ 否 | 中文编码处理 |

### 1.3 虚拟环境方案

```
推荐方案：Python venv（内置，无需额外安装）

项目虚拟环境路径建议：
  项目根目录/.venv/

创建步骤：
  cd <项目根目录>
  python -m venv .venv
  .venv\Scripts\Activate.ps1    # PowerShell 激活
  pip install -r requirements.txt
```

**虚拟环境管理规则**：
- 每个开发者使用独立的 venv，不共享
- venv 目录加入 .gitignore（已默认配置）
- requirements.txt 必须与 venv 中实际安装的版本同步
- 定期运行 `pip list --outdated` 检查过期包（但不盲目升级）

### 1.4 环境变量配置

| 变量名 | 用途 | 默认值 | 是否必需 |
|:-------|:-----|:-------|:--------|
| PYTHONPATH | Python 模块搜索路径 | 项目根目录 | 推荐设置 |
| PATH | 系统路径（含 Python/Scripts） | 系统默认 | 必需 |
| TIELV_ENV | 运行环境标识 | `production` | 推荐设置 |
| TIELV_DATA_DIR | 数据缓存目录 | `项目根目录/数据文件/` | 推荐设置 |
| TIELV_OUTPUT_DIR | 报告输出目录 | `项目根目录/output/` | 推荐设置 |
| TIELV_LOG_LEVEL | 日志级别 | `INFO` | 可选 |

**PowerShell 环境变量配置示例**（添加到 $PROFILE）：
```powershell
$env:PYTHONPATH = "C:\Users\34269\Documents\Claude\股票分析"
$env:TIELV_ENV = "production"
$env:TIELV_LOG_LEVEL = "INFO"
```

### 1.5 Python 路径检查

关键检查项：
- `python` 命令是否指向正确的 Python 版本（3.9+）
- `pip` 是否与 `python` 属于同一环境
- `where.exe python` 返回的第一个路径是否正确
- 虚拟环境是否已激活（命令行前缀显示 `(.venv)`）

## 二、PowerShell 环境

### 2.1 版本要求

| 属性 | 值 | 说明 |
|:-----|:---|:-----|
| 最低版本 | PowerShell 5.1 | Windows 10/11 内置版本 |
| 推荐版本 | PowerShell 7.x | 更好的跨平台支持和性能 |
| 执行策略 | RemoteSigned 或 Bypass | 允许运行本地脚本 |

**版本检查命令**：
```powershell
$PSVersionTable.PSVersion
```

**执行策略检查**：
```powershell
Get-ExecutionPolicy
```

### 2.2 PSGallery 模块清单

| 模块 | 用途 | 是否必需 | 当前项目使用情况 |
|:-----|:-----|:--------|:---------------|
| (内置 cmdlet) | 数据获取、报告生成 | ✅ 必需 | 全部脚本依赖内置模块 |
| PSScriptAnalyzer | 代码规范检查 | ⚠️ CI 用 | 仅 CI 流程使用 |

**核心理念**：铁律量化项目的 PowerShell 脚本**刻意避免外部模块依赖**，所有数据获取、文件操作、报告生成均使用 Windows 内置 cmdlet。这降低了环境配置复杂度和"在我机器上能跑"问题。

### 2.3 PSModulePath 配置

```
默认路径（Win 10/11）：
  C:\Users\<用户名>\Documents\WindowsPowerShell\Modules
  C:\Program Files\WindowsPowerShell\Modules
  C:\Windows\system32\WindowsPowerShell\v1.0\Modules
```

### 2.4 PowerShell 编码配置

```powershell
# 确保所有脚本和控制台输出使用 UTF-8
$OutputEncoding = [System.Text.Encoding]::UTF8
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8

# 在脚本文件开头声明
# -*- coding: utf-8 -*-
```

## 三、配置文件管理

### 3.1 config.json 结构约定

```json
{
  "project": {
    "name": "铁律量化",
    "version": "x.y",
    "root_path": "项目根目录绝对路径"
  },
  "api": {
    "timeout_seconds": 10,
    "retry_count": 3,
    "retry_delay_ms": 500,
    "rate_limit_ms": 300
  },
  "cache": {
    "enabled": true,
    "ttl_minutes": 30,
    "max_size_mb": 500,
    "auto_cleanup": true
  },
  "paths": {
    "data_dir": "数据文件/",
    "output_dir": "output/",
    "log_dir": "logs/",
    "temp_dir": "_temp/"
  }
}
```

### 3.2 .env 结构约定（敏感信息）

```
# API 密钥（如有）
TIELV_API_KEY=

# 数据库连接（如有）
TIELV_DB_HOST=
TIELV_DB_PORT=
TIELV_DB_USER=
TIELV_DB_PASS=

# 调试开关
TIELV_DEBUG=false

# 代理配置（如有）
HTTP_PROXY=
HTTPS_PROXY=
```

### 3.3 配置文件管理规则

- config.json 提交到版本控制（不含敏感信息）
- .env 绝不提交到版本控制（已在 .gitignore 中）
- .env.example 作为模板提交，标注各变量的用途
- 配置文件修改后必须同步更新文档
- 变更前备份当前配置文件

## 四、环境隔离方案

### 4.1 Python 隔离

```
方案：venv + requirements.txt 精确版本锁定

隔离层级：
  L1：操作系统级别 —— Python 基础安装
  L2：项目级别 —— .venv 虚拟环境
  L3：会话级别 —— activate/deactivate
```

### 4.2 PowerShell 模块版本锁定

```
策略：依赖内置 cmdlet，避免外部模块版本问题

如有必要使用外部模块时：
  1. 在脚本中使用 #Requires -Version 声明
  2. 使用 RequiredVersion 参数安装特定版本
  3. 在模块清单 (.psd1) 中声明版本
```

### 4.3 Git 分支隔离

```
分支策略（详见项目 Git 工作流）：
  main       —— 稳定发布版本
  master     —— 开发主线
  feature/*  —— 功能开发分支
  hotfix/*   —— 紧急修复分支
```

## 五、环境健康检查清单

### 5.1 每日快速检查（启动前）

| 检查项 | 方法 | 预期结果 | 异常处理 |
|:-------|:-----|:--------|:--------|
| Python 版本 | `python --version` | 3.9+ | 切换 Python 版本/激活正确 venv |
| pip 可用性 | `pip --version` | 正常输出版本 | 重新安装 pip |
| 关键包导入 | `python -c "import numpy"` | 无报错 | 重新安装依赖 |
| PowerShell 版本 | `$PSVersionTable.PSVersion` | 5.1+ | 升级 PS 或使用 PS7 |
| 执行策略 | `Get-ExecutionPolicy` | RemoteSigned | 调整执行策略 |
| 磁盘空间 | `Get-PSDrive C` | >1GB 可用 | 清理缓存/临时文件 |
| 工作目录 | `Get-Location` | 项目根目录 | 切换到正确目录 |

### 5.2 每周深度检查

| 检查项 | 方法 | 预期结果 |
|:-------|:-----|:--------|
| pip 包版本一致性 | `pip check` | No broken requirements |
| 过期包列表 | `pip list --outdated` | 记录而不盲目升级 |
| 缓存目录大小 | `Get-ChildItem -Recurse` | <500MB 或已配置上限 |
| 编码一致性 | 检查脚本文件编码 | 全部 UTF-8 |
| API 连通性 | 分别测试腾讯/新浪/东财 | 3/3 可达 |
| 报告生成能力 | 完整跑一次报告生成 | 成功产出 DOCX+HTML |

```

  $PSVersionTable.PSVersion                # 确认 5.1+
  Get-ExecutionPolicy                      # 确认 RemoteSigned 或更宽

第 7 步：验证脚本可运行
  # 选择一个轻量脚本测试
  # 例如运行 API 连通性测试

第 8 步：配置环境变量
  # 根据需要设置 PYTHONPATH、TIELV_ENV 等

第 9 步：运行完整冒烟测试
  # 数据获取 → 评分引擎 → 报告生成 → 输出检查

  # 将实际安装的版本记录到环境配置说明文件
```

- [ ] `python --version` 输出 3.9+

## 七、常见环境问题速查

### 7.1 Python 相关

| 问题 | 症状 | 解决方案 |
|:-----|:-----|:--------|
| 多版本 Python 冲突 | `python` 指向错误版本 | 调整 PATH 顺序或使用 py launcher |
| venv 激活失败 | 执行策略限制 | `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser` |
| pip 安装超时 | 网络问题 | 使用国内镜像：`pip install -i https://pypi.tuna.tsinghua.edu.cn/simple` |
| 缺少 Visual C++ 组件 | numpy 安装失败 | 安装 Visual C++ Redistributable |
| 编码错误 | UnicodeDecodeError | 确保所有文件 UTF-8，设置 `$OutputEncoding` |

### 7.2 PowerShell 相关

| 问题 | 症状 | 解决方案 |
|:-----|:-----|:--------|
| 脚本无法执行 | PSSecurityException | `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser` |
| 中文乱码 | 输出显示乱码 | 设置 `[Console]::OutputEncoding = [Text.Encoding]::UTF8` |
| 路径空格问题 | 文件找不到 | 使用引号包围路径或使用 `&` 操作符 |
| 命令找不到 | 未在 PATH 中 | 使用完整路径或添加到 PATH |

### 7.3 网络/API 相关

| 问题 | 症状 | 解决方案 |
|:-----|:-----|:--------|
| 所有 API 超时 | 网络不通 | 检查网络连接、防火墙、代理设置 |
| 单个 API 超时 | 特定源不可用 | 触发 1+2 降级路径 |
| SSL 证书错误 | SSL:CERTIFICATE_VERIFY_FAILED | 更新 certifi 包或检查系统时间 |
| DNS 解析失败 | 域名无法解析 | 检查 DNS 设置，尝试 nslookup |

## 八、环境配置变更记录规范

每次环境变更必须在以下位置记录：
1. **`.claude/agents/红枫-知识库/01-环境配置管理.md`**（本文件）：更新对应章节
2. **项目 `CHANGELOG.md`**：记录操作类环境变更
3. **Git 提交信息**：注明环境变更内容和原因

变更记录模板：
```
## 环境变更 — YYYY-MM-DD
- 变更类型：[Python升级 / 新增依赖 / 配置修改 / 路径调整]
- 变更内容：具体改了什么
- 变更原因：为什么改
- 回滚方式：怎么退回去
- 影响范围：哪些脚本/流程受影响
- 验证结果：怎么确认变更成功
```
