## 一、备份对象与策略

| 备份对象 | 频率 | 保留份数 | 备份方式 | 存储位置 |
|:--------|:----:|:-------:|:--------|:--------|
| Git仓库(代码+配置) | 每次commit | Git历史全量 | `git push` | 远程仓库 |
| 白皮书(.md/.docx) | 每日 | 30份 | 文件复制 | `历史数据/backup/白皮书/` |
| 历史数据(缓存/行情) | 每日 | 7份(滚动) | 文件复制 | `历史数据/backup/数据/` |
| 审计报告 | 每周 | 52份 | 文件复制 | `历史数据/backup/审计/` |
| 配置文件(.claude/) | 每次变更 | 30份 | 文件复制 | `历史数据/backup/配置/` |
| 临时报告 | 每月 | 12份 | 文件复制 | `历史数据/backup/临时报告/` |
| 环境配置快照 | 每次变更 | 30份 | 本文档自身 | `历史数据/backup/环境/` |

## 二、每日备份操作 (D06任务)

### 自动备份脚本骨架
```powershell
# backup_daily.ps1 — 每日备份脚本
param(
    [string]$BackupRoot = "$PSScriptRoot\..\..\历史数据\backup",
    [int]$RetentionDays = 7
)

$Date = Get-Date -Format "yyyy-MM-dd"
$BackupDir = Join-Path $BackupRoot $Date

# 1. 创建今日备份目录
New-Item -ItemType Directory -Path $BackupDir -Force | Out-Null

# 2. 备份缓存数据
$CacheDir = Join-Path $PSScriptRoot "..\..\历史数据\缓存"
if (Test-Path $CacheDir) {
    Copy-Item -Path $CacheDir -Destination (Join-Path $BackupDir "缓存") -Recurse -ErrorAction SilentlyContinue
}

# 3. 备份行情数据
$MarketDir = Join-Path $PSScriptRoot "..\..\历史数据\行情"
if (Test-Path $MarketDir) {
    Copy-Item -Path $MarketDir -Destination (Join-Path $BackupDir "行情") -Recurse -ErrorAction SilentlyContinue
}

# 4. 清理过期备份(滚动删除)
$OldBackups = Get-ChildItem -Path $BackupRoot -Directory | Where-Object { $_.Name -match "^\d{4}-\d{2}-\d{2}$" -and $_.LastWriteTime -lt (Get-Date).AddDays(-$RetentionDays) }
$OldBackups | Remove-Item -Recurse -Force -ErrorAction SilentlyContinue

Write-Output "备份完成: $BackupDir"
Write-Output "清理过期备份: $($OldBackups.Count) 份"
```

## 三、恢复操作

### 3.1 单个文件恢复

```powershell
# 查找备份
Get-ChildItem -Path "历史数据/backup" -Recurse -Filter "目标文件名"

# 恢复
Copy-Item -Path "历史数据/backup/YYYY-MM-DD/目标文件" -Destination "原始位置" -Force
```

### 3.2 整日数据恢复

```powershell
# 恢复到最近一次成功备份
$LatestBackup = Get-ChildItem -Path "历史数据/backup" -Directory | 
    Where-Object { $_.Name -match "^\d{4}-\d{2}-\d{2}$" } | 
    Sort-Object Name -Descending | 
    Select-Object -First 1

Copy-Item -Path $LatestBackup.FullName\* -Destination "历史数据/" -Recurse -Force
```

### 3.3 Git恢复(代码/配置)

```bash
# 查看最近提交
git log --oneline -20

# 恢复到特定commit(不改工作区)
git checkout <commit-hash> -- <file-path>

# 撤销未提交的更改
git checkout -- <file-path>

# 完全回滚(慎重！需要用户确认)
git revert <commit-hash>
```

### 3.4 缓存重建

```powershell
# 如果缓存损坏：
# 1. 删除损坏缓存
Remove-Item -Path "历史数据/缓存/*.json" -Force -ErrorAction SilentlyContinue

# 2. 运行缓存预热脚本(如有)
powershell -File "代码文件/预缓存/precache.ps1"

# 3. 或在下一次数据采集时自动重建

# 4. 若无预热脚本，手动拉取：
powershell -File "代码文件/每日荐股/scripts/batch_data_collector.ps1"
```

## 四、灾难恢复清单

完整灾难恢复按此顺序执行：

```
1. [ ] Git恢复 → git pull 或 git checkout 到正常版本
2. [ ] 环境检查 → 对照环境配置快照(红枫-知识库/05)检查依赖
3. [ ] 配置恢复 → 恢复.claude/目录下的配置文件
4. [ ] 数据恢复 → 从最近备份恢复缓存和行情数据
5. [ ] 缓存重建 → 运行预热脚本重建缓存
6. [ ] API验证 → 玉夜巡检验证所有数据源连通
7. [ ] 评分验证 → 新安运行Golden Master验证
8. [ ] 任务恢复 → 重新注册Task Scheduler任务
9. [ ] 报告测试 → 生成一天报告，对比基准
```

## 五、备份完整性验证

每周红枫执行一次备份完整性检查：

```powershell
# 验证最近备份
$LatestBackup = Get-ChildItem -Path "历史数据/backup" -Directory | Sort-Object Name -Descending | Select-Object -First 1

# 检查关键文件是否存在
$Checks = @(
    (Test-Path (Join-Path $LatestBackup.FullName "缓存")),
    (Test-Path (Join-Path $LatestBackup.FullName "行情"))
)

if ($Checks -contains $false) {
    Write-Output "⚠ 备份不完整！缺失: $($Checks.IndexOf($false))"
}

# 检查备份大小(与上次对比)
$Size = (Get-ChildItem -Path $LatestBackup.FullName -Recurse | Measure-Object -Property Length -Sum).Sum
Write-Output "备份大小: $([math]::Round($Size/1MB, 2)) MB"
```

## 六、维护规则

- 每日备份由Task Scheduler D06任务自动执行
- 每次部署前红枫验证最近备份完整性
- 恢复操作后记录恢复日志(时间/原因/恢复范围/验证结果)
- 备份失败时D06通知玉夜告警通道
