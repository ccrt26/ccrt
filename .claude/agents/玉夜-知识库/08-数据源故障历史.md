---

## 一、故障记录格式

每次数据源故障按以下模板记录：

```
【故障#YYYYMMDD-NN】
时间：[开始] ~ [恢复] (持续X小时Y分钟)
来源：[编号] 来源名称
现象：[具体报错/超时/数据异常]
影响范围：[哪些功能/报告受影响]
根因：[API侧/网络侧/代码侧——具体原因]
降级路径：[主→备→缓存，实际走的路径]
恢复动作：[自动恢复/手动切换/代码修复]
教训：[预防措施/监控增强/降级路径优化]
```

## 六、维护规则

- 每次故障发生后即时记录
- 每周玉夜巡检时更新趋势分析段
- 每季度汇总故障统计
- 同一源连续3次故障→触发玉夜告警，需给出替代方案
