# 09-突破性质分类

## 一、为什么需要突破性质分类

放量突破关键位（52周新高、均线压力、横盘区上沿）是强技术信号，但后续走势高度依赖于**突破的性质**：

- **基本面驱动突破**：盈利改善+资金确认 → 胜率高，可持续
- **纯资金驱动突破**：无基本面支撑 → 胜率中等，需紧止损
- **纯动量突破**：无基本面+无资金确认 → 胜率低，大概率假突破

外部批评指出东睦股份5/21-22突破被误判为"散户追涨"，本质是缺少突破性质分类节点。本文件建立分类标准和操作映射。

## 二、突破性质分类决策树

```
放量突破发生（成交额 > 20日均量1.5倍 + 价格突破52周新高或关键阻力位）
  ↓
检查1: 基本面因子正向？
  条件：ROE>10% + 毛利率趋势↑ + 扣非=基本 + 经营现金流>0
  ├─ 否 → 检查2: 资金因子正向？
  │       条件：连续3日主力净流入
  │        ├─ 否 → 【纯动量突破】
  │        └─ 是 → 【资金驱动突破】
  └─ 是 → 检查2: 资金因子正向？
           ├─ 否 → 【基本面突破(无资金确认)】
           └─ 是 → 【质量+动量共振突破】
```

## 三、四种突破类型的操作映射

| 突破类型 | 基本面 | 资金 | 操作建议 | 仓位上限 | 止损 |
|:--------|:----:|:--:|:--------|:------:|:---:|
| **质量+动量共振** | ✅ | ✅ | 持有+可加仓 | 16% | 正常止损(跳空缺口/MA10) |
| **基本面突破(无资金)** | ✅ | ❌ | 持有，等资金确认后加仓 | 12% | 正常止损 |
| **资金驱动突破** | ❌ | ✅ | 轻仓试探 | 8% | 紧止损(5%) |
| **纯动量突破** | ❌ | ❌ | ⛔不参与/减仓 | 0% | 现有持仓设5%紧止损 |

### 3.1 质量+动量共振突破（最优）

**特征**：基本面扎实 + 主力资金确认 + 放量突破关键位

**操作**：
- 现有持仓：持有，移动止盈至突破位下方2-3%
- 加仓：可在突破确认后(次日不跌回)加仓至16%上限
- 止损：跳空缺口下沿或MA10
- **例外**：RSI>80时，不加仓（技术面否决）

### 3.2 基本面突破（无资金确认）

**特征**：基本面好但主力资金尚未跟进

**操作**：
- 持有现有仓位
- 不加仓，等待资金确认（连续2日主力净流入）
- 若连续3日仍无资金确认 → 突破有效性存疑，减至半仓

### 3.3 资金驱动突破

**特征**：资金在买但基本面弱（题材股、扭亏股、ST摘帽等）

**操作**：
- 无仓位：轻仓试探(≤8%)，设紧止损(5%)
- 有仓位：不追加，设紧止损
- 连续2日主力流出 → 立即清仓
- 不适合中长期持有

### 3.4 纯动量突破（最差）

**特征**：无基本面支撑 + 无资金确认

**操作**：
- ⛔ **禁止开新仓**
- 现有持仓：设5%紧止损，任一交易日收盘低于突破位 → 立即清仓
- 这通常是消息刺激、散户跟风或大盘普涨带动的假突破

## 四、突破确认的三日观察窗口

突破发生后，用3个交易日确认有效性：

| 第N日 | 观察项 | 合格标准 |
|:----:|:------|:-------|
| T+0 | 突破日收盘 | 收盘价站稳突破位上方 |
| T+1 | 次日走势 | 不跌回突破位下方，成交量不萎缩至<日均50% |
| T+2 | 资金确认 | 主力资金方向与突破方向一致（放量上涨→主力净流入） |
| T+3 | 最终确认 | 三日收盘均在突破位上方 → 突破有效 |

任一日不满足 → 突破存疑，降级操作（如质量+动量共振降为基本面突破）

## 五、与现有框架的整合

- **Wyckoff周期定位**（腰子知识库03）：突破性质分类叠加在Wyckoff阶段判断之上。Markup阶段的质量+动量共振置信度最高
- **五红旗过拟合检查**（流金知识库04）：纯动量突破自动触发红旗③（高波动）审查
- **RSI超买否决**：RSI>80时，无论哪种突破类型，均不加仓
- **仓位公式**：突破类型决定仓位上限的基准值，ATR折扣在此基础上叠加
