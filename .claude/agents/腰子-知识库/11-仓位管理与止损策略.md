## 一、仓位管理的核心问题

仓位管理回答量化交易中最现实的问题：**每次下注多少，才不会在一次坏运气中死掉？**

很多人花99%的精力研究"买什么"，只花1%的精力想"买多少"。这是一个致命的倒置。在A股T+1、涨跌停的环境下，你已经知道今天会跌停，而仓位决定了你今天亏多少。

### 1.1 仓位管理的三个层面

| 层面 | 问题 | 项目中的对应 |
|:-----|:-----|:-----------|
| 组合层面 | 总资金多少比例参与市场？ | 大盘环境判断 → 仓位上限调整 |
| 个股层面 | 单只股票分配多少资金？ | 五档评分→仓位映射 |
| 动态层面 | 连续亏损/盈利后怎么调整？ | 三级响应机制 + 冷却期规则 |

## 二、凯利公式（Kelly Criterion）

### 2.1 经典公式

```
f* = p - (1-p) / b

其中：
f* = 最优仓位比例（占资金的比例）
p  = 胜率（盈利概率）
b  = 盈亏比（赔率，即平均盈利 / 平均亏损）
```

### 2.2 推导示例

胜率50%，盈亏比2:1（每次盈利赚2元，每次亏损亏1元）：
```
f* = 0.5 - (1-0.5)/2 = 0.5 - 0.25 = 0.25
```
最优仓位为每次下注25%的资金。

### 2.3 凯利的数学直觉

凯利公式最大化的是**长期对数增长率**，而非单次期望收益。这背后的逻辑是：

- 如果每次下注100%：一次亏损就清零，长期增长率为负无穷
- 如果每次下注0%：永远不会亏，但也永远不赚，增长率为0
- 如果每次下注f*：在风险与收益之间找到最优平衡，长期增长率最大

凯利的神奇之处：它计算的不是"怎么赚最多"，而是"怎么在不爆仓的前提下赚最多"——这两个问题完全不同。

### 2.4 凯利公式的致命缺陷

**缺陷一：凯利假设你确切知道p和b**

实际上，你永远不知道真实的胜率和盈亏比。你只有"估计值"——而估计值本身就包含误差。如果你估计的胜率是60%（实际只有55%），你用凯利算出的仓位会系统性偏高。

**缺陷二：凯利的波动极大**

凯利仓位对应的资金曲线波动剧烈——可能连续出现30-40%的回撤。这在数学上是最优的，但在心理学上是不可接受的。很少有人能承受自己40%的钱消失了一个月。

**缺陷三：凯利假设单次独立下注**

实际交易中，仓位间不是独立的——两只同板块的股票高度相关，同时下注相当于超配了这个板块。凯利没有考虑相关性。

### 2.5 实践中用"分数凯利"

| 倍数 | 仓位 | 特点 |
|:----:|:----:|:-----|
| 全凯利（f*） | 100% | 数学最优但波动巨大，几乎没人能坚持 |
| 半凯利（f*/2） | 50% | 长期增长率为全凯利的75%，但波动减半 |
| 四分之一凯利（f*/4） | 25% | 长期增长率为全凯利的55%，波动更小，实际中最常用 |

**项目的五档仓位（最高25%）本质上接近四分之一凯利。** 这是一个保守但务实的选择。

## 三、固定分数法

### 3.1 方法

每次下注固定比例的当前资金：
```
下注金额 = 当前总资金 × 固定比例（如2%）
```

### 3.2 优缺点

| 优点 | 缺点 |
|:-----|:-----|
| 极其简单，不会算错 | 不考虑当前机会的质量差异 |
| 永远不会一次亏光 | 好机会和差机会下注一样多 |
| 心理上容易坚持 | 可能错过极好的机会 |

### 3.3 与项目的关系

项目的仓位管理不是纯固定分数法——它按评分分档（≥80→25%、≥65→20%、≥45→10%、≥30→5%、<30→0%），本质上是在固定分数法的基础上加入了"信号强度加权"。评分高（信号强）→仓位高，评分低（信号弱）→仓位低。

这是一个合理的设计，前提是**评分本身有区分度**——如果评分与未来收益负相关（Spearman=-0.436），那么"高评分→高仓位"就变成了"高评分→高亏损"。

## 四、项目的仓位管理体系

### 4.1 五档评分→仓位映射

| CompositeScore | 仓位比例 | 说明 |
|:--------------:|:--------:|:-----|
| ≥ 80 | 25% | 强烈关注，重点配置 |
| ≥ 65 | 20% | 关注，正常配置 |
| ≥ 45 | 10% | 观察，轻仓试探 |
| ≥ 30 | 5% | 谨慎，极轻仓 |
| < 30 | 0% | 回避，不参与 |

来源：模拟交易白皮书v1.4 §2.3

### 4.2 仓位计算规则

- 仓位比例 = 占**当前现金**的百分比（非总资产）
- 买入股数向下取整到100股（一手）
- 单只股票买入金额不超过总资产的30%（SingleStockLimitPct）
- 若计算所得股数不足100股，跳过该股开仓

### 4.3 组合层面约束

| 约束 | 默认值 | 目的 |
|:-----|:------|:-----|
| 最大同时持仓 | 3只 | 分散风险 + 保证信号质量（只选最好的） |
| 单股上限 | 30%总资产 | 防止个股踩雷 |
| 最大回撤预警 | 8% | 超过后红旗警告，建议暂停开仓 |

### 4.4 仓位阶梯的设计原理

阶梯跳跃（评分64→10%、评分65→20%）看似粗糙，但有两层考虑：
1. **操作简化**：避免每次都为"评分63和64该差多少仓位"而纠结
2. **统计上合理**：仓位差异小于5%时（如20% vs 22%），实际执行中滑点和费用已经抹平了这个差异，没有意义的精度是伪精度

但阶梯跳跃也有风险：评分64和65的股票，仓位从10%跳到20%，差异翻倍。如果评分在阈值附近有系统性偏差（如总是在牛市中偏高），会导致仓位系统性偏高。

## 五、止损策略

### 5.1 止损的本质

止损不是"认输"，而是**承认之前的判断可能出错，以可控的成本了结错误**。每个交易员都会做错单。区别在于：好的交易员错得快、错得小；差的交易员错得慢、错得大。

### 5.2 四大止损方法

#### 方法一：固定百分比止损

```
止损价 = 入场价 × (1 - 止损%)
```

项目的硬止损是-7%（一票退出条件之一）。当亏损达到-7%时，无论技术面、资金面、基本面如何，强制退出。

| 优点 | 缺点 |
|:-----|:-----|
| 简单明确，不会犹豫 | 不考虑个股波动率差异 |
| 最大亏损事前已知 | 高波动股容易被"正常波动"扫出 |
| 所有股票一视同仁 | 低波动股止损过宽，亏得多 |

#### 方法二：ATR动态止损

```
止损价 = 入场价 - N × ATR(14)

其中：
ATR(14) = 最近14日的真实波动幅度均值（True Range）
```

项目默认N=2（模拟交易v1.4 §2.5.2）。止损硬上限为-8%（即使ATR计算出的止损>8%，也只取8%）。

| 优点 | 缺点 |
|:-----|:-----|
| 自适应个股波动率 | 宽止损→单次亏损更大 |
| 不会因正常波动被扫出 | ATR在极端行情时滞后（突然放大的波动需要14日才能反映在ATR中） |
| 科学性更强 | 不同N值结果差异大，N的选择本身需要优化 |

**ATR止损 vs 固定百分比止损的选择**：
- 横盘震荡市：ATR止损更优——波动小，固定止损可能过宽
- 剧烈波动市：固定止损更优——ATR滞后，止损调整不及时
- 低波动大盘股：两者差异不大
- 高波动小盘股：ATR止损更优——固定7%对高波动股来说等于"一买就准备止损"

#### 方法三：移动止损（跟踪止损 Trailing Stop）

```
止损价 = max(止损价, 持仓期间最高价 × (1 - 回撤比例))
```

止损价跟随价格上涨而上移，从不下降。当价格从最高点回落超过一定比例时触发退出。

**项目中没有直接使用跟踪止损，但有等价机制：**
- P4全部止盈（价格≥R3=入场价×1.10→全额卖出）功能类似于"涨10%就锁定全部利润"
- -7%硬止损配合ATR动态止损——止损价在入场后一般不调整，但价格大幅上涨后实际上已经远离了止损价

#### 方法四：时间止损

```
如果持仓超过N天仍未盈利 → 退出
```

项目的EUS退出机制中有两个一票退出条件使用了时间止损逻辑：
- **超15天且亏>5%** → 一票退出
- **价<MA20×0.95** → 一票退出（这个不是纯时间止损，但隐含了"趋势已经走坏"的判断）

时间止损的理论基础是**机会成本**：你的资金在这只股票上不赚不亏，但错过了其他股票的机会。同时，持仓越久信号越不可靠——你买入时依据的信号已经过了有效期。

### 5.3 项目EUS退出急迫度评分体系

来源：每日荐股v2.4 §二(五) + 附录B

**四维度加权**：

| 维度 | 权重 | 内容 |
|:-----|:---:|:-----|
| 时间因子 | 25% | 持仓天数越长→急迫度越高 |
| 盈亏状态 | 30% | 亏损→急迫度高；盈利→急迫度低 |
| 技术面 | 25% | 趋势恶化→急迫度高 |
| 资金面 | 20% | 资金流出→急迫度高 |

**决策规则**：

| EUS范围 | 操作 |
|:-------:|:-----|
| < 20 | 继续持有 |
| 20-35 | 减半仓，挂移动止盈 |
| 35-50 | 退出2/3，保留观察仓 |
| ≥ 50 | 全面退出 |

**一票退出条件**（优先级最高，触发即退出，不等EUS评分）：

| 条件 | 设计理由 |
|:-----|:---------|
| -7%硬止损 | 资金保护底线——单只股票最多亏7% |
| 超15天且亏>5% | 时间止损——15天还没解套，信号已经失效 |
| 价<MA20×0.95 | 趋势确认恶化——价格跌破20日均线5%以上 |

## 六、止损冷却期

### 6.1 项目的冷却期规则

| 触发场景 | 冷却时长 | 禁止操作 |
|:---------|:--------:|:---------|
| 止损（P1/P2/P3导致全部卖出） | 5个交易日 | 该股票不可开新仓 |
| 全部止盈（P4导致全部卖出） | 3个交易日 | 该股票不可开新仓 |

来源：模拟交易v1.4 §5

### 6.2 冷却期的统计学意义

**为什么止损后要冷却？**

"止损后冷却"防止的是**whipsaw（反复打脸）**——同一只股票刚止损又立即满足买入条件，导致连续止损。

统计学上：如果你连续两次在同一只股票上止损，你会产生心理上的"报复交易"倾向——加倍赌它反弹。冷却期强制你冷静下来，用时间换理性。

**为什么止盈后也要冷却？**

全部止盈后股价往往处于短期超买状态——你赚了10%走了，立即重新入场相当于在比之前高10%的位置买入，追高风险极大。3日冷却期给你一个冷静期：如果3天后信号依然在，再考虑重新入场。

**为什么是5日和3日？**

5日约等于一个交易周，这个时长：
- 足够短，不会错过真正的趋势延续（如果真的继续涨，5天后信号应该还在）
- 足够长，足以过滤假突破（假突破通常在1-3日内就会反向）
- 基于经验而非严格数学推导——更短或更长都是合理的，取决于策略的时间框架

**如果缩短为2日会有什么风险？**

当止损信号来自短期噪声（如单日大单砸盘导致的跌破止损价），2日后价格可能已经恢复，但信号的质量没有改变。2日太短，whipsaw风险极高——你可能会在同一个月内对同一只股票反复止损3-4次。

## 七、连续亏损的处理

### 7.1 随机游走下的连败概率

在胜率50%的随机游走中：

| 连败次数 | 概率 | 预期发生频率（每100笔交易） |
|:-------:|:----:|:------------------------:|
| 2连败 | 25% | 25次 |
| 3连败 | 12.5% | 12.5次 |
| 4连败 | 6.25% | 6.25次 |
| 5连败 | 3.125% | 3.1次 |
| 6连败 | 1.56% | 1.6次 |
| 8连败 | 0.39% | 0.4次 |

所以：5连败在随机游走中虽然不常见（约3%），但完全在正常范围内——仅凭5连败不能断定策略失效。

### 7.2 什么时候连败意味着策略真正失效？

**统计方法**：如果连败次数超出了该胜率下的99%置信区间上限，则有理由怀疑策略失效。

以胜率50%、20笔交易为例，99%置信区间上限约7连败。如果你的策略目标是60%胜率，那么5连败就已经接近99%置信区间上限。

**项目的规则**（模拟交易v1.4 §4.4 + §9.4）：

| 连败次数 | 响应级别 | 动作 |
|:-------:|:--------:|:-----|
| 3笔 | 第一级 | 关注，不操作 |
| ≥ 5笔 | 第二级 | 红旗警告，建议暂停开仓，审视信号有效性 |
| ≥ 8笔 | 第三级 | 方法论重构触发 |

### 7.3 连续亏损计数器的逻辑

模拟交易v1.4 §4.5定义了计数规则：
- 单笔完整平仓后，净盈亏>0 → 计数器重置为0
- 净盈亏≤0 → 计数器+1（保本也计入失败）
- P5止盈减仓（卖一半）→ 不计入统计
- 只有完整平仓才结算盈亏

设计理由：减仓动作无法判断该笔交易是"对了一半"还是"错了一半"，强行计入会污染连败统计。

## 八、出场优先级

### 8.1 五级优先级设计（模拟交易v1.4 §2.5.1）

| 优先级 | 出场原因 | 触发条件 | 操作 |
|:------:|:---------|:---------|:-----|
| P1 | 止损 | 当前价 ≤ KeyLevels.StopLoss | 全部卖出 |
| P2 | 趋势恶化 | TrendHealth 变为"危险" | 全部卖出 |
| P3 | 预判转空 | Short 从入场值变为"中性"或"看空" | 全部卖出 |
| P4 | 全部止盈 | 当前价 ≥ R3（入场价×1.10） | 全部卖出 + 3日冷却 |
| P5 | 止盈减仓 | 当前价 ≥ R2（入场价×1.05） | 卖出50%（向下取整到100股） |

### 8.2 优先级设计的逻辑

**P1止损永远第一**：截断亏损比锁定利润更重要。你可以在止盈上少赚1%，但止损上多亏1%就多亏了本金的1%。

**P2趋势恶化高于P3预判转空**：TrendHealth从"健康"直接变为"危险"是硬信号——趋势已经坏了，不需要等预判确认。而预判转空存在≥1日滞后（依赖日终评估数据），在趋势已经恶化时等预判确认等于白等一天。

**P4止盈高于P5止盈减仓**：到了R3（+10%）就全额退出——这是定好的目标价，到了就应该走。P5是到了R2（+5%）减仓一半——留一半看能不能到R3。

### 8.3 同一交易日多条件触发时

只执行优先级最高的一个。例如：如果股价同时触发P1止损和P5止盈减仓，只执行P1（全部卖出）。逻辑：你都要止损了，还考虑什么减仓不减仓——全出了。

## 十、自测题

**题1**：为什么凯利公式在实践中通常用"半凯利"或更保守的倍数？

**答案**：三个原因。（1）凯利假设你确切知道胜率和盈亏比，但实际上你只有估计值——估计误差会导致系统性超配仓位；（2）全凯利的资金曲线波动极大，可能连续回撤30-40%，心理上几乎无人能承受——在回撤中弃用策略的损失远大于"保守仓位少赚的钱"；（3）凯利假设交易间独立，但实际交易间存在相关性（同板块、同风格），独立假设会低估真实风险。所以实践中"四分之一凯利"比"半凯利"更常见，因为低估风险比高估收益更危险。

**题2**：ATR止损和固定百分比止损，各在什么市场环境下更优？

**答案**：ATR止损在正常波动和横盘震荡市更优——它能自适应个股波动率，避免被正常波动扫出。但在剧烈波动市（如突发事件导致波动率跳升），ATR因为使用14日平滑存在滞后，止损距离调整不及时，导致止损过窄——此时固定百分比止损反而更优（因为它"迟钝"地在极端行情中反而提供了保护）。A股的高波动特征下，两者各有优劣，项目的做法是"ATR为主（N=2），硬止损-8%为上限"——ATR负责日常，硬止损负责极端，这是一个合理的折中方案。

**题3**：止损冷却期为什么是5日？如果缩短为2日会有什么风险？

**答案**：5日≈一个交易周，这个时长的统计学意义：（1）足以让短期噪声消退——假突破通常在1-3日内反向；（2）足够短，不会错过真正的趋势延续——如果趋势真的继续，5日后信号应该还在；（3）强制情绪冷却——报复交易的冲动在5日内会消退。缩短为2日的风险：（1）whipsaw风险极高——刚止损又触发买入信号，可能同日再次止损——在同一个月对同一只股票反复止损3-4次的概率大增；（2）2日不足以确认信号是否真反弹还是假反弹；（3）冷却期的核心目的是防止"同一错误在同只股票上重复犯"——2日太短，起不到这个效果。A股T+1制度下，2日=2个交易日，这刚好是"今天止损-明天买-后天再止损"的最短路径——whipsaw的风险精确地落在了2日窗口内。

## 十一、三档试仓框架（v1.3 方法论新增）

### 11.1 定位

三档试仓框架是深度分析层面的仓位管理策略，与模拟交易层面的五档评分→仓位映射**正交叠加**，不是替代关系。

### 11.2 与现有五档评分体系的关系

| 维度 | 五档评分体系 | 三档试仓框架 |
|:-----|:----------|:----------|
| 输入 | 综合评分 (0-100) | 价格位置 + 证据等级 + 催化剂状态 |
| 粒度 | 粗: 5档 (0/5/10/20/25%) | 细: 3档 (3/8/12%) |
| 决策层 | 开仓前: "这只股票值多少仓位？" | 持仓中: "现在是建多少仓位的时候？" |
| 理论基础 | 凯利公式 + 固定分数法 | Wyckoff吸筹区 + 证据等级 + 催化剂时间线 |

**叠加规则**: 最终仓位 = min(五档评分→仓位上限, 三档当前档位仓位上限) × 折扣因子

### 11.3 三档的凯利公式解释

三档试仓本质上是对凯利公式的"分批下注"实现：
- 凯利要求你知道p(胜率)和b(盈亏比)
- 但p和b在开仓前是估计值，在价格上涨/下跌后会变化
- 分批建仓 = 随着信息增加(p和b更确定)，逐步增加下注

| 档位 | 等效凯利 | 推导 |
|:----:|:------|:-----|
| 第一档(试探仓) 3% | 四分之一凯利(p=50%, b=2 → f*=12.5%×0.25≈3%) | p=50%最不确定，仅下试探注 |
| 第二档(核心仓) 8% | 四分之一凯利(p=55%, b=2 → f*=13.75% + 首档3% ≈7%) | 价格企稳证实支撑有效，p提升至55% |
| 第三档(催化剂仓) 12% | 四分之一凯利(p=65%, b=2.5 → f*=8% + 前两档≈12%) | 催化剂落地，p大幅提升，b因溢价改善 |

**可证明**: 三档分批建仓的总期望损失 E[L] ≤ 单次满仓建仓的 E[L]，因为信息增量使后两档的条件胜率高于第一档。

### 11.4 三档触发条件的量化标准

| 档位 | 价格条件 | 技术确认信号 | 成交量要求 |
|:----:|:--------|:----------|:---------|
| 第一档 | 现价进入S0区域(近5日密集成交区) | RSI(9)<40 + 15分钟K线不再创新低(连续3根) | 缩量至5日均量×0.7以下 |
| 第二档 | 现价进入VP的VAH-VAL区间(HVN密集区) | 下影线>实体长度 + 收盘站回5日均线 | 量能开始回升(>前日1.2倍) |
| 第三档 | 催化剂事件入库(evidence_level≥L2+upgrade_flag=true) | — (以事件为准，不依赖技术信号) | — (以事件确认代替量价确认) |
