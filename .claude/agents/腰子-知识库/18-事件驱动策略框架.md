# 18 — 事件驱动策略框架

> **定位**：腰子（金融业务负责人）本地知识库 —— 将消息面评分维度升级为系统的事件驱动分析框架
> **更新**：2026-05-23 | **关联文件**：05-板块轮动与生命周期、06-估值方法、08-资金面分析、每日荐股白皮书v2.4 §消息面评分

## 一、为什么需要事件驱动框架

### 1.1 当前状态

白皮书的"消息面"维度（权重15%）目前仅基于研报覆盖数量做简单评分，缺乏对事件类型的系统分类和影响度量。实际上，A股的事件驱动机会是超额收益的重要来源。

### 1.2 事件的特殊性

事件不同于常规因子：
- **突发性**：事件通常在信息发布当日或次日产生最大冲击
- **衰减快**：事件影响的半衰期远短于基本面因子
- **方向不对称**：同类事件对大盘股/小盘股的影响方向可能相反
- **易于过度反应**：市场对事件的初始反应常有偏差，存在修正窗口

## 二、事件分类体系

### 2.1 四级事件分类

#### A类 — 公司层面事件

| 子类型 | 示例 | 典型方向 | 影响周期 | A股频率 |
|:------|:-----|:------:|:--------|:------:|
| 业绩预告/快报 | 季度预增/预减/预亏 | 同向 | 1-5日 | 季报季高发 |
| 重大合同/中标 | 中标金额>年营收20% | 正向 | 1-3日 | 不定期 |
| 并购重组 | 资产注入、借壳上市 | 正向为主 | 3-20日 | 政策周期驱动 |
| 股权激励 | 限制性股票/期权授予 | 正向 | 3-10日 | 不定期 |
| 定增/配股 | 再融资方案 | 定向(折价偏负/战投偏正) | 1-5日 | 不定期 |
| 股东增减持 | 大股东增持(正)/减持(负) | 同向 | 1-3日 | 解禁前后高发 |
| 分红送转 | 高送转、特别分红 | 正向 | 1-3日 | 年报季高发 |
| 管理层变更 | CEO/CFO/董事长更替 | 不定向 | 1-5日 | 不定期 |
| 诉讼/处罚 | 证监会立案、重大诉讼 | 负向 | 3-20日 | 不定期 |

#### B类 — 行业层面事件

| 子类型 | 示例 | 影响范围 | 影响周期 |
|:------|:-----|:--------|:------:|
| 产业政策 | 新能源补贴、半导体扶持 | 全行业 | 1-6个月 |
| 监管政策 | 反垄断、数据安全法 | 全行业 | 1-12个月 |
| 技术突破 | 创新药获批、芯片制程突破 | 行业+上下游 | 1-3个月 |
| 行业供需变化 | 稀土配额、猪肉收储 | 全行业 | 1-6个月 |
| 关税/贸易壁垒 | 欧盟反倾销、美国实体清单 | 出口导向行业 | 3-12个月 |

#### C类 — 市场层面事件

| 子类型 | 示例 | 影响范围 | 影响周期 |
|:------|:-----|:--------|:------:|
| 指数成分调整 | 沪深300/中证500调样 | 调入(+)/调出(-) | 调整日前后3日 |
| MSCI/富时调整 | A股权重变化 | 全市场/被调整个股 | 生效日前后5日 |
| 期指交割 | 每月第三个周五 | 日内波动放大 | 当日 |
| 解禁高峰 | 大额限售股解禁 | 个股/板块 | 解禁前1周→后1周 |
| IPO节奏变化 | 发行提速/暂缓 | 全市场(流动性虹吸) | 持续 |

#### D类 — 宏观层面事件

| 子类型 | 示例 | 影响范围 | 影响周期 |
|:------|:-----|:--------|:------:|
| 央行政策 | 降准/降息/LPR调整 | 全市场 | 1日-3个月 |
| 经济数据超预期 | GDP/CPI/PMI/社融 | 全市场/结构分化 | 1-5日 |
| 国际事件 | 美联储加息、G20峰会 | 全市场 | 1-10日 |
| 地缘政治 | 军事冲突、制裁升级 | 全市场+军工/能源 | 1-30日 |

## 三、影响度量模型

### 3.1 事件影响 = 方向 × 幅度 × 概率 × 市值系数

```
Impact = Direction × Magnitude × Probability × Cap_Adjust

Direction: +1(利好), -1(利空), 0.5(偏多), -0.5(偏空), 0(中性)
Magnitude: 基于历史同类事件的平均涨跌幅(abs值)
Probability: 事件发生的确定性(0-1)
Cap_Adjust: 小盘1.5 / 中盘1.0 / 大盘0.7 / 蓝筹0.5
  (小盘股对事件的反应更剧烈，白皮书v3.0 §1.3.1)
```

### 3.2 事件影响的时间线

```
事件时间线：

T-X日    T日       T+1日    T+2~5日   T+6~20日
  │       │         │         │         │
预告/传闻  事件公布   市场定价   修正/过度   影响消退
  │       │         │         │         │
  ├─ 部分定价  ├─ 最大冲击  ├─ 方向确认  ├─ 均值回复
  │          │          │         │
  └─ 信息泄露?  └─ 成交量峰值  └─ 判断是否过度反应
```

### 3.3 过度反应的识别

| 指标 | 过度反应信号 | 测量方法 |
|:-----|:----------|:--------|
| 日内振幅 | >10%(小盘)/>5%(大盘) | 最高/最低 vs 开盘 |
| 成交量异常 | 5日均量的3倍以上 | 当日成交量/5日均量 |
| 关联股联动 | 板块内所有股票同向，无论基本面 | 板块内涨跌比>90%或<10% |
| 次日反转 | 事件日方向与次日方向相反且次日幅度>50% | T日方向 vs T+1日方向 |

**过度反应后的修正交易**：
- 利好+过度上涨 → T+2~3日可能回撤30-50%的初始涨幅 → 短线逆势做空窗口
- 利空+过度下跌 → T+2~3日可能反弹30-50%的初始跌幅 → 短线抄底窗口

## 四、A股特有的事件特征

### 4.1 中国特色事件类型

| 事件 | 特征 | 分析要点 |
|:-----|:-----|:--------|
| 国企改革/混改 | 政策驱动、信息提前泄露常见 | 关注国资委/发改委文件时间线 |
| 高送转行情 | 年报季活跃，近年受监管压制 | 监管问询函是反向信号 |
| ST摘帽 | *ST→正常，摘帽前常提前炒作 | 关注年报审计意见+净资产转正 |
| 借壳上市 | 注册制后减少，但仍存在 | 关注控制权变更+资产注入公告 |
| 两会行情 | 每年3月，政策预期炒作 | 关注政府工作报告关键词变化 |
| 限电/双控 | 2021年后成为季节性风险 | 关注夏季/冬季用电高峰+发改委预警 |

### 4.2 A股事件的信息不对称特征

- **内幕交易普遍性**：重大公告前股价常已异动（统计上，A股重大资产重组公告前20日平均超额收益+5.8%）
- **媒体先行**：财联社/上海证券报等官媒具有"吹风"功能
- **监管问询**：交易所问询函本身即为重要事件信号(尤其是年报问询函)

## 五、事件数据库设计

### 5.1 事件记录格式

```json
{
  "event_id": "EVT_20260523_0001",
  "date": "2026-05-23",
  "type": "A-业绩预告",
  "subtype": "预增",
  "code": "601689",
  "name": "拓普集团",
  "description": "2026年中报业绩预告：归母净利润预增50-70%",
  "direction": 1,
  "magnitude_expected": 3.5,
  "magnitude_actual": null,
  "probability": 1.0,
  "cap_adjust": 0.7,
  "impact_score": 2.45,
  "expiry_date": "2026-06-05",
  "source": "巨潮资讯网",
  "notes": "超市场一致预期(预增35-45%)"
}
```

### 5.2 事件跟踪字段

- **impact_score** = direction × magnitude × probability × cap_adjust
- **actual_impact**：事件公布后5日实际涨跌幅（事后回填）
- **surprise** = actual_impact - expected_impact
- 正surprise → 市场反应强于历史均值 → 评估事件评级上调
- 负surprise → 市场反应弱于历史均值 → 事件被充分定价或市场不认可

## 六、与现有流程的整合

### 6.1 每日荐股中的应用

```
盘前Sentinel宏观简报
    ↓
Pulse数据巡检
    ↓
腰子分析 → 新增：扫描6只重点股票的事件日历
    │         - 未来3天是否有重大事件？
    │         - 近期事件的实际影响是否匹配预期？
    │         - 是否有未定价的事件机会？
    ↓
Vega风险评估 → 新增：事件风险敞口(单只股票事件集中度)
```

### 6.2 模拟交易中的事件规则

| 规则 | 内容 |
|:-----|:-----|
| 财报前静默 | 财报公布前3个交易日不开新仓（白皮书v3.0 §6.5不做清单） |
| 事件后冷却 | 重大事件公布后1个交易日等待市场完全定价 |
| 事件仓位调整 | 即将公布重大事件→仓位上限减半；事件公布且方向确认→恢复正常 |
| 事件止损松动 | 重大事件公布当日，S3止损价临时放宽10%（避免事件当日剧烈波动误触止损） |

### 6.3 事件对综合评分的影响

当前消息面权重15%仅基于研报覆盖。引入事件框架后：

```
消息面评分(v2) = 研报覆盖分(50%) + 事件影响分(50%)

事件影响分计算：
  - 扫描过去5日和未来3日的事件日历
  - 对每个事件计算 impact_score
  - 汇总：正向事件加权和 - 负向事件加权和 → 归一化到0-100
```
