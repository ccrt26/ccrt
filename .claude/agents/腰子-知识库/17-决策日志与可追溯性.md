# 17 — 决策日志与可追溯性

> 腰子知识库第17号 | 2026-05-23
> 定位：让腰子的每一个重要决策都可回溯、可复盘、可优化

---

## 一、为什么需要决策日志

人的记忆会骗自己。赚了钱记成"我判断准"，亏了钱记成"运气不好"。

决策日志的核心功能：**把决策时的信息和逻辑冻住**，事后复盘时不被结果带偏。

这个机制直接解决行为金融六大偏差中的三个：
- **后见之明**："我早就知道会这样" ← 日志告诉你当时并不知道
- **确认偏误**："我当时就是这样判断的" ← 日志告诉你当时其实犹豫了
- **自我归因**：赚钱归自己，亏钱归市场 ← 日志让过程透明

---

## 二、什么情况下必须写决策日志

| 场景 | 必须记录 | 原因 |
|:-----|:-------:|:-----|
| 团队成员意见不统一 | ✓ | 存在冲突→事后最需要回溯 |
| 新开仓 | ✓ | 核心决策，必须可追溯 |
| 提前止盈/止损（非机械触发） | ✓ | 主动干预→需要理由 |
| 否决了某方专家的明确建议 | ✓ | 信息不对称的决策点 |
| 市场状态判断发生切换 | ✓ | 大级别判断变化 |
| 机械化执行（评分够了就买，止损到了就卖） | ✗ | 规则驱动，无需额外记录 |
| 日常盘前检查 | ✗ | 例行公事 |

## 四、决策日志的使用方式

### 4.1 频率

不是每笔交易都写——只写"有判断含量的决策"。预计每周1-3条。

### 4.2 月度复盘

每月底翻看当月所有决策日志，问自己三个问题：

1. **有没有系统性错误？** 比如每次都在"弱势市场给了Alpha太高权重"——这是个需要修正的裁决倾向
2. **有没有漏掉的信息？** 多次出现"没咨询Vega"的日志→以后每次做类似决策要提醒自己叫Vega
3. **Pre-mortem里反复出现的风险是什么？** 如果连续三次都写到"最怕流动性风险"→可能需要系统性地降低流动性差的标的的仓位

### 4.3 与后评估的对接

每月后评估报告中增加"决策质量"维度：
- 有决策日志的决策 → 胜率 = ?
- 没有决策日志的机械化执行 → 胜率 = ?
- 对比：有人工判断参与的决策，是否比机械执行更优？

如果半年数据显示"腰子的主动判断不如机械执行"→ 说明应该减少主动干预，更多依赖规则。这不是失败，这是进步。

## 五、简易版（日常快速填写）

日常不需要填完整模板，用这个30秒版本：

```
#DD-YYYYMMDD 开/平 [标的] [方向]
意见：Sentinel__ Pulse__ Vega__ Alpha__
冲突：有/无 → 最高权重给____
Pre-mortem：最怕____
决定：____
```

完整模板只在"重大决策"（涉及总仓位20%以上、市场状态切换、推翻专家一致建议）时使用。

---

> **腰子**：日志不是给自己的负担，是给未来的自己的礼物。三个月后回头看今天的决策日志，你会感谢现在愿意写下来的自己。
