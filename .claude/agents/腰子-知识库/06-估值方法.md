## 一、PE（市盈率）——最常用的估值指标

### 1.1 三种PE的定义

PE（Price-to-Earnings Ratio）是最直观的估值指标，表示"投资者愿意为每1元净利润支付多少钱"。

| 类型 | 公式 | 数据来源 | 优点 | 缺点 |
|:----|:-----|:--------|:-----|:-----|
| **静态PE** | 股价 / 去年年报净利润 | 上一份年报 | 数据确定，不可篡改 | 严重滞后，反映的是6-18个月前的业绩 |
| **TTM PE** | 股价 / 最近4个季度净利润 | 滚动4份季报 | 时效性好，反映当前盈利水平 | 季报有季节性波动 |
| **动态PE** | 股价 / 预测全年净利润 | 分析师一致预期 | 前瞻性强 | 预测常不准确，误差可达30%+ |

**项目强制规则**：铁律量化使用PE(TTM)，禁止直接用腾讯API提供的静态PE做否决依据。

### 1.2 PE(TTM)计算公式（项目红线强制要求）

```
PE(TTM) = 当前价[1] / TTM_EPS[3]

TTM_EPS = 最新年报EPS - 去年同季EPS + 最新季报EPS
```

**计算示例：**
假设某公司2025年报EPS=2.0元、2025Q1单季EPS=0.3元、2026Q1单季EPS=0.5元：

```
TTM_EPS = 2.0 - 0.3 + 0.5 = 2.2元
PE(TTM) = 当前股价 / 2.2
```

**参考：规则红线v1.6 第1.3条。**

### 1.3 PE适用与不适用的行业

| 适用 | 不适用的行业 | 原因 |
|:-----|:----------|:-----|
| 消费 | 周期性行业（钢铁、化工、有色） | 盈利剧烈波动，PE在周期底部虚高、在顶部虚低 |
| 金融 | 亏损公司 | 分子为负，PE无意义 |
| 医药 | 重资产但折旧大的行业 | 折旧压低利润导致PE虚高 |
| 稳定盈利的制造 | 高科技但尚未盈利（如早期创新药企） | PE无法反映研发管线的价值 |

### 1.4 A股各行业合理PE区间

| 行业 | 正常PE区间 | 偏离解释 |
|:----|:---------|:--------|
| 银行 | 5-12 | 天然低PE，高杠杆限制估值扩张 |
| 非银金融 | 10-20 | 券商弹性大，牛市PE可达30+ |
| 食品饮料 | 20-40 | 消费龙头享受品牌溢价 |
| 医药生物 | 30-60 | 创新药管线价值超过当期利润 |
| 电子 | 30-80 | 半导体周期性强，景气期PE可达50+ |
| 计算机 | 40-100+ | 高研发投入压制当期利润，但成长性强 |
| 电力设备 | 20-50 | 新能源赛道高景气但竞争加剧 |
| 汽车 | 15-40 | 传统车低PE，新能源车高PE |
| 通信 | 20-60 | 光模块等高端通信估值较高 |
| 机械设备 | 15-35 | 制造业合理区间 |

### 1.5 项目PE阈值表（每日荐股v2.4 第(十七)条）

这是项目否决体系的核心参数，决定了什么PE水平会触发否决：

| 行业类型 | 绝对否决PE | 说明 |
|:---------|:--------:|:-----|
| 电子、计算机 | >300 | 科技成长股高PE是常态，300不是天花板但不是买入理由 |
| 通信 | >250 | 光模块/5G等高研发行业 |
| 汽车、电力设备、机械、传媒 | >150 | 制造业+科技转型，给予中等容忍度 |
| 医药生物 | >80 | 创新药估值有管线支撑但不能无限高 |
| 食品饮料 | >60 | 消费龙头但增长有限，PE>60即泡沫 |
| 非银金融 | >20 | 金融行业天然低估值 |
| 银行 | >15 | 银行PB<1是常态，PE>15已属高估 |

**关键理解：** 这组阈值不是"低于此值就合理"，而是"超过此值就直接否决"。阈值是底线（否决线），不是目标线。合理的PE应当在此基础上下调30%-50%。

## 二、PB（市净率）

### 2.1 公式与定义

```
PB = 股价 / 每股净资产
```

PB衡量的是"投资者愿意为每1元净资产支付多少钱"。

- PB=1：股价等于每股净资产（"不赚不赔"）
- PB<1："破净"，股价低于净资产——常见于银行
- PB>5：市场给予很高溢价——常见于品牌消费品、高科技

### 2.2 适用行业

| 适用 | 原因 | 典型PB范围 |
|:-----|:-----|:---------|
| 银行 | 核心资产是贷款(有明确账面价值) | 0.5-1.5 |
| 地产 | 核心资产是土地和在建项目 | 0.3-1.0 |
| 钢铁/煤炭 | 固定资产比重大 | 0.5-1.5 |
| 券商 | 资产主要为金融资产，PB参考性强 | 1.0-2.5 |

### 2.3 不适用的行业

| 不适用 | 原因 |
|:------|:-----|
| 科技/互联网 | 核心资产是IP、算法、人才——不在账上 |
| 消费品牌 | 品牌价值不在净资产里 |
| 医药 | 研发管线价值无法在净资产中体现 |
| 服务 | 核心是人和客户关系 |

### 2.4 ROE与PB的关系

这是一个关键关系：ROE决定了PB的合理性。

```
高ROE + 高PB = 合理（市场给盈利能力强公司的合理溢价）
高ROE + 低PB = 可能低估（好公司被错杀）
低ROE + 高PB = 泡沫（差公司被高估，最危险的组合）
低ROE + 低PB = 合理（市场给盈利能力差公司的正常折价）

经验公式：合理PB ≈ ROE / 必要回报率
```

例如：ROE=20%的公司，合理PB约在4倍左右（20%/5%=4），而ROE=5%的公司，合理PB约1倍。

## 三、PS（市销率）

### 3.1 公式与定义

```
PS = 总市值 / 营业收入
```

PS衡量的是"投资者愿意为每1元营业收入支付多少钱"。无视成本结构和利润率，只看规模。

### 3.2 适用场景

| 适用 | 示例 |
|:-----|:-----|
| 高成长但不盈利的公司 | 早期SaaS公司按PS估值（因为PE无意义） |
| 电商/平台型公司 | 京东、拼多多早期用PS估值 |
| 生物科技（无收入但有前景） | 管线估值，PS只是参考 |

### 3.3 PS使用注意事项

- PS完全忽视利润率——一家营收100亿但亏损50亿的公司和营收100亿但净赚30亿的公司PS相同，但价值天差地别
- PS必须配合毛利率、净利率趋势一起看
- 低PS + 高且稳定的毛利率 = 可能存在价值洼地
- 低PS + 低且恶化的毛利率 = 价值陷阱

**项目状态：** PS未纳入铁律量化评分体系（当前只使用PE估值），但在重点股票深度分析中作为辅助参考。

## 四、PEG（市盈率相对盈利增长比）

### 4.1 公式与定义

```
PEG = PE(TTM) / 净利润增长率(%)
```

PEG由传奇基金经理彼得·林奇推广，用于衡量"PE是否匹配增长速度"。

### 4.2 解释标准

| PEG | 含义 | 操作建议 |
|:---:|:-----|:--------|
| <0.5 | 深度低估（增长远超估值） | 重点研究，可能有价值机会 |
| 0.5-1 | 低估 | 有吸引力 |
| =1 | 合理 | PE与增长速度匹配 |
| 1-2 | 偏贵但仍可接受 | 高成长股常见区间 |
| >2 | 高估 | 估值已透支了增长预期 |
| >3 | 泡沫区域 | 增长完全无法支撑估值 |

### 4.3 PEG的关键陷阱

**陷阱1：用历史增长率代替未来增长率**

PEG的灵魂在于分母——增长率必须是对未来的合理预期。用过去3年50%的增长率来证明当前PEG=1合理，但如果未来增速降到15%，实际PEG超过3。

**陷阱2：增长率不可持续**

50%的增速通常只能维持1-2年，之后回归均值。用峰值增速做PEG会严重低估远期估值。

**陷阱3：低PE + 低增长 = PEG也可能<1，但不一定有价值**

例如PE=5、增长=3% → PEG=1.67。PEG低可能只是PE低、增长也低。

### 4.4 项目中的使用

**项目状态：** PEG不纳入每日荐股评分体系（因为净利润增长率数据来自分析师预测，准确性不可靠），但在重点股票深度分析v2.2 第1.2.1条中作为"财务健康评估"的9项指标之一，且注明"净利润增长率用未来3年预测"。

## 五、EV/EBITDA（企业价值倍数）

### 5.1 公式与定义

```
EV = 总市值 + 总负债 - 现金及等价物
EBITDA = 净利润 + 所得税 + 利息 + 折旧 + 摊销
EV/EBITDA = 企业价值 / EBITDA
```

EV/EBITDA排除了资本结构（负债率不同不影响比较）和折旧政策（不同折旧方法不影响比较）的差异，是跨行业、跨国比较最公平的估值指标。

### 5.2 优势

| 优势 | 与PE对比 |
|:-----|:--------|
| 排除杠杆差异 | PE高的公司可能是负债率高导致财务费用大，EV/EBITDA公平对比 |
| 排除折旧差异 | 重资产行业折旧大压低了利润→PE虚高，但EBITDA排除了折旧影响 |
| 适合并购估值 | 收购方关注的是整个企业的经营利润能力（EBITDA），而不是扣除了目标公司债务利息后的净利润 |

### 5.3 合理的EV/EBITDA区间

| 行业 | 合理区间 |
|:----|:-------|
| 稳定消费 | 8-15x |
| 科技成长 | 15-30x |
| 重资产周期 | 5-10x |
| 基础设施 | 8-12x |
| 高成长SaaS | 20-50x+ |

### 5.4 项目状态

**项目对接：规则红线v1.5 第1.5.1条**：EV/EBITDA为P2优先级，待实测东方财富深度财务接口。当前状态：**不可输出为具体数值**。在分析中如需提及，必须标注"框架性参考，未经实测验证"。

## 六、股息率

### 6.1 公式

```
股息率 = 每股年度分红 / 当前股价
```

### 6.2 高股息股的典型特征

高股息股通常是"三高一低"：
- 高现金分红意愿（国企、成熟企业）
- 高自由现金流（不需要大量再投资）
- 大市值（经营稳定）
- 低增长（不需要保留利润再投资）

### 6.3 A股行业股息率参考

| 行业 | 典型股息率 |
|:----|:--------:|
| 银行 | 4%-7% |
| 煤炭 | 5%-10%（高但不稳定） |
| 电力/公用事业 | 3%-5% |
| 消费龙头 | 1.5%-3% |
| 科技 | <1%（几乎不分红） |

### 6.4 股息率的使用

- 股息率 > 10年期国债收益率 → 具配置价值
- 股息率 > 5% → 但需确认分红是否可持续（利润是否真实、现金流是否充足）
- 警惕"高股息陷阱"：公司利润下滑但维持高分红（吃老本），最终不可持续

**项目状态：** 股息率不纳入每日荐股评分体系，但在重点股票深度分析中作为补充参考。在熊市或震荡市中，高股息具有防御配置价值。

## 七、PE百分位（历史分位）

### 7.1 公式

```
PE百分位 = 当前PE在过去N年中排在第几位 / N年总交易日数
PE百分位越低 = 当前PE在历史中处于越低水平 = 相对低估
```

### 7.2 判断标准

| PE百分位 | 含义 | 操作 |
|:-------:|:-----|:-----|
| <30% | 低估区域 | 当前PE处于历史低位，有安全边际 |
| 30%-70% | 合理区域 | 正常估值水平 |
| >70% | 高估区域 | 当前PE处于历史高位，需谨慎 |
| >90% | 极度高估 | 历史顶部，大概率回归 |

### 7.3 PE百分位的关键陷阱

**陷阱1：历史不代表未来**

如果行业逻辑已经改变（如银行从高增长行业变成成熟行业），历史的PE中枢已经不可比。过去的PE=15是低估，现在PE=15可能是合理。

**陷阱2：历史区间过短**

如果只有3年数据，恰好覆盖了牛市，那么当前PE即使看起来在30%分位，也可能在高位。

**陷阱3：盈利大幅波动**

PE百分位用的是PE值，如果公司最近一个季度净利润暴跌，PE会跳升，历史分位可能被高估。反之亦然。

### 7.4 项目中的使用

铁律量化通过K线+EPS本地计算PE百分位（非外部API，属于本地计算[5]）。用于重点股票v2.2 第1.2.1条的财务健康评估。

## 八、DCF估值（现金流折现法）

### 8.1 核心公式

```
企业价值 = Σ(第t年自由现金流 / (1+折现率)^t) + (终值 / (1+折现率)^n)
```

DCF是理论上最严谨的估值方法，它认为企业价值等于未来所有自由现金流的折现之和。

### 8.2 DCF的两大变量（高度敏感）

| 变量 | 典型范围 | 敏感性 |
|:----|:--------|:-----|
| 折现率 (WACC) | 8%-12% | 折现率从10%变为11%，估值可能下降15%-20% |
| 永续增长率 | 2%-4% | 永续增长率从3%变为4%，估值可能上升20%-30% |

### 8.3 DCF的适用条件

**适用：** 现金流稳定可预测的成熟公司（茅台、长江电力、银行）

**不适用：** 高成长但亏损的科技公司（未来现金流毫无可见度）、强周期公司（盈利波动巨大）

### 8.4 DCF vs PE

| DCF | PE |
|:----|:---|
| 严谨、理论上最正确 | 简单、直接、可比 |
| 需要预测未来10年现金流（几乎不可能准确） | 只有一个变量 |
| 对假设极敏感，差1%结果差20% | 对假设不敏感 |
| 适合证明"值多少钱" | 适合对比"比同行业贵还是便宜" |

### 8.5 项目中的使用

**项目对接：规则红线v1.6**：使用DCF估值时，必须明确标注"估算"——不可作为精确决策依据。DCF在铁律量化中仅用于重点股票的"内在价值估算"（重点股票v2.2 第1.2.2条），且输出时必须标明假设参数和敏感性区间。

## 九、常见误区

| 误区 | 正解 |
|:-----|:-----|
| "PE低就是便宜，PE高就是贵" | PE低可能是因为公司基本面恶化（"价值陷阱"），PE高可能是因为高速成长。需要结合ROE、增长率、行业周期综合判断。 |
| "PE百分位<30%就一定能买" | 历史PE中枢可能已经不可比。判断前需要确认公司/行业的盈利结构没有发生根本性变化。 |
| "PEG<1就是低估" | PEG依赖对未来增长率的预测，如果增长率预测错误，PEG毫无意义。用历史增长率计算PEG是自欺欺人。 |
| "PB<1就是便宜" | 银行PB<1是常态（资产质量不确定），并不是因为被低估。如果坏账真实计提，很多银行的实际PB可能>2。 |
| "DCF估值更准确" | DCF是"精确的错误"，PE是"模糊的正确"。DCF对假设的微小变化极其敏感，实际应用中几乎不可能给出精确估值。 |
| "高股息率=好股票" | 高股息可能是股价暴跌导致的（分母变小），本质上是"跌出了高股息"。如果分红不可持续，高股息是陷阱。 |

## 十、自测题

### 题目1：为什么科技股PE>300才否决，银行股PE>15就否决？

**答案：**

这不是"歧视银行"或"偏爱科技"，而是行业估值逻辑不同：

1. **盈利能力不同**：银行ROE通常在10%-15%之间，增长缓慢（3%-8%年增速），投资者对每1元盈利的定价自然有限。科技股在高速增长阶段ROE可达20%+、净利润年增速30%+，高PE反映的是对高增长的合理定价。

2. **资产结构不同**：银行是高杠杆经营（资产负债率>90%），净利润放大效应强，风险也更大，市场给予风险折价（低PE）。科技股是轻资产运营，研发投入压低了当期利润，但创造了无形资产价值。

3. **生命周期位置不同**：A股大多数银行处于成熟期甚至衰退期，而科技股可能处于成长期。不同生命周期的PE不可比。

4. **否决阈值的实际含义**：否决阈值是"底线"，不是"合理线"。银行PE>15否决意味着"PE>15的银行无论如何都太贵了"。科技PE>300才否决意味着"即使科技股享有高PE溢价，300倍也是不可接受的"。

### 题目2：一只亏损公司的PE是多少？这个PE有意义吗？

**答案：**

亏损公司的PE = 当前股价 / 负的EPS = 负数。

**PE为负数没有意义。** 理由是：

1. PE=10意味着"盈利不变则需要10年回本"，PE=-10意味着什么？毫无经济含义。
2. 两只亏损股，一只亏0.1元/股、一只亏10元/股，后者PE负得少。按PE排序反而认为亏10元的"更便宜"——荒谬。
3. 亏损公司应该用PS（市销率）、PB（市净率）甚至用户数、GMV等替代指标来估值。

**项目实践**：铁律量化V4绝对否决规定"EPS<=0且PE无法计算 → 否决"。这是正确的处理方式——亏损公司不参与基于PE的评分和筛选，直接否决。

### 题目3：PEG<1但是PE>100的公司，估值真的合理吗？

**答案：**

不一定。需要逐层分析：

1. **数学上可能合理**：如果PE=150，净利润增长率=200%，那么PEG=0.75<1——从数学上看是低估的。

2. **但核心问题是增长率能否持续**：200%的增长率通常来自低基数（去年只赚了1000万，今年赚了3000万），这种增速不可持续。一旦明年增速降到50%，PEG立刻变成3。

3. **PEG<1的隐含假设**：PEG模型假设增长率可以长期保持。高PE+高增长+PEG<1的逻辑是"高增长会持续足够长时间来消化高PE"，但这个假设在99%的情况下是错误的。

4. **需要验证增长的"质量"**：
   - 是一次性收入（卖资产）还是可持续收入（主营增长）？
   - 行业空间是否足够大（能否维持3-5年高增长）？
   - 竞争壁垒如何（高利润会不会吸引竞争对手涌入）？

**结论**：PEG<1 + PE>100可以作为一个"值得进一步研究"的信号，但绝不能仅凭PEG<1就判断估值合理。
