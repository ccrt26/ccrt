# 推荐哲学（核心指导思想）

> **核心信念**：推荐不是"今天谁涨得好就选谁"，而是"谁在未来一段时间最有可能上涨"。

股票推荐的目的是**提前发现价值**，而非追逐已经发生的价格变动。基于这一信念，推荐逻辑遵循以下层级：

```
政策/产业趋势 → 行业景气度判断 → 板块轮动相位 → 精选蓄势个股 → 择机埋伏
     (宏观)          (中观)          (中观)        (微观技术)      (执行)
```

**关键区分**：

| 维度 | 错误做法（追涨） | 正确做法（埋伏） |
|:----|:-----------------|:-----------------|
| 技术面 | 今日大涨→高分 | 均线收敛、底部抬高、缩量整理后温和放量→高分 |
| 资金面 | 今日主力净流入→高分 | 连续小单吸纳、成交额温和放大但价格未涨→高分 |
| 板块 | 今日热点板块→超配 | 轮动早期/中期板块→超配；过热板块→减配 |

一个好的推荐必须回答：
1. **为什么是这个行业？** → 板块轮动到哪个阶段了？
2. **为什么是这只股票？** → 技术面蓄势充分了吗？
3. **为什么是现在？** → 有什么即将发生的催化剂？
4. **空间和风险如何？** → 向上空间 > 向下空间？

# 第一章 流水线总览

## 1.1 每日流水线

```
build_dynamic_pool.ps1    →  动态池构建（板块扫描+相位判定+成分股合并）
         ↓
batch_data_collector.ps1  →  批量数据采集（行情/财务/资金流/K线）
         ↓
scoring_engine_v2.py      →  否决→评分→排序（绝对否决→六维评分→条件否决→取前25）
         ↓
gen_daily_html.ps1        →  报告生成（HTML + PDF）
```

**调度入口**：`daily_workflow.ps1 -Mode daily`

## 1.2 退出机制（独立模块，不纳入日报）

EUS（Exit Urgency Score）退出急迫度评分，独立运行：
- 四维度加权：时间因子(25%) + 盈亏状态(30%) + 技术面(25%) + 资金面(20%)
- EUS<20持有 / 20-35减半仓 / 35-50退2/3 / >50全面退出
- 一票否决：-7%硬止损 / 超15天且亏>5% / 价<MA20×0.95
- 输出至 `临时回溯/` 目录，不参与每日荐股报告

# 第二章 动态池构建

## 2.1 核心思想

每日根据板块轮动数据动态构建股票池，替代传统的固定池模式。核心逻辑：
1. 扫描全市场板块，识别当前热门板块（潜优期/主升期）
2. 从热门板块中提取成分股
3. 合并核心底仓（28只长期跟踪标的）
4. 输出去重动态池（80-120只）

## 2.2 执行流程

```
Get-SectorData (Top 30) + Get-SectorFundFlow (Top 30)
    ↓
板块五因子评分：相位 + 涨跌幅 + 换手率 + 资金流
    ↓
选择 Top 5 热门板块
    ↓
对每个热门板块 Get-SectorConstituents（前20只）
    ↓
合并 core_stocks.json（28只核心底仓）
    ↓
去重输出 dynamic_pool.json（80-120只）
```

## 2.3 板块相位判定

基于实时数据，将每个板块归入以下相位：

| 相位 | 判定条件 | 评分 |
|:----:|---------|:----:|
| 潜伏期(accum) | 涨跌幅≥-1.5%且换手率≤4%；或≥-2%且换手率≤2% | +10 |
| 主升调整(rise) | 换手率>3%且涨幅>0%；或换手率>2%且跌幅<-1% | +5 |
| 高潮期(peak) | 换手率>5%且涨幅>2% | -5 |
| 衰退期(decline) | 换手率>3%且跌幅<-3% | -10 |

## 2.4 板块综合评分

四个因子加权：

| 因子 | 评分规则 |
|:----|---------|
| 相位分 | 潜伏期+10 / 主升调整+5 / 高潮期-5 / 衰退期-10 |
| 涨跌幅分 | -2%~3%得+5；>5%得-5 |
| 换手率分 | 2%~6%得+5；>10%得-3 |
| 资金流分 | 净流入>0得+5；净流出<-1亿得-3 |

取总分前5名的板块，每个板块提取前20只成分股。

## 2.5 核心底仓

`core_stocks.json` 包含28只长期跟踪标的，行业分布：

| 医药生物 | 1 | 恒瑞医药 |
| 汽车 | 1 | 比亚迪 |

| 计算机 | 5 | 中科曙光、同花顺、恒生电子、金山办公、科大讯飞 |

```

    │
    ├── [1/5] 批量行情 → Get-StockQuoteBatch (腾讯多代码API，一次查完)
```

| 数据 | 主源 | 备源 | 缓存TTL |
|------|------|------|---------|

# 第四章 否决+评分体系

## 4.1 执行流程

```
绝对否决 → 六维评分 → 条件否决 → 按总分降序排序 → 取前25只推荐
```

> 否决在评分**之前**执行，但条件否决允许高分豁免。这确保了"有硬伤的不进池，有潜力但不完美的给机会"。

## 4.2 绝对否决（一条触发即否决，不评分）

| # | 否决条件 | 阈值 | 说明 |
|:-:|---------|:----:|------|
| V0 | ST股票 | 名称含"ST"、"*ST" | 带帽风险股，不纳入推荐 |
| V2 | PE估值泡沫 | 按行业不同（见4.4） | 超出行业合理估值范围 |
| V3 | 短期暴涨 | 30日涨幅 > 50% | 追高风险极大 |
| V4 | 财务数据异常 | EPS≤0且PE无法计算 | 财报数据不足 |
| V5 | 流动性枯竭 | 成交额<1500万且换手率<0.5% | 无人交易 |
| V6 | 高负债率 | 资产负债率>70%（预留） | 财务风险 |
| V7 | 严重负面事件 | 立案调查等（预留） | 黑天鹅 |

## 4.3 条件否决（先评分，分不够则否决）

| # | 否决条件 | 阈值 | 豁免条件 |
|:-:|---------|:----:|:--------:|
| C1 | 科技PE偏高 | PE>120（电子/计算机/通信等） | 总分 ≥ 85 |
| C2 | 高成长PE偏高 | PE>80 | 总分 ≥ 85 |
| C3 | 短期均线回踩 | MA5 < MA10×0.99 | 总分 ≥ 75 |
| C4 | 30日涨幅过高 | 30日涨幅>50% | 无豁免 |
| C5 | 均线死叉 | MA10≤MA20（原绝对否决V1降级） | 总分 ≥ 75 |

## 4.4 PE估值阈值（行业相对估值）

| 行业类型 | 绝对否决(PE>) | 说明 |
|---------|:-------------:|------|
| 电子、计算机 | 300 | 科技成长股，高PE是常态 |
| 通信 | 250 | 高研发投入行业 |
| 汽车、电力设备、机械设备、传媒 | 150 | 制造业+科技转型 |
| 医药生物 | 80 | 创新药估值 |
| 食品饮料 | 60 | 消费龙头适度放宽 |
| 非银金融 | 20 | 金融行业低估值 |
| 银行 | 15 | 银行天然低PE |

> 高PE科技股通过绝对否决后，仍需在条件否决C1/C2中证明综合评分≥85才能通过。这提供了"先看质量，再定去留"的弹性机制。

# 第五章 六维度评分体系

## 5.1 评分总览

六维度加权总分 = 基础(10) + 基本面(20) + 技术面(25) + 资金面(20) + 消息面(20) + 风控(5) = **100分**

**评级标准**：

| 总分范围 | 评级 | 操作建议 |
|:--------:|:----:|---------|
| ≥ 85 | 极品 | 蓄势充分+催化明确，优先推荐 |
| ≥ 75 | 优质 | 蓄势良好，积极推荐 |
| ≥ 65 | 达标 | 可推荐，适合轻仓 |
| 55-64 | 观察 | 蓄势中，仅纳入跟踪 |
| < 55 | 否决 | 不推荐 |

## 5.2 基础门槛 (10分)

- **非ST/非亏损**（3分）：ST直接否决
- **市值评分**（4分）：100-1000亿得4分；50-100亿或1000-3000亿得2分；<50亿得1分；>3000亿得0分
- **流动性**（3分）：日成交额>1亿得3分；>5000万得2分；>3000万得1分

## 5.3 基本面 (20分)

| 子项 | 满分 | 评分标准 |
|:----|:---:|---------|
| PE估值 | 12 | PE≤15得18→逐步递减至PE>80得6分，大盘股+2分（归一化至20分） |
| 市值溢价 | 8 | 大盘股额外加分 |

## 5.4 技术面 (25分) — 蓄势导向

7个子项评分后归一化：

| 子项 | 权重 | 评分核心 |
|:----|:----:|---------|
| S1 均线系统 | 6 | MA5>MA10>MA20多头得6分；均线收敛(间距<1%)得6分；死叉得1分 |
| S2 均线收敛发散 | 5 | 从收敛开始发散向上得5分；持续收敛得4分；发散向下得0分 |
| S3 量价蓄势 | 5 | 缩量整理后放量+小阳线得5分；底部连阳得4分；放量暴跌得0分 |
| S4 底部支撑 | 4 | 底部抬高得4分；回踩MA20/MA60不破得3分 |
| S5 RSI位置 | 3 | RSI 40-55得3分；>70得0分（突破形态除外） |
| S6 MACD | 2 | 金叉或即将金叉得2分；死叉0分 |
| S7 突破确认 | 2 | 剧烈震荡洗盘后放量突破前高得2分 |

## 5.5 资金面 (20分)

| 子项 | 评分核心 |
|:----|---------|
| 换手率 | 2%-5%活跃区间+4分；>8%过热-2分；<1%冷清-2分 |
| 振幅 | 3%-7%合理波动+3分；>10%异常-2分 |
| 资金流向 | 主力净流入>0+2分；净流出<-1000万-2分 |
| **板块动量** | **高潮期+4分；主升调整+2~3分；潜伏期+1分；衰退期-3分（见§5.8）** |

## 5.6 消息面 (20分)

以RS相对强度代替复杂的消息分析：
- 今日涨幅>3%+4分；>1%+2分；<-3%-3分
- **板块动量加成**：高潮期+2分；主升调整+1分；衰退期-1分（见§5.8）
- 最低1分，最高20分

## 5.7 风控 (5分)

- PE>0且<60 +1分
- 换手率1%-8% +1分
- 默认3分

## 5.8 板块动量加分（v2.1 新增）

板块动量不单独作为一个维度，而是对资金面(S_Money)和消息面(S_News)进行加权修正。

### 数据来源

从 **东方财富行业板块API** 获取真实市场数据（`push2.eastmoney.com/api/qt/clist/get?fs=m:90+t:2`），替换了v2.0中池内84只股票聚合计算板块数据的方法。解决了样本偏差问题（如通信板块全市场上百只，池子只有2只，池内聚合无法代表全行业）。

### 相位分类

`classify_phase(chg_pct, turn_rate)` 根据板块指数涨跌幅和换手率判断：

| 相位 | 判定条件 | 含义 |
|:----:|---------|------|
| 潜伏期 | 涨跌幅≥-1.5%且换手率≤4%；或≥-2%且换手率≤2% | 板块未启动，可埋伏 |
| 主升调整 | 换手率>3%且涨幅>0%；或换手率>2%且跌幅<-1% | 板块活跃中，持有不加仓 |
| 高潮期 | 换手率>5%且涨幅>2% | 板块过热，减仓回避 |
| 衰退期 | 换手率>3%且跌幅<-3% | 板块退潮，规避 |

### 加分规则

`calc_sector_bonus(phase, chg_pct, count)`：

| 相位 | 条件 | 资金面加分 | 消息面加分 |
|:----:|:----:|:---------:|:---------:|
| 高潮期 | turn>5, chg>2 | **+4** | +2 |
| 主升调整(强) | chg>3 | **+3** | +1 |
| 主升调整(弱) | 其他 | **+2** | +1 |
| 潜伏期 | 默认 | +1 | 0 |
| 衰退期 | turn>3, chg<-3 | **-3** | -1 |

> **注意**：如果板块在真实市场数据中不存在（东方财富行业分类更细），回退至池内聚合计算，但若池内该板块股票<3只，降级为基准加分（潜伏期水平）。

### 数据流

```
东方财富API → Get-SectorData(30行业板块) → batch_data_collector[5/5]
                                                              ↓
data_full.json: { Stocks, SectorData, SectorFundFlow } 
                                                              ↓
scoring_engine_v2.py: compute_sector_phases() → classify_phase() + calc_sector_bonus()
                                                              ↓
每只股票评分时: S_Money += money_bonus, S_News += news_bonus
                                                              ↓
data_scored.json: { Stocks, SectorPhaseMap(真实板块相位数据) }
                                                              ↓
gen_daily_html.ps1: 板块轮动表从 SectorPhaseMap 读取真实数据
```

### 数据流变更（v2.1）

```
旧: 东方财富API → build_dynamic_pool → 84只个股 → data_full.json(仅个股) → scoring_engine(池内聚合算板块) → 错误的数据
新: 东方财富API → Get-SectorData(真实板块指数) → data_full.json(含SectorData) → scoring_engine(直接用真实数据) → 正确的加权
```

# 第七章 数据质量

## 7.1 数据来源

# 附录B：退出机制(EUS)规范

EUS退出机制为独立模块，不纳入每日荐股流水线：

**四维度加权**：时间因子(25%) + 盈亏状态(30%) + 技术面(25%) + 资金面(20%)

**决策规则**：
- EUS<20：继续持有
- 20≤EUS<35：减半仓，挂移动止盈
- 35≤EUS<50：退出2/3，保留观察仓
- EUS≥50：全面退出
- 一票退出：-7%硬止损 / 超15天且亏>5% / 价<MA20×0.95
