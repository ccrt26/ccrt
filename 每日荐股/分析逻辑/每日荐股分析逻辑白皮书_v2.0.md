# 📌 推荐哲学（核心指导思想）

> **铁律**：推荐不是"今天谁涨得好就选谁"，而是"谁在未来一段时间最有可能上涨"。

## 0.1 核心信念

股票推荐的目的是**提前发现价值**，而非追逐已经发生的价格变动。基于这一信念，我们的推荐逻辑遵循以下层级：

```
政策/产业趋势 → 行业景气度判断 → 板块轮动相位 → 精选蓄势个股 → 择机埋伏
     (宏观)          (中观)          (中观)        (微观技术)      (执行)
```

**关键区分**：

| 维度 | ❌ 错误做法（追涨） | ✅ 正确做法（埋伏） |
|:----|:-----------------|:-----------------|
| 技术面 | 今日大涨→高分 | 均线收敛、底部抬高、缩量整理后温和放量→高分 |
| 资金面 | 今日主力净流入→高分 | 连续小单吸纳、成交额温和放大但价格未涨→高分 |
| 消息面 | 今日有利好→高分 | 政策即将落地、业绩预告前、行业催化临近→高分 |
| 板块 | 今日热点板块→超配 | 轮动早期/中期板块→超配；过热板块→减配 |

## 0.2 评分原则重述

评分是对 **"未来上涨概率与空间的综合评估"**，而不是对"过去表现的打分"。

- **技术面评分**：更看重均线收敛、底部构造、量价蓄势形态，而非单日涨跌
- **资金面评分**：更看重资金连续流入趋势，而非单日买卖比
- **消息面评分**：更看重未来催化剂（即将落地的政策、预期差），而非已兑现的利好
- **板块评分**：更看重板块轮动相位（位置决定空间），而非当日涨幅排名

## 0.3 什么才是好的推荐

一个好的推荐必须能回答以下问题：

1. **为什么是这个行业？** → 板块轮动到哪个阶段了？（第二章）
2. **为什么是这只股票？** → 技术面蓄势充分了吗？资金面有埋伏迹象吗？（第三章）
3. **为什么是现在？** → 有什么即将发生的催化剂？（消息面）
4. **空间和风险如何？** → 向上空间 > 向下空间？（风控+止损）

**一句话总结**：我们要找的是"蓄势待发"的股票，而不是"已经起飞"的股票。

# 第一章 股票池管理体系

## 1.1 概述

股票池是量化选股的基础。通过分级管理，将全市场5000+只股票逐步缩小到可跟踪、可分析的范围，确保覆盖效率和分析深度。

## 1.2 五级池架构

```
全市场池 (~5100只)
    │  剔除：ST/*ST、退市整理、停牌>30日、上市<60日、净资产为负
    ▼
基础池 (~800只)
    │  筛选：市值>50亿、日均成交额>5000万、非金融行业基础覆盖
    ▼
核心观察池 (~80-120只)
    │  筛选：基本面达标 + 行业覆盖 + 量化评分>50分 + 持续跟踪
    ▼
精选推荐池 (~30-50只)
    │  每日过筛：六维评分 + 一票否决检查 → ≥65分推荐
    ▼
剔除/冻结池 (动态)
        触发否决条件、或连续评分不合格的标的，等待条件恢复
```

### 1.2.1 全市场池 → 基础池（刚性剔除）
剔除以下股票：
- ST / *ST / 退市整理期
- 连续停牌超过30个交易日
- 上市不足60个交易日（次新股，数据不足）
- 最近一期净资产为负
- 最近一期营收低于1亿元（非金融）
- 流通市值 < 30亿

### 1.2.2 基础池 → 核心观察池（柔性筛选）
满足以下条件之一的股票可进入核心观察池：
- **基本面达标**：最近一季度净利润为正、营收同比正增长、毛利率>15%
- **行业覆盖需求**：每个申万一级行业至少有2只代表标的
- **量化评分**：六维评分 > 50分（见第三章）
- **流动性充足**：近20日日均成交额 > 5000万
- **机构覆盖**：至少有3家券商研报覆盖（辅助条件）

### 1.2.3 核心观察池 → 精选推荐池
每日收盘后，对核心观察池全部标的执行：
1. 六维评分计算
2. 一票否决检查
3. 行业分布平衡
4. 组合层规则校验
5. 评分 ≥ 65分 且 未触发否决 → 进入推荐候选

### 1.2.4 剔除/冻结池
触发以下条件之一的标的移入剔除池：
- 连续30个交易日评分 < 50分
- 触发绝对否决条件且预计短期内无法修复
- 行业景气度明确下行（如政策打压、技术替代）
- 被交易所风险警示

剔除池的标的每季度复审一次，条件修复后可回归核心观察池。

## 1.3 核心观察池动态轮换机制

核心观察池 **不是固定名单**，而是依据量化规则持续动态调整的。池中标的每周/每月/每季度按以下节奏进行复审和轮换。

### 1.3.1 选股理论基础

为什么选这42只，而不是其他？核心观察池的选股逻辑基于以下四条理论支柱：

**① 行业景气周期覆盖（宏观→中观）**
- 覆盖当前经济周期中处于上升期的行业（半导体、AI、新能源）
- 覆盖经济下行期具有防御属性的行业（消费、医药）
- 覆盖政策驱动型行业（网安、信创）
- 确保在任何市场风格下，池中都有处于轮动有利位置的标的

**② 市值分层策略（流动性优先）**
- 核心配置：100-1000亿市值（中盘成长股，蓄势型标的的主力区域）
- 卫星配置：50-100亿（高弹性）和1000-3000亿（稳定蓝筹）
- 排除了<30亿（流动性风险）和>3000亿（弹性不足）
- 每只标的近20日日均成交额>5000万，确保可交易性

**③ 行业龙头+弹性标的组合**
- 每个行业选取1-2只绝对龙头（如中科曙光、宁德时代）作为行业风向标
- 搭配2-3只高弹性标的（如天孚通信、东睦股份）作为收益增强
- 龙头提供稳定性，弹性标的提供超额收益机会

**④ 基本面门槛**
- 最近一季度净利润为正（剔除亏损股）
- 毛利率>15%（有基本盈利能力）
- 营收正增长（处于扩张期）
- 资产负债率<70%（财务安全）

> 每一个季度审核时，按以上四条标准重新评估池中标的，不符合的移出，新的符合条件的纳入。

### 1.3.2 轮换节奏

| 周期 | 动作 | 触发条件 | 调整幅度 |
|:----:|:----|:---------|:--------:|
| **每日** | 评分过筛 | 收盘后六维评分 | 评分<50分→移入观察列表 |
| **每周** | 微调轮换 | 周五收盘后复审 | 换手率≤10%（≤5只） |
| **每季度** | 全面审核 | 季报披露后 | 换手率≤30%（≤15只） |
| **事件驱动** | 旁路进出 | 突发利好/利空 | 单次≤3只 |

### 1.3.3 进出规则

**进入核心池的条件（满足任一即可）：**
- 基本面达标（净利润为正、营收同比增>10%、毛利率>15%）+ 量化评分>50分
- 所属行业当前覆盖不足（该行业已有标的<2只），且标的流动性达标
- 机构研报覆盖≥3家，且市场热度评分>60分
- 突发事件驱动的强势标的，通过"旁路机制"（5.3节）临时纳入

**移出核心池的条件（触发任一即移出）：**
- 连续5个交易日评分<50分
- 触发绝对否决条件（见第四章）
- 连续20个交易日日均成交额<3000万（流动性枯竭）
- 行业景气度明确下行（政策打压、技术替代等）
- 被交易所风险警示（ST/*ST）

> **移出后处理**：被移出的标的进入"观察恢复区"，若30个交易日内条件修复可重新进入；超过30日则移至冻结池，每季度复审一次。

# 第二章 板块行业分析框架

## 2.1 核心思想：板块轮动，数据驱动，而非写死

板块分析不是固定的"我们就看这6个板块"，而是基于市场数据的动态筛选过程。

**基本原则：**
- **覆盖基础为申万一级行业分类**（31个行业），作为分析框架的骨架
- **每日根据市场数据计算每个板块的热度评分和轮动相位**
- **报告聚焦当前处于有利轮动位置（潜伏期/启动期）的板块**
- **板块覆盖范围随市场轮动节奏动态调整**

```
全市场31个申万一级行业
    ↓ 每日数据驱动评分
热度评分 + 轮动相位判定
    ↓
聚焦潜伏期/启动期板块
    ↓
从对应板块中精选个股
```

> **关键区分**：不是"我们决定看哪些板块"，而是"市场告诉我们哪些板块值得看"。池中42只标的覆盖了11个申万一级行业，但每日分析的范围不受此限——通过板块指数数据，我们可以分析市场所有主要板块的轮动状态。

板块轮动的生命周期：

```
潜伏期 → 启动期 → 主升期 → 高潮期 → 衰退期
   ↑                                  |
   └────────── 调整后重新开始 ──────────┘
```

**各阶段特征与操作策略**：

| 阶段 | 价格特征 | 量能特征 | 资金特征 | 操作策略 |
|:----|---------|---------|---------|:--------:|
| 🟢 潜伏期 | 底部盘整，波动收窄 | 缩量→温和放量 | 机构悄悄吸纳 | ✅ **重点埋伏** |
| 🟢 启动期 | 突破关键均线，涨幅温和 | 成交量放大1.5-2倍 | 主力净流入转正 | ✅ **积极建仓** |
| 🟡 主升期 | 加速上涨，连续阳线 | 成交量持续高位 | 散户跟风入场 | ⚠️ 持有为主，不加仓 |
| 🔴 高潮期 | 放量滞涨，长上影 | 天量 | 主力边拉边出 | ❌ 减仓/回避 |
| 🔴 衰退期 | 连续阴跌，破位 | 缩量 | 持续净流出 | ❌ 回避 |

## 2.2 板块数据来源

板块分析依赖以下数据源：

| 数据维度 | 来源 | 用途 |
|---------|------|------|
| 板块指数涨跌 | 东方财富行业板块[m:90+t:2] | 各板块当日/5日/20日涨跌幅 |
| 个股行业归属 | 申万一级行业分类（本地映射表） | 将42只池中标的归类到对应行业 |
| 板块成交额 | 东方财富板块数据 | 量能趋势判断 |
| 资金流向 | 东方财富板块资金流 | 主力净流入/流出 |

> **数据驱动方式**：每日调用东方财富行业板块API获取全市场板块行情，结合池中个股数据，综合判断各板块的轮动状态。

## 2.3 板块轮动相位判定方法

### 2.3.1 判定因子

每交易日收盘后，对申万一级行业及各主要板块进行相位判定。判定基于以下三因子模型：

| 因子 | 权重 | 数据来源 | 计算方法 |
|:----|:---:|:---------|:--------|
| 短期相对强度 | 40% | 东方财富板块行情 | 板块当日涨跌幅 vs 大盘当日涨跌幅 |
| 中期相对强度 | 30% | 东方财富板块行情 | 板块5日涨跌幅 vs 大盘5日涨跌幅 |
| 量价配合度 | 30% | 东方财富板块行情 | 板块换手率趋势（3日均量 vs 20日均量） |

### 2.3.2 相位判定标准

综合三因子加权得分，判定板块所处轮动相位：

| 轮动相位 | 判定标准 | 典型特征 |
|:--------:|---------|---------|
| 🟢 **潜伏期** | 20日跑输大盘 -10%~-3%，近期换手率从地量回升 | 无人问津，机构悄悄吸筹 |
| 🟢 **启动期** | 近5日跑赢大盘 0%~+3%，量能温和放大1.2-1.5倍 | 开始获得关注，资金温和流入 |
| 🟡 **主升期** | 近20日跑赢大盘 +5%~+15%，量能放大1.5-3倍 | 趋势明确，市场共识形成 |
| 🔴 **高潮期** | 近20日跑赢大盘 >+15%，量能>3倍，或放量滞涨 | 情绪过热，主力可能出货 |
| 🔴 **衰退期** | 近5日跑输大盘 -3%以下，量能萎缩 | 趋势破坏，资金离场 |

> **重要说明**：相位判定需要连续3日处于同一相位才能确认，避免单日异常波动导致的误判。本期报告由于是首次应用，基于已知数据做初步判定，后续报告将基于历史数据进行连续性确认。

### 2.3.3 数据分析流程

```
Step 1: 获取东方财富全行业板块行情 (top100 by 涨跌幅)
Step 2: 识别当日强势板块（涨幅前10）和弱势板块（跌幅前10）
Step 3: 结合池中42只个股的申万行业归属，计算覆盖行业的表现
Step 4: 综合判定各覆盖行业的轮动相位
Step 5: 输出板块分析报告，重点聚焦潜伏期和启动期板块

# 第三章 六维度评分体系（蓄势导向）

## 3.0 评分哲学重述

**评分不是对过去表现的打分，而是对未来上涨概率的评估。**

因此评分重点关注：
- **技术面**：是否蓄势充分？（均线收敛、底部抬高、量能温和放大）
- **资金面**：是否有聪明钱提前埋伏？（连续小单吸纳，价格未涨）
- **消息面**：是否有即将落地的催化剂？（政策、业绩、事件）
- **板块面**：是否处于轮动有利位置？（潜伏期/启动期 > 主升期/高潮期）

> 评分权重最高的技术面子项，不是"今天涨了多少"，而是"是否准备好了上涨"。

## 3.1 评分总览

六维度加权总分 = 基础(10) + 基本面(20) + 技术面(25) + 资金面(20) + 消息面(20) + 风控(5)

**评级标准**：
| 总分范围 | 评级 | 操作建议 |
|:--------:|:----:|---------|
| ≥ 85 | ⭐ 极品 | 蓄势充分+催化明确，优先推荐 |
| ≥ 75 | ⭐ 优质 | 蓄势良好，积极推荐 |
| ≥ 65 | 🔹 达标 | 可推荐，适合轻仓 |
| 55-64 | 💤 观察 | 蓄势中，仅纳入跟踪 |
| < 55 | 🚫 否决 | 不推荐 |

**市场情绪自适应**：在极端市场条件下，评分阈值可下调5-10分（详见第七章）。

## 3.2 基础门槛 (10分)

| 子项 | 满分 | 评分条件 |
|:----|:---:|---------|
| 非ST/非亏损 | 3 | ST/亏损股直接否决，正常标的得3分 |
| 市值评分 | 4 | 流通市值100-1000亿得4分（蓄势型标的优选市值），50-100亿得3分，1000-3000亿得2分，<50亿得1分，>3000亿得0分 |
| 流动性 | 3 | 近20日日均成交额>1亿得3分，>5000万得2分，>3000万得1分，<3000万否决 |

> **否决条件**：流通市值<30亿 或 日均成交额<3000万 → 直接否决

## 3.3 基本面 (20分)

| 子项 | 满分 | 评分条件 | 数据源 |
|:----|:---:|---------|:------:|
| 净利润趋势 | 5 | 连续3季度净利递增得5分，稳定得3分，下滑得1分 | [3]同花顺 |
| 营收增长 | 4 | 营收同比>20%得4分，>10%得2分，>0得1分 | [3]同花顺 |
| 毛利率质量 | 4 | >50%且趋势向上得4分，>30%得2分，>15%得1分 | [3]同花顺 |

> **否决条件**：净利润连续2季度为负 或 资产负债率>70%

# 第四章 一票否决制

## 4.1 否决与评分的关系

一票否决在评分**之前**执行。触发否决的标的**不计算分数**，不进入推荐列表。否决类型分为绝对否决和条件否决。

**执行流程**：
```
股票 → 绝对否决检查 → 通过 → 条件否决检查 → 通过 → 六维评分
                ↓                        ↓
            不通过(永久移除)        不通过(暂缓推荐)
```

## 4.2 绝对否决（一条触发即否决，不移除）

| # | 否决条件 | 阈值 | 典型场景 |
|:-:|---------|:----:|---------|
| 1 | 净利润亏损 | 连续2季度净利润为负 | 亏损股 |
| 2 | PE估值泡沫(科技) | PE(TTM) > 80 | 海光信息PE=260 |
| 3 | 中期趋势空头 | MA10 ≤ MA20 | 均线死叉，趋势走坏 |
| 4 | 短期暴涨 | 30日涨幅 > 50% | 中际旭创30日+78% |
| 5 | 财务数据异常 | PE(TTM)无法计算 | 财报数据不足 |
| 6 | 严重负面事件 | 立案调查/财务造假/实际控制人问题 | 新闻确认 |
| 7 | 高负债率 | 资产负债率 > 70% | 杠杆过高 |
| 8 | 流动性枯竭 | 近20日日均成交额 < 3000万 | 无人交易 |

## 4.3 条件否决（满足条件+评分不足时触发）

| # | 否决条件 | 阈值 | 豁免条件 |
|:-:|---------|:----:|---------|
| 1 | PE偏高(科技制造) | PE(TTM) > 120 | 总分 ≥ 85 |
| 2 | PE偏高(高成长行业) | PE(TTM) > 80 | 总分 ≥ 85 |
| 3 | 短期均线回踩 | MA5 < MA10×0.99 | 总分 ≥ 85 |

## 4.4 PE估值否决细则（行业相对估值）

针对不同行业设置不同的PE(TTM)阈值：

| 行业类型 | PE绝对否决 | PE条件否决(需≥85分) | 说明 |
|---------|:----------:|:-------------------:|------|

| 亏损行业(如网安) | N/A | N/A | 参考PS估值 |

> PE(TTM)必须基于同花顺[3]EPS计算：PE(TTM) = 当前股价 / EPS(TTM)，EPS(TTM) = 最近4个季度净利润之和 / 总股本。禁用腾讯静态PE。

## 5.1 建仓条件

同时满足以下条件时触发买入：

| # | 条件 | 说明 |
|:-:|:----|------|
| 1 | 股价在建议建仓区间内 | 建仓区间 = [MA10, MA5] 或 [MA10, 前一交易日收盘价] |
| 2 | 成交量 > MA5均量 × 1.0 | 有量能支撑 |
| 3 | 未触发任何否决条件 | 见第四章 |
| 4 | 评分 ≥ 65 | 见第三章 |
| 5 | 大盘环境允许 | 大盘非暴跌日（跌>3%除外） |

- 开盘价 > MA5 + 3%（跳空高开不追高）
- 大盘当日跌幅 > 3%（系统性风险回避）
- 个股触发30日涨幅否决

## 5.2 止损规则（ATR动态止损）

> **改进**：从固定-5%止损改为2×ATR(14)动态止损

**止损价 = 买入价 - 2 × ATR(14)**

其中ATR(14)为14日平均真实波幅，自动适应不同波动率股票。

**ATR止损示例**：

| 股票 | 买入价 | ATR(14) | 2×ATR | 止损价 | 止损幅度 |
|:----|:-----:|:-------:|:-----:|:-----:|:--------:|
| 柏楚电子 | 179.26 | 4.1 | 8.2 | 171.06 | -4.6% |
| 中科曙光 | 101.36 | 2.8 | 5.6 | 95.76 | -5.5% |
| 新易盛 | 591.27 | 12.5 | 25.0 | 566.27 | -4.2% |

> 高波动股票(ATR大)止损幅度自然放大，低波动股票止损幅度收窄。这比固定-5%更合理。

**止损硬上限**：即使ATR计算出的止损幅度超过-8%，止损价仍设在买入价的-8%（最大容忍亏损）。

## 5.3 止盈规则（分级止盈）

| 层级 | 目标涨幅 | 操作 |
|:----:|:--------:|------|
| 第一止盈 | +5% | 减仓50% |
| 第二止盈 | +10% | 减仓剩余50%中的50%（即总仓25%） |
| 第三止盈 | +15% | 清仓 |

**移动止盈**：达到第一止盈后，止损价上移至盈亏平衡点（买入价），确保剩余仓位不亏损。

## 5.4 仓位管理

### 5.4.1 基础仓位

单只股票基础仓位 = 账户总资金 × 2% × 波动系数

### 5.4.2 波动系数

| ATR(14)/股价 | 波动率 | 系数 | 说明 |
|:------------:|:------:|:----:|------|
| < 2% | 低波动 | 1.5 | 可适度加仓 |
| 2%-5% | 中等波动 | 1.0 | 正常仓位 |
| > 5% | 高波动 | 0.5 | 减仓控制风险 |

### 5.4.3 市场环境调节

| 市场状态 | 总仓位上限 | 单只上限 |
|---------|:--------:|:--------:|
| 牛市(大盘MA5>MA20>MA60) | 100% | 20% |
| 震荡(均线交织) | 80% | 15% |
| 熊市(大盘MA5<MA20<MA60) | 50% | 10% |

## 5.5 旁路机制（事件驱动）

对于突发事件驱动的投资机会（如政策突然利好一个行业），可通过旁路机制将不在核心池中的标的临时加入精选池。

**旁路条件**（需同时满足）：
1. 有明确的事件驱动逻辑（政策/公告/行业变化）
2. 标的满足基础池的刚性条件（非ST/有流动性/有数据）
3. 通过六维评分（需≥65分）
4. 经人工确认

**旁路限制**：单日通过旁路机制加入的标的 ≤ 2只，避免绕过池子机制。

# 第六章 组合层规则

## 6.1 行业分散要求

| 规则 | 要求 | 原因 |
|:----|:----|:-----|
| 单行业推荐上限 | 不超过推荐总数的40% | 避免行业集中风险 |

## 6.2 推荐数量限制

| 条件 | 推荐上限 |
|:----|:--------:|
| 正常市场 | 5只 |
| 震荡市 | 3-5只 |
| 熊市 | 2-3只 |
| 特殊情况(如政策驱动行情) | ≤ 8只（需备注） |

## 6.3 持续跟踪

- 已推荐标的在持仓期间持续跟踪评分变化
- 评分降至60分以下时触发"重新评估"标记
- 触发止损的标的在5个交易日内不再推荐
- 连续3次推荐后止损的标的，冻结2周

# 第九章 报告输出规范

## 9.1 每日推荐报告

每日19:00前输出，包含以下内容：

### 格式选项

**格式A：Markdown精简版**（用于快速查阅）
```
- 精选推荐（≥65分，评分降序）
  - 每只：股票名/代码/评分/建仓区间/止损价/核心逻辑(一句话)
- 全部过筛表（评分+否决判定，表格格式）
- 否决明细
- 合规声明
```

**格式B：HTML完整版**（用于可视化展示）
- 卡片式布局
- 评分雷达图(可选)
- 行业分布统计
- 组合层规则执行情况

### 9.1.1 必含内容

1. **精选推荐列表**（评分降序）
   - 股票名称、代码、行业标签
   - 六维评分明细（各维度分数）
   - 关键指标（PE、MA5/MA10/MA20、RSI、量比）
   - 操作建议（建仓区间、止损价、仓位上限）
   - 一句话核心逻辑

2. **全部标的过筛表**
   - 所有核心池标的的评分、否决判定
   - 维度分数明细

3. **否决明细**
   - 逐个列出否决原因

4. **合规声明**
   - PE(TTM)计算方式确认
   - 数据源标注
   - 免责声明

## 9.2 每日个股简报

每只核心池股票的独立分析简报，在推荐报告生成前产出。

### 内容结构

```
1. 行动指南（可买条件/不可买条件/操作区间）
2. 评分总览（六维分数表）
3. 评分逻辑详解（每项评分说明）
4. 一票否决检查结果
5. 大盘与行业环境
6. 个股技术面分析(日线+周线)
7. 关键价位与历史概率
8. 资金面验证
9. 消息面与驱动因素
10. 中长期趋势判断
11. 行业专题分析(轮换)
12. 分风格操作策略(短线/中线/长线)
13. 风险提示(系统性/行业/公司/不可量化)
14. 总结与次日操作建议
```

## 9.3 输出时间线

| 时间 | 产出 | 说明 |
|:----|:----|:------|
| 16:00-17:00 | 个股简报 | 收盘后逐只分析 |
| 17:00-18:30 | 后评估(上一日推荐) | 评估昨日推荐表现 |
| 18:30-19:00 | 推荐报告 | 评分+过筛+推荐输出 |
