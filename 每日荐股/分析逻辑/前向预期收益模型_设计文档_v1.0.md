## 一、背景

v2.9 解决了"Top 5不推已爆发股票"的展示层问题（A档强制席位+C8拦截），但评分体系的核心矛盾仍然存在：

> **当前评分函数是截面排名（cross-sectional ranking），而非时序预测（time-series forecasting）。**
> 所有因子 f_i 是"并发因子"——描述股票今天的状态，而非预测明天的方向。

路线二的目标：建立一个**前向预期收益模型**，让评分直接回答"明天（及未来1-5天）谁更可能涨"，而非"今天谁涨得好"。

---

## 二、两阶段架构

```
阶段A（2026-05-23 → 2026-08-23）：数据积累管线
  ├── 每日评分后自动落库（分项得分+上下文+次日收益回填）
  ├── 零侵入：不改评分逻辑，不干扰现有流水线
  └── 目标：积累 ≥60个交易日 × ≥50只股票 ≈ 3000+ 条样本

阶段B（2026-08-23 启动）：前向因子建模
  ├── 单因子 IC/ICIR 分析 → 识别真正的前向预测因子
  ├── 多因子回归 → 构建预期收益模型
  ├── 滚动OOS验证 → 防过拟合
  └── 模型集成至 scoring_engine_v3.0
```

## 三、阶段A：数据积累管线（本次施工范围）

### 3.1 数据模型

每天每只通过否决的股票记录一行，JSONL 格式（每行一条 JSON），文件路径：

`代码文件/数据/score_history.jsonl`

#### 字段定义

| 字段组 | 字段 | 类型 | 说明 |
|:-------|:-----|:-----|:-----|
| **标识** | `date` | str | 交易日 YYYY-MM-DD |
|  | `code` | str | 股票代码 |
|  | `name` | str | 股票名称 |
|  | `industry` | str | 申万二级行业 |
| **上下文** | `phase` | str | 板块相位（潜伏期/主升调整/高潮期/衰退期）|
|  | `change_pct` | float | 当日涨跌幅% |
|  | `turnover` | float | 当日换手率% |
|  | `pe` | float | PE(TTM) |
| **分项得分** | `S_Base` | int | 基础门槛(0-10) |
|  | `S_Fund` | int | 基本面(0-15) |
|  | `S_Tech` | int | 技术面(0-20) — 已含相位折扣 |
|  | `S_Money` | int | 资金面(0-20) — 已含相位折扣 |
|  | `S_News` | int | 消息面(0-15) — 已含相位折扣 |
|  | `S_Risk` | int | 风控(0-5) |
|  | `S_SectorTrend` | int | 板块趋势(0-20) |
|  | `TotalScore` | int | 总分(0-100) |
| **技术子项** | `S1_MA`...`S8_Momentum` | int | 8个技术子项原始分 |
|  | `raw_tech` | int | 技术原始分(0-27) |
| **目标变量** | `ret_t1` | float | T+1 日涨跌幅%（次日回填）|
|  | `ret_t3` | float | T+3 累计涨跌幅%（回填）|
|  | `ret_t5` | float | T+5 累计涨跌幅%（回填）|
|  | `ret_t1_vs_market` | float | T+1 超额收益%（个股-全市场中位数）|

## 四、阶段B：前向因子建模（预留设计，阶段A完成后启动）

### 4.1 单因子IC分析

对每个分项得分做 IC（Information Coefficient）分析：

```
IC(S_Tech, ret_t1) = corr(技术得分排序, T+1收益排序)
ICIR = mean(IC) / std(IC)  （信息比率）
```

**预期发现**（假设）：
- S_Tech（已含相位折扣）→ 正IC，短期动量效应
- S_Money（已含相位折扣）→ 弱IC，资金流滞后于价格
- S_SectorTrend → 正IC，板块动量有前向预测力
- S_Fund → 近零IC，基本面因子在1-5日尺度无预测力

### 4.2 多因子预期收益模型

```
E[ret_t1] = α + β1×S_Tech + β2×S_SectorTrend + β3×phase_dummy + β4×change_pct + ε
```

使用滚动窗口训练（前40日训练→预测后20日），OOS验证。

### 4.3 集成路径

模型验证通过后：
- scoring_engine_v3.0 将 E[ret_t1] 作为独立维度纳入总分
- 或替换现有技术面+资金面得分为纯前向预测分
- 配合v2.9的展示规则（A档强制席位+C8拦截），形成完整的"预测→展示"闭环

## 五、风险与约束

| 风险 | 缓解措施 |
|:-----|:---------|
| 3个月数据量不足（~3000条） | 仅做线性回归，不做ML；IC显著水平设p<0.05 |
| **电脑不定期关机→评分断档** | ① 缺失交易日评分永久丢失（无法追溯，依赖当日动态池+板块数据）；② 回填脚本用K线历史数据，关机后开机自动追赶所有null记录；③ 60个交易日目标对应约4-5个日历月（假设80%开机率）；④ `--stats` 命令可随时查看覆盖率 |
| 市场风格切换（牛市→熊市因子失效） | 滚动窗口训练+衰减加权（近1月权重>远2月）|
| 过拟合 | OOS验证强制要求；v3.0上线前需3个独立月验证 |
| 数据断裂（停牌/除权） | ret_t1缺失时标记null，不纳入回归 |
