## 一、评估体系总纲

### （一）核心定位

次日后评估不是简单的「涨跌统计」，而是「评分质量检验 + 规则有效性验证 + 逻辑迭代驱动」三位一体的优化引擎。每日荐股分析与次日后评估形成完整闭环：

- N日20:00：每日荐股分析（开盘检查通过后执行，使用当前版逻辑白皮书 v2.9）
- N+1日15:00：次日收盘数据就绪
- N+1日19:00：次日后评估（开盘检查通过后执行，含数据采集、归因分析、参数校准建议）
- N+1日20:00：新版每日荐股分析（使用评估优化后的最新版逻辑白皮书）

评估结果驱动逻辑白皮书参数迭代，评估报告为中间产出，最终目标是将评估发现转化为可执行的参数修改建议，直接输入下一版逻辑白皮书。

**v1.6 新增定位**：后评估不仅是荐股逻辑的"质检员"，也是自身的"校准仪"——元评估框架（§7.5）持续监控评估体系本身的报警有效性，确保裁判的尺子不会偏。

### （二）核心指标

| 指标 | 公式 | 目标 | 说明 |
|:----|:----|:----:|:-----|
| 次日胜率 | 盈利次数 / 总推荐次数 | ≥浮动基准(§7.5.2) | 按次日收盘价计，含滑点 |
| 次日盈亏比 | 总盈利 / 总亏损 | ≥1.5:1 | 含次数权重，反映整体赔率 |
| 组合次日收益 | Σ各股次日收益率 / 推荐只数 | >0% | 等权组合视角 |
| 超额收益 | 组合次日收益 − 沪深300次日涨跌 | >0% | 跑赢大盘能力 |
| 评分区分度 | ≥70分组胜率 vs <70分组胜率 | 差值≥15% | 高分股确实比低分股表现好 |
| 评分区分度（相对排名） | spearmanr（评分排序，涨跌幅排序） | >0.2 | 消除市场beta对分组胜率差的影响 |
| 维度误判率 | 某维度给高分且亏损>3%次数 / 该维度高分总次数 | ≤20% | 见第三章 |
| 否决误杀率 | 被否股次日涨>5%只数 / 被否总只数 | ≤15% | 否决是否过严 |
| 豁免成功率 | 豁免股盈利比例 | ≥65% | 豁免条件是否有效 |
| 拥挤度预警有效性 | 触发拥挤预警的股票中次日跌>2%比例 | ≥60% | 高换手+高量能拥挤标记的有效性 |
| 路径优选有效性 | 各路径下推荐胜率差异 | 差异≥15% | 见§3.5场景化回检 |
| 动态权重区分度 | 上升趋势组 vs 下降趋势组推荐胜率差异 | 上升组≥下降组+10% | 市场状态自适应权重的效果验证 |
| **C8拦截有效性** ⭐ | C8被拦截股次日涨>3%只数 / C8拦截总只数 | ≤20% | v2.9新增：单日>7%追涨拦截是否误杀 |
| **A档席位填充率** ⭐ | Top5中A档只数 / 5 | ≥40%（≥2只） | v2.9新增：验证A档强制席位执行情况 |
| **A档vs非A档胜率差** ⭐ | A档Top5胜率 − 非A档Top5胜率 | ≥10% | v2.9新增：A档是否确实更优 |
| **相位折扣分面有效性** ⭐ | 折扣后各面误判率 vs 折扣前（回测） | 折扣后 ≤ 折扣前 | v2.9新增：折扣是否有效降低误判 |
| **元评估报警有效性** ⭐ | 报警后调整→10日胜率提升≥2%的次数/总报警次数 | ≥60% | 评估体系自身校准(§7.5) |

⭐ = v1.6 新增指标

**大盘环境归因（v1.6 升级为浮动基准）**：所有指标的计算结果必须附带当日大盘状态标记。v1.5 的固定三档阈值（强势/正常/弱势）升级为浮动基准体系，详见§7.5.2。

### （三）自动化调度时间线

铁律量化每日工作流由 daily_workflow.ps1 统一调度，v2.9 已扩展为 7 个 Phase：

| Phase | 时间 | 内容 | 模式 | 产出 |
|:-----:|:----:|:-----|:----:|:-----|
| 1 | N日 20:00 | 构建动态股票池 | daily/daily_latest | 选股池JSON |
| 2 | N日 20:00 | 批量数据采集 | daily/daily_latest | 行情+财务数据 |
| 3 | N日 20:00 | 评分引擎 v2.9（否决+评分+落库） | daily/daily_latest | 评分结果 + score_history.jsonl |
| 3.5 | N日 20:00 | 收益回填（路线二 阶段A） | daily/daily_latest | 历史null记录回填 |
| 4 | N日 20:00 | 生成每日荐股报告 | daily/daily_latest | HTML/PDF报告 |
| 5 | N日 20:00 | 重点股票深度分析 | daily/daily_latest | 重点股票报告 |
| 6 | N日 20:00 | 数据归档 | daily/daily_latest | 历史数据存档 |
| 7 | N+1日 19:00 | 模拟交易引擎 | eval | 模拟交易执行 |

**三个调度模式**：

| 时间 | 任务 | 模式 | 开盘检查 | 产出 |
|:----:|:----|:----:|:--------:|:-----|
| N日 20:00 | 每日荐股分析 | daily | 是 | Phase 1-6 → 每日股票推荐报告 |
| N+1日 19:00 | 次日后评估 | eval | 是 | 评估报告_YYYYMMDD.docx + Phase 7 模拟交易 |
| N+1日 20:00 | 每日荐股分析（新版） | daily_latest | 是 | 使用优化后白皮书的 Phase 1-6 |

**关键原则**：一是开盘判断前置，每个任务启动时先检查目标日是否开盘，不开盘则跳过，不阻塞后续任务；二是评估→优化→新分析闭环，N+1日19:00评估完成后立即优化白皮书，1小时后新版分析使用优化后的参数；三是自动化日志，每次执行记录到 workflow_records.csv，运行日志按月保存；四是人工确认点，次版本升级需人工确认后执行，参数微调自动执行。

### （四）输出文档命名规范

次日后评估生成的报告统一命名为 `评估报告_YYYYMMDD.docx`，其中 YYYYMMDD 为被评估的荐股日期（N日），而非评估执行日（N+1日）。例如正常场景下，N日2026-05-21、N+1日2026-05-22，报告命名为评估报告_20260521.docx。

**存储目录结构**：

```
事后评估\
├── 次日后评估白皮书_v{version}.md        ← 本文档
├── 次日后评估白皮书_v{version}.docx      ← 发布的DOCX版本
├── 次日后评估白皮书_CHANGELOG.md         ← 版本变更记录
├── 评估报告_YYYYMMDD.docx                ← 每日评估报告
├── records.csv                           ← 逐日评估明细
├── summary.csv                           ← 汇总统计
└── issues.csv                            ← 问题跟踪
```

**评估报告内容结构**：每份评估报告包含整体表现（胜率、盈亏比、组合收益、超额收益）、逐股明细（各推荐标的模拟交易结果）、维度回检摘要（技术/资金/板块/消息四维度预期验证，含相位折扣分面有效性）、规则验证（否决误杀率、C8拦截有效性、豁免成功率、巨量惩罚有效性）、参数校准建议（需调整的参数及建议值）、优化状态（灰度中项、待确认项）。详细报告模板见附录A。

### （二）模拟交易计算

**1. 买入模拟**

| 条件 | 买入价 | 说明 |
|:----|:------|:------|
| 正常开盘 | T+1日09:30开盘价 × 1.005 | 含0.5%单向滑点 |
| 一字涨停开盘 | 标记「无法成交」 | 不计入胜率统计 |
| 开盘跌>3% | 标记「开盘异常」 | 独立统计，不计入常规胜率 |

**2. 卖出模拟**

| 优先级 | 触发条件 | 卖出价 | 说明 |
|:-----:|:---------|:------|:------|
| 1 | 持仓期间最低价 ≤ 止损价 | 按触发价卖出 | ATR动态止损 |
| 2 | 盈利>10%后收盘跌破MA5 | 次日开盘价卖出 | 止盈保护 |
| 3 | 大盘当日跌>3% | 当日收盘价卖出 | 系统性风险 |
| 4 | 以上均未触发 | T+1日收盘价卖出 | 默认次日平仓 |

**3. 止损计算**

止损价 = 买入价 − 2 × ATR（14），其中ATR（14）使用T日收盘计算的14日ATR值。止损硬上限为−8%，即使ATR计算超过−8%，最大止损仍为−8%。

**4. 日内止损检查**

每个推荐标的在T+1日模拟卖出前，先检查日内最低价是否触发止损：

- 第一步：检查T+1日最低价 ≤ 止损价。若是，则以触发价卖出，记录 exit_reason = "intraday_stop"；若否，则继续检查其他条件（止盈/系统性风险/默认收盘价）。
- 止损价 = 买入价 − 2 × ATR（14），止损硬上限 −8%。

## 三、评分维度回检

### （一）逐维度预期验证

对每个亏损>3%的推荐标的，回检每个评分维度的预期是否成立。

**1. 技术面回检（v1.6：含相位折扣效果）**

T日评分依据（均线多头排列、均线收敛、底部抬高、量价配合、RSI 40-55、MACD金叉）逐一与T+1日实际表现对照，分别判定预期正确或错误。

v2.9 技术面已含相位折扣（潜伏×1.0/主升×0.75/高潮×0.55/衰退×0.45）。回检时需区分：误判是原始技术信号的问题，还是相位折扣力度的问题。若同一板块相位下技术面误判集中出现，说明该相位的折扣系数可能需要调整。

**2. 资金面回检（v1.6：含相位折扣效果）**

T日评分依据（连续净流入、量升价平、换手率回升）逐一与T+1日资金流向对照，判定趋势延续或趋势反转。

v2.9 资金面同样受板块相位折扣。回检时需关注：高潮期资金面被折扣后是否仍虚高？若折扣后资金面得分与次日实际资金流向严重背离，说明折扣系数不够或资金面指标本身在高潮期失效。

**3. 板块相位回检**

根据T日判定的板块状态（潜伏期/主升调整/高潮期/衰退期），对照T+1日板块实际表现，判定相位判断是否正确。

v2.9 板块相位直接影响技术/资金/消息三个面的折扣系数（影响范围从11%→52%），相位判断错误的影响被显著放大。回检时必须标注：相位判断正确/错误，若错误则评估对三个面得分的连锁影响。

**4. 消息面回检（v1.6：含相位折扣效果）**

根据T日的催化剂预期（明确催化剂即将落地/行业催化预期），对照T+1日实际落地情况，判定催化是否有效。

v2.9 消息面同样受板块相位折扣（CAR5包含当日暴涨 → 去水分），且C8规则（单日>7%且非潜伏期不进Top5）直接限制高涨幅股的消息面贡献。

**5. 风向标回检**

选取每个推荐标的所在行业的龙头股作为风向标。如果T+1日龙头股表现正常但推荐标的大跌，说明问题在个股而非行业；如果龙头股也大跌，说明行业/板块判断出问题。风向标选取规则：每个申万一级行业选取市值最大、流动性最好的1只股票。

### （二）维度误判率

维度误判率 = 某维度给高分（高于该维度满分60%）且该股票次日触发误判条件的次数 / 该维度给出高分总次数。

误判触发条件根据大盘环境动态调整：

| 大盘环境 | N日全市场平均涨幅 | 误判触发条件 |
|:--------|:----------------:|:------------|
| 强势市场 | >+2% | 个股涨幅 < 全市场平均 − 3%（跑输大盘） |
| 正常市场 | −2% ~ +2% | 亏损 > 3%（维持当前标准） |
| 弱势市场 | <−2% | 亏损 > 2%（收紧） |

全市场平均涨跌幅 = 当日所有A股（约5000只）等权平均涨跌幅。

**1. 误判率分级**

| 误判率 | 判定 | 操作 |
|:-----:|:----|:-----|
| ≤10% | 优秀 | 维持该维度权重 |
| 10%−20% | 正常 | 关注趋势 |
| 20%−30% | 偏高 | 连续5日超20% → 触发维度重构 |
| >30% | 失效 | 立即暂停该维度，排查评分逻辑 |

**2. 误判类型标记**

亏损>3%时，必须明确标注一个主要误判维度：技术面误判（TECH_MISJUDGE）、资金面误判（MONEY_MISJUDGE）、板块面误判（SECTOR_MISJUDGE）、消息面误判（NEWS_MISJUDGE）、基本面误判（FUND_MISJUDGE）、风控误判（RISK_MISJUDGE）。

v1.6 新增误判子类型：**相位折扣误伤（PHASE_DISCOUNT_HURT）**— 折扣后得分偏低导致优质股未能入选Top5，次日实际大涨；**相位折扣不足（PHASE_DISCOUNT_WEAK）**— 折扣力度不够，高相位股仍高分入选但次日大跌。

### （三）相关系数计算（周更 → 日更滚动）

每周日计算各维度评分与次日涨跌幅的Spearman相关系数：

ρ（维度X）= spearmanr（维度X评分，次日实际涨跌幅）

| 系数范围 | 判定 | 操作 |
|:-------:|:----|:-----|
| ρ > 0.3 | 有效预测 | 权重可上调 |
| 0.1 ≤ ρ ≤ 0.3 | 弱相关 | 维持当前权重 |
| ρ < 0.1 | 无预测力 | 重构评分逻辑 |
| ρ < 0（负相关） | 反向指标 | 立即暂停排查 |

**v1.6 升级**：相关系数从每周计算升级为每日滚动计算（5日窗口），详见附录B 5日滚动窗口说明。当 score_history.jsonl 积累≥30条记录后，相关系数自动切换为基于实际T+1收益计算（而非当日涨跌幅近似）。

### （四）误判子类型分析

**核心思路**：当前误判标记只到维度级，但同一维度内的不同误判原因命中率差异很大。「均线多头假突破」和「RSI钝化」都是技术面误判，但修复方案完全不同。只有拆到子类型级别，才能精准关闭失效信号、保留有效信号。

**1. 子类型分类体系**

亏损>3%时，除标注维度级误判标记外，必须进一步标注子类型：

| 维度级 | 子类型 | 标记 | 典型场景 |
|:-------|:-------|:-----|:---------|
| 技术面 | 均线多头假突破 | TECH_FAKE_BREAK | 均线刚形成多头排列，次日直接破位 |
| | 量价背离 | TECH_DIVERGENCE | 放量但价格不上涨，或缩量上涨 |
| | RSI钝化 | TECH_RSI_BLUNT | RSI在60以上钝化后回落 |
| | MACD假金叉 | TECH_FAKE_GOLDEN | DIF上穿DEA后立即死叉 |
| | 支撑位假突破 | TECH_BREAK_SUPPORT | 跌破关键支撑位后加速下跌 |
| 资金面 | 主力假流入 | MONEY_FAKE_INFLOW | 大单净买为正，但小单净卖出更大 |
| | 尾盘拉升出货 | MONEY_CLOSE_PUMP | 收盘前15分钟拉升，但全天主力净流出 |
| | 缩量反弹 | MONEY_SHRINK_BOUNCE | 反弹时成交量持续萎缩 |
| 板块面 | 潜伏期误判 | SECTOR_EARLY_MISS | 判断板块在潜伏期，实际仍在下跌通道 |
| | 启动期夭折 | SECTOR_ABORT | 板块启动后立即回调，未形成趋势 |
| | 主升期见顶 | SECTOR_TOP | 板块主升末端追入，次日开始回调 |
| 消息面 | 催化延迟 | NEWS_DELAY | 催化剂预期时间未落地 |
| | 催化落空 | NEWS_FAIL | 催化剂确定取消或远低于预期 |
| | 反向消息 | NEWS_ADVERSE | 出现未预见的利空消息 |
| **v1.6新增** | **C8误拦截** | **C8_FALSE_BLOCK** | C8拦截后次日继续大涨（阈值偏严） |
| | **A档虚高** | **TIER_A_FALSE** | A档评级但次日大跌（相位判断可能错误） |
| | **相位折扣误伤** | **PHASE_DISCOUNT_HURT** | 折扣后优质股被挤出（折扣系数偏高） |
| | **相位折扣不足** | **PHASE_DISCOUNT_WEAK** | 折扣力度不够，高位追入后次日暴跌 |

**2. 子类型命中率统计**

每个子类型单独统计命中率：子类型命中率 = 该子类型被标记次数 / 该子类型对应的评分信号出现总次数。

例如：统计过去30日「均线多头」信号出现的总次数，和其中被标记为 TECH_FAKE_BREAK 的次数，计算出该信号的虚假率。

**3. 信号级别停用与恢复机制**

| 命中率 | 判定 | 操作 |
|:-----:|:----|:------|
| ≤10% | 正常 | 维持信号权重 |
| 10%−20% | 观察 | 关注趋势，不操作 |
| 20%−30% | 偏高 | 信号降权50%；连续5日超20%则暂停该信号 |
| >30% | 失效 | 立即暂停该信号，从评分逻辑中剔除 |

被暂停的信号，如果后续30日内命中率降至≤15%，可自动恢复。恢复后先以50%权重运行10个交易日，稳定后再恢复全权重。

**4. 自动化频率**

每日统计各子类型当日的误判标记，更新累计命中率；每周一生成子类型命中率排行榜，输出需要关注的信号列表；每月回顾被暂停的信号，检查是否满足恢复条件。

### （五）场景化回检——路径优选分析

**来源**：华泰金工2026年5月研究报告《多维择时模型的拆解与重构》。研究发现不同因子在不同市场场景下表现差异显著，路径优选模型日频夏普比达1.72，显著优于不分路径的等权模型（1.48~1.50）。

**1. 四路径分类**

每只推荐标的在T日应标记所属路径：

| 路径 | 典型特征 | 适用评分维度 |
|:----|:---------|:-----------|
| 追高（Chase-High） | 均线多头排列+放量上涨+RSI>55 | 技术面权重最高 |
| 抄底（Bottom-Fish） | 缩量下跌+RSI<35+布林触及下轨 | 资金面+基本面权重最高 |
| 追空（Chase-Short） | 均线空头排列+放量下跌 | 风控权重最高 |
| 逃顶（Escape-Top） | 连续上涨+RSI>70+布林触及上轨+拥挤度预警 | 风控+资金面权重最高 |

分类特征已从仅用MA+RSI扩展为6特征矩阵：MA5/MA10/MA20相对位置、RSI（14）、当日涨跌幅、量比、布林带位置（上轨/中轨/下轨）、MACD位置（水上/水下/金叉/死叉）。

v1.6 新增路径与A档交叉统计：各路径下A档/B档/C档的分布及对应胜率，用于验证A档强制席位在不同路径下的效果差异。

**2. 按路径统计胜率**

评估时，除计算整体胜率外，按路径分别统计胜率、盈亏比、误判主要维度及趋势方向。路径优选有效性 = max（各路径胜率）− min（各路径胜率），目标 ≥ 15%。

**3. 场景适应性评估**

对比不同市场状态下各路径的表现：

| 大盘状态 | 最优路径 | 最差路径 | 启示 |
|:--------|:--------|:--------|:------|
| 上升趋势 | — | — | 追高有效，逃顶易过早离场 |
| 震荡行情 | — | — | 抄底+逃顶双向策略 |
| 下降趋势 | — | — | 追空有效，抄底易被套 |

当数据积累≥10个交易日后，此表可指导评分维度的市场状态自适应权重调整。

### （六）相位折扣三维有效性评估 ⭐

**v1.6 新增**。v2.9 核心变化：板块相位折扣从仅技术面（11%权重）扩展至技术+资金+消息三面（52%权重）。此项评估专门追踪折扣是否合理。

**1. 分面折扣有效性**

| 折扣面 | 满分 | 折扣影响 | 评估方法 |
|:------|:----:|:--------|:---------|
| 技术面 S_Tech | 20 | 高潮期最多砍9分 | 折扣后技术面得分 vs T+1实际涨幅的Spearman ρ |
| 资金面 S_Money | 20 | 高潮期最多砍9分 | 折扣后资金面得分 vs T+1资金流向的吻合率 |
| 消息面 S_News | 15 | 高潮期最多砍7分 | 折扣后消息面得分 vs T+1消息面实际兑现率 |

**2. 折扣系数合理性判定**

按相位分别统计折扣后的误判率：

| 相位 | 折扣系数 | 统计指标 | 判定标准 |
|:-----|:-------:|:---------|:---------|
| 潜伏期 | ×1.0 | 误判率基准 | 基准对照组 |
| 主升调整 | ×0.75 | 误判率 vs 潜伏期 | 误判率应 ≤ 潜伏期（折扣有效降低误判） |
| 高潮期 | ×0.55 | 误判率 vs 潜伏期 | 误判率应 ≤ 潜伏期；若显著更低说明折扣偏严 |
| 衰退期 | ×0.45 | 误判率 vs 潜伏期 | 误判率应 ≤ 潜伏期；关注是否过度折扣导致漏选 |

**3. 折扣力度校准决策树**

```
折扣后误判率 > 潜伏期基准 → 折扣不足 → 建议下调系数0.05
折扣后误判率 < 潜伏期基准且差值>15% → 折扣过度 → 建议上调系数0.05
折扣后优质股入选率 < 30%（潜伏期优质股中仅<30%入选Top5）→ 折扣误伤 → 仅对潜伏期放宽
折扣后劣质股入选率 > 40%（高潮期入选股中>40%次日亏损）→ 折扣不足 → 收紧高潮/衰退期折扣
```

**4. 数据积累要求**

- 初期（<20个交易日）：仅做定性观察，不输出调整建议
- 中期（20-60个交易日）：分面统计，输出"建议关注"级别的提示
- 成熟期（≥60个交易日）：全自动输出折扣系数调整建议，含置信区间

## 四、规则有效性诊断

### （一）否决规则验证

**1. 绝对否决跟踪**

对每个被绝对否决（未进推荐池）但实际次日大涨>5%的标的，记录否决原因、股票名称、T日评分、T+1日涨跌幅，并判定误杀原因（阈值偏严/行业PE应调整/牛市应放宽阈值/均线参数需调整/净利润亏损不应豁免）。

绝对否决误杀率 = 被绝对否决但次日涨>5%的只数 / 被绝对否决总只数。目标 ≤ 5%，连续3日>5%则审查相应否决条件的阈值。

**2. 条件否决跟踪**

每个被条件否决（评分达标但触发了条件否决条件）的标的，跟踪次日表现：记录股票、否决条件、豁免所需分、实际得分、次日涨跌幅。计算条件否决平均涨幅与推荐标的平均涨幅的差值。差值>3%说明条件阈值过严需放宽，差值<−3%说明阈值合理。

**3. 趋势豁免评估**

分别计算豁免组与非豁免组的胜率。豁免组胜率 ≥ 65% 说明豁免条件有效；豁免组胜率 < 50% 说明豁免条件失效；豁免组连续3天低于非豁免组10%以上，暂停趋势豁免功能。

**4. C8条件否决跟踪 ⭐**

**v1.6 新增**。v2.9 新增C8规则：单日涨跌幅>7%且非潜伏期 → 不得进入Top5展示。此项跟踪C8拦截的准确性。

| 统计项 | 公式 | 目标 |
|:------|:-----|:----:|
| C8拦截率 | C8拦截只数 / 非潜伏期推荐池总只数 | —（监测用） |
| C8拦截正确率 | C8拦截且次日跌>0%只数 / C8拦截总只数 | ≥60% |
| C8误杀率 | C8拦截但次日涨>3%只数 / C8拦截总只数 | ≤20% |
| C8漏网率 | 未被C8拦截但次日跌>5%的非潜伏期高涨幅股 / 非潜伏期高涨幅股总数 | ≤15% |

C8误杀率>20%连续3日 → 建议上调C8阈值（>7%→>8%或>9%）。
C8漏网率>15%连续3日 → 建议下调C8阈值或扩大拦截范围。
C8拦截正确率<50%连续5日 → C8规则可能无效，建议暂停并回测。

### （二）巨量惩罚监控

**1. 拥挤度预警阈值**

拥挤度预警不再使用固定阈值（换手率>8%+量比>2），改为动态分位阈值：

| 阈值类型 | 说明 |
|:---------|:-----|
| 动态分位阈值 | 换手率 > 该股票自身20日分位的80%值 且 量比 > 1.5 |
| 或 | 换手率 > 推荐池80分位值 且 量比 > 推荐池80分位值 |

**2. 量比惩罚阈值**

每日统计被量比超过阈值的股票次日表现，阈值根据大盘状态动态调整：

| 大盘状态 | 量比惩罚阈值 |
|:---------|:-----------:|
| 强势市场（>+2%） | >15 |
| 正常市场（−2%~+2%） | >12（维持当前） |
| 弱势市场（<−2%） | >8 |

判定标准：量比超过阈值的股票中，后续3日跌幅>3%的比例应 ≥ 70%。若连续3天该比例 < 70%，上调封顶阈值。

### （三）分市场阶段分析

在评估报告中按市场阶段（牛/震荡/熊）拆分统计胜率：

| 市场阶段 | 大盘状态 | 统计 |
|:-------:|:--------|:-----|
| 牛市 | MA5>MA20>MA60 | 胜率/盈亏比/评分区分度 |
| 震荡 | 均线交织 | 胜率/盈亏比/评分区分度 |
| 熊市 | MA5<MA20<MA60 | 胜率/盈亏比/评分区分度 |

用途：识别评分体系在不同市场环境下的表现差异，为白皮书第七章「市场情绪自适应」提供数据支撑。

### （四）对照组评估

**核心问题**：当前评估只验证了「推荐了的股票」表现，但缺少关键对照——「没推荐的股票」是不是真的更差？如果否决池的胜率和推荐池差不多，说明否决规则在误杀；如果推荐池的胜率和全市场随机选股差不多，说明评分体系没有区分度。

**1. 三组对照结构**

| 分组 | 定义 | 期望胜率 | 说明 |
|:----|:-----|:--------:|:------|
| 推荐池 | 评分通过 + 无否决 + 被选中推荐的标的 | ≥浮动基准 | 我们的目标 |
| 被否决池 | 评分达标但触发否决条件被剔除的标的 | ≤40% | 否决应该选出更差的 |
| 全市场基准 | 当日所有可交易A股的平均涨跌幅（等权） | ≈50% | 随机水平 |

**2. 关键判定指标**

| 指标 | 公式 | 目标 | 预警值 |
|:----|:----|:----:|:------:|
| 否决有效度 | 推荐胜率 − 否决池胜率 | ≥20% | <10%连续5日 |
| 评分区分度 | 推荐胜率 − 全市场胜率 | ≥10% | <5%连续5日 |
| 否决误杀率 | 否决池涨>5%占比 | ≤15% | >15%连续3日 |

**3. 诊断规则**

否决规则过严（否决有效度<10%）：被否决池胜率接近推荐池，说明部分否决条件无效在误杀好股，操作上逐条审查否决条件，暂停区分度最低的1−2条。

评分体系失效（评分区分度<5%）：推荐池表现接近随机水平，说明评分维度没有预测力，操作上全面审查六维评分的相关系数，触发维度重构。

否决池跑赢推荐池（否决有效度为负值）：被否掉的股票比推荐的表现更好，说明否决条件完全反向，操作上立即暂停所有否决条件，逐一回测后恢复。

**4. 数据存储**

在 summary.csv 中新增字段：recommended_win_rate（推荐池胜率）、vetoed_win_rate（被否决池胜率）、market_win_rate（全市场基准胜率，沪深300替代）、veto_effectiveness（否决有效度）、score_distinction（评分区分度）、**c8_block_count（C8拦截数）**、**c8_correct_rate（C8拦截正确率）**、**a_tier_fill_rate（A档席位填充率）**、**phase_discount_effectiveness（相位折扣有效性）**。

## 五、逻辑迭代引擎

### （二）L2 趋势预判机制 ⭐

**v1.6 新增**。v1.5 只有 L1（阈值报警，即指标达标后触发），缺少预警能力。L2 补充了"还没到阈值但正在恶化"的趋势检测。

**1. 预判规则**

对每个评估指标计算近5日趋势斜率（线性回归斜率 × 5日）：

| 指标 | 正常方向 | 预警斜率 | 预判信号 |
|:----|:--------|:--------|:---------|
| 胜率 | 高为优 | 连续3日下降且累计降幅>5% | 胜率可能即将跌破阈值 |
| 误判率 | 低为优 | 连续2日上升且累计升幅>3% | 某维度可能在恶化 |
| 否决误杀率 | 低为优 | 连续2日上升 | 否决阈值可能偏严 |
| 评分区分度 | 高为优 | 连续3日下降 | 评分体系预测力衰减 |

**2. 预判信号处理**

L2预判信号不触发自动调整（与L1不同），而是：
- 在评估报告中新增「预警关注」栏位
- 标注"若趋势延续，预计X日后触发L1阈值"
- 给人工提前干预的窗口期

**3. 与L1/L3的关系**

```
L1（阈值报警）：指标达标 → 自动触发调整流程
L2（趋势预判）：指标接近阈值 → 预警但不自动调整
L3（因子发现）：子因子IC分析 → 精确建议（数据≥60日后激活）
```

### （四）版本升级决策树

**1. 参数微调（不升版本号）**

可自动执行无需人工确认的条件：单个阈值调整幅度 ≤ 10%，仅涉及数值变更不改变评分逻辑结构，调整依据来自连续5日以上的评估数据。例如PE否决阈值从80上调至85、ATR止损倍数从2.0调整为2.2、C8阈值从7%上调至8%。

**2. 次版本升级（v1.0 → v1.1）**

需生成修订草案，AI提出建议，人工确认后执行：新增或删除评分子项、维度权重调整（单个维度±5%以上）、否决条件增删、市场阶段参数整体切换。触发条件包括某维度误判率超20%连续5日、评分区分度<10%连续5日、整体胜率<50%连续一周。

**3. 主版本升级（v1.x → v2.0）**

必须人工审核，全面重构：评分框架结构性调整、股票池体系规则变更、新增/废除核心机制、市场自适应逻辑重新设计。触发条件包括月度胜率<45%、多维度同时失效（≥2个维度误判率>20%）、市场结构发生根本性变化。

### （五）灰度测试规则

对评估发现的问题，新规则上线前需经过灰度测试：并行运行5个交易日（新旧规则同时评分，旧规则产出推荐，新规则记录不执行），第6日数据对比（新规则胜率 ≥ 旧规则+5%方可切换），对比通过次日正式切换，切换后跟踪10个交易日确认胜率无明显下降。

### （六）自动化回测引擎

**核心问题**：每次参数修改都是基于当前数据做的判断，但改完的参数真的最优吗？自动化回测引擎允许用历史数据模拟「如果当时用了新参数，结果会怎样」，让每次参数修改都经过历史验证。

**1. 回测流程**

加载历史数据（records.csv中最近30/60/90日的推荐记录及对应的评分明细、否决记录、次日行情）→ 模拟新参数（使用新参数重新计算评分、重新执行否决规则、重新生成推荐列表）→ 对比结果（新参数胜率 ≥ 旧参数胜率 + 3%则建议采纳）→ 输出回测报告（新旧参数各项指标对比表及采纳建议）。

**2. 可回测参数列表**

| 参数 | 回测方法 | 历史数据需求 |
|:-----|:---------|:-----------|
| PE否决阈值（科技80/消费50/金融15） | 调整阈值后重新筛选否决池，计算否决有效度 | 各行业PE值历史记录 |
| 涨幅否决阈值（牛市80%/震荡50%/熊市30%） | 调整阈值后重新筛选否决池，计算误杀率 | 评分+涨幅历史 |
| ATR止损倍数（牛2.5/震荡2.0/熊1.5） | 调整倍数后重新模拟止损触发 | ATR历史值 |
| 量比封顶阈值（当前12） | 调高后重新计算封顶股票的后续表现 | 量比+5日涨跌幅 |
| 均线收敛间距（当前<1%） | 调整间距后重新判断收敛信号准确率 | 均线数据+后续方向 |
| 连续流入天数（当前3日/5日） | 调整天数后重新计算资金面评分胜率 | 资金流向数据 |
| 子类型信号权重（当前均为100%） | 调整权重后重新计算综合评分的区分度 | 各子类型信号触发记录 |
| **C8涨幅阈值（当前>7%）** ⭐ | 调整阈值后重新计算C8拦截正确率 | C8拦截记录+次日涨跌 |
| **相位折扣系数** ⭐ | 调整系数后重新计算三面误判率 | 分相位评分记录+次日涨跌 |

**3. 回测触发条件**

主动触发（人工发起）：准备修改某个参数前，先回测3个候选值选最优；参数修改灰度通过后，回测确认是否真的优于旧参数。

自动触发：某维度误判率超20%连续3日→自动回测该维度各子信号的权重调整方案；否决有效度<10%连续3日→自动回测各否决条件的阈值调整方案；子类型命中率>30%→自动回测剔除该信号后的评分效果；每月1日全参数回测扫描；**C8误杀率>20%连续3日→自动回测C8阈值调整方案**；**某相位折扣后误判率>潜伏期基准连续5日→自动回测该相位折扣系数**。

**4. 回测记录与版本关联**

每次回测生成一条记录存储在 backtest_log.csv，包含回测编号、执行日期、参数名称、当前值、候选值列表、最优值、历史数据范围、新旧胜率对比、提升幅度、状态（待确认/已采纳/已拒绝）、采纳日期。核心原则：每次正式参数修改前，必须有对应的回测记录证明新参数更优。

**1. 数据源切换**

| 当前（v1.6） | 路线二就绪后（v2.0） |
|:------------|:-------------------|
| T日评分 ↔ T+1涨跌幅 近似相关 | T日评分 ↔ T+1/T+3/T+5 实际收益 精确IC |
| 维度级相关系数（6个维度） | 子因子级IC（8个技术子项+资金子项+板块子项） |
| 固定目标阈值 | 浮动基准（§7.5.2）自动校准 |
| 单参数独立调整 | 协方差分析 → 参数联动建议 |

**2. 子因子IC自动分析**

当 score_history.jsonl 记录数 ≥ 60 日 × 50 只 = 3000 条时，每晚评估后自动运行：

```
对每个子因子：
  IC = corr(子因子得分排序, ret_t1 排序)
  ICIR = mean(IC_近20日) / std(IC_近20日)

输出：
  IC > 0.05 且 ICIR > 0.3 → 有效因子，建议保留/加权重
  IC ∈ [-0.03, 0.03] → 无效因子，建议降权或移出
  IC < -0.03 且 |ICIR| > 0.3 → 反向因子，建议暂停排查
```

**3. 参数联动分析（协方差）**

当数据量≥3000条时，评估系统识别参数间联动关系：

```
例：PE阈值 ↑ 10 → 推荐池扩大 → C8拦截量 ↑ → C8误杀率可能随之变化
评估输出："PE阈值与C8拦截率协方差=+0.4，建议PE阈值调整时同步审查C8阈值"
```

## 七、优化决策流程

### （一）触发条件

| 触发条件 | 判定标准 | 响应动作 |
|:---------|:--------|:---------|
| 胜率警告 | 连续2周胜率<40% | 暂停策略，全面排查 |
| 回撤警告 | 单周组合收益<−10% | 暂停策略，全面排查 |
| 维度失效 | 某维度误判率>20%连续3天 | 触发维度重构流程 |
| 豁免失效 | 豁免组连续3天低于非豁免组10% | 暂停豁免功能 |
| 否决过严 | 否决误杀率>15%连续3天 | 放宽相应阈值 |
| 否决有效度低 | 有效度<10%连续5日 | 逐条审查否决条件，暂停区分度最低的1−2条 |
| 评分区分度低 | 区分度<5%连续5日 | 全面审查六维评分相关系数，触发维度重构 |
| 参数漂移 | 相关系数<0.1 | 该维度权重下调 |

### （二）「假设—验证—切换」流程

**Step 1 — 假设**：基于评估数据提出具体假设。数据来源包括维度误判率、相关系数、否决误杀率。例如：「假设PE否决阈值对于科技股过严，导致误杀率>5%」。

**Step 2 — 回测**：用历史数据验证假设。回测范围至少10个交易日，判定标准为新阈值能降低误杀率至少50%且不提高亏损率。

**Step 3 — 灰度**：新旧规则并行1周对比，详见灰度测试规则。判定标准为新规则胜率 ≥ 旧规则+5%。

**Step 4 — 切换**：胜率提升≥5%且盈亏比不降，则正式切换。同步更新逻辑白皮书参数附表和CHANGELOG。

**Step 5 — 跟踪**：切换后跟踪2周确认效果。核心指标为胜率、盈亏比、维度误判率。如新规则胜率低于旧规则，回退参数并重新分析。

### （三）问题跟踪闭环

所有发现的问题录入 issues.csv，按以下状态流转：发现 → 记录 → 分析 → 方案 → 灰度 → 修复 → 验证 → 关闭。验证不通过则回到发现状态。

| 状态 | 说明 | 责任人 |
|:----|:------|:------|
| 待确认 | 问题已记录，待人工确认 | AI发现→人工确认 |
| 灰度中 | 修复方案正在并行测试 | AI执行 |
| 已修复 | 灰度通过，正式切换 | AI执行 |
| 已关闭 | 验证通过，问题解决 | 人工确认 |

### （四）外部知识融合（月度大循环）

**核心思路**：当前评估体系的自我迭代完全依赖内部数据——自己试错、自己总结、自己优化。但有些问题靠内部数据永远发现不了。月度外部知识融合打破这个闭环，主动获取外部知识，为评估体系的优化提供新视角。

**1. 搜索策略**

每月初通过以下关键词搜索业界新方法：中文关键词包括「A股 短线 技术指标 有效性 实证」「量化选股 因子衰减 T+1 研究」「资金流向 量价分析 预测能力」「止损策略 最优参数 回测 对比」「评分模型 区分度 检验方法」；英文关键词包括「short-term signal effectiveness A-share」「technical indicator predictive power China」「factor decay short-term quantitative trading」「stock scoring model discrimination test」。

**2. 融合流程**

搜索 → 阅读摘要 → 对比当前体系 → 生成采纳建议 → 记录到外部知识调研日志。

每种发现记录包含：核心发现（该方法解决了什么问题）、与当前体系的差异（当前用什么方法、业界用什么方法、差异在哪）、适用性评估（该方法在A股短线场景是否适用）、对接环节（应接入评估体系的哪个环节）、采纳建议（建议尝试/建议跟踪观察/暂不采纳）。

**3. 与内部评估的协作关系**

外部知识融合不替代内部评估，两者互补：内部评估（每日/每周）发现「我们哪做错了」，外部调研（每月）发现「别人有什么更好的方法」。外部方法经回测验证和灰度测试后方可正式切换。

具体协作方式：外部调研发现的新方法进入候选信号列表等待内部数据验证；外部调研发现的参数优化方向直接通过回测引擎回测验证；外部调研发现已在用的方法记录无需变更；外部调研发现的方法与当前体系冲突时记录差异，设计对照实验验证。

**4. 调度与存储**

调度方式为通过定时任务每月1日触发，与重点股票后评估系统共用月度调研任务。调研记录追加写入逻辑积累\元评估\外部知识调研日志.md，候选信号进入逻辑积累\信号发现\候选信号.json。

### （五）元评估框架 — 评估体系的自我校准 ⭐

**v1.6 新增**。后评估体系是荐股逻辑的"裁判"，但裁判的尺子也需要校准。元评估（Meta-Evaluation）持续监控评估体系自身的有效性，确保报警是真正有价值的，而非误报噪音。

**1. 核心指标：报警有效性**

```
报警有效 = 报警触发 → 参数调整 → 10个交易日内胜率提升 ≥ 2%
报警误报 = 报警触发 → 参数调整 → 胜率无变化或下降
报警遗漏 = 未触发报警但胜率连续10日下降 > 5%

报警有效性 = 有效报警次数 / 总报警次数
目标 ≥ 60%
```

**2. 浮动基准（Market-Adaptive Benchmark）**

v1.5 使用固定目标值（如"胜率≥60%"），但不同市场环境下"优秀"的标准不同。v1.6 引入浮动基准：

| 市场状态 | N日全市场等权涨跌幅 | 胜率浮动目标 | 评分区分度浮动目标 |
|:--------|:------------------:|:-----------:|:-----------------:|
| 强普涨 | >+3% | ≥ 全市场上涨比例 − 5% | ≥ 推荐池涨幅 − 全市场中位数涨幅 ≥ 2% |
| 普涨 | +1% ~ +3% | ≥ 65% | ≥ 15% |
| 震荡 | −1% ~ +1% | ≥ 55% | ≥ 12% |
| 普跌 | −3% ~ −1% | ≥ 45% | ≥ 10% |
| 强普跌 | <−3% | ≥ 35%（能少跌就是本事） | ≥ 8% |

评估报告中的"胜率是否达标"不再用固定60%，而是对照当日市场状态下的浮动目标。

**3. 阈值自校准**

每个季度（或每60个交易日），回顾所有评估报警记录，计算各阈值的误报率：

```
若某阈值近60日误报率 > 40%：
  → 阈值过于敏感，自动松弛10%
  → 例：误判率报警阈值 20% → 22%

若某阈值近60日遗漏率 > 30%：
  → 阈值过于迟钝，自动收紧10%
  → 例：否决误杀率报警阈值 15% → 13%
```

阈值自校准结果作为"建议"输出，需人工确认后生效。首次校准需积累≥60个交易日数据。

**4. 元评估自身的数据积累**

| 数据项 | 存储位置 | 用途 |
|:------|:--------|:-----|
| 每次报警记录 | issues.csv（新增 meta_alert 类别） | 回溯报警是否有效 |
| 每次调整记录 | backtest_log.csv | 调整是否带来改善 |
| 市场状态日志 | 每日 workflow_records.csv | 计算浮动基准 |
| 元评估季度报告 | 逻辑积累\元评估\元评估季度报告_YYYYQQ.md | 评估体系整体健康度 |

**5. 元评估触发条件**

- 月度：每月1日自动回顾上月所有报警 → 计算报警有效性 → 输出"评估体系健康度"评分
- 季度：每季度末阈值自校准 → 输出建议调整的阈值列表 → 人工确认
- 紧急：报警有效性 < 40% 连续2月 → 评估体系可能系统性偏差 → 全面排查

**v1.6 浮动基准说明**：胜率、评分区分度等核心指标不再使用固定目标值，改用§7.5.2定义的浮动基准。评估报告中的"达标/未达标"判断以当日大盘状态对应的浮动目标为准。
