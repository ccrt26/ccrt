## v1.0 — 2026-05-21

**初始版本。** 基于"每日荐股逻辑评估白皮书_v1.2"重构，定位从「通用评估框架」转为「次日实战归因闭环」。

### 设计背景

原有评估白皮书 v1.2 提供了完整的胜率统计、维度归因、规则诊断框架，但在实践中存在以下缺口：
1. **评估与优化脱节**：评估数据未能直接驱动逻辑白皮书的版本迭代
2. **次日执行流程不明确**：缺乏从「获取次日数据」到「生成评估报告」的标准化步骤
3. **缺失量化反馈链路**：没有定义「评估结果 → 评分逻辑修正」的参数化映射

v1.0 聚焦填补以上缺口，将评估从「事后统计」升级为「次日即反馈的优化引擎」。

### 核心设计

**次日闭环：**
```
T日 荐股报告 → T+1日 收盘数据 → T+1日 20:00 评估报告 
    → 归因分析 → 校准参数建议 → 更新逻辑白皮书参数附表
```

**新增内容（vs v1.2）：**
- 新增：第1.3节 执行时间线（精确到分钟的次日操作流程）
- 新增：第2.2节 历史数据比对（昨日报告 vs 次日实盘逐项对照表）
- 新增：第3章 评分维度回检（每个推荐标的的各维度预期 vs 实际表现）
- 新增：第4.3节 维度误判率动态阈值（连续5日超限自动触发版本修订）
- 新增：第5章 逻辑迭代引擎（评估结果 → 逻辑白皮书参数映射表）
- 新增：第5.3节 版本升级决策树（何时改参数、何时升次版本、何时升主版本）
- 新增：第6章 数据结构定义（评估记录CSV schema、汇总统计格式）
- 新增：附录A 次日评估报告模版
- 新增：附录B 评估指标速查卡

**保留的合理逻辑：**
- 保留：核心评估指标（胜率/盈亏比/超额收益）
- 保留：归因分析框架（亏损>3%必须标注误判维度）
- 保留：趋势豁免独立评估与量比>12封顶监控
- 保留：条件否决股票跟踪机制
- 保留：分市场阶段分析框架
- 保留：「假设-验证-切换」流程
- 保留：数据积累里程碑
