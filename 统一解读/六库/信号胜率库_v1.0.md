## 一、信号字段定义（v1.1 补全）

| 字段 | 类型 | 必填 | 说明 |
|:-----|:-----|:-----|:-----|
| signal_id | string | 是 | 信号唯一标识 |
| signal_name | string | 是 | 信号名称 |
| signal_type | string | 是 | 技术/资金/情绪/事件/宏观 |
| description | string | 是 | 触发条件描述 |
| historical_winrate | float | 是 | 历史胜率 (0-1) |
| sample_count | int | 是 | 样本数 |
| **source_file** | string | **是** | 胜率数据来源文件路径 |
| **sample_period** | string | **是** | 样本期间 (YYYY-MM-DD 至 YYYY-MM-DD) |
| **sample_definition** | string | **是** | 样本定义（正例判定条件） |
| **calculation_method** | string | **是** | 胜率计算方法 |
| **last_verified_date** | date | **是** | 最后验证日期 |
| **source_level** | string | **是** | L1-L5 来源等级 |
| **seed_estimate** | boolean | **是** | 是否为种子估计（非项目实证） |
| applicable_environment | string | 是 | 适用环境 |
| failure_environment | string | 是 | 失效环境 |
| can_upgrade_action | boolean | 是 | 是否支持动作升级 |
| confidence_adjustment | string | 是 | 置信度调整方向 |

> ⛔ **seed_estimate=true 的信号，can_upgrade_action 必须为 false。**
> 来源等级标注规则见 `知识库来源等级标准_v1.0.md` §2.2

## 三、信号组合规则（v1.1 修正）

> ⛔ 所有组合规则受 L5-seed 限制：涉及 seed_estimate=true 的信号时，不得用于动作升级。

| 组合 | 效果 | 限制 |
|:-----|:-----|:-----|
| 2个技术信号同向 | 置信度+1级 (LOW→MEDIUM) | 至少1个非seed |
| 技术+资金同向 | 置信度+1级 | 至少1个非seed |
| 技术+事件同向 | 仅HOLD→WATCH | 不得升级到BUY（seed限制） |
| 3信号同向 | 置信度→HIGH | 需全部非seed或腰子特批 |
| 单一信号 | 不得触发BUY/SELL | 无论seed状态 |
