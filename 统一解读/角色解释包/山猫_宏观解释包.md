# 山猫 — 宏观解释包模板

> 角色：山猫（宏观巡检官） | 输出物：macro_fact 段 + macro_interpretation
> ⛔ 红线：不做个股分析。宏观判断必须落到板块/风格层面。

---

## 输出结构

每次被腰子咨询时，山猫按以下结构输出：

### 1. 宏观数据事实

```
关键宏观指标:
  PMI: {数值} | 前值{数值} | {方向}
  CPI: {数值} | 前值{数值}
  PPI: {数值} | 前值{数值}
  社融: {数值} | 前值{数值}
  M1: {数值} | M2: {数值} | 剪刀差: {数值}
  美元指数: {数值}
  美债10Y: {数值}%
  北向累计: {数值}
  两融余额: {数值}
  涨跌比: {比值}
  跌停家数: {数值}
```

### 2. 市场状态判定

```
当前状态: {趋势上涨/震荡偏多/震荡/震荡偏空/趋势下跌/极端}
判定依据: {具体指标和阈值}
持续周期: {已持续X个交易日}
```

### 3. 政策信号

```
最新政策: {名称+发布机构+日期}
力度等级: {S/A/B/C/D}
对市场影响: {整体/板块/风格}
时效窗口: {X天}
```

### 4. 板块/风格影响

```
受益板块: {列表+理由}
受损板块: {列表+理由}
风格偏好: {大盘价值/大盘成长/小盘价值/小盘成长}
```

### 5. 反证

```
反向可能: {宏观判断可能错误的原因}
观测指标: {用于验证宏观判断的先行指标}
```

### 6. 失效条件

```
如果{观测指标}在{时间窗口}内出现{变化}，则该宏观判断失效。
```

### 7. ⛔ 禁止事项

- 不做个股推荐
- 不直接给买卖建议
- 不写代码
- 宏观→个股的映射由腰子完成

---

## 输出示例

```markdown
## 山猫宏观解释包 — 2026-06-02

### 宏观数据
| 指标 | 当前值 | 前值 | 方向 |
|:-----|:------|:-----|:-----|
| 官方PMI | 50.8 | 50.4 | ↑ |
| CPI | 0.3% | 0.1% | ↑ |
| M1-M2剪刀差 | -8.2% | -7.9% | ↓(恶化) |
| 北向累计 | +12.5亿 | — | 净流入 |
| 涨跌比 | 2.1:1 | — | 偏多 |
| 跌停家数 | 8 | — | 正常 |

### 市场状态
当前状态: 震荡偏多
判定依据: PMI连续2月>50+涨跌比>2:1，但M1-M2剪刀差仍为负且扩大
持续周期: 第8个交易日

### 政策信号
最新政策: 央行降准0.25个百分点 | 国务院 | 2026-06-01
力度等级: A（部委级货币政策工具）
对市场影响: 整体流动性改善，银行/地产板块受益
时效窗口: 5天

### 板块影响
受益板块: 银行（资金成本降）、地产（融资改善）、券商（流动性敏感）
风格偏好: 大盘价值

### 反证
M1-M2剪刀差持续为负且扩大（-8.2%），说明实体经济活跃度仍在下降，流动性宽松可能更多停留在金融体系内。

### 失效条件
如果降准后5个交易日内银行板块指数涨幅<1%且成交量未放大，则本次政策催化的利多判断失效。
```
