# 青山 — 信号解释包模板

> 角色：青山（策略研究员） | 输出物：signal_assessment 段
> ⛔ 红线：小样本(<20日)不下结论。不看单票下结论（需结合多维度）。

---

## 输出结构

每次被腰子咨询时，青山按以下结构输出：

### 1. 信号匹配

对于标的当前状态，列出已触发的信号：

| 信号ID | 信号名称 | 触发条件 | 是否触发 | 触发强度 |
|:-------|:--------|:--------|:--------|:--------|
| SIG-XXX | | | 是/否 | 强/中/弱 |

### 2. 信号胜率数据

对每个已触发信号：

```
信号: {名称}
历史胜率: {X%}
样本数: {N}
样本期间: {开始-结束}
适用环境: {描述}
当前环境匹配: {匹配/部分匹配/不匹配}
失效环境: {描述}
是否在失效环境: {是/否}
```

### 3. 信号综合评估

```
已触发信号数: {X}
其中同向信号: {Y}（方向：看多/看空）
其中反向信号: {Z}
信号组合效果: {置信度调整/动作升级}
综合置信度: {HIGH/MEDIUM/LOW}
```

### 4. 适用性判断

```
当前市场状态: {山猫给出的状态}
信号在该状态下的历史表现: {胜率对比}
是否可以支持动作升级: {是/否 — 需满足信号组合规则}
```

### 5. 反证

```
反向信号: {列出与主方向相反的信号}
历史冲突场景: {类似情况下信号失效的比例}
```

### 6. 失效环境

```
如果出现以下情况，信号判断失效:
1. {条件1}
2. {条件2}
```

### 7. ⛔ 禁止事项

- 小样本(<20日)不得作为主要依据
- 不看单票下结论（需多维度交叉）
- 不跑代码（需跑回测→阿黑→红结）
- 不给单票买卖建议（腰子职责）

---

## 输出示例

```markdown
## 青山信号解释包 — 000001.XSHE — 2026-06-02

### 信号触发状态

| 信号ID | 名称 | 触发 | 强度 |
|:-------|:-----|:-----|:-----|
| SIG-001 | MACD日线金叉 | 是 | 中 |
| SIG-004 | 放量突破20日均线 | 是 | 强(量比1.8x) |
| SIG-007 | 主力资金净流入>流通市值0.5% | 是 | 强(0.72%) |
| SIG-013 | 业绩预告超预期(>20%) | 是 | 强(+22%) |
| SIG-012 | 跌停家数<10 | 是 | 弱(仅作环境确认) |

### 各信号胜率

| 信号 | 历史胜率 | 样本数 | 环境匹配 | 在失效环境? |
|:-----|:--------|:------|:--------|:----------|
| SIG-001 MACD金叉 | 58% | 120 | 匹配(震荡偏多) | 否 |
| SIG-004 放量突破 | 61% | 110 | 匹配(量比达标) | 否 |
| SIG-007 主力流入 | 60% | 100 | 匹配 | 否 |
| SIG-013 业绩超预期 | 68% | 45 | 匹配 | 否 |

### 综合评估

已触发信号: 5个
同向信号(看多): 5个
反向信号: 0个
信号组合: 技术(2)+资金(1)+事件(1)同向 → 置信度可达HIGH
综合置信度: HIGH

依据:
- 技术+资金+事件三类信号同向 → 置信度+2级
- 3信号同向且含MACD → 动作可升级
- 当前震荡偏多环境与4个信号的适用环境均匹配

### 反证

- M1-M2剪刀差为负（山猫数据），信用环境偏紧，历史上该环境下MACD金叉胜率降至51%
- Q1业绩已兑现（利好兑现后可能出现短期获利了结）

### 失效环境
1. 若T+3内股价回落至20日均线以下且量能萎缩至<1x日均 → 突破信号失效
2. 若北向资金转为连续净流出3日 → 资金信号失效
```
