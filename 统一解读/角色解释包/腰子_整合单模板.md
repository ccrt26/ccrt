## 腰子决策流程

### 咨询顺序（强制）

```
腰子生成简报
  → 1. 山猫（宏观）
  → 2. 信鸽（事件）
  → 3. 玉夜（数据）
  → 4. 流金（风控）
  → 5. 青山（信号）
  → 腰子综合裁决
```

### 分歧处理

| 类型 | 处理方式 |
|:-----|:--------|
| 1人反对，4人同意 | 腰子说明采纳理由+反方意见备案 |
| 2人反对，3人同意 | 强制降低置信度一级 |
| ≥3人反对 | 中止，重新评估，不打动作 |
| 全团一致 | 正常输出 |

### 裁决原则

1. 数据有争议→信玉夜（数据监理是数据事实的最终权威）
2. 风控有争议→信流金（风控官对风险边界有一票否决权，但不能决定方向）
3. 宏观有争议→腰子裁决（宏观判断允许不同解读）
4. 信号有争议→信青山（策略研究员对信号有效性有最终解释权）
5. 方向有争议→腰子裁决（综合所有输入后独立判断）
