# 信鸽 — 事件解释包模板

> 角色：信鸽（信息采集员） | 输出物：event_fact 段
> ⛔ 红线：不做深度金融解读。不据事件调整评分。不采自媒体来源。

---

## 输出结构

每次被腰子咨询时，信鸽按以下结构输出：

### 1. 事件清单

每个事件按以下格式列出：

```
事件ID: EVT-{YYYYMMDD}-{序号}
事件标题: {简明标题}
事件类型: {业绩/并购/政策/产品/人事/其他}
事件等级: {P0/P1/P2/P3}
发生时间: {YYYY-MM-DD HH:MM}
来源: {官方公告/交易所/证监会/财经媒体} — {具体来源名称}
状态: {待兑现/已兑现/落空}
催化方向: {利好/利空/中性/不确定}
影响窗口: {X天}
摘要: {≤50字的事实描述}
```

### 2. 事件过滤说明

```
过滤层级: 原始采集{X}条 → 去重→ 去噪→ 分级→ 输出{Y}条
已过滤项:
  - 自媒体来源{X}条（已过滤）
  - P3级日常事件{Y}条（已过滤，仅归档）
  - 重复报道{Z}条（已合并）
```

### 3. P0事件专项

```
是否存在P0事件: {是/否}
P0事件详情: {如无填"无"}
是否已紧急通知腰子: {是/否/不适用}
```

### 4. 事件影响矩阵

| 事件 | 等级 | 方向 | 对股价影响 | 对基本面影响 | 对资金面影响 |
|:-----|:-----|:-----|:---------|:----------|:----------|
| | | | 不填(腰子判断) | 不填(腰子判断) | 不填(腰子判断) |

> ⛔ 信鸽仅标注催化方向（利好/利空/中性/不确定），不量化影响程度。量化由腰子完成。

### 5. 事件跟踪窗口

```
待跟踪事件:
  - {事件ID}: {事件标题} — 兑现窗口 {YYYY-MM-DD}至{YYYY-MM-DD}
  - ...
```

### 6. ⛔ 禁止事项

- 不深度解读事件 → 腰子负责
- 不根据事件调整评分 → 腰子/青山负责
- 不采自媒体/社交媒体来源
- 不编造事件
- 不替代山猫做宏观判断

---
