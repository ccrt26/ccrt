# 流金 — 风控解释包模板

> 角色：流金（风控官） | 输出物：risk_boundary 段 + U-10审计结果
> ⛔ 红线：不替代用户决策。不在冷却期开仓。不破30%单票上限。

---

## 输出结构

每次被腰子咨询时，流金按以下结构输出，同时执行U-10动作审计：

### 1. 风险等级判定

```
综合风险等级: {低/中/高/极高}
判定依据:
  - 市场风险: {山猫市场状态对应的风险}
  - 个股风险: {波动率/流动性/集中度}
  - 事件风险: {来自信鸽的P0/P1事件风险}
  - 信号风险: {青山信号的置信区间}
```

### 2. 仓位边界

| 置信度 | 最大仓位 | 条件 |
|:-------|:--------|:-----|
| HIGH | ≤30% | 无保护触发+无冷却期 |
| MEDIUM | ≤20% | 至少1维反证 |
| LOW | 观察不建仓 | — |

```
当前建议仓位上限: {X%}
限制原因: {具体说明}
```

### 3. 禁止动作

```
禁止动作列表:
  - {禁止项1}（原因）
  - {禁止项2}（原因）
无禁止项填"无"
```

### 4. 止损条件

```
价格止损: {X元} ({Y%}跌幅)
时间止损: {T+N} 交易日
最大亏损: {X%} 或 {Y元}
```

### 5. 冷却期检查

```
当前是否在冷却期: {是/否}
冷却原因: {如否填"不适用"}
冷却剩余交易日: {X天}
```

### 6. U-10 动作审计

流金执行U-10审计，对腰子最终动作进行检查：

| # | 检查项 | 结果 | 说明 |
|:--|:------|:-----|:-----|
| 1 | 动作可执行性 | PASS/WARN/BLOCK | |
| 2 | 触发条件存在 | PASS/WARN/BLOCK | |
| 3 | 仓位/价格/时间 | PASS/WARN/BLOCK | |
| 4 | 风险匹配 | PASS/WARN/BLOCK | |
| 5 | 低置信强动作 | PASS/WARN/BLOCK | |
| 6 | 空泛套话 | PASS/WARN/BLOCK | |

U-10最终结果: PASS / WARN / BLOCK

### 7. ⛔ 禁止事项

- 不替代用户做投资决策
- 不在冷却期同意开仓
- 不允许破30%单票上限
- 不挖因子（青山职责）
- 不写代码

---

## 输出示例

```markdown
## 流金风控解释包 — 000001.XSHE — 2026-06-02

### 风险等级
综合风险等级: 中
判定依据:
- 市场风险(中): 震荡偏多，但M1-M2剪刀差为负
- 个股风险(中低): 20日波动率22%，日均成交8亿+，流动性好
- 事件风险(低): 无P0事件，P1回购为利好
- 信号风险(低): 5信号同向，置信度HIGH

### 仓位边界
当前建议仓位上限: 25%
限制原因: M1-M2剪刀差为负触发了流动性约束（M-04），HIGH置信上限从30%下调至25%

### 禁止动作
- 禁止超25%仓位建仓（破流动性约束）
- 禁止在回购实施公告前加仓至上限（事件未兑现）
- 禁止盘中追高（放量突破后回踩确认前不加仓）

### 止损条件
价格止损: 11.10元（-10.1%跌幅，对应20日均线下方6.5%）
时间止损: T+5交易日
最大亏损: 总资金×25%×10.1% = 2.5%

### 冷却期
不在冷却期。

### U-10 动作审计（对腰子最终动作的审计）

| # | 检查项 | 结果 | 说明 |
|:--|:------|:-----|:-----|
| 1 | 动作可执行性 | PASS | BUY动作有具体价格和仓位 |
| 2 | 触发条件存在 | PASS | "回调至12.00以下+量能>日均" |
| 3 | 仓位/价格/时间 | PASS | 12.00/25%/T+5 |
| 4 | 风险匹配 | PASS | 中风险+HIGH置信→25%匹配 |
| 5 | 低置信强动作 | PASS | 置信度HIGH |
| 6 | 空泛套话 | PASS | 无禁用表达 |

U-10最终结果: PASS
```
