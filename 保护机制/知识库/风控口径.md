# 风控口径 — 止损优先级与冲突处理

> 维护者：流金 + 青山 | 版本：v1.0 | 生效日期：2026-06-01

---

## 一、止损优先级

### 1.1 核心原则

```
纪律止损 > 策略止损 > 主观止损
```

1. **纪律止损优先于策略止损。** 纪律止损来自个人风控参数（硬止损-8%、单日亏损限额等），策略止损来自技术分析（青山的技术区间、支撑位）。当两者共存时，以纪律止损为准。
2. **如果纪律止损价高于策略止损价（即纪律止损更保守），使用纪律止损作为有效止损。** 数学表达：`effective_stop = max(discipline_stop, strategy_stop)`（取更高止损价=更早触发）。
3. **如果两个止损冲突超过 3%，保护机制必须提示"止损口径冲突"，盘中结论默认"等"。** 冲突度量：`|discipline_stop - strategy_stop| / avg_cost > 3%`。

### 1.2 止损冲突处理流程

```
计算 discipline_stop（个人风控参数）
  → 计算 strategy_stop（青山技术区间）
    → 比较两者差距
      ├── 差距 ≤ 3%：取更保守者作为 effective_stop
      └── 差距 > 3%：
            ├── 标记 stop_loss_conflict = true
            ├── 写入 stop_loss_conflict_detail
            ├── final_guard.default_action ≥ "等"
            └── 用户如仍要求买入→最终结论"否"
```

### 1.3 有效止损在不同场景下的行为

| 场景 | 有效止损 | 说明 |
|:-----|:--------|:-----|
| 纪律止损 > 策略止损 | 纪律止损 | 纪律更保守 |
| 策略止损 > 纪律止损 | 策略止损 | 策略更保守 |
| 冲突 > 3% | 不生效，标记冲突 | 需人工裁决 |
| 数据 stale/missing | 仅用纪律止损 | 不允许策略技术价 |
| 无纪律止损(新股) | 策略止损 | 青山独立判断 |

## 二、浮亏加仓禁令

### 2.1 规则

> ⛔ 浮亏状态禁止加仓摊平。

### 2.2 例外条件（全部满足才可突破）

用户如确需在浮亏状态下追加同一标的，必须**同时满足以下全部条件**：

1. **新增理由**：明确写出与原始买入理由不同的、独立的、新的买入逻辑
2. **止损依据**：给出新的止损价及计算依据（不能沿用旧止损）
3. **最大亏损金额**：明确写出此笔加仓的最大可接受亏损金额
4. **腰子批准**：上述三项经腰子审核后，腰子仍可否决

任一项缺失 → 腰子结论"否"。

### 2.3 加仓后仓位管理

- 加仓后单票总仓位不得超过单票上限（30%）
- 加仓后总仓位不得超过上限（70%）
- 违反任一项 → 腰子结论"否"

## 三、数据质量→结论降级

### 3.1 降级规则

| 数据状态 | 盘中结论 | 盘前结论 | 说明 |
|:--------|:--------|:--------|:-----|
| normal | 正常判定 | 正常简报 | — |
| degraded | 正常判定+标注 | 正常简报+标注 | 部分源降级但不影响关键字段 |
| stale | 默认"等" | 保守定调 | 数据过期 > 10 分钟 |
| conflict | 默认"否" | 保守定调+冲突标注 | 多源数据不一致 |
| missing | 默认"否" | 降级简报 | 关键数据完全缺失 |

### 3.2 数据不可用时的硬性约束

- **不允许用旧目标价支持买入。** 数据 stale/missing 时，目标价标记为不可靠。
- **不允许用历史胜率推算当前胜率。** 信号胜率标记为 stale。
- **不允许在没有当前价格的情况下计算盈亏比。** 盈亏比标记为 N/A。

## 四、仓位与亏损上限

### 4.1 硬上限

| 参数 | 值 | 超限动作 |
|:-----|:--|:--------|
| 单票仓位上限 | 30% | 硬阻断，"否" |
| 总仓位上限 | 70% | 硬阻断，"否" |
| 单日亏损限额 | 5%（1,800元） | 硬阻断，触发冷却 |

### 4.2 冷却期触发

| 触发条件 | 冷却动作 | 持续天数 |
|:--------|:--------|:--------|
| 单笔亏损超 5% | 次日禁止开新仓 | 1 天 |
| 连续 2 笔止损 | 暂停交易 | 2 天 |
| 连续 3 笔止损 | 暂停交易 + 腰子复盘 | 5 天 |
| 单日亏损超 5% | 强制冷却 | 1 天 |

冷却期内：
- `/保护 刹车` 任何买入请求 → automatic "否"
- 卖出请求可正常执行（止损离场不受冷却限制）

## 五、盈亏比门槛

### 5.1 最低要求

- 目标收益 / 止损风险 ≥ 2:1
- 不满足 → 软警告，默认"等"
- 用户可提供额外理由突破，但腰子仍可否决

### 5.2 盈亏比计算

```
盈亏比 = |target_price - entry_price| / |entry_price - effective_stop_loss|
```

若 effective_stop_loss 因冲突未能确定，盈亏比标记为 `冲突/不可算`，默认"等"。

## 六、口径冲突处理总表

| 冲突类型 | 检测方式 | 动作 |
|:--------|:--------|:-----|
| 止损口径冲突 > 3% | 纪律止损 vs 策略止损 | 默认"等"，提示冲突 |
| 报告方向 vs 用户方向 | report_direction vs 刹车方向 | 软警告 |
| 信号方向 vs 用户方向 | triggered_signals vs 刹车方向 | 若信号胜率 < 50%，硬阻断 |
| 市场情绪 vs 用户方向 | sentiment 冰/冷 vs 买入 | 软警告 |
| 仓位上限 vs 加仓 | position_pct + new > 30% | 硬阻断"否" |
