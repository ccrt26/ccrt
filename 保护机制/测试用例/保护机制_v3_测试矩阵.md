## T1：盘前正常

| 项目 | 内容 |
|:-----|:-----|
| **触发条件** | 交易日 8:57，数据源正常 |
| **前置状态** | 保护快照.json 已生成（8:53），data_status=normal，持仓东睦股份 |
| **操作** | `/保护 盘前` |
| **预期结果** | 六角色齐全简报，腰子给出明确纪律结论（可/等/否/强制冷却之一），飞书发送成功 |
| **验收标准** | 简报含全部六角色标记 + 免责声明 + ≤30行 |

## T2：盘前数据 stale

| 项目 | 内容 |
|:-----|:-----|
| **触发条件** | 交易日 9:00，快照 stale_seconds > 600 |
| **前置状态** | 快照数据过期，data_status=stale |
| **操作** | `/保护 盘前` |
| **预期结果** | 降级处理，标注数据时效，腰子默认"今日少动或不动" |
| **验收标准** | default_action ≥ "等"，简报含数据过期标注 |

## T3：东睦浮亏加仓

| 项目 | 内容 |
|:-----|:-----|
| **触发条件** | 用户持有东睦股份 600114，浮亏 -7.3%，发起买入 |
| **前置状态** | positions[东睦].unrealized_pnl_pct < 0, cooling_period_active=false |
| **操作** | `/保护 刹车 600114 买入 36.00 10000 抄底摊低成本 止损35.00` |
| **预期结果** | 硬阻断：浮亏加仓禁止。腰子结论"否" |
| **验收标准** | hard_blocks 含 loss_averaging 类型阻断，default_action="否" |

## T4：新标的追涨无事件

| 项目 | 内容 |
|:-----|:-----|
| **触发条件** | 新标的当日涨幅 4%，无消息面催化，用户发起买入 |
| **前置状态** | has_valid_catalyst=false, price_change>3%, action=buy |
| **操作** | `/保护 刹车 XXXXXX 买入 XX 5000 涨得好追一下 止损-5%` |
| **预期结果** | 硬阻断：无事件催化追涨>3% |
| **验收标准** | hard_blocks 含 chase_without_event 阻断，default_action="否" |

## T5：止损口径冲突

| 项目 | 内容 |
|:-----|:-----|
| **触发条件** | 纪律止损价 36.34，策略止损价 32.00，差距 > 3% |
| **前置状态** | positions[某标的].stop_loss_conflict=true |
| **操作** | `/保护 刹车 XXXX 买入 XX 5000 技术面好 止损32.00` |
| **预期结果** | 软警告：止损口径冲突提示，默认"等" |
| **验收标准** | soft_warnings 含 stop_conflict 类型，default_action="等" |

## T6：冷却期买入

| 项目 | 内容 |
|:-----|:-----|
| **触发条件** | 冷却期激活中（连续3笔止损），用户发起买入 |
| **前置状态** | real_account.cooling_period_active=true, cooling_reason="连续3笔止损" |
| **操作** | `/保护 刹车 XXXXXX 买入 XX 5000 好机会 止损-8%` |
| **预期结果** | 硬阻断：冷却期禁止开新仓。腰子结论"强制冷却" |
| **验收标准** | hard_blocks 含 cooling 类型阻断，default_action="强制冷却" |

| **验收标准** | 保护机制/盘前简报/YYYY-MM-DD.md 存在且内容完整，飞书发送异常有日志 |
