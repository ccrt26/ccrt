## 核心设计原则

1. **广度与深度分离**：每日荐股负责市场广度筛选（全市场→基础池→核心池→精选），重点股票跟踪负责深度分析（对精选池中的核心标的多维度持续跟踪）
2. **多周期融合**：任何预判必须同时给出短期（1-5日）、中期（1-4周）、长期（1-6月）三个时间维度的观点
3. **证据加权**：不做单一指标决策，采用"证据权重"法——多个独立维度指向同一方向时方可形成结论
4. **持续跟踪而非一次性判断**：重点股票不是分析一次就结束，而是建立档案持续跟踪关键信号变化
5. **可验证、可回溯**：每个预判必须有明确的验证标准，事后可判断对错

## 1.1 技术面分析

技术面是判断买卖时机和趋势状态的核心手段，采用"多周期趋势 + 量价关系 + 关键形态 + 指标组合"四层递进。

### 1.1.1 多周期趋势判断

| 周期 | 均线体系 | 趋势定义 | 用途 |
|:----|:---------|:---------|:-----|
| **短期**（日线） | MA5 / MA10 / MA20 | MA5>MA10>MA20 多头排列 → 短期上升趋势 | 入场/离场时机 |
| **中期**（周线） | MA10 / MA20 / MA50 | 周线MA10>MA20 且价格在MA20之上 → 中期上升趋势 | 持仓/方向判断 |
| **长期**（月线） | MA20 / MA50 / MA120 | 月线级别均线多头 → 长期牛市格局 | 战略仓位判断 |

**趋势一致性原则**：
- 三个周期趋势方向一致时 → 趋势强劲，可重仓
- 短期与中长期方向相反 → 按中长期方向定战略，短期信号定战术
- 中期趋势不明（均线交织）→ 以区间震荡对待，高抛低吸

### 1.1.2 量价关系分析

采用 Wyckoff 量价分析法判断主力行为：

| 量价形态 | 含义 | 操作含义 |
|:---------|:-----|:---------|
| 价涨量增 | 需求旺盛，趋势健康 | 持仓或加仓 |
| 价涨量缩 | 上涨动力减弱，量价背离 | 警惕回调，减仓 |
| 价跌量缩 | 下跌无承接，但仍未企稳 | 观望，等待放量企稳 |
| 价跌量增 | 恐慌抛售或主力出货 | 区分是 Selling Climax 还是 Distribution |
| 放量突破压力位 | Wyckoff 的 Sign of Strength (SOS) | 确认突破有效，加仓 |
| 缩量回踩支撑位 | Wyckoff 的 Last Point of Support (LPS) | 最佳加仓点 |
| 放量跌破支撑位 | 趋势转弱 | 止损离场 |

**Wyckoff 四阶段识别**（用于判断股票所处的大周期位置）：

| 阶段 | 典型特征 | 操作策略 |
|:-----|:---------|:---------|
| **吸筹区（Accumulation）** | 长期下跌后横盘，成交量逐步放大，底部抬高 | 建立底仓 |
| **拉升区（Markup）** | 放量突破横盘区，均线多头排列 | 加仓/持仓 |
| **派发区（Distribution）** | 大幅上涨后横盘，高位放量滞涨，出现上冲回落的Upthrust | 逐步减仓 |
| **下跌区（Markdown）** | 跌破派发区，均线空头排列 | 清仓/观望 |

### 1.1.3 经典技术形态识别

| 形态名称 | 周期 | 含义 | 目标位测算 |
|:---------|:----|:-----|:-----------|
| 头肩底/双底 | 日/周线 | 中期底部反转 | 颈线高度等距 |
| 头肩顶/双顶 | 日/周线 | 中期顶部反转 | 颈线高度等距 |
| 上升/下降旗形 | 日线 | 趋势中继 | 旗杆高度等距 |
| 上升/下降三角形 | 日/周线 | 趋势突破在即 | 三角形最宽处 |
| 圆弧底 | 周/月线 | 长期底部 | 缓慢，持久 |
| W底/M顶 | 日/周线 | 常见反转形态 | 颈线高度等距 |

### 1.1.4 技术指标组合

**不依赖单一指标，采用"组合确认"策略。** 至少两个独立指标同时发出信号方可确认。

| 指标维度 | 指标 | 参数 | 用法 |
|:---------|:-----|:-----|:-----|
| **趋势** | MACD (12,26,9) | 标准参数 | DIF方向 + 柱状体 + 零轴位置判断趋势强度 |
| **趋势** | 均线系统 | 5/10/20/50/120/250 | 多周期趋势状态 |
| **趋势** | ADX (14) | >25为趋势行情，<20为震荡 | 判断是否为趋势市 |
| **动量** | RSI (14) | 超买>70，超卖<30；底背离/顶背离 | 短期反转信号 |
| **动量** | Stochastic (14,3,3) | %K与%D交叉，超买/超卖区域 | 辅助RSI确认 |
| **动量** | MFI (14) | 带量的RSI，>80超买，<20超卖 | 量价结合的动量判断 |
| **波动率** | Bollinger Bands (20,2) | 触及上下轨 + 带宽变化 | 超买超卖+突破确认 |
| **波动率** | ATR (14) | 衡量波动幅度，设置止损 | 动态止损参考 |
| **成交量** | OBV | 趋势确认，背离信号 | 量先行于价 |
| **成交量** | 成交量均线(5/20) | 放量/缩量对照 | 量能变化 |

**组合确认规则**：
- 做多信号：均线多头 + MACD零轴上方金叉/DIF向上 + RSI 40-60区间向上 + 成交量配合
- 做空信号：均线空头 + MACD零轴下方死叉/DIF向下 + RSI 60-80区间向下 + 成交量配合
- 背离信号：价格新高但RSI/MACD未新高 → 顶背离（看空）；价格新低但RSI/MACD未新低 → 底背离（看多）
- 震荡判断：ADX<20 + 布林带走平 + 价格在上下轨之间来回 → 区间操作

### 1.1.5 K线形态分析（辅助验证）

| K线形态 | 含义 | 确认要求 |
|:--------|:-----|:---------|
| 十字星/纺锤线 | 多空平衡，变盘信号 | 次日方向确认 |
| 锤子线/上吊线 | 底部/顶部反转 | 长下影线+放量 |
| 吞没形态 | 强反转信号 | 实体完全覆盖前一根 |
| 晨星/暮星 | 底部/顶部反转 | 三根K线组合 |
| 三白兵/三黑鸦 | 持续/反转 | 三根连续同向 |

## 1.2 基本面分析

基本面用于判断股票的"内在价值"和"安全边际"，决定中长期持仓的底气。

### 1.2.1 财务健康评估

| 指标 | 计算方式 | 健康标准（A股） | 用途 |
|:-----|:---------|:---------------|:------|
| ROE | 净利润/股东权益 | ≥15%（优秀）；≥10%（合格） | 盈利能力的核心指标 |
| 毛利率 | (营收-营业成本)/营收 | ≥30%（优秀）；≥20%（合格） | 护城河与议价能力 |
| 净利润增长率 | (本期净利润/上期净利润)-1 | 连续3年≥20%为成长股 | 成长性判断 |
| 营收增长率 | (本期营收/上期营收)-1 | ≥15% | 收入端扩张情况 |
| 资产负债率 | 总负债/总资产 | ≤50%（稳健）；≤30%（优秀） | 财务风险 |
| 经营性现金流/净利润 | 经营活动现金流净额/净利润 | ≥1（优秀）；≥0.8（合格） | 利润质量 |
| 存货周转率 | 营业成本/平均存货 | 行业对比 | 运营效率 |
| PE百分位 | 当前PE/近5年PE区间 | <30%为低估，>70%为高估 | 估值位置 |
| PEG | PE/净利润增速 | <1为低估 | 成长性估值匹配 |

### 1.2.2 估值评估

| 估值方法 | 适用范围 | 判断标准 |
|:---------|:---------|:---------|
| PE（市盈率） | 盈利稳定的公司 | 与行业平均PE对比 + 历史百分位 |
| PB（市净率） | 金融/周期/重资产 | 破净<1为低估信号，<0.8为深度低估 |
| PS（市销率） | 亏损/高成长/互联网 | 行业对比 |
| EV/EBITDA | 跨行业比较 | 消除资本结构差异 |
| DCF（现金流折现） | 现金流稳定的成熟公司 | 内在价值 vs 当前市价 |
| 股息率 | 分红稳定的蓝筹 | 高于10年期国债收益率时具配置价值 |

### 1.2.3 核心竞争力分析

| 维度 | 评估内容 | 强度判断 |
|:-----|:---------|:---------|
| 护城河 | 品牌/专利/渠道/网络效应/成本优势 | 强/中/弱 |
| 行业地位 | 市占率排名、定价权 | 龙头/领先/跟随 |
| 技术壁垒 | 研发投入占比、专利数量 | 高/中/低 |
| 管理层 | 历史业绩、战略清晰度 | 优秀/合格/存疑 |

## 1.3 消息面与情绪面分析

消息面决定短期股价的核心驱动力——"炒股炒预期"，预期靠消息催化。

### 1.3.1 催化剂分级体系

| 级别 | 类型 | 影响周期 | 预期影响幅度 |
|:----:|:-----|:--------|:-----------|
| **S级** | 业绩超预期/重磅政策/行业变革 | 1-6个月 | >±20% |
| **A级** | 大订单/重大合同/股权激励 | 1-4周 | ±10-20% |
| **B级** | 新产品发布/合作签约/回购 | 3-10日 | ±5-10% |
| **C级** | 行业新闻/分析师评级/传闻 | 1-3日 | ±3-5% |

### 1.3.2 催化剂跟踪框架

对每个重点股票维护一个"催化剂日历"：

```
未来1个月催化剂清单：
  1. 2026-05-28 一季报发布 (S级)
  2. 2026-06-10 行业政策预期 (A级)
  3. 2026-06-15 解禁日 (B级，偏空)

催化剂落地跟踪：
  ✅ 已落地 → 对比预期 vs 实际 → 判断是否 Price In
  ⏳ 待落地 → 维持催化预期，关注进度变化
  ❌ 落空 → 降低评级，重新评估
```

### 1.3.3 情绪面指标

| 情绪指标 | 数据来源 | 判断标准 | 合规状态 |
|:---------|:---------|:---------|:---------|
| 研报覆盖数 | 东方财富[11] HTTP GET | 近期密集覆盖→市场关注度提升 | ✅ 已实测 |
| 分析师评级变动 | 东方财富[11] HTTP GET | 上调/下调数量对比 | ✅ 已实测 |
| 互动平台活跃度 | 上证e互动/深交所互动易 | 提问量激增→散户关注度高 | ❌ 框架性参考，无公开API，需人工录入 |
| 融资融券余额变化 | 东方财富[12] HTTP GET | 融资余额大幅增加→多头情绪 | ✅ 已实测 |
| 社交媒体热度 | 雪球/微博/股吧 | 热度异常→短期情绪拐点信号 | ❌ 框架性参考，无稳定API，需人工录入 |

> 合规说明：[11][12]已通过东方财富HTTP GET接口实测验证，可自动输出。互动平台和社交媒体两项无自动化数据源，目前仅作为分析框架参考，不参与自动评分计算。

### 1.3.4 消息面验证规则

```
利多消息出现时的判断：
  1. 消息真伪：官方公告 > 媒体报道 > 传闻
  2. 是否 Price In：消息公布前股价是否已大涨（利好出尽是利空）
  3. 市场反应：公告后首日涨幅+成交量 → 确认市场认可度
  4. 位置判断：低位利好 → 积极解读；高位利好 → 警惕出货

利空消息出现时的判断：
  1. 实质性 vs 情绪性：业绩暴雷=实质，负面新闻=情绪
  2. 是否过度反应：跌幅>预期 → 可能超跌机会
  3. 低位利空 → 往往最后一跌；高位利空 → 趋势可能转势
```

## 1.4 板块与行业分析

> 个股走势与板块高度相关——A股中约60%的个股日涨跌幅可由板块解释。选股必须先看板块。

### 1.4.1 板块相位判断

使用"板块指数"（申万一级/二级行业指数）判断板块所处生命周期：

| 相位 | 板块指数特征 | 对应操作 |
|:-----|:------------|:---------|
| **见底期** | 长期下跌后企稳，成交量开始放大，底部抬高 | 开始关注，选股纳入观察 |
| **启动期** | 板块放量突破下跌趋势线或横盘区，龙头股率先上涨 | 重点关注，可建仓 |
| **主升期** | 板块指数沿5/10周线上涨，成交量持续活跃，多只个股共振 | 加仓/持仓 |
| **高潮期** | 板块放巨量滞涨，出现上影线，波动加大，非龙头补涨 | 分批减仓 |
| **退潮期** | 板块跌破20周线，龙头股率先下跌，成交量萎缩 | 清仓回避 |

### 1.4.2 板块轮动位置

根据市场阶段判断配置方向（基于"高切低"轮动规律）：

| 市场阶段 | 优势板块类型 | 避免板块 | 轮动速度 |
|:---------|:------------|:---------|:---------|
| 牛市初期 | 券商+金融+科技龙头 | 防御型板块 | 慢 |
| 牛市中期 | 成长+消费+赛道股 | 周期股 | 中 |
| 牛市末期 | 周期+补涨+小盘 | 高位白马 | 快 |
| 熊市初期 | 防御型（公用事业+消费） | 高估值成长 | 快 |
| 熊市末期 | 超跌+政策受益 | 补跌股 | 慢 |

### 1.4.3 行业内个股联动分析

| 分析维度 | 方法 | 判断 |
|:---------|:-----|:------|
| 龙头追踪 | 行业龙头的走势 vs 目标股 | 龙头强+目标股强→板块健康；龙头弱+目标股强→个股独立行情 |
| 共振度 | 行业内上涨/下跌个股比例 | >70%个股上涨→强共振，趋势可靠 |
| 分化度 | 行业内涨幅标准差 | 标准差大→内部分化，选股能力重要 |
| 资金集中度 | 行业内前3大成交额占比 | 集中度高→资金聚焦少数龙头 |

## 1.5 资金面分析

> A股是资金驱动型市场，资金流向往往领先于价格变化。

### 1.5.1 主力资金追踪

| 资金类型 | 数据来源 | 判断标准 | 合规状态 |
|:---------|:---------|:---------|:---------|
| 北向资金持股 | 东方财富[8] HTTP GET | 持股数量与占比变化→外资动向 | ✅ 已实测（季度） |

### 1.5.2 市场成交量分析

| 量能状态 | 成交额特征 | 含义 |
|:---------|:----------|:------|

| 放量下跌 | 成交额>5日均量2倍+跌幅>3% | 恐慌抛售或主力出逃 |
| 缩量下跌 | 成交额<5日均量×0.7+下跌 | 下跌动能衰竭，可能见底 |
| 地量 | 成交额创近30日新低 | 市场关注度极低，变盘前兆 |

### 1.5.3 筹码分布分析

# 第二章 三周期预判体系

> 对每个重点股票，必须同时给出短期/中期/长期三个时间维度的预判，形成完整的"趋势意见书"。

## 2.1 短期预判（1-5个交易日）

| 分析依据 | 权重 | 关键信号 |
|:---------|:----:|:---------|
| 日线级别技术形态 | 35% | K线组合 + 支撑/阻力位 + 日内量价关系 |
| 短期均线排列（5/10/20） | 20% | 多头/空头/纠缠 |
| 短期技术指标（RSI/Stoch/布林带） | 15% | 超买超卖+交叉信号 |
| 近3日消息面催化 | 15% | 是否有近期催化剂将落地 |
| 次日大盘预期 | 15% | 大盘短期方向影响个股 |

**短期预判输出格式**：
- 方向：看多 / 偏多 / 中性 / 偏空 / 看空
- 关键阻力位：XX.XX元（突破位）
- 关键支撑位：XX.XX元（止损位）
- 短期催化剂：XXX事件（预期影响±X%）
- 置信度：高（>70%）/ 中（50-70%）/ 低（<50%）

## 2.2 中期预判（1-4周）

| 分析依据 | 权重 | 关键信号 |
|:---------|:----:|:---------|
| 周线级别趋势 | 30% | 周线均线排列 + 周线MACD方向 |
| 板块相位与轮动 | 20% | 板块所处生命周期阶段 |
| 中期催化剂 | 20% | 未来1-4周内确定性催化事件 |
| 基本面趋势 | 15% | 业绩预期 + 估值水平 |
| 资金面中期趋势 | 15% | 北向资金/主力资金连续方向 |

**中期预判输出格式**：
- 方向：趋势看多 / 区间震荡 / 趋势看空
- 目标区间：上沿XX元 / 下沿XX元
- 关键验证点：XXX（什么事件将验证或证伪判断）
- 中期催化剂：XXX事件（时间、预期影响）

## 2.3 长期预判（1-6个月）

| 分析依据 | 权重 | 关键信号 |
|:---------|:----:|:---------|
| 基本面价值评估 | 30% | ROE趋势 + 营收增速 + 估值百分位 |
| 行业/产业趋势 | 25% | 渗透率 + 替代率 + 市占率（三率体系） |
| 月线级别大趋势 | 20% | 月线均线 + 长期技术形态（Wycokff大周期位置） |
| 宏观政策方向 | 15% | 政策受益/受损判断 |
| 机构共识 | 10% | 分析师目标价 + 机构持仓变化趋势 |

**长期预判输出格式**：
- 方向：长期看好 / 长期中性 / 长期看空
- 战略判断：处于Wyckoff周期的哪一阶段（吸筹/拉升/派发/下跌）
- 合理估值区间：基于DCF或可比估值法
- 核心逻辑：一句话概括长期持有/回避的理由

## 2.4 三周期综合判断矩阵

| 短期 | 中期 | 长期 | 综合判断 | 建议操作 |
|:----:|:----:|:----:|:---------|:---------|
| ↑ | ↑ | ↑ | **强势看多** | 重仓持有，每次回调都是加仓点 |
| ↑ | ↑ | → | **谨慎看多** | 持仓，关注长期逻辑是否强化 |
| ↑ | → | ↑ | **短期机会** | 可在支撑位做多，注意中期风险 |
| ↑ | ↓ | ↑ | **反弹看待** | 仅做短线，中期压力大 |
| → | ↑ | ↑ | **等待买点** | 中期趋势好，等短期回调企稳介入 |
| ↓ | ↑ | ↑ | **中期趋势中的回调** | 重点观察是否是健康的缩量回调 |
| ↓ | ↓ | ↑ | **中期调整** | 减仓，等中期趋势明朗再回补 |
| ↓ | ↓ | ↓ | **强势看空** | 清仓回避，等待反转信号 |
| ↑ | ↓ | ↓ | **超跌反弹** | 仅做短线反弹，快进快出 |
| → | → | → | **方向不明** | 观望，减少交易 |

> ↑=看多  →=中性/震荡  ↓=看空

## 3.2 趋势健康度评估

追踪趋势的**持续性**和**健康度**，防止过早下车或该走不走：

| 指标 | 健康 | 预警 | 危险 |
|:-----|:----|:-----|:------|
| 上升趋势中的回调幅度 | <10% | 10-15% | >15% |
| 上升中的成交量 | 量增 | 缩量上涨 | 放量滞涨/放量下跌 |
| 均线发散状态 | 多头平行向上 | 均线开始走平 | 死叉/交叉向下 |
| MACD状态 | DIF在零轴上方 + 柱状体向上 | DIF走平 | DIF下穿零轴 |
| RSI趋势 | 50-70之间震荡向上 | 70以上钝化 | 跌破50 |
| 板块相对强度 | 强于大盘 | 与大盘同步 | 弱于大盘 |

### 3.2.1 趋势健康度评分触发规则

- 健康度评分≥80：正常持有，无需特别操作
- 健康度评分60-79：关注预警指标，设定止损
- 健康度评分40-59：进入警戒状态，准备减仓
- 健康度评分<40：立即评估是否需要清仓

# 第六章 操作建议与交易计划体系（v2.0 新增）

> **本体系是整个白皮书中最关键的产出环节。** 前五章分析最终要落地为可执行的交易指令——什么价格买、买多少、什么价格卖、什么价格止损。
>
> 核心原则：分析可以模糊，操作必须精确。

## 6.1 价格分层体系

对每个重点股票建立六层价格带，作为所有操作建议的基础：

```
上方
  R3（强阻力）  →  之前设定的中期目标价，如果突破则趋势加速
  R2（中阻力）  →  关键技术阻力（MA50/前高/黄金分割61.8%）
  R1（弱阻力）  →  短期阻力（MA10/MA20/前日高点）
  ─────────────────── 当前价格 P ───────────────────
  S1（弱支撑）  →  短期支撑（MA10/MA20/前日低点）
  S2（中支撑）  →  关键技术支撑（MA50/前低/黄金分割38.2%）
  S3（强支撑）  →  趋势防守位（MA120/黄金分割23.6%/止损底线）
下方
```

### 6.1.1 价位计算方法

| 层级 | 主要计算方法（按优先级） | 备用方法（数据不足时） |
|:-----|:------------------------|:---------------------|
| **R3** | 前高 + ATR×1.5；或 Fibonacci 扩展 127.2% | P×1.10（日涨幅极限参考） |
| **R2** | MA50 / MA120；或前高；或 Fibonacci 61.8% | P×1.06 |
| **R1** | MA10 / MA20；或前日最高价；或 Fibonacci 38.2% | P×1.03 |
| **S1** | MA10 / MA20；或前日最低价；或 Fibonacci 38.2% | P×0.97 |
| **S2** | MA50 / MA120；或前低；或 Fibonacci 61.8% | P×0.94 |
| **S3** | MA120 / MA250；或前重要低点；或 ATR 三倍止损 | P×0.90 |

> ATR 取值周期为14，用于动态调整价位间距。高波动股票（ATR/价格>5%）的价位间距应放宽，低波动股票（ATR/价格<2%）适当收紧。

## 6.3 仓位管理体系

### 6.3.1 单只股票仓位上限

| 综合评分 | 评级 | 单只仓位上限 | 建议配置 |
|:--------:|:----|:-----------:|:---------|
| ≥85 | 强烈关注 | 30% | 可重点配置 |
| 70-84 | 关注 | 20% | 正常配置 |
| 55-69 | 观察 | 10% | 轻仓试探 |
| 40-54 | 谨慎 | 5% | 极轻仓或观望 |
| <40 | 回避 | 0% | 不参与 |

### 6.3.2 分批建仓/加仓规则

| 买入梯队 | 价位 | 仓位比例 | 条件 |
|:---------|:-----|:--------:|:-----|
| 第一笔 | 回调至S1附近企稳 | 目标仓位的40% | S1处出现止跌信号（缩量十字星/下影线） |
| 第二笔 | 回调至S2附近企稳 | 目标仓位的30% | S2处放量企稳或出现底背离 |
| 第三笔 | 突破R1回踩确认 | 目标仓位的30% | 突破R1后回踩不破，确认有效突破 |

### 6.3.3 仓位调整规则

| 触发条件 | 操作 | 逻辑 |
|:---------|:-----|:------|
| 股价从成本价上涨至R1 | 减仓1/3 | 锁定部分利润，降低持仓成本 |
| 股价从成本价上涨至R2 | 减仓1/3 | 进一步锁定利润 |
| 股价从成本价上涨至R3 | 减仓至底仓1/4 | 大幅获利后的利润保护 |
| 股价跌破S1且2日收不回 | 减仓1/2 | 短期趋势可能转弱 |
| 股价跌破S2 | 仅保留底仓或清仓 | 中期趋势存疑 |
| 股价跌破S3 | 无条件清仓 | 趋势破位，纪律性止损 |
| 连续大涨后出现放量滞涨 | 减仓1/2 | 主力出货信号 |

## 6.4 输出优先级规则

当生成分析报告时，**操作建议章节必须放在所有分析内容之后、免责声明之前**，作为报告的"最终结论"。

操作建议的输出顺序：
1. 三周期价格分层一览（快速了解关键价位）
2. 短期操作建议（最紧迫，明日就要用）
3. 中期操作建议（次紧迫，本周/本月参考）
4. 长期操作建议（战略参考）
5. 仓位建议（当前仓位管理）

> 每个重点股票的每日输出中，**短期操作建议的"明日操作情景计划"是唯一必须手把手级别的输出**——告诉持有者明天每种情况怎么应对。
>
> 仓位建议必须明确给出数字（XX%），而不是模糊的"适量加减仓"。
