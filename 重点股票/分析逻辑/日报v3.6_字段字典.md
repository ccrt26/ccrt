# 日报 v3.6 字段字典

> 版本: 3.6.0 | 日期: 2026-06-01 | 关联: 日报v3.6_schema.json

## 一、P0 明日决策卡（9字段）

| 字段 | 类型 | 必填 | 数据源 | 示例 | 规则 |
|:-----|:-----|:----:|:-----|:-----|:-----|
| `t1_action` | enum | ✅ | baseline+delta综合 | `观望` | 六枚举之一，不得与baseline方向矛盾超一级 |
| `current_position_cap` | string | ✅ | 深度baseline×风控折扣 | `0%` | 与触发后仓位分开写 |
| `triggered_position_cap` | string | ✅ | 触发条件+仓位 | `缩量回踩MA20企稳后3%` | 写清触发条件 |
| `key_buy_point` | string | ✅ | 深度baseline S1/S2 | `35.16元(MA20)+缩量<20万手` | 价位+确认条件 |
| `key_sell_point` | string | ❌ | 深度baseline R1/R2 | `放量跌破MA20或收盘<35.16` | 减仓触发价 |
| `forbidden_actions` | string | ✅ | 流金不做清单 | `放量下跌不买;MA20下方不买` | 至少2条 |
| `new_position_stop_loss` | string | ✅ | 买入价-ATR×2 | `32.00元` | 新建仓止损，与已持仓分开 |
| `held_position_stop_loss` | string | ✅ | 深度baseline S3 | `25.66元(S3)` | 无持仓写"无持仓" |
| `confidence_level` | enum | ✅ | 数据完整度+信号胜率 | `中(50-70%)` | 三枚举之一 |
| `action_change` | enum | ✅ | trigger检查结果 | `unchanged` | 五枚举之一 |
| `one_line_conclusion` | string | ✅ | 综合判断 | `中期逻辑未破，等缩量企稳` | ≤40字 |

## 二、action_change 五枚举

| 值 | 含义 | 触发条件 | 后续动作 |
|:-----|:-----|:-----|:-----|
| `upgrade` | 增强 | >=2独立维度正向确认 | 可上调仓位上限或提前触发 |
| `unchanged` | 不变 | delta与baseline一致 | 维持原策略 |
| `downgrade` | 降级 | >=1关键维度恶化 | 降低仓位上限或推迟触发 |
| `stop_watch` | 暂停 | baseline被部分否定但不反转 | 完全停止操作，进入观察 |
| `reanalysis_required` | 需重评 | 触发10条重评条件之一 | 腰子全团咨询 |

### 4.2 四档资金（日报§2.2 必须输出）
| 字段 | 类型 | 数据源 | 规则 |
|:-----|:-----|:-----|:-----|
| `super_large_net` | string | [9]东方财富 | 超大单净额，T+1延迟 |
| `large_net` | string | [9]东方财富 | 大单净额 |
| `mid_small_net` | string | [9]东方财富 | 中小单净额 |
| `main_force_total` | string | [9]计算 | 超大单+大单合计 |
| `structure_judgment` | enum | AI判断 | 共识/分歧/大资金撤散户接/资金认可/资金分歧/抛压释放 |

结构判断规则：
- 超大单流出+大单流出+小单流入 → 大资金撤，散户接，禁止抄底
- 超大单流入+大单流入+缩量企稳 → 资金认可，允许小仓位试探
- 超大单流出+大单流入 → 资金分歧，降低置信度
- 主力净流出但跌幅缩小 → 抛压释放，等待次日确认

## 五、信号胜率

| 字段 | 类型 | 规则 |
|:-----|:-----|:-----|
| `signal_id` | string | 如TECH_007/FUND_001 |
| `signal_name` | string | 信号名称 |
| `sample_count` | int | <20→low_sample=true |
| `t1_winrate` | float(%) | <50%→不得增强买入 |
| `t5_winrate` | float(%) | <50%→不得增强T+5乐观结论 |
| `avg_t1_return` | float | — |
| `avg_t5_return` | float | — |
| `max_drawdown` | float | — |
| `low_sample` | bool | sample_count<20→true |
| `usable_for_buy` | bool | t1_winrate>=50%且!low_sample→true |
| `impact_on_action` | string | 对明日动作的影响描述 |

降权规则：
1. 胜率<50%：不得增强买入建议，只能辅助
2. 样本<20：标注low_sample，不能单独决策
3. 多低胜率(均<50%)共振：降置信度，不简单加分
4. 高+低混合：以高胜率为主，低不参与加权

## 十一、禁止级矛盾（PDF闸门拦截）

| # | 矛盾 | 检测方法 |
|:--|:-----|:-----|
| 1 | 仓位上限0%但建议立即买入 | p0_action∈{加仓,试探} AND current_position_cap=0% → BLOCK |
| 2 | 止损价前后不一致 | new_position_stop_loss ≠ held_position_stop_loss 但只有一个数字 → BLOCK |
| 3 | 日期与星期错误 | trade_date的weekday ≠ 文中写的星期 → BLOCK |
| 4 | 量能判断前后冲突 | "缩量休整"+"放量下跌"同时出现 → BLOCK |
| 5 | 评分格式错误 | 出现"60/10"等非标准格式 → BLOCK |
| 6 | 本地有数据但写不可获取 | 融资[12]出现"不可获取" → BLOCK |
| 7 | 低胜率强化买入 | t1_winrate<50% AND 文中出现"信号支持买入" → BLOCK |
