## v1.0 (2026-05-21)

**初始版本**。基于多周期多维度融合分析框架建立重点股票跟踪体系。

### 新增内容

1. **第一章 多维度分析框架** — 六大独立分析维度
   - 1.1 技术面：多周期MA趋势判断 + Wyckoff量价分析 + 经典形态 + 指标组合 + K线形态
   - 1.2 基本面：财务健康评估（ROE/毛利率/增长率等）+ 估值评估 + 核心竞争力
   - 1.3 消息面与情绪面：S/A/B/C催化剂分级 + 催化剂跟踪 + 情绪指标 + 验证规则
   - 1.4 板块与行业：板块五相位判断 + 轮动位置 + 行业内联动分析
   - 1.5 资金面：主力资金追踪 + 成交量分析 + 筹码分布分析

2. **第二章 三周期预判体系** — 短/中/长期预判框架
   - 2.1 短期（1-5日）：35%技术形态 + 20%均线 + 15%指标 + 15%消息 + 15%大盘
   - 2.2 中期（1-4周）：30%周线趋势 + 20%板块 + 20%催化 + 15%基本面 + 15%资金
   - 2.3 长期（1-6月）：30%基本面 + 25%行业趋势 + 20%月线 + 15%宏观 + 10%机构
   - 2.4 三周期综合判断矩阵（10种组合场景）

3. **第三章 综合评分与评级体系**
   - 3.1 六维加权评分（技术25%/基本面20%/消息15%/板块20%/资金15%/宏观5%）
   - 3.2 综合评级（★★★★~☆）
   - 3.3 趋势健康度评估 + 触发规则

4. **第四章 跟踪与更新机制**
   - 4.1 重点股票档案结构
   - 4.2 多级更新频率（每日/即时/财报/每周）
   - 4.3 三池管理（核心观察10只/跟踪20只/雷达30只）
   - 4.4 退出机制

5. **第五章 数据存储与版本管理**

6. **附录A/B** — 分析流程速查卡 + 关键术语表

### 设计原则
- 广度与深度分离（与每日荐股互补）
- 多周期融合（短/中/长期同时预判）
- 证据加权（多维度交叉验证）
- 持续跟踪（档案化管理）
- 可验证可回溯（事后对错判断）
