# 一、评估体系概述

## 1.1 目的与范围

**目的：** 对前日生成的重点股票分析报告进行系统性复盘，评估六维评分、三周期预判、趋势健康度、关键价位的准确性，持续改进分析逻辑。

**范围：**
- 评估对象：前日生成的每份重点股票分析报告
- 评估频率：每个交易日盘后执行
- 评估数量：全部在库重点股票（当前6只）

## 1.2 评估触发条件

| 条件 | 说明 |
|:----|:-----|
| 时间条件 | 每个交易日下午收盘后（15:00后） |
| 数据条件 | 当日行情数据可获取 |
| 前置条件 | 前日已生成对应的分析报告 |
| 特殊条件 | 节假日/停牌自动跳过 |

## 1.3 评估流程

```
前日报告数据 → 采集当日行情 → 逐项对比验证 → 打分评估 → 生成复盘报告 → 更新优化记录 → 触发自优化(可选)
```

1. 读取前日报告的关键数据（评分、预判、关键价位）
2. 采集当日行情数据
3. 逐项对比预测 vs 实际
4. 按评估维度打分
5. 生成结构化复盘报告
6. 更新历史准确率跟踪表
7. 判断是否触发自优化

# 二、评估维度与评分标准

## 2.1 方向预判评估 (30分)

### 2.1.1 短期方向评估 (15分)

对比前日报告的短期预判（看多/偏多/中性/看空/看空）与当日实际涨跌幅：

| 预判方向 | ✅ 正确 (满分) | ⚠️ 部分正确 (50%) | ❌ 错误 (0分) |
|:---------|:-------------|:-----------------|:-------------|
| 看多 | 当日涨跌幅 ≥ +0.5% | +0% ≤ 涨跌幅 < +0.5% | 涨跌幅 < 0% |
| 偏多 | 当日涨跌幅 > 0% | -0.5% ≤ 涨跌幅 ≤ 0% | 涨跌幅 < -0.5% |
| 中性 | 涨跌幅在±1%以内 | ±1% < 涨跌幅 ≤ ±2% | 涨跌幅 > ±2% |
| 看空 | 当日涨跌幅 < -0.5% | -0.5% ≤ 涨跌幅 ≤ 0% | 涨跌幅 > 0% |

评分规则：正确得15分，部分正确得8分，错误得0分

### 2.1.2 日内波动评估 (15分)

评估前日预判的波动方向是否准确：
- 若预判为"看多"或"偏多"，当日最高价 > 开盘价：正确(15分)；否则(0分)
- 若预判为"看空"，当日最低价 < 开盘价：正确(15分)；否则(0分)
- 若预判为"中性"，当日振幅 ≤ 3%：正确(15分)；否则(0分)

## 2.2 关键价位验证 (20分)

### 2.2.1 支撑位验证 (8分)

- 当日最低价 > 预测支撑位 × 0.98 → 支撑有效 (8分)
- 当日最低价在支撑位 × 0.95 ~ 0.98 → 部分有效 (4分)
- 当日最低价 < 支撑位 × 0.95 → 支撑失效 (0分)

### 2.2.2 阻力位验证 (8分)

- 当日最高价 < 预测阻力位 × 1.02 → 阻力有效 (8分)
- 当日最高价在阻力位 × 1.02 ~ 1.05 → 部分有效 (4分)
- 当日最高价 > 阻力位 × 1.05 → 阻力失效 (0分)

### 2.2.3 止损位验证 (4分)

- 当日最低价 > 预测止损位 → 未触发 (4分)
- 当日最低价 ≤ 预测止损位 → 已触发 (0分)（自动标记风险）

## 2.3 技术面验证 (20分)

### 2.3.1 MA趋势延续性 (6分)

前日判断的MA趋势（多头/空头/纠缠）在当日是否延续：
- 趋势延续 → 6分
- 趋势走弱（多头→纠缠，或空头→纠缠） → 3分
- 趋势逆转（多头→空头，或空头→多头） → 0分

### 2.3.2 MACD信号验证 (6分)

前日MACD判断（金叉/死叉/零轴上/零轴下）与当日对比：
- 信号增强或维持 → 6分
- 信号走弱 → 3分
- 信号逆转 → 0分

### 2.3.3 RSI区域判断 (4分)

前日RSI判断（超买/正常/超卖）与当日对比：
- 判断准确 → 4分
- 偏差1个区间 → 2分
- 偏差2个区间以上 → 0分

### 2.3.4 量能分析验证 (4分)

前日量能判断（放量上涨/缩量下跌等）与当日实际量价关系对比：
- 准确 → 4分
- 部分准确 → 2分
- 不准确 → 0分

## 2.4 报告质量评估 (30分)

### 2.4.1 数据源完整性 (8分)

- 所有关键数据有[编号]标注 → 8分
- 部分缺失 → 4分
- 多处缺失 → 0分

### 2.4.2 分析逻辑一致性 (8分)

- 评分与文字分析一致，无前后矛盾 → 8分
- 少量不一致 → 4分
- 多处矛盾 → 0分

### 2.4.3 风险提示充分性 (7分)

- 有明确风险提示和免责声明 → 7分
- 风险提示不完整 → 3分
- 无风险提示 → 0分

### 2.4.4 格式规范性 (7分)

- 报告结构完整、格式规范 → 7分
- 结构基本完整 → 3分
- 结构混乱 → 0分

## 2.5 综合评分与评级

| 综合评分 | 评级 | 说明 |
|:-------:|:----|:-----|
| ≥ 85 | ⭐⭐⭐⭐⭐ 优秀 | 预判准确，报告质量高 |
| ≥ 70 | ⭐⭐⭐⭐ 良好 | 主要预判正确，需微调 |
| ≥ 55 | ⭐⭐⭐ 一般 | 部分预判正确，需改进 |
| ≥ 40 | ⭐⭐ 较差 | 多数预判失准，需审视逻辑 |
| < 40 | ⭐ 差 | 预判错误，需重大修正 |

### 2.5.1 一票否决

以下情况直接评为"差"（无需继续评分）：
- 方向预判完全相反（看多→大跌，看空→大涨）
- 关键价位全部失效
- 数据源标注缺失超过3处

# 三、评估算法

## 3.1 方向预判评分算法

```
Score_Direction = Score_ShortTerm + Score_Intraday

Score_ShortTerm (0~15):
  - 基于§2.1.1表格映射预判→结果
  - 正确=15, 部分=8, 错误=0

Score_Intraday (0~15):
  - 基于§2.1.2判断日内方向
  - 正确=15, 错误=0

Score_Direction_Max = 30
```

## 3.2 关键价位评分算法

```
Score_Levels = Score_Support + Score_Resistance + Score_StopLoss

Score_Support (0~8):
  - Low > Support*0.98 → 8
  - Low > Support*0.95 → 4
  - else → 0

Score_Resistance (0~8):
  - High < Resist*1.02 → 8
  - High < Resist*1.05 → 4
  - else → 0

Score_StopLoss (0~4):
  - Low > StopLoss → 4
  - else → 0

Score_Levels_Max = 20
```

## 3.3 技术面评分算法

```
Score_Tech = Score_MA + Score_MACD + Score_RSI + Score_Volume

Score_MA (0~6): 趋势延续=6, 走弱=3, 逆转=0
Score_MACD (0~6): 增强/维持=6, 走弱=3, 逆转=0
Score_RSI (0~4): 准确=4, 偏差1区间=2, 更多=0
Score_Volume (0~4): 准确=4, 部分=2, 不准确=0

Score_Tech_Max = 20
```

## 3.4 质量评分算法

```
Score_Quality = Score_Source + Score_Logic + Score_Risk + Score_Format

Score_Source (0~8): 完整=8, 部分缺失=4, 多处缺失=0
Score_Logic (0~8): 一致=8, 少量不一致=4, 多处矛盾=0
Score_Risk (0~7): 充分=7, 不完整=3, 无=0
Score_Format (0~7): 规范=7, 基本完整=3, 混乱=0

Score_Quality_Max = 30
```

## 3.5 综合评分

```
Score_Total = Score_Direction + Score_Levels + Score_Tech + Score_Quality

Score_Total 范围: 0~100

评估评级:
  ≥ 85 → 优秀
  ≥ 70 → 良好  
  ≥ 55 → 一般
  ≥ 40 → 较差
  < 40 → 差
```

## 4.1 报告结构

每份复盘报告应包含以下章节：

6. **数据来源附录**

# 五、自优化机制

## 5.1 评估指标跟踪

每次评估后，更新以下跟踪指标：

```
每维度准确率  = 某维度得分 / 该维度满分 × 100%
综合准确率    = 综合得分 / 100 × 100%
方向预判准确率 = 方向得分 / 30 × 100%
关键价位准确率 = 价位得分 / 20 × 100%
```

跟踪表存储在：`重点股票\次日评估\评估准确率跟踪.csv`

## 5.2 阈值优化

当累计评估达到5次后，自动分析各维度评分与次日实际走势的相关性：

| 分析项 | 方法 | 输出 |
|:-------|:-----|:-----|
| 评分区分度 | 高分股票次日是否确实表现更好 | 评分有效性系数 |
| 维度权重优化 | 回归分析各维度权重 | 建议的新权重分配 |
| 评分阈值调整 | 最优评分分段阈值 | 阈值调整建议 |

## 5.3 权重调整

当满足以下条件时，触发权重优化：
1. 累计评估 ≥ 5次
2. 连续3次某维度评分与实际情况偏差 > 20%
3. 某维度准确率持续低于50%

权重调整幅度：单次调整不超过±5个百分点

## 5.4 优化执行流程

```
触发自优化条件
  ↓
读取历史评估数据（最近N次）
  ↓
统计分析各维度准确率
  ↓
生成优化建议报告
  ↓
人工确认是否执行优化
  ↓
更新重点股票跟踪分析逻辑白皮书（新版本）
  ↓
更新后评估白皮书版本
```

## 5.5 优化记录保存

每次优化必须记录：
- 触发条件
- 分析数据（N次评估结果摘要）
- 建议变更内容
- 是否执行
- 执行后效果跟踪
