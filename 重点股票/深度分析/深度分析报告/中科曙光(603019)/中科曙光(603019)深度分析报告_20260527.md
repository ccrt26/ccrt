| 维度 | 内容 |

| 所属行业 | 计算机/服务器（申万一级: 计算机） |
| 主营业务 | AI服务器(国产GPU/昇腾)+液冷数据中心+高性能存储 |
| 市场地位 | 国内HPC市占率>50%，国产AI服务器第一梯队 |
| 上市板块 | 上交所主板 |

### 1.2 核心投资逻辑

1. **国产AI算力需求爆发** — 昇腾芯片出货量爆发→曙光作为核心OEM直接受益
2. **液冷渗透率提升** — 数据中心PUE政策+高密度AI芯片→液冷标配化
3. **信创服务器替代** — 政府/国企国产服务器采购→存量替代市场
4. **海光信息投资收益** — 持有海光信息约28%股权→投资收益贡献可观
