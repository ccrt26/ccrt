## 一、公司概要

### 1.1 业务描述

东睦股份是国内粉末冶金(P/M)及金属注射成型(MIM)领域的龙头企业，产品覆盖汽车零部件(粉末冶金齿轮/轴承)、消费电子铰链(MIM折叠屏铰链)、医疗器械及机器人关节零部件。

| 维度 | 内容 |
|:-----|:-----|
| 所属行业 | 机械设备（申万一级）/ 粉末冶金（二级） |
| 主营业务 | 粉末冶金+金属注射成型(MIM)+软磁材料 |
| 市场地位 | 国内粉末冶金龙头，MIM折叠屏铰链国内最大供应商 |
| 上市板块 | 上海主板 |

### 1.2 核心投资逻辑

1. **折叠屏铰链MIM核心供应商** — 华为/OPPO/小米折叠屏铰链MIM件核心供应商，折叠屏渗透率从2%→8%的加速期
2. **机器人概念+粉末冶金齿轮** — 人形机器人关节齿轮需求（MIM工艺天然适配），概念催化+实质需求双重逻辑
3. **汽车粉末冶金轻量化** — 传统粉末冶金齿轮/轴承受益于混动车型增量（变速箱+电驱系统）
4. **软磁材料（新能源）** — 金属软磁粉芯用于新能源汽车OBC/光伏逆变器，第二增长曲线

### 1.3 子赛道三步下钻

```
第1步 — 申万一级：机械设备
第2步 — 申万二级/三级：通用设备 / 粉末冶金制品
第3步 — 核心概念赛道：折叠屏MIM铰链 + 机器人关节零部件 ← 资金定价锚点
```
