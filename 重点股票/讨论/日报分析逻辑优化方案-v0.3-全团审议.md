## 二、全团一致性结论（无需争议）

以下6条为山猫+信鸽+玉夜+流金+青山全体同意，腰子确认生效，冻结为口径规则：

### 2.1 日报总定位 ✅

> 日报不是荐股，不是小深度分析。日报是**已关注标的的状态变化检查器 + 周报指令执行器 + 后评估留痕入口**。

腰子整合说明：三套体系边界（日报 vs 深度分析 vs 每日荐股）按原文 v0.2 的表不修改，全团认可。

### 2.2 五层装载模型 ✅

L0 路由层 → L1 权威层 → L2 周报层 → L3 日频增量层 → L4 触发与留痕层

全团确认模型结构合理，频率匹配正确。L2周报层的A4/A5/A7引用、L3只算增量变化、L4做状态切换和留痕，无争议。

### 2.3 用户摘要结构 ✅

固定5项（今日状态/今天变了什么/主要风险/接下来盯/明确结论），控制在1屏内，结论必须明确可执行。全团支持。

**补充禁止表达表（全团确认，较v0.2新增）**：

| 禁止表达 | 问题 | 替代表达 |
|:---------|:-----|:---------|
| 后续关注 | 没有动作 | 继续跟踪，明天只看XX元是否守住 |
| 需进一步观察 | 没有判断 | 等待确认，不新增观察动作 |
| 风险可控但需警惕 | 结论含糊 | 降级观察，跌破XX且次日未收回 |
| 短期扰动不影响长期 | 没有证据边界 | 移出跟踪，除非mini深度分析重新通过 |
| 数据表现较好建议留意 | 堆数据没动作 | 继续跟踪，核验逻辑未变 |

### 2.4 状态机 ✅

采用 A/B/C/D/E/M 六状态，不另造新状态。状态定义按v0.2原文不变。

**腰子裁决确认以下口径**：
- E严格限定为B的子状态，A状态下不活跃
- D回B必须满足：mini深度分析 + 至少1条L1新事实 + 团队确认
- M层只做宏观覆写，不改变个股基础状态

### 2.5 结论规则 ✅

日报最终结论只能写：
1. 继续跟踪
2. 等待确认
3. 降级观察
4. 移出跟踪

附加M激活时改："（临时覆写）暂停动作"

### 2.6 数据缺失处理 ✅

数据缺失时统一走 `degraded_items/WARN/BLOCK`，禁止正文写"不可获取"糊过去。全团支持。

## 三、全团分歧及腰子裁决（部分修改意见）

### 3.1 M层触发条件（山猫提案 → 通过并细化）

**山猫意见**：三条硬性触发（恐慌情绪/流动性危机/黑天鹅）+ 建议增P1级关注。

**腰子裁决**：采纳并升级为：

| 级别 | 触发条件 | 响应 |
|:-----|:---------|:-----|
| M-P0（强制覆写） | ① 全A涨跌比≤1:5且跌停≥50家 ② DR007≥2.0%且央行连续3日净回笼 ③ 指数单日-3%+或重大黑天鹅 | 自动暂停所有买入动作，日报标注"宏观覆写中" |
| M-P1（关注/预警） | ① 连续3日温和恶化（如DR007逐日上行但未超阈）② 情绪极端（恐慌≥85或贪婪≥80） | 标记"宏观关注"，山猫确认后升级为M-P0 |

M-P0最长维持3个交易日（流金约束），超时后要么解除覆写，要么进入正式状态重评估。

**M触发后日报必须标注触发依据的具体指标和数值**，不可笼统写"宏观风险"。

### 3.2 事件在日报中的执行（信鸽提案 → 通过）

**信鸽意见**：日报不重新做事件分析，只做三件事：
1. 周报约定的催化事件今日有无新进展（引用信鸽采集结果）
2. 有无意外P0事件触发
3. 到期事件是否按时兑现

**腰子裁决**：通过。A4指令执行表中每条D-n（周报事件观察项）必须标注：
- 事件等级（P0/P1/P2）
- 预期触发窗口（expected_trigger_date）
- 当前状态（未到期/到期未兑现/已兑现/延期）

日报阶段据此判断"到期未兑现→B等待确认"或"到期已兑现→支持A状态"。

### 3.3 状态切换的风控约束（流金提案 → 通过）

**流金提出的5条约束**：

| # | 约束 | 腰子裁决 |
|:--|:-----|:---------|
| ① | B→A需要3个交易日冷却期 | ✅ 通过，写入状态切换规则 |
| ② | C维持5日自动触发移出检查 | ✅ 通过 |
| ③ | E状态仓位≤2% | ✅ 通过，但这是仓位规则，记入交易纪律不影响日报逻辑 |
| ④ | M时效3日，超时解除或重评估 | ✅ 通过 |
| ⑤ | 否决项定义须与白皮书一致 | ✅ 通过 |

**追加裁决**：红灯状态下（风险灯🔴）即使周报指令说"继续跟踪"，日报结论也必须降级，不做例外。风控高于逻辑。

## 七、建议冻结的 8 条口径（最终版）

> 以下8条为全团咨询后冻结的正式口径，G3阶段以此为准：

1. **日报定位**：日报是"状态变化检查器 + 周报指令执行器 + 后评估留痕入口"，不是荐股，不是小深度分析。

2. **用户摘要**：固定5项（今日状态/今天变了什么/主要风险/接下来盯/明确结论），放在日报最前面，控制1屏内，结论必须可执行。

3. **用户摘要质量要求**：禁止使用替代表中的8条禁用表达，每条结论必须动作化。

4. **状态机**：A/B/C/D/E/M 六状态为唯一状态机，E严格为B的子状态。

5. **D回B条件**：mini深度分析 + 至少1条L1新事实 + 团队确认，缺一不可。

6. **M层约束**：M-P0/M-P1两级，最长3日，触发标注具体指标。

7. **数据缺失处理**：统一走 degraded_items/WARN/BLOCK，禁止正文"不可获取"糊弄。

8. **风控优先级**：红灯状态下，风控高于周报逻辑。
