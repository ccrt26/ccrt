## 9. 样式变更管理流程

### 9.1 变更权限

| 行为 | 权限 |
|:-----|:-----|
| 修改样式基线文档本身 | 仅限人工 |
| 修改报告生成代码中的样式 | AI可提议，须经人工确认 |
| 新增CSS类名 | AI可提议，须经人工确认 |
| 修改颜色值/字体/字号 | AI可提议，须经人工确认 |
| 修改页面布局结构 | AI可提议，须经人工确认 |
| 样式冻结类名清单的增删 | 仅限人工 |

### 9.2 变更流程

1. **提议**: 在对应 `CHANGELOG.md` 或 `改进日志.md` 中记录样式变更需求及理由
2. **确认**: 人工确认变更是否可执行
3. **执行**: 修改对应生成代码中的样式定义
4. **同步**: 更新本样式基线文档（更新版本号 + 变更记录）
5. **通知**: 确保 PreToolUse hook 的样式检查规则同步更新

### 9.3 版本历史

| 版本 | 日期 | 变更内容 |
|:-----|:-----|:---------|
| v1.0 | 2026-05-22 | 初始版本，冻结所有报告样式基线 |
